## 0. 一句话定义

**第一波涨了 D（A→B），整理后回落到 C，当价格重新越过 B（前高）时，第二波目标 = C + D。**

```
A ─╮                        ╭ B  ← 第一波高点（必须被越过才算成立）
    ╰╮      ╭──────────────╮│
     ╰╮    ╱  矩形/下漂旗   ╰╮
      ╰─A─╯                  ╰╮  ← 越过 B：确认 C 是低点
       │                      ╰╮
       └── D = B − A ──┐        ╰→ 第二波目标 = C + D
                        C
```

**与跌幅满足完全镜像**：跌的那篇是「跌破前低才追认反弹高点 C，目标 = C − D」；这篇是「越过前高才追认回档低点 C，目标 = C + D」。**都是拿 C 当投影基准，不是拿颈线/前高当基准。**

## 1. 为什么算得这么准——主力作价习性（本课真正的核心）

讲义开头花了三分之一的篇幅讲这个，不是废话，是这套方法能用的**唯一理由**：

> "我拉了一档股票，从 20 块拉到 30 块，这是我作价习性。20 拉到 30 拉了十块。整理完之后下一波我从 28 块拉，那我就很习惯地再拉十块钱，到 38 块左右。这就是所谓的一个满足。"

三个层次：

1. **同一个主力，每一波拉相同幅度**（或相近幅度）。这是"习性"，不是数学规律
2. **不同股票、不同主力，幅度完全不同**："每个人走路姿势都不一样，睡姿也不同"
3. 所以公式是 `D（这只股票这只主力的习惯幅度）+ C`，**D 必须从这只股票自己身上量**，不能套用别的股票、不能用行业平均

**"随便一拉都 20%"**——讲义原话："破底翻的时候就已经讲主力作价，随便一拉都 20%，几乎没有低于 20%。低于 20% 表示他作价失败。会失败的主力还蛮少的，要当主力一定有本事的。"

→ **推论（这是可以拿来筛票的）**：底部确认后，如果第一波涨幅不到 20%，说明这不是主力做的，或者主力做失败了。**这种票的"第二波"不要等。**

## 2. 成立的三个前置条件（缺一不算）

| 条件 | 判定 | 讲义原话 |
|---|---|---|
| **① 越过前高 B** | 价格必须实打实穿过第一波高点 | "一定要越过这个 35 块才能确定 30 块是低点。要不然你随时都去算啊，这边也有低点，到底确定哪个次低点" |
| **② 起涨低点 C 被确认** | C 是整理段的最低点，且已被"越过前高"这个动作追认 | 同上 |
| **③ 第一波 D 完整** | A→B 是一段完整上涨，不是上涨中的一根 K 线 | 隐含 |

**条件①是全课的技术核心，和跌幅满足的"必须跌破前低"是同一条规则的镜像。**

**可以算 / 不可以算：**

| 可以算 | 不可以算 |
|---|---|
| 第一波完整、整理结束、已越过前高 | 还在整理中，没越过前高（C 未确认） |
| 整理形态清晰（矩形/下漂旗/收敛） | 整理段没有明显低点（一路横盘，C 不唯一） |
| 同一复权口径 | 跨除权日拼接 |
| 主力作价痕迹明显（放量突破） | 无量假突破（见 §6） |

## 3. 算法与两个易错点

```
D = B − A          （第一波幅度：从起涨低点到第一波高点）
目标 = C + D        （C = 整理后的起涨低点）
```

### 易错点一：用"突破点"起算，而不是"整理低点 C"

收敛三角那课是「**突破点** + 边长」，这课是「**整理低点 C** + 第一波幅度」。**两个基准不同，不要混**：

| 工具 | 起算基准 | 算的是哪一段 |
|---|---|---|
| 收敛三角边长法 | 突破颈线的**实际价位** | 突破后**第一段**的目标 |
| 波段涨幅满足 | 整理段的**最低点 C** | **第二段**的目标 |

工行同一只股票两种算法（都成立，见 §4）：三角法第一波 5.15，波段法的"第一波"是 4.50→6.16 那一段——**它们算的根本不是同一段**。

### 易错点二：D 用"收盘"还是"最高最低"

讲义全部用**最高价 − 最低价**（不是收盘价）。因为它要捕捉的是主力"拉到哪、砸到哪"，收盘价会被尾盘做图干扰。

→ 复盘时统一用极值，并且注明是日线还是周线的极值（周期不同，D 能差 5%~15%）。

## 4. 与收敛三角法的交叉验证（工行实例）

同一只股票、同一波行情，两个独立算法给出的目标几乎重合，这是**最高置信度**的信号：

| 算法 | 第一段 | 第二段目标 | 实际最高（2018 视角前复权） |
|---|---|---|---|
| 收敛三角边长法 | 2.95 + 2.2 = **5.15** | 5.15 + 2.2 = **7.35** | 5.23 / **7.53** |
| 波段涨幅满足 | 4.50→6.16（D=1.66） | 5.57 + 1.66 = **7.23** | — / **7.53** |

两法都指向 **7.2~7.35**，实际 7.53，都低估 2.4%~4.2%。

**用法：两个算法算出来的目标相差在 3% 以内 → 高置信，按此止盈。差 10% 以上 → 说明形态认定有误，回去重画。**

## 5. 中途整理的形态规律（决定第二波能不能来）

> "第一波涨上来之后，通常都会往下整理，先洗掉第一波的获利了结单子，然后再拉第二波，这个叫做甩轿。"

| 方向 | 中途整理形态 | 目的 |
|---|---|---|
| **上涨中继** | **矩形**（最常见）/ **下漂旗**（斜向下）/ 收敛三角 | 洗掉第一波获利盘（甩轿） |
| **下跌中继** | **矩形** / **上漂旗**（斜向上） | 诱多后再叠一段 |

**为什么会做成"下漂旗"**：往下斜的整理让持筹者以为见顶了，交出去；然后再拉。所以**下漂旗是上涨中继的典型形态，不是见顶信号**。

崩跌方向反过来：下跌中做成"上漂旗"，让抢反弹的人以为反转了，然后再跌一段。

**破底翻也是甩轿的一种**（讲义原话）——所以整理段里出现破底翻，是洗盘不是转空。

## 6. 满足点之后：满足就好，然后大概率假突破

这是本课给的**风控出口**，也是全课最实用的一段：

> "为什么叫满足点？就是满足就好了。人要懂得满足……有时候它还可能再涨一波，但是你经常做这种满足的感觉，大部分你都是对的。错过一只也没关系——一只股票从 4 块涨到 14 块了，你还要多少？"

**满足点后的典型剧本（12 例中至少 6 例出现）**：

```
到达满足点 → 假突破（过一点点就掉）→ 崩跌
```

讲义称假突破为**"逃顶的神招"**，与破底翻"抄底神器"配对：

| 位置 | 招式 | 用法 |
|---|---|---|
| 底部 | 破底翻 | 抄底信号 |
| 顶部/满足点 | 假突破 | 逃顶信号 |

**赣锋锂业是最典型的"卖早不卖晚"**：目标 61.95，实际冲到 68.73（超 10.9%），但"两天就下来了"——讲义原话"卖掉不要可惜，也不过是两天的时间"。

→ **到满足点就走，别为了最后 10% 把整段利润还回去。** 12 例里超涨均值只有 +2%，为了抓那 2% 承担 -30% 的回撤不划算。

→ **操作含义（和跌幅满足相反）**：
- 做多止盈：目标 ×1.00 就减第一批，**剩下的一半留着看能不能到 ×1.05**（因为有 25% 的概率超 5%）
- 做空/抄底：目标给区间，别指望穿太多

**规律三：低价股的偏差没有放大。** 银行股（4.69、7.23）与高价股（保利 14.24、平安 75.85）精度相当——因为 D 是绝对涨幅，低价股 D 小、误差也同比缩小。这与跌幅满足"低价股偏差 5.6%"形成对比，是涨跌不对称的又一证据。

## 8. 落地清单 / 禁止清单

**算之前必须确认的 5 件事：**
1. 第一波 A→B 完整（有明确起涨低点和第一波高点）
2. **已越过前高 B**——没越过不算，C 不成立
3. 整理形态清晰（矩形/下漂旗/收敛），C 是整理段最低点
4. 复权口径统一、周期统一（日线就全程日线）
5. D 取自**这只股票自己的第一波**，不套用别的股票

**算完之后必须做的 3 件事：**
1. **目标 ×1.00 减第一批**（12 例中 58% 落在 ±2%，别指望穿太多）
2. 留一半到 ×1.05（25% 概率超 5%，如赣锋 +10.9%）
3. 目标位挂好止盈后，**盯假突破**：过目标一点点就掉头 = 逃顶信号，清掉

**绝对禁止：**
- ❌ 没越过前高就算（"这样每个地方都是低点"）
- ❌ 用突破点替代 C（那是收敛三角的基准，不是这课的）
- ❌ 拿别的股票的 D 套过来（"每个主力走路姿势都不一样"）
- ❌ 满足点到了不走、等第三波（12 例 0 例给第三波）
- ❌ 第一波涨幅 < 20% 还等第二波（讲义："低于 20% 表示作价失败"）

## 10. 与其它工具的接口

| 工具 | 关系 |
|---|---|
| **波段跌幅满足** | 完全镜像。跌用 `C − D` 定价值区（左侧），涨用 `C + D` 定目标（右侧） |
| **收敛三角形涨幅满足** | 不同层级：边长法算突破后第一段，本法算第二段。两法目标差 3% 内 = 高置信（工行实例） |
| 破底翻 | 抄底神器，与本法配合：破底翻入场 → 涨幅满足出场 |
| 假突破 | 逃顶神招，满足点后的标准剧本 |
| 主力洗盘（甩轿） | 中途整理的本质；下漂旗/矩形是上涨中继，不是见顶 |
| 量价验证 | 突破必须带量；整理回落必须缩量（"拉回量缩正常，突破带量"） |
