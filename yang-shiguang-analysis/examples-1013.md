# 《今年报》2026-10-13 期：AI盈利拆账与全球杀估值

> **案例说明**：本期是「增长质量」主题的完整示范——把美股 EPS 高增速逐层拆到记忆体的量价贡献，得出「涨价撑增速、增速自带断点」的结论；并用台股筹码三件套读出法人「极度看空但怕反弹」的结构。方法论沉淀见 `references/18-m91-m92.md`（M91 增量量价拆账法、M92 卖权买权比反指判读法）。

## 一、核心逻辑链（节目主线）

```
缺货推单价（HBM4 现货 48-53 美元/GB，合约价仅 19-25）
→ 记忆体贡献全球半导体增量约八成（4330 亿/5661 亿美元）
→ 增量中价贡献 85%（3790 亿 vs 量 640 亿）→ 涨价直接变毛利
→ 美股 Q3 EPS 年增约 26% 几乎全靠半导体（八成）+能源（两成）撑
→ 投行下修 2027 年 HBM 合约价预估（48 → 30 美元）
→ 价格若到不了 30 → EPS 增速急剧放缓（G 因子断）
+ 折现率上行（联储加息周期 + ECB 每月缩表 400 亿）
→ 估值两头挨打 → 股价先于现货价下跌（海力士、三星近腰斩）
```

**M91 演示**：增量 5661 亿 → 品类归因（记忆体 4330 / 逻辑 1080）→ 量价拆分（价占 85%）→ 判定涨价市 → 断点条件（合约价 <30 = 增速断）→ 压力测试（价格持平则增速剩余所剩无几）。

## 二、台股筹码三件套（M92 演示）

## 三、节目其余要点

1. **韩国股市**：连跌五天、跳空跌破年线（200 日线），费城半导体被记忆体双雄拖累；外资年内已从韩股撤近 1500 亿美元，台股更多——「价格反映明年增速，甚至 2028-29 的估值」。
2. **美股结构**：S&P500 超 280 家（过半）跌破年线，但 Q3 EPS 预计年增 16%（S&P 口径）/26%（节目口径）——本益比顶不动（无风险利率 5%+），全靠 EPS 撑；增长集中在半导体与能源，消费类无增速。全球手机出货量 Q3 同比 -20%，回到 14 年前水平。
3. **宏观**：联储新加息周期（两周后或 12 月各一次，明年或还有两次）；欧央行量缩（月 400 亿）→ 法债希债喋喋不休的根子在缩表不在政局。
4. **大陆**：沪深 14 个月低点；「唯一能救的是地产股——地产股反弹股市止跌快，地产股没救股市继续跌」→ 盯地产股即盯 A 股跌速。新能源车出口退税率 13%→9%，行业毛利率不足 4% 被吞掉，「不要听嘴巴怎么说，看身体怎么做」。
5. **印度**：国际收支千亿赤字 + 油价高 → 准外汇管制，卢比贬值压不住，「看印度股市先看印度汇率」。
6. **收尾定性**：AI 是「华尔街资本 + 好莱坞剧本」的收割叙事，发达国家公债收益率走高（美银行/富国 7% 票息至 2093 年）是「收割最后的过程」，买单的是全球投资人——泡沫风险向新兴市场转嫁。
