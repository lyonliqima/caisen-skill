1. **本文件的公式可用，数字必须先过核验表**。公式（副产品扣减、亩→吨换算、仓单分项加总）是方法论，可复用；具体参数（单产 400–600kg/亩、出成率 55%、副产品价 3500 元/吨）属**该文的参数选择**，换品种/换年份必须重估。
2. **判「成本底」必须声明用的是哪一层**。本文最大的价值是揭示了「成本不是一条线，是五层」。引用「跌破成本」时若不标层级 = 无效表述。
3. **「三级及以下=副产品」是本文的口径瑕疵**（见核验表 §2.5）。郑商所三级（280–340 个/kg & 总糖 ≥70%）**仍是替代交割品**，真正的副产品是三级以下的等外品/次枣。引用时须区分。
4. **不可复算的参数只能作参照**：副产品出成率、副产品单价无官方源，标「自述/未验证」。
5. 本文件为**方法论登记**，不构成任何品种的方向判断。

## 一、结论摘要

1. 红枣成本可分为两段：**田间现金成本** → **仓单成本**，中间必须扣减**副产品（次枣/等外品）收入**。
2. 扣除副产品后，**南疆核心产区自有地净种植成本（575–2074 元/吨）远低于通货收购价（≈4000 元/吨）**。
3. 按「不计地租 + 自有地 + 通货压至近年最低 + 新疆制仓单 + 扣副产品」的极端低成本参数，**产业链从田间到盘面仍有利润**：种植端 +1926 元/吨、仓单端 +1951 元/吨（盘面 7580 计）。
4. 推论：**「研报普遍认为的行业亏损」不成立**；某些环节亏损是经营常态，不是行业见底的标志。
5. 作者结论：供给侧现金成本被副产品收入大幅拉低，**产能出清的疼痛阈值被推后**，底部只能「以年为单位慢慢熬」；唯一可能的转机是新一轮天气减产炒作。

## 二、算法拆解（方法论 · 公式原样）

### 2.1 主公式链

```
① 副产品收入（元/亩） = 亩产(kg) × 副产品出成率 × 副产品单价(元/kg)

② 净种植成本（元/亩） = 亩现金成本(元/亩) − 副产品收入(元/亩)

③ 净吨成本（元/吨）  = 净种植成本(元/亩) ÷ 单产(吨/亩)
                    = 亩现金成本 ÷ 单产 − 亩产×出成率×单价 ÷ 单产
                    = 亩现金成本 ÷ 单产 − 出成率×副产品单价×1000

④ 仓单净成本（元/吨） = 净种植成本 + 收购流通加价 + 加工包装运费等（含↓各项）

⑤ 加工包装运费等 = 加工费 + 包装费 + 短途运费 + 出入库费 + 仓储费 + 检验费
                 + 资金利息 + 交割手续费
```

**公式 ③ 的化简很有用**：扣副产品后的净吨成本 = 亩现金成本 ÷ 单产 − (出成率 × 副产品单价 × 1000)。
即副产品抵扣项**与单产无关**（只与出成率和单价有关），单产只影响亩成本的摊薄。

### 2.3 关键设计选择及其理由

| 维度 | 该文怎么算 | 它替代了什么/为什么这么选 | 数据来源与频率 |
|---|---|---|---|
| 副产品抵扣 | 出成率 × 单价，从亩成本中**减掉** | 替代「把总产量当交割品成本」的naive算法——那是把 50%+ 的次枣当废物 | 郑商所/研报；年度（随新季采收） |
| 地租处理 | 自有地口径取 0 | 多年生木本，地租在 1–3 年内是沉没成本，不构成退出决策变量 | 作者另文《红枣——弹性消费，地租成本无意义》 |
| 单产分档 | 400/500/600 kg/亩三档 | 替代单一平均值——揭示「单产是成本最大弹性来源」（400→600kg 使吨成本降 60%） | 未注明；年度 |
| 交割库选址 | 新疆（升贴水 0） | 河北/河南交割库有 **+600 元/吨** 地区升水 → 新疆制仓单是成本最低口径 | 郑商所公告 |

### 内部一致性检查

- 亩成本合计：自有地 0+500+300+100+600+19 = 1,519（下限）、0+800+600+300+800+45 = 2,545（上限），文中「1,500–2,500」为四舍五入区间 ✓
- 亩→吨：1,500÷0.6=2,500 ✓；2,000÷0.5=4,000 ✓；2,500÷0.4=6,250 ✓
- 副产品收入：275×3.5=962.5≈963 ✓；330×3.5=1,155 ✓
- 净吨成本：1,037÷0.5=2,074 ✓；345÷0.6=575 ✓
- 仓单合计：3,889+1,400+450+150+50+180+625+200+0.5 = 6,944.5 ✓；上限 7,499.5≈7,500 ✓
- 仓单净成本：575+500+3,055=4,130 ✓；2,074+500+3,055=5,629 ✓

→ **算术全对，问题只出在口径（§3.5 副产品池定义）与参数自述（§3.7–3.8）。**

### 本框架补充（推论，非事实层）

1. **本文未提但重要的反向数据**：§3.5 的口径错误方向是**对「仍有利润」结论有利**的（副产品池放大→净成本更低→利润更高）。修正口径后（三级仍算交割品，副产品池收窄），**种植端利润会下降、仓单净成本会上移**。即：作者结论方向可能正确，但**幅度被夸大了**。
2. **作者选取「极端低成本参数」是压力测试而非基准情形**。全国平均（含租地、含低产）成本显著高于此。要把表 H 当作**利润上限**，不是中值。
3. **本文的净成本口径与「现金成本」高度重叠**，特别适合判断「农户会不会退出/砍树」，**不适合**判断「产业是否亏损」。两者是不同的问句。

## 六、运输成本口径（2026-09-14 补 · 用户追问「里面不用计算运输成本吗」）

**结论：算了，但只算了一段；另一段被「交割库选址」规避、被「地区升贴水」补偿。**

### 6.1 运输成本在红枣成本链上的两个位置

| 段 | 路径 | 实测值 | 谁承担 / 在哪层 |
|---|---|---|---|
| **短途集货** | 枣园 → 新疆交割库（图木舒克/阿拉尔/阿克苏） | ≈150 元/吨 | 卖方，计入 L4 仓单成本（表 F 已列） |
| **出疆长途** | 新疆 → 沧州（崔尔庄）/郑州 | **420–500 元/吨**（正常季；Mysteel+中泰周报三口径实测 420 / 480–500 / 500）；**旺季约 1000 元/吨**（神华研究院 2019 口径：正常 600 / 旺季 1000） | 内地制仓单则由卖方承担；**新疆制仓单则本就不发生** |
| 到消费终端 | 交割库 → 终端 | 不固定 | **买方**，不进期货成本 |

### 6.2 为什么表 F 里只有「短途运费 150」而没有出疆运费

因为文章把交割库选在**新疆（升贴水 0）**——货不出疆，出疆长途运费**本就不发生**。这是自洽的，不是漏算。

**交易所已把出疆运费制度化**：郑商所红枣交割库 14 家（新疆 10 / 河南 1 / 河北 3），**新疆升贴水 0，河北、河南升水 +600 元/吨**。这个 +600 本质就是「出疆长途运费 + 销区集散成本」的**标准化补偿**，与实测长途运费 420–500（正常）/ 900–1000（旺季）量级吻合。

### 6.3 三个必须写清的口径点

1. **期货成本口径止于「交割库出库价」**。郑商所红枣合约定义：交割基准价 = 基准交割品在**基准仓库出库时汽车板交货的含税价格（含包装）** → 交割库到消费终端的运输**不进期货定价**，属买方成本。文章不算终端运费是对的。
2. **表 F/G 是「新疆口径」**，与「升贴水 0」配套。**若要评估冀豫库交割的真实成本，必须显式加回出疆长途运费 420–500 元/吨（旺季 ≤1000）**，否则低估约 500–600 元/吨——该数恰好与 +600 升水对上。
3. **「收购流通加价 +500 元/吨」是黑箱，与「新疆制仓单」存在潜在口径冲突**。若该 +500 含出疆长途运费，则与「货不出疆」前提矛盾（重复计入/口径不明）；若不含，则它只应是产地集货+分级+贸易利润。**原文未拆解，引用时须标注「口径未公开」。**

### 6.4 对「判成本底」的直接影响

- 文章的 **L3 仓单净成本 ≈5629 元/吨是「新疆最省运费口径」**，等价于**成本下限 / 利润上限**。
- 换成 **冀豫库口径**（+ 出疆运费 420–500）：L3 上移至 ≈**6050–6130 元/吨**；按旺季运费 1000 则 ≈**6629 元/吨**。
- 结论：**盘面 7580 对新疆口径仍有 ~1950 元/吨空间，对冀豫旺季口径收窄至 ~950 元/吨**。方向不变（盘面仍高于成本），但**幅度对「用哪个库、哪个季节」高度敏感** → 引用必须写清区位与季节。

### 6.5 品种特性提示

红枣**不适合铁路运输**（不耐挤压 / 堆放易发热 / 倒驳费高），**出疆全部走汽运**（17.5 m 板车，载重约 30 t）。因此：
- 运费随**油价 + 季节**波动大（旺季较淡季可高 400–500 元/吨）；
- **4 月为分界线必须进冷库**，冷库费是「持有过 4 月」的额外成本；表 F 的「仓储费 180 元/吨（60 天）」只覆盖新疆常温仓 3 元/吨·天，**长持成本另有跳升**。

## 七、与「资金成本」层的分界（2026-09-17 追加 · 交叉指向）

> 本节只做**口径划界与指向**，不改动上文任何成本层。

**要点**：**本文的五层成本（L1–L5）全是「产业成本」，不含任何资金成本。**

- 若某处出现「融资成本 / 资金占用 / 库存搬运成本 / 贸易融资利息」，**不得塞进 L3 或 L4**——那会造成口径污染（把宏观利率变量混进仓单会计口径）。
- 资金成本单独成层，见 **`成本底与资金结构法-20260903.md` 第七节 A6「利率与融资成本口径」**（2026-09-17 追加）。A6 给出三算式（库存搬运成本 / 贸易融资成本 / 库存意愿定性）与两条筛子（进口依赖度分档 / 内外价差领先指标）。
- **判「成本底」时的正确挂法**：`有效成本底 = A4 某一层成本 + A6 该持有期资金成本`。利率上行期必须把 A6 加回去，否则会把「利率抬升导致的成本主动上移」误读成「成本底没动，还有下跌空间」。
- **本层与 A6 的分界一句话**：A4 回答「产业要多少钱才不亏」，A6 回答「钱本身变贵了多少」。两者**并行使用、互不替代**、可相加但不可混同层号。
- **反向提示**：A4 第六节的运输成本（短途 150 / 出疆长途 420–500 或旺季 ≤1000）**也不含资金占用**——运输是服务成本，资金占用按持有天数单独算，二者不重复。

## 八、加工品口径迁移：粕类/饲料蛋白原料（2026-09-17 追加 · 交叉指向）

> 本节只做**口径迁移与指向**，不改动上文任何成本层。归档源：期货团 `caisen-futures-team/references/饲料蛋白原料-粕类定价与价差替代-20260917.md`。

**问题**：本文 L1–L5 是为**种植品**（红枣）设计的——成本 = 田间投入 ÷ 单产 − 副产品。粕类是**加工品**，套用会错。

**迁移映射（三条，方向一致）**：

| 种植品（本文原口径） | 加工品（粕类） | 一致性 |
|---|---|---|
| L1 田间现金成本 − 副产品 = 农户不退出底线 | 粕价底部 ≈ 油籽原料到港成本 ÷ 出粕率 + 压榨费分摊 | 同构：都是"不亏即停产"的底线 |
| **L3 仓单净成本（扣副产品）** | **压榨收益 = 油收入 + 粕收入 − 原料成本 − 加工费** | **粕类的"副产品抵扣项"就是油**——L3 的扣副产品思想可整段搬用 |
| L5 研报宽口径（易高估） | 内外价差倒挂口径（进口完税价，含关税/增值税/港杂，不可复算） | 同构：都是"看起来是成本、其实含不可比项" |

**两条必须新增的口径纪律**（本文原表没有，来自粕类归档）：

1. **库存三级口径**：`油厂库存 / 港口库存 / 交易所仓单` 三者不可互换。实测差 18 倍（菜粕油厂库存 1.0 万吨 vs 郑商所仓单约 18.18 万吨）。→ 这是本文分层纪律在**库存维度**的同构应用：**不标层级的"库存紧"同样是无效表述**。可接 `成本底与资金结构法-20260903.md` 的 A5-4「仓单-成本匹配律」。
2. **单位蛋白成本**：`价格(元/吨) ÷ (蛋白% × 10) = 元/kg蛋白`。跨品种比价在同一"蛋白"基准上才可比。→ 实测：外部来源用绝对价差得出「DDGS 具替代价值」「花生粕失去价格优势」两个结论，改为单位蛋白后**方向双双相反**。

**判粕类"成本底"的正确挂法**：

```
粕类有效成本底 = 油籽原料到港成本 ÷ 出粕率 + 压榨费分摊 + 该持有期资金成本(A6)
                 再按 油粕比 倒推粕端应分摊的份额（粕通常占压榨收入 ~62%）
```

**本层与本文的分界一句话**：L1–L5 回答「种一亩要多少钱才不亏」，第八节回答「榨一吨油籽要多少钱才不亏，其中粕该摊多少」。两者**并行使用、互不替代**，门槛值不可跨用。

**反向提示**：粕类的成本锚**高度依赖外盘**（CBOT 大豆 + 升贴水 + 汇率 + 关税/采购政策），所以它比红枣多了一层**政策变量**——关税磋商、采购节奏、USDA 报告都会整体移动成本底。判粕类成本底时，**必须同时给"政策假设"**，否则锚是浮的。
