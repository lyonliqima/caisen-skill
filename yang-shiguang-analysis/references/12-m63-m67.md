## M63：名义利率三段分解归因法（实际利率 / 通胀补偿 / 期限溢价）

> 任何「利率上行是因为通胀 / 是因为财政」的说法，**在没做三段分解之前，都是猜测**。
> 名义长端 = 实际利率 + 通胀补偿 + 期限溢价。三段的经济含义、持续性、应对方式完全不同——
> 实际利率主导 = 资本竞争 / 生产率预期（货币政策压不住）；通胀补偿主导 = 通胀预期脱锚（要靠鹰派）；
> 期限溢价主导 = 财政供给（要靠削减赤字，货币政策无效）。

### 核心原理

```
名义长端收益率 ≡ 实际利率（TIPS） + 通胀补偿（breakeven） + 期限溢价（模型估计）

三段各自的含义与应对：
  实际利率↑  → 资本需求竞争（AI capex / 国防 / 能源基建）+ 中性利率重估
               → 货币政策无效（加息正是推高实际利率的原因之一）
               → 对策：只能等投资回报率兑现或资本开支退潮
  通胀补偿↑  → 通胀预期脱锚（真正的货币现象）
               → 货币政策有效（鹰派能压）
               → 对策：看 5y5y 是否突破 2.5%
  期限溢价↑  → 财政供给超发 + 持有人结构恶化（官方减持→私人定价）
               → 货币政策无效（央行不买长债就没法压）
               → 对策：看赤字收敛 / 回购是否削减净发行
```

### 三条判据（决定结论怎么写）

```
① 通胀锚判据：5y5y 远期通胀 < 2.5% → 「通胀预期未脱锚」
   → 此时禁止把长端上行写成「通胀中枢抬升 / 通胀失控」
   → 应归因实际利率或期限溢价

② 主因判据：谁贡献了名义变动的 >50%，谁就是主因
   → 必须报出三段各自的 BP 贡献，不能只说「长端涨了 X BP」

③ 模型分歧判据：不同期限溢价模型（ACM / KW / D'Amico-Wei）读数常差 30–80BP
   → 报期限溢价必须带模型名 + 日期
   → 若某模型读数与「财政爆炸」叙事相反，不得静默丢弃，须并列报出
```

### 标准分析步骤

```
□ 第一步：取名义长端（30Y / 10Y）当前值与年初值，算总变动 BP
□ 第二步：取同期限 TIPS 实际利率（FRED DFII30 / DFII10），算实际利率贡献 BP
□ 第三步：取同期限 breakeven（FRED T30YIE / T10YIE），算通胀补偿贡献 BP
          → 残差 = 期限溢价 + 流动性溢价 + 口径误差（并报模型估计值做交叉）
□ 第四步：取 5y5y 远期（FRED T5YIFR）判「锚是否还在」（<2.5% = 在）
□ 第五步：与政策利率路径交叉——若市场抬升的是「risk-neutral 期望短端」而非期限溢价，
          说明市场在重估美联储反应函数（不是财政问题，是政策问题）
□ 第六步：输出三段贡献表 + 主因判定 + 该主因下「货币政策是否有效」
```

### 实战案例（2026-09-17 核验：一次典型的「归因写反」）

**被核验的说法**：某五维推演稿称「美联储上调远期通胀预期 → 通胀中枢会系统性抬升 → 利率中枢也会高于过去 20 年」。

**实测三段分解（2026 年初 → 8/31–9/1）**：

| 段 | 指标 | 年初 | 最新 | 贡献 |
|---|---|---|---|---|
| **名义 30Y** | 30Y 国债 | 4.86% | **5.27%** | **+41BP** |
| **实际利率** | 30Y TIPS | **2.63%** | **2.99%** | **+36BP（≈88%）** |
| **通胀补偿** | 隐含 30Y 通胀 | ≈2.23% | ≈**2.26%** | **+3BP（≈7%）** |
| 期限溢价（ACM） | 10Y ACM | ≈0.80% | ≈**0.73%** | **−7BP（反向）** |
| **锚判据** | 5y5y 远期 | 2.22% | **2.33%** | **+11BP，仍在锚定区间** |

**结论**：
- **30Y 名义涨的 41BP 里，实际利率占了约 36BP（≈88%）**——与「通胀中枢抬升」无关
- **5y5y 仅 +11BP（2.22%→2.33%），远低于 2.5% 的脱锚线**——市场不认通胀中枢抬升
- **ACM 期限溢价反而下降 7BP**——「全是财政期限溢价爆炸」的解释也不成立；模型 risk-neutral 期望短端成分从 3.47% 升至 4.07%（+60BP）→ **真正在涨的是市场对美联储未来短端路径的预期**
- ⚠️ **官方 SEP 与市场定价存在 ≈135–140BP 的系统性分歧**（官方 2026 PCE 3.7% / 长期通胀 2.1% vs 市场 5y5y 2.33%）——**这个分歧本身是信息，两边必须分开报，不得只报一边**

**引用纪律**：凡写「通胀中枢抬升 / 结构性通胀回归 / 零利率时代结束」，**必须先过本模块的第一步到第四步**；5y5y 未破 2.5% 时改用「实际利率 / 资本竞争」作为归因表述。

## M64：汇率—利差背离的驱动源裁决法

> 当「利差创历史极值」与「汇率反向升值」同时为真时，**不得再用利差解释汇率**。
> 正确动作是**裁决驱动源**：这个货币由经常账户定价，还是由金融账户定价？

### 核心原理

```
汇率的两个定价账户：
  经常账户（贸易）  → 顺差 = 外汇供给 = 本币升值压力（结构性、慢、黏性强）
  金融账户（资本）  → 利差 / 风险偏好 = 资本流动 = 本币贬值压力（周期性、快、弹性大）

两者反向时，谁大谁定价：
  → 顺差规模 > 资本流出规模  →  经常账户定价（利差推论失效）
  → 利差极值但汇率升值       →  就是这个状态
```

### 判据（四步裁决）

```
□ 第一步：判区制（前置条件，不可省）
   开关 = 美元指数能否收盘站稳 100 以上持续 2 周
   → 未站稳 = 正常态（制度主导，利差推论无效）
   → 站稳   = 压力态（利差恢复主导，UIP 重新生效）

□ 第二步：判经常账户
   取顺差规模 + 趋势（近 3 个月同比），判断外汇供给是否在增长
   → 顺差扩大 + 汇率升值 = 经常账户在定价

□ 第三步：判反身性（排除反向因果）
   须排除「升值预期 → 压低本国长债收益率 → 利差被动扩大」这条反向链
   → 若本国长债收益率在利差走阔期间同步下行，则利差是内生结果，不能当外生原因

□ 第四步：裁决并输出
   若①未开+②顺差扩大+③利差是内生 → 判「经常账户定价」
   → 结论写成「汇率由贸易顺差驱动，利差推论在当期无效」，并给出证伪位（顺差同比转负）
```

### 实战案例（2026-09-17 核验）

| 项 | 读数 | 口径 |
|---|---|---|
| 中美 10Y 国债利差 | **327BP（09-10，创有记录以来历史最高）** → 328.6BP（09-12） | 中国 1.686% vs 美国 4.972% |
| 人民币 | 09-02 在岸 6.7195 → **09-17 22:02 实时 6.7060**（离岸 6.7031） | T0 实时 |
| 人民币累计升幅 | 2025-04-09 至 2026-09-03 **离岸近 9%、在岸超 8.5%** | 17 个月 |
| 中国 10Y 国债 | 1.679%（09-09）→ 1.686%（09-12），稳定在 1.68% | 未随利差走阔而急升 |
| 贸易顺差 | 2026 年 1–7 月对美顺差约 **$1,708 亿** > 2025 年同期 $1,655 亿 | 同比扩大 |

**裁决**：**利差 327BP 极值 + 汇率升值 9% + 本国长债利率稳定 + 顺差同比扩大 → 经常账户定价。** 「利差扩大 → 贬值压力」这条推论在 2026 年当期**无效**。

**被纠错的说法**：某推演稿称「美债短端利率走高、中美短端利差扩大 → 人民币短期仍有贬值压力」——**方向错**。须改写为「人民币由贸易顺差定价，升值趋势的证伪位是顺差同比转负」。

**与 M-C1 的分工**：M-C1 给**区制开关**（DXY 100 判据）；本模块在其上做**驱动源裁决**（经常账户 vs 金融账户）。**先跑 M-C1 判区制，区制为「正常态」时才需要本模块做归因裁决；区制为「压力态」时直接用利差推论。**

## M65：政策范式转移的定价映射法

> 当央行目标函数发生变更（如把分配目标纳入、或主动拆除透明度工具）时，**不要去想「它会怎么做」，去映射「市场必须重新定价哪三样东西」**。
> 目标函数不可观测，但**定价结果可观测**。

### 核心原理（三条必然的定价映射）

```
央行范式转移（如拆除前瞻指引 / 终止点阵图 / 纳入分配目标）
  │
  ├─ 映射①  看跌期权【行权价下移】≠ 期权取消
  │     机制：托底频率↓、触发门槛↑、介入时点滞后
  │     ⚠️ 不可读成「取消」——棘轮效应保证它仍会介入
  │     判据：央行资产负债表中长期规模 / 流动性工具使用记录 / 工作组改革方向
  │
  ├─ 映射②  波动率【中枢上移】，且不是渐变而是阶梯式
  │     机制（**VaR 冲击链**，本模块核心）：
  │       政策沉默（无前瞻指引）
  │         → 波动率输入走阔
  │         → 突破机构 VaR 风险限额
  │         → 触发机械去杠杆（与观点无关）
  │         → 强制卖出进一步推高波动 → 自我强化
  │     ⚠️ 该链条只需假设「央行不说话」，不需假设「央行想让市场跌」
  │     拥挤度放大器：查最拥挤交易调查 + 杠杆型策略（CTA/风险平价）的待售存量
  │
  └─ 映射③  股权风险溢价【归一 / 转负】——TINA 终结
        判据：无风险利率 vs 股市盈利收益率（= 1 / trailing P/E）
        → 若 无风险利率 > 盈利收益率  → ERP 为负 → 现金/短债变成有效替代
        → 「买指数赚贝塔」的机会成本从零变为正
```

### 标准分析步骤

```
□ 第一步：识别范式转移的【结构性动作】（不是措辞，是机制）
   例：是否拒绝提交预测？是否撤销前置指引？是否设立改革工作组？工作组主持人的学术立场？
   ⚠️ 工作组主持人的既有论文往往直接预告改革方向（案例：Rajan 的《Liquidity Dependence》
      论证 QE/QT 不对称与棘轮效应 → 直接指向「缩表不可逆」的谨慎立场）

□ 第二步：映射① —— 算期权行权价而非问「有无期权」
   报出：托底门槛（什么条件下才会介入）+ 介入滞后（多久）+ 依据

□ 第三步：映射② —— 算波动率的【机制】而非【水平】
   查三项拥挤度：①最拥挤交易调查（拥挤比例）②板块估值 vs 大盘 ③杠杆策略待售存量
   → 三项同时偏高 = 去杠杆会集中爆发 = 波动率阶梯式上移

□ 第四步：映射③ —— 算 ERP
   ERP = 1 / trailing P/E − 无风险利率
   → ERP < 0：主动定价价值上升，但成因要写清是「被动化」还是「央行不托底」

□ 第五步：输出——三条映射分别给「方向 + 触发条件 + 证伪位」，不并列情景
```

### 实战案例（2026-09-17 核验：Warsh 范式转移）

**结构性动作（已核实）**：
- 2026-06-17 FOMC：**116 词声明**，**Warsh 拒绝提交自己的点阵图预测**
- 2026-07-09：设立 **5 个独立特别工作组**——Communications / Balance Sheet Policy / Data / Productivity and Employment / Inflation Framework
- **Raghuram Rajan 联合主持资产负债表政策组**——他是 2022 杰克逊霍尔《Liquidity Dependence: Why Shrinking Central Bank Balance Sheets is an Uphill Task》合著者
- 国会证词：「美联储只有一个目标，就是 2%」，**拒绝任何软性通胀目标**
- 卖方共识（4+ 独立来源）：城堡证券「或将正式终结」；Wedbush《告别美联储看跌期权》
- 精确表述：「The Fed Put has not disappeared. **However, its strike price may be lowered.**」

| 映射 | 读数 | 证据 |
|---|---|---|
| ① 行权价 | **下移，非取消** | Rajan 的棘轮效应：QE 训练出的私人部门流动性索取权在 QT 时不同步收缩 → 系统性事件时美联储**仍会被迫介入** |
| ② 波动率 | **阶梯式上移风险高** | **80% 基金经理认「做多全球半导体」最拥挤**；SMH **48–49x** vs S&P 28x；约 **$930 亿 CTA 多头**趋势破位时待售 |
| ③ ERP | **已转负** | 10Y 美债 **4.62%** vs S&P 盈利收益率 **4.05%**（trailing P/E 24.7） |

**引用纪律**：凡写「美联储看跌期权终结」，**必须写成「行权价下移」并附「≠取消」的机制说明**；凡写「美股调整会更深更久」，**必须走 VaR 冲击链，不得从「政策容忍度」直接推出**。

## M66：顺差回流路径重构法

> 「某国顺差 → 买某国国债 → 支撑其融资」这条链条**不是物理定律，是一条可被制度变迁切断的路径**。
> 当被问「加息能否重建买债意愿」时，先重建这条路径，再判断加息是在解决「意愿」还是只在「竞价」。

### 核心原理

```
传统链条（布雷顿森林 II 时代的默认）：
  顺差国出口 → 获得美元 → 央行/外储买入美债 → 为赤字国融资

这条链条成立需要三个前提：
  前提①  顺差国依赖外储管理汇率  → 故被动持有低收益安全资产
  前提②  顺差国的美元收入集中在【官方部门】  → 故价格不敏感
  前提③  美元资金直接回流【目标市场】  → 无中间节点分流

三个前提任一被破坏，链条就退回「价格竞争」：
  → 央行不再是价格不敏感买家，私人部门成为边际定价者
  → 私人部门要求【风险补偿】，不存在「无论如何都买」
  → 加息不是恢复意愿，是提高报价
```

### 三条判据（前置条件检验）

```
□ 前提①检验：汇率制度是否已转向浮动/有管理浮动？
   → 已转向 = 对外储依赖下降 = 官方被动买盘减少
□ 前提②检验：美元收入去向是【金融资产】还是【产能投资】？
   → 产能投资占比上升 = 这部分美元不会回流债券市场
   （判据：查该国制造业固定资产投资 / FDI 流出 / 产能扩张公告）
□ 前提③检验：资金是否经第三地循环（香港/新加坡等）？
   → 是 = 中间节点分流，目标市场拿不到全额
```

**若三问都指向「不再买」→ 结论必须从「意愿问题」改写为「价格问题」**：
`目标债券收益率需要长期维持在高于疫情前的水平，才能吸引足够资金承接新增供给。`
**而不是**：`加息会重建买债意愿。`

### 实战案例（2026-09-11 澳新银行）

**被质疑的说法**（某推演稿）：加息核心目标是「重建全球买家对美债的信心」。

**三问检验结果**：
- **前提①**：亚洲主要经济体已大多实行自由浮动或有管理浮动汇率 → 对外储依赖**明显下降** ❌
- **前提②**：**更多亚洲经济体正将贸易顺差用于扩大制造业产能，而非增加金融资产配置（越南、印度）** ❌
- **前提③**：**更多美元资金正通过香港和新加坡循环，而非直接配置到美国资产** ❌

**结论**：三个前提**同时被破坏** → 链条已结构性失效。

**改写后的表述**：
- ❌「加息是为了重建全球买家对美债的意愿」
- ✅「美债收益率可能需要**长期维持在高于疫情前的水平**，才能吸引足够资金承接新增供给」
- ✅「加息是提高报价去竞标，不是把意愿找回来」

**与「财政工具无效」的联合验证（M67）**：如果这是「价格问题」而非「意愿问题」，那么**任何不削减净发行的工具（回购/换久期）都只能短暂影响价格**——这一点已被 2026-08 贝森特的回购操作实测验证（见 M67）。

## M67：财政工具效力的持续天数检验法

> 当财政当局动用市场工具（回购 / 换久期 / 缩短发行期限）干预长端时，
> **判据不是「公告当天涨了多少」，而是「几个交易日后还在不在」。**
> 首日反应是流动性冲击；持续天数才是对「融资需求是否被削减」的检验。

### 核心原理

```
财政工具的两类作用：
  类①  改变【存量久期结构】（回购旧债、换发短债）
        → 只影响供需的期限错配，不改变总融资需求
        → 效果：短暂（交易日级别），随后被基本面吞掉
  类②  削减【净发行规模】（减赤字、停发某期限）
        → 直接减少可投标的
        → 效果：持久（季度级别）

判据（持续天数）：
  公告后 3 个交易日内收益率回到公告前水平  → 类①（无效）
  公告后 10 个交易日仍维持在低位（≥5BP 改善）→ 类②（有效）
  → 若类①被反复使用而无效，说明政策当局自己也知道问题在净发行，但改不动
```

### 标准分析步骤

```
□ 第一步：确认工具性质——是「置换久期」还是「削减净发行」？
   → 读官方公告原文，看它说的是「改善市场功能/流动性」还是「减少发行量」
   ⚠️ 措辞「改善市场流动性和市场运行状况」= 类①，「减少净发行」= 类②

□ 第二步：量化规模占存量/净发行的比例
   → 年化规模 ÷ 年度净发行额 = 覆盖率
   → 覆盖率 <10% = 象征性操作，不足以改变趋势

□ 第三步：验证持续天数（核心）
   → 记录公告前 / 首日 / 第3日 / 第10日的长端收益率
   → 若首日改善被完全回吐 → 判「无效」

□ 第四步：交叉验证——查卖方是否已识别该工具的性质局限
   → 若多家机构一致指出「只改期限结构、不改融资需求」，则趋势判断应以机构共识为准

□ 第五步：输出——把「长端基准形态」写成「高位横盘 / 供给驱动熊陡」，
   而非「熊平见顶」；并给证伪位（净发行额是否下降）
```

### 实战案例（2026-08–09 贝森特国债回购）

| 项 | 读数 |
|---|---|
| 工具 | 扩大国债回购计划 |
| 规模变化 | 单次操作上限 **$20 亿 → 至少 $40 亿** |
| 运行期 | **2026-09-09 至 11-04** |
| 年化规模（市场估） | 约 **$1,280 亿** |
| 公告后首日 | 长端借贷成本下降，股票与风险资产上涨，市场紧张短暂缓解 |
| **第 3 日** | **收益率反弹；开盘后前期涨幅全部消失，部分长债收益率回到公告前水平** |
| 官方措辞 | 「改善市场流动性和市场运行状况」= **类①（置换久期）** |

**卖方判定（多源一致）**：
- 高盛：只改变存量债务期限结构，**不改变政府总体融资需求**，难以从根本上压低长期收益率
- Evercore ISI：贝森特很可能已「认识到美国无法持久地阻止基本面决定收益率」
- 法兴（Subadra Rajappa）：回购很难真正改变美债走势，市场关注仍是债务与赤字方向
- 中国银河：**「前瞻指引弱化 + 结构性缩表 + 通胀框架多维验证」三大改革共同推升长端不确定性溢价**，叠加财政部中长期国债供给维持历史高位 → 长端**易上难下**

**结论**：**类①工具 → 效果 3 日级 → 无效。** 长端的基准形态应写成「**高位横盘或供给驱动的熊陡**」，**不是「熊平见顶」**。

**与 M-Y3 的分工**：M-Y3 判**当日曲线形态→定价权归属**（熊平 = 货币政策定价权）；本模块判**中期长端趋势**（财政工具能否压住）。**两者分属不同时段，必须分层报出，不可混用**——本案正是「加息当日熊平（M-Y3）」与「财政供给推长端（M67）」同时成立的典型。

## M63–M67 联动配方

```
判「长端为什么涨」        → M63（三段分解）→ 得主因（实际利率/通胀/期限溢价）
判「该不该做多长债」      → M63 主因 + M67（财政工具效力）
                            → 若主因=实际利率 且 财政工具为类① → 不可做多
判「汇率方向」            → M64（先 M-C1 判区制，再裁决驱动源）
判「央行范式转移影响」    → M65（三映射：行权价 / 波动率 / ERP）
判「加息能否重建买债意愿」→ M66（三前提检验）→ 得意愿问题 vs 价格问题
判「财政干预是否有效」    → M67（持续天数检验）
```

**共用一条铁律**：**凡「名义利率上行」的表述，一律先做 M63 分解；凡「利差→汇率」的表述，一律先做 M64 裁决。** 这两条是本项目 2026-09-17 两次核验中**同一类错误的两个实例**（把名义变量当实质变量、把周期性变量当结构性变量）。
