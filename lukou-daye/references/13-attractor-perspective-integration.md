## 二、五步法（挂在 L 树上的读法）

> 世界观一句话：世界是**生成式**的（自组织、涌现、路径依赖），不是决定式的钟表 → **不预测点位，给机制、路标和赔率结构**。

| 步 | 动作 | 对应路口大爷模块 |
|---|---|---|
| **① 描述系统** | 主体 → 结构 → **能量流/信息流**；钱与货就是经济金融系统的两种能量流 | L6 资金双轨、L7 三方博弈、**L21 钱货双循环** |
| **② 洞察动力机制** | 找**主要矛盾**（驱动演化的动力源）。⚠️ 从表象反推机制**没有唯一解** → 先观察表象 → 给设想 → 找证据验证 | L3 深层归因、L17 供给弹性、**L24 反转性质判别** |
| **③ 构想路径 + 路标** | 给几条演化路径 + 每条**明确可观察的路标**，贝叶斯动态更新置信度；实际演化与所有路径都不符 → **退回②重检** | L4 地缘情景、**L25 轮动时间线**（路标即时间刻度） |
| **④ 发现生态价值** | 能更大比例、更长期**留存能量流**的节点 = 生态价值更大 = **收益来源**；兼顾可持续性 | L9 卖水卖铲子、L10 定价权转移、**L23 传导系数** |
| **⑤ 构建适应性策略** | 每条路径给最佳策略；环境混沌时按「**淘汰—保留**」选；清晰时向高置信度倾斜但**永远保留多元化备案** | L20 泡沫真实性、Mi姐仓位纪律（外部） |

**两种能力**：前两步靠**理解力**，后三步靠**想象力 + 自省力**——把未知未知 → 已知未知 → 已知已知。

## 五、三条口径硬规则（不守会得出反向结论）

1. **是状态指数，不是价格。** value 归一化到 **[-1, 1]**（0≈中性，±1 极端），state 三档（上升/中性/下降），stateChange 是相对上期跳变。**禁止当行情价或百分比读**，只作路标/背景板。
2. **信用必须价格/数量分开读。** `中国-信用环境`（att_00000045）= 信用**条件/价格**；`中国-信用数量`（att_00003318）= 数量。**2026-08-31 实测：信用环境 +0.8571（上升），而社融/居民信贷增速在降 → 裁断「宽而不松：钱便宜但没人借」**，与 L21「两个出口均关闭」自洽。
3. **限流 1000/天（按 Key）：** `--health` 与查询共享配额 → **禁止预检探活**（等于砍半日配额）；业务接口只有 `POST /macro/latest`，不要试探未文档化端点。

## 六、使用纪律（并入后的硬约束）

1. **触发不冲突**：吸引子由「切换到吸引子 / 吸引子怎么看 / 查宏观数据 / 最新宏观读数」等触发；路口大爷由宏观/资金流/地缘/周期/定价权/美元体系触发。**两者可同时激活**。
2. **宏观分析时的加载顺序**：先跑 `macro_latest.py` 取读数（**不凭训练语料编行情**）→ 再按 F 组 L21–L25 判别 → 最后用五步法组织输出。
3. **观点必须标注**：吸引子的方向性判断标「**吸引子观点·源自《十分吸引》语料**」，路口大爷判别器结论标「本框架推导」，两者**不得混写**。
4. **红线继承**：不给买/卖/仓位/点位的具体指令；数据必须来自工具；不确定就明确说不确定。
5. **引用其 51 项指标但不可复算的部分**（归一化算法未公开）→ 一律标「自述/未验证」，只作路标不作结论支点。
