## 四大经济理论基础

### 1. 费雪债务通缩理论

**核心公式**：m × v = P × Q

**关键创新**：将债务纳入货币供给m的核心构成，而非仅视为央行发行的基础货币。

**传导链条**：
```
债务顶到天花板 → 企业/个人无法新增债务 → 货币创造停止(m收缩)
→ 同时为还债抛售资产 → 资产价格下跌 → 抵押品价值缩水
→ 银行惜贷 → 货币周转速度v断崖式下降 → 商品价格P全面下跌
→ 债务-通缩螺旋
```

**关键补充**：Q（产出）并非绝对定量，通缩会导致企业减产、工人失业，Q也随之下降，形成更恶性循环。单纯发消费券无法解决 —— 只能短期刺激P，无法修复债务导致的m和v的结构性崩溃。

### 2. 卡莱斯基利润理论

**会计恒等式**（而非理论假设，永远成立）：
```
总利润 = 投资 + 政府赤字 + 净出口 + 资本家消费 - 工人储蓄
```

**颠覆性意义**：
- **政府赤字直接构成企业利润**：解释了为什么美国疫情期间大规模财政赤字下企业利润反而创历史新高 —— 政府花的每一分钱，最终都会变成企业的收入和利润
- **资本家消费也是利润来源**：打破了"利润来自生产效率"的传统认知，富人奢侈消费同样拉动企业利润

**隐含批判**：主流经济学刻意淡化这两个变量，本质上是为了掩盖政府财政和资本家行为对经济的决定性影响。

### 3. 明斯基金融不稳定假说

**三个融资阶段**：

| 融资阶段 | 核心特征 | 美国对应 | 标志性信号 |
|----------|----------|----------|------------|
| 对冲性融资 | 现金流覆盖本金+利息 | 2020年前 | 财政盈余或低赤字 |
| 投机性融资 | 现金流仅覆盖利息 | 2021-2024 | 债务规模持续扩大，利息占财政收入上升 |
| 庞氏融资 | 借新债还旧债+利息 | 2025年后 | 利息超财政收入，必须发新债付息 |

**明斯基时刻触发机制**：并非债务规模本身，而是债务链条的某一个环节突然断裂（如大型银行违约、主权债务违约），引发市场信心崩溃，所有资产同时被抛售，形成系统性危机。准确时间节点无法预测，但趋势确定。

### 4. 明斯基“稳定不稳定理论”

**核心逻辑**：稳定本身就是不稳定的根源。经济长期稳定会让市场主体放松警惕，非理性融资行为不断累积，最终必然导致危机。

**2008年美国的错误应用**：明斯基主张“大政府+大银行”在危机初段干预。但美国在危机末段才出手，用无限财政赤字和央行扩表熨平危机，没有出清过剩产能和不良债务，导致债务进一步膨胀。

**中国的优势**：中国在危机中段就开始主动处置恒大、万科等债务问题，清理资本市场乱象，避免了危机发展到不可收拾的末段。
