第一步：经济周期定位

中国经济当前处于衰退期尾声→弱复苏过渡阶段：

美林时钟定位：衰退期尾声 → 最优资产仍是债券，股票需要结构性机会。

第二步：货币政策与利率环境

中国央行维持宽松立场（降息降准），但面临流动性陷阱特征：货币已大量释放但进入不到实体经济，资金在银行系统空转。这正是杨世光所强调的"流动性陷阱的中国版本"。

美联储方面，沃什推行"棄資管債"政策，全球利率环境趋紧，中美利差收窄对人民币有支撑（人民币升至6.77），但也限制了国内降息空间。

第三步：美元周期与人民币

人民币从7.2附近升至6.77，升值幅度显著。根据杨世光框架中的国民经济恒等式 S-I=X-M：

人民币升值 → 出口变贵、进口变便宜 → 贸易盈余↓ → 超额储蓄↓ → 总需求↑ → 消费回暖
→ 对中免利好：居民购买力提升 + 进口奢侈品成本降低 + 出境游回暖

第四步：流动性分析

北向资金5月大幅净卖出中免（单日2.8亿元），但1月曾增持。万亿ETF资金从A股撤退——杨世光解读为"储备弹药，等待第二波攻势"。中免作为消费龙头，在资金面趋紧时首当其冲。

第六步：地缘政治与政策影响

中美关税战趋于缓和（沃什反对关税战），有利于国际品牌供货和免税品进口。但国务院《对外投资规定》收紧资本外流，反而利好国内消费回流——出境消费受限，海南免税成为替代选择。

🟣 卢麒元视角：制度结构与财政分析

广义财政论视角：免税行业的制度定位

卢麒元的广义财政论强调"所有经济问题本质上都是财政问题"。中免作为央企，其盈利能力直接关联政府财政收入：

维度分析影响
白色财政贡献中免2025年纳税约80-100亿元，是财政收入的直接来源政府有动力维护免税行业
灰色财政关联海南自贸港的土地出让、基础设施投资与免税商业高度绑定封关后政策红利将持续释放
财政权延迟风险地方政府依赖免税概念拉动投资和地产，形成隐性债务海南概念过度炒作的隐患

费雪债务通缩：中免面临的宏观逆风

运用费雪公式 m×v=P×Q 分析：

房地产债务顶到天花板(63万亿) → m收缩 → 资金空转v下降 → P(消费品价格)承压
→ 居民消费降级 → 免税品从高频消费变为低频消费
→ 客单价下降 → 中免收入承压
→ 但封关+新政可部分对冲通缩效应（供给侧改革）

卡莱斯基利润公式的应用

总利润 = 投资 + 政府赤字 + 净出口 + 资本家消费 - 工人储蓄

中免的客户群体可拆解为：

  • 资本家消费（高端客群）：依然强劲，支撑高端免税品（奢侈品、珠宝）
  • 工人储蓄（大众客群）：储蓄率攀升，消费意愿低迷，拖累大众品类
  • 政府赤字：海南封关后基础设施投入增加，间接拉动客流

明斯基金融不稳定假说：中免的融资阶段

中免本身处于对冲性融资阶段（现金流覆盖本息），财务健康。但其上下游（供应商、商业地产）部分已进入投机性甚至庞氏融资阶段，存在链条传导风险。

向心坍缩理论的视角

卢麒元的向心坍缩模型认为，全球美元体系存在"三流逆变"风险。对中国消费的影响：

三流维度当前状态对中免影响
流量全球美元流动性趋紧（沃什缩表）外资品牌定价权上升，中免采购成本增加
流向资本回流美国核心资产中国消费股被外资减仓（北向卖出验证）
流速部分资产流动性枯竭A股消费板块交易缩量，筹码松动
🟣 卢麒元结论：偏空（结构性风险）
从制度结构看，中国通缩→消费降级的根源是债务-通缩螺旋（费雪效应）和贫富分化（卡莱斯基效应）。中免面临的不是简单的周期问题，而是中国消费结构从"资本家消费繁荣"向"全民消费萎缩"的结构性转变风险。封关红利是政策对冲，但无法根本改变宏观通缩环境。建议：不重仓，等待直接税改革和人民币实质性升值的制度性拐点。
