## 节目核心问题

**"台積電海力士賣鏟 vs 美七姐妹賣慘？韓股賣鏟 vs 韓元賣慘？"**

核心论点：AI产业链中"卖鏟人"（半导体上游）与"卖慘人"（中下游应用）严重分化；韩国/台湾出现"强出口+强股市+弱货币"的背离，暗示全球资本正在外流。

---

## 观点一：亞洲三雄FCF大幅領先美科技七姐妹——賣鏟人全面勝出

**使用的方法论**：M20賣鏟人vs賣慘人分化分析法

**具体观点**（截至2026/6/9）：

- 台积电+三星+SK海力士2027e自由现金流接近$5,000亿
- 亚洲三雄FCF/Sales = **38.8%**，远超美科技七姐妹的14.2%
- AI大模型找不到B端/C端商业模式（"找不到C也找不到B"）→ 现金流向上游集中
- 费城半导体指数YTD **+82.2%**，美科技七姐妹指数仅+3.74%
- 把NVIDIA踢掉后七姐妹回报率更低
- 汇丰研报核心结论：亚洲科技三雄把全球"低端现金流"给吸干了

**观点权重衰减**：FCF数据每季度更新，但"賣鏟人FCF远大于賣慘人"这个结构性判断在3个月内仍有较高参考价值。

---

## 观点二：Intel代工復活——Google/Apple/NVIDIA全面回流

**使用的方法论**：M20賣鏟人vs賣慘人分化分析法 + M6地缘政治传导法

**具体观点**（截至2026/6/9）：

- Google在2028年前要把**300万片TPU**交给Intel代工（总目标600万片的一半）
- 原因：台积电产能不够，必须分散
- Apple全线（笔电到手机）进入Intel 18A设计链
- NVIDIA正在验证Intel 18A的制作技术及制程
- Intel YTD **+199%**，远超所有科技巨头
- 这不仅是现金流问题，更是**经营资本与实业资本之间的竞逐**
- Intel不能尽快加大代工产能 → 亚洲三雄吸金能力将进一步扩大 → 加剧全球美元不平衡

**观点权重衰减**：订单进展每月变化，但"Intel代工复活=賣鏟人格局从三雄垄断向四方竞逐转变"这个结构性判断在6个月内仍有效。

## 观点三：韓元創17年新低——"出口收入在岸缺席"

**使用的方法论**：M21贸易盈余-汇率背离分析法

**具体观点**（截至2026/6/9）：

- 韩国Q1 GDP年增率3.8%（翻了一倍多），经济强劲
- 3月经常帐盈余**373亿美元**（历史新高），4月283亿美元，连36个月顺差
- 但USD/KRW达1561（6/5），韩元创**17年新低**（逼近2008年次贷危机水平）
- FT中文网（6/1）解读"韩元和海力士背离：资金去哪了？"：
  1. 出口收入没有回到国内 → 三星/海力士用于海外再投资（设备采购、建厂、偿还美元债）
  2. 韩国散户大举投资海外股市（特别是美股）→ 金帐顺差但资本帐逆序
  3. "赚10美元可能只有1-5美元回到韩元"
- 韩元6/5见到1561低点后连续两天强弹 → 可能出现**假突破反转信号**

**观点权重衰减**：汇率每日变化，但"强出口+强股市+弱货币=资本外流"这个诊断框架始终有效。

## 观点四：台幣與韓元同樣背離——台幣升值才是AI泡沫終結信號

**使用的方法论**：M21贸易盈余-汇率背离分析法

**具体观点**（截至2026/6/9）：

- 台湾GDP也创下数十年最高，贸易盈余强劲，但台币维持31.5附近弱势
- 原因与韩国相同：大量外汇收入没有回到境内 + 台湾散户大量炒作美股
- **关键先行指标**：台幣止貶轉升 = AI短期泡沫終結的状况指标
- 回溯验证：韩元2024/12低点和2025/4低点 vs 美国科技股高点具有领先关系
  - 韩元见底回升 → 美国科技股高点出现
  - 韩元第二个低点完成 → 美股就已经在跌了
- "真正的低点是什么时候？是台币开始止貶轉升"

**观点权重衰减**：台幣/韓元汇率每日变化，但"台幣升值=AI泡沫終結"这个先行指标逻辑在6个月内仍有效。需持续监控。

## 观点五：人民幣走強與台幣/韓元脫鉤——政策拔掉资本外流插头

**使用的方法论**：M21贸易盈余-汇率背离分析法 + M9 A股特化分析框架

**具体观点**（截至2026/6/9）：

- 中国1-5月贸易顺差4,517亿美元，5月重新扩大，全年挑战1.2兆美元
- 但人民币走强（与台币/韩元走势完全相反）
- 原因：**政策拔掉资本外流的插头**
  - 6/12富途/老虎对外投资新规关键转折点
  - 国家队疯狂抛售ETF + 对外投资新规范 → 境外资本流出管道被关门
  - SpaceX不对中国投资人进行IPO配发 → 又一个投资通道被关闭
- 中国海外获利转向人民币需求（投资最大漏洞被堵住）
- 人民币汇率月线图上出现"N字等距测幅满足"技术形态

**观点权重衰减**：政策变化具有节点性质，6/12新规实施后此观点权重需重新评估。但"资本管制收紧→人民币走强"的逻辑链在3个月内仍有效。

## 观点六：中國貿易盈餘不可持續——鴉片戰爭的現代翻版

**使用的方法论**：M22历史贸易失衡类比法

**具体观点**（截至2026/6/9）：

- 中国年贸易顺差1.2兆美元，单独拿出来可排全球GDP前15名
- 欧洲人民党（EPP）主席："天真的时代已经结束"，欧盟对华贸易政策不能再有幻想
- 欧洲商会指出中国化工、汽车、钢铁、电子零组件对欧洲产业产生巨大压力
- **"中国什么都能做，却什么都做不了"**：
  - 制造业/商品几乎无所不能
  - 但对全球贸易秩序/条件/壁垒无能为力
- 历史类比：1820年代中国茶叶/丝绸/瓷器贸易盈余 → 全球白银50%流入中国 → 英国被迫用鸦片平衡贸易 → 鸦片战争
- 当代：中国1.2兆贸易盈余不可持续 → 关税壁垒+贸易制裁 = 现代版"鸦片"
- **唯一解决方案 = 人民币升值**

**观点权重衰减**：历史类比是结构性判断，3-6个月内参考价值较高。但具体贸易冲突事件演变快速，需持续跟踪。

## 观点七：戰爭第102天——以色列伊朗宣停火但油價不跌

**使用的方法论**：M6地缘政治传导法 + M15事件计数法 + M16油轮跟踪法

**具体观点**（截至2026/6/9）：

- 美以伊战争持续102天，以色列和伊朗分别宣布"战时停火"
- 消息面说油价要打下来，但实际上没有跌
- 核心矛盾：是否解除对伊朗制裁、是否解冻海外被扣押资产
- "利益关系不是一千亿美金、不是每天一千万桶原油，而是海权秩序的改变"
- 台塑六艘油轮：君善轮在费赫勒港已等**15天**（比6/8的14天又增加），周转率再度放缓

**观点权重衰减**：地缘事件每日演变，1个月后此观点权重降至80%。但"海权秩序改变"的结构性判断在6个月内仍有效。

## 观点八：台塑五月營收月減——需求與供給雙重困擾

**使用的方法论**：M16油轮跟踪法 + M5大类资产轮动法

**具体观点**（截至2026/6/9）：

- 台塑公布五月份财报重新出现月度下滑
- 军善轮+崇善轮在费赫勒港停留过久 → 周转率放缓 = 需求问题
- 整个需求问题与供给问题困扰的不仅是台塑集团运营
- 也困扰了全球长期物价与总合攻击的成本

**观点权重衰减**：台塑月报每月更新，需持续跟踪。
