## 二度破底翻净化法

> 一次破底翻不够稳，两次破底翻 = 洗盘净化完成。单脚不成底，双脚才是真底。

### 核心逻辑

```
破底翻次数与可靠性：
┌──────────────┬──────────────┬────────────────┐
│ 破底翻次数     │ 可靠性          │ 操作策略               │
├──────────────┼──────────────┼────────────────┤
│ 一次破底翻     │ 中等（可能假底） │ 买权试探，不做期货     │
│ 二度破底翻     │ 较高（净化完成） │ 期货进场，停损明确     │
│ 三度破底翻     │ 极高（彻底洗盘） │ 重仓机会（罕见）       │
└──────────────┴──────────────┴────────────────┘
```

### 操作要点

- 第一次破底翻：用买权试探，控制损失
- 等二次打底：类似「单脚不成底」，需要二次确认
- 二度破底翻确立后：
  - 支撑看「今天低点」（每次破底翻当天的低点）
  - 净化区完成 → 风险可控 → 可用期货
  - 60分钟线也有破底翻（辅助确认）

### 与M6的联动

- M6讲破底翻的基本识别 → 本方法讲**次数与可靠性**
- 一次破底翻可能只是洗盘的开始
- 二度破底翻 = 净化完成 = 真正的底部确认

## 小波段高胜率法实操纪律

> 工具好用，但50%的人用不好。问题不在工具，在「感情用事」。

### 60分钟线破线操作

```
操作流程（60分钟K线）：
Step 1：观察60分钟线是否破线（破趋势线/颈线）
Step 2：看收盘确认（关键！不看盘中）
  - 收盘破了 → 确认破线 → 执行策略
  - 盘中破但收盘没破 → 假突破 → 不执行
Step 3：假突破 = 反向操作信号
  - 假突破向上 → 追空
  - 假突破向下 → 做多
Step 4：停损点设好
  - 颈线上方/下方一定点数
  - 严格执行，不带感情
```

### 去感情化纪律清单

| 错误行为 | 原因 | 正确做法 |
|----------|------|----------|
| 盘中破了就追 | 感情用事、怕错过 | **看收盘**，不看盘中 |
| 追空后被弹洗掉 | 没看收盘确认 | 等收盘确认再执行 |
| 失败后在留言区找理由 | 感情浓厚 | 失败不要找理由 |
| 嫌工具不好用 | 把失败归咎外因 | 不适合就不用，不要找理由 |
| 设了停损不执行 | 带感情进去 | 模拟盘练到机械化 |

### 工具适用人群分布

```
工具使用效果分布：
├── 50% 觉得好用 → 能稳定盈利
├── 30% 用得上但无法完全掌握 → 时赚时赔
└── 20% 完全无法使用 → 不适合（换方法）
```

> 不好用就不要用，不要找理由说工具不好。问题可能在执行者自身。

## 整理盘预警法

> 频繁做头的时间越长，表示整理盘来了。

### 核心逻辑

```
整理盘信号识别：
├── 做头次数越多 → 整理盘概率越大
├── 做头时间跨度越长 → 整理力度越大
├── 高点越来越低 → 整理盘确认（动能衰减）
└── 一旦高点越过（破底翻确立） → 整理结束信号
```

### 实战指标

| 做头次数 | 整理盘概率 | 预期整理时间 |
|----------|-----------|-------------|
| 2次 | 中等 | 较短 |
| 3次 | 较高 | 中等 |
| 4次以上 | 极高 | 较长 |

### 操作策略

- 整理盘中：不追价，等底型
- 整理盘结束信号：破底翻确立（高点越过前高）
- 每一波有其涨点 → 高点越来越高 = 多头
- 高点越来越低 = 整理/空头 → 等破底翻

## 回拉低点支撑线画法（6-17视频新增）

> 创新高后回拉的低点，向右延伸画支撑线。这是颈线之外的另一种动态支撑画法。

### 画法步骤

```
回拉低点支撑线流程：
Step 1：股价创新高后出现回拉（pullback）
Step 2：找到回拉的最低点
Step 3：从此低点向右画水平支撑线
Step 4：后续价格回测此线不破 = 支撑有效

与颈线的区别：
├── 颈线：连接形态中的反弹高点/回踩低点，用于确认形态突破
└── 回拉支撑线：突破后创新高再回拉的低点，用于跟踪动态支撑
```

### 实战应用

- 新股上市后突破、回拉、再创新高 → 从回拉低点画支撑线
- 两低点出来后 → 风险已明确，可以量化停损幅度
- 配合"开高百分比"：如开高6%，风险就是6%，回拉不破低点则继续持有

## 新股主力攻击成本停损法（6-17视频新增）

> 新股突破后的长红K线 = 主力攻击成本，停损设在攻击成本下缘，并随行情推进动态调整。

### 三阶段停损调整

```
新股突破后的停损动态调整：
┌─────────────┬─────────────────────┬──────────────┐
│ 阶段             │ 停损位置                     │ 适用场景              │
├─────────────┼─────────────────────┼──────────────┤
│ 刚突破         │ 主力攻击成本（长红K线）下缘   │ 突破后首次回拉          │
│ 涨一波压回     │ 整理区下缘                   │ 第一波涨幅后回拉          │
│ 涨过一波又回来 │ 只看下缘（不再看攻击成本） │ 趋势已确认，只需跟踪低点  │
└─────────────┴─────────────────────┴──────────────┘
```

### 主力攻击成本识别

- 长红突破K线 = 主力攻击成本
- 如长红涨幅15%，压回一半(7.5%) → 风险剩下不到8%
- 赚一倍后压回不破支撑 = 策略成功
- 压回在支撑线附近 = 确认支撑有效

### 实战案例（SpaceX新股）

```
SpaceX上市分析：
1. 创新高后回拉低点 → 画支撑线
2. 隔天开高6% → 风险就是6%
3. 两低点出来 → 风险已明确
4. 长红突破 = 主力攻击成本 → 停损设在下缘
5. 压回一半(7.5%) → 风险不到8% → 赚一倍
```

## 急缩量翻红标记法（6-17视频新增）

> 急缩量后出现翻红K线 = 转折确认信号，应特别标记。

### 识别规则

```
急缩量翻红确认法：
Step 1：连续下跌过程中出现急缩量（成交量急剧萎缩）
Step 2：紧接着出现翻红K线（收阳）
Step 3：标记此K线为转折点
Step 4：配合破底翻 = 强烈底部信号

与带量指纹确认法的区别：
├── 带量指纹：带量大K线=指纹，回测不破=确认
└── 急缩量翻红：急缩量+翻红=卖压耗尽+转折确认
```

### 标记方式

- 在急缩量翻红的K线旁标注"翻红"文字
- 此K线的低点 = 短期支撑
- 如同时突破颈线 → 双重确认
