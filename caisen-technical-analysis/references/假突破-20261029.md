## §0 一页看懂

| 问题 | 答案 |
|---|---|
| 假突破是什么 | 主力在高档出货的最后一步：拉过颈线诱多 → 几天内灌回颈线之下 |
| 为什么会有 | 出货需要买盘。最后拉一把把追高盘骗进来，然后从高档一路灌给追高的人 |
| 前置条件 | **该轮涨幅中位数 137%，12 例中 10 例（83%）已翻倍**。没翻倍不用谈 |
| 停留多久 | 跌回 −10% **中位 1 周**（13 例中 12 例 ≤2 周） |
| 后续跌多少 | 累计跌幅 **−34.8% ~ −68.9%，中位约 −50%** |
| 何时确立 | **必须跌回颈线以下**。只突破不跌破 = 没有假突破，不许动手 |
| 失败含义 | 非死即伤：要么直接跌，要么受伤回档，但修复时间远长于上涨时间 |
| 止损 | 重新站上前高并站稳（前高 ×1.03） |

## §1 出货机制：为什么一定会有假突破

讲义把出货的物理过程讲透了，这是它比"突破又跌破"这个图形定义更有价值的地方。

### 1.1 五步出货链

```
① 起涨：主力 20~30 元区间吸筹        （对应破底翻那一端的建仓）
② 拉抬：拉到 70~80 元高档            （一大笔钱拉升）
③ 派发：在区间高档反复上冲下洗       （"拉上去用几千手，下来了就有几万手灌下来"）
④ 诱多：最后一次用 3~4 万手拉过 80   （散户以为又要启动）
⑤ 灌杀：从上往下 86→85→82→80 一路倒  （到手的都是追高盘的钱）
```

关键点在 ④ 和 ⑤ 的**数量不对称**：讲义原文

> "我从高档一路往下灌，86、85、83、82，1 万、1 万、2 万、3 万的一直灌……就算我没有办法在最高档出掉，**没关系，我在 80 以下出也一样，因为我的成本是在 20 几块而已**。"

**主力不需要出在最高点。** 他从 20 拉到 80，就算全出在 75，也是三倍多。这条解释了为什么"假突破后还会再跌很多" —— 因为出货还没结束，继续跌他照样赚钱。

### 1.2 量价不对称（本课最实用的一条）

讲义原话：

> "出货下来少一点筹码就撑住了，因为跌的时候筹码都不用太多，拉上去比较需要用力嘛。"

| 动作 | 需要的筹码 | 原因 |
|---|---|---|
| **往上拉** | 多 | 必须主动吃掉上方所有卖单才能推高价格 |
| **往下撑** | 少 | 不买就行，自然回落；撑只是间歇性托一下，延缓跌速，让人以为"还有戏" |
| **往上假突破** | **最多** | 要同时吃掉解套盘 + 追涨盘，还要做出突破形态，所以必须放大量 |

**实测验证**（11 例有量能数据）：假突破那一周相对前 4 周均量的**放量倍数中位 1.45，10/11 例确实放量**（华夏幸福 7.91 倍为极端爆量）；而**之后 4 周均量全部小于突破周**。

→ 所以诱多那一下必须是巨量。 **不放量的突破，反而不像出货，更像真突破。**
→ 唯一未放量的一例是洛阳钼业第二次假突破（0.97 倍）——它恰恰是 2018 年大盘系统性下跌中的头部，属于被大盘带下来的，不是主力自己拉出货的典型形态。**这种是"顺势做头"，不是"诱多做头"，形态一样但成因不同。**

## §2 主力为什么不敢在突破位停留（本课最原创的机制）

讲义这段是全课含金量最高的地方，也是之前技能的简版里完全没有的：

> "我主力不会在 80 块停留太久，因为他（套牢盘）会形成解套卖压，**如果你涨不动**……通常几天之内就灌下来，有的是今天上去、明天就下来，有的是一个上影线当天就下来，**不敢留太久**。"

**逻辑链：**

```
主力已在 80 附近反复派发多次 → 80 上方堆了一层套牢盘（成本 80~86）
                             ↓
若股价停在 80 以上 → 之前套在 80 的人不但不卖，还抱着更高期待
                             ↓
但同时：前期套牢盘看到"还没解套"，不会主动卖 → 卖压暂时冻结
                             ↓
一旦横得久了，套牢盘失去信心开始割 → 主力自己成了唯一的买家 → 成本抬升
                             ↓
所以：突破后必须速战速决，用最短时间把追高盘的钱收走，立刻回到 80 以下
```

**这条可以直接量化，且验证通过：**

| 标的 | 假突破高点 | 日期 | 跌到 −10% 耗时 |
|---|---|---|---|
| 华夏幸福 | 48.30 | 2017-04-12 | **1 周** |
| 中国神华 | 29.43 | 2018-02-09 | **1 周** |
| 万科A | 42.24 | 2018-01-26 | **1 周** |
| 中信证券 | 38.40 | 2015-04-10 | **1 周** |
| 北京银行 | 15.77 | 2015-06-12 | **1 周** |
| 北方稀土 | 20.69 | 2017-08-11 | **1 周** |
| 新华保险 | 73.05 | 2017-11-24 | **1 周** |
| 洛阳钼业① | 8.90 | 2017-09-15 | **1 周** |
| 洛阳钼业② | 9.80 | 2018-03-23 | **1 周** |
| 中国重工 | 14.64 | 2011-02-18 | **1 周** |
| 中国中铁 | 10.63 | 2016-12-02 | **1 周** |
| 青岛海尔 | 23.20 | 2018-01-19 | 2 周 |
| 海通证券 | 31.66 | 2015-04-24 | 2 周 |

**13 例中 12 例在 2 周（含）以内跌掉 10%，中位 1 周。**

→ **操作含义：价格的确认窗口极短。突破后如果 2 周（日线图就是 3~8 个交易日）还站在颈线上方没被灌回来，那就不是假突破，别卖。** 讲义反复强调"一定是要跌到下面来才能确定"，就是这个意思。

## §3 三个必要条件（缺一不可）

### 条件一：位置必须在相对高档

讲义的框架是"主力 20~30 元建仓 → 拉到 70~80 出货"。所以第一个筛选就是：**这轮涨了多少。**

**实测 12 例突破前涨幅（从该轮起涨低点到假突破高点）：**

| 标的 | 起涨低点 | 假突破高点 | 涨幅 |
|---|---|---|---|
| 中信证券 | 9.97 | 38.40 | **+285%** |
| 海通证券 | 8.77 | 31.66 | **+261%** |
| 青岛海尔 | 7.24 | 23.20 | **+220%** |
| 万科A | 16.74 | 42.24 | +152% |
| 洛阳钼业① | 3.71 | 8.90 | +140% |
| 北京银行 | 6.66 | 15.77 | +137% |
| 华夏幸福 | 21.24 | 48.30 | +127% |
| 中国重工 | 6.44 | 14.64 | +127% |
| 新华保险 | 33.01 | 73.05 | +121% |
| 中国神华 | 12.72 | 29.43 | +131% |
| 北方稀土 | 10.57 | 20.69 | +96% |
| 洛阳钼业② | 5.80 | 9.80 | +69% |

> **中位数 +137%，最小 +69%，12 例中 10 例（83%）涨幅已超过 100%（翻倍）。**

**→ 硬筛选：一轮涨幅没到翻倍，不要判定假突破。** 低位的"突破又跌破"多半只是整理失败（对应 `washout-techniques.md` 里的洗盘），不是出货；出货的必要条件是**主力有巨大的账面利润可以兑现**。这条把误判率压掉大半。

### 条件二：必须有 " 拉 + 灌 " 的量能动作

突破那周要放量（见 §1.2），跌回来的时候量能萎缩（**维持价不需要量**）。讲义说的那种"爆量又收在颈线之下"（华邦电案例）是最强信号。

### 条件三：必须有确立动作 —— 跌回颈线以下

讲义多次强调：

> "**这边突破要跌破才能确立。你不能说突破就说它是假突破。** 我们一定要有一个确立动作。"

这是全套方法里纪律性最严的一条，也是避免"看谁都像假突破"的唯一解药。

## §4 非死即伤

这是讲义给出的、对"卖错了怎么办"的唯一答案：

> "我们所谓的假突破呢，通常一句话叫做**非死即伤**。股价不是受伤，就是死掉了……既然是受伤了，就要花很多的时间去疗养。那你卖掉也没有什么好可惜的。"

### 4.1 实测：洛阳钼业（讲义的完整案例）

| 项目 | 数据 |
|---|---|
| 第一次假突破高点 | **8.90（2017-09-15）** |
| 回档最低 | 5.80（2017-11-24），**−34.8%** |
| 再次上穿 8.90 | **2018-03-09（最高 9.07）** |
| **套牢 → 解套耗时** | **25 周 ≈ 5.8 个月** |
| 解套后最高 | 9.80（2018-03-23）—— 仅比原高点 **+10.1%** |
| 第二次假突破后最低 | 3.44（2018-10-19），**−64.9%** |

**结论：**

1. 所谓"受伤"，是**套牢近半年才解套，而且只多给了 10%**。为了这 10%，扛了 6 个月 + 中间 35% 的浮亏。
2. 解套后的那个新高，本身又是下一次假突破的起点。**"受伤"不等于"可以继续拿"，而是给了第二次逃命机会。**
3. 讲义的处理态度很明确：**"常常在这一波一波我们在操作……你卖在这里也不用看他再创新高在可惜。我只要会赚钱、我做的比别人好，这样就够了。"**

→ **这是概率决策，不是精确预测。** 假突破确立后卖出，允许自己错；错了的代价是错过最后 10%，对了的好处是躲掉中位 −50% 的下跌。

## §5 操作执行

### 5.1 卖出 vs 做空

| 场景 | 动作 |
|---|---|
| 现货/多头持仓 | 跌回颈线以下 → **清仓或减到最低**。破底翻那课讲的"停损设在线下面"，在这里就是执行点 |
| 期货/可以双向 | 跌破颈线**第一卖点/空点**；反抽站不回颈线 → 第二空点加码 |
| 讲义给的优选 | "做多要买破底翻，**做空要空这种假突破转弱的**" |

### 5.2 止损

假突破的止损 = **承认自己看错了出货**：

**重新站上假突破高点并站稳（前高 × 1.03）→ 止损出场。**

理由：主力出货完毕后没有理由再花钱拉回去。如果价格创新高并站稳，说明要么主力没走，要么有新主力接手，"出货"的前提不成立。

### 5.3 下跌目标的估算

沿用 `波段跌幅满足-20261029.md` 的框架，头部反过来用：

```
头部形态高度 D = 头部颈线 − 头部最高点（负值）
第一满足点 = 颈线 − D
```

**但本课给的实测参考是：假突破后累计跌幅中位约 −50%，区间 −34.8% ~ −68.9%。**
→ 空单不要在 −20% 就跑；**第一目标放在 −35%**，−50% 附近分批平。

### 5.4 讲义给出的两个陷阱

**(1) 吸引打板 / 追突破的资金**
中信证券案例：突破那天甚至做涨停板。"有时候还做涨停板给你看，吸引打板的、吸引短线抢入的，然后一次就结束了。**涨停板有时候隔天就没高点。**"

→ 高档区域的涨停突破，反而是最高危的形态，不是最强形态。

**(2) 训练出来的价格错觉**
华邦电（台股 2344）案例讲得最透：

> "股价从 8 月一直到 1 月，已经五个月了，**让你习惯它就是八、九、十九块**……一突破，你觉得它又要开始涨了，因为之前很会涨。主力就是利用这种心态。"

→ 这是行为金融层面的：**"之前很会涨"本身就是最好的诱饵。** 所以条件一（涨幅已翻倍）既是出货的可能性条件，也是散户追高的心理条件 —— 两者互为因果。

## §6 跨市场适用（含方向反转）

讲义明确说这在个股之外也成立：

> "不管是汇率啦、个股啦，其实都是一样的。"

**人民币（USD/CNY）案例**：
美元兑人民币的形态向下假突破 → 代表人民币**大幅升值**（因为报价方向是反的）。

**日元案例**：同样是"震荡 → 突破 → 跌破 → 形成假突破"，随后完成头肩顶左肩/头部/右肩。

> **⚠️ 方向反转的纪律**：在 USD 报价货币对里，**向下**的假突破 = 该非美货币看涨。镜像应用时必须先把报价方向确认清楚，抄形态不抄方向。这是汇率/ exporter 商品（如以美元计价的商品在该逻辑下的反向）最容易出低级错误的地方。

**未在东财复权周线接口覆盖、本轮未核的**：台股 2344 华邦电、USD/CNY、USD/JPY（接口无对应周线源）。这三条只作形态参考，未做数据验证。

## §7 与其他方法的衔接

```
左侧： 波段跌幅满足（定价值区） → 破底翻（发现主力、找买点）
                                      ↓
右侧： 破底翻确认后第一买点 / 带量突破颈线加码
                                      ↓
       波段涨幅满足 / 收敛三角边长法（算两波目标位）
                                      ↓
       涨到满足点 → 高档出现「假突破」→ 确立后清仓 / 反手做空
                                      ↓
       头部完成 → 波段跌幅满足，开始下一轮左侧
```

**衔接要点：**

1. **假突破是"卖出触发器"，不是"目标计算器"。** 目标由 `波段涨幅满足` / `收敛三角边长法` 给出；假突破负责告诉你"就是这里了"。
2. **两者一致性检查**：如果还在涨幅度满足点以下就出现"假突破"，先怀疑形态画错了（见 `收敛三角形-底部涨幅满足-20261029.md` §5.4 —— 只涨一波就跌破是真麻烦）。满足点附近的假突破才可信。
3. **与 `washout-techniques.md` 的分工**：洗盘发生在低位上升途中（"吓你不伤你"，1~3 天收回）；假突破发生在高档（**前一轮涨幅已翻倍**）。**判断分水岭就是"这轮涨了多少"。**

## §8 检查清单（看到疑似假突破时逐项核）

**判定前（缺一不可）**
1. ☐ 该轮起涨以来涨幅是否 **≥100%**？（实测中位 137%，低于此基本是洗盘）
2. ☐ 是否已到波段涨幅满足点 / 收敛三角两波满足点附近？
3. ☐ 突破那周是否放量？（实测中位 1.45 倍，唯一未放量例是被大盘带下来的）

**确立（必须满足）**
4. ☐ 价格是否已**跌回颈线以下**？（没有 = 不成立，不许动手）
5. ☐ 跌回是否够快？（中位 1 周跌 10%；超过 2 周还没跌回来要重新评估）

**执行**
6. ☐ 多头：跌破颈线清仓/减至最低
7. ☐ 双向：第一空点在跌破颈线，第二空点在反抽站不回颈线
8. ☐ 止损设在 **前高 ×1.03**
9. ☐ 空单第一目标 −35%，−50% 分批平（实测中位 −50%）
10. ☐ 提醒自己：即使"受伤"（假摔），也是套牢近半年才给 10%（洛钼实测），卖了不亏

---

## §9 禁止事项

1. **不许在低位用假突破。** 未翻倍的下跌，90% 是洗盘或普通整理失败，按假突破做空会在半山腰被套。
2. **不许"突破就说是假突破"。** 必须有跌回颈线的确立动作 —— 这是讲义反复强调的头号纪律。
3. **不许因为"之前很会涨"而放宽和追。** 那条正是主力要利用的心理。
4. **不许把"受伤后的新高"当成可以继续持有的证据。** 洛钼解套后只多给 10%，那 10% 是逃命机会不是加仓机会。
5. **不许跨越报价方向。** 汇率、反向 ETF、美元计价商品里，结构镜像但方向可能反转，先确认报价方向再套用。
