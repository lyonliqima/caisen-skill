# 笨鸟 M47-M49：利率归因与政策可行性三工具

> 来源：2026-09-11 对一份债市会议纪要的方法论蒸馏（已做事实核查）。
> 定位：这三件是**工具**，不是结论。每次使用必须用**当下最新数据**重跑，禁止直接引用本文中的任何数字当结论。

---

## M47：利率双拆法与归因窗口敏感性（量化核心）

**核心洞察**：债券收益率上行时，市场主流解释（"通胀""地缘""避险"）几乎永远是错的或不完整的。真正的驱动来源只有两种拆法能定位，而**拆完之后必须声明时间窗口**——因为同一句"X 是主驱动"，换窗口真假会翻转。这是本方法最重要的一条纪律。

### 第一步：锁定被解释变量

明确三件事，缺一不可：
1. 哪个券种（10Y / 30Y / 2Y，美债还是德债日债）
2. 哪个时间窗口（起止日期，精确到月）
3. 这段时间总共变动了多少 bp

**纪律**：没有这三要素，后面所有推导都是空的。听到任何人说"利率上行是因为 XX"，先反问窗口。

### 第二步：两种拆法交叉验证

```
拆法 A（路径 vs 补偿）：
    名义收益率 ≈ 预期未来短端利率均值 + 期限溢价

拆法 B（实际 vs 通胀）：
    名义收益率 ≈ 实际收益率 + 盈亏平衡通胀率
```

两种拆法必须**同时做**，用交叉结果定性：

| 拆法 A 结果 | 拆法 B 结果 | 驱动定性 |
|---|---|---|
| 短端预期主导 | 实际利率主导 | **货币政策收紧**（央行要加息/不降息）→ 属周期性，政策转向即缓解 |
| 期限溢价主导 | 实际利率主导 | **长期财政/主权信用担忧**（供给恐慌、需求结构恶化）→ 属结构性，降息也压不住长端 |
| 期限溢价主导 | 盈亏平衡通胀主导 | **通胀预期失锚** |
| 短端预期下行 + 期限溢价上行 | 实际利率上行 | **纯信用/供给驱动**，且已盖过宽松预期 → 最危险的组合 |

### 第三步：窗口敏感性检验（本方法的灵魂）

**同一现象至少跑三个窗口**，结论不一致时必须以最新短窗口为准，并显式说明长窗口是历史事实：

1. **年初至今**（YTD）：反映当年定价主线
2. **近 12 个月**：反映中期结构性变化
3. **最近 1-3 个月**：反映当下边际切换——**这个窗口往往才是交易依据**

**判读规则**：如果在最近短窗口里驱动因子已经切换（例如从"短端预期主导"切到"期限溢价主导"），那么长窗口的结论虽然历史正确，但已不能指导当下。

### 第四步：给驱动因子找硬证据（禁止用历史类比当主证据）

期限溢价上行，只认三类硬证据：

| 证据类型 | 具体指标 | 说明 |
|---|---|---|
| 需求侧 | TIC 外国官方持仓（月度）、央行黄金储备占比 | 官方净卖出 + 增持黄金 = 需求结构恶化，最硬 |
| 供给侧 | 财政部借款咨询委员会（TBAC）季度发行计划、长债拍卖尾部（tail）与投标倍数 | 发行结构向长端倾斜 = 供给恐慌 |
| 竞争侧 | 投资级企业债净发行规模（尤其科技/AI 资本开支相关） | 企业债挤占配置额度 = "抽水效应" |

**纪律**："中国不买美债""市场失去信心"这类判断，必须落到上面某一条可查数据上。历史类比（如北宋交子、南宋称提）只能用于生成机制直觉，**不能作为结论依据**——制度环境差异过大。

### 第五步：输出必须收敛

产出格式固定为四项，缺一不可：
- **方向**：长端收益率区间判断（如 10Y 4.7–5.1%）
- **切换条件**：什么情况下驱动因子会翻转（如"短端预期重新主导 / 联储转鸽"）
- **证伪位**：期限溢价跌破哪个数值 → 判断作废
- **跟踪清单**：2-3 个可月度更新的指标

### 数据源

- **期限溢价**：纽约联储 ACM 期限溢价数据集（Adrian-Crump-Moench，五因子无套利模型），日频公开，官网检索 "term premia" 即可；若页面路径变更以官网检索为准
- **实际收益率 / 盈亏平衡通胀**：同期限 TIPS 与名义国债收益率之差（10Y TIPS 实际收益率、10Y breakeven）
- **需求结构**：美国财政部 TIC 月度数据

### 常见误用（务必避开）

1. **"实际利率涨得更快，所以不是通胀驱动"** —— 这是跳步推理，不成立。实际利率上行有三个来源：通胀预期下行、中性利率 r\* 上抬、期限溢价。必须走第二步拆法 A 才能区分后两者。
2. **只跑一个窗口就下结论** —— 最常见的错误，第三步专治此病。
3. **把模型估计值当观测值** —— ACM 期限溢价是模型拟合结果，不同模型（ACM / KW / DMSP）口径不同，跨模型比较要说明。

### 示例（2026 年实测，**仅供理解步骤，勿当结论**）

同一句"期限溢价是主因"，三窗口结论翻转：
- 2026 年 1—7 月：10Y 上行约 48bp，短端预期 +52bp，期限溢价 **-4bp** → **不成立**
- 近 12 个月：上行约 40bp，其中期限溢价 +34bp（约八成）→ **成立**
- 2026 年 7 月至今：上行约 25bp，短端预期 -7bp，期限溢价 +32bp → **完全成立**

## M48：对手方资产负债表检验法（政策可行性评估）

**核心洞察**：判断一项政策能否落地、能落多大规模，不要问"决策者想干什么"，要问"谁为它买单，他买得起吗"。政策规模上限由**对手方的亏损承受力**决定，不由决策者的意愿决定。

### 第一步：识别真正的对手方

列出政策要达成目标所必须依赖的参与方。注意：名义执行者往往不是真正对手方。
- 美债回购 → 对手方是**持有长久期旧券的机构**（保险、养老金、海外官方），不是财政部
- 收储存量房 → 对手方是**开发商/房东**，不是地方政府
- 化债 → 对手方是**银行与债权人**，不是中央财政

### 第二步：算对手方的盈亏账

对每一类对手方，计算按政策条款参与时的**即时确认损益**：

```
对手方参与损益 = 政策出价 − 对手方持仓成本（或账面价值）
```

**关键**：要看的是**已实现/需确认的亏损**，不是浮亏。很多政策要求对手方按市价交出资产，等于把浮亏一次性坐实，这在会计上和考核上都是不可接受的。

### 第三步：换算成参与率上限

把"亏损幅度"翻译成"机构行为"：

| 单笔亏损幅度 | 机构行为推断 | 政策规模上限 |
|---|---|---|
| < 3% | 可逐步参与 | 大规模可行 |
| 3%–10% | 需最高层特批，仅象征性参与 | 中小规模 |
| > 10% | 主流机构集体拒绝（除非监管强制） | 只能点到为止 |

### 第四步：交叉验证资金盘子

即使对手方愿意参与，还要看资金够不够：
```
可动用资金规模  vs  待解决问题总规模
```
若前者不足后者 5%，政策只能是**流动性调节工具**，不可能是结构性方案。

### 第五步：结论表述

输出必须是"**该政策只能做 X，做不到 Y**"的边界判断，而不是"政策会不会成功"的二元判断。

### 常见误用

- **把"决策者反复强调"当成"政策会落地"** —— 高调喊话往往正是因为落地困难。
- **忽略会计与考核约束** —— 机构拒绝不是因为不爱国，是因为当季财报和风控线不允许。

## M49：宣布效应 / 反身性信号检验（政策沟通评估）

**核心洞察**：有一类操作，**悄悄做能成，公开宣布就失败**。机制是：宣布行为本身泄露了信息——你越需要公开显示实力，越说明你没有实力。这会触发逆向选择与挤兑。

### 第一步：判断该操作属于哪一类

| 类型 | 特征 | 宣布的后果 |
|---|---|---|
| **实力展示型**（回购、护盘、注资、储备干预） | 目的是让市场相信"我有足够的弹药" | **宣布即削弱效果**，甚至反转 |
| **规则宣示型**（加息、减税、监管新规） | 目的是改变行为预期 | 必须高调宣布，透明度即有效性 |
| **中性型**（常规发行、例行操作） | 无信号含量 | 无所谓 |

**只有第一类适用本方法。** 用错类别会导致完全相反的结论。

### 第二步：识别"宣布"泄露了什么

追问一句：**如果这个操作不宣布，市场会不会知道？**
- 不会知道，且宣布后市场反而更紧张 → 宣布泄露了"主动干预的需求"，即承认有缺口
- 反正会知道（如拍卖结果、公开市场操作）→ 宣布无额外损害

### 第三步：推演反身性链条

```
宣布干预 → 市场解读为"情况比已知的更糟"
        → 理性参与者抢先行动（挤兑/抛售/提前赎回）
        → 缺口被放大
        → 干预成本上升，被迫加大力度或放弃
```

### 第四步：给操作方式评级

| 操作方式 | 效果预期 |
|---|---|
| 低调、小規模、常态化、不预告 | 最优，可持续，能悄悄释放流动性 |
| 低调但规模大 | 可能被市场自行发现，中等风险 |
| 高调且提前预告时间 | 最差，等于公告储备底牌 |

### 第五步：与 M48 联动

M48 判断"能不能做成"，M49 判断"怎么做才不失败"。**两个都要过**，才算完整评估：
- M48 说"对手方不愿意参与" → 政策规模天然有限
- M49 说"还不能声张" → 政策既做不大又说不得 → 只能是短期流动性工具

### 常见误用

1. **宿命化** —— "高调宣布所以必然失败"是错的。低调操作同样可能失败，宣布只是**削弱**效果，不是决定成败的唯一变量。
2. **人身归因** —— "因为他能力差，所以政策出错"这类判断**不可证伪、不产生任何信号**，且会让你系统性低估对手。禁止用决策者个人能力代替机制推演。
3. **把叙事当判断** —— "结构矛盾无解，最终以极端方式平衡"不是判断，因为它没有方向、期限、幅度和证伪位。凡结论无法收敛到这四项的，一律视为**叙事**，不作为决策依据。

## 组合使用

| 场景 | 配方 |
|---|---|
| 主权债利率异常上行 | M47（定位驱动）+ M44（债务供需结构）→ 收敛到区间与证伪位 |
| 某项财政/货币政策能否落地 | M48（对手方账本）+ M49（宣布方式）→ 输出规模上限与操作方式评级 |
| 政策表态与市场反应背离 | M49 + M29（预期差归因）+ M23（前后表态交叉验证） |
| 判断某资产是否被"挤占" | M47 第四步竞争侧证据 + M14（资产赛马与流动性虹吸） |

## 铁律

1. **任何归因必须写明时间窗口。**
2. **任何结论必须收敛到方向 + 期限 + 幅度 + 证伪位**，做不到就不是判断。
3. **有硬数据时，不用历史类比当主证据。**
4. **本文所有数字都是历史示例，用最新数据重跑。**
