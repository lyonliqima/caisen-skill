## 一、五层定义

| 层级 | 信源 | 性质 |
|------|------|------|
| **T0** | 期货基差与期限结构 / 期权隐波与风险逆转 / CFTC COT 持仓 / ETF 份额与折溢价 / 融资融券 / CDS / 预测市场赔率 / 港口吞吐与库存 / 开工率 / BDI·SCFI 运价 / AIS 船位 / 海关 HS 分项 / 发电量 / 招聘岗位数 / 招投标中标公告 / 环评能评备案 | 物理痕迹与交易痕迹，未经任何机构转述 |

## 二、使用规则（四条，强制）

1. **核心结论支撑证据必须含 ≥1 条 T1/T2**
   任何写入报告「核心结论」的支撑证据，至少一张卡来自 T1 或 T2；纯 T3/T4 支撑不得作为核心结论的主证据。

2. **仅 T3 支撑的结论自动降为 🟡 中置信**
   若一条核心结论的全部支撑证据只有 T3（无 T1/T2），无论措辞如何，置信度自动标 **🟡 中置信**，不得使用 🟢 高置信。

3. **仅 T4 的只能进「情绪佐证」，不得进因果链**
   纯 T4 信息（股吧 / 雪球等）不得进入因果链，也不得作为方向性判断的主证据；只能作为「情绪佐证 / 散户行为线索」辅助参考。若据此做方向判断，必须在报告中标注证据等级降为弱。

4. **供需类结论必须有 T0 支撑**
   凡结论涉及「供需 / 景气度 / 需求强弱 / 产能瓶颈 / 库存周期」，
   支撑证据必须含 ≥1 条 T0。只有 T1–T3 支撑的，置信度上限 🟡 中置信，
   不得使用 🟢 高置信，无论措辞多确定。

## 三、公告类专门规则

- **优先巨潮 / 披露易原文**：涉及公司公告、财报、交易所问询函、招股书等，一律优先抓取**巨潮资讯（A股）/ 披露易（港股）原文**。
- **东财转载仅作发现渠道**：东方财富资讯 / 股吧上的公告转载、快讯，只用于「发现哪有公告」；回溯与引用必须跳到巨潮 / 披露易原文，**不得把东财转载本身当作 T1 出处**（它实际是 T3）。
- 同一公告落卡：`origin` 写巨潮 / 披露易（T1），`via` 可标「东财发现」，`tier` 记 **T1**。

## 四、与诚实度协议的衔接

- 本表是 `SKILL.md`「诚实度协议」三级确定性标注（🟢高 / 🟡中 / 🔴低）的**证据底座**：🟢 要求多源 T1/T2；🟡 可由单 T3 触发；🔴 为纯推测或仅 T4。
- 第0步机械核查（数表）中「全表 T1/T2 ≥1」「独立 origin ≥3」即本表规则的可计数化版本。
