### 引用硬规则（5 条，引用前必读）

1. **符号 > 数值 > 趋势。** 引用 L54 三档读数时，先给符号（谁是净付方），再给数值，最后给斜率。**只给数值不给符号 = 口径错误**：净投资收益为正（全球在补贴它）与为负（它在向全球付息）是两个世界，数值接近时尤其不能混说。
2. **归因必须拆到端。** 「净收益恶化/改善」必须指明是哪一端（FDI 端 vs 组合投资+其他投资的付息端）。**混说总额即误判**——本轮总额从 +2590 亿崩至接近零，恶化 100% 来自付息端，FDI 端反而增强，两者不是同一件事。
3. **占比下降 ≠ 需求萎缩，必须跨柱交叉。** 用「储备份额」判"需求流失"必须与「交易盘」（OTC 份额 / 大宗计价份额）同看。本轮储备端降、交易端（2025-04 OTC 89.2%）稳，单指标下结论 = 过度读。
4. **自噬点必须找第二个，且必须落在另一根支柱上。** 只找到一个自噬点（L55）不算完成第二个必须与第一个在**不同的四支柱**上，否则只是同一件事的两种说法。
5. **三个日期必分离；引用新机制的规模用"存量占比"不用"预测值"。** 签署日 / 终规到期日 / 最迟生效日三者不可混用；机构预测（如某行"2028 年 2 万亿"）一律标「机构情景分析·非事实」，不得当既成事实进结论支点。

### M 组速查（L54–L56 · 纯步骤登记）

```
① L54 债务转嫁能力三档读数法（把"开关"变成"刻度"）：
   命题「霸权国A可以让全球替它买单」本身不可证伪，不能直接当结论。
   转三档可测读数（由粗到精，必须逐档下钻，禁跨档直接引用）：
   ┌ ① 存量档：该货币占全球外汇储备比例（COFER）/ 海外持有本国国债额
   │   测"别人愿意持有多少"。缺陷：是占比不是现金流；被汇率估值效应污染；
   │   不反映持有成本。→ 判"是否干净"的唯一办法：查当期汇率波动区间
   │   （本轮 IMF 明说 2026Q2 汇率在 ±2% 内 → 份额变动主要来自主动再配置）。
   │   ② 流量档（★最贴题）：对外净投资收益 NII（初次收入净额）
   │   测"到底谁在给谁钱"。↑这一档才真正回答"能不能向外转嫁"。
   │   缺陷：需拆归因（规则2）；绝对值口径多源不一致 → 方向可用、绝对值双列。
   └ ③ 价格档：本国国债的安全资产溢价（convenience yield）
       测"别人愿意为这份安全少收多少利息"。最敏感也最有争议；
       英格兰银行 2026-09 实测：历史约 +70bp，**已大幅削弱、长端甚至转负**。
   三条纪律：
   (a) 读法顺序永远是 规模 → 斜率 → 符号；**符号翻转是级别最高的事件**
       （本轮：2024 年 NII 首次翻负 = 布雷顿森林解体后首次向全球净付息）。
   (b) NII = FDI端（股权/直接投资收益差）+ 组合投资&其他投资端（付息）。必拆。
   (c) 单档不得下结论；至少①+②交叉，且①须与交易盘交叉。
   【挂 L11 / L12 / L50 / 09-四支柱·支柱二】

② L55 政策自噬校验法（同一工具的双代价检验）：
   主线叙事常是「用 X 来维护 Y」。本 L 强制检查 X 是否同时在损耗 Y 的另一条腿。
   三步：
   ┌ ① 列现金流：把该政策的全部现金流列出（谁付、付给谁、方向、量级）。
   │ ② 找回头流：其中是否有现金流向当初要拉拢/要压制的那一方？
   │   若有 → 该政策存在【内置成本地板】，规模越大越快触顶。
   └ ③ 定临界值：求"在多大剂量下 ②的损失会吃掉 ①的收益"——
       这个临界值才是可盯的证伪位，**而不是拍脑袋的目标价**。
   ★ 硬纪律：**只找到第一个自噬点不算完成。** 必须找第二个，且第二个
     要与第一个落在【不同的四支柱】上（本轮：货币支柱 vs 实体硬支撑）。
   本轮实例化：
   · 自噬点一（货币侧）：高利率维护美元 → 抬高外国持有的约 26 万亿计息
     资产的应付利息 → 直接吃掉 NII（L54②流量档）。
   · 自噬点二（能源政治侧）：制造"不太平"维持美元避险需求 → 油价上行推高
     本国通胀 → 打击执政方支持率（本轮 35% 经济支持率）→ 反过来威胁该政策
     的连续性。
   【挂 L16 战略叙事依赖 / L45 战争成本自损-转嫁 / L32 能源政治 / L11】

③ L56 政治日历 → 观测时点映射法（三日期必分离）：
   立法/监管/选举事件常被当"花絮"，但它们往往是框架的真约束变量。
   三步：
   ┌ ① 同推迟聚合法：当【两个以上彼此独立】的重要动作都被推迟到同一个
   │   日期之后，那个日期才是真正的约束变量——不是最近的那个数据事件。
   │   （本轮：财政整顿方案 + 对伊朗第二轮打击计划，双双被排在
   │     2026-11-03 中期选举之后 → 11-03 = 分水岭，而非同期的 FOMC。）
   │ ② 三日期分离登记：签署日 / 终规（实施规则）到期日 / 最迟生效日。
   │   ⚠️ **错过终规期限是常态不是例外**（本轮 GENIUS 法案：2025-07-18 签署，
   │     终规原定 2026-07，监管机构错过，法律最迟 2027-01-18 生效）。
   │   → 推论：新基础设施的"上线日"按【最迟生效日】排，不按签署日排。
   │     按签署日排会系统性高估其当期作用。
   └ ③ 存量占比 vs 预测值分离：新机制当期作用一律用"今天占存量的比例"，
       不用机构预测值。本轮：稳定币总市值 3076 亿、发行人持美债不足美债
       总量 1%（发行国财政部 TBAC 自己口径）→ 判为【期权而非引擎】。
   【挂 L5 政策工具四维 / L42 战争终止条件 / L12 双管道施工】
```

### 与既有归档的裁断（2026-10-23）

- **vs L11（美元信用支柱崩塌-重建）**：L11 判的是"支柱松没松"，本组 L54 给的是"松了多少、以什么代价"的**刻度读数盘**。二者不并列——**先用 L54 取数，再交给 L11 定性**。回写：**L11 的诊断输入从"定性判断"升级为"三档读数交叉"**。
- **vs L12（结构性需求锁定·双管道）**：L12 追踪"双管道施工"，本组**确认了第三条管道的存在且在法律上已被造出来**——GENIUS 法案强制美元稳定币 1:1 配短债，等于把铸币权从央行下沉到个人手机。已据此**回写 09-四支柱：新增第五支柱·链上美元**（见该文件增补段）。**纪律**："制度已被立法造出来"是法律事实，与"其规模是否已能接住国债"是两回事，二者不可互换，须按 L56③ 分开说。
- **vs L50（商品锚缺失后双路径）**：L50 的核心裁断是"技术上的可行 ≠ 政治上的稳固"。本组提供了 L50 政治侧此前**缺失的那个数字**：NII 的符号。**换言之**——技术路径回答的是"失去商品锚后，法币靠利率规则在技术上还能不能转"；NII 符号翻转回答的是另一件事：**政治路径的现金红利已经用完**（美国仍拿得到储备货币这个记账单位地位，但已经要为净负债开始向外净付息）。两条路径不可互相证伪，L50 原有裁断不变。
- **vs 11-号（美元霸权下通胀化债）**：11 号②"通胀可转移性三要素"是从**能不能转嫁出去**判；本组 L54 是从**转嫁净额还剩多少**判。**裁断：11 号回答"有没有这条出路"，L54 回答"这条出路还剩多宽"，串成链路不并列。**
- **vs L45（战争成本自损-转嫁结构）**：L55 的"双代价检验"是 L45 的**泛化版**——L45 限于战争，L55 适用于任何"用 X 维护 Y"的政策（本轮实例化：自噬点一在货币侧、自噬点二在能源政治侧，二者落在**不同的四支柱**上，符合 L55 硬纪律）。**裁断：L45 是 L55 在战争场景下的特例，二者不重复，L55 更高一层。**
