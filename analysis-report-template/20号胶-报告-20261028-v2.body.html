12.2 核心结论

结论一（🟢 高置信）：上一轮的"需求塌方"是数据误读，必须撤回。10 月第一周的 28.97%/28.48% 是国庆 7 天停产的制度性停摆，不是需求信号。10-15 当周已回升至 53.31%/57.80%，10-22 当周 59.42%/64.64%——半钢已完全持平 8 月（64.57%），全钢仅低 4.22pct。抽掉这一票，上一轮"5 空 / 0 多"的证据分布变成"2 多 / 2 中性 / 2 空"。这是我必须明确承认的错误：不是结论偏了，是地基错了。

14. 🟥 红队 · 对抗性终审（这一轮红队要攻击的是"翻多"本身）

14.1 最强反面证据：这个多头判断有四个致命弱点

  • 弱点一：期限结构不支持多头。如果供给真的这么紧，曲线应该是 backwardation（近月贵）。实际是近乎全平水（2611 16,575 / 2701 16,595 / 2705 16,665），2701→2705 年化仅 +1.27%。市场明确拒绝为"未来更紧"付钱——这比任何基本面数据都更能说明交易者的真实看法。
  • 弱点二：去库是"被动"的，随时可逆。去库速度已衰减 71%（−0.135 → −0.039 万吨/天），且保税降幅（−2.23%）远大于一般贸易（−0.28%）。这是"到港少了"造成的去库，不是"用掉了"造成的去库。泰国南部雨一停、到港恢复，一周就能转累库。
  • 弱点三：需求的天花板是硬的。乘用车零售同比 −28%、外胎产量 −3.3%、小客车胎出口环比 −6.14%、欧盟强制海关登记。开工率从 28.97% 回到 59.42% 只是填坑，不是扩张——同比仍低 10–13pct，且半钢成品库存周转 37.61 天在逆势上升（+0.66）。开工率回升 + 成品库存上升 = 产成品在积压，不是需求在好转。
  • 弱点四：98.9% 分位意味着赔率不对称。从 16,595 向上到 17,800 是 +7.3%，向下到 15,953（MA60）是 −3.9%。但真正的尾部在下面：B 招测幅 14,420 是 −13.1%。用 15% 仓位做多的期望值，取决于"回到 17,800"的概率是否真的大于 50%——而傅海棠的"低价"维度说不是。

14.2 最脆弱环节：我的"合理价"判断依赖一个未经验证的假设

"进口 −17.85% 是因为海外供给紧"——这个因果链没有证据。进口下降也可能是因为：① 内外价差不利（进口亏损），贸易商主动少进；② 20 号胶缺乏交割利润，进口胶转向混合胶或一般贸易（9 月混合胶进口结构变化未查）；③ 需求端订单少，主动减少采购。如果是 ② 或 ③，那"进口断崖"就不是供给信号，而是需求信号——整个多头逻辑的支柱会塌。这一条我本轮没能证伪，必须标为未解决。
