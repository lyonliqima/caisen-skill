# 杨世光宏观·指标时序属性前置校验法（M126）

> **来源**：杨世光《金钱豹》2026-11-12 期口播逐字稿（ASR 文本）。逐条核查与观点记录见 `examples-1112.md`。
> **性质**：**研究方法，不是观点集合**。节目中的方向性判断（「PCR 回到 85%/100% 决定反弹时间与幅度」「11 月中下旬见右侧起跌」）是历史时点的例子，不可当当前结论复用。
> **定位**：本工具不新增任何指标，而是给**所有既有指标加一道前置闸门**——用指标预测「什么时候、涨多少」之前，先证明它真是领先的。
> **立规背景**：本期口播用台指选择权 P/C ratio 69% → 85%/100% 去推「这波反弹或回升的**时间与幅度**」，但 P/C ratio 的定义是 **Put 未平仓量 ÷ Call 未平仓量**，属存量部位，公开口径明确「通常落后指数 1–2 周，不是领先讯号」。**指标用对了、时间箭头用反了**。同类提醒在 `examples-1106-fragments.md`（「没说领先多久」）出现过一次但未成工具，本次固化。
> **配套红线**：R23（禁滞后/同步指标定时）全文在 `SKILL.md`，本文件只留立规背景与实测。

---

## 核心原理

```
指标的时间属性由「它记录的是什么」决定，不由「我希望它预测什么」决定。

  流量/成交类  → 多与价格同步，偶尔领先（成交是当下行为）
  存量/持仓类  → 多为同步或滞后（部位是过去决策的沉淀，调整要时间）
  会计/统计类  → 几乎必然滞后（先有经济行为，后有报表）

用途上限（硬约束）：
  领先 → 可定时、可定幅（仍须给证伪位）
  同步 → 只能确认「现在是什么状态」
  滞后 → 只能做事后归因与结构描述
```

🔺 **默认规则**：没做过领先性检验的指标，**一律按同步或滞后处理**。举证责任在使用者，不在质疑者。

## 校验四步（缺一步不许写时间窗）

| 步 | 动作 | 交付物 |
|---|---|---|
| 1 | **查编制定义**：一手交易所/统计方口径，至少两家交叉；写明分子分母是成交量还是未平仓量、是存量还是流量 | 口径卡片（含数据源与发布日期） |
| 2 | **归三分类**：领先 / 同步 / 滞后。未平仓量、余额、存量报表默认落「滞后」档 | 分类结论 + 理由 |
| 3 | **做领先性检验**（若要主张领先才做）：与标的做错峰相关（lag −k…+k）、事件对齐（指标转折是否早于价格转折）、样本外复核 | 错峰相关表 / 领先期数；无检验则不得主张领先 |
| 4 | **按属性限定用途**：把允许写的句子类型写进结论模板 | 「只能确认状态」或「可定时/定幅 + 证伪位」 |

### 判据表

| 属性 | 允许写 | 禁止写 |
|---|---|---|
| 领先（已检验） | 「若 X 在 T 前达到 N，则…；否则…」+ 证伪位 | 无检验就定时 |
| 同步 | 「当前状态偏多/偏空」 | 「还能涨多久」「X 月见高点」 |
| 滞后 | 「事后看，部位在…已堆积」 | 一切时间窗与幅度预测 |

## 本期实测（2026-11-12）

| 项 | 核实结果 |
|---|---|
| 指标定义 | TAIFEX 台指选择权 **P/C ratio = Put 未平仓量 ÷ Call 未平仓量**；>100% 偏多、<100% 偏空（反向解读）；成交量 PCR 才反映短线偏好，两者不可混用 |
| 时序属性 | **未平仓 PCR 通常落后指数 1–2 周，不是领先讯号**（Blave 量化工作室；与 TAIFEX 官方口径一致） |
| 序列 | 11/02 约 **47.77%**（本库 `examples-1106.md` 归档）→ 11/12 约 **69%**，确在回升 |
| 口播用法 | 用 69% → 85%/100% 推「反弹或回升的**时间与幅度**」「够不到则 11 月中下旬见右侧起跌」 |
| 裁决 | ❌ **时序越权**。69% 只能读作「卖权相对堆积、情绪较 11/02 修复」，不能读作「还能涨多久」。85% 亦为无窗口标注的经验阈值（Z17 / R17） |
| 正确写法 | 「PCR 自 47.77% 回升至 69%，仍 <100%，法人未翻多（同步状态描述）。反弹能否延续，须另挂**领先**指标（量能、月线扣抵日 M98、政策生效日 M114）与可证伪价位」 |

> 交叉印证：M92 纪律 3 原本就写「M92 是**日内/周度情绪刻度**，不承载中期方向判断」——本工具是把这条纪律从「提醒」升级为「所有指标通用前置闸门」，不是推翻 M92。

## ⚠️ 使用纪律

1. **同一指标的不同口径可以分属不同分类**：成交量 PCR（流量）≠ 未平仓 PCR（存量）。混用口径是本期最容易复发的一处。
2. **「领先多久」必须给数**：`examples-1106-fragments.md` B3 已吃过一次亏（散装船在手订单当作领先量却没给领先期）。主张领先必须写清领先几周/几月，并给历史样本。
3. **滞后指标不是废指标**：它适合做事后归因、结构描述、拥挤度确认；被禁的只是「定时与定幅」。
4. **阈值要标窗口**：100% 是 P/C 公认多空分界；85% 这类经验阈值须给历史窗口、样本数、胜率，否则按 R17（过期价格锚）/R18（峰值三件同报）处理。
5. 与 **R8**（不可证伪命题）、**R12**（相位外推带时间锚）叠加使用：本工具管时间箭头，R8 管可证伪，R12 管慢变量外推频率。
