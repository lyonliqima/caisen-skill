### L 组速查（L51-L53 · 纯步骤登记）

```
① L51 数据核验与来源分层法：
   分析任何宏观/市场叙事，第一步不是推导，是先核验 + 分层。
   三步：① 查官方一手（海关/统计局/美联储/IMF/CME），与转写数字逐条对账；
   ② 逐句标源：「原话✓ / 作者解读⚠️ / 未核△」，分离"发言人说了什么"与"别人替他总结了什么"；
   ③ 单位/口径纠错（量级差万倍级的单位错误、美元/人民币混用、市场年度 vs 日历年度）。
   输出：可引用原料（原话 + 已核数字）与待验证假说（解读 + 未核数字）两份清单。
   【挂 L19/L48·同源：发言效力靠核验与分层才能判定】

② L52 量价拆解判别法（需求拉动 vs 成本推动）：
   任何"金额/价格增长"强制拆为  金额 = 数量 × 单价  两因子。
   量增价平（或量增主导）→ 需求拉动（真实景气、可持续）；
   价增量平 / 价增量减 / 价增主导 → 成本推动或涨价驱动（非需求扩张、价格幻象）。
   判读：涨价驱动的增长，一旦价格回撤（产能跟上/需求退潮），金额迅速回落。
   【挂 L23/L24/L17·补贸易与价格数据的量价维度】

③ L53 PPI 购进-出厂剪刀差 → 上下游利润挤压诊断：
   差 = 购进PPI − 出厂PPI = 上游成本向中下游传导中"可被吞噬的利润厚度"。
   差为正且扩大 → 中下游毛利被压（成本推动型通胀，终端未提价，企业利润表先扛）；
   差为负/收敛 → 下游开始向终端转嫁（L23 传导指数 >1）。
   叠加 生活资料PPI 符号（负 = 内需弱、终端提价无力）→ 判"输入性通胀 vs 内生通胀"。
   ⚠️ 剪刀差为正 + 生活资料为负 = 典型"上游吃肉、下游挨打"，政策必偏向扩内需。
   【挂 L23/L24/L21】
```
