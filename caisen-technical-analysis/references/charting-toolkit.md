## K线图表划线方法（蔡森式标注法）

当用户提供股票K线图要求分析时，需要在图表上进行专业标注。以下是蔡森在实战教学中使用的划线规范：

### 划线工具与颜色规范

| 元素 | 颜色 | 用途 |
|------|------|------|
| 颈线（支撑/阻力） | **黑色水平线** | 标注形态的关键颈线位置 |
| 跌破/危险线 | **红色水平线** | 标注跌破即确认空头的关键位 |
| 目标/满足线 | **绿色水平线** | 标注测幅满足目标价位 |
| 辅助参考线 | **紫色水平线** | 标注次要支撑阻力或前高前低 |
| 整理区域 | **紫色虚线矩形** | 框选矩形整理/箱体震荡区间 |
| 突破方向 | **红色箭头** | 指向突破方向或关键转折点 |
| 关键点 | **红色圆圈** | 圈出重要价格转折点 |
| 进场点 | **"+" 标记** | 标注建议进场位置 |
| 失败点 | **"X" 标记** | 标注形态失败/止损位置 |
| 价格标注 | **数字** | 在所有关键位置标注具体价格 |
| 测幅距离 | **蓝色竖线 + 数字** | 标注形态高度（用于计算满足点）|

### 划线步骤（按蔡森实战顺序）

**第1步：画水平颈线**
- 在图表上画出形态的关键颈线（水平线为主）
- 底部形态：连接反弹高点 → 黑色水平线
- 头部形态：连接回调低点 → 黑色水平线
- 在每条线旁标注具体价格数字

**第2步：标注形态结构**
- 用文字或标记标注：左肩、头部、右肩（头肩形态）
- 标注：第一底、第二底（W底）
- 标注：前高、前低
- 用手绘线连接关键点形成形态轮廓

**第3步：画整理区域（如有）**
- 若存在矩形整理/箱体震荡，用紫色虚线矩形框选
- 标注上沿和下沿的价格

**第4步：标注量价信号**
- 在成交量图上标注关键量变化
- 用红色箭头指向关键K线（如破底翻的破底K线、突破K线）

**第5步：计算并标注测幅满足**
- 用蓝色竖线测量形态高度（从底部到颈线，或从顶部到颈线）
- 在竖线旁标注高度数值
- 从颈线位置投射等距高度，用绿色水平线标注目标价位
- 标注文字："满足点 XXX"

**第6步：标注进出场位置**
- 用 "+" 标记进场点
- 用 "X" 标记止损点
- 用红色箭头标注突破/跌破方向

### 多周期分析标注

蔡森习惯同时分析多个时间周期：
1. **先看月线**：确定大方向和大级别形态
2. **再看周线**：确认中级趋势和形态
3. **最后看日线/60分钟线**：找精确进出场点

标注时需说明当前分析的是哪个周期，不同周期的形态可能不同。

### 日线画线分析窗口规范（2026-06-17更新）

**日线形态分析默认窗口 = 60个交易日（约3个月）**，对应算法回看范围120根K线（含缓冲）。

| 分析需求 | K线窗口 | 形态识别优先级 |
|---------|---------|---------------|
| **标准日线画线** | 最近60个交易日 | W底→M头→头肩底→头肩顶→破底翻→收敛三角→旗形→趋势线 |
| 大格局（周线级） | 最近120个交易日 | 同上，但满足幅度更大 |
| 短线（60分钟级） | 最近30根60分钟K线 | 以破底翻/假突破为主 |

**画线必须参照 `drawing-guide.md` 中的量化形态识别算法**：
- 局部极值检测（lookback=3~5）
- 双底/双顶差值阈值（5%）
- 颈线倾斜角度判断（<15°）
- 破底翻量化判定（跌破3%+收回）
- 收敛三角边长等长测幅
- 配色体系统一（橙色#FF6B00颈线、绿色#2ecc71支撑、红色#e74c3c阻力）
- 四色K线系统（红=强势阳线/黄=假阴线/绿=假阳线/蓝=强势阴线）

### 输出格式（带图表分析）

当用户提供K线图时，输出应包含：
1. **形态识别**：当前走势属于什么形态
2. **图表标注**：按上述划线方法在图上标注（用文字描述标注位置和内容）
3. **颈线标注**：颈线位置及含义
4. **量价分析**：成交量与价格的配合情况
5. **多空判断**：当前应做多、做空还是观望
6. **交易计划**：进场条件、止损、目标价位
7. **风险提示**：形态失败的条件

## K线四种颜色系统

K线图中出现四种颜色，遵循华人金融市场惯例“红涨绿跌”：

| 颜色 | 含义 | 画在哪里 | 条件 |
|------|------|----------|------|
| 红色 | 上涨（阳线） | K线实体填充 | 收盘价 > 开盘价 |
| 绿色/蓝色 | 下跌（阴线） | K线实体填充 | 收盘价 < 开盘价 |
| 黑色 | 影线 | 上下影线细线 | 每根K线都有 |
| 白色 | 平盘（十字星） | K线实体空心 | 收盘价 ≈ 开盘价 |

**注意**：不同平台颜色略有差异（如通达信用蓝色代替绿色表示阴线，TradingView用西方惯例绿涨红跌）。分析时需先确认颜色编码。

## 多平台联动分析工作流

蔡森在视频教学中使用4个不同平台进行联动分析，每个平台负责不同市场：

| 顺序 | 平台 | 分析对象 | 目的 |
|------|------|----------|------|
| 第1步 | 东方财富金融终端 | A股大盘/沪深300/可转债 | 判断中国市场大环境 |
| 第2步 | XQ全球赢家(保哥财经分析系统) | 台股期货(7000A/7652A) | 判断亚太区域趋势 |
| 第3步 | TradingView | BTC/USDT(4小时线)+美债殖利率(日线) | 全球风险偏好+利率环境 |
| 第4步 | 通达信金融终端 | 美股个股(NVDA/AMD/INTC等) | 深入个股分析 |

**分析联动逻辑**：
1. 先看A股大盘（沪深300）→ 确认中国市场整体多空
2. 再看台股期货 → 判断亚太资金流向和短线趋势
3. 看BTC走势+美债殖利率 → 判断全球风险偏好和利率环境（BTC涨=风险偏好上升，殖利率回升=资金成本上升）
4. 最后深入美股个股 → 结合基本面+技术面做最终判断

## 通达信基本面速查法

蔡森在通达信金融终端分析美股时，会同时查看右侧基本面面板：

| 指标 | 关注重点 | 蔡森的判断逻辑 |
|------|----------|---------------|
| 总市值 | 绝对规模 | 大市值=主力难操控，中小市值=弹性大 |
| P/E(市盈率) | 估值高低 | P/E过高=泡沫风险，配合技术面判断是否见顶 |
| ROE(净资产收益率) | 盈利能力 | ROE>30%=优质公司，ROE<10%=需警惕 |
| EPS(每股收益) | 成长性 | EPS持续增长=基本面支撑股价 |
| 负债率 | 财务风险 | 负债率过高(>70%)+技术面走弱=危险信号 |
| 股息率 | 防守价值 | 高股息率=下跌时有支撑 |
| 机构股东变动 | 聪明钱方向 | 大机构(Blackrock/Vanguard)增持=看多信号 |
| 盘前交易价格 | 隔夜消息影响 | 盘前大幅波动=当日需注意风险 |

## 半导体板块轮动跟踪法

蔡森特别关注半导体板块的全球联动：

```
轮动链条：NVDA(龙头) → AMD(二线) → INTC(转型) → 台股半导体 → A股半导体 → 上游材料(玻纤/化学)

观察顺序：
1. NVDA见顶信号 → 整个半导体板块风险上升
2. AMD财报前/后 → 判断二线半导体强弱
3. INTC转型进展 → 传统半导体是否回暖
4. 台股半导体(台积电/联发科/南亞科) → 亚太半导体风向标
5. A股半导体板块 → 联动传导，阿尔科技等
6. 上游材料(玻纤紧跟) → 旗滨集团(601636)等上游材料跟随半导体板块
```

**蔡森的半导体板块操作原则**：
- NVDA创新高 → 板块整体看多，可做多二线半导体
- NVDA见顶(M头/假突破) → 减仓所有半导体持仓
- NVDA破底翻 → 板块重新看多，但需确认量能
- 半导体龙头涨完后 → 关注上游材料(玻纤)补涨机会

## K线图表涨跌幅标注法

蔡森在通达信/东方财富的K线图上，会直接标注关键区间的涨跌幅百分比：

```
标注位置：K线图空白区域（图表上方或下方）
标注颜色：绿色=涨幅、红色/蓝色=跌幅
标注格式："+17.42%"、"-21.3%"、"+31.1%"
标注目的：直观展示某段行情的总涨跌幅，辅助判断测幅满足
```

**与测幅满足的结合**：
- 若前一段上涨+31.1%，回调-21.3%，再次上涨目标可参考前段涨幅
- 标注历史涨跌幅可以帮助识别"涨幅满足"或"跌幅满足"的区间

## 时间衰减权重机制

蔡森的观点和分析结论按时间加权，越近的观点参考比重越高：

| 时间范围 | 权重 | 说明 |
|----------|------|------|
| 7天内 | 100% | 最高参考，当前市场环境的直接判断 |
| 1个月内 | 80% | 高度参考，趋势判断仍有效 |
| 3个月内 | 60% | 中等参考，大方向有效但细节需验证 |
| 6个月内 | 40% | 辅助参考，需结合最新数据 |
| 1年以上 | 20% | 仅做历史参考和方法论学习 |

**冲突处理规则**：当不同时期的观点冲突时，以最新观点为准。旧观点保留但标注"已被新观点覆盖"。

**记录规范**：每条分析结论必须标注日期（从视频截图时间戳提取），格式：`[YYYY-MM-DD] 观点内容`。
