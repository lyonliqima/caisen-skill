## Z21 资产负债表两端定位四步法

**一句话**：先问「这是谁的表」，再定钱从哪来、到哪去；**只有负债端方向变了，才允许推资产端重估**。

### 操作步骤（缺一步不准往下推）

1. **定主体**：全球美元体系 / 某央行 / 商业银行 / 企业 / 自己账户。同一段话里换主体＝偷换概念，必须拆开写。
2. **标两端**：负债端＝资金来源 + 成本；资产端＝资金去向 + 收益。逐项写**存量**与**成本/收益率**，不许只写比率。
3. **判方向变化**：负债端是收缩还是扩张？用的是**增量**还是**价格**？没有方向变化就不得推出「崩塌」。
4. **逐段找断点**：把传导链画成若干段，逐段标 ✅/❌ 与归因；断点定位到具体一段，不许停在「万物皆跌」。

### 三条硬约束

| 约束 | 说明 | 2026-11-12 实锤 |
|---|---|---|
| **存量 ≠ 比率** | 资产负债是**存量恒等式**，两端收益率之比是**流量比率**；用后者推前者须计久期、汇率折算、冲销成本 | 口播「一块钱美元资产 cover 三块人民币负债」＝ 5.1% ÷ 1.7%。用真实数 4.86~5.01% ÷ 1.59% ≈ 3.06，量级巧合接近，但**两个输入都错**（中国 10Y 实为 1.59% 非「2% 以上」，负债端约 1.2~1.35% 非 1.7%） |
| **错输入凑出对量级 ≠ 方法对** | 结果看着对不能豁免输入校验（2026-10-28 已立「修饰性增量同等强度校验」，本条为其比率版） | 同上 |
| **资产端要逐资产举证** | 「负债端收缩 → 资产端崩塌」是骨架，不是每个资产的证据 | 口播把钻石、中药材、威士忌、葡萄酒、黄金、油价、人格、神性全装进同一个解释，**不可证伪** |

## Z22 万能解释免疫检查：可证伪三件套

**一句话**：任何「A 导致 B」的宏观判断，必须同时交出 **① 传导通道 ② 触发阈值 ③ 证伪位**；缺任一条，判为**软证据，不得作买卖触发条件**（承接 Z14–Z17 的硬度分级）。

### 操作步骤

1. 把结论写成 `若 [可观测信号] 在 [时间窗] 达到 [数值]，则 [资产] 走 [方向 + 幅度]；否则 [反向动作]`。
2. 检查三件套是否齐：通道写清中间几段了吗？阈值有口径与窗口吗（Z17）？证伪位是可观测的吗？
3. 三件套不齐 → 降级为「观察清单 / 背景叙事」，**不得进入交易清单**。
4. 反向自查：这个解释有没有「无论涨跌都能自圆其说」的版本？有 → 直接剔除。

### 实锤（2026-11-12）
- 口播全篇**只有一处**自带三件套：台指 PCR 69% → 85%/100% + 11 月中下旬 + 够不到即右侧起跌。**这个动作要学**。
- 但缺口径（成交量 PCR 还是未平仓 PCR）、缺数据源、85% 无历史窗口与胜率 → 三件套只交出一半。
- 「黄金跌下去会沉睡 20 年」「资产端崩塌只是谁先谁后」→ 无阈值无证伪位，判**软证据**，仅作背景。

### 接口
- **Z14–Z17** 的硬度分级是 Z22 的裁判：软证据只能描述「现在大概在哪」，不能触发买卖。
- **Z13** 双叙事对照前先过 Z22，否则两套读法都不可证伪。

## Z23 指标时序属性检查（领先 / 同步 / 滞后）

**一句话**：**拿指标预测未来之前，先证明它是领先的**。没证明就默认同步或滞后——这是本期最贵的一处误用。

### 操作步骤

1. 查该指标的编制定义与公认时序属性（一手：交易所 / 统计方；至少两家交叉）。
2. 若口径为「未平仓量」类存量指标，默认**滞后**，须做领先性检验（与标的滚动相关、错峰回归）才能当预测变量。
3. 若仍要用，只能用于**确认状态**，不得用于**预测时间与幅度**。
4. 阈值若非公认分界（如 100%），必须标历史窗口、样本数与胜率。

### 实锤（2026-11-12）
- TAIFEX 定义：P/C Ratio = Put **未平仓量** ÷ Call 未平仓量，>100% 偏多、<100% 偏空（反向解读）。
- 交叉源明确：未平仓 PCR **通常落后指数 1–2 周，不是领先讯号**；成交量 PCR 反映短线偏好，两者不可混用。
- 口播用 69% 去推「这波反弹或回升的**时间与幅度**」「11 月中下旬见右侧起跌」→ **时序误用**。
- 序列对照：11/02 归档读数 47.77% → 11/12 约 69%，确在回升，但只能读作「卖权相对堆积、情绪修复」，不能读作「还能涨多久」。
- 100% 是公认多空分界；**85% 为经验阈值**，无窗口标注，按 Z17 判不可用。

### 接口
- 与 **Z12**（季节性失效）、**Z18**（一阶导陷阱）同属「读法防错」族；Z18 防念反符号，Z23 防念反时间箭头。
- 与 **Z6** 的「落后指标反推领先拐点」（examples-20261104 第七个硬伤）为同一错型在不同市场的复现 → **第三次出现，固化为永久前置开关**。
