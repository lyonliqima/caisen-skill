## 二、算法拆解（可复用的方法论）

### 2.1 能繁母猪 → 商品猪出栏 传导周期（猪周期的时间轴）

```
商品猪出栏量(t)  ←  10~12 个月前能繁母猪存栏量
                   其中：母猪妊娠 ≈ 114 天(3.8 月) + 仔猪哺乳/保育 + 育肥至出栏 ≈ 6 月
                   ≈ 9.8~12 个月（行业一般说 9~10 月，实测前置去化经 10~12 月传导兑现）

推演用法：
  当下某合约对应出栏月份 = 合约月份
  其供给源头            = 该月份 − 10~12 个月的能繁母猪存栏
  例：LH2611(2026-11 出栏) ← 2025-11 ~ 2026-01 的能繁存栏（偏高 → 放量）
      LH2709(2027-09 出栏) ← 2026-09 ~ 2026-11 的能繁存栏（若 Q3 调减到位 → 收缩）
```

**为什么这是生猪分析的第一性原理**：能繁母猪是产能的"种子"，它的变化要经近一年才变成"肉"。所以**近月合约定价的是 10 个月前的产能决策，远月合约定价的是当下的产能决策**——这正是近弱远强（或反身性反转）价差结构的根源。

### 2.2 近月 vs 远月 策略矩阵（现实供给 vs 预期供给）

| 维度 | 近月（如 2611） | 远月（如 2705/2707/2709） |
|---|---|---|
| 定价对象 | 当下出栏量（现实） | 8~10 月后供给收缩（预期） |
| 主导逻辑 | 现实供给压制，难快速扭转 | 博弈产能去化兑现，预期重定价 |
| 抄底可行性 | 极低（空头压制+时间少） | 需等数据验证去化，磨底后修复 |
| 关键风险 | 交割月临近、供给持续放量 | 去化不及预期→预期落空；Contango 移仓贴钱 |

**原文铁律（可吸收）**：做多不图便宜买近月低价合约——近月没有拉升机会；要做多远月，但**时机要对**（等能繁实际淘汰+仔猪存栏下行被数据确认）。

### 2.3 硬目标约束下的产能出清更彻底（政策驱动的周期性放大）

```
过往周期：能繁去化 = 挤牙膏式（外部压力推一点、行业淘汰一点）→ 出清慢、底部长
本轮：    农业农村部设 Q3 硬性调减死任务（逆周期调控，省负总责+菜篮子市长负责制）
         → 头部企业+全行业集中行动：加速商品猪出栏 + 推进能繁淘汰
         → 短期集中出栏放大供给压力（压制近月）
         → 但为远月埋下供给收缩支撑（出清比挤牙膏式更彻底）
```

**结构性含义**：政策硬约束把"慢出清"变成"快出清"，代价是**短期阵痛**（近月最痛），收益是**远月更干净的底部**。这是生猪区别于纯市场化品种的关键变量。

### 2.4 时间锚（把"死任务"翻译成交易日历）

```
Q3（2026-07~09）能繁调减达标死任务
   → 集中出栏/淘汰发生在 Q3
   → 对应商品猪出栏收缩出现在 Q3 + 10~12 个月 ≈ 2027 年下半年
   → 远月合约（2705/2707/2709）正是这段窗口，修复逻辑对应的就是这里
```

> ⚠️ 注意：2026-06 末能繁存栏已降至 3780 万头（绿色区间 100.8%），去化已"大体到位"，Q3 更多是把目标**钉死+巩固**，而非从零开始。所以"倒推 8~10 个月出行情"的锚点，应从 **2026Q3 调减加速段**算起，对应 **2027 下半年**远月，而非从零计。

### 5.1 ↔ `换仓时机-roll-timing.md`（月差结构）
- 生猪常态 **Contango**（远月升水），与文章"远月价格远高于近月"一致。

### 5.2 ↔ `prediction-framework.md`（圆桌投票如何落地生猪）
- **产业基本面派**（傅海棠五维拐点/叶庆均供需）：能繁→出栏传导是典型"供需矛盾前置指标"，近月供大于求=产业偏空，远月供给收缩=产业偏多。**多空分离到不同合约**，不是简单多空。
- **政策驱动**（索罗斯反身性/葛卫东混沌）：硬目标约束制造"人为加速出清"，是反身性中的政策外生冲击，放大近月阵痛、埋远月预期。
- **趋势跟踪派**（利弗莫尔/克罗）：近月增仓下行=空头主动（方向可信），远月需等"去化数据+技术拐点"确认再入场，不在磨底中抄底。
- **风控前置**（risk-control-expert）：近月不碰是天然风控；远月多头须设"去化不及预期/仔猪存栏回升"为证伪止损。

### 5.3 一句话记忆
**近月看 10 个月前的母猪（现实），远月看现在的母猪（预期）；政策死任务把慢出清变快出清，代价近月最痛、收益远月最干净——但 PSY 提升对冲了名义去化，远月修复的置信要打折，且 Contango 移仓成本必须算进账。**

## 六、引用硬规则（四条，不遵守不得引用）

1. **价格先复核**：文中 2611/2701 数字为 2026-09-18 盘中 snapshot，引用前查 DCE 实时最新价，不得当稳态。
2. **去化分两层**：说"能繁去化"必须同时给名义存栏（3750 万目标/3780 万实际）与**等效供给（PSY 效率对冲）**，只讲名义视为无效表述。
3. **远月多头算盈亏比**：必须叠加 Contango 移仓成本（见 roll-timing），远月涨幅 > 月差成本才成立，否则"修复逻辑"只是方向、不是可开仓的交易。
4. **现货必多口径，且不得跨源比方向**（2026-09-30 新增）：生猪现货均价存在供应商口径差异，**同一交易日不同口径的涨跌方向可以相反**。
   实测 2026-09-30：我的农产品网（Mysteel）**+0.06**（9.99→10.05）｜ 搜猪网/机构外三元 **−0.11**（10.07→9.96）｜ 中国养猪网瘦肉型（猪好多）**−0.18**（10.23→10.05）；同一日同一指标绝对价差达 0.09 元/公斤。
   **判"止跌 / 连涨"只认同一口径的连续序列**；跨源比较涨跌方向，或只给单一来源的方向，均视为无效表述（与粕类"双口径"规则同源）。

### 7.2 行业完全成本反推（新增算式，可复用）

```
行业平均完全成本（元/公斤）
  = (现货均价 × 出栏均重 + 自繁自养盈利) ÷ 出栏均重
  实测：现货 10.53 元/公斤（9/16）、自繁自养 −200.7 元/头、出栏均重 129.25 kg
  → (10.53 × 129.25 + 200.7) ÷ 129.25 = 12.08 元/公斤 ≈ 12,100 元/吨
  （口径敏感度：均重取 125 kg 得 12.14，同量级）
```
**用法**：把成本线画到远期曲线上，立刻看出哪些合约已把「回到盈亏平衡」定价完毕。
2026-09-30 曲线：2611=10575｜2701=11320｜2703=11145｜2705=12275｜2707=13115｜2709=13740
→ **2705 刚贴成本线；2707/2709 已在成本线上方 8%~13%。** 远月的「修复」不是预期，是**已定价**。

### 7.5 移仓的赚赔临界：Contango → Back（对 roll-timing 第三节的补充）

```
多头移仓赚赔 = f(月差结构)
  Contango（近便宜、远贵）：卖便宜买贵 → 贴钱
  转为 Back（近贵、远便宜）：卖贵买便宜 → 赚钱
```
**这是主升浪的标志性事件**：现货起飞 → 近月贴着重力飞 → 曲线由 Contango 转 Back → **多头移仓成本由负转正**。

→ 交易含义：**磨底期用远月建底仓**（避开近月被现实供给压制打爆）；**趋势确认后把主力切到近月**（弹性最大），此后每一次向上移仓都在赚月差。
→ 反向信号：现货见顶 → 曲线重回深度 Contango → 此刻持多头即「最差组合」，必须离场。

## 八、政策与储备机制口径（2026-09-30 补 · 防串错来源）

> 背景：本框架上一轮曾引用自媒体口径「商务部 9/29 第三次投放冻肉 1 万吨、累计 3 万吨」与「中央收储仍未官宣」，**经官方来源核验后两处均需修正/降级**。本节把正确口径固化，避免再次串错。

### 8.1 猪粮比价预警区间（2021《完善政府猪肉储备调节机制 做好猪肉市场保供稳价工作预案》）

| 猪粮比价 | 预警等级 | 政策动作 |
|---|---|---|
| **低于 5:1** | **过度下跌一级预警** | **启动临时储备收储** |
| 连续 3 周 5:1–6:1 | 过度下跌二级预警 | 视情启动收储 |
| 低于 6:1 | 过度下跌三级预警 | 暂不启动收储 |
| 6:1–9:1 | 正常 | — |
| 高于 9:1 / 连续 2 周 10:1–12:1 / 高于 12:1 | 上涨三级 / 二级 / 一级 | 视情至启动抛储 |

- **6:1 为盈亏平衡点**（2015 版曾定 5.5:1–5.8:1，引用旧口径即为错）。
- 辅助指标：能繁母猪存栏单月同比降幅 ≥5% 或连续 3 月累计降幅 5%~10% → 二级；单月同比降 ≥10% 或连续 3 月累计降幅 >10% → 一级。

**实测读数（2026-09）**：**9/28 全国 4.31:1**（同花顺，9/29 发布）｜ 9/20–24 周全国 4.93:1（发改委）｜ 浙江 9/14–18 周 4.66:1（省发改委）。→ **已深处一级预警区**（历史收储触发时多在 4.5–5.0，2022-03 最低 4.53）。
> ⚠️ 一级预警在历史上很少长期停留，常被视为**养殖板块反转的参考信号**——但注意：**它是"政策底"信号，不是"价格底"信号**（见 8.2 流拍事实）。

### 8.2 储备肉的真实操作形式：**轮换 ≠ 单边投放**

```
华储网标准动作 = 「出库竞价 + 同步收储」双向轮换
  实测 2026-09：9/12 通知 9/15、9/16 各挂牌轮换出库 15,500 + 12,900 = 28,400 吨
                9/18 收储通知同步收储 15,500 + 12,900 = 28,400 吨
                → 出多少收多少，一吨不差 → 净库存不变
```
**关键纪律**：看到"投放/出库 N 万吨"的标题，**必须先问是不是轮换**。
- 轮换 = 换批次（交储肉须为交易日之后加工、保质期≥18 月、60 日内入库）→ **净库存不变，托市效果≈0，信号意义 > 实际作用**
- 单边投放（保供）= 增加供给 → 利空
- 单边收储（净买入）= 减少供给 → 利多
三者不可混用。**把"轮换出库"读成"抛储压价"或"收储托价"都是错的。**

### 8.3 流拍是重要读数（市场用脚投票）

实测 2026：6 月出库流拍率约 19%（挂牌 19,100 吨）；8 月 900 吨**连续四次流拍**；9/15 未成交 4,000 吨于 9/21 二次竞价、仍未成交的 2,500 吨于 9/28 三次竞价。
→ **流拍率高 = 产业不接受当前价 = 基本面仍偏弱 = 政策"保底价"预期弱**。反过来说，**流拍率下降**才是储备政策开始有效的第一个信号。

### 8.4 地方先行是中央行动的领先指标

实测：**云南省**农业农村厅会同发改委/商务厅/财政厅开展**冻猪肉商业储备收储 1,000 吨**（9/4 公示承储企业：云南神农 700 吨、红塔区供销食品 300 吨；9/14 发布）。
→ 用法：**跟踪"哪个省先动、动了多少吨"**，是判断中央是否跟进的领先指标（省级商业储备 ≠ 中央储备，量级差一个数量级，不可混谈）。

### 8.5 假期跳空清单（为什么 9/30 收盘价在 10/8 不是有效价格）

| 机制 | 说明 |
|---|---|
| **信息密度** | 生猪是**日报价**品种，休市 9 天累积 ≈ 平时 9 个交易日的现货信息量，全部挤到复市首日一次性定价 |
| **持仓已薄** | 实测 9/29 主力 2611 单日减仓 **35,702 手（−18.8%）**，前 20 会员净空收窄至 **9,892 手（近 30 日最浅）** → 薄持仓下边际资金易打出大波动 |
| **季节方向不确定** | 国庆是双节最后一段旺季（宴席/旅游餐饮），但节后即转季节性回落 |
| **政策窗口在假期** | 一级预警 + 地方跟进 → 假期随时可能出公告 |
| **现货生命线** | 三口径全部贴在 **10.0 元/公斤**关口（二育抄底心理价位）。守住=磨底，失守=期现共振向下 |
| **节后出栏挤压** | 10 月有效出栏天数仅 20 余天，节前未出完的猪集中到节后 |

**结论**：不能说"必然向上/向下跳空"，准确表述是——**9/30 的收盘价在 10/8 大概率不是有效价格；节前持仓在假期内无法调整，9 天信息量是平时的 9 倍。**
