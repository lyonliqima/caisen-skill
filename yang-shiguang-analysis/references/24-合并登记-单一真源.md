## 二、A 类：同一工具两个编号 → 实质合并（2 组）

### A1 · M106 → M92（卖权买权比 / Put-Call Ratio 反指读法）

- **证据**：两者是同一指标、同一反指逻辑，**连实测样本都相同**——2026-10-13 台股 P/C 68.95%、10/28 仍 <80%。`examples-1013.md`（M91–M92 首秀）与 `examples-1028.md`（M106 实测）写的是同一段行情。
- 🔺 **更值得记的审计发现**：`examples-1106.md` 第 30 行在 **2026-11-06 就已经写明**「本期没有新增 Put/Call Ratio 工具……与既有 M92 / M106 同源，属同一工具的实务口径延伸，**不另立编号**」。判断正确，但当时只做到「不再新增第三个编号」，**没有回头把已有的两个编号收口**，于是重复正文又留存了 4 天。已在 `examples-1106.md` 追加去重回写段（原文不改）。教训写入第七节规则 6。
- **更严重的是口径冲突**：M92 定义「反指 = 极端读数只否决顺势追空，不给抄底信号」；M106 标题写「反指」，判据却按**同步指标**写（「PCR >90%–110% = 多头讯号 → 通常对应多头行情」「<80% = 法人未翻多」），并在纪律里又写「极高=乐观过头注意反转、极低=悲观但需价格确认」——同一条目里「反指」与「同步」两种用法并存，会被下游读成相反结论。
- **裁决**：以 **M92 为主**（三件套同向极端 + 反指只否决追空的纪律更严谨）。统一口径为：
  - **结构层（同步读）**：PCR 高 = 法人做多并买 put 保险；PCR 低 = 未翻多 / 极度看空。
  - **反指层（操作读）**：极高提示多头拥挤、极低否决追空；**两者都不给「立即反手」的信号**，须价格确认。
  - 禁止把「PCR 低」直接写成「该抄底」，也禁止把「PCR 高」直接写成「该追多」。
- **M106 独有增量已移交 M92**：① 必须**连续观察**（单日无意义）；② `<70% 长期低迷 = 反抽≠反转`；③ 10/13→10/28 持续 <80% 的跟踪实测。
- 文件：`references/21-m105-m110.md` 的 M106 段收口为别名指针；`references/18-m91-m92.md` 增「合并接收」子节。

- **证据**：两者都做「名义长端 = 实际利率 + 通胀补偿 + 期限溢价」拆解，都用 breakeven 判通胀锚，都回答「货币政策压不压得住」。`references/09-m44-m53.md` 的 M44 步骤与 `references/12-m63-m67.md` 的 M63 步骤逐条对应，仅粒度不同。

## 七、防重复新增规则（此后生效）

1. **新增 M 编号前必做三查**：① 按指标名 / 英文缩写 / 别称全库 grep（M92 与 M106 就是「卖权买权比」与「Put/Call Ratio」漏配）；② 查本文件第二、三、六节；③ 查是否只是既有方法的**新对象**——是则登记为应用案例，不开新编号。
2. **同一行情的实测只能进一个方法的正文**，其余方法引用时写「见 MXX 实测」，不复制数据表。
3. **红线只写一次**：立规时写进 `SKILL.md` 表，来源文件只留背景与实测。
4. **口径冲突优先于去重**：发现两个编号对同一指标给出不同判读阈值时，**先裁决口径再合并**（A1 即是），不得把两套阈值并列留着。
5. 历史观点记录（`examples-*.md`）**只追加回验，不新建平行记录、不覆盖原文**。
6. 🔺 **「同源」识别到就要当场收口编号**：写下「不另立编号」只防住了第三个编号，**不等于已有两个编号已合并**（M92 / M106 的实锤）。凡在案例里写出「与既有 MXX / MYY 同源」，同一步必须执行：指定主编号 → 把另一编号改成别名指针 → 迁移独有增量 → 更新方法树。
