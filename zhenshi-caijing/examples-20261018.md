## 🔴 本框架二次思考（4 项遗漏 / 风险，引用前必须补齐）

1. **工业硅冲突（最高优先级）**：用户已持有**工业硅空单（止损 8300、区间 [8300,9300]）**，而「电与算力→光伏」叙事对 SI 是**远水多头**。近月 SI 主矛盾是**产能严重过剩 + 高库存**，光伏需求增量被产能砸穿，2027 前难反转。→ 结论是：**不能用该叙事去平空翻多工业硅**；SI0 现价 8,925 已在区间上沿、高于止损 8300 = 空单当前浮亏，**9,300 上破才挑战空单逻辑**，与该叙事无关。
2. **AI capex 证伪尾部风险**：沪铜「算力溢价」的根基是全球 hyperscaler（微软/谷歌/亚马逊）资本开支持续高增。若任一巨头下修 capex 指引，铜的叙事溢价回吐——这是 CU 多单的**头号证伪情景，比供需更致命**。
3. **第二站时间成本**：报告轮动顺序为 **金→油→电与算力**，"电与算力"是 **2027 起**的扩散，不是当下主线。现在提前布局 AL/CU 要接受**资金占用 + 区间震荡**的时间成本，不是立刻兑现。
4. **中国电价管制削弱"电"表达纯度**：工商业/居民电价非完全市场化，铝的成本传导有折扣（云南水电铝成本低），故沪铝的"电"表达不如海外铝纯；支撑主要来自**煤价 + 产能天花板 + 绿电成本分化**，而非直接电价。

## 观点一（★结构读数支点）：电与算力是实物重估第二站——PPI 分项签名

**用到的方法**：Z13 双叙事拆解 + 结构判定（同一份 PPI，读出「谁是涨价的主角」）
**推导链条**：中国 9 月 PPI +5.0% 整体偏高 → 拆分项里**数据存储设备 +46.7%、计算机 +21.8%** 远超总体 → 这不是需求全面回暖（CPI 仅 +0.9%、核心 +1.0% 证伪普遍性需求通胀）→ 而是**AI 基建拉动的硬件/设备价格重估** → 与「油（能源第一站）→ 电（耗电金属）→ 算力（铜/硬件）」的实物重估扩散顺序咬合 → **PPI 分项里的 +46.7% 就是通胀第二站的签名**。
**框架态度**：🟢 **这是本档案最有价值的一条**——把"电与算力"从宏观叙事降维成可月度复核的 PPI 分项读数。可独立验证：每月盯「计算机通信设备制造业 PPI」「电气机械 PPI」是否维持高增。与 examples-20261017 观点十一至十六（CPI/PPI K 型分化）同源，属真实财经原生触发面。
**后续追踪**：每月 PPI 行业分项（重点：计算机通信设备制造、电气机械及器材制造、有色金属冶炼）；若分项从 +46.7% 回落至 <20%，则"第二站"动能衰减。
**证伪位**：数据存储设备 / 计算机 PPI 同比连续 2 个月回落至 <20%，或全球 hyperscaler 资本开支指引集体下修 → "电与算力第二站"作废。

## 观点二（交易表达·电的载体）：沪铝 = 电的固态形式

**用到的方法**：结构判定（耗电金属 = 电价/电量的实物代理）+ 左侧区间定位
**推导链条**：电解铝吨耗电约 1.35 万度（行业估算）→ 是全球最"电密集"的期货品种 → 电价/电量上涨 → 成本支撑上移；同时铝用于变压器、线缆、新能源车电机（算力基建与能源转型都吃铝）→ 双向受益。技术面：AL0 现价 23,270（2026-10-16），20 日回踩 -4.0% 至区间低位 [23040, 24400]，贴近 23,040 支撑 → **已落入左侧买入区，非追高**。

> **收敛判断（十二专家框架口径，非真实财经原生）**：方向=多；期限=2026Q4–2027Q2（电价传导 + 炼能修复滞后）；幅度=23,270 → 24,400 前高上方（约 +8~10%）；证伪位=AL 有效跌破 22,500（云南水电铝复产放量 + 煤价下行，成本支撑塌）；置信度=70。

**框架态度**：🟢 本框架首选"电"表达——逻辑纯、技术位给左侧机会。
**后续追踪**：电解铝运行产能 / 云南来水与电价政策 / 煤价（焦煤 JM0 现 1,482，20 日 -6.5%，若续跌削弱 AL 成本支撑）/ 铝锭库存。
**证伪位**：AL 周线有效跌破 22,500，且云南复产消息兑现 → 多单逻辑作废。

## 观点三（交易表达·算力的载体）：沪铜 = 算力直接载体，等回踩

**用到的方法**：结构判定（数据中心铜密度）+ 区间等待纪律（不追高）
**推导链条**：一个 AI 数据中心 = 海量铜（电缆、变压器、母线槽）；叠加全球电网投资 + 电动车，铜是"算力通胀"最干净的表达。但技术面：CU0 现价 109,860（2026-10-16）位于 20 日区间 [107030, 111320] **上沿**，未给回踩 → **当前不在买点，等回落至 107,000 附近再扣扳机**。

> **收敛判断（框架口径）**：方向=多；期限=2027 全年（AI capex 持续投放）；幅度=109,000 → 120,000+（供给刚性 + 需求结构性增量）；证伪位=CU 跌破 105,000（hyperscaler capex 下修 或 铜矿新产能集中释放）；置信度=72。

**框架态度**：🟢 逻辑最纯的"算力"表达；🔵 **但纪律上必须等回踩**——现在 109,860 追入等于买溢价，违背"越跌越买左侧"原则。
**后续追踪**：LME + 沪铜库存、全球铜矿 capex 指引、Microsoft/Google/Amazon 季度 capex 表述。
**证伪位**：CU 周线跌破 105,000，或头部云厂 capex 指引下修 → 多单逻辑作废。

## 观点四（风险标注·慎碰与冲突）：锂/硅过剩 + 工业硅持仓冲突

**用到的方法**：结构判定（主矛盾识别）+ 持仓冲突显影
**推导链条**：① 碳酸锂 LC0 20 日 **-28.6%** 砸至区间下限 96,320——"数据中心备电 + 电网储能"逻辑对，但**主矛盾是锂过剩未出清**，跌幅是价值陷阱风险，只宜小仓左侧、等矿端减产/库存拐头信号；② 多晶硅 PS0 -6.0%、工业硅 SI0 +3.7% 均处光伏链过剩格局；③ **工业硅与用户空单反向**：用户已空 SI（止损 8300、区间 [8300,9300]），"电与算力"叙事是 SI 远水多头，近月救不了 → 明确**不建议因该叙事平空翻多 SI**。

**框架态度**：🔴 **锂/硅非本 thesis 的优先表达**；⚠️ 工业硅持仓冲突必须显式标注（见二次思考第 1 条）：SI0 8,925 高于止损 8300 = 空单浮亏，**9,300 上破才挑战空单**，与该叙事无关。
**后续追踪**：锂盐库存拐点 / 多晶硅组件排产 / 工业硅 9,300 关口（空单警戒线）。
**证伪位**：工业硅周线有效突破 9,300 → 用户空单逻辑受挑战（需独立重新评估，非本叙事驱动）。
