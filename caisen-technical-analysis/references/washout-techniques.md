# 主力洗盘手法识别（4 类）

> **定位**：本文是「主力行为识别」的专题补充，配合主方法论的 **M3 量价验证法**、**M6 破底翻/假突破策略**、**外资养套杀三步法** 与 **第六步资金流动分析** 一起使用。
> 洗盘（washout / shakeout）的本质是：**主力在拉升前用短期痛苦击穿散户心理防线，低成本清洗浮筹，为后续主升浪减少抛压**。它发生在「养」阶段，与「出货/杀」在量价结构上有本质区别。
>
> **内容来源标注**：
> - 第一类、第二类、第三类「核心操作手法 + 关键识别信号 + 散户应对策略」= **会议原文**。
> - 第三类「补充识别参考 / 补充应对参考」、第四类「联合利空洗盘核心逻辑」= **非会议原文，基于通用技术逻辑补充**（原文会议仅提及类型、未展开）。
> - 文末「实战识别 Checklist」「与蔡森方法论联动」= 整合梳理，便于落地。

## 四类洗盘手法对照表

| 类型 | 针对人群（心理弱点） | 手法特征 | 量能结构 | 时间跨度 | 关键识别锚点 |
|------|----------------------|----------|----------|----------|--------------|
| 一、暴力深砸 + 快速回拉 | 死扛亏损、不肯割肉的散户 | 大额卖单砸盘，暴跌 15%~20%，大阴/跌停/跳空 | **跌时放量（恐慌盘涌出）→ 收回缩量（筹码稳定）** | 砸盘后 **1~3 天** 快速收回 | 不破 20 日线/前期平台低点；3 天内收复全部跌幅 |
| 二、长期横盘震荡 | 有耐心但定力不足、爱追热点的散户 | 5%~10% 窄幅反复震荡，涨就压、跌就托 | 成交持续低迷、逐步萎缩 | **1~3 个月** | 区间收窄、量萎缩；低点抬高、高点上移；不破关键均线 |
| 三、诱空破位假摔 | 懂技术、严格按均线/支撑位止损的散户 | 刻意砸破公认支撑位，收破位大阴，1~2 天拉回 | 破位当日放量（止损盘）≠主力出逃；收回放量（主动承接） | 假破位后 **1~2 天** 收回 | 破位前处上升/低位震荡、无实质利空；快速收回支撑 |
| 四、联合利空洗盘 | 信息驱动、看消息面反应的散户 | 借业绩预减/减持/问询等利空公告 + 股价打压 | 利空落地后不跌反涨；非基本面真恶化 | 随消息面节奏 | 「利空出尽反涨」；消息多为配合工具 |

## 一、暴力深砸 + 快速回拉（暴力洗盘）

**针对人群**：死扛亏损、不肯轻易割肉的散户。
这是所有洗盘手段中最直接、冲击力最强的一种。

### 核心操作手法（会议原文）
主力放弃常规的小幅震荡洗盘，直接用大额卖单砸盘，拉出大阴线、跳空大跌甚至跌停，让股价在短时间内暴跌 15%~20%，制造「主力出逃、股价崩盘」的极端恐慌氛围。
砸盘完成后，主力会在 1~3 天内快速拉升股价，K 线收出长下影线或放量阳线，让股价回到暴跌前的位置，完成一次「深 V 收割」。
其本质是用短期大幅账面亏损击穿散户心理防线，让散户误以为股票基本面恶化、主力跑路，在恐慌中割肉，主力则低价承接筹码后迅速拉回。

### 关键识别信号（会议原文）
- **量能特征**：下跌时放量（恐慌盘集中涌出），股价收回时缩量（场内筹码稳定，主力未离场）。
- **价格特征**：大跌不会有效跌破 20 日线、前期平台低点等关键支撑位，且 3 天内快速收复全部跌幅，走势干脆不拖沓。

### 散户应对策略（会议原文）
暴跌时不盲目割肉，若股价缩量企稳可继续持有；当股价重新收回关键支撑位时可加仓。只要未有效跌破支撑、未出现持续放量出逃，就坚定持仓，不被恐慌情绪带动。

### 与形态学联动
- 对应 **M6 破底翻 / 二度破底翻净化法**：暴跌后快速收回、3 日站稳 = 破底翻确认，是「假摔」而非真破位。
- 暴跌收长下影线 = 单针探底 / V 底雏形，需结合 **M13 V型反转等级鉴定**（个股 V 转可信度高于指数）。

## 二、长期横盘震荡（磨人洗盘）

**针对人群**：有一定耐心但定力不足、热衷追热点赚快钱的散户。
这是最考验心态、最消磨意志的洗盘方式。

### 核心操作手法（会议原文）
主力主动暂停拉升动作，让股价在 5%~10% 的狭窄区间内反复震荡：股价小幅上涨就砸盘压价，小幅下跌就托底拉升，每日波动幅度极小，成交量持续低迷，整个横盘周期可达 1~3 个月。
核心逻辑是「用时间换空间」：利用散户普遍想赚快钱的心理，让持有者眼睁睁看着其他板块、个股上涨，自己的持仓却长期不动，最终心态失衡，割肉离场去追热点，主力借此完成筹码清洗。

### 关键识别信号（会议原文）
- 横盘区间逐步收窄，成交量持续萎缩，说明场内筹码锁定性不断提升。
- 震荡过程中低点逐步抬高、高点稳步上移，中长期上涨趋势并未被破坏。
- 横盘期间不会出现放量大阴线，股价始终站稳关键均线。

### 散户应对策略（会议原文）
横盘阶段不轻易割肉，耐心持有，不盲目切换到热点个股。只要趋势未走坏、未出现放量破位，就坚定持仓，对应市场中「横有多长，竖有多高」的规律。

### 与形态学联动
- 对应 **矩形整理 / 水底型底部识别法**：长期底部横盘 = 水底型，破底翻信号更强。
- 横盘不破关键均线 + 区间收窄 = 三角收敛 / 矩形整理中继形态，突破方向跟随原趋势（**多为向上**，因处于上升趋势中）。

## 三、诱空破位假摔（诱空洗盘）

**针对人群**：懂基础技术分析、严格按均线/支撑位执行止损的散户。
这是最狡猾、迷惑性最强的洗盘方式。

### 核心操作手法（会议原文）
主力刻意砸破市场公认的关键技术支撑位，比如 20 日线、平台整理下沿、前期低点，K 线收出破位大阴线，从技术形态上看完全符合「趋势反转、即将开启大跌」的特征。
但在砸破支撑后的 1~2 天内，主力会迅速把股价拉回支撑位之上，收出放量阳线，形成典型的「假破位、真诱空」走势，让按技术位止损的散户卖在最低点。

### 补充识别参考（非会议原文，基于通用技术逻辑）
- 破位当日放量，但多为止损盘集中涌出，并非主力资金持续出逃。
- 破位后股价不持续下探，能快速收回支撑位，且收回过程伴随放量，代表资金主动承接。
- 破位前个股处于上升趋势或低位震荡阶段，基本面无实质性重大利空。

### 补充应对参考（非会议原文，基于通用技术逻辑）
不要机械执行止损，可预留 2~3 天的观察期：若股价快速收回支撑位，确认是假摔，可继续持有甚至加仓；若连续 3 天站不回支撑位、且成交量持续放大出逃，再考虑离场。

### 与形态学联动
- 对应 **M6 假突破策略法**（反向应用：假跌破 = 诱空）。
- 破位大阴 + 跳空缺口：用 **缺口存亡确认法** 验证——跌破型跳空若 1~2 日回补 = 诱空；不补且持续下探 = 真破位。
- 破位当日放量但收回缩量/收回放量 = 与 **M3 量价验证** 一致（缩量跌破可信度低，放量收回=主动承接）。

## 四、联合利空洗盘

> 说明：本次会议记录中仅提及该洗盘类型，未展开具体讲解。以下核心逻辑为结合 A 股市场常见操作补充。

### 核心逻辑（补充）
这类洗盘是主力与消息面配合的打法：主力会联合上市公司、或借助市场突发利空，发布业绩预减、股东减持、监管问询等利空公告，在消息面制造恐慌，同时配合股价打压，双重打击散户持股信心，逼迫散户割肉。

### 典型特征（补充）
- 「利空落地后股价不跌反涨」，所谓的利空更多是配合洗盘的工具，并非公司基本面真正恶化。
- 利空公告后若放量下跌但很快收回、且基本面无实质恶化，多为洗盘；若利空伴随持续放量出逃、跌破关键支撑且站不回，需警惕是真利空。

### 与形态学联动
- 对应 **利空利多反作法**：利空出尽做多、利多出尽看空。洗盘型利空 = 「利空出尽」买点。
- 判定真假利空必须回归 **M3 量价验证 + 关键支撑位 + 资金流背离**，不可单看消息面。

## 实战识别 Checklist（快速判定：洗盘 vs 真破位 / 出货）

> 用以下 5 条逐条核对。命中越多「洗盘」特征，越应坚定持仓；命中越多「出货」特征，越应离场。

| 维度 | 洗盘（持有/加仓） | 真破位 / 出货（减仓/离场） |
|------|-------------------|----------------------------|
| **关键支撑位** | 不破 20 日线 / 前期平台低点；或破位后 1~3 天快速收回 | 有效跌破且连续 3 天站不回 |
| **量能结构** | 跌时放量（恐慌/止损盘）、收回缩量或放量（主动承接） | 下跌缩量说明无人接、或持续放量出逃不止 |
| **时间维度** | 深砸 1~3 天收回；横盘 1~3 月收窄；诱空 1~2 天收回 | 破位后持续下探、阴跌不止 |
| **消息面** | 利空落地后不跌反涨、无实质基本面恶化 | 利空伴随业绩/基本面真实恶化、持续发酵 |
| **资金流背离** | 大户/外资低位承接（买）、散户恐慌抛（卖）= 筹码转移筑底 | 大户卖出 + 散户买入 = 「套/杀」阶段（见第六步框架） |

**一句话记忆**：洗盘 = 吓你但不伤你（支撑守住、量价反常、快速收回）；出货 = 真跑（支撑破、量能持续放大出逃、资金流大户卖散户买）。

## 与蔡森方法论联动索引

- **M3 量价验证法**：洗盘的量能「跌放收回缩 / 收回放量」是确认假破位的核心依据；真跌破不依赖量、但持续放量出逃是出货信号。
- **M6 破底翻 / 假突破策略**：暴力深砸后快速收回 = 破底翻；诱空破位后拉回 = 假跌破（诱空买点）。
- **外资养套杀三步法**：洗盘发生在「养」阶段（拉现货吸筹）；若同时出现「现货买、期货空单大增」需警惕升级为「套/杀」。
- **利空利多反作法**：联合利空洗盘 = 「利空出尽做多」的实战场景。
- **第六步 散户与大户资金流动分析**（强制）：洗盘判定必须叠加资金流背离检测——大户买 + 散户卖 = 真洗盘筑底；大户卖 + 散户买 = 假洗盘真出货。
- **缺口存亡确认法**：跳空跌破型洗盘，1~2 日缺口回补即诱空确认。
- **整理盘预警法 / 水底型底部**：长期横盘震荡的识别与「横有多长竖有多高」的幅度预期。
