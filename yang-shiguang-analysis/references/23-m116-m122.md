## M116 同一价格变动的短/中/长三尺度符号分层法（政治油 / 金融油）

**用途**：当一个价格变动同时被拿来支持「短期利多」和「长期利空」时，避免两个尺度互相污染。本期标题「政治油的下跌所带来的股市利多 / 金融油的下跌所带来的长空趋势」就是标准的三尺度问题。

**定义（先拆词，不混用）**：
- **政治油（实体现货 / 物流属性）**：受断供、航道、战事、制裁、库存支配；观测现货升水、区域价差、运费、AIS 通行量。
- **金融油（交易所期货 / 预期属性）**：受需求预期、实际利率、金融条件、持仓支配；观测近月合约、远期曲线、管理基金净多。
- 二者**是否同创新高**是区制判别第一刀（接 M86 期现货价差裁决法）。

**步骤**：
1. 锁定一个价格变动 ΔP，标明品种、口径（现货/期货）、起止日。
2. 拆三个尺度：**事件窗（数日至数周）／季度（货币政策与库存周期）／多年（产能与需求结构）**。
3. 每个尺度**单独指定**传导链与主导变量，单独给方向符号；禁止一条证据链通吃三个尺度。
4. 逐尺度给**独立证伪位**与失效价，任一尺度被证伪不影响其他尺度。
5. 输出三行结论（短 / 中 / 长），而不是一句「看多还是看空」。

**红线**：
- 🔺 禁止把长尺度警讯直接当短尺度交易信号；也禁止用短尺度反弹去否定长尺度结构。
- 🔺 同一条数据不得同时用于支撑两个尺度上相反的结论（R9 的尺度版）。
- 🔺 「政治油 ≫ 金融油」必须由现货/期货价差 + 曲线形态 + 库存三器佐证（M86），不能只凭「现货创高」一句话。

**实测（2026-11-10）**：节目观察到现货原油创高而纽约原油期货未过 2022/3 高点 → 判「实体冲击 > 金融定价、问题在需求端」，方向成立。但把「油价跌」直接跨到「长期通缩 / 大周期结束」时缺中间变量（R20）：WTI 10/30 **102.95** → 11/10 **84.76**（−17.7%）的直接触发是 11/9–10 美伊就 **3.67% 铀浓缩上限**形成初步框架 + 霍尔木兹复航预期，属**事件驱动的溢价回吐**。三尺度正确写法：短期（和谈溢价回吐 → 成本与通胀预期改善，利多股市）／中期（OPEC+ 与 SPR 补库托底，区间）／长期（需求结构待验证，不给结论）。

## M117 事件冲击边际弹性衰减法（利多不涨的峰值序列版）

**用途**：判断「每一条利多都兑现了，但价格高点一次比一次低」到底是不是需求承接不足。

**与既有工具的分工**：M15 只**计数**事件、M96 判长端单次/第二次背离、`21-思考链路-利多不涨反向读心法` 是七步思考链；本工具专攻**峰值序列的斜率**与**单位事件弹性**。

**步骤**：
1. 建事件日历：每个事件标日期、类型（战事/制裁/航道/谈判）、**强度等级**（可观测：受影响桶数、封锁天数、通行量降幅）。
2. 对齐每个事件后的价格峰值，取**峰值序列** P₁…Pₙ（用收盘价，同 M96）。
3. 检验两件事：峰值是否**单调递减**，同时事件强度是否**未下降**。两者同时成立才叫「钝化」。
4. 算单位事件弹性 εₙ ＝ ΔPₙ / 事件计数ₙ（或 ΔPₙ / 强度分），看 ε 是否衰减。
5. **强制做事件强度归一化**：若同期出现和谈启动 / 停火 / 复航 / 制裁松动，事件强度本身在下降，则峰值递减属**溢价回吐**，不得归因于需求塌陷。
6. 补三器证据：库存 / 远期曲线（近月−远月）/ 持仓净多，才能把「钝化」升级为「需求端问题」。
7. 结论边界：只判**边际买盘衰竭**，不判绝对方向、不判崩盘时点。

**红线**：
- 🔺 禁止跳过第 5 步。本期节目把 259 天的峰值递减全部归给「需求端问题」，但 11/3 中期选举后美伊和谈重启、伊朗七条开出、沙特油轮在美军情报保护下准备通行霍尔木兹——**事件强度在系统性下降**。
- 🔺 禁止把「利多出尽」当看空入场点（同 M92/M112：只否决追多，不构成做空）。

**实测**：3/9 WTI 盘中 **119.48** 为年内高点，此后高点递减；10/30 102.95 → 11/10 84.76。同期霍尔木兹通行量仍仅战前约 **75%**、美国 SPR 为 1982 年以来最低、IEA 预计 2026 需求同比 **−110 万桶/日**、10 月已现供应过剩 → **需求侧确有裂痕，但不足以解释 11 月这一段斜率**；主因是事件溢价回吐。WTI 持仓 7 天减少 28%。

## M118 跨资产见顶序列计时法（掩护链 → 信用事件窗口）

**用途**：用不同资产**见顶的时间次序**推断风险传导走到哪一段，给「观察窗口」而不是「必然崩盘日」。

**步骤**：
1. 列全资产见顶日与见顶价（股 / 房 / 金 / 白银 / 农产 / 能化 / 工业金属 / 信用利差），按时间排序。
2. 找**最后一个见顶的品种**，算它与后续信用事件（违约/破产/救助）的时滞。
3. 判每一棒的性质：是「拉 A 缓解 B 的风险」还是「拉 A 掩护 B 撤退」——**只记录价格次序，动机一律不写**（R10）。
4. 把当期序列逐项对齐：每个品种现在处在自己历史区间的什么位置（**必须同比 + 环比双口径**）。
5. 只有当**多数品种已确认见顶且回落**时才把序列判为「走完」；否则只给「第 N 棒」。
6. 输出：当前第几棒、剩余观察窗口、窗口内的可观测触发条件。

**红线**：
- 🔺 历史 analog 必须附**宏观前提差异清单**（利率环境 / 央行反应函数 / 杠杆结构 / 是否有政策托底），差异足以推翻则降级为参考情景（沿用 lukou-daye M 组硬规则 3）。
- 🔺 禁止裸用「末位见顶 → N 个月后雷曼」做定时；2008 是一次样本，不是分布。
- 🔺 环比回落 ≠ 见顶；必须给同比与历史分位。

**实测（本期关键反证）**：节目以 2008 序列（房 2006Q3 → 股 2007/10 → 金 2008/3/7 破 1000 → 黄豆 2008/7/3 1636 → 油 2008/7/11 147 → 雷曼 9/15）暗示大宗转弱后的信用事件窗口。核验：**RJ/CRB 9/9 高点 423.11、10/28 最后逃命点属实**，但 11/5 环比 −3.6% 同时**同比 +32.7%**；南华商品环比 −1.2% / 同比 **+14.8%**；铜 **13,888.5** 美元仍靠近 9/10 历史高点 14,875 → **序列未走完，是高位分化不是周期终结**。

## M119 滞胀主导生产要素迁移识别法

**用途**：判「这一轮滞胀的关键生产要素是什么」，防止把上一轮（1970s 原油 + 小麦玉米黄豆）的品类直接套到这一轮。

**步骤**：
1. 先算**篮子权重与贡献 pp**：CPI/PPI 各分项的 权重 × 同比 ＝ 贡献 pp（接 M94），找出 >40% 的易变主导项。
2. 算该要素在**工业生产成本 / 居民生活成本**里的占比（节目自称「交通燃料占比已经很低」但**没给数**——必须补数）。
3. 判「无效价格上涨」：价格涨了，是否带来**额外生产力**？无额外产出 ＝ 滞胀特征（节目称 token 疯狂投资但未提供额外生产力）。
4. 与历史滞胀期做**要素清单对照**，列差异，不套品类。
5. 做排除法：若当期能源贡献仍 >40%，则「主导要素已迁移」不成立，新要素降级为**待验证假说**。
6. 输出：主导要素 + 贡献 pp + 可观测价格序列 + 证伪位。

**红线**：
- 🔺 新生产要素必须给**可观测的价格/成本序列与权重**，否则只是叙事（R11 定性必须量化）。
- 🔺 禁止用「未来成本会上升」否定已实现的价格事实（R2）。
- 🔺 只做归因，不做估值与方向（同 M97）。

**实测（本期证伪）**：节目判「2026–27 油价大跌后通胀仍不会显著下滑，因为这一波滞胀来自 token」。核验：**中国 10 月 PPI 同比 +5.7%，能源九行业拉动 6.14pct** → 当前通胀边际推力仍主要在能源；节目未提供 token 价格序列、成本占比、贡献 pp 三项中的任何一项 → **判为待验证假说，不进结论支点**。方法（先找当期主导要素再谈滞胀）可复用，结论不继承。

## M120 金油比区制与螺旋校验法

**用途**：把「金油比很高 ＝ 大周期结束」这种直觉拆成可核验的区制判断。基础定义见 `analysis-framework.md`（比值高 ＝ 避险/衰退担忧，历史均值约 15–25 倍），本工具补**读数纪律与螺旋检验**。

**步骤**：
1. 算当前比值：金价 ÷ 油价（同币种、同口径、标日期；现货对现货或期货对期货，禁混）。
2. **排历史极值必须三件同报**：历史峰值及其日期 / 次高值及其日期 / **当前值与偏移幅度**。禁止用年初或历史峰值冒充现值。
3. 拆驱动源：比值上行来自分子（金）还是分母（油）？分别给两者同期涨跌幅。
4. **螺旋假设必须做同期协动检验**：找油显著下跌的窗口，看金是否同跌。金反涨或走平 → 螺旋不成立。
5. 金的锚回到 **实际利率 + 央行购金 + 美元**（M11 / M18 / lukou-daye L15），不得由油价单独推出。
6. 区制判读：比值高位 + 金油同跌 ＝ 通缩/去杠杆；比值高位 + 油跌金涨 ＝ 避险与信用裂痕。**两种 regime 结论相反**。

**红线（对应 R18）**：
- 🔺 引用比值/历史极值必须同时给「峰值日期 + 当前值 + 偏移」；把年初极值当现值推演 ＝ 时间锚错误。
- 🔺 禁止未经协动检验就写「螺旋」二字。

**实测（本期最直接的反面教材）**：节目称金油比 72 倍、并推「油跌金也跌的螺旋」。核验：72.1 是 **2020/4 峰值**，2026/1 **71.2**、2 月 **70.6** 为历史第二高；**2026-11-10 现值 4136.20 / 84.76 ≈ 48.8 倍**。且 10/30→11/10 WTI −17.7% 而 COMEX 金 3884.9→4085.7 **+5.2%**（11/9 盘中 4157.7）→ **螺旋被同期数据直接证伪**。Q3 全球央行净购金 **321 吨 / 同比 +42%**，与实际利率共同定价黄金，与油价无稳定传导链。

## M121 产业链权益价格反推实物预期法

**用途**：用对物流/运价最敏感的**权益价格**，反推实物端风险溢价的消退方向，作为商品与航运的领先观察。

**步骤**：
1. 选标的：对目标物流变量弹性最高的权益（油轮、干散货、港口、管道），列 2–4 家做横切面。
2. **拆股价变动来源**：运价/租金预期 vs 大盘 beta vs 公司特有事件（增发、财报、指数调整）。只有扣掉后仍显著的那一块才是信号。
3. 与实物三器交叉：即期租金 / AIS 通行量（M16）/ 现货升水与远期曲线（M86）。
4. 估权益领先商品风险溢价的时滞，用公告日 / 复航日 / 运价转折点对齐。
5. 输出只判**溢价消退方向 + 观察窗**，不判商品绝对价位。

**红线**：
- 🔺 必须扣大盘 beta。本期 11/9 美股三大指数 **+2.15% / +2.35% / +2.74%**、11/10 台股 **+2.5% 收 42,711.92**，**普涨背景下油轮股逆势跌才构成信号**；节目未扣。
- 🔺 权益是对**预期**定价，预期可被证伪；不可当成实物已恢复的证据。

**实测**：节目提到招商轮船、中远海能等油轮商股价大跌、快破线，同期沙特油轮在美军情报系统保护下准备通行霍尔木兹 → 方向（战争溢价消退）成立，可作复航预期侧证；但**通行量仍仅战前约 75%**，实物未恢复。

## M122 选举结果 → 财政立场迁移判读法

**用途**：把「多国选举后财政要收紧」从印象转成可观测刻度的传导链，补 M89（资产通胀 → 保守派失票）与 lukou-daye L59（财政日历 → 供给传导）之间缺失的**中间环节**。

**步骤**：
1. 列选举结果与席位变化（只记**可核的席位/法案**），不评人物。
2. 找**财政立场的可观测代理**：预算案表决、支出上限条款、赤字率目标、债务上限时点、国债发行计划（refunding）。
3. 判方向：扩张 / 中性 / 撙节；须**至少一个已落地的法案或表决**，不能只凭竞选发言。
4. 与**货币立场**并列成 2×2（货币紧/松 × 财政紧/松），四种组合对股/债/商品的映射不同；禁止只讲「双紧缩」。
5. 给生效日与观测窗（接 M114：宣布 ≠ 生效）。
6. 输出：组合象限 + 生效日 + 失效条件。

**红线**：
- 🔺 **政治叙事、宗教/文化解读、人物褒贬一律不继承**（沿用 lukou-daye M 组硬规则 2）。本期大量关于信仰与选举的解读整段剔除，只留「席位变化 → 财政表态」链条。
- 🔺 禁止把「某党某人说了要撙节」写成「全球财政已进入紧缩周期」；须给出跨国的可核法案数与时间表。
- 🔺 双紧缩对短期股市**也可能是利多**（通胀预期与长端利率回落），不可单向解读（接 M116 三尺度）。

**实测**：节目以美国 11/3 中期选举（共和党丢参众两院，参院 **54:44**）、巴西/塞尔维亚/保加利亚/法国预算表态，推出「货币收缩 + 财政收缩」双周期。可核部分：Fed 10/28 以 **10:2 维持 3.75%–4.00%**、两票主张加息；11/9 3Y 标售得标 4.627%。**不可核部分**：跨国财政撙节已落地 → 标「待验证」。
