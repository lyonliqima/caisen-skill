> **来源**：杨世光《金简报》2026-10-07 期录音整理稿（ASR 二次转写）。原文核验见 `base-logic/公用事业见顶信号与海耶克资本财争夺-核验观点.md`。
> **性质**：这是**研究方法**，不是观点集合。节目里的方向性判断（美股见顶、黄金跌破 4000、押注反转）是历史时点的例子，**不可**当当前结论复用。

> **与 M63–M67 的分工**：M63–M67 解决「**长端利率为什么动、动到什么程度**」（利率本体）；M75–M78 解决「**实物与信用端状态**」。
> **顺序**：先跑 M63 定利率归因，再跑 M75–M78 定实物与信用端状态，**不可颠倒**。

## M75：防御板块相对强度的驱动源裁决法

> 当一个**防御性 / 类债板块**（公用事业、必需消费、REITs、电信）相对强度异动时，
> **不要立刻按「避险」解读**。同一个价格信号，在不同驱动源下**含义可以完全反转**。
> 正确动作是**先裁决驱动源**（避险流 / 利率敏感流 / 结构性成长流），再决定它是不是信号。

### 核心原理

```
防御板块相对强度↑ 的三种驱动源（必须裁决，不可默认）：

① 避险流（原机制）        → 利率预期下行 / 风险偏好收缩
   判据：同期限长端利率【下行】，且高贝塔板块同步走弱
   → 原有含义成立：大盘风险上升（公用事业＝最类债板块，领先利率预期）
   → 2014 Charles H. Dow Award（Bilello & Gayed）机制原文：
     「利率下行 → 对公用事业是正面的、对整体市场是负面的；
       利率上行 → 对公用事业是负面的、对整体市场是正面的」

② 利率敏感流（反面机制）   → 股息替代效应 / 久期跷跷板
   判据：长端利率【下行】，但属「降息交易」而非「避险」
   → 与①区分：①伴随信用利差走阔，②伴随信用利差收敛

③ 结构性成长流（新机制）   → 板块已不再「防御」，被纳入成长叙事
   判据：同期限长端利率【上行】，且板块与高贝塔科技同步上涨
   → 原信号【作废】——该板块已不是「类债资产」
```

### 四条判据（决定结论怎么写）

```
① 利率方向判据（第一顺位，不可省）：
   取异动期间同期限长端利率方向（10Y / 30Y）
   → 利率同向上行 = 结构性成长流 → 原「避险」信号作废
   → 利率反向下行 = 避险流或利率敏感流 → 进入 ②

② 信用利差判据（区分避险流 vs 利率敏感流）：
   → 信用利差走阔（HY OAS ↑）= 避险流（原机制成立）
   → 信用利差收敛             = 利率敏感流（是降息交易，不是风险信号）

③ 属性漂移判据（板块还是不是「防御板块」）：
   查该板块的收入驱动是否已从「稳定现金流」转向「结构性资本开支需求」
   → 若已转向（例：公用事业由电价管制现金流 → AI 数据中心电力需求）
   → 该板块已不能作为避险代理 → 信号永久失效，须替换代理变量

④ 首日不确认纪律：单日板块涨幅居首不构成确认，须连续 ≥5 个交易日相对强度站在首位
```

### 标准分析步骤

```
□ 第一步：锁定异动的板块与代理变量（板块指数 / 等权 ETF，写明口径与日期）
□ 第二步：取异动期间同期限长端利率方向 → 走 判据①
□ 第三步：取同期信用利差（HY OAS / IG OAS）方向 → 走 判据②
□ 第四步：查该板块的收入驱动是否已结构性漂移 → 走 判据③
□ 第五步：输出——「信号有效（驱动源=避险流）」或「信号作废（驱动源=XX流）」，
          并给出替换后的代理变量与证伪位
```

### 实战案例（2026-10-07 核验：一次「按原机制应作废」的误用）

**被核验的说法**：某节目称「昨天美股涨幅最大的是公用事业 → 公用事业股大涨是大盘动荡的领先指标 → 美股即将见顶」（并引用 2014 Dow Award 论文作依据）。

| 判据 | 读数 | 指向 |
|---|---|---|
| 异动事实 | 10/6 标普十一大板块**十涨一跌**，公用事业 **+3.01%** 领涨 | 事实成立 |
| ① 长端利率方向 | 10Y 约 **5.277%**，处高位且本轮在上行（30Y 约 5.27–5.30%） | ❌ **不是避险流** |
| ① 同向板块 | 公用事业上涨同日，AI 相关（Marvell +5.8%、AMD +2.8%）**同向上涨** | ❌ 结构性成长流特征 |
| ③ 属性漂移 | 驱动源为 **Alphabet 与星座能源 20 年电力协议（890MW 新增核电、逾 $43 亿）**，CEG 单日 **+12.3%~14.9%** | ❌ **板块已由「类债」转为「AI 电力成长」** |
| ② 信用利差 | 高收益债 OAS 仍在低位（09-17 归档口径） | 非避险环境 |

**裁决**：**该信号当期作废。** 原论文机制的**前提是「公用事业强势来自利率预期下行」**，而实测为**利率上行 + 驱动源为 AI 电力需求**，两项前提同时被破坏。
⚠️ **反讽点**：按原论文机制，利率上行本应**利好**整体股市——与节目的「见顶」结论**方向相反**。

**引用纪律**：凡写「防御板块领涨 = 见顶信号 / 风险上升」，**必须先跑判据①**；利率同向上行时**禁止**沿用该信号，改用 M76 的资源争夺链解释。

## M76：资本财—消费财资源争夺链

> 把「通胀」从**货币现象**改写为**资源在两类生产之间的再分配**。
> 资本的用途只有两类：**资本财**（设备 / 厂房 / 电力 / 算力）与**消费财**（商品 / 服务）。
> 二者争夺同一组**生产资源**：工人、土地、资本。谁的价格走高，资源就流向谁。
> —— 海耶克 1931《The 'Paradox' of Saving》的周期机制，本模块为其**可观测化执行版**。

### 核心原理

```
两条相反的分支（起点不同，终点不同）：

【分支 A：消费需求走高 → 衰退】
  消费财价格↑ → 厂商把资源转向消费财 → 资本财生产不足
  → 投资不足 → 失业 → 衰退

【分支 B：资本需求走高 → 过热 → 资本财循环中断（当前适用的分支）】
  信用扩张 / 干预 → 资本财需求↑ → 资本财价格↑（电力·晶片·记忆体·核电）
  → 抢占工人·土地·资本 → 排挤消费财生产
  → 消费财供给不足 → 物价走高 → 「强迫储蓄」（不是爱存钱，是买不起）
  → 消费物价持续走高 → 央行被迫升息
  → 生产资源转回消费财（建店约半年 vs 建晶圆厂约三年半，回收期差 ≈7 倍）
  → 资本财投入循环中断 → 萧条

关键：萧条的发起点不是「需求不足」，而是「资源错配 + 回收周期错配」。
```

### 四条判据（可观测化，缺一不可）

```
① 资本财端价格判据：电力 / 晶片 / 记忆体 / 核电等资本财价格或订单是否在上行
   → 判据：相关标的与合约价格近 3 个月趋势

② 要素争夺判据：服务业是否出现用工短缺 / 工资上行（资源被抽走的直接证据）
   → 判据：服务业时薪同比、住宿餐饮职位空缺率、企业招工难度调查
   → ⚠️ 本判据是链条的【中枢】——没有要素争夺，链条不成立

③ 传导判据：消费物价（尤其【服务】分项，非商品、非 PPI）是否持续走高
   → 必须用服务 CPI / 核心服务，不能用 PPI（PPI 更多反映资本财）
   → 这是「海耶克预言是否成真」的唯一可观测出口

④ 反馈判据：长端利率是否同向走高（央行被迫升息）
   → 若服务 CPI 上行但长端利率下行 → 说明是实际利率下行驱动 → 链条证伪
```

### 标准分析步骤

```
□ 第一步：判分支——当前是消费需求主导（A）还是资本需求主导（B）
□ 第二步：跑 ①—④ 四条判据，逐条给出读数（不可跳过②）
□ 第三步：把链条写成「资本财价格 → 用工 → 服务 CPI → 长端利率」四段，标注时滞
□ 第四步：与 M57（增量拐点）交叉——核心是【融资需求增量】是否还在扩张
□ 第五步：输出——链条处于哪一段 + 下一段触发条件 + 证伪位
```

### 与既有模块的分工（正交互补，不可互相替代）

| 模块 | 视角 | 本模块的关系 |
|---|---|---|
| **M32** AI 产业链债务传导链 | **债务 / 信评**（CDS、承诺链断裂） | 本模块看**实物要素**（电力、用工、物价）——同一引擎的两个侧面 |

### 实战案例（2026-10-07 核验）

| 判据 | 读数 | 指向 |
|---|---|---|
| ① 资本财端价格 | 10/6 **CEG +12.3%~14.9%**（Alphabet 890MW 核电协议、逾 $43 亿）；AI 硬件（Marvell +5.8%、AMD +2.8%）走强；台股 10/7 被动元件、光通讯族群涨停 | ✅ 资本财端在上行 |
| ② 要素争夺 | 节目自述「台湾餐厅都缺人」（**属自述，未获一手源**）；美国服务业工资未取到当期一手数据 | ⚠️ **未验证 → 链条中枢缺失** |
| ③ 传导（服务 CPI） | 当期未取到服务 CPI 一手读数；09-17 归档口径显示官方**核心 PCE 被上调至 3.4%、17/18 位官员看上行风险** | ⚠️ 方向一致，须补当期读数 |
| ④ 反馈（长端利率） | 10Y **5.277%**、30Y 约 5.27–5.30%（09-15 曾创 2007 年以来新高） | ✅ 长端高位 |
| 分支判定 | 资本财需求主导（AI capex 扩张） | 适用**分支 B** |
| 交叉 M57 | 09-17 归档：**「AI capex 增速见顶」未获证据支持，反向证据占优**（2027 发债预计再增约 40%） | ✅ 链条前半段仍在进行、**后半段（中断）尚未启动** |

**结论**：**链条处于第 1–2 段（资本财价格上行 + 长端高位），第 3–4 段（要素争夺 → 服务 CPI → 被迫升息 → 循环中断）证据不足。**
**证伪位**：① AI capex 增速回落且服务 CPI 同步回落 → 链条断；② 服务 CPI 上行但长端利率下行（实际利率下行）→ 链条证伪。
**可交易落点（窄结论）**：不是「全面萧条」，而是「**资本财端要素与融资成本同时上升 → 资本财相对回报被压缩 → 资金向消费财 / 实物资源再配置**」。

## M77：储蓄性质二分法（主动 / 被动）

> 「储蓄率上升会拖垮需求」是一个**条件命题**，不是一个定律。
> 储蓄率上升有两种性质：**主动储蓄**（意愿性预防）与 **被动储蓄**（买不起）。
> 两者的政策含义**完全相反**——前者该刺激消费，后者刺激是白花钱。

### 核心原理

```
凯因斯式读法（把被动前提误当普遍）：
  储蓄过多 → 有效需求不足 → 萧条 → 该由政府创造需求（补贴 / 退税 / 基建）

海耶克式读法（区分性质）：
  资本财需求↑ → 资本财涨价 → 排挤消费财生产 → 消费财涨价
  → 居民收入被必需品支出挤压 → 被迫减少消费、被动储蓄
  → 这里是【价格结构问题】，不是【意愿问题】
  → 刺激消费只会推高消费财价格，不会恢复需求

判别价值：
  主动储蓄 → 需求问题   → 补贴 / 刺激【有效】
  被动储蓄 → 价格结构问题 → 补贴 / 刺激【无效】，须先解决供给约束
```

### 三条判据（分类判据，不预设结论）

```
① 价格判据：储蓄率↑ 期间，消费财价格是【走弱】还是【走强】？
   → 消费财价格走弱 = 需求不足 = 主动储蓄
   → 消费财价格走强 = 供给约束 = 被动储蓄

② 结构判据：储蓄↑ 的来源是【可选消费收缩】还是【必需品支出占比上升】？
   → 可选消费收缩（减少旅游 / 耐用品）= 主动储蓄
   → 必需品支出占比上升（食品 / 房租 / 医疗挤压）= 被动储蓄

③ 收入判据：实际可支配收入是【增长但未花】还是【停滞或下降】？
   → 增长但未花   = 主动储蓄（意愿）
   → 停滞或下降   = 被动储蓄（能力）
```

### 标准分析步骤

```
□ 第一步：取储蓄率趋势（住户部门口径，非全国总储蓄，须写明）
□ 第二步：跑 ①—③ 三条判据，输出「主动 / 被动 / 混合」三分类（含各自权重）
□ 第三步：若判为【被动】——结论禁止写成「需求不足」，须写成「供给约束 + 价格结构问题」
□ 第四步：政策判断——主动储蓄则刺激消费有效；被动储蓄须先解除供给约束，否则刺激无效
□ 第五步：输出——性质判定 + 政策效力判断 + 证伪位（必需品支出占比是否回落）
```

### 应用纪律

- **本模块是判别器，不是结论。** 任何「中国储蓄过多 → 该强刺激」或「储蓄过多 → 需求崩塌」的表述，**必须先过本模块分类**。
- 与 `base-logic/中国通缩问题与人民币升值路径.md` **必须并读**——同一问题在中国场景下，需求不足型与价格结构型的政策结论差异极大。
- ⚠️ 口径纪律：**住户储蓄率 ≠ 国民总储蓄率 ≠ 存款余额增速**，三者不可互代；引用必须写明口径。

## M78：新发债首日表现温度计

> **一级市场的订单簿（order book）不是需求，二级市场的承接力才是需求。**
> 当超大额新发债在**首个交易日即跌破面值**，说明定价方对边际新增供给的容忍度已经恶化——
> 这是一个**高频、可量化、不可粉饰**的信用市场温度读数。

### 核心原理

```
一级 vs 二级的「需求幻觉」缺口：

  一级（簿记 / 招股）  → 超额认购倍数、订单簿规模   ← 号码可以「喊」
    · 承销商通常把价格定在投资者能小幅获利的水平
    · 最后一刻退出者会让部分机构意外持仓过重 → 首日抛压集中
  二级（首日成交）      → 相对面值偏离（pt / BP）   ← 只能用真金白银说话

判据（首日偏离）：
  首日 0 ~ −1pt      → 正常
  首日 −1 ~ −3pt     → 需求走弱（警惕）
  首日 < −3pt        → 定价失败（承销商失去定价权）
  → 特大额（>$300 亿）+ 首日破面 = 结构性信号，不是「一天的波动」
```

### 三条判据

```
① 偏离判据：首日成交价相对面值偏离（投资级 / 高收益两档分别报）
② 比例判据：首日偏离幅度 ÷ 发行规模（大额破面的信息量远大于小额）
③ 分层判据：
   · 新发债破面   = 边际新增供给的定价失败
   · 存量旧债同步走弱 = 资本结构向新债倾斜（旧债劣后）→ 存量持有人受损
   → 两者同时成立，才是「信用转弱」；仅新债破面，只说明「新增供给过载」
```

### 标准分析步骤

```
□ 第一步：记录发行规模、评级、期限结构、定价（较基准 BP）
□ 第二步：记录一级订单簿峰值 vs 最终获配（缺口 = 需求蒸发量）
□ 第三步：记录首日 / 第 3 日 / 第 10 日成交价相对面值偏离（沿用 M67 的持续天数精神）
□ 第四步：核对存量旧债同期是否同步走弱 → 走判据③
□ 第五步：输出——「信用市场整体转弱」还是「仅边际新增供给过载」，两者结论完全不同
```

### 实战案例（2026-10-01 ~ 10-06 派拉蒙天舞并购债）

| 项 | 读数 |
|---|---|
| 发行规模 | **$414 亿**（中文源口径 $520 亿）；为收购华纳兄弟探索（$1,100 亿）融资 |
| 期限结构 | 8 档第一留置权（$300 亿，票息 6.30%–8.90%，2028–2066）＋第二留置权（$114 亿，7.00%–9.125%）＋ $85 亿 TLB |
| 一级订单簿 | 峰值 **$1,090 亿** → 最终约 $800 亿 |
| 首日（10/1） | 8 年期美元债 **面值 100 → 95~96**；$60 亿 8.25% 2031 二留债 → **97.50** |
| 存量旧债 | 6.875% 2036：85 → **79**；收益率 9.25% → **10.4%**；Fitch 降级后**创历史低** |
| 持续天数 | 首周 2L 三档收在发行价下方 **2.125–4.5pt**；Goldman：**「强订单簿不一定转化为二级承接」** |
| 权威定调 | Gundlach：「本周浮出史上最大高收益债发行，随后债券立即在交易中抛售——**这不是强市场的信号**」 |

**与 M41 / M43 的分工**：
- **M41**（债务可持续性二分，r vs g）判**长期可持续性**；
- **M43**（机构行为变迁）判**定价中枢移动**；
- **M78** 是二者的**即时读数件**——在季度数据出来之前，先用首日偏离定位「融资端是否已开始拒绝为边际供给买单」。

**引用纪律**：派拉蒙案例**不等于**「信用市场全面转弱」——同期整体 HY OAS 仍在低位（09-17 归档）。正确表述：**「融资端对边际新增供给的容忍度下降」**，须与整体利差分层报出。
→ 这一点恰好构成 **M76** 的可交易含义：**资本财扩张的融资端已开始出现拒绝信号**。
