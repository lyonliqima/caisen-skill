## 零、总纲：工具的串联顺序

七个工具不是平铺并列，而是**有先后顺序的操作链**。顺序错了，工具再准也会做反。

```
第一步  周期定位   → 标的在底部/上升/顶部/下降哪个阶段？大周期还是小波段？
第二步  形态识别   → 破底翻（底部反转）/ 假突破（顶部反转）出现了吗？
第三步  两波检查   → 下跌是否走完两波？没走完 = 观望（可切对数图辅助）
第四步  量价验证   → 底部带量？大量高点过了？压回缩量？杀盘K线被吃掉？
第五步  定点画线   → 颈线 / 前低 / 大量高点 / 长红低点 / 60分钟起涨点
第六步  进场       → 效率操作点（颈线突破）或回测支撑不破
第七步  风控       → 破线第一时间跑；仓位降到"睡得着"
```

**一句话逻辑链**：先知道自己在哪（周期）→ 再等信号（形态）→ 用成交量证明信号是真的（量价）→ 用颈线把模糊的判断变成一条可执行的线（画线）→ 线上的点就是买卖点，线下就是止损点。

## 一、七种核心技术工具

### 1.1 破底翻：最高优先级的底部反转信号

**定义**：价格跌破关键支撑（前低或颈线）后没有持续下行，反而快速收回并站上该支撑，形成「假跌破 + 真反转」。

**为什么有效**（底层逻辑）：跌破支撑是空头最后一次发力，此时多头把抛出来的筹码**全数承接**。空头在这一击中用完了全部动能，后面没有力量再砸了，结构就翻了。

| 要素 | 操作要点 |
|------|----------|
| 确认条件 | 跌破前低/颈线后迅速收回；**最好带量收回，吃掉破位那根阴线的实体** |
| 买入时机 | 收回支撑位并站稳后买入。激进者收回当日进场；稳健者等回测支撑不破再加码 |
| 止损设置 | 以破底翻**当日最低点**或前低下方为止损，跌破即离场 |
| 适用市场 | 股票、期货、汇率均适用 |
| 汇率优势 | **破底翻在汇率波段上准确率高于个股**——汇率市场体量极大、参与者以央行和机构为主，趋势一旦形成不易被单一资金扭转 |
| 期货铁律 | 期货不做长期投资想法：**破线一定要跑，出现破底翻再买回来**，如此循环"就不会有事" |

**判定规则（不依赖概率的操作化转换）**：
- ✅ 破位后 **3 日内收回** 且收盘站上支撑 → 破底翻成立
- ✅ 收回时成交量 ≥ 破位阴线成交量 → 有效性确认（量不够则降一级，只做试探仓）
- ❌ 破位后 3 日内没收回 → **不是破底翻，是真破位**，按空头处理
- ❌ 收回后又被打回支撑下方 → 破底翻失败，立即离场，不摊平

**配套阅读**：`references/practical-discipline.md` 的「二度破底翻净化法」——一次破底翻只做试探，二次破底翻才算洗盘净化完成，可用期货。

**录音实例（均为 2026-08-28 时点，非当前结论）**：
- 台币汇率：大形态假突破后破底翻，跌破大颈线后收回
- 白银：突破前波高点 17226，空头形态被破坏
- 纯碱：底部反转，破线跑、破底翻再买回
- 苹果期货：带量破底翻，吃掉上影线带量杀盘 K 线
- 玉米 ETF：周线级别破底翻
- 热卷：带量杀盘处被吃掉，底部量缩，有机会形成右侧回升

### 1.2 假突破（多头陷阱）：顶部反转的镜像信号

**定义**：价格向上突破关键压力（前高或颈线）后站不稳，迅速回落到压力位下方，形成「假突破 + 真反转」。

**为什么有效**（底层逻辑）：突破需要持续买盘承接。突破后立刻掉回来，说明上面的卖压比想象中大，而**买盘已经在这个位置用光了**——往往是主力拉高出货。

| 要素 | 操作要点 |
|------|----------|
| 确认条件 | 突破前高/颈线后快速回落，重新跌破该位；突破时量能不济**或**回落时放量 |
| 操作含义 | 假突破本身是反转信号，但**要等形态确认**，确认前不可直接追空 |
| 汇率应用 | 汇率市场中「很漂亮的假突破，非常好用」 |
| 量度跌幅 | 头部颈线跌破后，**几乎会回到起涨点**（美元指数案例：头部从 2022 做到 2025，颈线跌破后大概率贬回升值起涨点）|

**判定规则**：
- ✅ 突破后 **3 日内收盘跌回压力位下方** → 假突破成立
- ✅ 突破当日量能明显低于前均量，或回落时放量 → 确认信号增强
- ⚠️ 假突破 ≠ 立刻做空的指令，它是**"多头逻辑失效"的警报**。真正的做空触发点是**头部颈线被跌破**
- ❌ 突破后站稳 3 日以上并继续创新高 → 不是假突破，按真突破处理

**配套阅读**：`references/core-strategies.md`（破底翻/假突破两大核心策略与期权纪律）。

**录音实例**：美元指数（资金回流走强后假突破，头部整理一年多、四个循环）、韩币（与台币同步）、惠阳 KY（右肩假突破后获利调节，70→108 后做片线出货）。

### 1.3 颈线与支撑位：多空分水岭与风控锚点

**定义**：颈线是连接两个或多个关键低点（底部形态）或高点（顶部形态）的趋势线，是多空力量的分水岭。支撑位是前期成交密集区或关键低点，是止损的核心依据。

**六种必画的线**：

| 画线对象 | 画法 | 作用 |
|----------|------|------|
| 形态颈线 | 底部：连接双底/头肩底两个低点之间的高点。顶部：连接两个高点之间的低点 | 突破/跌破 = 形态完成确认；颈线处即**效率操作点** |
| 前低支撑 | 最近一波回调的最低点 | 持仓止损线；破位离场 |
| 大量高点/低点 | 成交量显著放大那根 K 线的最高点或最低点 | 站上大量高点 = 多头掌控；跌破大量低点 = 空头掌控 |
| 长红低点 | 突破时那根长阳线的最低点 | 更紧的止损位，风险控制更精确 |
| 60 分钟线起涨点 | 短周期第一根转强 K 线的低点 | 短线进场的风险锚点 |
| 起涨点支撑 | 一波行情发动的起点低点 | 回测不破 = 趋势健康 |

**画线微调原则**（极易被滥用，务必严格执行）：
> 支撑线可以在**事前**微调，目的是"更准确一点、控制风险"；但**绝不能在做错之后才微调**——那是给自己找借口。

**判定规则**：
- 进场前必须把线画完，**没画线 = 不允许下单**
- 线画好后，止损位就是这条路线的另一侧，**不允许盘中挪动**
- 若发现画错了（比如漏了更重要的前低），**先离场，重画，再重新进场**——不允许"带单改线"

### 1.4 量价结构：验证形态有效性的核心

**核心逻辑**：形态是价格画出来的，但价格可以被单一资金短时间做出来；成交量是真金白银堆出来的，更难造假。所以**形态必须靠量来证伪或证实**。

| 量价组合 | 含义与操作 |
|----------|-----------|
| 底部带量 + 大量高点被突破 | **周期底部完成的确认信号**。「大量的高点一过，这个底部就属于周期底部完成」（纺织、棉花案例）|
| 压回缩量 + 拉抬带量 | 健康的多头结构。长鑫科技：压回在大量之上时量缩，一拉就带量 |
| 底部量明显萎缩 | **卖压枯竭信号**。热卷：破底翻时量缩，底部量明显缩 |
| 带量杀盘被吃掉 | 空头力量被多头反吞。苹果、热卷：带量杀盘 K 线被后续阳线吃掉 |
| 突破下降趋势时量增 | 量突破下降趋势 + 价转强 = 回升坡确认（德明利案例）|
| 换手率极高（如 66%）后站稳 | 新股大量换手后站稳大量高点之上，后续表现好（长鑫科技案例）|

**四条判定规则**：
1. **底部必须带量**，缩量创新低不是底，是"没人管的阴跌"
2. **大量高点是最硬的一关**，过了它才算底部完成
3. **压回缩量 = 主力没走**；压回放量 = 主力在出，形态可疑
4. **杀盘 K 线被吃掉**（收盘价超过它的最高价）= 空头力量被完全消化

### 1.5 对数图：极端波动下的底部识别工具

**使用场景**：标的波动极大、常规坐标下底部结构看不清时（如苹果期货从 6500-7000 涨到 10500 又跌回 7000 多）。

**底层逻辑**：对数图按**百分比**而非绝对值显示价格。常规坐标下，高价区的 1000 点和低价区的 1000 点视觉长度一样；但对数坐标下，**同样是跌 20%，在高价区和低价区占的视觉长度相同**——这符合真实的盈亏感受，适合判断"是否跌回历史低位区"。

**三步操作流程**：
1. 先在**常规坐标**上发现破底翻信号，但第二波下跌似乎尚未到位
2. 切换**对数坐标**（通达信：右键 → 对数坐标），观察两波下跌在对数尺度上是否已经到位
3. **判断完成后必须切回常规坐标**，否则后续画线会"怪怪的"（发言者自述经常忘记切回）

> ⚠️ **最常见的操作事故**：对数图画完线忘了切回，导致颈线和支撑位画在错误的绝对价位上。检查清单第 10 项专门用来防这个。

**苹果案例的关键推理**：物价长期上涨，名义价格跌回起涨点很难（因为钱不值钱了）。但如果用对数图看，剔除通胀后的实际价格已经进入历史低点区——这时候"跌回起涨点"这个条件实际上**已经满足**了，不需要等名义价格跌到底。

### 1.6 大量区操作法：站在大量之上做多

**核心逻辑**：巨量成交代表多空激烈换手。巨量本身不说明谁赢了，但**如果后续价格站稳在大量 K 线的高点之上**，说明在换手中**多头胜出**——因为所有在大量区买进的人都没有被套，说明下面有更强的承接力。

| 环节 | 操作 |
|------|------|
| 选股 | 寻找出现异常大量（高换手率）的标的，尤其是**新股**或**长期底部后首次放量** |
| 画线 | 以大量 K 线的**最高点**画水平支撑线 |
| 确认 | 后续震荡中价格始终站稳大量高点之上，**压回时量缩** |
| 进场 | 长红 K 线拉出时进场，止损设在**长红低点**或**大量高点** |
| 风险收益 | 若失败（跌破大量高点），止损位明确、**风险可控**；若成功，后续表现好 |

**判定规则**：
- ✅ 大量日换手率 > 20%（新股可到 60%+）→ 标记为"大量 K 线"
- ✅ 后续 N 日最低价 **始终 ≥ 大量高点** → 站稳确认
- ✅ 压回时成交量萎缩至大量日的 50% 以下 → 洗盘而非出货
- ❌ 跌破大量高点 → 立即离场，说明换手中空头胜出

**实例**：长鑫科技新股上市单日换手率 66%，后续震荡一直拉在大量高点之上，压回缩量、拉抬带量。

### 1.7 效率操作点与两波下跌结构

**效率操作点**：指**颈线突破的位置**。这是形态完成、趋势确认的临界点，在此进场风险报酬比最高。

为什么叫"效率"——因为在颈线处进场，止损位（颈线下方）与进场点几乎重合，**止损空间最小、潜在空间最大**。同样的行情，在颈线进场和在突破后追高进场，盈亏比可以差 3 倍以上。

**两波下跌结构**：下跌趋势通常呈现两波（或以上）推动浪。

| 情景 | 判断 | 操作 |
|------|------|------|
| 破底翻出现 + 两波下跌已走完 | 底部确认度高 | 可在效率操作点进场 |
| 破底翻出现 + 两波未走完 | **"还没到两坡的时候尽量观望"** | 观望，或用对数图辅助判断第二波是否到位 |
| 第二波下跌在对数图上"刚刚好"到位 + 带量破底翻 | 双重确认 | 确认底部 |

**苹果期货完整推理链**：第一波下跌后反弹 → 第二波下跌在对数图上看"刚刚好"到位（名义价没跌回 6500-7000，但对数尺度已进历史低点区）→ 叠加带量破底翻（吃掉带量杀盘 K 线）→ 底部确认。

**配套阅读**：`references/两波等距涨跌对称-测幅满足案例-20260714.md`（两波等距与测幅满足）。

## 二、交易纪律与仓位管理

> 技术方法解决"何时买卖"，交易纪律解决"能否活下来"。以下纪律是长期生存的核心，优先级**高于**任何形态信号。

### 2.1 六条铁律

| 铁律 | 含义 | 为什么（底层逻辑） | 判定规则 |
|------|------|------------------|----------|
| **多头不看压，空头不看撑** | 多头趋势中压力区通常会过，但**不要在压力区追价**；空头趋势中支撑通常会破，不要在支撑区追空 | 压力区的作用是**"不追价"**，不是"做空"。趋势中逆势操作的胜率和盈亏比双低 | 只在支撑区买、颈线突破买；压力区只做减仓，不做新开仓 |
| **卖到睡得着为止** | 波段获利后逐步减仓，降到"无论后续涨跌都能安心睡觉"的仓位 | 仓位决定心态。利润大幅回吐会破坏平常心，导致后续判断变形 | 惠阳 KY 从 108 回档到 90（-20%），若全程持有利润大幅回吐 → 在压力区减仓到回撤 20% 也无感的仓位 |
| **高出低进，不追高杀低** | 到满足区（压力/换手区）减仓，回支撑区再接回 | "不是每天在那边冲上冲下"，而是按波段高低点操作 | 满足区 = 测幅满足位 or 前高压力区 → 减；支撑区 = 颈线/前低/大量高点 → 接 |
| **破线第一时间跑** | 支撑跌破立即离场，不抱幻想、不摊平 | 破线说明形态判断的前提错了。前提错了还加仓，是致命错误 | 期货尤其严格：**破线就跑，破底翻再买回来** |
| **操作不带感情、不带政治** | "做技术分析就只看利（价格），不要有任何政治观念" | 政治偏好会让你对不符合预期的价格信号视而不见 | 中立看待两岸市场，**哪个形态好做哪个** |
| **无压力仓位** | 资金控制在心理无压力区间 | 过重仓位导致判断变形 | 发言者个人做法：股市固定 2000 万台币，行情好追加到 5000 万，**多了领出、少了不补** |

### 2.2 仓位与风控的具体参数

- **高波动板块**（如记忆体）：单笔风险控制在 **10% 以内**算"风险可控"
- **支撑线止损**：所有标的进场前必须画好支撑线，破线即走
- **获利回吐应对**：效率操作买点较高（贴近颈线），回档时利润回吐快 → 更应**主动减仓锁定利润**，而不是被动承受
- **不补仓原则**：个人做法"少了也不补"，避免在亏损中加大暴露

### 2.3 标的选择的优先级

1. **强者恒强**：形态相似时，选**站在大量之上**的强势股（如选长鑫科技而非跌深反弹的华邦电）
2. **跌深反弹也可做**：跌得够深、支撑明确的标的（如德明利），反弹坡也有约 20% 空间
3. **只做市场焦点**：科技股只做有共识的细分（如记忆体），不碰边缘标的
4. **流动性优先**：普通投资者做 ETF 而非不动产，因 ETF"一件买进、一件卖出"，不动产流动性差、被套难变现

## 三、底层知识体系（为什么这些方法成立）

### 3.1 技术分析三大假设

1. **价格反映一切信息**：所有基本面、资金面、情绪面信息最终都反映在价格走势中 → 因此"只看价格"即可，不需要额外拼凑信息
2. **价格沿趋势运动**：趋势一旦形成倾向于延续，直到出现明确的反转信号（破底翻/假突破/颈线突破）
3. **历史会重演**：人类心理与资金行为模式重复出现，形态因此具有预测价值

> 注意假设 2 的推论：趋势延续是**默认状态**，所以**反转需要证据**（形态 + 量价）。这就是为什么"不预测，只跟随"是操作纪律而非风格偏好。

### 3.2 周期理论

| 周期 | 时长 | 当前位置（2026-08-28 时点的判断，需重新验证） |
|------|------|------|
| 库存周期（基钦） | 约 40 个月 | 农产品、化工品处于周期底部 |
| 半导体景气周期 | 资本开支→产能释放→供需失衡→价格调整 | AI 资本开支见顶 ≈ 半导体周期顶点 |
| 生猪周期 | 母猪存栏→生猪供给→猪价传导 | 母猪创新低 = 供给收缩 = 未来价格上行 |
| 航运周期 | BDI 反映散装航运供需 | "涨的时候一直涨、跌的时候一直跌"，趋势性极强 |
| 房地产周期 | 台湾约 8-10 年一轮回 | 股市先行于现货 1-2 个季度 |

### 3.3 宏观与国际资本流动

- **美元潮汐**：美元升值 → 资本回流美国、新兴市场资产承压（本轮收割以亚洲 AI 题材市场为主）；美元贬值 → 资本流向全球、非美资产与商品受益
- **化债逻辑**：美国债务高企后的终局手段 = 通膨 + 美元贬值,"让钱不值钱"
- **汇率市场的高确定性原理**：汇率市场体量极大、参与者以央行和机构为主 → 假突破/破底翻后的反转确定性高于个股

> ⚠️ **汇率方向速查（大陆用户极易看反）**：台币汇率报价为 **USD/TWD**（1 美元兑多少台币）。**数字下跌 = 台币升值**。所以手册中"台币长空"指的是 **USD/TWD 走空 = 台币升值**，不是台币贬值。同理"韩币长空"= 韩元升值。读原始记录时必须换算，否则方向完全做反。

### 3.4 先行指标体系

| 先行指标 | 领先对象 | 应用 |
|----------|----------|------|
| 股价 | 企业业绩（1-2 季度） | AI 股在 Q3 业绩期前提前反应 |
| 地产股 | 不动产现货价格 | 地产股突破颈线后再考虑买房 |
| BDI | 散装航运股 | BDI 突破颈线 = 航运股 D-Day |
| 商品价格 | 原物料类股 | 商品创新高 → 对应股票打底完成 |
| 涨幅榜频率 | 板块资金持续性 | 频繁上榜 = 有资金持续布局 |

### 3.5 交易心理学

- **仓位决定心态**：过重仓位导致判断变形，"无压力"才能理性执行信号
- **沉没成本谬误**：被套后不认错、摊平成本是常见致命错误
- **获利回吐的心理冲击**："赚 100 万一回剩二三十万"会破坏平常心 → 因此**主动减仓**而非被动承受
- **兴趣驱动可持续性**："第一个是兴趣，第二个能靠兴趣赚钱"才能长期生存

## 四、实操检查清单

每次交易前逐项核对，**全部通过才允许下单**：

```
□ 1. 周期定位：标的处于底部/上升/顶部/下降哪个阶段？是大周期还是小波段？
□ 2. 形态识别：是否出现破底翻、假突破、双底/头肩底等反转形态？两波下跌是否到位？
□ 3. 量价验证：底部是否带量？大量高点是否突破？压回是否缩量？杀盘 K 线是否被吃掉？
□ 4. 颈线与支撑：是否已画好形态颈线、前低支撑、大量高点/长红低点？
□ 5. 进场点：是在效率操作点（颈线突破）还是回测支撑进场？是否在压力区追价？
□ 6. 止损预设：跌破哪条线无条件离场？期货是否准备好"破线就跑、破底翻买回"？
□ 7. 仓位检查：这笔仓位是否让我"睡得着"？高波动标的风险是否控制在 10% 以内？
□ 8. 止盈计划：到满足区/换手区是否准备减仓？是否设定了"卖到睡得着"的仓位目标？
□ 9. 情绪中立：是否带入了政治偏好或主观执念？是否只按价格信号操作？
□ 10. 对数图归位：若使用过对数坐标，是否已切回常规坐标？
```

**一票否决项**（违反任一即禁止下单）：
- 第 4 项未完成（没画线）
- 第 6 项无明确止损位
- 第 10 项未归位（对数图残留导致画线错误）
