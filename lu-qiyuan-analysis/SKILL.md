# 卢麒元制度结构分析方法论

> **核心定位**：这是一套**研究方法**，不是观点集合。每次分析时，按方法论独立推导结论。卢麒元本人的观点只是方法论的实战示例。

## 工作流程 / 使用步骤

当用户要求分析某个经济现象时，按以下步骤进行：

### 第一步：广义财政分析

用"三色财政"框架评估经济健康状况：

| 类别 | 定义 | 典型表现 |
|------|------|----------|
| 白色财政 | 受财政法规约束的收支行为 | 预算内收支、正规税收 |
| 灰色财政 | 超越法规但仍合法的财政行为 | 土地出让金、地方融资平台 |
| 黑色财政 | 完全超越法律的财政行为 | 贪腐、权力寻租、暗箱操作 |

**健康度判断**：
- 白色财政为主体 → 健康
- 灰色财政扩张 → 警告
- 黑色财政大量出现 → 危机

**死亡底线**：
- 灰黑色财政 > 白色财政 → 危险
- 广义财政总量接近GDP的80% → 系统性崩溃临界点

### 第二步：财政权异化分析

检查财政权是否被以下四种方式侵蚀：

**1. 财政权分割**（征税权被分割给非政府组织）
- 金融机构获得超额利差 → 变相征收"存款税"
- 房地产超额利润 → 变相征收"居住税"
- 实质负利率 → 强制全社会为贷款人提供资本补贴

**2. 财政权转移**（征税权转移给非政府组织）
- 社会保障体系不透明 → 实际税负远高于名义税负
- 仿效美国模式但缺乏成熟的基金管理能力

**3. 财政权延迟**（大规模举债延迟税赋）
- 地方政府大规模举债 → 寅吃卯粮
- 债务黑洞 → 金融癌症
- 透支子孙后代的财政资源

**4. 财政权让渡**（征税权交付外国政府或机构）
- 联系汇率制度 → 让渡铸币税
- 失去管理通胀的能力 → 他国向中国输出通胀

### 第三步：货币分析

**法币本质公式**：
```
法币 = 国家发行的债务（记账符号）
法币的信用基础 = 可变现资产 + 可征税赋 + 可举债额度
```

**货币强弱判断**：
- 货币强 = 严格的法律约束 + 蒸蒸日上的经济体系
- 货币弱 = 无约束的发行 + 经济管理能力低下

**卢麒元的货币类型学**：

| 货币类型 | 代表 | 特征 |
|----------|------|------|
| 金美元 | 1971年前 | 黄金背书 |
| 石油美元 | 1971-2015 | 石油定价+美元结算 |
| 碳美元 | 2030后（预测） | 碳交易+碳排放权 |
| 国债币 | 当前美元 | 核心是资本控制权 |
| 资产币（理想） | 理想的人民币 | 中央铸币权、主权货币 |

### 第四步：中国经济三大问题分析

卢麒元识别的中国经济三大病症：

**1. 走资（资本外逃）**
- 估算规模：不低于3万亿美元（约21万亿人民币）
- 影响：消灭中产阶级的基础
- 根源：新殖民主义+财政权让渡

**2. 资本沉没**
- 广义沉没：约300万亿人民币（主要是房地产）
- 狭义沉没：约50万亿人民币
- 触发器：2015年后房企大规模外债（约1700亿美元引爆63万亿债务）
- 本质：投入产业的资本流动速度趋近于零

**3. 资金空转**
- 货币已大量发行但进不到实体经济
- 资金在银行系统内循环
- 到不了需要钱的人手上

### 第五步：直接税分析

卢麒元的税制改革主张：

| 税种 | 目标 | 作用 |
|------|------|------|
| 遗产税 | 切断财富世袭传递 | 矫正财富分配失衡 |
| 房产税 | 挤出不动产中的资本 | 推动资本流向实体经济 |
| 资本利得税 | 向资本收益课税 | 公平税制 |
| 离境税 | 防止走资 | 保护国家资本积累 |
| 赠与税 | 堵截避税通道 | 完善直接税体系 |

**关键逻辑**：
```
当前：全部税负指向劳动 → 不公平
理想：向资产持有和资本利得课税 → 公平
附加效果：税务局 = 最好的反腐败机构
债 = 预征税负（所有债都是预征税负，还原为税来理解）
```

### 第五步补充一：税的三重意义（录音纪要增补，2026-10-11 归档）

直接税不只是"多征一种税"，而是**三层递进、顺序不可颠倒**的结构（详见 `references/tax-politics-and-history.md`）：

| 层次 | 内容 | 机制 |
|---|---|---|
| **第一重（政治性）** | 资产的合法性确认 + 身份的合法性确认 | "尊重诚实劳动，不尊重攫取"；寻租诈骗所得在此环节已有处理 |
| **第二重（调结构）** | 调整资本流转的**空间/时间/产业**三维分布 | **税收 = 分隔资本流转的堤坝/挡板** |
| **第三重（社会分配）** | 二次分配 | 税收是社会分配最核心的工具 |

- **"税是堤坝"模型**：调高资产持有税负 → 压缩不必要持有 → 资本从资产端回流实体端
- 连带：直接税 = "透明法"，带动民法与反腐败，并**形成信用借贷的基础条件**（不再"根据砖头压出来"）
- 制度终点：财政部由**收支机构 → 资管机构**（须有资产数据中心）

### 第五步补充二：直接税"推不动"的阻力五条（分析"该改而不改"的通用模板）

① 意识形态已被地租经济化（教育/学术/传媒）→ ② 租在进入税收系统前已被分配并被"神圣化" → ③ 行政体系的既得利益共识（"大家都在吃这个东西"）→ ④ 知识精英的阶级立场（以对直接税的态度为试金石）→ ⑤ 周期位置（实体普遍亏损时推税阻力极大）。

### 第五步补充三：数据资产应纳入税基（M13 配套）

数字资产天然具有**共生性/公共属性**，被少数人占有即形成"新财阀"。暴富三件套 = **无人认领 + 占有 + 未正常纳税**。确权与征税立法落地将改变数字平台公司的估值基础。

### 第六步：美元强弱与资本三流分析

**判断美元强弱的核心指标**（摒弃美元指数误区）：

| 指标 | 美元当前 | 弱(<40%) | 中性(40-60%) | 极强(>60%) | 人民币当前 |
|------|---------|----------|-------------|-----------|----------|
| 全球贸易结算份额 | 51% | 弱 | 中性 | 极强 | 3% |
| 全球央行储备占比 | 57% | 弱 | 中性 | 极强 | 2.1% |

**强美元三大形成机制**：
1. **全球最大商品买方**：美国是全球最大消费市场（预计2030年前被中国超越）
2. **全球最大资本市场（卖场）**：最成熟、流动性最强的资本市场（短期难被撼动）
3. **全球最大军事力量（保安）**：为美元全球流通和结算提供终极保障

**资本三流分析**（沃什核心操作框架）：
- **流量**：全球美元供给总量（是否超实体经济需求）
- **流向**：资本流动方向（流向美国还是新兴市场）
- **流速**：资本周转速度（加速还是冻结）
- AI技术已实现对三流的实时感知和精准操控

**强美元下的应对策略**：
- 国家层面：建立货币发行法律约束 + 精兵简政 + 直接税改革 + 汇率一步到位
- 产业层面：信息技术改造传统产业 + 低碳技术改造传统产业
- 建议：建立水循环基金 + 碳排放基金
- AI防御：加快建立基于AI技术的国家资管体系，打造金融战核心防火墙
- 个人/机构：不过多持有弱势货币的资产，顺势而为

**命题**：资本流转必须有载体；**载体在变，与之匹配的经济治理制度、政策乃至政治制度都必须变**。

| 时期 | 载体 | 形态 |
|---|---|---|

### 第六步补充四：殖民三问与法偿性三级判据（M15 / M16，2026-10-11 归档）

**M15 殖民三问**（对任一国家/地区/行业）：
1. **谁**（哪种资本、哪一国货币）完成了资本化？
2. **用什么**完成资本化（是否以对方货币计价/定值）？
3. **资本化收益归谁占有**？

配套：**要素资本化清单**（土地/劳动力/环境/资源性资产/实体产业资产/数据资产，逐项检查）+ **货币化—非货币化轴**（是否允许产生超越实体经济的货币化收益）。

**M16 法偿性三级判据**（与第三步"货币类型学"**正交**：类型学按锚定物分期，本判据按法偿能力分级）：
```
无限法偿信用货币（1971 前美元，35 美元/盎司）
 → 有限法偿（能力持续下落）
 → 计价单位（价值=0）→ 必须"充值" → 对外殖民的动力学来源
```
- 充值手段：让美元在资产与商品交易中充当**定价"定盘星"**（不一定用美元交易，但定价基础是它）
- **加息与缩表 = 美元资本流转的过程**，本质是为美元"充值"
- 用法：先判级别 → 一旦落入第三级，必找"大体量、已完成/正在完成要素资本化"的经济体作为充值对象

详见 `references/neocolonialism-globalization-collapse.md`。

### 第六步补充五：财政—历史制度对照法（M14，2026-10-11 归档）

遇"某制度为何推不动 / 某盛世为何转衰"，先问三问：
① **册籍（登记基础）还在不在**？（明黄册/鱼鳞册；"天火烧册"= 资产隐匿与外挂的时点信号）
② **税基是否已被挂靠、外挂或隐匿**？（当代形态：数据资产海外上市、外汇外挂、境外公司+密码式转移）
③ **直接税（对资产征）还是间接税（对人头/消费征）占主体**？

**因果链模型**：税收上不来 → 不是中央缺钱，是地方财阀太有钱 → 财阀勾结军阀 → 割据离乱。
**补充判据**：名义主权 ≠ 实质收益权（"都挂在公营事业上逃避税收……表面都在皇家，他看不到钱"）。

### 第六步补充六：美元周期论断的数据核验纪律（2026-10-12 归档）

> 由网传"美元弱周期·四类资产"洗稿文案核验案沉淀（完整案例见 `references/case-four-assets-2026-10-12.md`）。核心病因：把**十年期结构**说成**当下状态**。

1. **长期结构 ≠ 当下状态**：美元霸权侵蚀是十年级叙事（COFER 71%→57%），但任何"美元弱周期已开启"的当下判断必须先过三关——① DXY/广义美元的位置；② Fed 政策路径；③ 美债收益率方向。2026-10 实例：DXY 102.51 近 52 周新高 + Fed 9/16 加息至 3.75–4.00% + 10Y 美债 5.3% → 当下实为"长期弱 + 周期强"。**两层结论方向可以相反，相反本身是结论。**
2. **COFER 引用纪律**：不得表述为"持续下滑至多年新低"——2026Q1 美元占比 57.13%，较 2025Q4 的 56.42% **回升 0.71pp**（约半数季际变动来自汇率估值效应，非主动减持）。引用必须带最新季度值 + 环比方向；长期侵蚀 ≠ 逐季下滑。
3. **金油比 = 论据过期温度计**：以金油比度量"石油被低估"类论断的时效——2026-01-28 峰值 85.8 → 2026-10-12 约 44.7（腰斩），同期油价 +68~84%、黄金 -4.5%。**凡引用"金油比极端高位"必须带时点。**
4. **SWIFT 支付份额 = "充值"实时读数**：2026-03 美元占比 51.14% 创纪录——战争避险时刻美元需求不降反升，M16"法偿性三级判据"的充值靠的不只是信用还有安全溢价；"去美元化不可逆"在 risk-off 时刻会被打断。
5. **广义美元 vs DXY 双口径**：DXY 不含人民币且可被非经济手段扰动；2025-10→2026-10 广义美元（DTWEXBGS）+0.2% 与 DXY +4.3% 分歧——同一"美元强弱"问题两个答案，报告必须同时给两个口径。

## 事实核查与时效纪律（2026-10-11 立）

1. **引用前必读**：凡引用本 skill 中任何具体数字、年份、机构名，先查对应归档文件末尾的「事实核查与时效表」。
2. **三类已查明的高频错误，不得再犯**：
   - 国税地税合并 = **2018 年**（不是 2014）；2015 年 10 月是中央通过征管体制改革**方案**的年
   - 中国**从未实行联系汇率制度**；正确序列是 1994 并轨 → 2005 7·21 参考一篮子 → 2015 8·11 完善中间价
   - **黄册（1381）、鱼鳞图册（1387）是明代制度**，不是唐代（唐代为手实+计帐、租庸调）
3. **过期预言按时间衰减处理**：2022–2023 年时点的判断（"2024 财年要崩"、"东亚共同体 2032"、"2.3 万亿隔夜"）不得作为当前结论，须用当下数据独立复核后再用。
4. **反向证据必须写入**：若实测数据与归档观点冲突，冲突本身是结论的一部分（例：ON RRP 归零说明"待释放泡沫燃料"逻辑已失效，但"利息压垮财政"判据反而被证实且更严重）。
5. **归属不可混**：卢麒元（二次分配/税改/资本流转）与对话者温铁军（一次分配/生态资源/县域）是两套并列方案，合并输出时须分别标注。
