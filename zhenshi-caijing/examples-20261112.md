## 🧰 本日可复用方法（学步骤，不抄结论）

### M1 资产负债表两端定位法（本期最值钱，见 `references/04-z21-z23-*.md` Z21）
**步骤**：① 先写明「这是谁的表」（全球美元 / 某央行 / 商业银行 / 自己账户）→ ② 标负债端＝钱从哪来、成本多少；资产端＝钱到哪去、收益多少 → ③ 只有**负债端发生方向变化**时才推资产端重估 → ④ 逐段标 ✅/❌ 找断点，不许跳到「万物皆崩」。
**本期示范**：美元是全球负债端 → 加息 + 高收益率 → 负债端收缩 → 非美资产重估。骨架成立。
**必补**：央行「利差覆盖倍数」是**存量恒等式**，不是两个收益率相除；须计久期、汇率折算、冲销成本。用错输入凑出对量级 ≠ 方法对。

### M2 给每个判断配「数值阈值 + 时间窗 + 证伪位」（Z22）
本期唯一自带三件套的是 PCR：69% → 85%/100% + 11 月中下旬 + 够不到即右侧起跌。**这个动作本身要学**。
**必补三项**：口径（成交量 PCR 还是未平仓 PCR；TAIFEX / 月度还是周度）、数据源、阈值的历史窗口与胜率。且**先验证指标的时序属性**——未平仓 PCR 是落后 1–2 周的同步/滞后指标，不能拿来预测「反弹的时间与幅度」（Z23）。

### M3 跨资产崩塌观察清单：存量跌幅与当期涨跌分开写（Z18 + Z2）
口播列钻石 / 中药材 / 威士忌 / 葡萄酒 / 黄金 / 油 → 清单本身好用。
**步骤**：每个资产各取 ① 当期环比（一阶导）② 距高点累计（存量）③ 供给段 / 需求段，三行分开写，再横向比谁先谁后。
**实锤**：钻石 8488→2055 是**累计** −75%，但 2026-05 小颗粒已环比回升；把两件事混成「这礼拜又破底」就是方向念反。

### M4 周期类比只能当提问清单，不能当结论（Z14 / Z9）
**步骤**：① 找货币政策同相位（1981 沃克两位数利率 →1984；2022–23 →2026）② 找财富 / 估值极值点 ③ **先列差异项，差异项比相似项重要** ④ 给证伪位。
**实锤**：王安 1984→1992 的硬归因是接班与错过 PC，不是货币周期；「3 年对 3 年」是事后挑相位（Z14 锚点挑选）。

### M5 供给侧缓解 → 品种映射（对期货最可直接落地）
口播命题「现在所有产业都是供给侧问题，没有需求侧压力；供给侧一旦缓解，价格波动会很吓人」是**可检验命题**，不是结论。
**步骤**：列触发事件（俄乌、贸易摩擦降温）→ 映射品种（他自己点了 **DRAM、货柜航运**）→ 每个品种给「缓解的观测指标 + 证伪位」→ 才允许进交易清单。
