# Mi姐三维分析框架（可运行版）

把 Mi姐股市文集的经验性内容工程化为可运行、可回测的分析框架。根模型：
**三周期共振（大方向·中结构·小时机） × 三类资金博弈 × 交易三要素（情绪/筹码/时间）**。

## 模块（数值阈值集中在 framework.py 的 CONFIG）
- **A 趋势**：价格>250日线 + 均线多头排列(5>10>20>60>250) + 周线>60周线 → 多/空/震荡
- **B 结构**：回踩 MA20 的 0.97~1.02 区间且量<0.7×均量 → 健康回调；破 MA20×0.95 放量 → 破位；远离年线2倍+RSI>80 → 顶部
- **C 时机**：收盘≤MA5×1.005 且量比≤1.5 → 买；收盘<MA20 / 浮亏6% / 持仓>6日不涨 → 卖
- **D 资金筹码**：量比>2.5+大涨 → 游资；缩量上涨+多头 → 机构；熊市急涨放量 → 出货预警；牛市急跌缩量 → 洗盘
- **E 情绪**：量能z-score+动量+RSI 定位 潜伏/启动/加速/高潮/分化/冰点 六阶段（个股proxy）
- **F 仓位**：牛市单标≤20%总仓85% / 熊市单标≤5%总仓30% / 震荡单标≤10%总仓50%
- **决策矩阵**：多 + 健康回调 + 买 + (机构/游资) + (启动/加速) → 买入；空/破位/卖/出货/高潮冰点 → 退出

## 文件
- `data_feed.py` — 行情层（新浪可达；腾讯/东财沙箱掐断）。带7天本地缓存，支持离线/定时跑。
- `framework.py` — 模块 A–F + 决策矩阵 + `build_signals()`。
- `backtest.py` — 2019–2025 事件驱动回测，逐条测试 Mi姐口诀有效性。
- `scan.py` — 每日扫描脚本（观察池/指定标的/CSV，可导出）。

## 运行（用托管 venv）
```
PY=/Users/weihaoli/.workbuddy/binaries/python/envs/default/bin/python3
$PY scan.py                              # 内置观察池扫描
$PY scan.py --codes sh600519,sz300750   # 指定标的
$PY scan.py --csv watch.csv --out r.csv # CSV 观察池 + 导出
$PY backtest.py                         # 跑全样本回测与口诀筛选
```
首跑联网拉数据并缓存；之后离线可用缓存。沙箱对股票API有通过率上限，全市场扫描须在用户本机运行。

## 回测已验证结论（蓝筹样本 2019–2025）
- 基准买入持有 +64%；基线(ABC)回踩策略 0.95x 跑输 → 单纯回踩不灵。
- **全框架(ABCDE) +0.05x、盈亏比0.74→1.14、回撤-7.6%→-2.3%** → **D/E 资金情绪门控有效**。
- **避冰点高潮 +0.04x** → 有效。
- 买横买坑不买竖 / 连续大阳不买 / 高位放量滞涨 → 与结构定义冗余，无额外增益。
- 急跌洗盘持有 → 蓝筹样本中性偏负，未验证。
- 完整无偏结论须本机跑全市场（含题材/周期股）。

## Serenity 估值/周期交叉验证增援（可选）

当 Mi姐技术面给出「扣扳机」信号后，可用以下已安装的 Serenity 技能做**基本面/估值/周期门控**，避免技术买点踩中基本面破坏或估值泡沫。它们已安装于 `~/.workbuddy/skills/`，用 Skill 工具按名称调用。

| 技能 | 强化 Mi姐模块 | 用法 |
|------|------|------|
| `gf-dma-health-index` | B结构 / C时机 | 验证回踩/买点是否「基本面支撑的健康回调」：评分<40 视为趋势破坏，即使技术买点触发也降级 |
| `juglar-cycle-stock-stage` | A趋势（大方向） | 补行业朱格拉周期位置：行业 Stage 4过热/5出清期，即便个股技术多头也降仓 |
| `bayesian-intrinsic-growth-valuation` | F仓位 | 估值状态=泡沫化/严重高估 → 单标上限下调、只交易不投资 |
| `tam-adj-peg` | F仓位 | 成长股 PEG 经 TAM跑道/质量修正后若>2.5 → 仓位降级 |
| `serenity-alpha` | E情绪（叙事防骗） | 把题材/新闻翻译为可验证财务弹性假设，与「高潮禁买」互为印证，防被叙事带偏 |
| `buy-side-equity-research-memo` | 全模块（L4 尽调） | 深度研究时产出完整买方备忘录，作为扣扳机前的质地尽调 |

> 门控逻辑：技术面触发 且 估值/周期门控通过 → 正常扣扳机；技术面触发 但 门控告警（健康分<40 / 行业出清期 / 估值泡沫）→ 下调仓位或仅观察。门控不取代 Mi姐 D/E 资金情绪门控（回测已验证 D/E 才是 alpha 来源），只作基本面安全垫。

## 与既有体系关系
本框架定位「中观个股择时 + 仓位纪律 + 情绪周期」，与蔡森形态测幅、资本三流宏观互补（见交叉验证文档）；Serenity 估值/周期技能作为可选基本面门控增援（见上节）。
