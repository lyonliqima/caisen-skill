# 期货历史数据取数与超卖定位法（M-H 系列）

> **建立日期**：2026-09-13
> **触发场景**：用户问「短线跌多了吗 / 是不是历史低价 / 跌到位了吗」这类**位置判断题**。
> **来源**：2026-09-13 红枣 CJ2701 追问（用户第二轮「短线跌多了吗，确实是历史低价吗」）实盘跑通。
> **定位**：本文件是**工具书**（方法与接口），不是观点。其中案例数据只作校准参照，**不得直接外推**。

---

## 使用规则（5 条硬规则，违反即结论无效）

1. **先取数，再开口。** 任何「历史最低 / 历史高位 / 分位数」的说法，必须由本文件第 2 节的接口实拉全历史数据算出，**禁止凭印象或二手研报口径断言**。
2. **主力连续 ≠ 真实市场。** 主力连续是**不复权拼接**，换月跳空会污染极值与收益率。凡用连续序列得出的结论，**必须**用单合约交叉验证（M-H4），并在结论里标注污染方向。
3. **「跌多了」与「跌完了」必须分开报，且分开下结论。** 超卖（M-H6）是**已发生的幅度**，见底（M-H7）是**未发生的转折**。混为一谈 = 本框架最典型的错判。
4. **历史统计不得裸用。** 任何「历史上新低后 X 日上涨概率 Y%」必须过第 5 节五关（M-H10~M-H14），否则只作背景、不进结论。
5. **连阴/连涨类表述必须逐日核。** 日线连阴、周线连阴、合约上市以来、品种上市以来是**四组不同口径**，混用会造出「15 连阴」这类事实错误（见 M-H9）。

---

## 一、结论摘要（这个模块解决什么）

回答「跌多了吗」这个问题，需要**三层独立工作**，任何一层缺失都会导致错判：

| 层 | 问题 | 方法 | 产出 |
|---|---|---|---|
| **取数层** | 数据从哪来、全不全 | 新浪期货历史日K接口（第 2 节） | 全历史 OHLCV+持仓+结算 |
| **定位层** | 现价在历史上是什么位置 | M-H1~M-H5 | 分位数、历史极值、分年区间、污染校正 |
| **判定层** | 是「跌多了」还是「跌完了」 | M-H6（超卖）/ M-H7（见底要件） | 两张独立计分表 |
| **校验层** | 历史统计能不能用 | M-H10~M-H14 | 通过/驳回 + 可用的 EV 表述 |

**核心判断句（本模块的最终输出模板）**：
> 现价处于 **[品种] 上市以来 [N] 个交易日的 [P]% 分位**；超卖指标 **[x/5] 达标**，见底要件 **[y/4] 达标**；历史统计声称 **[通过/驳回]**（理由）；因此结论是 **[做多/不动/追空]** —— 若为寻找左侧买点，可用表述为 **[统计优势不可证成，但赔率与期望值可证成为正/负]**。

## 二、取数层：新浪期货历史日K接口

### 2.1 接口原文（已实测，2026-09-13 复验通过）

```
https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_<SYM>=/InnerFuturesNewService.getDailyKLine?symbol=<SYM>
```

- **`<SYM>` 出现两次**，两处必须一致（JSONP 回调名里的 `_<SYM>` 与 query 的 `symbol`）。
- 返回 HTTP 200，`Content-Type` 为 JS，**JSONP 包裹**：`/*<script>location.href='//sina.com';</script>*/\nvar _CJ0=([{...}]);`
- 需要带 `User-Agent`（实测 `Mozilla/5.0` 即可）。

```bash
# 取主力连续（枣）
curl -s -m 25 -A "Mozilla/5.0" \
  "https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_CJ0=/InnerFuturesNewService.getDailyKLine?symbol=CJ0" \
  -o cj0.txt

# 取单合约（枣 2701）
curl -s -m 25 -A "Mozilla/5.0" \
  "https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_CJ2701=/InnerFuturesNewService.getDailyKLine?symbol=CJ2701" \
  -o cj2701.txt
```

### 2.2 字段与解析

字段（**顺序固定**）：

| 键 | 含义 | 单位 |
|---|---|---|
| `d` | 日期 | `YYYY-MM-DD` |
| `o` `h` `l` `c` | 开 / 高 / 低 / 收 | 元/吨（字符串型小数） |
| `v` | 成交量 | 手 |
| `p` | **持仓量** | 手 |
| `s` | **结算价** | 元/吨 |

解析片段（**注意是 `var _XXX=(...)` 圆括号包裹，不是 `[` 直接开始**）：

```python
import re, json
t = open('cj0.txt', encoding='utf-8').read()
m = re.search(r'var\s+_\w+\s*=\s*\((\[.*\])\)', t, re.S)
bars = json.loads(m.group(1))
# bars[i] = {'d','o','h','l','c','v','p','s'}
bars = [{k: (float(v) if k != 'd' else v) for k, v in b.items()} for b in bars]
```

### 2.3 symbol 命名规则与实测样本

- **主力连续**：`<品种代码>0`（枣 = `CJ0`），返回从品种上市首日至今的**全历史**。
- **单合约**：`<品种代码><年份后两位><月份>`（枣 = `CJ2701` / `CJ2609` / `CJ2607` / `CJ2605` / `CJ2603`），返回该合约**自上市首日至最后交易日**。

## 三、定位层：历史分位与极值定位（M-H1~M-H5）

### M-H1 历史分位计算（严格口径）

`分位 = (历史收盘价 < 当前收盘价 的交易日数) ÷ 总交易日数`

- 用**收盘价**口径，不用盘中价（盘中极值受单笔瞬时撮合影响）。
- **必须同时报盘中极值**作为参照（例：2026-09-11 收 7580 / 低 7575；2026-08-05 低 7560 才是区间真正的最低盘中价）。两个数都报，不要只挑对自己有利的那个。
- 分位 0.0% 的表述要写全：**「该数值为 N 个交易日内的最低收盘价」**，而不是模糊的「历史低位」。

### M-H2 换月污染识别（三查）

主力连续是不复权拼接，换月日会出现**不属于行情本身的跳空**。三查：

1. **单日跳空查**：相邻交易日 |涨跌幅| > 3σ（用该品种 250 日收益率标准差）→ 高度可疑。
2. **相邻合约价差查**：跳空幅度是否接近当时近远月价差的量级 → 若吻合，判为换月。
3. **单合约交叉验证查**：同一日在单合约序列上是否**没有**这个跳空 → 若没有，判为换月。

> 实锤（枣，2026-08-05 → 08-06）：收 7680 → 8345，单日 **+8.66%**，是**换月跳空**，不是行情。

### M-H3 污染的系统性偏误方向（必须标注）

**关键判断：污染不是随机的，是有方向的。**

在 **contango（近低远高，即供大于求的常规结构）** 下，换月是**向上跳**的 → 主力连续序列被**系统性抬高** → **真实市场（以近月/交割月衡量）比连续序列显示的更弱**。

推导：近月 6300 → 远月 7580，换月时连续序列从 6300 跳到 7580，凭空增加 1280 元/吨的「非行情涨幅」。因此：
- 用连续序列算出的「跌幅」**低估**了实际跌幅；
- 用连续序列算出的「历史分位」**偏高**（显得没那么极端），实际更极端；
- 用连续序列算出的收益率**波动被放大**（见 M-H14）。

**反向情形**：backwardation（近高远低，供不应求）下换月向下跳 → 连续序列被系统性压低。**每次都必须先判结构，再定偏误方向。**

### M-H3b 换月跳空的定量修正法（强制·2026-09-15 立）

> **为什么必须补这一步**：M-H3 只给了**偏误方向**（"真实比连续更弱"），没给**定量修正工具**。结果是——知道方向，却仍然直接引用受污染的读数。
> **实锤（生猪，2026-09-15）**：因只做了 M-H3 的方向定性、未做定量修正，首轮报告直接用 `LH0` 原始读数得出「**生猪不超卖**（近250日分位 40.8%、距 MA250 仅 −1.0%）」。次轮复核实拉 1378 根日K、逐日修正后，真实读数是 **近250日分位 0.4%、距 MA250 −27.1%**——**结论完全反向**。方向判断对了，不下手修正等于没判。

**执行四步（可直接照做）**：

1. **检出跳空日**：对主力连续序列算日收益 `r[i] = c[i]/c[i-1] − 1`，标记 `|r[i]| > 3.5%` 为候选。
   ⚠️ 阈值不要用 3σ——生猪 250 日收益率标准差被跳空自身放大，3σ 会漏检。**3.5% 是商品期货的经验可用值**（可品种微调，须在报告中声明）。
2. **二次确认**（M-H2 三查）：与相邻合约价差量级比对 + 该日单合约序列上是否**没有**这个跳空 → 成立才判为换月。
3. **重构序列**：把跳空日的收益 `r[i]` **替换为该日前 20 日收益的中位数**（而非置零、也非删除该日），得到 `r2[]`；再从**最后一日真实收盘价倒推**：
   ```
   c2[-1] = c[-1]
   c2[i]  = c2[i+1] / (1 + r2[i+1])      # 从后往前
   ```
   （必须**以最后一日为锚倒推**，不能从首日前推——首日前推会把误差累积到最后一日，使"当前价"失真，反而毁掉结论。）
4. **双列报出**：原始读数与修正读数**必须并列**，并说明跳空次数与最大单日跳空。

**生猪实锤对照表（2026-09-15，1378 根日K，检出 76 次跳空，最大 2026-04-15 +19.0%）**：

| 指标 | 原始连续 | 跳空修正后 | 差异 |
|---|---|---|---|
| 全历史分位 | 7.4% | **0.1%** | −7.3pct |
| 近250日分位 | 40.8% | **0.4%** | **−40.4pct（决定性）** |
| 近60日分位 | 16.7% | **1.7%** | −15.0pct |
| 距 MA250 | −1.0% | **−27.1%** | **−26.1pct（决定性）** |
| 距 MA60 | −3.3% | −7.6% | −4.3pct |

**两条规律**：
- **越短的窗口，被污染得越狠**。近250日窗口里大部分交易日位于台阶之下 → 分位从 40.8% 塌到 0.4%。而全历史（1378 日）被稀释后只从 7.4% 到 0.1%。**所以"用长窗口分位证明不超卖、用短窗口分位证明超卖"这种混用最危险。**
- **对照检验**：`CJ0` 同样修正（1789 根、85 次跳空），距 MA250 由 −18.1% → −21.4%，**方向一致、结论被加强而非推翻**。→ **修正不改结论时是加固，改结论时必须回到 M-H4 单合约复核。**

**与 M-H4 的配合**：修正序列仍属**合成序列**，不是可交割实物水位。修正只用于回答"位置有多极端"，**不得替代 M-H4**。生猪本轮的最硬锚是单合约事实——`LH2611` 盘中 11225 **＝该合约上市以来新低**，与修正后的极端分位互相印证。

### M-H4 单合约交叉验证（强制）

连续序列给不出「市场真实最悲观水位」，**近月/交割月合约才给得出**。

- 取当时**最近仍在交易的且未进交割月**的合约，以及**即将进入/已在交割月**的合约，各拉一次。
- **交割月价格 = 可交割实物的真实结算水位**，是判断「远月含多少乐观溢价」的硬锚。

> 实锤（枣，2026-09-13）：主力 `CJ2701` 收 **7580**，近月交割月 `CJ2609` 收 **6300** → 近月比远月低 **1280 元（-16.9%）**。**远月相对可交割实物的真实水位升水 20.3%**。
> → 结论：市场最悲观的地方不在 7580，在 6300。**用 7580 谈「历史最低」是选错了观察窗。**

### M-H5 分年区间表（防单一长周期掩盖）

必须逐一列出**每年**的收盘区间，再判断「今年最低是否低于历年最低」。

> 实锤（枣，主力连续）：2019 8615–11475 ｜ 2020 8890–10930 ｜ 2021 8315–17275 ｜ 2022 10100–14230 ｜ 2023 9375–15620 ｜ 2024 9200–15120 ｜ 2025 8625–11685 ｜ **2026 7580–9575**（2026 年内最低**低于历年最低**）。
> 历史最高 17655（2021-11-23）→ 现价 **-57.1%**。

## 四、判定层：超卖 ≠ 见底（M-H6~M-H9）

### M-H6 五维超卖计分表（判「跌多了」）

| # | 指标 | 达标阈值 | 说明 |
|---|---|---|---|
| 1 | RSI14 | < 25 | 日线 |
| 2 | KDJ(9) 的 J | < 10 | `J = 3K − 2D` |
| 3 | 布林带(20) | 收盘 < 下轨 | 用 20 日均值 ± 2σ |
| 4 | 均线偏离 | 对 MA250 偏离 < −10% | 同时报 MA20/MA60 偏离 |
| 5 | 区间跌幅 | 距高点跌幅 > 30% | 高点取「最近一个显著高点」并注明日期 |

> 实锤（枣，2026-09-11）：RSI14 **21.7** ✅ ｜ J=**3.8** ✅ ｜ 收 7580 < 下轨 7614 ✅ ｜ MA20 −5.40% / MA60 −6.72% / **MA250 −16.79%** ✅ ｜ 距 2025-10-17 高点 11480 **−33.97%** ✅ → **5/5 达标**。

### M-H7 见底四要件（判「跌完了」）—— **这是闸门，不是评分**

四项必须**同时**满足才可称「冰点」；**缺一项即否决**：

| # | 要件 | 达标定义 |
|---|---|---|
| 1 | **缩量** | 当日成交量 < 0.7 × 20 日均量 |
| 2 | **持仓转降** | 20 日持仓变化率 < 0（多头认输离场/空头平仓） |
| 3 | **期货转贴水** | 期货相对现货转为贴水（现货强于盘面） |
| 4 | **前 20 席净空减少** | 净空持仓环比下降（空头主动减仓） |

> 实锤（枣，2026-09-11）：① 量 20.16 万手 = 20 日均量 **1.41 倍**（**放量**）❌ ② 20 日持仓 **+6.69 万手（+42%）** ❌ ③ 期货仍**升水**现货 480 ❌ ④ 前 20 席净空未减 ❌ → **0/4**。

⚠️ **M-H7 第 2 项（持仓转降）的可比性限定（2026-09-13 生猪实锤新增）**：合约**上市初期持仓机械增长、临近交割机械下降**，故「20 日持仓变化率」在合约生命周期不同阶段**不可比**。生猪实测（`生猪历次暴力反弹复盘-20260913.md` 第四节）：LH2201 在 2021-09-24 底部录得持仓 20 日 **+50.0%**、LH2209 在 2022-03-17 底部 **+60.2%**——若照本项字面执行会把两个历史大底误判为「空头加码」。**判定前必须先确认该合约处于主力稳定期**（已转主力且距交割 >2 个月），否则第 2 项记「不可比」而非「未达标」。

⚠️ **M-H7 第 1 项（缩量）的适用性抗辩 —— 尚未验证，不许据此改判据（2026-09-15 红队提出）**

有观点认为「缩量」是从**股票市场**搬来的要件，而**期货底部常在放量/增仓中完成**（多空集中换手、挤仓、套保盘移仓），把「缩量」设为前置等于要求该要件只能在底部**之后**才满足，存在**结构性滞后**，可能系统性错过底部。同源抗辩还指出：对**高结转库存 + 有持仓费**的品种（红枣、棕榈），期货升水现货是**正常的持货成本（contango）**，把「期货升水」当作见底否证，等于要求市场先进入稀缺态才算见底，同样存在**要件与品种结构不匹配**。

**当前处置（保守，不得越界）**：
- **不修改判据**。上述抗辩尚无实盘验证——从未统计过「历次底部当日的量能究竟是放量还是缩量」。
- **验证路径**：在 `生猪历次暴力反弹复盘-20260913.md` 的**底部签名表**上补录历次底部当日的**量比（当日量 / 20 日均量）**，统计放量底部 vs 缩量底部的占比。
  · 若**放量底部占比显著（>50%）** → 第 1 项须改为「放量或缩量均可，但须**配合持仓转降**」。
  · 若缩量底部占多数 → 维持原判据。
- **在完成该统计前，第 1 项照原判据执行，但报告中必须注明该要件存在适用性争议**，不得静默使用。

⚠️ **M-H7 第 4 项（前 20 席净空减少）的口径陷阱（2026-09-15 生猪实锤新增）**：该要件只盯**空头席位**，但当日可查到的分席位数据往往只有**多单**变化（如 2026-09-14 红枣「前 20 **多单** +2908 手」）。**拿多单变化去推断空头行为＝无据推断。** 规则：第 4 项所需数据取不到时，记「**不可判定**」并依「缺一即否决」处理，**不得用总持仓变化或多单变化替代**。（本轮回溯发现：某版推导用「总持仓创新高」推出「空头主动加码」，而唯一可查的席位数据是多单增加——这是必须避免的典型错误。）

### M-H8 铁律：超卖 5/5 ≠ 见底 0/4

**这条是本模块存在的理由。** 两个计分表可以同时是极端值且方向相反：
- 5/5 超卖 + 0/4 见底 = **「在加速下跌段」**，不是底部。
- 含义区分：**放量增仓下跌 = 空头在主动加码**；**缩量减仓下跌 = 多头在投降**。只有后者才是冰点。

> 枣案例的两句话表述：
> ① **跌多了** —— 是，5/5 达标，且是上市以来最低收盘。
> ② **跌完了** —— 不是，0/4，空头在加码而非投降。
> **正确动作：不动。** 做多缺见底证据；追空位置过低（历史分位 0%）盈亏比不足。若必须参与，仅限**短线博反弹**且需先见 M-H7 第 1 或第 2 项转正。

> 生猪反向实锤（LH2611，2026-09-11，见 `生猪历次暴力反弹复盘-20260913.md`）：**超卖 1/5、见底 0/3（第 4 项缺数据）**。**这不是「5/5 vs 0/4」的极端组合，而是两头都不极端——盘面既不超卖也没见底。** 与红枣的关键差别：红枣是「跌多了但没跌完」，生猪是「跌得不算多，也没跌完」（RSI14 仅 29.7，MA60 偏离仅 −7.34%，均未触及超卖阈值）。**同一份计分表可以给出完全相反的诊断，取决于品种所处的周期阶段——必须逐品种实拉，禁止跨品种套用结论。**

### M-H9 连阴/跌幅表述的四组口径（防事实错误）

| 口径 | 界定的东西 | 常见错误 |
|---|---|---|
| **日线连阴** | 连续交易日收跌 | 与「本周收跌」混用；中间停盘日算不算 |
| **周线连阴** | 连续周（周五收）收跌 | 把日线累计跌幅说成周数 |
| **合约上市以来** | 该单合约生命周期内 | 用 5 个月合约的极值冒充「历史」 |
| **品种上市以来** | 主力连续自品种上市日 | 被换月污染（M-H2/M-H3） |

> ⚠️ **实锤错误**：2026-09-13 首份红枣报告 7 处写「周 K 线 **15 连阴**」，逐日核验后实为 **周线 5 连阴**（8/14、8/21、8/28、9/4、9/11）。同时「近 30 个交易日」为「跌 16 天 / 涨 13 天」，**日线最长连阴仅 3–4 天** → 形态是**持续阴跌**，不是崩塌式连跌。原表述「15 连阴在统计上极度罕见」属**夸大**，正确表述是「周线 5 连阴 + 收盘价处 1788 个交易日历史 0.0% 分位」。
> **规则**：连阴数必须用日 K 原始序列**按目标口径重算**，不得从二手描述转写。
>
> 🔁 **2026-09-14 双口径复算补记（修正上条的归因）**：对红枣再拉两组数据自建周 K，发现「15 连阴」与「5 连阴」**是同一时点两个口径的真实结果，两篇报告各自都没算错**：
>
> | 口径 | 数据量 | 周实体连阴（收<开） | 起点 |
> |---|---|---|---|
> | **CJ2701 单合约** | 160 根日 K | **15 根**（含进行中 W38 为 16） | W23（6/1，开 10200） |
> | **CJ0 主力连续** | 1789 根日 K | **5 根**（9/14 为 6 根） | W33（8/10，开 8340） |
>
> **根源**：8 月上旬红枣**主力尚未换到 2701**，CJ0 当时跟踪的旧合约价格区间为 7860–8315，且该合约 7/27–8/7 两周**收阳**，把连阴链打断；而 CJ2701 自 6 月初起就是连续实体阴线。
> → 故 **2026-09-14 那份明确写「2701 合约」的报告，其「15 连阴」是正确的**；2026-09-13 用 CJ0 算出的 5 连阴也正确。**真正的错误是双方都没有声明合约口径**，且历史分位（CJ0 的 1788 个交易日）与单合约连阴数写在同一结论里 = 一份报告内混用两种口径。
> → **M-H9 加固（新增第 3 组维度）**：连阴计数必须写清三件事，任一缺失即表述无效——① **哪个合约**（单合约 / 主力连续 / 品种指数）；② **哪个口径**（周实体收<开 / 周收盘<上周收）；③ **含不含进行中的本周**。上表「日线连阴 / 周线连阴 / 合约上市以来 / 品种上市以来」是**标的维度**，此处补的是**计数口径维度**，两组维度正交、都要声明。

## 五、校验层：历史统计声称五关（M-H10~M-H14）

凡出现「历史上新低后 X 日上涨 Y%」这类统计声称，逐关过。

### M-H10 去重关（最容易致命）

**问题**：以「创 N 日新低」为事件时，相邻事件高度重叠 —— 连续多日创新低会被记成多个「独立事件」，把样本量虚增数倍。

**做法**：把**时间窗重叠**的新低日**归并为一个事件簇**，取每簇**首日**（不是末日）为代表。

> 实锤（枣）：原始 24 个「创 250 日新低」样本 → 归并后有效**独立事件仅 ≈12 段**；取每簇首日重算 → **7 胜 6 负 = 54%**，双侧 **p ≈ 1.0（零信息）**。
> 原「20 日 67% 上涨」单侧 p = 0.076（不显著），Bonferroni ×4 后 ≈ **0.30**。

### M-H11 前视偏差关

**问题**：「连续日归一后取段**最后一日**为新低日」= 用了未来信息（当天不可能知道自己是段末）。

**做法**：取**首日**作事件日。任何需要「确认这是一段」才能定出的样本，都是前视偏差。

### M-H12 口径一致关（因变量不许换）

**问题**：用「路径失败（此后是否再创新低）」去否定「20 日固定期胜率」—— 两者是**不同的因变量**。

> 实锤（枣）：用路径失败否定固定期胜率是**偷换因变量**；事实上 2026 三次超卖的 20 日收益**全为正**（+11.49% / +5.54% / +3.68%）。

**做法**：一次检验只用**一个**因变量，并在表头写明（`路径标准` 或 `固定持有期标准`）。

### M-H13 EV 关（看期望值，不看胜率）

**这是五关里唯一可能**挽回**结论的一关。**

```
盈亏平衡胜率 = 平均亏损 / (平均盈利 + 平均亏损)
```
只要**实测胜率 > 盈亏平衡胜率**，即使胜率低于 50% 也是**正期望**。

> 实锤（枣）：即使按最保守的 54% 胜率，平均盈利 **+6.79%** / 平均亏损 **−4.07%** → **盈亏平衡胜率仅 37.5%** → 正期望。且 60 日最差 **−5.66%**、最好 **+66%** → **下行有界、上行无界**（左侧交易的赔率来源）。

### M-H14 测量误差关（多重检验 + 换月污染量化）

两个子检查：

1. **多重检验**：同一问题试了几个口径/几个窗口/几个阈值？用 Bonferroni 或至少报「跑了 k 次」。
2. **污染量化对比**：把 M-H2 找到的换月跳空幅度，与你要检验的效应大小**直接对比**。

> 实锤（枣）：8/5→8/6 换月跳空 **+8.66%** = 20 日收益中位数（+3.68%）的 **2.3 倍** → **测量误差大于被测量的效应**，统计不可用。

### 五关后的裁定模板（**必须拆成两句，不许合并**）

> ① 「**历史统计不可外推**」—— 成立（且被去重与污染分析**强化**）。
> ② 「**历史新低构成买入理由 / 不构成买入理由**」—— 该判断**不成立/成立**（给分）。
> **正确表述**：「统计优势不可证成，但赔率与期望值可证成为正」→ 这是**「正 EV 的左侧交易」**，不是**「无理由的交易」**，也不是**「高胜率的机会」**。

## M-H15 季节性窗口「双维检验法」（2026-09-16 红枣实盘立 · 权重 100% 可复用）

**触发**：凡遇到「XX 品种每年这个季节都会有一波行情 / 到某节日必涨 / 季节性修复窗口」类叙事，禁止只报一个结论。

**为什么单独立一条**：2026-09-16 红枣追问「能不能像以前几次一样逆转」，把 7 个 1 月合约的「9月15日 → 10月31日」窗口实拉复算后发现，**只报「期末涨跌」或只报「窗口内最高」都会误导人** —— 这是一维报告的通病，必须双维。

**方法（三步）**：

| 步 | 算什么 | 作用 |
|---|---|---|
| ① 期末口径 | 基准日收盘 → 窗口末收盘 的涨跌幅，**逐个历史合约**列表 | 回答「持有整个窗口能不能赚钱」 |
| ② 路径口径（易漏） | 「相对基准日的**最大先跌幅度**」与「窗口内**最高涨幅**」，两者并列 | 回答「趋势有没有可能先破位再修复」——决定入场点，而非方向 |
| ③ 底色拆分 | 把样本按当年基本面（丰产/平年/减产）着色，看窗口结果是否由某个子集驱动 | 防止「平均值」掩盖「只有某种年份才涨」 |

**实锤（红枣 CJ 1 月合约，7 个完整样本，单合约实拉复算）**：
- 期末口径：+2.98 / −1.40 / +2.36 / −11.12 / −0.75 / +8.28 / −6.63 → **3 正 4 负，中位 −0.75%**
- 路径口径：**7/7 全部先向下打出空间**，先跌中位 **−6.0%**、平均 −6.2%
- 底色拆分：两次最大正样本（+17.52%、+13.16%）分别对应 2021、2024 **减产年**；丰产/平年样本窗口内最高仅 +1.12%~+5.66%
- 结论：**「季节性必反弹」被证伪（期末中位负），但「先跌后修复」这条路径规律成立（7/7）**，且这笔交易能不能做取决于入场价在哪 —— 从窗口起点买，期望≈0；从先跌 6% 之后买，盈亏比才转正。

**三条硬规则**：
1. **禁止把「窗口内最大涨幅」当成预期收益**。它隐含「你买在最低点」的假设，而这是事后才知道的。正确做法是先给「路径先跌中位 X%」，再以它为入场位重算盈亏比。
2. **样本必须 ≧5 个且按基本面着色**，n<5 或不做底色拆分的季节结论一律降级为「背景，不作决策依据」。
3. **季节性窗口结论必须与 M-H7 见底四要件同向才有意义**。两者背离时（如本例：先跌 −6% 后可能修复，但见底要件 0/4）→ 结论是「等位置，不要现在进场」，不是「做多」也不是「做空」。

**回访（2026-09-16 vs 2026-09-13 本 本案 案例）**：上一轮在 CJ2701=7580（或 CJ0 口径 7580）时判「不动·等 7725 以上破底翻确认」，至 2026-09-15 收 7320（−3.4%）并创全历史新低 —— **判断方向命中 ✅**。当时「见底 0/4」的判定经 13 个交易日仍成立（持仓反而从 ~22.5 万增至 23.6 万、净空扩大）。**教训写入**：左侧品种的「不动」要给出**启动价位**而不只是「等待」，本轮已补 6860–6900 三条件启动结构。

## M-H16 同一品种多源数据的「地基级分歧」处理（2026-09-16 红枣实盘立）

同一交易日同一指标的**两个权威源给出互斥数值**时（本例：郑商所仓单 5580 张 vs 8396 张，差 2827 张 / 1.41 万吨；现货 7990 vs 6390，差 1600 元/吨 = 25%），禁止二选一、禁止用「大概率是 XX」糊过去。

**处理顺序**：① **双列**并在报告中用同一张图两个柱子并列呈现；② **判定该分歧会影响哪几条结论**（本例影响「去库 37.6%」还是「几乎没去」）—— 若该指标是某结论的**唯一支点**，则该结论强制降为 🟡 中置信；③ 在「数据检查声明」里把它列为显式剔除点，并因此**下调置信度上限**（本例由 75 降至 65）；④ 给出能当场裁定分歧的**下一个必看数据**（如 Mysteel 周报库存 / 交易所日度仓单原始数据）。

> ⚠️ 陷阱：在商品分析里，**现货基准价出现 25% 的分歧 = 定价锚不可用**，此时任何「期现基差 → 估值高低」的推论都必须停用。
