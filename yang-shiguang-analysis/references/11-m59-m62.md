## M59：中性利率锚定校验法（r\* 三口径定位与换算）

> 任何「利率要到 X% 才算限制性」的说法，**在没写清 X 是哪一种 r\* 之前，都是无效表述**。
> 中性利率 r\* 不是观测值，是**估算值**——不同机构、不同方法能差出 100BP 以上。用一个估算量当锚，结论的可靠性就完全取决于锚的正确性。

### 核心原理

```
r* 有三种口径，必须先定位，再比较：

  口径 A｜官方长期点阵（Fed SEP "longer run"）
         → 名义联邦基金利率中位。每年 3/6/9/12 月更新。**最权威、最可复现**
         → 换算实际 r*：实际 r* = 官方名义 r* − 目标通胀（2.0%）

  口径 B｜学术模型估算（HLW / LW / Laubach-Williams）
         → 分「实际 r*」直接给数，通常低得多（0.5%–1.5% 区间）
         → 用途：判断长期趋势；不用于给政策利率定靶

  口径 C｜市场隐含（5y5y 远期、TIPS 长期实际利率）
         → 从价格里倒推，反映**市场定价**而非理论值
         → 用途：校验 A/B 是否与市场脱节

定位纪律（三条）：
  ① 说 r* 必须带口径 + 日期 + 名义/实际标签
  ② 跨口径比较前先换算成同一口径（名义↔实际 ±目标通胀）
  ③ 差额 > 50BP 时，不得直接下「限制性/非限制性」结论 → 改用行为证据（M62）
```

### 标准分析步骤

```
□ 第一步：取官方 longer-run 名义中位（Fed SEP），记下「本期值 + 上期值 + 变动」
□ 第二步：换算实际 r* = 名义中位 − 目标通胀（现行 2.0%）
□ 第三步：取市场隐含（5y5y 远期 / TIPS 长期实际利率）做交叉校验
□ 第四步：算「当前政策利率 − 官方名义 r*」的差额（BP）
        → 差额 < 0（政策利率低于 r*）→ 政策仍在宽松侧，央行有继续收紧的空间
        → 差额 > 0 → 才进入限制性区间
□ 第五步：**用行为证据替换估算锚做终判**（本模块的核心纪律）
        行为证据优先级：NFCI/金融状况指数（M62）> 信用利差 > 实体融资成本 > 通胀趋势
        → 若行为证据与 r* 推算冲突，**以行为证据为准**，并把 r* 标为「待修正」
□ 输出：r* 口径 + 数值 + 差额 BP + 行为证据是否一致 + 结论置信状态
```

### 实战案例（2026-09-17 核验：同一时点的三种 r\*）

| 口径 | 数值（2026-09） | 与当前政策利率（3.875% 中点）之差 | 结论指向 |
|---|---|---|---|
| **A 官方长期点阵（名义）** | **3.2%**（自 3.1% 上调；2016-03 以来最高，10 年 6 个月新高） | **−67.5BP** | 政策利率已**高于**官方长期中性 → 按官方口径已具限制性 |
| A' 官方长期（名义，季度细值） | 3.250%（自 3.063% 上调） | −62.5BP | 同上 |
| **B 某纪要自述的「真实中性」** | **4.5%**（未注明口径） | **+62.5BP** | 结论完全相反：仍不够紧 |
| C 市场隐含（2027 年底点阵中位） | 4.1% | +22.5BP | 明年仍在限制性之上 |

**⚠️ 同一时点，「已具限制性」与「仍不够紧」两个结论同时成立——差别 100% 来自 r\* 口径。**
纪要选了口径 B 的 4.5%（且未注明名义/实际），与官方口径 A 差 **130BP**。

🔍 **本框架判定**：**纪要用一个错锚推对了一个正确结论**。真正的支撑不是 r\*=4.5%，而是三条行为证据：
① 主席原话「很难将眼下的金融状况描述为具有限制性」；
② NFCI 综合 −0.564（10 年 3.3 分位）且连续 4 个月加速宽松（见 M62）；
③ 声明的政策意图明示为「撤回（reversing）部分宽松」。
→ **三条同向，且不依赖任何估算的 r\*。** 这就是「行为证据优先」的价值。

### 与现有框架的协作

- **与 M2（货币政策与利率）**：M2 讲利率周期的方向，M59 补上「水平够不够」的锚定方法
- **与 M47（确定性溢价）**：无风险利率相对 r\* 的位置，决定「等待」本身的机会成本
- **与 M58（单一锚点触发器）**：M58 用价格量判拐点，M59 判水平位置——**位置定区间、锚点定时机**，两者配合
- **与 M62**：M62 是 M59 第五步「行为证据」的具体执行工具，**两者必须连用**
- **反模式**：引用任何二手材料里的「中性利率 X%」时，不追口径直接用 → 这是本模块要拦下的错误

## M60：央行声明措辞删减读法（Mandate 权重漂移检测）

> 读央行声明，**看它删了什么，比看它加了什么更重要**。新增措辞往往是修饰，**删除的措辞才是不想再承诺的东西**。

### 核心原理

```
声明改版时，逐句做「三栏对照」：

  保留 ｜ 新增 ｜ 删除

三类信号按可靠性排序（高 → 低）：
  ① 前瞻指引的存在与否   → 决定市场定价方式（有 → 锚定预期；无 → 数据驱动、波动率上移）
  ② 双重使命的措辞取舍   → 就业侧 / 物价侧，哪一侧被写、哪一侧被删
  ③ 分配叙事的措辞变化   → 关注哪一类群体（往往是①的包装，不是独立目标）

关键纪律｜**措辞变化必须绑定一个可观测的恢复条件**：
  声明删掉 A 侧，不代表永久取消 A 侧；要读成「在条件 B 成立期间，A 侧让位」。
  条件 B 一旦不成立，A 侧权重立刻恢复 → 这才是判断政策抗压阈值的关键。

歧义澄清器（避免把副产品当目标）：
  「保护低资产/低收入群体」在官方语境里 = 「价格稳定」的**同义替代**
  （理由：该群体不持有金融资产、靠工资生活 → 通胀是购买力的唯一敌人）
  ≠ 「打压资产价格」
  资产估值承压是该目标的**副产品**，不是目标本身 → **副产品可逆，目标不可逆**
  ⚠️ 把副产品当目标，会系统性高估政策对资产价格下跌的容忍度。
```

### 标准分析步骤

```
□ 第一步：取新旧两版声明全文，做逐句三栏对照（保留/新增/删除）
□ 第二步：标出「前瞻指引」相关句子是否消失 → 判市场定价机制是否切换
□ 第三步：标出「双重使命」两句话各自的存留情况 → 判权重漂移方向
□ 第四步：把所有措辞变化归因到**条件**，而非**立场**（写成「若 X 消失，则 Y 恢复」）
□ 第五步：区分「官方目标」与「本框架衍生推论」——分配叙事类措辞尤其容易混淆

  ⚠️ 分界线测试（第四步的强化）：
     官方是否说过「愿意承受 A 下跌」？
       说过 → 属目标层，可写入结论
       没说过 → 只能写成「若…则…」的条件式推演，**不得写成官方立场**
□ 输出：删了什么 / 权重漂向了哪侧 / 恢复条件是什么 / 哪些是本框架推演
```

### 实战案例（2026-09-16 FOMC 声明改版）

| 三栏 | 内容 | 信号 |
|---|---|---|
| **保留** | 「经济活动稳健扩张…通胀仍处高位」「维持银行体系充裕准备金」 | 事实描述 |
| **新增** | 「The Committee will deliver price stability」（结尾六词，反复重申） | 目标层：物价稳定成为唯一显性承诺 |
| **删除** | ① **全部前瞻指引**（含「宽松倾向」表述）；② **maximum employment（最大化就业）相关表述** | ① 定价机制切换；② **权重漂移** |
| 字数 | 341 字 → **130 字** | 结构简化 = 减少可被解读的措辞 |
| 投票 | **12–0 全票** | 无异议票 |

**双重使命的让位条件（第五步的产出）**：
主席原话：「because the underlying strength of the economy — we are largely operating consistent with full employment — **we can be focused on stable prices**」
→ **恢复条件已明确写死在原话里**：就业侧让位的前提是「接近充分就业」。一旦失业率跳升，该前提消失，**就业侧权重会立刻回归**。

🔍 **判定**：纪要读对了「分配叙事转向」，但把它写成「愿意承受资产估值回调」（**官方从未表述**）——越过了第五步的分界线测试。正确的读法：**价格稳定是目标，估值承压是副产品；附带一个可观测的恢复条件**。这决定了政策对美股下跌的**容忍阈值是有上限的，且上限由就业数据触发**。

### 与现有框架的协作

- **与 M26（央行主席意识形态）**：M26 从人的历史倾向推政策，M60 从文本结构验政策——**人的倾向可能被委员会稀释，文本变化是已发生的事实**
- **与 M19（通胀内外申分层）**：若声明删就业侧保物价侧，则外生通胀（地缘/能源）的传导被明确列为打击对象
- **与 M49（流动性优先）**：前瞻指引消失 → 短端利率波动率上移 → 久期定价的确定性溢价下降
- **与 `benniao-analysis` M24（政策文本模块化拆解）/ M25（措辞潜台词反推）**：同族工具，M60 的增量在**「删减」权重高于「新增」+ 恢复条件绑定**

## M61：点阵图分布净变化重读法（相对当前基点重映射每一档）

> 点阵图**中位数讲的是共识，分布才讲真相**。但读分布有一个必做的重映射动作——
> **每一档必须换算成「相对当前政策利率的净变化」**，否则会把「再加两次」误读成「维持不动」。

### 核心原理

```
第一步（最容易漏）：取「当前政策利率中点」作为 0 基点
    → 本例：加息后中点 = 3.875%

第二步：把每一档的绝对点数，翻译成「相对 0 基点 = 加/减几个 25BP」
    ❌ 错误读法：看到 4.125% 和 4.375%，按绝对水平高低描述
    ✅ 正确读法：4.375% = 再加两次；4.125% = 再加一次；3.875% = 不变；3.625% = 降一次

第三步：分别统计「加 / 不动 / 减」的票数，而不是只报中位
第四步：把分布拆成三层路径（**这是与交易直接相关的分层**）：
    中位路径   → 可交易、可定价
    右尾路径   → 只能作为情景，**不得与中位混用**
    左尾路径   → 尾部风险对冲的依据
第五步：检查「分布形状是否正常」
    正常的点阵随期限延长向下散开（预期回归中性）
    → 若远期不散反聚/上移，说明**中性预期本身在移动**（与 M59 联动）
```

### 标准分析步骤

```
□ 取当前政策利率中点，设为 0 基点
□ 逐档换算成净变化（+2 / +1 / 0 / −1 / −3 次）
□ 统计三票数：加 __ 票 / 不动 __ 票 / 减 __ 票（**不报百分比，报票数**）
□ 分出中位 / 右尾 / 左尾三条路径，各自标注可行条件
□ 检查分布形状：是否出现「远期不散反聚/上移」→ 触发 M59 复查 r*
□ 与上一季 SEP 对比：中位变动 BP + 分布重心迁移方向
□ 输出：中位路径 + 票数结构 + 形状异常提示 + 右尾路径的触发条件
```

### 实战案例（2026-09-16 SEP 点阵，18 位提交，主席未提交）

**2026 年（当年）**

| 绝对点 | 人数 | **净变化重读** | 交易含义 |
|---|---|---|---|
| 4.375% | 4 | **再加两次** | 右尾 |
| 4.125% | 12 | 再加一次 | **中位（4.1%）** |
| 3.875% | 2 | 不再变化 | 左尾 |
| — | — | **降息 0 票** | **无人预期年内降息** |

**2027 年（次年）**

| 绝对点 | 人数 | **净变化重读** |
|---|---|---|
| 4.375% | 8 | **再加两次** |
| 4.125% | 6 | 再加一次 |
| 3.625% | 3 | 降一次 |
| 3.125% | 1 | 降三次 |
| — | — | **14/18 位认为 2027 年末利率高于当前** |

**中位路径**：2026 4.1% → 2027 4.1% → 2028 3.9% → 2029 3.6% → 长期 **3.2%**
**形状检查**：2027 年中位**与 2026 持平**（未按惯例向中性下行）+ 长期点由 3.1% 上移至 3.2%
→ ⚠️ **触发「中性预期本身在移动」提示** → 送 M59 复查 r*

🔍 **两次读法的差别（这就是本模块的价值）**：

| 读法 | 2026 年 12/4/2 这组数被读成 | 后果 |
|---|---|---|
| ❌ 按绝对水平读 | 「12 人支持加 1 次，4 人支持加 2 次，**2 人主张降息**」 | 凭空虚构出 2 票鸽派 → 误判内部有宽松力量 |
| ✅ 按净变化重读 | 「12 票加 1 次，4 票加 2 次，**2 票不变，降息 0 票**」 | 分布**极度单边**：16/18 位年内还要加 |

同一天另有一次读法错误（2027 年）：把 8 票「**再加两次**」读成「还要**再加一次**」、把 6 票「再加一次」读成「**维持不动**」
→ **整体低估鹰派浓度**：实际 14/18 位认为明年利率仍高于当前，被稀释成「6 人不动 + 8 人加一次」。

### 与现有框架的协作

- **与 M13（利率市场定价消化）**：点阵是官方意图，市场隐含是定价结果，两者之差 = 预期差空间
- **与 M26（央行主席意识形态）**：本任主席**未提交点阵**（Warsh 弃权），且公开表示点阵未来可能取消 → 「点阵失效风险」须计入（属制度性变量）
- **与 M59**：第五步的形状检查是触发 r* 复查的开关
- **与 M58**：点阵给区间，M58 的价格锚点给时机
- **反模式**：只报中位、不报分布；报分布只报百分比不报票数；按绝对水平描述而不做净变化重映射

## M62：金融状况指数来源归因法（三层分解 → 政策泄漏度）

> 金融状况指数只说「松还是紧」，**不说松在哪里**。而「松在哪里」决定了央行下一步会做什么——
> **同样的 −0.56，松在资产端和松在信用端，是两种完全不同的世界。**

### 核心原理

```
美国最权威的金融状况综合指数：芝加哥联储 NFCI
（National Financial Conditions Index，**注意不是 CFCI**）
  构造：105 个指标，等权标准化（均值 0、方差 1）
        风险 risk 30 + 信用 credit 35 + 杠杆 leverage 40
  读数：> 0 = 紧于历史平均；< 0 = 松于历史平均；> +1 = 实质压力区
  频率：**周度**（每周三更新，含上一周数据）；历史自 1971/1993 起
  发布：芝加哥联储官网 / FRED（NFCI、NFCIRISK、NFCICREDIT、NFCILEVERAGE、NFCINONFINLEVERAGE）

三层分解（本模块的核心动作）：
  风险子指数   → 股市波动率、股票收益、风险溢价  → **资产端**
  信用子指数   → 银行放贷标准、贷款拖欠、商业地产  → **实体端**
  杠杆子指数   → 美联储资产负债表、货币市场、回购、券商杠杆 → **影子银行端**

来源归因表（把「松/紧」翻译成「谁在松/紧」）：

  综合值 | 风险 | 信用 | 杠杆 | 判定 | 央行含义
  -------|------|------|------|------|----------
   松    |  松  |  松  |  松  | 全面宽松 | 政策的确宽松，有收紧空间与必要
   松    |  极松| 中性 |  紧  | **政策泄漏** | 货币收紧被资产端宽松抵消 → 央行**更鹰**
   紧    |  紧  |  紧  |  紧  | 全面收紧 | 政策已足够紧，继续加会伤实体
   紧    |  中性|  紧  |  松  | 信用收缩主导 | 加息在起作用，但风险来自实体端

研究机构常报告的 NFCI 归因（示例口径，可替换为 FRED 原值）：**金融状况 × 风险 / 信用 / 杠杆**三层，三层合成一个综合读数——关键是三层**各自读数**，不是只看合成。

政策泄漏度（本模块的可交易输出）：
  泄漏度 = 政策利率方向 与 金融状况方向 的**背离持续期**
  → 加息若干次后 NFCI 仍不回升（维持 < 0 或继续下行）= 泄漏加重 = **央行被迫加得更多**
  → 这是逐月可检验的硬判据，不依赖任何叙事
```

### 标准分析步骤

```
□ 第一步：取 NFCI 综合值 + 三个子指数（risk / credit / leverage）的**同期读数**
□ 第二步：算「综合值 vs 各子指数」的偏离 → 填来源归因表，判类型
□ 第三步：看趋势而非单点——连续几个月的方向（加速宽松 or 转向收紧）
□ 第四步：交叉校验信用端 —— 高收益债 OAS、银行贷款标准 → 确认信用是否真松
□ 第五步：算政策泄漏度 —— 加息 N 次后 NFCI 是否回升？未回升则泄漏成立
□ 第六步：与央行原话对照 —— 主席是否公开承认「不具限制性」？（原话是最强的侧证）
□ 输出：松/紧 + 松在哪一层 + 趋势 + 泄漏度 + 与官方表述是否一致
```

### 实战案例（2026-09-04 读数，宏观素材核验实测）

| 系列 | 数值 | 分位/解读 |
|---|---|---|
| **NFCI 综合** | **−0.564** | 10 年 **3.3 分位**（z = −1.49σ）→ 十年最宽松区间 |
| **风险 NFCIRISK** | **−0.648** | 5.8 分位，z = −1.42σ → **极松（宽松主引擎）** |
| **信用 NFCICREDIT** | **−0.060** | **近中性**（自 6 月 −0.031 微降） |
| **杠杆 NFCILEVERAGE** | **+0.081** | **为正 = 偏紧** |
| 非金融杠杆 | −0.354 | 宽松 |
| 趋势 | 6 月 −0.508 → 9 月 −0.564 | **连续 4 个月加速宽松** |

**填写来源归因表**：综合松 + 风险极松 + 信用中性 + 杠杆紧 → **类型 = 政策泄漏**

🔍 **判定**：这就是「**压的是信用与杠杆，松的是风险偏好**」的硬证据——风险与信用两个子指数**相差 10 倍以上**，杠杆端甚至是正的。
**推论（可检验）**：央行面临「加息但金融条件更松」的困境 → 加息的空间与必要性**同时上升**。
**最强侧证**：主席公开表态「**很难将眼下的金融状况描述为具有限制性**」——官方口径与 NFCI 三层分解**完全同向**。

⚠️ **常见误读纠正**：
- 名称错：把 NFCI 写成「CFCI」→ 引用时须用正确名称与 FRED 系列号
- 只用综合值：看到 −0.56 就说「环境宽松」→ 漏掉「杠杆端 +0.081 是紧的」这一层，等于丢掉了最有力的弹药
- 把 NFCI 当经济指标：NFCI 分离的是**金融压力**，不是经济强弱。**可以「金融松 + 经济弱」并存**（2020 年即是）——这正是它与 GDP/失业率互补的原因

### 与现有框架的协作

- **与 M59（中性利率锚定）**：M59 第五步指定 NFCI 为「行为证据」的第一优先级 → **M62 是 M59 的执行件，两者必须连用**
- **与 M4（流动性分析）**：M4 看央行资产负债表/准备金/RRP，M62 看**这些动作在金融条件上的净结果**——投放与条件松紧不是一回事
- **与 M55（BP 归因）**：M55 判「通胀或实际利率主导」，M62 判「松紧在资产端还是信用端」，两者合成一幅完整的利率图景
- **与 `benniao-analysis` M4（反常信号识别）**：本模块的「政策泄漏」正是一类典型反常信号（政策方向与条件方向背离）
- **与 `capital-three-flow`（资本三流日度观测）**：泄漏度可作为「流速」维度的外围验证项
