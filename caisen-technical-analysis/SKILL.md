# 蔡森形态学技术分析方法论

> **核心定位**：这是一套**研究方法**，不是观点集合。每次分析时，按方法论独立推导结论。蔡森本人的观点只是方法论的实战示例。

## 工作流程 / 使用步骤

当用户要求分析某标的走势时，按以下步骤进行：

### 第一步：识别当前所处形态

从K线走势中识别属于哪类形态：

**底部形态（做多信号）**：
| 形态 | 识别特征 | 确认条件 | 量化confidence |
|------|----------|----------|---------------|
| W底（双底） | 两次探底，第二次不低于第一次太多 | 放量突破颈线（两底之间的高点） | 65→80（放量） |
| 头肩底 | 左肩→头（更低）→右肩（高于头） | 放量突破颈线 | 75→85（放量） |
| V底 | 急跌后急涨，无明显底部横盘 | 反转伴随巨量 | 60（难以量化） |
| 圆弧底 | 缓慢弧形筑底，时间较长 | 突破圆弧顶部水平线伴随放量 | 70 |
| 三重底 | 三次探底，底部接近 | 放量突破颈线 | 75→85 |
| 矩形底 | 长时间底部横盘震荡 | 放量突破矩形上沿 | 70 |
| **破底翻** | 跌破支撑后快速收回 | 3日站稳确认 | 60→75（站稳） |

**头部形态（做空信号）**：
| 形态 | 识别特征 | 确认条件 | 量化confidence |
|------|----------|----------|---------------|
| M头（双顶） | 两次冲高，第二次未能有效突破第一次高点 | 跌破颈线（两顶之间的低点） | 65→80（确认跌破） |
| 头肩顶 | 左肩→头（更高）→右肩（低于头） | 跌破颈线 | 75→85 |
| 斜颈线头部（上升楔形头部） | 顶部区域低点递升形成斜颈线，高点无力创新高 | 跌破斜颈线（上升趋势线） | 70→85（放量跌破） |
| 圆弧顶 | 缓慢弧形见顶 | 跌破圆弧底部水平线 | 70 |

**中继形态（趋势延续）**：
| 形态 | 识别特征 | 操作方向 | 量化confidence |
|------|----------|----------|---------------|
| 旗形整理 | 急涨/急跌后小幅反向平行通道整理 | 突破旗形方向延续原趋势 | 65→75 |
| 三角收敛 | 高点递降、低点递升，波动收窄 | 向上突破做多，向下突破做空 | 55→70 |
| 矩形整理 | 水平区间震荡 | 突破方向跟随 | 70 |

### 第二步：画颈线

颈线是形态分析的灵魂：

1. **底部形态颈线**：连接形态中的反弹高点，形成阻力线。突破颈线 = 多头确认。
2. **头部形态颈线**：连接形态中的回踩低点，形成支撑线。跌破颈线 = 空头确认。
3. **颈线可以是水平线或倾斜线**，取决于反弹/回调的具体价位。

### 第三步：验证量价关系

量价配合是确认形态有效性的关键：

| 场景 | 量价要求 | 含义 |
|------|----------|------|
| 突破颈线（多头） | 放量突破 | 突破有效，可进场做多 |
| 突破颈线（多头） | 缩量突破 | 突破可疑，可能假突破 |
| 跌破颈线（空头） | 可放量也可不放量 | 跌破即有效，不需量确认 |
| 回踩颈线 | 缩量回踩 | 健康回调，可加仓 |
| 上涨过程 | 量增价涨 | 趋势健康 |
| 上涨过程 | 量缩价涨 | 上涨乏力，警惕 |

### 第四步：计算测幅满足（目标价位）

测幅满足用于预估行情目标位，制定止盈计划：

**底部形态测幅**（做多目标）：
```
目标价 = 颈线价格 + 形态高度
形态高度 = 颈线价格 - 底部最低点价格
```

**头部形态测幅**（做空目标）：
```
目标价 = 颈线价格 - 形态高度
形态高度 = 顶部最高点价格 - 颈线价格
```

**特殊测幅规则**：
- 三重底/矩形底：可用矩形高度计算
- 头肩底：也可用头部到颈线距离的1.5~2倍估算
- 旗形：旗杆长度 = 突破后预期涨幅
- 月线大级别形态：满足幅度更大，可信度更高
- **M头/头肩顶两波跌幅满足**：第一波跌幅H=形态高度（顶→颈线），第二波跌幅=从颈线再投射H，两波等距即"满足"。第一满足点=颈线-H，第二满足点=颈线-2H。到达第一满足点后可能反弹整理，到达第二满足点后跌势大概率尾声

> **⚠️ M头/双顶 跌幅满足修正（两头顶中点法，用户 2026-07-08 手把手纠正，蔡森教学图验证）**
> 上方「M头 H=顶→颈线」是**头肩顶**算法，不能直接套到 **M头/双顶**。M头必须用**两头顶中点**测 H：
> - **MID = (头1 + 头2) / 2**（左峰与右峰价格的中点）
> - **H = MID（中点） − 颈线**
> - 第一波满足 = 颈线 − H ；第二波满足 = 满足1 − H = 颈线 − 2H（两波等距）
> - 教学图验证：两头顶 100/110 → MID=105，颈线 80 → H=25 → 满足1=55、满足2=30（与蔡森图示完全吻合）
> - 实战案例（BABA 9988.HK）：头1=186.2、头2=174.2、颈线=140 → MID=180.2、H=40.2 → 满足1=99.8、满足2=59.6
> - 易错点：❌ 用绝对最高点（左峰）单测 H（高估 H，目标价偏低）；❌ 用较低峰（右峰）单测 H（H 偏小）；✅ 必须 (头1+头2)/2。头肩顶才是「头部最高点−颈线」，别混。
> - 配色：颈线黑、双顶连线红、两头顶中点紫(点线)、H蓝竖线、两波满足绿(实/虚)。

### 第五步：制定交易计划

基于以上分析，输出交易计划模板：

```
【形态分析结论】
标的：XXX
当前形态：XXX（底部/头部/中继）
颈线位置：XXX

【交易方向】做多/做空/观望

【进场条件】
- 具体触发条件（如：放量突破颈线XXX元）

【止损设置】
- 做多：跌破颈线或形态底部下方2-3%
- 做空：突破颈线或形态顶部上方2-3%

【目标价位】
- 第一目标（测幅满足）：XXX
- 第二目标（如有）：XXX

【量价观察要点】
- 需要关注的量价信号
```

### 第六步：散户与大户资金流动分析（强制）

> ⚠️ **每次分析股票时必须执行此步骤，不可跳过。** 形态看的是"价格走到哪了"，资金流看的是"谁在推动价格"。两者矛盾时，资金流往往是先行信号。

**分析逻辑**：蔡森反复强调，散户是行情的反向指标（散户疯狂=见顶，散户恐慌=见底），大户/外资是行情的主导力量。必须同时看两边才能判断当前处于"养→套→杀"的哪个阶段。

**必须搜索的资金流动数据**：

| 类别 | 指标 | 含义 | 获取方式 |
|------|------|------|----------|
| **散户端** | 融资余额/融资增速 | 散户杠杆水平，融资破历史高位=危险信号 | 搜索"标的+融资余额"或大盘融资余额 |
| | 散户多空比 | 散户情绪温度计，极端多=见顶，极端空=见底 | 小台指/台股多空比、A股散户多空比 |
| | 零股/定期定额买入 | 散户被动买盘力量（台股尤其重要） | 搜索"标的+零股交易/定期定额" |
| | 新增开户数/新基金发行 | 散户入场意愿，火爆=顶部信号 | 搜索"A股/台股+新增开户数" |
| | 个股散户持股比例变化 | 散户是否在接盘 | 搜索"标的+散户持股比例/筹码集中度" |
| **大户/外资端** | 外资现货买卖超 | 外资是养（买）还是杀（卖） | 搜索"标的+外资买卖超/三大法人买卖超" |
| | 外资期货空单部位 | 外资是否在期货布局做空 | 搜索"台指期/股指+外资期货未平仓" |
| | 外资ETF申赎 | 外资是否通过ETF被动买入 | 搜索"标的+ETF净流入流出" |
| | 主力资金净额 | 主力资金流向（A股关键指标） | 搜索"标的+主力资金净额/大单净流入" |
| | 机构/法人持仓变动 | 大户筹码增减 | 搜索"标的+机构持仓/法人持仓变动" |
| | 投信/自营商买卖超 | 法人内部结构分化 | 搜索"标的+投信买卖超/自营商买卖超" |

**资金流动判断框架**：

```
Step 1：散户端信号扫描
  □ 融资余额趋势：上升/下降/持平？是否接近历史高位？
  □ 散户多空比：偏多/偏空/中性？极端值出现？
  □ 散户被动买盘（零股/定期定额）：持续流入/开始放缓？
  □ 散户情绪：疯狂追高/恐慌抛售/中性观望？

Step 2：大户/外资端信号扫描
  □ 外资现货方向：持续买入/持续卖出/拉高出货？
  □ 外资期货部位：多单/空单？空单是否在扩大？
  □ 主力资金净额：净流入/净流出？连续天数？
  □ 机构持仓趋势：增持/减持/持平？

Step 3：散户vs大户背离检测（核心！）
  ┌────────────────────────┬──────────────────────────┐
  │ 组合                      │ 含义                        │
  ├────────────────────────┼──────────────────────────┤
  │ 大户卖出 + 散户买入        │ 养套杀的"套/杀"阶段，危险    │
  │ 大户买入 + 散户卖出        │ 筹码转移，可能筑底            │
  │ 大户卖出 + 散户也卖出      │ 恐慌性下跌，可能接近底部      │
  │ 大户买入 + 散户也买入      │ 共振上涨，趋势健康            │
  │ 大户期货空单大增+现货仍买  │ 养套杀布局中（最危险）        │
  └────────────────────────┴──────────────────────────┘

Step 4：结合形态判断所处阶段
  □ 底部形态 + 大户买入+散户卖出 = 真底部（高信心做多）
  □ 头部形态 + 大户卖出+散户买入 = 真头部（高信心做空）
  □ 底部形态 + 大户卖出+散户买入 = 假底部（可能继续跌）
  □ 头部形态 + 大户买入+散户卖出 = 假头部（可能继续涨）
```

**与蔡森方法论的联动**：
- 配合**M3量价验证法**：资金流是量价背后的"谁在买谁在卖"
- 配合**外资养套杀三步法**：判断当前处于养/套/杀哪个阶段
- 配合**量价背离庞氏信号**：融资余额背离是顶部预警
- 配合**M9多头十大罪状**：融资破记录+外资养套杀=多条罪状触发
- 配合**主力洗盘手法识别**：区分「洗盘（吓你不伤你）」与「出货（真跑）」——洗盘多发生在「养」阶段，典型量价反常（跌放收回缩）、关键支撑守住、1~3天快速收回；诱空破位后 1~2 天拉回即假摔。详见 references/washout-techniques.md

**交易计划模板补充**（在原模板"量价观察要点"后添加）：

```
【散户与大户资金流动分析】
- 散户端：融资余额___（趋势___）/ 散户多空比___ / 散户情绪___
- 大户端：外资买卖超___ / 期货空单___ / 主力资金净额___
- 背离检测：大户___+散户___ = 当前处于"___"阶段
- 资金流结论：支持/不支持/中性 形态判断的方向
```

## 操作纪律

1. **只做明确的形态**：形态模糊不清时，宁可错过也不做错
2. **严格止损**：每笔交易必须设定止损，绝不扛单
3. **波段持有**：买入后持有到测幅满足或形态破坏，不做日内差价
4. **大周期优先**：月线、周线形态比日线更可靠，优先操作大级别形态
5. **量价配合**：永远用量价关系验证形态有效性
6. **不预测，只跟随**：等待形态确认后再行动，不提前预判
