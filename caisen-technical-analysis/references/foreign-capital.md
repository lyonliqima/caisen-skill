## 外资养套杀三步法

蔡森39年操盘经验总结的外资操纵台股经典模式：

```
Step 1（养）：拉现货
  - 外资在台股高档卖出个股（如台积电）
  - 同时大买ETF → ETF基金经理人被迫买入台积电
  - 结果：外资边卖边涨，散户看到赚钱拼命追入

Step 2（套）：空期货
  - 外资在期货市场大举做空（如69000口，契约金额6200亿+）
  - 散户却在期货抢多
  - 结果：外资空单部位庞大，散户多单被套

Step 3（杀）：杀现货
  - 外资集中抛售现货（单日900亿+）
  - 期货同步下跌 → 散户多单被杀到跌停
  - 选择权卖方被断头
  - "半夜行刑"：夜盘台指期货暴跌
```

**蔡森的应对策略**：
- 买个股、空指数
- 只要看到指数假突破，一定做空
- "赚一千点赔三五百点，还是赚"
- 到颈线是否回补看S&P500是否假突破

## 量价背离庞氏信号

蔡森将量价背离与庞氏骗局类比，用于判断多头末期：

### 核心逻辑

```
庞氏骗局：后面进来的人付前面人的利息 → 后面没人跟了就崩盘
股市多头：后面融资/资金进来推高股价 → 融资不再进来就崩盘
```

### 检测方法

1. **融资余额背离**：股价创新高但融资余额增速放缓或不再增加
   - 融资破5000亿以上 → 历史级别危险信号
   - 融资不跟 = 后面没人跟 = 准备崩盘
2. **成交量背离**：最大量不是出现在最高价
   - 最大量的K线之后价格继续涨但幅度变小 → 背离
3. **世代同堂借贷**：信贷+房贷+车贷+融资全部膨胀到极限

### 实战应用

- 蔡森在会员频道提前画出压力区（前大量K线的上下缘）
- 到达压力区时开始减仓："卖到你睡得着为止"
- 睡不着 = 有压力 = 需要继续减仓

## 本益比反向操作法

蔡森用实战经验颠覆传统本益比逻辑：

| 传统认知 | 蔡森实战经验 |
|----------|-------------|
| 本益比低=便宜可买 | 本益比低可能已是股价高点（高点获利最好时本益比最低） |
| 本益比高=贵不宜买 | 本益比高（甚至亏损无法计算）往往是股价底部 |

### 实战案例

- **南亚科**：底部时EPS亏损，本益比无法计算（最高）→ 股价25.6元见底 → 涨到获利大增时本益比反而只有10倍（已是高位）
- **S&P 500**：席勒本益比约41是155年来第二高 → 但股价已在天上 → 这是"double kill"（股价高+本益比也高）

### 使用原则

- 不能用本益比高低作为买卖依据
- 底部都出现在本益比最高（或亏损无法计算）的时候
- 高点都出现在本益比最低（获利最好）的时候
- 当前本益比高+股价也高 = 极度危险

## 带量指纹确认法

带量K线是市场留下的"指纹"，回测不破指纹区=反弹确认。

```
带量指纹操作流程：
□ 找到带量大K线（成交量明显大于前后K线）
□ 标记带量K线的上下缘 = 指纹区
□ 价格回测指纹区是否不破？
  - 不破 = 反弹确认，可以进场
  - 破了 = 指纹失效，观望
□ 配合时间波对称：看前一个反弹周期长度，推测本次反弹时间
□ 配合多周期：4小时线看指纹，日线看大方向
```

## 外资卖股转ETF养套杀链条

外资操纵台股完整操作链，从“养套杀三步法”进一步演化：

```
外资卖股转ETF养套杀链条：

Step 1（布局）：外资卖出台积电
  - 从4月份开始持续卖出，已卖近100万张
  - 但外资仍持1800万张台积电

Step 2（拉现货）：买ETF迫使基金经理买台积电
  - ETF规模达8兆，若10%买台积电 = 8000亿
  - 政策放宽到最高30%可买台积电
  - 基金经理人被动式买入，台积电跌就跟着买

Step 3（散户定期定额）：每月400亿零股买盘
  - 台积电定期定额+主动零股交易每月约400亿
  - 大跌时散户反而大买（因为一直创新高养成习惯）

Step 4（杀现货）：假突破出现后全面杀出
  - 外资期货做空+现货卖出同时发动
  - ETF被动接盘形成流动性问题

关键观察：
  - 外资卖台积电但股价不跌 = 还在“养”的阶段
  - 外资卖且不买ETF = 开始转向“套/杀”
  - 散户大跌时还在买 = 还没到“杀”的尾声
```
