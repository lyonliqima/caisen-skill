## 三、圆桌调度流程（两种模式，主 agent 决定）

### 模式 A：真并行 spawn（优先）
- 当前环境支持 Agent 子智能体时，用 `Agent` 工具按 13 位大师并发调用（同一 message 多个 tool_use block）。
- 每个子智能体仅加载其来源章节（`references/domestic-masters.md` 或 `international-masters.md` 对应段落），只推导不交叉阅读他人。
- 子智能体返回**固定格式一页摘要**（见第四节模板）。

### 模式 B：上下文内推导（降级）
- 无法 spawn 时，主理人（期海众）在当前上下文内**逐位**按方法论独立推导后汇编，报告中须标注「圆桌降级为上下文推导」。

## 四、单席输出模板（每位大师固定格式）

```
【大师名 · 流派】
① 对该品种的核心判断：多 / 空 / 观望（标注🟢共识/🔵独立推导/🟡假说验证中）
② 置信度（0-100 整数）
③ 关键证据（2-3 条，含数据/库存/基差/政策等来源）
④ 证伪条件（什么情形出现则本判断失效，1-2 条）
⑤ 最该被其他流派验证的 1 个交叉点（可选）
```

## 五、交叉验证矩阵打分（主理人汇编用）

套用 `../references/prediction-framework.md` 第一章矩阵，对 5 维度各打 -2~+2 分：

| 维度 | 权重 | 代表大师 |
|------|------|---------|
| 宏观面 | 25% | 索罗斯、葛卫东、保罗·都铎·琼斯 |
| 产业面 | 30% | 傅海棠、叶庆均、林军、刘福厚、林广袤、冯成毅 |
| 技术面 | 20% | 利弗莫尔、克罗、青泽 |
| 情绪面 | 15% | 索罗斯、林军 |
| 系统面 | 10% | 徐长波 |

**决策规则**：
- 加权总分 ≥ +1.0 且 ≥3 维度同向 → 高确定性，可重仓（30%-50%）
- 总分 +0.3~+1.0 且 ≥2 维度同向 → 中等确定性，轻仓试错（10%-20%）
- 总分 -0.3~+0.3 或维度矛盾 → 放弃，继续等待
- 总分 ≤ -0.3 → 反向机会，按同规则评估做空

## 六、圆桌综合视角输出格式（最终交付）

```
【期货团·圆桌综合视角】— <品种> <合约/周期>
1. 多空分布：看多 X 席 / 看空 Y 席 / 观望 Z 席（共 13 席）
2. 交叉验证矩阵加权总分：<分> → 确定性等级（高/中/放弃/反向）
3. 核心共识：<2-4 条跨流派一致点>
4. 关键分歧：<1-3 条对立点 + 分歧根源>
5. 交易计划建议（非指令）：
   - 方向偏好：偏多/偏空/观望
   - 候选入场区间 / 关键突破位
   - 逻辑破位止损位
   - 建议仓位（基于盈亏比与确定性，注明为建议）
   - 盈亏比估算
6. 失效条件：<触发即证伪本轮判断的 1-3 条>
⚠️ 风险提示：期货高杠杆，本视角为方法论推演，不构成投资建议。
```
