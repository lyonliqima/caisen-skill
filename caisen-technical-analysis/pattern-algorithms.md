# 蔡森形态学量化检测算法

> 来源：炒股 app pattern-recognizer.ts 实现，提炼为可参考的量化检测标准。
> 用途：辅助人工判断形态是否成立，提供客观的数值参考。

---

## 通用工具函数

### 局部极值检测

```
寻找局部最小值（底部）：
- 对比前后 N 根 K 线（lookback=5）
- 若当前 K 线 low ≤ 前后所有 K 线 low → 标记为局部底部

寻找局部最大值（顶部）：
- 对比前后 N 根 K 线（lookback=5）
- 若当前 K 线 high ≥ 前后所有 K 线 high → 标记为局部顶部
```

### 均量计算

```
均量(start, end) = sum(volume[start..end]) / count
用于判断突破时是否放量（> 均量 × 1.3 = 放量确认）
```

### 价格容忍度合并

```
两个底部"接近"的判定：|close1 - close2| / min(close1, close2) ≤ 3%
两个顶部"接近"的判定：|close1 - close2| / max(close1, close2) ≤ 5%
```

## 形态1：W底（双底）检测

**量化条件**：
1. 最近 120 根 K 线中找到至少 2 个局部底部
2. 两底之间价格差 ≤ 5%（容忍度）
3. 两底之间间隔 ≥ 8 根 K 线
4. 两底之间存在一个明显的高点（颈线位）
5. 第二个底之后收盘价突破颈线 → 确认突破

**突破放量验证**：
```
突破时 volume > 前5根均量 × 1.3 → 放量确认（confidence=80）
未放量但收盘价突破 → 突破可疑（confidence=65）
```

**目标价计算（底部至颈线的距离 = 突破颈线后的等幅距离）**：
```
depth = neckline - min(底1, 底2)  // 蔡森公式：底部至颈线的距离

第一满足点 = neckline + depth      // 等幅距离投射
第二满足点 = neckline + 2 × depth  // 两波涨幅满足
止损价 = min(底1, 底2) × 0.97

教学数值：底1=15, 底2=13, 颈线=19
depth = 19-13 = 6
第一满足 = 19+6 = 25
第二满足 = 19+12 = 31
```

**划线规范**：
- 颈线：橙色虚线（#FF6B00），标注"W底颈线"
- 双底支撑：绿色虚线（#2ecc71），连接两个底
- 标注：左底（绿）、右底（绿）、颈线（橙）

## 形态2：M头（双顶）检测

**量化条件**：
1. 最近 120 根 K 线中找到至少 2 个局部顶部
2. 两顶之间价格差 ≤ 5%（容忍度）
3. 两顶之间间隔 ≥ 8 根 K 线
4. 两顶之间存在一个明显的低点（颈线位）
5. 第二个顶之后收盘价跌破颈线 → 确认跌破

**两波跌幅满足目标价计算**：
```
height = max(顶1, 顶2) - neckline

第一满足点（基本测幅）：
  target1 = neckline - height
  蓝色竖线距离 = height

第二满足点（延伸测幅）：
  target2 = neckline - 2 × height
  蓝色竖线距离 = 2 × height

止损价 = max(顶1, 顶2) × 1.03（+3%缓冲）
```

**两波跌幅满足判定**：
```
跌破颈线后：
  □ 第一波跌幅 = H（顶→谷的跌幅）
  □ 第二波跌幅 = H（破颈线后的等距投射）
  □ 两波等距即“满足” → 到达 target1 减仓，到达 target2 跌势尾声
```

**划线规范**：
- 颈线：红色虚线（#e74c3c），标注“M头颈线”
- 双顶压力：红色虚线，连接两个顶
- 第一满足点：绿色水平线（#2ed573）
- 第二满足点：绿色虚线水平线（#2ed573，较淡）
- 形态高度：蓝色竖线（#4a9eff）从顶部到颈线
- 标注：左顶（红）、右顶（红）、颈线（红）

## 形态3：头肩底检测

**量化条件**：
1. 最近 150 根 K 线中找到至少 3 个局部底部
2. 中间底部（头部）必须是最低点
3. 左肩与右肩价格差 ≤ 8%（对称性检查）
4. 左肩→头→右肩间距各 ≥ 5 根 K 线
5. 颈线斜率角度 ≤ 15°（颈线不能太陡）

**颈线计算**：
```
左峰 = 左肩与头之间的最高收盘价
右峰 = 头与右肩之间的最高收盘价
slope = (右峰 - 左峰) / (右峰index - 左峰index)
angle = atan(slope / 左峰) × 180 / π
若 angle > 15° → 颈线过陡，形态不成立
```

**目标价计算**：
```
neckline_avg = (左峰 + 右峰) / 2
depth = neckline_avg - head_close
目标价 = neckline_avg + depth
止损价 = head_close × 0.97
```

**confidence = 75**

## 形态4：头肩顶检测

**量化条件**：
1. 最近 150 根 K 线中找到至少 3 个局部顶部
2. 中间顶部（头部）必须是最高点
3. 左肩与右肩价格差 ≤ 8%
4. 间距各 ≥ 5 根 K 线
5. 颈线斜率角度 ≤ 15°

**颈线计算（"点多的为主"原则）**：
```
左谷 = 左肩与头部之间的最低收盘价
右谷 = 头部与右肩之间的最低收盘价

多点检测（核心）：
  扫描左谷±3%范围内的所有K线低点，统计触碰次数(touchLeft)
  扫描右谷±3%范围内的所有K线低点，统计触碰次数(touchRight)
  若 |左谷 - 右谷| / min(左谷,右谷) ≤ 3% → 两个谷在同一价位附近
    → 合并统计总触碰次数 = touchLeft + touchRight
    → 若总触碰 ≥ 4次 → 极强水平颈线
    → 若总触碰 ≥ 3次 → 强效水平颈线
    → 若总触碰 ≥ 2次 → 有效水平颈线
    → neckline = (左谷 + 右谷) / 2
  否则 → 两谷差距较大
    → 画倾斜颈线，斜率 = (右谷 - 左谷) / (右谷index - 左谷index)
    → 角度 = |atan(斜率 / 左谷) × 180/π|
    → 若 angle > 15° → 颈线过陡，形态不成立

水平线优先原则：
  若多个低点都集中在同一价位±3%内 → 必须画水平线（不是斜线）
  蔡森原话："横的平的，零角度的平的横线""最漂亮""最正确"
```

**两波跌幅满足目标价计算**：
```
height = head_close - neckline_avg

第一满足点（基本测幅）：
  target1 = neckline_avg - height
  蓝色竖线距离 = height

第二满足点（延伸测幅）：
  target2 = neckline_avg - 2 × height
  蓝色竖线距离 = 2 × height

止损价 = max(左肩, 右肩) × 1.03（+3%缓冲）
```

**两波跌幅满足判定**：
```
当价格跌破颈线后：
  □ 跌到 target1 附近 → 第一波跌幅满足 → 减仓/不追空
  □ 继续跌破 target1 → 看 target2 → 第二波跌幅满足
  □ 两波跌幅等距（都是 height）→ "两波跌幅满足"
  □ 到达 target2 后跌势大概率进入尾声
```

**划线规范**：
- 颈线：红色虚线（#e74c3c），标注"头肩顶颈线"
- 左肩/头部/右肩：分别用 pin 标注
- 形态高度：蓝色竖线（#4a9eff）从头部到颈线
- 第一满足点：绿色水平线（#2ed573）
- 第二满足点：绿色虚线水平线（#2ed573，较淡）
- 逃命波：反弹到颈线处标注"逃命/右侧逃命"

**confidence = 75**（放量跌破颈线可达 85）

## 形态4.5：假突破检测（头肩顶/M头假突破）

**量化条件**：
1. 先检测头肩顶或M头形态是否成立
2. 价格突破前高阻力位（突破 > 前高 × 1.01）
3. 突破后 ≤ 5根K线内跌回阻力位下方（假突破确认）
4. 随后跌破颈线（假突破确立 = 卖出/做空信号）

**假突破判定流程**：
```
Step 1：识别头部形态
  头肩顶：左肩~90，头部~95，右肩~85
  M头：两顶接近，第二个顶略高于第一个

Step 2：检测假突破
  突破确认：收盘价 > 前高阻力位（如95）
  假突破确认：突破后 ≤ 5根K线内跌回阻力下方

Step 3：颈线计算
  左谷：~68 | 右谷：~72
  若 |68 - 72| / 68 ≈ 5.9% > 3% → 画倾斜颈线
  斜率 = (72 - 68) / (右谷index - 左谷index)

Step 4：假突破确立信号
  "跌落頸線下假突破確立賣出訊號"
  股价跌破颈线下方 = 假突破成立 = 做空信号

Step 5：跌破颈线加码信号
  "跌破頸線空單加碼訊號"
  价格继续下跌到颈线以下（如72位置）
  → 第二个加码做空点
```

**目标价计算**：
```
height = 假突破高点(95) - 颈线均价(70) = 25
目标价 = 颈线均价 - height = 70 - 25 = 45
止损价 = 假突破高点(95) × 1.03
```

**假突破 vs 真突破的量化区分**：
```
假突破特征（confidence = 70~85）：
  □ 突破时成交量 < 前5日均量 × 1.0（缩量或量价背离）
  □ 突破K线长上影线（上影 > 实体 × 1.5）
  □ 突破后 ≤ 5根K线跌回阻力下方

真突破特征（confidence = 75~90）：
  □ 突破时成交量 > 前5日均量 × 1.3（明显放量）
  □ 突破K线实体收盘（收盘 > 阻力位）
  □ 突破后站稳阻力上方，不回踩
```

**划线规范**：
- 前高阻力线：红色水平线（#e74c3c）
- 颈线：黑色/红色水平线
- 假突破高点：红色圆圈标注
- 跌破颈线点：红色圆圈 + 红色向下箭头
- 止损：X标记在假突破高点上方
- 满足目标：绿色水平线（#2ed573）

**confidence = 70**（量价配合 + 头部形态确认可达 85）

## 形态5：破底翻检测

**量化条件**：
1. 先确定前低支撑位（破底发生前的局部最低价 = 前低；**注意不是含破底K线在内的最近30根最低价**，否则会把破底新低误当支撑）
2. 出现一根 K 线收盘价跌破前低 × 0.97（破底确认，跌破幅度通常 2-3%）
3. 之后出现一根 K 线收盘价重新站上前低（翻回确认）
4. 两个事件之间间隔不超过 30 根 K 线

**颈线（翻回后的高点）**：
```
consolidateHigh = 跌破前后 10 根 K 线的最高价
```

**目标价计算**：
```
# support = 前低（破底前的支撑位），不是破底后新低
目标价 = neckLine + (neckLine - support)
止损价 = 前低 × 0.97      # 跌破前低即认错
```

**止损铁律（蔡森）**：破底翻 = 跌破"前低"后快速翻回的假跌破洗盘。进场后若再次跌破"前低" = 翻底失败，立即止损。止损锚定**前低**（破底前的支撑位），**绝不锚定破底最低点**——后者会让风险敞口多出"前低 → 破底低点"这段无效亏损，认错太晚。

**confidence = 60**（需要更多确认信号）

**蔡森补充**：破底翻需3日站稳确认，不是单日翻回即可。

## 形态6：收敛三角形检测

**量化条件**：
1. 至少 2 个递降的局部高点（descendingHighs）
2. 至少 2 个递升的局部低点（ascendingLows）
3. 高低点交替出现，波动收窄

**方向判断**：
```
若 最近低点 > 起始低点 → isRising=true → 底部三角形（bullish）
否则 → 顶部三角形（bearish）
```

**目标价计算**：
```
maxWidth = |lastMax.high - lastMin.low|  // 三角形最宽处
上涨目标 = lastMax.high + maxWidth
下跌目标 = lastMin.low - maxWidth
```

**三角形头部跌幅满足算法（蔡森教学）**：
```
三角形头部高度 H = 头部高点 - 三角形底部（颈线）

有效跌破条件：
  跌破位置必须在三角形的 1/2 到 3/4 处
  有效区间 = [底部 + H×1/2, 底部 + H×3/4]
  教学值：H=20, 底部=60 → 有效区间 = [70, 75]
  → 太早跌破（靠近头部）= 不算三角形
  → 太晚跌破（靠近尖端）= 力度太弱

跌幅满足：
  第一满足 = 底部 - H
  第二满足 = 底部 - 2H
  教学值：60-20=40, 60-40=20
  实战：80→65(破线)→45(第一波)→25(第二波)
```

**confidence**：
- 接近三角形尖端（高点间距 < 15根）→ 70
- 远离尖端 → 55

**划线规范**：
- 上轨：红色实线（#e74c3c），连接递降高点
- 下轨：绿色实线（#2ecc71），连接递升低点

## 形态7：旗形整理检测

**量化条件**：
1. 找到至少 2 个递降/递升的高点和低点
2. 高点和低点同方向移动（平行通道）

**分类**：
```
下飘旗形（Bull Flag）：
- 高点和低点都递降
- 且之前是上涨趋势（旗杆）
- → 上涨中继，突破上沿继续涨

上飘旗形（Bear Pennant）：
- 高点和低点都递升
- 且之前是下跌趋势
- → 下跌中继，跌破下沿继续跌

上飘旗形 + 波段跌幅满足算法：
```
前提：急跌后形成向上旗形整理
  波段高点 = wave_high
  旗形下沿 = flag_low（= 前低）
  旗形上沿 = flag_high

确认条件：
  必须跌破 flag_low（前低）才能确认 wave_high 是有效高点
  蔡森原话："跌破前低才能确定前高，是高點才能计算跌幅满足"

跌幅满足计算：
  H = wave_high - flag_low
  第一满足 = flag_low - H
  第二满足 = flag_low - 2H

教学数值：
  wave_high=90, flag_low=70, flag_high=75
  H = 90-70 = 20
  第一满足 = 70-20 = 50
```

**confidence = 65**（跌破旗形下沿后可达75）

## 形态8：趋势线检测

**量化条件**：
1. 找到至少 2 个局部底部/顶部
2. 上升趋势线：后一个底部 > 前一个底部
3. 下降趋势线：后一个顶部 < 前一个顶部
4. 斜率角度在 0.5° ~ 45° 之间（太陡不可靠）

**角度计算**：
```
slope = (val2 - val1) / (idx2 - idx1)
angle = atan(slope / val1) × 180 / π
有效范围：0.5° < angle < 45°
```

**confidence = 55**（仅作为参考线）

## 多头支撑线有效性判定算法（收盘价确认规则）

**量化条件**：
1. 确认当前处于多头趋势（价格位于支撑线上方，近期低点递升）
2. 在多头整理区找到多个低点，用"点多的为主"原则画出支撑线
3. 每日用收盘价判定支撑有效性

**支撑线绘制算法**：
```
扫描多头整理区（最近 60 根K线）的所有低点
统计各低点价位的触碰次数（±3%范围内合并）
触碰次数最多的价位 = 支撑线价格（support_line）

支撑线颜色 = 绿色 #2ecc71
支撑线类型 = 水平线（多点价位一致时）
```

**每日收盘价判定算法**：
```
每日收盘后执行：
  close_price = 当日收盘价
  support_line = 支撑线价格

  if close_price > support_line:
    status = "支撑有效" → 多头继续，持股不动
  elif close_price < support_line:
    status = "支撑失效" → 多头结构破坏，等待新信号
  else:
    status = "临界状态" → 观望，下一日再确认

特殊规则：
  盘中最低价 < support_line 但 close_price > support_line
    → 不算跌破（主力洗盘），支撑仍有效

加码信号判定：
  回踩支撑线不破 + 当日为阳线 + 成交量 > 前5日均量 × 1.3
    → 加码买入信号
```

**多层级支撑线算法**：
```
第一层支撑（主支撑）：
  = 整理区低点连线，触碰次数最多
  = 多头生命线，收盘跌破 = 趋势结束

第二层支撑（次级参考）：
  = 反弹高点/突破后回踩位（黑色水平线）
  = 可作为第二层支撑或目标位参考

第三层参考（前压力位）：
  = 历史阻力/目标位（紫色水平线）
  = 突破后角色转换为支撑
```

## 平台跌破判定算法（向下跌破·头部形态）

**量化条件**：
1. 识别高位整理平台（价格在某区间内反复震荡 ≥ 20 根K线）
2. 平台顶部：至少 2 个局部高点，价格差 ≤ 8%
3. 平台底部：多个低点触碰同一价位（"点多的为主"），差值 ≤ 3%
4. 价格有效跌破平台底部颈线（收盘价跌破）

**平台颈线绘制算法**：
```
扫描平台整理区（最近 60 根K线）的所有低点
统计各低点价位的触碰次数（±3%范围内合并）
触碰次数最多的价位 = 平台底部颈线（support_line）
平台顶部 = max(平台内局部高点)
平台高度 H = 平台顶部 - support_line

颈线颜色 = 黑色水平线
触碰 ≥ 2次 = 有效，≥ 3次 = 强效，≥ 4次 = 极强
```

**跌破判定算法**：
```
每日收盘后执行：
  close_price = 当日收盘价
  support_line = 平台底部颈线

  if close_price < support_line:
    status = "平台跌破确认" → 做空进场
    target1 = support_line - H（第一满足点）
    target2 = support_line - 2H（第二满足点）
    stop_loss = max(平台内局部高点) × 1.03

特殊规则：
  跌破不需要放量确认（下跌不需要量——蔡森铁律）
  跌破后不能再站回颈线（站回 = 形态失败，空头止损）
  跌破后反弹到颈线 = 逃命波（右侧逃命信号）
```

**confidence = 70**（平台整理时间越长、触碰次数越多，可达 85）

## 与蔡森人工判断的结合

量化检测是辅助工具，最终判断仍需蔡森体系的人工确认：

1. **量化先筛选**：自动扫描所有形态，给出候选列表
2. **人工再验证**：检查量价关系、多周期共振、基本面配合
3. **蔡森操作纪律**：形态不明确不操作，严格止损
4. **大周期优先**：量化检测在日线级别以上更可靠

**重要提醒**：60分钟以下周期的量化检测结果仅供参考，不建议作为操作依据。
