# 笨鸟 M57-M58：三表连接与个股估值五法

> 来源：2026-10-07 对一份财经基础教育课（资产负债表 / 利润表 / 现金流量表 的连接，及 PE / PEG / PB / PCF / DCF 五种估值法）的方法论蒸馏。
> 定位：这是一套**个股基本面研究的工具**，不是观点，也不是宏观利率框架。它补的是笨鸟此前缺的一块——**从公司财报与估值出发做方向研判**。
> 与笨鸟宏观模块（M41–M56）的关系：宏观模块解决"利率 / 通胀 / 汇率 怎么驱动大类资产"；本模块解决"落到单只股票，怎么用三张表和五把尺子量它贵不贵、价值与价格的缺口在哪"。二者并行使用：先用本模块判个股内在价值区间，再用 M47/M56 的利率因子校 DCF 现值。
> ⚠️ 所有数字（320元股价、4元EPS、上海房产300万、2%/4%租金报酬等）均为**教学示例**，不是当下行情。实际分析必须用最新财报与市价重跑。

## M57：三表连接与财报勾稽（长河模型）

**核心洞察**：三张报表不是三张独立的表，是**同一门生意在三个维度的投影**。资产负债表是"节点快照"（存量），利润表与现金流量表是"期间河流"（流量）。看懂它们怎么互相穿透，才不会把利润当真金、把净资产当死数。

### 三个定义（先钉死性质）

| 报表 | 会计基础 | 性质 | 回答的问题 | 节点 / 期间 |
|---|---|---|---|---|
| **资产负债表 BS** | 存量 | 某一时点的"状态" | 钱从哪找（负债+资本金）、用到哪（资产） | 季报/半年报/年报的结算时刻 |
| **利润表 IS** | 权责发生制（权益发生制） | 期间流量 / 增量 | 这段期间做了什么生意、赚还是赔 | 会计历年（1/1–12/31） |
| **现金流量表 CF** | 现金发生制 | 期间流量 | 钱真正从哪里进来、流向何处 | 同期间，分经营/投资/筹资 |

> 一长河比喻：企业经营是一条长河，季报/半年报/年报是河上"停下来的节点"——每个节点拍一张资产负债表快照；两节点之间的河段是利润表（这段时间发生的经营行为）；河里真正流动的水是现金流量（收付可能跨年度：11月做生意、次年1月才收款；或今年纯收去年该收的账）。

### 第一步：期初存量 → 期间经营 → 期末存量

```
期初资产负债表（存量起点，上一期年报结转）
   │  找钱：负债 + 资本金；用钱：各类资产
   ▼
期间利润表（经营行为，权责发生制）
   │  收入 − 成本 − 费用 = 净利润
   ▼
期末资产负债表（净资产 = 期初净资产 + 本期净利润 + 其他综合收益）
```

**勾稽点**：利润表的净利润，最终"长"到期末资产负债表的「股东权益 / 净资产」科目上。这是三表最硬的一条线。

### 第二步：净利润 → 经营活动现金流（间接法）

```
净利润
  + 非付现费用（折旧摊销等）
  ± 营运资本变动（应收↑减、应付↑加、存货↑减）
  − 资本性支出（投资活动）
  = 经营活动现金流（再减维持性资本支出 = 自由现金流，见 M58-4）
```

**勾稽点**：利润表是"赚赔的权利义务"（权责发生制），现金流量表是"真金白银的收付"（现金发生制）。二者之差，几乎全部来自**应收应付、存货、折旧**这些"时间错配"科目。

### 第三步：经营行为穿透资产 / 负债端（逐笔映射）

每笔生意都会在三表同时留痕，举最容易错的一组：

| 经营动作 | 资产端变化 | 对利润表 | 对现金流 |
|---|---|---|---|
| 卖货收现金 | 货币资金 ↑（加） | 收入确认 | 经营现金流入 |
| 卖货开票据 | 应收票据 ↑（加） | 收入确认 | 暂未流入（票据到期才流） |
| 先货后款（赊销） | 应收账款 ↑（加） | 收入确认 | 暂未流入（**可能收不回**） |
| 卖出存货 | 存货 ↓（减） | 成本结转 | — |
| 买设备 | 固定资产 ↑ | — | 投资现金流出 |
| 利润分配/分红/借款 | — | — | 筹资活动 |

**勾稽点**：利润表收入↑，资产端（应收/票据/货币）必同步↑；利润表成本/费用↑，存货↓或负债↑。**任何"利润很好看但应收暴增、经营现金流为负"的组合，都是红灯**——利润可能是纸面富贵。

### 第四步：存量 vs 流量，谁更重要

```
1 个存量（BS） + 2 个流量（IS、CF）
增量（利润）= 赚赔的权利义务，可能虚
流量（现金流）= 真金收付，最难造假
存量（净资产）= 家底，但要防账面价值过时（见 M58-3 通胀重估）
```

**判读结论**：流动性为王。利润表告诉你"权利义务"，现金流量表告诉你"钱到底到没到"。**质量检验永远优先看经营现金流能否覆盖净利润**（经营现金流 / 净利润 长期 <1，警惕）。

### 常见误用

1. **把利润当现金** —— 权责发生制下，赊销也算收入，但钱可能永远收不回。
2. **只看单张表** —— 三表必须合看；净利润与经营现金流背离是最经典的健康度信号。
3. **把净资产当真实家底** —— 历史成本计价的老资产在通胀下账面偏低（M58-3），而淘汰资产账面虚高。
4. **用旧财报当现在** —— 利润表是过去时，估值必须滚动到最新（引出动态 PE / TTM，见 M58-1）。

## M58：个股估值五法（PE / PEG / PB / PCF / DCF）

**核心洞察**：五种方法构成一条"**简单↔精准、精准↔难算**"的光谱。越简单（PE）越不精准，越精准（DCF）越难算、越依赖预测。实务上**没有一把尺子通吃**，要按行业属性选尺子，再用"价值−价格缺口"找市场失灵。

```
简单 ←————————————→ 精准
PE  →  PEG  →  PB  →  PCF  →  DCF
（只看利润）（带成长）（看净资产）（看真钱）（看未来全部现金流）
```

### M58-1 市盈率 PE = P / EPS

- **P** = 每股价格（一次性付出的成本）；**EPS** = 每股盈余（每年得到的报酬）。
- **倍数含义**：20倍 = 用20元买1元/年的利润；隐含报酬率 = 1 / PE。
  - 20倍 → 隐含报酬率 5%（20年回本，假设不成长、不倒闭）
  - 10倍 → 10%（10年回本）
  - 5倍 → 20%（5年回本）
- **静态 PE 的硬伤**：① 用的是**过去**EPS（旧财报，投资永远看后视镜）；② 受一次性业外扭曲——卖地、处分子公司会让EPS暴增、PE骤降，但不可持续，**失真**。
- **修正**：动态 PE（滚动四季度 TTM）、平滑 PE（跨数年平均），剔除单期噪声。
- **纪律**：PE 高 ≠ 贵，PE 低 ≠ 便宜，必须结合成长性（接 PEG）。

### M58-2 市盈率相对盈利增长 PEG = PE / G

- **G** = EPS 年成长率（%）。把成长性带入 PE：PE 除以成长率，得到"经成长修正后的交换代价"。
- **判读**：
  - PEG < 1 → 通常低估（有价值投资机会）
  - PEG > 1 → 偏高（不代表坏，可能因高成长支撑）
  - **小通常代表好，大需警惕**
- **解释 A 股 PE 偏高的真相**：A 股上市公司 G（成长率）普遍大（维持五成增长比比皆是），PE 高但 PEG 合理 → 并不贵。单纯横向比 PE 会误判。
- **题材/概念股的底层逻辑**：国家扶持、接到大订单、政策刺激 → **改变 G 的预期（G 变大）→ PEG 变小 → 估值显得便宜 → 股价涨**。涨的不是现在，是"未来现金流斜率"被改写了（同 DCF 逻辑）。
- **关键提醒**：G 是预期，会落空。PEG 买卖的是"成长兑现"，不是"成长叙事"。

### M58-3 市净率 PB = P / B

- **B** = 每股账面价值（净资产）。存量视角：用多少钱买 1 元净资产。
  - PB < 1 → 用不到 1 元取得 1 元资产（"CP值高"，破净）
  - PB > 1 → 超过净值买
- **为何 PB 普遍 > 1（通胀逻辑）**：老资产按历史成本入账、未重估；物价上涨使同一资产的收益能力上升，账面净资产偏低 → PB 易 > 1。例：上海房产2010年300万买、租金报酬2%；后来房租涨、报酬变4%，但账面仍记300万 → 真实价值已升，PB 反映的"便宜"是账面滞后造成的。
- **为何金融股 PB 常 < 1**：银行赚息但可能赔本金，净资产创造财富的能力被打折扣（风险折价）。
- **适用行业**（重要）：
  - ✅ 稳定现金流、重资产、非高成长：电信、金融、钢铁、水泥 —— 看 PB 有意义
  - ❌ 高成长、轻资产：营销渠道、创意、管理能力为主的公司（如部分电子/消费） —— PB 参考价值低
- **用法**：稳定现金流行业中，价格大幅低于账面价值（PB 深度破净）= 市场失灵信号，才是机会。

### M58-4 市现率 PCF = P / 自由现金流

- **自由现金流 = 经营活动现金流 − 资本支出（维持性再投资）**。"自由"= 赚的钱够覆盖设备更新+未来投资后还有剩，可随意分红 / 还债 / 回购。
- **逻辑**：利润可能假（应收收不回），所以要"给我真钱"。巴菲特强调自由现金流，正是因为它最难造假、最贴近股东真实回报。
- **判读**：P / 自由现金流 = 倍数，与你的**要求报酬率**比较：
  - 自由现金流报酬率 > 你的要求报酬率 → 可投
  - 反之 → 不投
- **资金成本（要求报酬率的两种算法）**：
  - **会计成本**：借来的钱有利息（如配资 7% 利率，则股票年报酬要 > 8% 才赚，否则倒贴利息）
  - **机会成本**：不投这个去投别的能赚多少（如房地产年报酬 4%，则股票要 > 4% 才值得换）
- **七二法则（校准目标用）**：财富翻倍年数 ≈ 72 / 年化报酬率%。
  - 年 12% → 约 6 年翻倍；年 6% → 约 12 年翻倍；7 个涨停板（10%）≈ 翻倍
  - **纪律提醒**：散户常设"天天打板"这类人类达不到的目标 → 被迫追高 → 赔钱。先问自己"本金多少、想赚多大、想多快"，目标定了才有可交易的估值锚。

### M58-5 DCF 未来现金流折现法

- **逻辑**：把未来所有现金流（股利 / 自由现金流）按利率因子折现到现在：
  `现值 = Σ CF_t / (1 + r)^t`（t=1,2,3…）
- **折现直觉**：明年的 50 元 < 今天的 50 元（今天拿到可存息生利；时间等待有成本；通胀侵蚀）。越远的钱除以越大的 (1+r)^t，现值越小。
- **利率 r 与股价的传导（核心）**：
  - r ↑ → 分母变大 → 现值 ↓ → 股价跌
  - r ↓ → 分母变小 → 现值 ↑ → 股价涨
  - **成长股 / 创投股对 r 最敏感**（远端现金流占比大，r 一动现值波动最猛）。
- **成长的斜率**：无论是 PEG 还是 DCF，改变未来现金流预期（新产品、新商业模式、新政策）→ 直接改估值。题材炒作、科创板大涨，本质都是"未来 CF 的斜率被改写了"。
- **地位与局限（必须讲清）**：DCF 是最精准的"交易圣杯"，是公司真实价值之所在（甚至清算价值最重要）。但**做不到**有两处硬约束：① 无法预知未来多年现金流；② 无法预知未来利率路径。所以正确的用法是：**保持这个上帝视角做方向研判，而非追求精确数字**——尤其用 M47/M56 的利率因子校现值方向。

### 配套：河流图（PE/PB 估值带 · 五线谱）

- **逻辑**：标准差法。中间红线 = 固定 PE（或 PB）下的股价平均值（中枢）；上下各 1 个标准差、再各 1 个（共五条线，像五线谱）。
- **用法**：不按绝对价格算高低，按"历史估值带位置"算：股价飘在带上方 = 高估区，下方 = 低估区。
- **斜率判读**：EPS 或净值增长使中枢从左下到右上 = 正斜率（成长，优先买）；左上到右下 = 负斜率（衰退，回避）。
- **定位**：PE/PB 常用法的补充——固定合理 PE/PB + 标准差修正，让你知道"承担的风险"与"预期的利润"。

### 五种方法速查表

| 方法 | 看什么 | 公式 | 最适合 | 最大缺陷 |
|---|---|---|---|---|
| PE | 利润能力 | P/EPS | 通用初筛 | 用旧EPS、受业外扭曲 |
| PEG | 利润+成长 | PE/G | 成长股、A股 | G是预期，会落空 |
| PB | 净资产 | P/B | 稳定现金流/重资产 | 轻资产/高成长无效 |
| PCF | 真实现金 | P/自由现金流 | 质量检验、价值股 | 资本支出口径难统一 |
| DCF | 未来全部现金流 | ΣCF/(1+r)^t | 方向研判（上帝视角） | 现金流与利率都不可知 |

### 常见误用

1. **PE 低就买** —— 可能是价值陷阱（盈利不可持续、行业衰退）。
2. **PE 高就卖** —— 高成长下 PEG 可能很低，杀错好公司。
3. **只看利润不做现金流检验** —— 应收暴增、经营现金流为负时利润是纸面富贵。
4. **用 PB 量轻资产公司** —— 渠道/创意/管理价值在 PB 里完全看不见。
5. **把 DCF 当精确计算器** —— 它是方向框架不是点预测，远端假设一改结果天差地别。
6. **设不可能达到的收益率目标** —— 不先定"要求报酬率"就用 PCF，等于没锚。

## 组合使用

| 场景 | 配方 |
|---|---|
| 初筛个股贵不贵 | **M58-1 PE** → 横向比同业、纵向比自身历史 |
| 成长股估值 | **M58-2 PEG**（先确认 G 是真成长还是叙事） |
| 银行/钢铁/电信等 | **M58-3 PB**（结合破净程度看市场失灵） |
| 检验利润含金量 | **M57 第三步** + **M58-4 PCF**（经营现金流/净利润 是否 <1） |
| 利率上行周期判成长股 | **M58-5 DCF** 方向 + **M47/M56** 利率因子（r↑→现值↓） |
| 看历史估值高低 | **M58 河流图**（五线谱，按估值带不按价格） |
| 财报健康度总检 | **M57** 三表合看（净利润↔经营现金流↔净资产勾稽） |

## 铁律（个股基本面）

1. **三表必须合看**——净利润与经营现金流长期背离，一律视为红灯。
2. **没有一把尺子通吃**——按行业属性选 PE/PEG/PB/PCF，跨行业比 PE 会误判（尤其 A 股高成长拉高 PE）。
3. **价值−价格缺口才是机会**——五种方法给出"内在价值区间"，价格显著低于它 = 市场失灵信号，反之警惕泡沫。
4. **DCF 只做方向，不做点预测**——现金流与利率都不可知，用它定"利率↑则成长股现值↓"这类方向，不报精确价。
5. **G 是预期不是事实**——PEG 与题材逻辑买卖的是"成长兑现"，叙事落空即证伪。
6. **先定要求报酬率再谈估值**——用 PCF 前，先算清会计成本与机会成本（M58-4），否则没有买不买的锚。
7. **示例数字不可当行情**——本文件与来源课程中的具体数字均为教学示例，落地必须用最新财报与市价重跑。
