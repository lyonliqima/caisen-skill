🔵 杨世光 宏观六步法分析

经济周期定位

用美林时钟框架：美国处于"过热→滞胀"过渡期（失业率4.3%低位+CPI 4.2%粘性），中国处于"复苏初期"（CPI/PPI低迷+PMI在50附近徘徊）。这种周期错位意味着：

  • 美国不降息甚至可能加息 → 美元强势 → 中概股估值受压
  • 中国维持宽松 → 流动性充裕但实体经济传导迟滞 → "流动性陷阱"特征

美元周期与资本三流

杨世光视角：全球美元荒格局下，资本流向美国核心资产（美债5%+无风险收益），新兴市场和中概股遭遇"虹吸效应"。阿里作为在美上市中概股，受美元周期直接冲击。当前美元贸易结算份额51%、央行储备占比57%的极强地位尚未动摇。

实质利率对估值的影响

实质利率 = 名义利率 - 通胀预期。当前美国实质利率已转正并上升，直接压制高估值成长股的DCF折现值。阿里虽然P/E仅约10倍（远低于美股科技股），但在加息预期下仍面临估值天花板。

跨市场传导链

油价$95 → 通胀粘性 → Fed不降息 → 美元强 → 人民币承压 → 中概股承压 → BABA股价下跌。但同时，中国通缩环境下人民币实际购买力增强，可能酝酿升值周期，这对以人民币计价的阿里资产是长期利好。

杨世光结论：【谨慎偏多，长期看涨】短期（1-3月）受美元周期和加息预期压制，但中国处于复苏初期+阿里AI转型加速，中长期（6-12月）看好。催化剂：人民币升值确认+Fed降息信号。

🟣 卢麒元 制度结构分析

广义财政三色分析

用卢麒元三色财政框架审视阿里巴巴所处的制度环境：

  • 白色财政：中国政府推动数字经济、AI产业升级，阿里云作为国家AI基础设施获得政策支持
  • 灰色财政：地方政府债务问题 → 国有云/政务云订单受地方财政约束
  • 制度转型信号：中国正从"土运时代"（地租）转向"数字租时代"，阿里作为数字平台龙头将直接受益

资本三流与阿里巴巴

卢麒元视角：阿里巴巴面临独特的"资本三流"格局——
  • 流量：阿里3800亿人民币AI投资计划（3年）是全球最大规模AI资本开支之一，创造巨大货币需求
  • 流向：AI投资→云基础设施→算力采购→资本流向半导体上游（台积电、英伟达等），形成"中国需求→海外供给"格局
  • 流速：自由现金流转负（-¥466亿），说明资本周转速度在加速（投资期），但投资回报尚需时间验证

明斯基融资阶段判断

用M6分析阿里当前融资阶段：FY2026经营现金流¥94亿 vs 去年¥275.2亿（大幅下降），同时自由现金流转负。企业处于"投机性融资→对冲性融资"过渡期——大规模AI投资类似基础设施建设期，现金流短期承压但长期可能产生稳定回报。

卡莱斯基利润分析

总利润 = 投资 + 政府赤字 + 净出口。阿里FY2026 Non-GAAP净利润下降62%，但核心原因不是业务恶化，而是AI资本开支激增（投资项大增）。从卡莱斯基角度看，只要投资能转化为未来现金流，当前利润下降是"建设期"而非"衰退期"。

人民币升值与阿里估值

根据底层逻辑S-I=X-M恒等式，中国贸易盈余必须通过人民币升值来平衡。人民币升值将直接提升阿里人民币资产的美元价值，是中概股估值修复的终极驱动力。

卢麒元结论：【战略看多，等待制度红利】阿里是中国"数字租"时代的核心受益者。短期资本开支压制利润，但3800亿AI投资是在为"下一个十年"铺设护城河。人民币升值将是估值重估的终极催化剂。

M14 资产赛马视角

当前全球金融结构下，阿里处于"中间层被抛弃"的受害者位置——美债5%+安全收益吸引保守资金，AI科技巨头吸引激进资金，而阿里这种"高增长但利润被投资吞噬"的标的被两端抛弃。但随着AI投资进入回报期，这一格局可能逆转。

笨鸟结论：【数据面偏多，等待利润拐点】M1拆解显示：收入结构在改善，云+AI增长强劲，但利润和FCF被投资压制。M4反常信号表明市场过度悲观。类比亚马逊AWS投资期（2012-2015年股价横盘→2016年后爆发），阿里可能正在经历类似阶段。

📐 底层逻辑关联

1. 国民收支恒等式 S-I=X-M

中国巨额贸易盈余（1-5月$4,517亿）→ 超额储蓄S>>投资I → 通缩。阿里作为出口链的"数字服务提供商"，受益于贸易盈余，但通缩环境压制消费需求。解法：人民币升值 → 缩小S-I缺口 → 提升国内消费 → 阿里电商+消费业务受益。

2. 美联储流动性框架

Fed不降息+可能加息 → 净流动性收紧 → 美元荒 → 全球资本回流美国 → 中概股被抛售。阿里股价的38%跌幅，部分反映了这一全球流动性传导。当Fed转向降息时，中概股将迎来估值修复的"水涨船高"。

3. 真金白银vs虚拟财富

阿里3800亿AI投资是"真金白银"投入，但市场将其视为"虚拟财富"（尚未转化为利润）。这体现了"建设期"特征——如同亚马逊AWS投资期，短期FCF为负但长期回报丰厚。

4. 向心坍缩vs美债重置

无论美国走"向心坍缩"（卢麒元）还是"美债重置"（雷倩）路径，中概股都面临短期压力+长期机会：短期美元流动性收紧压制估值，长期美元体系变化可能推动人民币资产重估。
