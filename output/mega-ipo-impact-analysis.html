🔵 杨世光宏观分析 宏观六步法

自上而下：经济周期→货币政策→美元周期→流动性→大类资产→地缘政治

🔵 第一步：经济周期判断——"后期扩张，接近滞胀"

  • PMI：制造业PMI在50附近徘徊，服务业保持扩张但动能放缓
  • GDP：美国Q1 2026增速放缓但仍为正增长，AI投资支撑但消费疲软
  • 就业：非农数据强劲（数量↑），但质量分化——金融/保险被AI替代（↓），政府/石油扩张（↑）
  • 通胀：中东局势推升油价，关税政策叠加→通胀反弹风险升温
  • 判断：经济处于过热期尾声→滞胀期过渡，美林时钟指向"现金/短债"配置窗口

🔵 第二步：货币政策——Fed "棄資管債"框架转型

  • 联邦基金利率：3.50-3.75%，3月会议维持不变，高盛预测年内再降2次至3.00-3.25%
  • 沃什新政：Fed从"供给驱动"转向"需求驱动"流动性框架，RMP渐进缩减（$400亿→$250亿→$100亿/月）
  • 资产负债表：从峰值$8.91T缩至$6.704T，缩表仍在继续
  • r*上升：NY Fed数据显示自然实质利率全球性上升——AI资本需求+财政扩张+国债定价权转移
  • 关键判断：低利率时代彻底结束。IMF戈皮纳特警告：AI企业占投资级债49%、垃圾债38%，利率上升后资产面临重估

🔵 第三步：美元周期——弱势美元+资本争夺并存

  • 美元指数：跌破100至99.49，处于近年低位
  • 矛盾现象：美元走弱但全球资本仍在涌入美国资本市场（"卖场"优势）
  • 去美元化：美元全球贸易结算份额51%、央行储备57%——"不强不弱"
  • 人民币：创新高6.8187，中国对外投资新规收紧资本管控
  • 判断：美元走弱周期利好黄金和新兴市场，但巨型IPO可能短期逆转资本流向

🔵 第四步：流动性分析——"美元荒"与"资产荒"的极端演绎

  • 巨型IPO抽水：$2000亿+一次性抽取 = 2025全年IPO的4.5倍，流动性冲击前所未有
  • Alphabet棄債轉股：$847.5亿股权融资 = 利率已过拐点，企业宁可稀释股权也不加杠杆
  • 指数基金再平衡：SpaceX纳入S&P 500后，万亿级被动资金被迫买入→对现有成分股形成挤出效应
  • Fed缩表叠加：QT继续回收流动性 + 巨型IPO抽水 = 流动性双重收紧
  • 判断："美元荒"加剧，类似2023-2024年但更为极端，一旦触发因素出现→流动性冲击→资产价格剧烈调整

🟣 卢麒元结构分析 制度结构/向心坍缩

广义财政论 × 资本三流 × 明斯基三阶段 × 向心坍缩理论

🟣 第一步：广义财政分析——美国已进入"庞氏融资"阶段

  • 美国国债：~$37万亿，超过GDP的120%，年利息支出~$1万亿（超过国防开支）
  • 明斯基阶段判断：2025年后美国进入庞氏融资阶段——必须借新债还旧债+利息
  • Q1 FY2026赤字：$6024亿，净利息占赤字的44.5%——利息正在吞噬财政空间
  • CBO预测：2036年利息支出将达$2.1万亿，公债占GDP 120%
  • 死亡底线逼近：广义财政/GDP逼近危险区（60-80%），灰黑色财政（军工复合体、隐性担保）扩张

🟣 第二步：资本三流分析——巨型IPO是"向心坍缩"的加速器

  • 流量：$2000亿+IPO + $850亿Alphabet增发 + Meta增发 = 从市场一次性抽取天量流动性
  • 流向：全球资本被迫流向美国科技IPO → 新兴市场资本外流 → "流向逆转"正在发生
  • 流速：指数基金再平衡（SpaceX纳入S&P 500）将触发万亿级被动资金流动，但方向单一→其他资产流速冻结
  • 判断：巨型IPO潮是美元体系"三流逆变"的最新表现，加速全球资本从非美市场回流美国
巨型IPO潮的"三流"传导链： ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 流量：$2000亿+ 一次性抽取 → 全球美元流动性急剧收紧 流向：新兴市场/非美资产 → 美国科技IPO（被迫回流） 流速：指数基金再平衡 → 万亿级被动资金单向流动 → 其他资产"速冻" → 向心坍缩第一阶段特征：流量失控 + 流向逆转 → 如果叠加Fed缩表+利率高位 → 可能触发第二阶段：流动性雪崩

🟣 第三步：卡莱斯基利润公式——AI CapEx撑起利润，但能撑多久？

  • 恒等式：总利润 = 投资 + 政府赤字 + 净出口 + 资本家消费 - 工人储蓄
  • 当前状况：科技巨头AI CapEx（投资）暴增 → 直接推高AI供应链企业利润 → NVIDIA等利润创新高
  • 致命问题：当AI CapEx增速放缓或回报不及预期时 → 投资项急剧萎缩 → 总利润断崖式下降
  • 与Google棄債轉股的关联：企业宁愿稀释股权也要继续投资 → 说明投资回报率已经接近临界点 → 再融不到资就撑不下去

🟣 第四步：费雪债务通缩——AI泡沫破裂的传导链

  • AI公司债务占比：投资级债49%、创投87%、垃圾债38% → AI债务已深度嵌入信用市场
  • 如果AI估值暴跌 → AI公司无法新增债务 → m收缩 → 同时抛售资产 → 抵押品缩水 → 银行惜贷
  • v断崖下降 → P全面下跌 → 债务-通缩螺旋
  • 这与2000年科技泡沫高度相似：Cisco（网络设备）= 今天的NVIDIA（算力设备）

🟢 第一步：数据拆解——巨型IPO的"数量"与"质量"

┌ 数量 ↑ → $2000亿+ 一次性抽取 = 2025全年4.5倍 → 流动性枯竭 巨型IPO ─┤ └ 质量 ↓ → 全是AI/科技公司 → 集中度极端 → 板块风险传染
  • 数量维度：三大IPO合计$2000亿+，Alphabet增发$847.5亿，Meta增发未知 → 总计可能超$3000亿
  • 质量维度：100%集中在AI/科技板块 → Mag7已占S&P500的34.8% → 新增IPO将进一步加剧集中度
  • 结构信号：AI公司占投资级债49%、垃圾债38% → 如果AI板块出问题，整个信用市场都会受冲击

🟢 第二步：降息预期推导

┌ 数量 ↑（IPO抽水） → 流动性收紧 → 等同"隐性加息" → 美元走强 巨型IPO ─┤ └ 质量 ↓（AI集中）→ AI CapEx回报不确定 → Fed观望 → 不降息 非农数据 ─┤ 数量 ↑ → 就业强劲 → 不降息 → 贵金属暴跌 └ 质量 ↓ → 金融/保险↓（AI替代）→ 长期结构性风险
  • 核心判断：巨型IPO的流动性抽取效果等同"隐性加息" → 即使Fed不加息，市场流动性也在急剧收紧
  • 叠加效应：Fed缩表（QT）+ 巨型IPO抽水 + 中东油价冲击 → 三重紧缩
