## 两大核心策略

### 破底翻（做多绝招）

蔡森最推崇的做多策略。主力在底部洗盘，刻意跌破支撑清洗浮筹后迅速收回。

**识别步骤**：
1. 股价在底部区域形成支撑（画出底部颈线/支撑线）
2. 某日带量跌破支撑线（散户恐慌抛售）
3. 随后快速收回到支撑线之上（主力吸筹完毕的信号）
4. 回调不破底部低点 → 确认破底翻成立

**进场时机**：
- 第一个买点：股价翻回支撑线上方时
- 第二个买点（加码）：突破颈线时
- 胜率约70%，适合波段持有

**止损**：若再次跌破底部低点，则破底翻失败，止损出局。

### 假突破（做空绝招）

与破底翻对称的做空策略。股价突破前高后迅速回落，表明突破失败。

> **经典实战案例图**：`images/false-breakout-example.png`
> 图中展示：上升趋势中价格突破紫色颈线冲至142.350后，立即大阴线跌回颈线下方（~118），跌幅约17%，是教科书级假突破诱多陷阱。

**图形视觉特征**：
```
  价格
  150 │              ╭──╮ 假突破高点（142.350）
  140 │    ──────────│──│──── 紫色水平颈线（阻力位 ~131）
      │              │  │
  130 │──────────────┤  ├───────
      │              │  │   ╲
  120 │              │  │    ╲ 大阴线贯穿颈线！
      │              │  │     ╱
  110 │              │  │    ╱
      │    ╭─────────┤  ├──╯
   90 │   ╱          │  │
      └────────────────────────→ 时间

  核心要素：
  ① 趋势背景：明确上升（从100→130+）
  ② 颈线：多次测试的水平阻力位
  ③ 假突破：1根K线超出颈线（8-9%幅度）
  ④ 反转：紧接着1-2根K线大阴线跌回
  ⑤ 结果：跌破颈线后继续下跌
```

**识别步骤**：
1. 股价在头部区域形成阻力（画出颈线）——可以是水平颈线、头肩顶/M头颈线、或上升趋势中的关键阻力位
2. 某日突破前高/阻力线（散户追高买入）
3. 随后快速回落到阻力线下方（主力出货完毕）——**关键：回落速度越快、跌幅越大，假突破越确定**
4. 反弹无法再站上阻力线 → 确认假突破成立

**假突破的量化判定增强**：
| 判定维度 | 假突破信号 | 本案例表现 |
|----------|-----------|-----------|
| 突破幅度 | 超出颈线 > 3% 即可疑 | 超出约 **8.3%**（131→142.35），大幅突破更危险 |
| 回落速度 | ≤5根K线内跌回 | **1-2根K线**即大幅回落 |
| 回落力度 | 跌破颈线 > 3% | 跌破约 **10%**（到118），极强确认 |
| K线形态 | 大阴线/长上影线 | **大阴线**直接贯穿颈线 |

**进场时机**：
- 股价回落跌破颈线时做空（第一卖点/空点）
- 反弹无法站回颈线时加码做空（第二空点）
- **最佳时机**：大阴线跌破颈线的收盘时刻或次日开盘

**止损**：若再次突破并站稳前高上方（如146.6 = 142.35×1.03），则假突破失败，止损出局。

**测幅满足**（基于本案例估算）：
```
height = 假突破高点 - 颈线 = 142.350 - 131 ≈ 11.35
第一满足点 = 131 - 11.35 ≈ 119.65  ← 已接近！
第二满足点 = 131 - 22.7 ≈ 108.3
```

## 期权操作纪律

蔡森反复强调的期权操作铁律：

| 原则 | 说明 | 原因 |
|------|------|------|
| **绝不做卖方** | 不卖Call也不卖Put | 卖方收益有限但风险无限（可能被断头） |
| **只做买方** | 看多买Call，看空买Put | 买方风险有限（最多赔权利金），收益空间大 |
| **选择权卖方=被杀对象** | 盘中一口拉到涨停板就是卖方被断头 | 一次极端行情就能让卖方全部亏损 |

**实战案例**：台股大跌时，卖权（Put卖方）一口被拉到涨停板，成交仅两口就V型反转——这两口就是卖方被强制平仓（断头）。
