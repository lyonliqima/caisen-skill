# 杨世光宏观·通胀定价与政治传导五工具（M93–M97）

> **来源**：杨世光《今年报》2026-10-15 期录音整理稿（ASR 文本）。逐字稿解读、事实核查与纠错见 `examples-1015.md`。
> **性质**：这是**研究方法**，不是观点集合。节目里的方向性判断（「明年油价 130 才撑得住 CPI」「反弹是逃命机会」等）是历史时点的例子，**不可**当当前结论复用。
> **定位**：
> - M93 是**通胀率可持续性的门槛件**——回答「要维持现在的通胀率，关键分项得涨到多少」；
> - M94 是**分项主导权交接的读数件**——回答「现在的通胀是谁在撑、下一棒谁接」；
> - M95 是 M89（资产通胀的政治传导）的**油价对偶件**——M89 管「股价涨→失票」，M95 管「油价涨→失票」，两者合成价格—选票双通道；
> - M96 是**事件驱动型方向转折的第一性判读件**——管「数据利空出尽」的那一刻，与 M13（定价消化）、M58（曲线四象限）构成三级；
> - M97 是**供给侧通胀的归因件**——把杨世光「资本被占用、资源被浪费」的口头总纲转成可证伪判据。
> **顺序**：判通胀方向先跑 M94（谁在撑）→ M93（门槛在哪）→ M97（是需求还是错配）；判事件交易先跑 M96，再看 M58 曲线形态。

## M93：通胀门槛倒推法

> **要维持现在的通胀率，不是「油价别跌」，而是「油价要涨回同样的幅度」——门槛由篮子权重决定，不由上游价格直接决定。**
> 节目核心句：「年增率要维持 3.74% 的年增率，代表明年油价至少在 130 块以上；只要在 130 块以下，基本上美国 CPI 就会放缓——因为这是个增速逻辑。」

### 核心原理

```
第一步：目标方程
  CPI 同比 = Σ (分项权重 wᵢ × 分项同比 yoyᵢ)          …各分项不变时
  要维持 CPI 同比 = R₀ → 各分项同比须大体维持原值
  ⇒ 关键分项「所需同比」≈ 该分项「当期同比」（不是它的上游价格同比）

第二步：分项内部拆篮子（这一步最容易漏）
  能源 CPI ≠ 原油同比。美国 CPI 能源分项近似构成：
    汽油 ≈ 49% ｜ 电力 ≈ 36% ｜ 公用燃气 ≈ 11% ｜ 燃油 ≈ 3%
  电力/燃气与原油几乎不联动（当期电力同比仅 +2~3%）
  ⇒ 要复现「能源 CPI 同比 +20.4%」，几乎全部压力压在汽油身上

第三步：单品对上游套弹性
  汽油零售同比 ÷ 原油同比 = 传导弹性 k
  （本次实测：34.2% ÷ 44.7% ≈ 0.77，含税、炼油价差、零售滞后）
  ⇒ 所需原油同比 = 所需汽油同比 ÷ k

第四步：换算成价格水平
  所需上游价格 = 当期上游价格 × (1 + 所需原油同比)
```

### 本次实测（2026-10-15 口径）

| 步骤 | 数值 |
|---|---|
| 当期 WTI | 90.34 美元（去年 9 月 62.43，同比 +44.7%） |
| 能源 CPI 同比 | +20.4%，权重反推 ≈ 7.35%（贡献 1.50pp ÷ 20.4%） |
| 能源对总 CPI 贡献 | 1.50pp / 3.7% = **约四成** |
| 要维持 CPI 3.7% | 能源同比须维持 +20.4% |
| 汽油需同比 | 0.52·g + 1.41pp（电/气残项） = 20.4 → g ≈ **+36.5%** |
| 原油需同比 | 36.5% ÷ 0.77 ≈ **+47.7%** |
| **门槛价** | 90.34 × 1.477 ≈ **133 美元** |

**反向门槛（更有用）**：CPI 同比要跌破 3.0%，能源贡献需 ≤ 0.8pp → 能源同比 ≤ +10.9% → 汽油同比 ≤ +14.8% → WTI 同比 ≤ +19.3% → **WTI ≤ 约 108 美元**。

### ⚠️ 使用纪律

1. **禁止用上游价格同比直接替代 CPI 分项同比**。两者差一整个篮子结构：能源 CPI 篮子有一半是电力/燃气，当期几乎零涨。直接把「WTI 同比 +45%」当成「能源 CPI 同比」会让门槛口径错位。
2. **禁止用整篮子弹性能平移**。0.46（能源 CPI ÷ WTI）是**篮子构成效应**而非传导弹性，它只在电/气维持零涨时成立；真正可平移的是汽油对原油的弹性 k ≈ 0.77。
3. **门槛是「增速门槛」不是「价格门槛」**——它随基期滚动。明年 9 月算一次要重新取基期，不能把 133 当长期点位用。
4. 门槛法只回答「通胀能不能自己掉下来」，**不回答「掉下来对资产是利好还是利空」**——后者要接 M96/M44。

> **本次反面教材（Agent 自纠）**：本工具建立过程中，曾把「能源 CPI 同比 20.4%」直接当作对 WTI 的传导率（弹性 =1），推出门槛 108–115，并据此判节目「130–135 说高了」。**错在跳过第二步篮子拆解**。按正确四步法重算得 ≈133，与节目口径一致。**结论：本期「130–135」这个数是站得住的，错的是过程没交代、且与他自己给的 20.4% 并列时无法自洽。**

## M94：CPI 分项主导权交接判读法

> **通胀是一个「接力赛」：先看谁在带队，再看谁接了棒。**
> 节目核心句：「能源项目在年增率当中贡献了将近 1.4%，快一半；扣掉食品能源的核心商品，创下 13 个月新高——**是接棒**。」

### 核心原理

```
对每个分项算三件数：
  ① 权重 wᵢ（BLS 相对重要性）
  ② 当期同比 yoyᵢ
  ③ 贡献 ppᵢ = wᵢ × yoyᵢ    ；对总同比的占比 = ppᵢ ÷ 总同比

判读表：
  单分项贡献占比 > 40%          → 单一分项主导（脆弱：该分项一转向，通胀立刻换脸）
  主导项环比动能转弱 + 
  次分项环比创 N 月新高         → 「接棒」成立，通胀从事件驱动转黏性驱动
  各分项环比齐升、无单一主导     → 广泛性通胀（最难对付，政策必须更紧）
```

**为什么「接棒」比「高通胀」更可怕**：单一分项主导（如能源）是**可逆的**——地缘一缓和就掉；一旦接力棒交到核心商品/服务手上，就变成**不可逆的黏性**，因为它由工资—成本、租金、产业错配驱动，货币政策效果最差。

### 本次实测（2026-09 美国 CPI）

| 分项 | 环比 | 同比 | 对 3.7% 的贡献 | 判读 |
|---|---|---|---|---|
| 能源 | +5.2% | **+20.4%** | **1.50pp（40.5%）** | 主导项（可逆，地缘驱动） |
| 其中汽油 | +9.1% | +34.2% | 单项贡献环比过半 | 主导中的主导 |
| 核心商品 | **+0.3%**（前值 +0.1%） | +0.7%（持平） | 边际支撑 | **接棒候选**：二手车 +0.7%（连三月）、服装 +0.3%、电脑/外围 +1.4% |
| 核心服务 | +0.4%（前值 +0.3%） | +3.1% | 最黏 | 黏性底盘：OER +0.3%、外出住宿 +2.3%（连两月）、运输服务 +0.6%、机票同比 +22.4% |
| 食品 | 0.0% | +2.5% | 中性 | 不参与 |

### ⚠️ 使用纪律

1. **必须同时报环比与同比**。节目只说「核心商品创 13 个月新高」——那是**环比**口径；同期核心商品**同比持平于 0.7%**。只说环比会夸大接棒进度。
2. 单看一个分项环比不足以下「接棒」判定，须三验：**环比连升 ≥2 月 + 同比转头 + 传导来源可指认**（本次可指认来源：关税传导完毕后的商品端价格动能修复 + 能源向运输服务二次传导）。
3. 权重取 BLS 官方相对重要性，**不要反推**：用「贡献 pp ÷ 分项同比」反推权重会受指数构造影响（本次反推 7.35% vs 节目口径 7.78%，由此节目算出的贡献 1.59pp 高于官方 1.50pp）。
4. 与 M19（通胀内外申分层）分工：**M19 判「这一波是哪来的」，M94 判「这一波由谁在撑、还能撑多久」**。

## M95：油价—选票政治反馈闭环法

> **产油对手把油价当选举武器：油价涨 → 惩罚对方选民 → 选民惩罚执政党。**
> 节目核心句：「伊朗很聪明，透过油价走高惩罚美国消费者，再透过美国选民来惩罚川普……这就是透过价格讯号来影响消费者，之后转化成选票的流向。」

### 核心原理

```
闭环四段：
  ① 地缘对手主动制造供给扰动（不是被动战争外溢）
  ② 油价上行 → 加油价/柴油/运费 → 美国消费者体感恶化
  ③ 体感恶化 → 支持率下降 → 执政党中期选举失票
  ④ 执政党为避免失票 → 反压油价（释放储备/施压停火/松绑对手出口）

判别「武器化」的两个硬标志：
  A. 对手自述。凡对手公开声明「目的是影响对方选举」→ 直接认定武器化，无需推断
  B. 时间对齐。扰动密度是否在选举日临近时抬升（攻击次数/单周事件数斜率）
```

### 本次实测（2026-10-15 口径）

| 环节 | 证据 |
|---|---|
| ① 主动制造 | 10 月以来霍尔木兹及周边 ≥24 艘船遇袭，**超 9 月全月**；10/14 一艘载 2500+ 箱货轮触雷沉没 |
| ② 价格 | WTI 90.86、布伦特 103.02；美国全国汽油均价 4.33 美元/加仑（战前 2.98）；柴油 >6.25 美元/加仑（9 月下旬创历史新高） |
| ③ 体感 | 实际时薪同比 **−0.7%，连续第六个月下降**；密歇根消费者信心进一步恶化；益普索：约 78% 美国人归咎于关税与美伊战争 |
| ④ 反压 | 特朗普 10/11 宣布俄乌「能源停火」；10/12 起对乌施压（威胁停情报共享、星盾限速）；同时维持对伊朗港口海上封锁 |
| **A 标志** | ✅ 伊朗高级官员**自述**：正部署新战术打击海峡船只，以「维持油价高位并影响美国中期选举」——武器化获对方亲口确认 |

### ⚠️ 使用纪律

1. **不要用「美国汽油价」单指标判闭环成立**——须与支持率/信心指数配对；价格是手段，选票才是目的。
2. **选举日前后闭环会反转**：对手的动机在投票日之后消失，油价的地缘溢价会快速衰减。**选举日 = 溢价到期日**，不是风险持续期。
3. 与 M89（资产通胀的政治传导）合并使用：**M89 管股市通道（资产涨→保守派失票→政策反噬），M95 管油价通道（物价涨→全体失票→政策反压）**。两条通道同时激活时，「政策立刻转向」的概率最高。
4. 与 M52/M88 的时间尺度纪律一致：**选举是数月尺度，不得用来推单周价格**。

## M96：长端「利空不跌 / 利多不涨」转折判读法

> **数据是利空、长端价格却收涨——这不是噪音，是市场对「加息终点」开始定价的第一声。**
> 节目核心句：「CPI 超出预期叫利多不涨……尤其 30 年期，收盘全线跌破。对于债券价格来讲，第一次尤其在中长天期碰到利空不跌——**利空不跌找买点**。」

### 核心原理

```
事件（数据/讲话）与长端收盘方向的关系矩阵：

  事件对债【利空】 → 收益率应上行（价格跌）
      └ 结果「收盘仍下行（价格涨）」 = 利空不跌 = 债市买点第一信号
  事件对债【利多】 → 收益率应下行（价格涨）
      └ 结果「收盘仍上行（价格跌）」 = 利多不涨 = 债市卖点第一信号

为什么必须是【收盘】而不是【盘中】：
  盘中反应的是算法与情绪（第一层），收盘价才包含真实承接盘（第二层）。
  只盘中背离 = 噪音；盘中冲高 + 收盘翻向 = 结构。
```

### 判读三档

| 档 | 判据 | 含义 | 动作 |
|---|---|---|---|
| **单次** | 一次事件后，中长端（7Y/10Y/20Y/30Y）多数收在反向 | 疑似转折，样本不足 | 记录，不动手 |
| **第二次** | 同类事件再现同向背离（如两次 CPI／两次 FOMC） | **转折成立** | 债券偏多成立，股票端同步下调风险偏好 |
| **第三次** | 连续三次背离 + 曲线形态确认（转牛平/牛陡） | 加息周期定价结束 | 按 M58 曲线四象限切换配置 |

### 本次实测（2026-10-14 美国 9 月 CPI 后）

| 期限 | 盘中峰值 | 收盘 | 收盘变动 |
|---|---|---|---|
| 5Y | 5.153%（2007 年来最高） | 4.994% | **−1.44BP** |
| 7Y | — | — | **−2.16BP** |
| 10Y | 5.3272% | 5.1854% | **−2.30BP** |
| 20Y | — | 5.5729% | **−3.00BP** |
| 30Y | — | 5.5231% | **−3.38BP** |
| 2Y | 4.9499% | 4.7975% | +0.84BP（唯一收涨） |

**读数**：CPI 全面超预期（利空债），但**中长端全部收在反向，且越长越明显（30Y 最强）** → 第一信号成立。短端（2Y）仍收涨，说明**政策路径预期未变，变的是久期偏好**——市场开始要求「更长期限的确定性」，而非「更低的政策利率」。这是熊平转牛平的早期特征。

### ⚠️ 使用纪律

1. **单次背离不得直接建仓**，必须等第二次同向背离（节目自己也说「等第二个讯号」）——本条是纪律不是修辞。
2. 判背离前先扣掉**供给因素**（当日是否有国债拍卖/发行），否则会把「供给冲击」误读为「需求转折」（接 M79/M80）。
3. 区分「长端不跌」与「短端不跌」：**长端不跌 = 转折信号；短端不跌 = 只有降息预期才有意义**。本次短端收涨、长端收跌，属前者。
4. 与 M13（利率市场定价消化）分工：M13 量**数据前后隐含利率的变化幅度**（定价了多少）；M96 量**方向是否被否决**（定价是否失效）。M13 先，M96 后。

## M97：资源错配型通胀验证法

> **把「资本被占用、资源被浪费」从口头总纲，做成能证伪的判据：当需求端被独立证据排除后，价格还在涨，就只能归因供给端被占用。**
> 节目核心句：「需求是没有的……那为什么价格走高？那就供给面出问题了。大量的供给被某一个东西给吸走了——**资本被占用、资源被浪费**。」

### 核心原理

```
物价 = 供需均衡点。价格走高的解释只有两个来源：

  ① 需求端驱动 → 应有伴随证据：零售销售↑、必需消费股↑、实际工资↑、周转率↑
  ② 供给端驱动 → 应有伴随证据：必需消费股↓、实际工资↓、核心商品价格↑、产能投放延迟

排除法（本工具的核心动作）：
  若「需求端证据」全部为负，而「价格」为正 → 需求端解释被否决
  ⇒ 剩余唯一解释 = 有效供给不足
  ⇒ 有效供给不足若非产能/技术原因 → 只能是要素被其他部门占用
  ⇒ 判定「资源错配」，并追问：被谁占用？占用是否可持续？
```

### 验证三件（缺一不可验）

| 件 | 看什么 | 本次实测（2026-09~10） |
|---|---|---|
| ① 需求端对照 | 必需消费渠道股价、实际工资、零售量 | 实际时薪同比 **−0.7%（连续第 6 个月负）**、周薪环比 −0.5%；必需消费类股价走弱 → **需求端解释被否决** |
| ② 价格端 | 核心商品环比、涨价的品类分布 | 核心商品环比 +0.3%（前值 +0.1%）、二手车连三月 +0.7%、服装 +0.3%、电脑/外围 +1.4% → 价格端为正 |
| ③ 占用方对账 | 谁在大规模提走资本与产能 | AI 资本开支：台积电 2026 资本支出 600–640 亿美元、2026–2028 显著高于过去三年；CoreWeave 单家负债+租赁 520 亿美元 → **占用方 = AI 资本开支** |

**结论格式**：① 为负 + ② 为正 + ③ 可指认 → 「资源错配型通胀」成立。三条中缺任一，退回「需求驱动」或「不可判定」。

### ⚠️ 使用纪律

1. **本工具只做归因，不做估值**。「资源错配」不等于「相关资产要跌」——占用方在错配被纠正前仍可能继续上涨（本轮台积电同日法说会交出超预期指引即为例）。
2. **必须做占用方对账（第③件）**。「错配」如果没有可指认的占用方，就是叙事而非判据。
3. **与 M76 分工**：M76 描述**链条**（资本财价格→要素争夺→服务 CPI→被迫升息）；M97 提供**判据**（如何证明这是错配而非需求）。先 M97 定性，再 M76 推链条。
4. 与 M86/M87 组成实物侧三校验：M86 判当期价格真假、M87 判物理可行性、M97 判价格上行的归因。
