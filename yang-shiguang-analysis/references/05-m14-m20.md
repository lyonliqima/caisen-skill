## M17：MSCI风格因子輪动法

> 不同利率环境下，表现最好的风格因子截然不同。

### 四种利率情境

| 情境 | 含义 | 最优风格 | 最差风格 |
|------|------|----------|----------|
| 熊平（Yield Flat） | 收益率曲线平坦，经济放缓 | 高股息、低波动 | 成长、动量 |
| 熊陡（Yield Steep） | 长端利率上升，经济复苏 | 价值、等权重 | 高股息 |
| 牛平（Rate Cut Flat） | 降息周期，曲线平坦 | 成长、动量 | 价值 |
| 牛陡（Rate Cut Steep） | 降息+经济强劲 | 品质、增强价值 | 低波动 |

### 实战应用

- 当前环境（2026/6）：Fed不降息 + 长端利率上升 → “熊陡”情境
- “熊陡”环境下：价值股和等权重股表现优于成长股
- 含义：科技股/成长股承压，传统价值股/高股息股相对抗跌

# M18：黃金-利率相關性週期法

> M11看R²强度变化，M18看相关性**符号翻转**——这是更深层的超级周期信号。

### 核心逻辑

```
黄金 = 零息资产（Zero Coupon Bond）
持有黄金的机会成本 = 实质利率

正常状态：黄金与实质利率 = 负相关（利率↑→金价↓）
异常状态：黄金与实质利率 = 正相关（脱钩=泡沫信号）
```

### 相关性符号翻转周期

| 时期 | 相关性 | 驱动 | 后续结果 |
|------|--------|------|----------|
| 1970s~1980s中 | 负→正（脱钩） | 石油危机+通胀失控，黄金脱离利率定价 | 黄金沉寂20年才解套 |
| 2024~2025 | 负→正（脱钩） | 去美元化+央行购金+投机炒作 | 金价冲至$5,662 ATH |
| 2026 | 正→负（回归） | 实质利率重新主导定价 | 金价吐回涨幅至$4,200附近 |

### 判断规则

- **负相关→正相关（脱钩）** = 泡沫顶峰信号，市场与价值脱钩，投机买盘压倒利率逻辑
- **正相关→负相关（回归）** = 泡沫消退信号，黄金重新被利率定价
- **脱钩后等待期**：历史参照15~20年（上一次70年代脱钩后等了20年）
- **应用**：判断当前黄金是"利率驱动的合理价"还是"投机泡沫价"

### 与M11的协作

- M11：每年跑回归看R²强度 → 判断"黄金是否还跟利率走"
- M18：跨年代看相关性符号翻转 → 判断"黄金处于超级周期的哪个阶段"

## M19：通脹內外申變量分層法

> 通胀不是单一来源，必须拆分为"内生"和"外生"两层驱动力。

### 分析框架

```
通胀驱动力 = 内申变量 + 外申变量

内申变量（内生，结构性）：
  菲利普曲线机制：低失业率 → 工资增速↑ → 消费力↑ → CPI↑
  特征：持续性强，难以用货币政策以外的手段压制

外申变量（外生，冲击性）：
  ├── 油价冲击：中东冲突 → 供给中断 → 能源价格↑
  ├── 全球化逆转：效率低成本 → 安全高成本（关税/脱钩/友岸外包）
  └── 地缘风险：战争/制裁 → 供应链中断 → 物资短缺

关键判断：
  内申+外申同时升温 → 通胀压力远超单一来源
  内申降温+外申升温 → Fed陷入两难（菲利普曲线 vs 供给侧冲击）
```

### 实战应用（2026/6）

- 内申变量：失业率4.2%低位 → 工资增长强劲 → 菲利普曲线推力大
- 外申变量：伊朗冲突→油价$95、关税→全球化成本、红海封锁→航运成本
- 结论：**内外夹攻**，通胀粘性远超市场预期，Fed不降息甚至加息的逻辑基础

### 与M12的协作

- M12菲利普曲线：定位"失业率×CPI"在哪个象限
- M19内外申分层：拆解CPI的来源结构，判断通胀是"内生过热"还是"外生冲击"还是"内外夹攻"

## M20：賣鏟人vs賣慘人分化分析法

> 在科技产业周期中，区分"卖鏟人"（供应链上游/基础设施提供商）和"卖慘人"（中下游应用/平台商），是判断泡沫集中在哪个环节的关键工具。

### 核心逻辑

```
淘金热类比：
  賣鏟人 = 提供挖金工具的人（稳赚不赔）
  賣慘人 = 挖金矿的人（大部分失败）

AI产业链类比：
  賣鏟人 = 半导体代工/存储器（台积电、SK海力士、三星）
  賣慘人 = AI大模型/应用层（美科技七姐妹中的中下游）
```

### 分析模板

```
□ 比较賣鏟人 vs 賣慘人的FCF绝对值和FCF/Sales比率
□ 比较两组指数/个股的年初至今回报率差异
□ 判断分化是否在扩大（賣鏟人持续吸金）还是在收敛（利润开始向下游转移）
□ 关注"Intel代工复活"等信号 = 賣鏟人竞争格局变化
□ 当AI大模型找不到B端/C端商业模式时，现金流向上游集中 = 泡沫集中在賣鏟人
```

### 实战案例（2026/6/9）

| 指标 | 賣鏟人（亚洲三雄） | 賣慘人（美科技七姐妹） |
|------|-------------------|-------------------|
| 2027e FCF | ~$5,000亿 | 与三雄接近但增速更慢 |
| FCF/Sales | **38.8%** | 14.2% |
| 费半指数YTD | **+82.2%** | +3.74%（七姐妹指数） |
| NVIDIA YTD | +11.9% | — |
| Intel YTD | **+199%** | — |

### 关键判断

- **分化扩大** → 泡沫集中在上游供应链，中下游估值被压缩
- **Intel代工复活**（Google 300万片TPU、Apple全线、NVIDIA验证18A）→ 賣鏟人格局从"亚洲三雄垄断"向"四方竞逐"转变
- 亚洲三雄吸金能力若持续扩大 → 加剧全球美元不平衡
