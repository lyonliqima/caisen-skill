## 分析后置动作

**自选股管理**：十二专家分析完成后，将核心推荐标的自动加入自选股跟踪
```bash
python3 mx-zixuan/mx_zixuan.py add "贵州茅台"
```

**模拟组合验证**：当十二专家给出明确建议时，可用模拟组合验证
```bash
python3 mx-moni/mx_moni.py "我的持仓"
python3 mx-moni/mx_moni.py "买入 600519 1200 100"
```

**社区发布**：分析完成后可将核心观点发布到东方财富社区
```bash
python3 mx-poster/mx_poster.py post --title "..." --text "..."
```
