# 蔡森形态学技术分析方法论

> **核心定位**：这是一套**研究方法**，不是观点集合。每次分析时，按方法论独立推导结论。蔡森本人的观点只是方法论的实战示例。

## 工作流程 / 使用步骤

当用户要求分析某标的走势时，按以下步骤进行：

### 第一步：识别当前所处形态

从K线走势中识别属于哪类形态：

**底部形态（做多信号）**：
| 形态 | 识别特征 | 确认条件 | 量化confidence |
|------|----------|----------|---------------|
| W底（双底） | 两次探底，第二次不低于第一次太多 | 放量突破颈线（两底之间的高点） | 65→80（放量） |
| 头肩底 | 左肩→头（更低）→右肩（高于头） | 放量突破颈线 | 75→85（放量） |
| V底 | 急跌后急涨，无明显底部横盘 | 反转伴随巨量 | 60（难以量化） |
| 圆弧底 | 缓慢弧形筑底，时间较长 | 突破圆弧顶部水平线伴随放量 | 70 |
| 三重底 | 三次探底，底部接近 | 放量突破颈线 | 75→85 |
| 矩形底 | 长时间底部横盘震荡 | 放量突破矩形上沿 | 70 |
| **破底翻** | 跌破支撑后快速收回 | 3日站稳 + 带量翻回；**支撑在成本区下沿不在破底低点**；破底幅度 3%-10%（>15% 多为真跌） | 60→75（站稳）/ 无量翻回 35 |

**头部形态（做空信号）**：
| 形态 | 识别特征 | 确认条件 | 量化confidence |
|------|----------|----------|---------------|
| M头（双顶） | 两次冲高，第二次未能有效突破第一次高点 | 跌破颈线（两顶之间的低点） | 65→80（确认跌破） |
| 头肩顶 | 左肩→头（更高）→右肩（低于头） | 跌破颈线 | 75→85 |
| 斜颈线头部（上升楔形头部） | 顶部区域低点递升形成斜颈线，高点无力创新高 | 跌破斜颈线（上升趋势线） | 70→85（放量跌破） |
| 圆弧顶 | 缓慢弧形见顶 | 跌破圆弧底部水平线 | 70 |
| **假突破（出货末端）** | 高档区间盘整后向上突破前高/颈线，数日内灌回颈线之下 | **必须先确认该轮涨幅≥100%**（13例实测中位+137%）→ **突破周放量**（中位1.45倍）→ **跌破颈线才算确立**（不许光看突破就判定）；实测跌10%中位仅1周 | 75→88（确立后）/ 未翻倍或2周未跌回 → 降级35 |

**中继形态（趋势延续）**：
| 形态 | 识别特征 | 操作方向 | 量化confidence |
|------|----------|----------|---------------|
| 旗形整理 | 急涨/急跌后小幅反向平行通道整理 | 突破旗形方向延续原趋势 | 65→75 |
| 三角收敛 | 高点递降、低点递升，波动收窄 | 向上突破做多，向下突破做空（**突破须落在总宽度 1/2~3/4 处**，末端突破大概率失败并反向） | 55→70（1/2~3/4 处放量突破）/ 末端 30 |
| 矩形整理 | 水平区间震荡 | 突破方向跟随 | 70 |

### 第二步：画颈线

颈线是形态分析的灵魂：

1. **底部形态颈线**：连接形态中的反弹高点，形成阻力线。突破颈线 = 多头确认。
2. **头部形态颈线**：连接形态中的回踩低点，形成支撑线。跌破颈线 = 空头确认。
3. **颈线可以是水平线或倾斜线**，取决于反弹/回调的具体价位。

### 第三步：验证量价关系

量价配合是确认形态有效性的关键：

| 场景 | 量价要求 | 含义 |
|------|----------|------|
| 突破颈线（多头） | 放量突破 | 突破有效，可进场做多 |
| 突破颈线（多头） | 缩量突破 | 突破可疑，可能假突破 |
| 跌破颈线（空头） | 可放量也可不放量 | 跌破即有效，不需量确认 |
| 回踩颈线 | 缩量回踩 | 健康回调，可加仓 |
| 上涨过程 | 量增价涨 | 趋势健康 |
| 上涨过程 | 量缩价涨 | 上涨乏力，警惕 |

### 第四步：计算测幅满足（目标价位）

测幅满足用于预估行情目标位，制定止盈计划：

**底部形态测幅**（做多目标）：
```
目标价 = 颈线价格 + 形态高度
形态高度 = 颈线价格 - 底部最低点价格
```

**头部形态测幅**（做空目标）：
```
目标价 = 颈线价格 - 形态高度
形态高度 = 顶部最高点价格 - 颈线价格
```

**特殊测幅规则**：
- 三重底/矩形底：可用矩形高度计算
- 头肩底：也可用头部到颈线距离的1.5~2倍估算
- 旗形：旗杆长度 = 突破后预期涨幅
- 月线大级别形态：满足幅度更大，可信度更高
- **M头/头肩顶两波跌幅满足**：第一波跌幅H=形态高度（顶→颈线），第二波跌幅=从颈线再投射H，两波等距即"满足"。第一满足点=颈线-H，第二满足点=颈线-2H。到达第一满足点后可能反弹整理，到达第二满足点后跌势大概率尾声
- **收敛三角形底部涨幅满足（右侧目标，2026-10-29 新增）**：`边长 = 三角左端第一组高低点之差`（主力作价区高度；取"整体极值"会差 66%），`第一波 = 实际突破点 + 边长`，`第二波 = 第一波满足点 + 边长`。⚠️ **三个精度点**：① 边长只从**左端起点**量，不从突破K线量、不取三角最大跨度；② 突破点用**实际穿线价**，不是三角顶点——斜颈线时顶点法会高估 10% 以上（工行：2.95+2.2=5.15 命中 5.23；3.5+2.2=5.7 永不达）；③ **目标×0.98 就减第一批**，5 例实测超涨 −2.8%~+8.8%（均值 +2.2%），等精确点会漏掉提前回落的票。**最多算两波**（5 例两波兑现 3 例）；**只涨一波就跌破突破位 = 假突破，必减码**（网宿科技 −89% 反例）；突破须在总宽度 **1/2~3/4 处**，末端突破大概率反向（原因：突破点已到低位，`突破点+边长` 目标太低，主力没做价空间）。复权口径必须锁定（高分红股今日前复权早期价为负，边长不可算）。完整规则/5 例复算/真实数据核验见 `references/收敛三角形-底部涨幅满足-20261029.md`
- **收敛三角形头部跌幅满足（右侧目标·做空，2026-10-30 新增）**：**与底部完全镜像**——`边长 = 三角左端第一组高低点之差`（同一纪律），`第一波 = 实际跌破点 − 边长`，`第二波 = 第一波满足点 − 边长`。⚠️ **头部专属要点**：① 跌破必须落在总宽度 **1/2~3/4 处**（末端跌破反向，不追空）；② **停损设在颈线（线）上面**——上方套牢卖压保护空头，做错有从容时间补回；③ **上飘旗=空头中继站 / 下漂旗=多头中继站**（汇川技术案例明示，中继形态鉴别）；④ **只跌一波判定**：`破线价−边长 ≤ 0` 时第二波不可算，第一波到位即收（例：12.6−8=4.7，再减为负）；⑤ **满足点是反弹点不是铁底**——东方/亨通/科大讯飞讲义"实际最低"被后续股灾深穿，系统性崩盘会远低于目标，满足点先减。5 个命名 A 股案例已用新浪不复权日线交叉核验（温氏/汇川实测落在 T1/T2 区间；东方/亨通/科大讯飞待按原图复算）。完整规则/案例复算/核验脚本见 `references/收敛三角形-头部跌幅满足-20261030.md`
- **波段涨幅满足（右侧止盈，2026-10-29 新增）**：`D = 第一波高点B − 起涨低点A`，`目标 = 整理低点C + D`。**必须越过前高 B 才算**（否则 C 不成立，"每个地方都是低点"）——与跌幅满足镜像。⚠️ **起算基准是整理低点 C，不是突破点**（突破点是收敛三角边长法的基准，两者不是同一段）。12 例实测：精确命中 3 例（中行 4.69、平安 75.85 误差 0.00%）、±2% 内 7 例、平均绝对偏差 2.6%，**偏差单向超涨（无一例欠涨超 2%）** → 目标×1.00 减第一批、留一半到 ×1.05。**第一波涨幅 <20% 表示主力作价失败，不要等第二波**。满足点后标准剧本是假突破（逃顶神招）。完整规则/12 例复算/主力作价习性见 `references/波段涨幅满足-20261029.md`
- **波段跌幅满足（左侧抄底定位，2026-10-29 新增）**：任何「下跌 A→B → 反弹到 C → 跌破 B」结构，第二波跌幅 = 第一波，**满足点 = C − (A−B)**，其中 C 是**破线后确认的反弹高点**（不破前低不算）。⚠️ 投影基准是 **C 不是颈线**，两者不等价（实测颈线法会低估 20%~50%，导致永远等不到价）。8 例实测偏差：目标≥25元 1.0% / 目标<12元 5.6%，**必须给区间分批进，不挂单死等**。完整规则、容差表、三种例外（破底翻优先 / 期货改买权 / 基本面差无效）见 `references/波段跌幅满足-20261029.md`

- **卖铲人与泡沫顶判定（2026-11-14 新增·跨周期定位）**：`股东回报 = EPS增长 − PE收缩`（思科：EPS+700%、PE 200→20 倍、乘积≈0，2000/3/27 收 80.06 → 2002/10 低 8.12（−87%）→ **2025/12/10 才首次收出 80.25，25 年 8 个月**）。**卖铲人收入 = 下游 capex，应用端变现迟 4–6 年**（思科顶 → Google 2004 上市 → Meta 2012 上市），故「卖铲人崩」是「应用端起飞」的**前置条件而非同时发生**；卖铲人内部「独占者→替代者」的转移是**周级别可交易**，卖铲人→应用端是**年级别只能配置**。**两种死法必须分开**：思科死于**估值**（慢、公司能活），朗讯死于 **vendor financing**（`(对客户投资+应收+担保)/营收` 持续上升 = 朗讯路径，84 美元→1 美元以下，不可逆）。**上缘做否定判据**：破颈线 → 反弹 → **不过整理区上缘 = 头部成立**（看跌幅满足）；过得上缘 = 假跌破回补原判断。颈线是必要条件、上缘是充分条件、量是确认，**只过第一层就是陷阱**。**大盘空头/横盘时破底翻胜率仅 50%（多头才 70–80%）**，此时唯一有正期望的动作是**假突破做空**，不是抄底。⚠️ **等幅外推不得跨品种滥用**：型态给位置、估值给空间，两套逻辑不可混用（NVDA 颈线等幅外推得 54 美元，与其 13 倍前瞻 PE、63.7% 净利率矛盾）。完整规则/思科三段时间轴/PE 预支年数速查/压低出货陷阱/语音转录纠错表见 `references/卖铲人与泡沫顶判定-20261114.md`

> **⚠️ M头/双顶 跌幅满足修正（两头顶中点法，用户 2026-07-08 手把手纠正，蔡森教学图验证）**
> 上方「M头 H=顶→颈线」是**头肩顶**算法，不能直接套到 **M头/双顶**。M头必须用**两头顶中点**测 H：
> - **MID = (头1 + 头2) / 2**（左峰与右峰价格的中点）
> - **H = MID（中点） − 颈线**
> - 第一波满足 = 颈线 − H ；第二波满足 = 满足1 − H = 颈线 − 2H（两波等距）
> - 教学图验证：两头顶 100/110 → MID=105，颈线 80 → H=25 → 满足1=55、满足2=30（与蔡森图示完全吻合）
> - 实战案例（BABA 9988.HK）：头1=186.2、头2=174.2、颈线=140 → MID=180.2、H=40.2 → 满足1=99.8、满足2=59.6
> - 易错点：❌ 用绝对最高点（左峰）单测 H（高估 H，目标价偏低）；❌ 用较低峰（右峰）单测 H（H 偏小）；✅ 必须 (头1+头2)/2。头肩顶才是「头部最高点−颈线」，别混。
> - 配色：颈线黑、双顶连线红、两头顶中点紫(点线)、H蓝竖线、两波满足绿(实/虚)。

> **⚠️ 颈线法 vs 反弹高点法：先看 C 是否等于颈线（2026-10-29 实测修正）**
> 「颈线−H」只在**反弹高点 C ≈ 颈线**时成立。若破线后的反弹明显超出颈线再回落（C > 颈线），必须改用 **满足点 = C − H**（C 为反弹高点）。
> - 实测反证（江丰电子 2017-11~2018-02，真实日线）：A=88.13、B=53.96 → H=34.17；C=73.44。
>   `C−H = 39.27` → 实际最低 39.01 ✅ ；`颈线(B)−H = 19.79` → 相差 50% ❌
> - 三例一致：比亚迪低估 20%、江丰II 低估 27%。**目标价算太低 = 抄底单永远等不到价**，比算太高危险。
> - 判定口诀：**先画 C（破线后反弹高点），C 落在颈线上就用颈线法，C 高出颈线就用 C 起算。**

### 第六步：散户与大户资金流动分析（强制）

> ⚠️ **每次分析股票时必须执行此步骤，不可跳过。** 形态看的是"价格走到哪了"，资金流看的是"谁在推动价格"。两者矛盾时，资金流往往是先行信号。

**分析逻辑**：蔡森反复强调，散户是行情的反向指标（散户疯狂=见顶，散户恐慌=见底），大户/外资是行情的主导力量。必须同时看两边才能判断当前处于"养→套→杀"的哪个阶段。

**必须搜索的资金流动数据**：

| 类别 | 指标 | 含义 | 获取方式 |
|------|------|------|----------|
| **散户端** | 融资余额/融资增速 | 散户杠杆水平，融资破历史高位=危险信号 | 搜索"标的+融资余额"或大盘融资余额 |
| | 散户多空比 | 散户情绪温度计，极端多=见顶，极端空=见底 | 小台指/台股多空比、A股散户多空比 |
| | 零股/定期定额买入 | 散户被动买盘力量（台股尤其重要） | 搜索"标的+零股交易/定期定额" |
| | 新增开户数/新基金发行 | 散户入场意愿，火爆=顶部信号 | 搜索"A股/台股+新增开户数" |
| | 个股散户持股比例变化 | 散户是否在接盘 | 搜索"标的+散户持股比例/筹码集中度" |
| **大户/外资端** | 外资现货买卖超 | 外资是养（买）还是杀（卖） | 搜索"标的+外资买卖超/三大法人买卖超" |
| | 外资期货空单部位 | 外资是否在期货布局做空 | 搜索"台指期/股指+外资期货未平仓" |
| | 外资ETF申赎 | 外资是否通过ETF被动买入 | 搜索"标的+ETF净流入流出" |
| | 主力资金净额 | 主力资金流向（A股关键指标） | 搜索"标的+主力资金净额/大单净流入" |

| | 投信/自营商买卖超 | 法人内部结构分化 | 搜索"标的+投信买卖超/自营商买卖超" |

**资金流动判断框架**：

```
Step 1：散户端信号扫描
  □ 融资余额趋势：上升/下降/持平？是否接近历史高位？
  □ 散户多空比：偏多/偏空/中性？极端值出现？
  □ 散户被动买盘（零股/定期定额）：持续流入/开始放缓？
  □ 散户情绪：疯狂追高/恐慌抛售/中性观望？

Step 2：大户/外资端信号扫描
  □ 外资现货方向：持续买入/持续卖出/拉高出货？
  □ 外资期货部位：多单/空单？空单是否在扩大？
  □ 主力资金净额：净流入/净流出？连续天数？
  □ 机构持仓趋势：增持/减持/持平？

Step 3：散户vs大户背离检测（核心！）
  ┌────────────────────────┬──────────────────────────┐
  │ 组合                      │ 含义                        │
  ├────────────────────────┼──────────────────────────┤
  │ 大户卖出 + 散户买入        │ 养套杀的"套/杀"阶段，危险    │
  │ 大户买入 + 散户卖出        │ 筹码转移，可能筑底            │
  │ 大户卖出 + 散户也卖出      │ 恐慌性下跌，可能接近底部      │
  │ 大户买入 + 散户也买入      │ 共振上涨，趋势健康            │
  │ 大户期货空单大增+现货仍买  │ 养套杀布局中（最危险）        │
  └────────────────────────┴──────────────────────────┘

Step 4：结合形态判断所处阶段
  □ 底部形态 + 大户买入+散户卖出 = 真底部（高信心做多）
  □ 头部形态 + 大户卖出+散户买入 = 真头部（高信心做空）
  □ 底部形态 + 大户卖出+散户买入 = 假底部（可能继续跌）
  □ 头部形态 + 大户买入+散户卖出 = 假头部（可能继续涨）
```

**与蔡森方法论的联动**：
- 配合**M3量价验证法**：资金流是量价背后的"谁在买谁在卖"
- 配合**外资养套杀三步法**：判断当前处于养/套/杀哪个阶段
- 配合**量价背离庞氏信号**：融资余额背离是顶部预警
- 配合**M9多头十大罪状**：融资破记录+外资养套杀=多条罪状触发
- 配合**主力洗盘手法识别**：区分「洗盘（吓你不伤你）」与「出货（真跑）」——洗盘多发生在「养」阶段，典型量价反常（跌放收回缩）、关键支撑守住、1~3天快速收回；诱空破位后 1~2 天拉回即假摔。详见 references/washout-techniques.md

## 操作纪律

1. **只做明确的形态**：形态模糊不清时，宁可错过也不做错
2. **严格止损**：每笔交易必须设定止损，绝不扛单
3. **波段持有**：买入后持有到测幅满足或形态破坏，不做日内差价
4. **大周期优先**：月线、周线形态比日线更可靠，优先操作大级别形态
5. **量价配合**：永远用量价关系验证形态有效性
6. **不预测，只跟随**：等待形态确认后再行动，不提前预判
7. **下单前过检查清单**：10 项核对 + 3 项一票否决（没画线 / 无止损位 / 对数图未归位）→ 详见 references/实战手册-20260828.md 第四节
8. **六条铁律**（优先级高于任何形态信号）：多头不看压·空头不看撑 / 卖到睡得着为止 / 高出低进不追高杀低 / 破线第一时间跑 / 操作不带感情不带政治 / 无压力仓位
9. **供给冲击型品种先定性、再画线**：分析原油/能源/化工/农产品等受地缘供给冲击影响的品种时，先按 `references/oil-geopolitics-playbook.md` 做定性分档（需求型 vs 供给型上涨、当前处于哪一档、三阶段推演到哪一步），**警戒档以上禁止追多**，再进入形态分析
