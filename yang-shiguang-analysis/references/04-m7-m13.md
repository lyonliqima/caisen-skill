## M7：ETF资金流分析法

> ETF资金流是机构行为的实时投影，是大势先行指标。

### 分析框架

```
ETF资金流分析：
□ 跟踪主要ETF近7天资金流（净流入/流出）
□ 计算累计流入/流出金额和速度
□ 识别“投降信号”（连续流出>7天、最大单日流出）
□ 对比ETF净资产变化与价格变化 → 是否出现溢价/折价异常
```

### 关键ETF观察清单

| 类别 | 关键ETF | 观察指标 |
|------|---------|----------|
| 加密货币 | IBIT/FBTC/ETHA | 连续流出天数、净资产变化率 |
| 黄金 | GLD/IAU | 持仓量变化 vs 金价走势 |
| A股宽基 | 沪深300ETF/创业板ETF | 净申购/赎回金额 |
| 行业 | 半导体ETF/新能源ETF | 资金轮动方向 |
| 美债 | TLT/SHY | 久期偏好变化 |
| 新兴市场 | EEM/VWO | 资本流向新兴市场vs发达市场 |

### 先行指标解读

- **连续净流出>5天** → 机构投降信号（如IBIT连续11天净流出=散户恐慌）
- **ETF折价交易** → 市场恐慌，赎回压力大于买入
- **逆势净流入** → 聪明钱在抄底（如黄金ETF在金价下跌时净流入）

## M8：加密货币分析框架

### 加密货币传导链

```
Fed政策 → 实际利率 → BTC定价（BTC本质是“零息资产”）
地缘风险 → 避险情绪 → BTC短期跌（流动性需求）/ 长期涨（法币信用危机）
监管政策 → 合规成本 → 机构进入/退出
ETF资金流 → 机构行为 → 价格方向
链上数据 → 散户vs巨鲸行为分化
```

### 分析模板

```
□ BTC价格与纳斯达克相关性：正/负/脱钩？
□ ETF资金流方向：净流入/流出？连续天数？
□ 链上数据：巨鲸持仓变化、交易所BTC余额
□ 稳定币市值变化：USDT+USDC总市值 → 市场购买力
□ 情绪指标：恐慌贪婪指数、泡菜溢价、期货资金费率
□ 监管动态：SEC行动、各国政策变化
□ 矿工行为：矿工余额比、矿工卖出压力
```

### 反常信号

- **泡菜溢价转负** → 韩国散户恐慌（历史罕见，FTX爆雷时出现过）
- **Strategy卖币** → 最坚定多头开始投降 → 市场底部附近
- **矿工余额比创新高** → 矿工不愿卖 → 看涨信号

## M9：A股特化分析框架

> A股是全球最政策驱动的市场，必须用“政策面→资金面→技术面”三层传导。

### 三层传导模型

```
第一层：政策面（决定方向）
  □ 国务院/证监会/央行最新政策
  □ 行业监管变化（鼓励/限制/中性）
  □ 资本市场改革进度（注册制/退市/回购）
  □ 对外政策（资本管控、关税、制裁）

第二层：资金面（决定力度）
  □ 两融余额趋势（杠杆资金）
  □ 北向资金流向（外资态度）
  □ ETF净申购/赎回（机构行为）
  □ 万亿级国家队资金动向
  □ 新增开户数（散户情绪）

第三层：技术面（决定时机）
  □ 指数形态（用蔡森方法论）
  □ 成交量趋势（量能是否配合）
  □ 板块轮动节奏（主线是否明确）
  □ 涨跌家数比（市场宽度）
```

### A股特有信号

| 信号 | 含义 | 操作含义 |
|------|------|----------|
| 国务院发文 | 政策顶/底 | 高度关注，通常领先市场1-2周 |
| 两融余额创新高 | 杠杆过热 | 警惕回调 |
| 北向资金连续净流出 | 外资撤退 | 短期压力 |
| 国家队入场（汇金/证金） | 政策底 | 中期底部信号 |
| 新基金发行火爆 | 散户入场 | 通常是顶部信号 |
| 创业板vs主板分化 | 风格切换 | 关注哪个板块领先 |

### 时间衰减权重

方法论不过期，观点会过期：

| 时间范围 | 观点权重 | 方法论权重 |
|----------|----------|------------|
| 7天内 | 100% | 100%（始终适用） |
| 1个月内 | 80% | 100% |
| 3个月内 | 60% | 100% |
| 6个月内 | 40% | 100% |
| 1年以上 | 20% | 100% |

## M10：巴菲特指標估值法

> 市值/GDP比率是衡量市场整体估值是否极端的终极标尺。

### 分析框架

```
巴菲特指標 = 股市总市值 / GDP

美国：截至 2026/6/5 = $78.05兆 / $32.02兆 = 243.7%
     历史趋势线 ≈ 134%，当前超出 2.5个标准差 → 严重高估
台湾：截至 2026/6/8 = NT$141.9兆 / NT$31.58兆 = 449.3%
     历史高值 461.9% (2026/5)，当前亦处于极端区域
```

### 标准差带判断

| 偏离度 | 含义 | 美股参考值 |
|--------|------|------------|
| +2σ | 严重高估，历史级别泡沫 | >219% |
| +1σ | 偏高，警惕回调 | 176%~219% |
| 趋势线 | 合理估值 | ~134% |
| -1σ | 偏低，投资机会 | ~90% |
| -2σ | 严重低估，抄底时机 | <49% |

### 跨市场比较法

- 美国 vs 台湾 vs 日本 vs 韩国：哪个市场泡沫更大？
- 台股巴菲特指標 449% 远超美股 243% → 台股泡沫化程度更高
- 单日市值蒸发规模：美股 6/5单日蒸发$2.13兆；台股 6/8单日蒸发NT$5.1兆

## M11：黃金-實質利率迴歸分析法

> 黄金与实质利率的相关性本身就是一个先行指标——相关性回归意味着市场逻辑在“正常化”。

### 分析框架

```
每年单独跑回归：金价 = a × 实质利率 + b

2018~2019：y = -278.71x + 1503.5，R² = 0.8175 → 强负相关（正常）
2020~2021：y = -272.15x + 1578.6，R² = 0.7065 → 强负相关（正常）
2022~2023：y = 18.70x + 1852.8，R² = 0.0251 → 相关性完全消失（异常）
2024年：y = -50.18x + 2486.6，R² = 0.0016 → 负相关完全消失（极端异常）
2025年：y = -2032x + 7431.7，R² = 0.4249 → 负相关回归
2026年：y = -1850.8x + 8346.9，R² = 0.5603 → 负相关性较2025年更强
```

### 解读要点

- **R²从接近0回升** → 黄金重新被实质利率定价，市场逻辑正常化
- **斜率绝对值变大**（-278 → -1850） → 实质利率每变动1%，金价波动幅度增大
- **应用场景**：判断黄金是否“超涨”（实际价格 vs 回归线预测值的残差）
- **回归正常？** → 2026年黄金与实质利率的负相关性已接近历史正常水平，黄金上涨的主要驱动力不再是“去美元化异常溢价”

## M12：菲利普曲線定位法

> 将当前失业率+CPI数据点画在菲利普曲线上，判断经济处于哪个象限。

### 四象限判断

```
            高通胀
              │
  过热期     │     滞胀期
 (高通胀+低失业) │ (高通胀+高失业)
─────────┼─────────
  复苏期     │     衰退期
 (低通胀+低失业) │ (低通胀+高失业)
              │
            低通胀
```

### 当前定位（2026/4）

- 失业率 4.3%，CPI同比 3.81% → 偏“过热期”象限
- 非农强劲 + 通胀粘性 → 不支持降息，市场开始定价加息
- 川普发文：“就业报告出色，股市理应上涨而不是下跌。增长并不意味着通胀！”

### 政策含义

- 高通胀+低失业 = Fed不会降息，可能加息
- “好消息=坏消息”反常信号出现：强就业数据→股市暴跌

## M13：利率市場定價消化法

> 市场已经消化了什么预期，比政策本身更重要。

### 分析框架

```
□ 查看Fed funds期货隐含的加息/降息预期（以bp为单位）
□ 比较数据发布前后的预期变化（如非农前 vs 非农后）
□ 关注哪些会议已被定价“加息”、哪些还是“降息”
□ 注意“充分消化”的含义：市场已 price-in，后续影响有限
```

### 实战案例（2026/6/5非农后）

- 非农前（2/27）：市场预期年内降息约50bp
- 非农后（6/5）：市场已充分消化年底前加息25bp的预期
- 含义：市场已从“降息交易”转向“加息交易”，这是重大风向转变
