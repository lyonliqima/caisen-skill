## M29：頁岩油產能見頂分析法

> 美国页岩油产能是否见顶，决定了全球原油长期供给增量。关键洞察：页岩油是页岩气的副产品，天然气价格才是产能的决定变量——气价占7成，油价仅占3成。

### 核心逻辑

```
传统油气：油为主，气伴生
  → 油价决定产能

页岩油气（美国技术）：气为主，油伴生
  → 天然气价格决定产能（占7成影响权重）
  → 油价仅占3成影响权重

传导链：
  气价高 → 大规模开采页岩气 → 副产品页岩油供给增加
  → 天然气过剩 → 气价崩盘
  → 气价低 + 油价回落 → 毛利率收窄
  → 企业再投资意愿下降 → 产能见顶
  → 页岩油/气产出零增长

结论：页岩油产能见顶 = 全球原油长期供给增量大幅收窄
```

### 分析模板

```
□ 跟踪美国天然气价格趋势：是否持续低迷？
□ 跟踪页岩油气企业再投资/资本支出趋势：是否下降？
□ 跟踪页岩油产出增速：是否接近零增长？
□ 跟踪页岩气产出增速：是否接近零增长？
□ 诊断：
  气价低迷 + Capex下降 + 产出零增长 → 产能已见顶
  气价低迷 + Capex仍在增 → 接近见顶但尚未确认
□ 含义：产能见顶 → 全球原油长期供给增量收窄 → 能源品长期定价中枢抬升
```

### 实战案例（2026/6/23）

| 指标 | 状态 | 含义 |
|------|------|------|
| 天然气价格 | 全球气价崩盘后持续低迷 | 页岩气开采动力不足 |
| 油价 | 回落至80美元附近 | 叠加气价低迷，毛利率收窄 |
| 再投资意愿 | 显著下降 | 企业不愿扩产 |
| 产出增速 | 基本零增长 | 产能已接近峰值 |
| 欧佩克判断 | 美国页岩油2024-2026见顶 | 长期供给增量不足 |

### 与现有框架的协作

- **与 M30（美元-油价相关性模型）**：页岩油见顶是美元-油价正相关关系瓦解的根本原因
- **与 M3（美元周期分析）**：页岩油见顶后，美元的能源实体属性支撑消退，转为金融属性主导
- **与 M5（大类资产轮动）**：页岩油见顶 → 全球能源供给收缩 → 大宗商品大周期信号
- **与 M15（地缘事件计数法）**：页岩油见顶叠加中东地缘风险 = 能源供给双重压力

## M30：美元-油價相關性三階段模型

> 美元与油价的相关性本身就是一个领先指标。从负相关到正相关、再回归负相关的翻转，反映了美国能源贸易结构的根本性变化，是判断大宗商品超级周期的深层信号。

### 三阶段演变

```
第一阶段：传统负相关（2017年之前）
  逻辑1：美国是全球最大能源逆差国
    油价↑ → 贸易收支恶化 → 利空美元
    油价↓ → 贸易收支改善 → 利好美元
  逻辑2：购买力平价机制
    原油以美元计价，供需不变时
    美元↑ → 油价名义价格↓ （维持实际购买力稳定）
    美元↓ → 油价名义价格↑

第二阶段：正相关形成（2017年之后）
  驱动：美国页岩油革命
    → 美国从能源净进口国走向能源净出口国
    → 油价↑ → 改善美国贸易收支 + 带动能源出口的美元需求
    → 油价与美元同步上涨
  本质：市场对美国能源贸易结构变化的定价

第三阶段：回归负相关（当前正在发生）
  驱动：页岩油产能见顶
    → 美国能源贸易结构优化红利结束
    → 无法再通过能源出口增量支撑美元
    → 油价对美元的正向驱动消失
  含义：
    短期：美元走强压制油价（计价效应）
    长期：全球能源供给增量收缩 → 能源品长期定价中枢抬升
```

### 判断规则

| 相关性状态 | 含义 | 信号 |
|-----------|------|------|
| 稳定负相关 | 美国能源净进口，传统格局 | 正常 |
| 负相关→正相关（翻转） | 页岩革命生效，美国走向能源净出口 | 能源结构质变 |
| 正相关→负相关（回归） | 页岩油见顶，能源红利消退 | 大宗商品超级周期前兆 |

### 与M18（黄金-利率相关性周期法）的对称性

- M18：黄金与实质利率的相关性符号翻转 = 黄金超级周期信号
- M30：美元与油价的相关性符号翻转 = 大宗商品超级周期信号
- 两者都是「相关性符号翻转」方法论，用于判断资产是否进入超级周期

### 与现有框架的协作

- **与 M29（页岩油产能见顶）**：M29提供因果解释，M30提供价格信号验证
- **与 M3（美元周期分析）**：M30解释美元强弱与油价的联动关系，M3分析美元本身的驱动因素
- **与 M5（大类资产轮动）**：相关性状态决定美元和商品的轮动关系

## M31：軋空風險評估法

> 当「现货库存极低」+「期权/期货空头持仓极高」同时出现时，市场隐含巨大的轧空（逼空）风险。一旦出现供给端利好或情绪反转，空头集中平仓会推动价格快速拉升。

### 分析框架

```
□ 现货库存诊断：
  □ 商业库存（不含战略储备）处于历史什么分位？
  □ 关键交割点库存（如库欣）是否逼近「死亡线」？
  □ 库存趋势：持续下滑 or 正在回补？

□ 空头持仓诊断：
  □ 期权空头持仓量：是否接近或创历史新高？
  □ 期货空头持仓量：投机空单 vs 套保空单的比例
  □ 空头集中度：是否集中在少数机构？

□ 综合诊断：
  低库存 + 高空单 → 轧空风险极高
  低库存 + 低空单 → 供给偏紧但无逼空压力
  高库存 + 高空单 → 供给宽松，空头有底气
  高库存 + 低空单 → 中性偏空

□ 轧空触发信号：
  突发供给中断（地缘/天气）
  需求端意外利好（旺季/政策刺激）
  空头龙头率先平仓 → 连锁反应
```

### 实战案例（原油 2026/6/23）

| 指标 | 数据 | 轧空风险评估 |
|------|------|------------|
| 商业原油库存（不含SPR） | 过去5年低位 | 现货端供给不宽松 |
| 库欣交割点库存 | 过去5年低位 | 接近逼空条件 |
| 全球原油期权空头持仓 | 即将创历史新高 | 空头极度拥挤 |
| 综合判断 | 低库存+高空单 | **轧空风险极高** |
| 亚洲盘弱/欧美盘强 | 亚洲交易和谈乐观，欧美交易供给风险 | 日内节奏分化 |

### 与6/18会议的呼应

- 6/18会议已提出"库欣库存逼近2000万桶死亡线"和"有轧空潜力但不是100%发生"
- 6/23会议升级为"期权空单即将创历史新高"，轧空风险从"有潜力"升级为"隐含巨大"
- 追踪逻辑：库存低位持续 + 空单持续增加 → 轧空风险逐步升级

## M32：AI产业链债务传导链分析法（"雷曼时刻"诊断）

> 当产业链的资金循环依赖少数关键节点的"承诺"而非真实现金流时，单一节点的信评降级或融资困难就会像雷曼时刻一样沿链条传导。核心是识别"承诺-承诺"循环的脆弱性。

### 核心逻辑

```
AI产业链资金循环（以软银-OpenAI为例）：
  关键金主节点（软银，信评BB+=垃圾级）
    └→ 承诺投资AI应用公司（已投650亿，未来还有300亿承诺）
       └→ AI公司向算力提供商下订单/承诺
          ├→ 向云服务商下订单（未履约订单数千亿）
          └→ 向硬件商采购芯片（硬件商财报优秀，预付金抢产能）

雷曼类比：
  市场初期把每个节点危机当"独立事件"
  → 实际是"套圈式"连锁反应，每一层高度相关
  → 任何一环"承诺"无法兑现 → 整条链断裂
```

### 分析模板

```
□ 识别产业链的关键资金节点（谁在提供"承诺资金"？）
□ 监测关键节点的债务风险指标：
  □ 信评等级（是否降至垃圾级BB+以下？）
  □ CDS信用违约交换（是否飙升创新高？是否超过濒临破产企业？）
  □ 过桥贷款/短期债务到期压力窗口
  □ 融资困难程度（筹资遇阻信号）
□ 梳理"承诺-承诺"循环：
  □ 节点A承诺给B多少资金？
  □ B拿到资金后向C下了多少订单/承诺？
  □ C的财报中有多少来自B的未履约订单？
□ 诊断传导风险：
  关键节点信评降级 + 承诺规模巨大 + 下游依赖度高 = 雷曼时刻风险
□ 类比检验：当前与雷曼/贝尔斯登的"独立事件误判"阶段有多相似？
```

### 实战案例（软银 2026/6/29）

| 指标 | 数据 | 含义 |
|------|------|------|
| 信评 | BB+（标普，垃圾级） | 融资成本飙升 |
| 股价 | 一个月跌35% | 市场已定价危机 |
| CDS | 超过快破产的日产汽车 | 违约风险急剧攀升 |
| 明年3月到期过桥贷款 | 400亿美元 | 偿付压力窗口 |
| 对OpenAI承诺 | 累计~650亿，未来还有300亿 | 承诺规模巨大 |
| ARM持仓质量 | 市值3570亿，PE 393倍，营收仅15亿 | 资产估值荒谬 |

### 关键判断规则

- **"独立事件"误判期** = 最危险阶段：市场把每个节点危机当孤立事件，实际已高度关联
- **CDS > 濒临破产企业** = 债务市场已定价极端违约风险
- **过桥贷款到期窗口** = 流动性压力测试时点
- **承诺规模 / 实际融资能力** = 承诺兑现率，低于50%即危险

### 与M20（賣鏟人vs賣慘人）的协作

- M20：看上下游FCF分化，判断利润集中在上游还是下游
- M32：看债务承诺链断裂风险，判断产业链资金循环是否可持续
- 配合使用：M20发现賣鏟人吸金 → M32检验賣鏟人的金主能否持续供血

## M33：行业债务排挤效应评估法

> 当单一行业的债务增量超过主权国家时，说明该行业正在从全球资金池中"排挤"其他行业和主权国家的融资需求。这种排挤效应是判断泡沫是否接近临界点的宏观标尺。

### 核心逻辑

```
全球资金供给量（一定时期内）≈ 恒定
资金需求方排名（按债务增量）：
  1. 美国国债（增量第一）
  2. AI行业债务（增量已超越日本国债、中国国债）
  3. 日本国债
  4. 中国国债
  ...
  N. 其他行业/企业

排挤效应传导：
  AI行业债务暴增 → 占用全球资金供给
  → 其他行业融资成本上升
  → 主权国家发债困难/利率上升
  → 非AI产业投资被挤出
```

### 分析模板

```
□ 计算目标行业的债务增量规模（公司债+银行贷款+IPO募资）
□ 计算同比增速（如同比+357% = 暴增3.5倍）
□ 将行业债务增量与主权国家债务增量排名对比
□ 评估排挤效应严重度：
  □ 行业债务增量排名进入全球前3 → 严重排挤
  □ 行业债务增量 > 主要主权国家 → 极端排挤
  □ 行业债务增量增速远超GDP增速 → 不可持续
□ 追踪排挤效应的受害者：
  □ 哪些行业融资成本因此上升？
  □ 哪些主权国家发债被挤出？
  □ 哪些企业被迫放弃投资计划？
```

### 实战案例（AI行业债务 2026/6/29）

| 维度 | 数据 | 含义 |
|------|------|------|
| 上半年AI相关债务发行 | 2360亿美元 | 较去年同期暴增357% |
| 年底预估 | 5700亿美元 | 持续膨胀 |
| 全球债务增量排名 | 美国国债 > **AI行业** > 日本国债 > 中国国债 | 行业超越主权国家 |
| SpaceX单笔公司债 | 250亿美元（从200亿扩至250亿） | 单一企业发债规模惊人 |
| SpaceX信评 | BBB（接近垃圾级） | 质量与规模不匹配 |

### 关键判断规则

- **行业债务增量超越主权国家** = 历史罕见，通常出现在超级泡沫期
- **暴增3倍以上** = 资金集中度极端化，排挤效应已显著
- **散户热烈追捧掩盖机构风险定价** = 垃圾级/接近垃圾级债券仍被抢购 = 泡沫末期特征

### 与M10（巴菲特指标）的协作

- M10：用市值/GDP判断股市整体泡沫
- M33：用行业债务增量/主权国家债务增量判断债市泡沫的排挤效应
- 配合使用：M10看股，M33看债，双重验证泡沫

## M34：风险货币/避险货币汇率比领先指标法

> 用"风险偏好货币÷避险货币"的汇率比值，作为股市多空转换的领先指标。分子是高β商品/投机货币，分母是低β避险/套息货币，比值反映市场整体风险偏好温度。

### 核心逻辑

```
汇率比 = 风险货币/美元 ÷ 避险货币/美元 = 风险货币/避险货币
（美元在分子分母中约掉）

经典组合：澳币/日元
  分子（澳币）：商品货币（出口铁矿石/煤炭）+ 投机/风险货币（高β）
  分母（日元）：避险货币（全球动荡时资金涌入）+ 套息货币（低利率被借来投资高息资产）

比值含义：
  澳币/日元↑ → 风险偏好升温 → 股市 likely 上涨
  澳币/日元↓ → 风险偏好降温 → 股市 likely 下跌
  比值跌破支撑线 → 股市领先看空信号
```

### 分析模板

```
□ 选择风险货币/避险货币组合（经典：澳币/日元；其他：加币/瑞郎等）
□ 计算汇率比值的时间序列
□ 识别支撑线/压力线的技术位置
□ 与股市指数做时间序列对比，验证领先关系
□ 用CFTC持仓数据交叉验证：
  □ 风险货币：多单减+空单增 = 单边看空
  □ 避险货币：多空同步退场 = 观望
  □ 两者形成高度负向发展 = 风险偏好转折确认
□ 扩展应用：
  □ 风险货币与特定资产的相关性追踪（如澳币与AI板块的正相关性）
  □ 货币对的风险偏好 = 全球市场风险偏好的代理指标
```

### 实战案例（澳币/日元 2026/6/29）

| 信号 | 数据 | 含义 |
|------|------|------|
| 澳币/日元汇率 | 跌破短期支撑线 | 风险资产降温领先信号 |
| CFTC澳币持仓 | 多单大减+空单大增 | 单边看空 |
| CFTC日元持仓 | 多空同步退场 | 观望 |
| 澳币 vs AI板块 | 高度正相关（摩根研究） | 澳币走弱=AI板块风险偏好降温 |

### 关键判断规则

- **汇率比跌破支撑** → 股市领先看空信号（历史上常为领先指标）
- **风险货币多减空增+避险货币多空退场** → 风险偏好转折确认
- **风险货币与特定板块正相关** → 可作为该板块的风险偏好代理指标

### 与M3（美元周期）和M5（大类资产轮动）的协作

- M3：分析美元本身的强弱势周期
- M5：大类资产轮动的跨市场联动
- M34：提供具体的汇率比领先指标，是M3/M5的"先行信号工具"
- 配合使用：M34发出信号 → M3确认美元周期 → M5判断资产轮动方向

## M35：资本财进口结构异常诊断法

> 通过拆解贸易赤字中资本财的占比异常，诊断经济结构是否发生异变。当一个发达国家出现类似"发展中国家初期资本积累"的资本财进口暴增，但库销比同时恶化时，说明资金正被单一领域（如AI基建）虹吸，实体经济被掏空。

### 核心逻辑

```
正常发展中国家：
  贸易赤字 ← 资本财进口大增（建厂/设备）
  + 金融账盈余 ← 吸引外资
  = 资本积累阶段（正常）

异常发达国家（如当前美国）：
  贸易赤字创历史新高 ← 资本财进口暴增（AI基建）
  + 库销比持续恶化 ← 制造业/批发业货架越来越空
  + 消费品进口未同步增加 ← 不是库存回补
  = AI基建虹吸全部资金，实体经济被掏空（异常）

资本虹吸-红利兑现二阶段检验：
  阶段一（虹吸期）：全球资本涌入单一领域
    → 其他地区投资不足、消费被消耗
  阶段二（兑现检验）：
    成功 → 红利回流，各地受益
    失败 → 掏空效应不可逆
  关键变量：大投资能否产生真实现金流回报
```

### 分析模板

```
□ 拆解贸易赤字结构：
  □ 资本财占比（计算机/服务器、半导体、电信设备等）
  □ 消费品占比、食品/原材料占比、二级加工品占比
□ 对比历史比例：
  □ 资本财占比是否远超历史均值？
  □ 哪些品类增速异常？（如服务器翻倍、半导体增50%+）
□ 库销比检验：
  □ 库销比是否持续恶化（货架越来越空）？
  □ 进口大增是否为库存回补？（若库销比恶化=非库存回补）
□ 资本虹吸方向诊断：
  □ 资金集中流向哪个领域？其他领域是否被挤出？
□ 红利兑现检验（历史类比法）：
  □ 当前资本外流是否有历史类比案例？
  □ 历史案例是"成功返乡"还是"掏空"？
  □ 判断标准：投资能否产生真实现金流回报
```

### 实战案例（美国贸易赤字 2026/6/29）

| 指标 | 数据 | 含义 |
|------|------|------|
| 5月贸易赤字 | 回到1000亿美元以上 | 历史高位（仅疫情/对等关税时期可比） |
| 资本财占进口比 | 近四成 | 发达国家异常高（似发展中国家资本积累） |
| 计算机/服务器进口 | 较去年同期翻倍 | AI基建拉动 |
| 半导体/电信设备进口 | 增长50%+ | AI基建拉动 |
| 库销比 | 持续恶化（从3个月→2个月→1个月） | 货架空但非库存回补 |
| 综合诊断 | AI基建虹吸全部资金 | 实体消费被压缩 |

### 历史类比：掏空效应检验

| 维度 | 历史案例：东帝士/陈又豪 | 当代案例：软银/孙正义 |
|------|----------------------|---------------------|
| 行为 | 掏空台湾资产投资大陆 | 掏空日本资产投资美国AI |
| 站在投资地角度 | 大商人、爱国、享受红利 | 有远见的大商人 |
| 站在母地角度 | 掏空台湾、留烂摊子 | 掏空日本、留烂摊子 |
| 关键检验 | 大陆投资能否赚钱返乡？ | 美国AI投资能否产生现金流？ |
| 成功结局 | 归鱼返乡，消费暴增 | 全球资本受益于AI红利 |
| 失败结局 | 掏空罪名，十年消费不振 | 全球资本被无底洞吞噬 |

### 关键判断规则

- **资本财占比远超历史均值** → 经济结构异变信号
- **库销比恶化+进口大增但非库存回补** → 资金被单一领域虹吸
- **发达国家出现"发展中国家资本积累"特征** → AI基建排挤效应已显著
- **全球千千万万"孙正义"把资本堆向单一领域** → 成功则红利回流，失败则全球掏空

### 与M27（实体经济三线验证法）的协作

- M27：消费线+库存线+固投线验证GDP增长质量
- M35：资本财进口结构+库销比+历史类比诊断经济结构异变和资本虹吸方向
- 配合使用：M27发现三线疲软 → M35解释为什么（资金被AI虹吸） → 历史类比判断可持续性
