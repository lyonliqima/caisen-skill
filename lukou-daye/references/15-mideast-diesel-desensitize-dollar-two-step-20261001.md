## 引用硬规则（5 条，引用前必读）

1. **方法论可吸收，观点必须标「外部观点」。** 四组判别步骤（L31–L34）= 可复用；"美国主动操盘、不急于结束战争""10 月必然加息""2900–3200 黄金布局窗口" = **外部观点·待验证**。
2. **"主动性归因"只作叙事层理解，不进结论支点。** 本文的核心框架是"一切皆是美国主动操盘"——这类**动机归因不可证伪**（战局顺利=操盘成功，战局不顺=更深谋远虑）。本框架只吸收其**传导机制**（冲突→美元需求/柴油→欧洲成本/高息→资本流入），**"是否故意"不作为分析输入**。这与 G 组归档的处理方式一致。
3. **数据先查本文件第四节核验表。** 柴油数据核验**基本属实**（15.4%/126 万桶/日，文中"近 16%/130 万桶"为近似）；**PCE 统计方法调整未查到一手信源**，标「自述/未验证」，不得作结论支点。
4. **禁止把条件式判断转录为概率。** "若信用没稳住就降息，美元会丧失霸权"等 → 原样转证伪位。
5. **观点带时间衰减。** "10 月加息"“禁止柴油出口落地与否”等事件层判断按权重衰减表处理（同 0801 归档格式），需用最新数据独立验证。

## 五、补充推论（本框架推论，非事实层）

1. **L32 的证伪位**：若美国柴油出口禁令**落地**且欧洲 TTF/柴油裂解价差随后见顶回落（禁令放空=利空出尽），则"柴油武器化推升欧洲通胀"链条被证伪一半；若禁令始终不落地仅作威慑，则支持"口头施压消耗欧洲安全垫"的解释。**观测点：白宫正式公告 vs 长期停在表态。**
2. **L33 的分岔判据**：收益率新高时观测（a）美债拍卖投标倍数与间接竞购占比（b）一级交易商持仓（c）是否有机构集中减仓新闻。三者在位=脱敏有效（阴跌消化）；投标倍数骤降+间接竞购萎缩=脱敏失效（踩踏启动）。**这与 0819 的"债务螺旋抢钱"是同一次检验的两个出口。**
3. **L34 与 L12 的合流检验**：两步走"第一步完成"的验收 = L28 三开关开始翻转（美元指数趋势性下行 ≥12 个月 / 美债海外持有止跌 / 大宗美元计价份额企稳）。**当前（2026-10）三开关均未启动 → 仍处第一步，作者"后续转弱美元"是路径判断非当下事实。**
4. **与 14 号归档的统一**：本文把"禁止柴油出口"解释为对欧施压武器；14 号把它登记为"美国自身柴油 6.06 美元/加仑创纪录、国内承压"的证据。**裁断：两个解释可同时成立**——国内政治压力（抑制国内油价）与对外施压（逼迫欧洲）共用同一工具，动机归因不唯一，但**价格传导方向唯一**：全球柴油边际供给收紧 → 裂解价差上行 → 通胀上行。

## 六、可吸收清单（H 组 L31–L34 + L15 补充判据）

### L31：战争持续性收益结构判别法 　【挂 L4 / L11】

```
判据：地缘冲突久拖不决时，先问"谁在从持续性中持续获益"，再判"战争为什么不结束"。
三重收益维度（作机制分析，不作动机归因）：
① 需求税维度：冲突→风险溢价→进口国被迫增持结算货币→结算货币需求刚性上升
   （验证指标：结算货币在全球储备/结算份额是否随冲突上行）
② 裹挟维度：冲突→产油国主权风险+资本外流+航运成本→财政福利脆弱性暴露
   →倒逼选边→减产托价同盟松动
   （验证指标：OPEC+ 内部政策分歧度、产油国对美/对冲势力外交动作）
③ 贸易流重塑维度：冲突→航道风险→买方转向"安全"供应方→供应方绑定依赖
   （验证指标：欧洲/东亚自美国能源进口份额变化）
⚠️ 使用纪律：三个维度只回答"持续性对谁有利"，不回答"是不是故意设计的"
   ——后者不可证伪，禁止进结论
频率：事件驱动 + 季度
```

### L32：成品油分层打击判别法（柴油优先级） 　【挂 L4 / L26】

```
判据：能源战的打击深度按"馏分"分级——柴油 > 原油。
为什么柴油是战略级：
  柴油 = 货运/船舶/农机/工程机械/发电的通用燃料 → 价格直达
  工业生产成本 → 物流成本 → 食品价格 → 核心通胀（比原油更下沉更直接）
打击方三要素（须同时成立才有"柴油武器"资格）：
  ① 自身是最大柴油出口国（当前：美国 15.4% 全球第一）
  ② 目标方存在柴油结构性缺口（当前：欧洲，失俄供后长期依赖进口）
  ③ 手握出口阀门可放可收（口头施压逼对方动用应急储备 = 先消耗安全垫；
     放风出口禁令 = 威胁供给收缩）
观测链：出口国政策表态 → 目标方应急储备动用 → 柴油裂解价差 → 目标方 PPI/核心通胀
⚠️ 美国口径修正（对 14 号 #4 的精细化）：美国是最大"产油国"非最大"原油出口国"，
   但确是最大"柴油/馏分燃料出口国"——引用时必须分品种，不可混称
频率：周月度（柴油库存/裂解价差/政策表态）
```

### L33：美债"市场脱敏"预期管理识别器 　【挂 L11 / L19】

```
判据：长端利率反复冲高却不触发系统性抛售时，判"脱敏"还是"踩踏前夜"。
脱敏形成三步（观测是否走完）：
  ① 关键位前媒体密集渲染"崩盘" → ② 实际突破后无系统性灾难 → ③ 多轮重复后
  "高位常态化"，市场不再因收益率上行集中恐慌
脱敏的机制效果：浮亏不集中兑现 → 慢跌/阴跌消化 → 为发行方持续滚动融资争取时间
分岔检验（脱敏有效 vs 踩踏启动）——三个指标：
  □ 美债拍卖投标倍数与间接竞购占比（在位=有效；骤降=失效）
  □ 一级交易商持仓变化（被动累积可控=有效；被迫抛售=失效）
  □ 机构集中减仓/强平事件（无=有效；出现=启动）
与 0819 归档合读：被动锁定（想卖不能卖）+ 主动脱敏（预期被驯化）= 同一稳态的两面；
  任一面破裂（锁仓松动/脱敏失效）→ 债务踩踏风险
⚠️ "发行方有意脱敏"是动机归因；本判别器只测"脱敏状态是否存在"
频率：每次收益率冲击关键位时检验
```

### L34：强弱美元两步走切换检验法 　【挂 L11 / L12 / L28】

```
框架：强美元与弱美元不是矛盾，是同一战略的时序两步。
第一步（进行中检验）：强美元修信用
  实体锚 = 石油/大宗交易美元绑定（冲突推高交易性美元需求，挂 L31/L32）
  金融锚 = 高息差 + 产业红利 + 避险预期 → 资本流入美股美债
  目标：保障美元全球流动性 / 自由兑换 / 相对安全性
第二步（待启动检验）：弱美元放空间
  三红利：稀释本币计价债务 / 提升出口竞争力 / 释放流动性开启全球资产重估
切换验收 = L28 三开关开始翻转：
  □ 美元指数趋势性（≥12 个月）下行
  □ 美债海外持有份额止跌
  □ 大宗商品美元计价份额企稳
顺序铁律（文中条件式，原样转证伪位）：
  若信用未稳（三开关未翻转）即转向降息放水 → 弱美元丧失"硬通货"共识 →
  霸权受损。即：**三开关未翻转前的降息 ≠ 第二步启动，只是周期性宽松**。
当前读数（2026-10）：三开关均未启动 → 仍处第一步（避险强汇阶段）
频率：月度
```

### L15 补充判据：黄金"调节器 vs 避险主角"角色切换 　【挂 L15，不新设编号】

```
黄金在美元体系内的双重角色：
  体系内配角（调节器）：短期避险需求被压制（加息/期货盘/舆论），
    全球共识被引导为"避险首选美元美债" → 金价震荡/滞涨

切换观测：央行购金速度（持续高位=体系外角色强化）× 实际利率
  × 危机时刻金价与美元同涨还是背离（同涨=体系外角色启动的强信号）
⚠️ "美国有意压制黄金"是动机归因，不进结论；只观测角色状态
```

## 七、交叉裁断记录

### 裁断 1（vs 0819 归档）：美债"不崩"的两种解释

- 0819：**被动锁定**——全球资本稀缺 + 机构被套不敢卖 + 浮亏不兑现。
- 本文：**主动脱敏**——预期管理让"狼来了"失效，市场接受高位常态。
- **裁断：同一稳态的两面，合并为 L33 的观测框架**（被动锁定 = 持仓行为面，主动脱敏 = 预期面）。检验出口见第五节推论 2：拍卖倍数/交易商持仓任一破裂，两种解释同时失效。

### 裁断 2（vs 14 号归档）：美国"最大出口国"口径精细化

- 14 号裁断：美国是最大**产油国**不是最大**出口国**（原油口径）✅ 维持。
- 本文：美国是最大**柴油出口国**（15.4%）✅ 新增验证。
- **裁断：两裁断不冲突，分品种成立。** 后续引用统一口径：**原油产量第一 / 原油出口非第一 / 成品油（馏分）出口第一 / LNG 出口第一**。L32 已写入。

### 裁断 3（vs L12 / L28 / 0801）：强弱美元时序统一

- L12：弱美元前置 = 双管道（石油美元 + 稳定币）完工。
- L28：弱汇强币是目标非现状（三开关未启动）。
- 0801：强美元哲学悖论（通胀高企时避险强汇）。
- 本文：两步走——先强修信用，后弱放空间，顺序不可反。
- **裁断：四者完全自洽，合流为 L34**。0801 的"避险强汇" = 第一步的当下状态；L28 三开关 = 第一步→第二步的验收表；L12 双管道 = 第二步的基础设施。**当前（2026-10）处于第一步中段：实体锚在重建（冲突推高美元交易需求），金融锚在承压（收益率破 2007 新高但资本仍在流入——FT：截至 7 月海外购美股超 9,400 亿美元创纪录）。**

### 裁断 4（vs 12 号归档 / 吸引子基线）：加息与内需矛盾

- 本文主张 10 月继续加息；12 号判中国"宽而不松、内需躺地板"。
- **裁断：不冲突**——美元加息强化息差 → 非美被动紧缩 → 中国本已疲弱的内需修复更难（输入性紧缩）。这与 11 号归档"对华传导三步"一致：中国的缓冲屏障（独立货币+资本管制）挡住金融冲击，但挡不住**出口需求端**的全球紧缩。**合读：美国每多维持一季高息，中国"两个出口"（中央财政发力/企业再借款）的紧迫性就高一分。**
