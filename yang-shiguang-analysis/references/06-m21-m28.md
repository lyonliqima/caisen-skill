## M21：貿易盈餘-匯率背離分析法

> 当"强出口+强股市+弱货币"三者同时出现时，说明资本正在外流，出口收入没有回流本国。

### 分析框架

```
□ 贸易盈余趋势：是否持续创新高？
□ 出口/GDP表现：经济是否强劲？
□ 汇率走势：本币是升值还是贬值？
□ 背离诊断：
  强出口 + 强股市 + 弱货币 = 資本外流
  
□ 资本外流来源拆解：
  1. 企业海外再投资（设备采购、建厂、偿还美元债）
     → 出口收入"在岸缺席"，留在海外账户
  2. 散户海外投机（炒股、杠杆投资）
     → 金帐顺差但资本帐逆序
  3. 政策驱动的资本管制（阻止流出 vs 鼓励回流）
```

### 实战案例——韩国（2026/6/9）

| 指标 | 数据 | 含义 |
|------|------|------|
| GDP年增率 | 3.8%（Q1 2026） | 经济强劲 |
| 经常帐盈余 | 373亿美元（3月），连36个月顺差 | 历史高 |
| USD/KRW | 1561（6/5），近17年低点 | 货币极弱 |
| 原因 | 三星/海力士海外再投资 + 散户疯狂炒美股 | 资本外流 |
| 结论 | 赚10美元可能只有1-5美元回到韩元 | 贸易盈余打折 |

### 实战案例——台湾

- 台币维持31.5附近弱势，与贸易帐和GDP增长背离
- 散户大量炒作美股，形成资本外流
- **台幣止貶轉升 = AI泡沫終結的先行指標**

### 实战案例——中国（对照组）

- 1-5月贸易顺差4,517亿美元，全年挑战1.2兆
- 人民币走强（与台币/韩元脱鉤）
- 原因：对外投资新规（富途/老虎关门）+ 国家队抛售ETF → 资本外流管道被拔掉

### 先行指标应用

- **韩元/台币升值** = 海外资金开始回流 = AI短期流动性泡沫见顶
- 韩元2024/12低点和2025/4低点 vs 美国科技股高点具有领先关系

## M22：歷史貿易失衡類比法

> 当一个经济体的贸易盈余达到全球不可持续的水平时，必然引发贸易冲突或汇率重估。用历史类比来理解当代贸易失衡。

### 分析框架

```
□ 计算贸易盈余占全球GDP比重
□ 寻找历史上类似的贸易失衡案例
□ 分析历史案例的结局（战争/关税/汇率重估）
□ 对比当代案例的相似与不同之处
```

### 核心案例：1820年代中国 vs 当代中国

| 维度 | 1820年代中国 | 当代中国（2025） |
|------|------------|----------------|
| 出口品 | 茶叶、丝绸、瓷器 | 半导体、汽车、钢铁、电子 |
| 贸易盈余 | 全球白银50%流入中国 | 年贸易顺差1.2兆美元 |
| 对手方 | 英国（工业革命产品滞销） | 欧盟+美国（产业被挤压） |
| 不可持续性 | 英国无法用工业品平衡贸易 | 欧美无法承受中国出口冲击 |
| 历史结局 | 鸦片战争（武力打开市场） | 关税壁垒+贸易制裁 |
| 唯一解法 | 鸦片创造了"反向需求" | **人民币升值** |

### 关键原则

- **"什么都能做，却什么都做不了"**：中国制造业几乎无所不能，但对全球贸易秩序/条件/壁垒无能为力
- **贸易盈余不可持续 → 冲突必然发生**：当年是鸦片，今天是关税+贸易壁垒
- **汇率升值是最终解**：贸易失衡的终极调节器是本币升值
- 欧洲人民党（EPP）"天真的时代已经结束" = 欧洲对华贸易政策转向的信号

### 与M6（地缘传导法）的协作

- M6：分析地缘事件的传导链
- M22：从历史维度理解贸易失衡为何必然走向冲突，提供长周期视角

## M23：歷史資金規模類比法

> 将当代重大地缘/外交协议的资金规模与历史事件做量化对标，揭示其颠覆性影响。

### 分析框架

```
□ 计算当代协议的资金规模（增量资金 + 存量资产解冻）
□ 计算接受方的年度财政收入、国防预算等基准
□ 将资金规模折算为“X年财政收入”或“X倍国防预算”
□ 寻找历史上类似量级的资金转移事件
□ 对比历史事件的后续影响（工业化、军事扩张、经济转型）
```

### 实战案例（美伊MOU 2026）

| 维度 | 美伊和谈MOU | 马关条约1895 |
|------|------------|------------|
| 资金规模 | 3000亿重建基金 + 1100亿资产解冻 | 2.3亿两白银（折3.6亿日元） |
| 对标基准 | 伊朗年财政收入~1000亿 | 日本年财政收入~9000万日元 |
| 倍数 | ≈ 4年财政收入 | ≈ 4年财政收入 |
| 后续影响 | 伊朗无需发债，转为财政盈余国 | 日本工业化+军事扩张 |

### 关键原则

- **量级对标比绝对数字更重要**：3000亿看起来只是数字，但“4年财政收入”才能揭示颠覆性
- **增量+存量要并计**：不能只看新资金，还要算解冻的存量资产
- **历史类比要匹配倍数关系**：不是随便找历史事件，而是找“资金量/财政收入”倍数相近的案例

## M24：協議落地障礙評估法

> 任何重大地缘协议，都必须用“国际组织背书 + 国内政治”双维度评估其最终落地概率。

### 分析框架

```
□ 评估国际组织背书维度：
  □ 哪些国际组织参与背书（联合国安理会/国际原子能署等）
  □ 常任理事国/关键成员国的态度（支持/弃权/反对）
  □ 是否存在“单方面承诺但未征求多方意见”的风险
□ 评估国内政治维度：
  □ 协议是否需送交国会表决
  □ 表决时间窗口是否与大选周期重叠
  □ 两党/多党博弈对协议的影响
□ 综合判断落地概率：
  双维度均顺畅 → 高概率落地
  一个维度受阻 → 中度风险
  双维度均受阻 → 极可能搁浅
```

### 实战案例（美伊MOU 2026）

| 维度 | 障碍 | 风险级别 |
|------|------|----------|
| 联合国安理会 | 中国曾弃权、俄罗斯曾反对票；美国单方面承诺解除安理会制裁，未征求其他常任理事国 | 高 |
| 美国国会 | 正式协定60天后送交国会表决，恰逢2026年底大选，两党博弈可能导致搞浅 | 高 |
| 综合判断 | 双维度均受阻 → “我觉得不会成” | 极高 |

## M25：第一性原理估值批判法

> 马斯克推崇的“第一性原理”本质是管理学中的“本质拆解法”——先质疑现有叙事，拆解行业容量天花板，再检验宣称市值是否合理。

### 分析框架

```
□ 拆解宣称的市值叙事：公司/行业声称要拿下多大的市场？
□ 计算行业容量天花板：整个行业的全球市场规模是多少？
□ 检验竞争格局：公司在行业中的实际地位、市占率、技术壁垒
□ 对比竞争对手：同行业龙头的市值/管收/EPS是否匹配
□ 暴露估值荒谬性：用“要干掉多少家竞争对手”来还原叙事的离谱程度
```

### 实战案例

**台股国巨悖论**：
- 国巨市值逼近700亿美元，直追全球第一村田制造所（~1200亿）
- 但国巨仅为全球第四大被动元件厂商，主打中低端产品
- 营收规模、EPS、技术壁垒均远不及村田、TDK、三星电机
- 结论：“台湾很多上市公司市值膨胀到无法解释的地步”

**SpaceX估值泡沫**：
- 宣称要拿下全球7000亿线上广告市场 + 1万亿网络服务市场
- 相当于“干倒全球所有电信公司、科技七姐妹中的五家、所有AI公司”
- 估值完全脱离行业实际容量

### 与M10（巴菲特指标）的协作

- M10：宏观层面，用“总市值/GDP”判断整体市场泡沫
- M25：微观层面，用“行业容量天花板 vs 宣称市值”判断个股/单行业泡沫

## M26：央行主席意識形態拆解法

> 央行领导人的意识形态倾向（左/右/极右）决定了政策方向，用历史类比评估其政策风险。

### 分析框架

```
□ 定位央行主席的意识形态光谱：
  极左（MMT/无限QE）← 中性 ← 极右（效率市场假说/金本位/去干预）
□ 拆解其核心政策理念：
  □ 对市场价格的信念（效率市场假说 vs 市场失灵）
  □ 对干预权力的态度（扩权 vs 缩权）
  □ 对通胀/就业的优先级
  □ 对资产泡沫的容忍度
□ 寻找历史类比人物：哪个历史人物的理念与此相似？历史结局如何？
□ 评估潜在风险：类似理念在历史上导致什么结果？
```

### 实战案例（沃许 2026）

| 维度 | 沃许 | 历史类比：欧文·费雪1929 |
|------|------|--------------|
| 意识形态 | 近百年来最右的Fed主席 | 大崩盘前的乐观主义经济学家 |
| 核心理念 | 极端信奉效率市场假说，“债券、股票、商品的价格不会错” | “股市已来到永远的高点” |
| 对泡沫态度 | 即使30Y国债破5%也不干预 | “企业盈余高成长合理化了股价上涨” |
| 政策行动 | 成立五大工作小组重构Fed（类比“雍正军机处取代内阁”） | — |
| 历史结局 | 特观察 | 1929年10月崩盘+大崩盘 |

### 沃许“军机处”五大工作小组

1. 美联储沟通机制改革
2. 美联储市场代表体系调整
3. 决策数据依赖与规模优化
4. AI时代潜在生产率变化研究
5. 美联储通胀框架重构

## M27：實體經濟三線驗證法

> GDP增长是否真实？必须从消费、库存、固定投资三条线交叉验证，排除“账面数据支撑”的虚假繁荣。

### 分析框架

```
□ 消费线：
  □ 零售销售名义增速 vs 扣除物价因素后的实际增速
  □ 若名义增长但实际停滞 → 消费“虚假繁荣”
□ 库存线：
  □ 制造业/批发业/零售业库销比趋势
  □ 库销比创新低 → 企业不愿补库存 → 对未来需求极度悲观
□ 固定投资线：
  □ 新屋开工数趋势
  □ 商业营业投资趋势
  □ 持续下滑 → 实体经济投资萎缩
□ 综合判断：
  三线均疲软 + GDP仍增长 → 增长仅靠特定行业账面数据支撑（如AI投资）
  三线均强劲 + GDP增长 → 增长质量高，可持续
```

### 实战案例（美国经济 2026年5月数据）

| 线路 | 数据 | 含义 |
|------|------|------|
| 消费线 | 5月零售销售年增6.88%，扣除物价因素后实际增长几乎停滞 | 消费“硬着陆”接近 |
| 库存线 | 制造业/批发业/零售业库销比全线创出新低 | 企业极度悲观，不愿补库存 |
| 固投线 | 新屋开工数、商业营业投资持续下滑 | 实体经济投资萎缩 |
| 综合 | GDP增长仅靠AI投资的账面数据支撑 | 虚假繁荣，与1929年类似 |

### 与M12（菲利普曲线）的协作

- M12：定位“失业率×CPI”在哪个象限
- M27：拆解GDP增长的真实质量，判断是否仅由单一行业撑起

## M28：周期股估值法（PB vs PE）

> 周期股（存储芯片、钢铁、化工、航运等）的估值逻辑与成长股完全相反——PE是后验指标，PB才是前瞻指标。"买在高本益比，卖在低本益比"是周期股投资的经典法则。

### 核心逻辑

```
周期股盈利随行业景气度大幅波动：

景气底部：
  盈利大幅下滑 → PE被动拉高（甚至亏损导致PE失效）
  但此时PB接近历史低位 → 资产价值被低估 → 买入时机

景气顶峰：
  盈利爆发增长 → PE被压至极低
  但PB远超历史均值 → 资产价值被高估 → 卖出时机

核心原则：
  周期股看PB不看PE
  「买在高PE（景气底部），卖在低PE（景气顶峰）」
  市场用低PE给周期股定价=周期股泡沫化的典型特征
```

### 分析模板

```
□ 确认标的属于强景气周期股（存储/钢铁/化工/航运/能源等）
□ 查看当前PE水平：处于历史分位数的什么位置？
□ 查看当前PB水平：处于历史分位数的什么位置？
□ 诊断：
  低PE + 高PB → 景气顶峰，市场在用高盈利定价 → 卖出/回避
  高PE + 低PB → 景气底部，市场在用低盈利恐慌 → 买入机会
  PE失效（亏损）+ PB历史低位 → 极端底部 → 最佳布局点
□ 验证：行业产能利用率、库存周期、产品价格趋势
```

### 实战案例（SK海力士 2026/6/23）

| 指标 | 数据 | 诊断 |
|------|------|------|
| 营业利润率 | ~70%（极端高位） | 景气顶峰特征 |
| 2025e盈利 | ~1800亿美金 | 盈利爆发式增长 |
| 四年累计盈利预测 | ~7000亿美金 | 市场以此推高估值 |
| 市值 | 超过三星电子 | 市值/盈利不匹配 |
| 估值误区 | 市场用低PE追高 | 泡沫化情绪表现 |
| 正确做法 | 用PB估值 | 检验PB是否已远超历史均值 |

### 与现有框架的协作

- **与 M20（賣鏟人vs賣慘人）**：周期股估值法用于评估賣鏟人（半导体上游）的估值是否已透支景气顶峰盈利
- **与 M25（第一性原理估值批判）**：M25批判市值叙事，M28批判盈利定价方式，两者配合全面诊断估值泡沫
- **与 M10（巴菲特指标）**：M10判断整体市场泡沫，M28判断个股是否处于周期顶峰
- **与 F6（杜邦分析）**：杜邦分析拆解ROE来源，周期股估值法判断ROE处于周期哪个位置
