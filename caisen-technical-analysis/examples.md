# 蔡森形态学实战案例

> **⚠️ 独立性声明**：本文件仅用于演示如何识别和应用12种技术形态。其中的具体市场方向判断（做多/做空、目标价位等）是历史时点的观点，不是当前分析的答案模板。读取时只学习「形态识别步骤」，忽略所有方向性结论。

## 案例一：W底破底翻做多

### 走势描述

某股票从100元下跌至60元后反弹至80元，再跌至58元（略低于第一底60元），随后快速反弹至82元突破颈线80元。

### 分析过程

**第一步：识别形态**
- 第一次探底：60元
- 反弹高点（颈线）：80元
- 第二次探底：58元（破底翻变体W底）
- 第二底略低于第一底 → 形成**破底翻**

**第二步：画颈线**
- 颈线位置：80元（两底之间的反弹高点）

**第三步：量价验证**
- 第二底58元破底时带量（恐慌抛售）
- 翻回80元上方时量能温和（抛压已轻）
- 突破80元颈线时放量 → 有效突破

**第四步：测幅满足**
```
形态高度 = 80 - 58 = 22元
目标价 = 80 + 22 = 102元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：W底 + 破底翻
颈线位置：80元

【交易方向】做多

【进场条件】
- 第一买点：股价翻回80元上方时（82元进场）
- 第二买点（加码）：放量站稳80元上方3日确认

【止损设置】
- 跌破58元（底部最低点）止损
- 风险幅度：82 - 58 = 24元

【目标价位】
- 测幅满足：102元
- 预期获利：102 - 82 = 20元

【风险提示】
- 若翻回后再次跌破60元，破底翻失败
- 若突破颈线后缩量，可能是假突破

【盈亏比】20 / 24 ≈ 0.83（偏低，但胜率约70%可接受）
```

## 案例二：头肩顶假突破做空

### 走势描述

某股票从50元上涨至120元（左肩）回落至90元，再涨至150元（头部）回落至95元，第三次上涨至125元（右肩，低于头部），尝试突破前高150元失败，最高148元后快速回落跌破颈线。

### 分析过程

**第一步：识别形态**
- 左肩：120元
- 头部：150元（最高）
- 右肩：125元（低于头部）
- 右肩尝试突破150元但仅到148元 → **假突破**信号

**第二步：画颈线**
- 左肩回调低点：90元
- 头部回调低点：95元
- 颈线：从90元到95元的向上倾斜线

**第三步：量价验证**
- 左肩成交量大，头部更大，右肩明显缩量 → 上涨动能衰竭
- 假突破时量能虽大但价格未能有效创新高 → 出货信号
- 跌破颈线时放量 → 恐慌性抛售

**第四步：测幅满足**
```
形态高度 = 150 - 92.5（颈线中点） = 57.5元
目标价 = 92.5 - 57.5 = 35元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：头肩顶 + 假突破
颈线位置：90-95元（向上倾斜）

【交易方向】做空

【进场条件】
- 跌破颈线（约93元处）做空
- 反弹无法站回颈线上方时加码

【止损设置】
- 站回148元（假突破高点）上方止损
- 风险较大，需控制仓位

【目标价位】
- 第一目标：60元（颈线 - 形态高度的部分满足）
- 第二目标：35元（完全满足）

【风险提示】
- 若再次突破150元，头肩顶失败
- 跌破颈线后可能出现逃命波反弹
```

## 案例三：矩形底突破做多

### 走势描述

某股票在30-40元之间横盘震荡18个月，多次触及40元回落，多次触及30元反弹。最终某日放量突破40元。

### 分析过程

**第一步：识别形态**
- 下沿：30元（多次触及）
- 上沿：40元（多次触及）
- 横盘时间：18个月
- 形态：**矩形底**

**第二步：画颈线**
- 颈线 = 矩形上沿 = 40元

**第三步：量价验证**
- 横盘期间成交量逐渐萎缩（底部筑底）
- 突破40元当日成交量为近期2倍以上 → 有效突破
- 突破后连续3日站稳40元上方 → 确认突破

**第四步：测幅满足**
```
矩形高度 = 40 - 30 = 10元
目标价 = 40 + 10 = 50元
```
18个月的大级别矩形底，实际涨幅可能远超满足点。

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：矩形底（18个月大级别）
颈线位置：40元

【交易方向】做多

【进场条件】
- 突破40元站稳3日确认后进场
- 或回踩40元不破时进场

【止损设置】
- 跌回矩形内部（跌破38元）止损

【目标价位】
- 第一目标：50元（测幅满足）
- 第二目标：55-60元（大级别形态超额满足）

【风险提示】
- 若突破后快速跌回矩形内部，为假突破
- 横盘18个月的大底，突破后趋势通常较强
```

## 案例四：三角收敛后突破

### 走势描述

某股票从100元上涨至160元后开始整理：
- 第一个高点160元，低点120元
- 第二个高点150元，低点125元
- 第三个高点142元，低点130元
- 最终向上突破142元

### 分析过程

**第一步：识别形态**
- 高点递降：160 → 150 → 142
- 低点递升：120 → 125 → 130
- 形态：**三角收敛**（上升三角偏向）

**第二步：画颈线**
- 上轨：160 → 150 → 142（向下倾斜）
- 下轨：120 → 125 → 130（向上倾斜）

**第三步：量价验证**
- 整理期间成交量逐渐萎缩（正常）
- 突破上轨142元时放量 → 有效突破

**第四步：测幅满足**
```
三角形最宽处 = 160 - 120 = 40元
目标价 = 142 + 40 = 182元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：三角收敛（向上突破）
颈线位置：上轨142元

【交易方向】做多

【进场条件】
- 放量突破142元时进场
- 或突破后回测142元不破时进场

【止损设置】
- 跌回三角内部（跌破135元）止损

【目标价位】
- 测幅满足：182元

【风险提示】
- 三角收敛可能向任一方向突破
- 若突破后迅速回落至三角内部，为假突破
```

## 案例五：M头做空

### 走势描述

某股票从30元上涨至80元（第一顶）回落至60元，再涨至78元（第二顶，略低于第一顶）后开始回落。

### 分析过程

**第一步：识别形态**
- 第一顶：80元
- 回调低点（颈线）：60元
- 第二顶：78元（未能创新高）
- 形态：**M头**

**第二步：画颈线**
- 颈线 = 两顶之间的回调低点 = 60元

**第三步：量价验证**
- 第一顶成交量大，第二顶缩量 → 上涨动能不足
- 第二顶低于第一顶 → 多头力量衰减
- 跌破60元颈线时确认M头成立

**第四步：测幅满足**
```
形态高度 = 80 - 60 = 20元
目标价 = 60 - 20 = 40元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：M头
颈线位置：60元

【交易方向】做空

【进场条件】
- 跌破60元颈线时做空
- 反弹60元附近无法站回时加码

【止损设置】
- 站回65元（颈线上方5元）止损

【目标价位】
- 测幅满足：40元

【风险提示】
- 若跌破60元后快速收回，可能形成破底翻（反转形态）
- 注意观察跌破后的量价关系
```

## 常见错误与注意事项

### 错误一：形态未确认就提前进场
- **错误做法**：W底还在形成中就买入
- **正确做法**：等突破颈线确认后再进场

### 错误二：忽略量价配合
- **错误做法**：缩量突破颈线就追进
- **正确做法**：突破颈线需放量确认

### 错误三：不设止损
- **错误做法**：破底翻失败后死扛
- **正确做法**：跌破底部低点立即止损

### 错误四：过度交易
- **错误做法**：每天都找形态操作
- **正确做法**：只在形态明确时操作，宁可错过不可做错

### 错误五：忽视大周期
- **错误做法**：只看日线形态
- **正确做法**：先看月线/周线大趋势，再看日线找买点

### 错误六：做期权卖方
- **错误做法**：卖Call或卖Put收取权利金
- **正确做法**：只做买方（买Call或买Put），风险有限收益无限
- **案例**：台股大跌时卖权一口拉到涨停板，成交仅两口就是卖方被断头

### 错误七：用本益比判断贵便宜
- **错误做法**：看到AI股本益比20-30倍就认为便宜
- **正确做法**：底部出现在本益比最高（亏损时），高点出现在本益比最低（获利最好时）
- **案例**：南亚科底部时EPS亏损本益比无法算，涨到高位时本益比才10倍

## 案例七：月线翻黑先行信号链 + 纪律操作复盘（百度网盘教学视频）

### 背景

2026年6月蔡森直播教学，覆盖COMEX黄金、BTC、苹果、沃尔玛、NVIDIA、台积电、台指期、机器人概念股的实战分析。

### 第二步：假突破做空纪律操作（M11）

```
台指期做空全流程复盘：
1. 假突破出现 → 做空（铁律）
2. 第一次做空 → 赚4000点

```
BTC 4小时线分析：

3. 破底翻结构出现（但还差一点点确认）
4. 时间波对称：看前一个反弹周期长度，推测本次反弹时间

```
机器人概念B01操作：

4. 测幅满足 → 刚刚好到目标价
5. 满足后不追价！设停利点
6. 逆势走强的看逆势低点作强弱分界
```

### 辅助指标

- **黄金COMEX**：$4349，从$1000涨5倍，2024年喷出后创新高后大量反转，"大量必有高点"

### 错误八：断章取义计算胜率
- **错误做法**：只算错的次数，不算前面赚的次数
- **正确做法**：前面赚的也要算，赚三次错一次又赚一次 = 总体还是赚
- **案例**：蔡森假突破做空连赚多次，中间错一次，然后又赚，总体胜率仍85%

### 错误九：收敛三角满足后追价
- **错误做法**：看到突破后追进去
- **正确做法**：满足后不追价，设停利点，等下一次机会

  - 盘中破了颈线 → 看起来要跌2000点

  - 但收盘没收破 → 假突破
