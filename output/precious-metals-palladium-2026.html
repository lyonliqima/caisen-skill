  • 黄金在2025年末突破$4,500后，2026年初延续飙升势头，5月一度触及$4,732（同比+41%），但6月初急剧回调至$4,330附近

  • 钯金走势严重分化：2025年大涨38.85%后，2026年YTD暴跌20.43%，6月5日单日跌5.36%至$1,263
  • 美联储6月维持利率概率98.6%，高盛预期6月和9月各降息25bp，但ADP非农强劲令降息预期骤降
  • 美元指数跌破100至99.49，但10Y美债收益率4.54%仍接近系统性危机红线
  • 地缘政治持续紧张：中东局势、中美贸易博弈、关税暂缓到期（7月）构成多重不确定性

  • 黄金ETF在2025年创纪录资金流入后，2026年流入势头仍在延续

钯金专项舆情：

  • 路透调查2026年钯金中位预测$1,262.50（较前次上调15%），但Long Forecast极端看涨$2,700
  • 钯金供应赤字预计收窄至约2吨，2025年赤字→2026年可能转为小幅过剩
  • 氢燃料电池（FCEV）对钯金的长期需求替代效应开始显现
  • 技术面：钯金已跌破中长期上升通道下沿，中期偏弱，短期存在超卖反弹可能

第一步：经济周期定位

当前美国经济处于晚周期扩张→过热初期过渡阶段：

指标当前数据信号
PMI制造业~52仍在扩张区间但动能减弱

CPI核心通胀仍有粘性服务通胀顽固，商品通缩

美林时钟定位：处于"过热期"尾部→若Fed不降息可能滑向"滞胀"。过热期最优资产为商品/大宗商品，这解释了贵金属的整体强势。

第二步：货币政策与利率环境

联邦基金利率 3.65% → 6月维持不变概率98.6%
→ 高盛预期6月+9月各降息25bp → 但ADP强劲数据压制降息预期

→ 但黄金无视正利率持续创新高 → 反常信号！主导逻辑已切换

第三步：美元周期分析

美元指数跌破100（99.49）是重大信号：美元进入弱势周期的初期阶段。

  • 美元走弱 → 以美元计价的贵金属获得汇率支撑
  • 去美元化趋势加速：全球美元结算份额从60%降至56%
  • 各国央行持续增持黄金替代美元储备
  • 但"全球比差逻辑"仍在：欧洲和日本经济更差，美元相对仍有支撑

资本三流分析

费雪债务通缩诊断

m（货币供给）：美国债务/GDP >125%，债务扩张空间极为有限
v（周转速度）：资金在金融系统空转，M2增速>实体GDP增速
P（价格）：CPI仍有粘性（~2.5%），PPI受关税影响上行
Q（产出）：PMI仍在扩张但减速
→ 判断：美国尚未进入债务-通缩螺旋，但已进入"债务高原期"——新增债务越来越多用于还旧债

卡莱斯基利润恒等式

总利润 = 投资 + 政府赤字 + 净出口 + 资本家消费 - 工人储蓄

  • 政府赤字持续扩大 → 直接构成企业利润（解释了美股为何在高利率下仍坚挺）
  • 但赤字扩大的代价是国债利息负担加剧 → 长期不可持续
  • 对贵金属的含义：美国不敢停止赤字（否则企业利润崩盘），只能继续发债→美元信用持续受损→黄金长期看涨

美债重置 vs 向心坍缩

结合雷倩分析的三条路径（黄金重估+比特币储备+稳定币），美国正在尝试用金融工程手段避免硬着陆：

  • 黄金重估：如果美国将黄金官方价从$42.22重估至$10,000+，资产端一夜扩大数万亿→利好黄金持有者
  • 稳定币接盘：稳定币发行商已成为美债第17大持有者（~$1,350亿），未来可能增长10倍
  • 无论哪种情景：黄金都是赢家（重估→暴涨，坍缩→避险涨）

M13涨价拆解：钯金涨价是供给端还是需求端？

维度钯金分析判断
驱动因素2025年涨势：供给收缩（南非/俄罗斯）+ 汽车催化剂需求供给端涨价
量价关系价涨量跌（EV替代导致催化剂需求下降）恶性涨价

结论：钯金2025年的涨势属于供给端涨价（输入性通胀型），价涨量跌，不可持续。这解释了2026年的急剧回调。

📐 底层逻辑关联

美联储流动性框架

  • Fed缩表结束 → 净流动性拐点已现
  • 准备金管理购买（RMP）渐进补充 → 流动性底部有托底
  • r*（自然利率）上升：AI资本需求+军费扩张+人口老龄化 → 低利率时代一去不返
  • 实际利率~2% → 传统利空黄金，但被去美元化+央行购金覆盖

真金白银 vs 虚拟财富

  • 美国财政"明天就过不了" → 房地美紧急甩卖2000亿 → 财政流动性枯竭信号
  • 所有政策在用"未来收益"换"当下现金" → 黄金重估成为可能选项
  • 账面财富≠流动性：当危机来临时，实物黄金是唯一不可替代的资产

S-I=X-M 恒等式

  • 中国巨额贸易盈余 → 超额储蓄 → 通缩 → 人民币升值是唯一解
  • 美国巨额贸易赤字 → 储蓄缺口 → 必须外部融资 → 37万亿美债就是缺口的累积
  • 对贵金属含义：中国通缩→人民币升值→以人民币计价的金银可能走弱；但以美元计价的金银因美元走弱而走强

向心坍缩 vs 美债重置

  • 卢麒元预言硬着陆（三流逆变）vs 雷倩揭示金融工程续命（布雷顿森林3.0）
  • 关键变量：中国是否配合美元体系
  • 无论哪种情景：黄金都是赢家
  • 钯金则在两种情景下都面临产业替代风险
