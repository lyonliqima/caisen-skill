# 研判纪律 · 环境过滤器（判市优先于方向）

> 来源：2026-08-25 复盘 6 条预测偏了的归因。本文件是 **append.py 的硬性闸门**，每次方向性分析"给方向之前"必须先过这里。
> 一句话总纲：**先判市，再给方向；弱市不赌方向。**

---

## 第 0 步：先判市（必做，写入 market_regime 字段）

动手给任何方向之前，先回答一个问题——**现在是什么市况？**

| market_regime | 定义（用证据判定，不是拍脑袋） | 给方向的默认规则 |
|---|---|---|
| **趋势市** | 均线多头/空头排列 + 放量突破关键位 + 主线清晰 | 可以给方向；置信度可 >70（需 `trend_confirmed=true`） |
| **震荡市** | 区间上下沿清晰、量能萎缩、无主导方向 | 给方向**必须带条件触发**（"若站上 X 则多"），否则降级为"区间+方向待确认" |
| **弱势市** | 均线压制、量价背离、反弹无量、基本面无改善 | **默认不给单边多/空**，改"区间+方向待确认"；只有放量突破关键位+均线转多才给 |

判定证据来自框架，不要凭感觉：
- 均线系统（蔡森技术形态）→ 多空排列
- 量能（价量一票）→ 突破是否放量确认
- 资本流向（资本三流/路口大爷）→ 钱往哪去

---

## 规则 1：弱势市不赌方向

- 弱势市（market_regime=弱势市）给"多"或"空" → **append.py 会警告**（并强制把置信度压到 60）。
- 正确写法：把单方向改成 **"区间 + 方向待确认"**，例如：
  - ❌ `方向:多 目标:+8%~+20%`
  - ✅ `方向:中性偏多(待确认) 目标:弱反弹看X；放量站上X转多，否则观望；破Y认错`
- 影石创新（`P-20260727-001`）就是这么写的（站稳147转多 / 跌破120转空），所以最后偏空方向判对——**这条写法要推广到所有方向判断**。

## 规则 2：可能加速的品种，不封顶（品位 = 目标上移）

对正在加速/趋势的品种（黄金、股指、强趋势商品），**主判断写"当前区间 A–B；站上 B 看 C"，绝不写"封顶 B"**。

- ❌ `中性 区间3959-4100（封顶4100）` → COMEX黄金后来冲到 4665，封顶被打脸。
- ✅ `偏多；当前3959-4100，站上4100看4300+，破3959转震荡`
- 逻辑：加速品种用"固定上沿"框，尺子一定不够长。把上沿变成"触发位"，破位即上移目标。

## 规则 3：弱势品种不给涨幅，只给"反弹位 + 止损"

弱势/震荡品种，**不写"+8%~+20%"这种涨幅目标**（那是把反弹当趋势，乐观偏差）。

- ❌ `中性震荡偏多 目标:+8%~+20%`（中国铝业，实际只 +1.7%）
- ✅ `弱反弹看 X（约+3%~+5%）；放量站上关键位再看高；破 Y 认错，仓位压低`
- 赌赔率不赌方向，仓位自然压低。

## 规则 4：所有方向性结论改成"条件式"

把"多"改成 **"若放量站上 X 则多，否则观望"**。这样即使看错，也是"条件没触发=没动"，不是"做了反向"。

- 触发条件写进 `falsification` 和 `target_range`（append.py 会检测是否含"若/站上/跌破/放量/转多/转空/待确认"等条件词）。
- 无条件的单边方向在弱势/震荡市会被闸门警告。

---

## 三道关：方向别脱离框架，先过这三关

给方向之前，按资产类别先过对应的一道（或几道）：

| 资产 / 情景 | 必过关卡 | 作用 |
|---|---|---|
| **股指 / 美股 / 宏观** | **路口大爷**：资本流向 + 美元周期 | 标普偏空错 → 没看流动性/美元周期（宽松下美股不跌）。方向前先确认美元与资本流向。 |
| **商品 / 避险资产** | **资本三流**：流向（钱往哪去） | 黄金破4100 → 资本明显流向黄金（避险/贬值），资金流早指向它，但预测写了中性。资金流必须转化成方向。 |
| **弱势个股"偏多"** | **Mi姐**：D/E 资金情绪门控 | 弱势股给"多/偏多"前，先过资金情绪门控；情绪筹码不配合就不给多。 |

> 这三关是框架的"方向前校验"，不是可选项。判市（第0步）之后、写 direction 之前必须跑。

---

## 置信度纪律

- **弱势市的方向性判断，置信度上限 60**（append.py 自动压）。
- **趋势市置信度 >70，必须 `trend_confirmed=true`**（趋势确认：放量突破+均线排列），否则封 70。
- 震荡市方向性判断，置信度建议 ≤65 且带条件。
- **校准线（每次复盘重点看）**：标 70 分的预测，是否约七成兑现？连续不兑现 → 整体偏高，下一轮统一下调。

---

## 检查清单（append 前逐项打勾）

- [ ] 写了 `market_regime`（趋势/震荡/弱势），且有证据支撑
- [ ] 弱势市：没给无条件的单边多/空（否则改"区间+方向待确认"）
- [ ] 加速品种：没写死"封顶"，用了"站上 X 看 Y"
- [ ] 弱势品种：没写涨幅目标，只给了反弹位+止损
- [ ] 方向性结论带条件触发词（若/站上/跌破/放量/转多/转空/待确认）
- [ ] 按资产过了对应关卡（路口大爷 / 资本三流 / Mi姐）
- [ ] 置信度符合纪律（弱势≤60；趋势>70需 trend_confirmed）

## ⚠️ 口径勘误：`append.py` 的 `expiry` 用**日历日**，不是交易日（2026-10-13 实测）

- **实测**：`_infer_expiry()` 的实现是
  `datetime.strptime(date_str,"%Y-%m-%d") + timedelta(days=int(N))`，
  即 `time_window="20D"` 一律按 **20 个自然日**推进。2026-10-13 写盘得到 `expiry=2026-11-02`。
- **与框架正文冲突**：`caisen-10-experts-analyst/SKILL.md` 第 6.6 步与「节假日日历必须查」条明确要求
  **「N 个交易日」必须逐日计数、不得按周历推**。按交易日口径，自 2026-10-13 起 20 个交易日应为 **2026-11-10**
  （逐日：10/14–16 计 3、10/19–23 计 8、10/26–30 计 13、11/2–6 计 18、11/9–10 计 20）。
- **两者差 8 天**，节假日前后的窗口误差会更大（例：跨国庆/春节的 20 日窗口，日历日口径会短 6–9 个交易日）。
- **当前处置（不改代码，先立纪律）**：
  1. **报告正文一律用交易日口径**（这是用户要的可核查口径）；
  2. **台账 `expiry` 沿用工具口径（日历日）**，但在报告与台账 `note` 里**同时写出两个日期**，注明哪个是工具口径、哪个是交易日口径；
  3. 复盘打分时（`score.py`）**以交易日口径的人工核对为准**，不得因 `expiry` 提前 8 天就提前判定 hit/miss。
- **待办**：`append.py` 增加 `--trading-days` 开关或交易日历映射（与 SKILL.md 里 `event_trading_days()` 同一思路），使 `expiry` 与正文口径统一。**在未修好之前，本条纪律为强制。**

# 🔺 方向收敛铁律（2026-10-29 立 · 用户实锤「最近预测基本没有明确方向」）

> 起因：2026-10-20 至 10-28 台账 60 条记录实测 —— **65% 方向写「中性/震荡」，60% 动作写「不动/观望/仅记录」，40% 两者同时成立（对用户零可用信息）**；全量 411 条已结算率仅 **3.2%**（hit 2 / partial 3 / miss 7 / void 1，其余 398 条全 open）。
> 根因不是「行情真的没方向」，而是**四条规则互相叠加形成了「结构性不出方向」的死锁**。以下七条覆盖旧规则，优先级最高。

## 铁律 1：`direction` 字段禁用「中性/震荡」类取值

**允许值只有五个**：`多` / `偏多` / `空` / `偏空` / `不覆盖（本轮剔除该标的）`。
**禁用值**：`中性` / `中性震荡` / `中性偏多` / `中性偏空` / `区间震荡` / `方向待确认` / `划边界不猜方向`。

- 「震荡」是**市场状态**，只能写进 `market_regime`，不能当**判断结果**写进 `direction`。把状态当结论是本轮最大的语病。
- 真的推不出方向 → 写 `不覆盖`，并在 note 写明「本框架无独立推导，该标的本轮出局」，**不许用「中性」占版面**。
- 证据：NR2701（P-20261028-008）自己承认 `random_dir: {'error': '中性/震荡方向无明确方向基准，无法计算 random_dir'}` —— **中性方向连对错都无法判定，等于没有预测**。

## 铁律 2：置信度 ≠ 动作，禁止「低置信 → 不动」

**死锁链条（本轮实测）**：用户主战场是「60 日商品方向」→ 可预测性评级必为「低」→ 置信度硬顶 65 → 叠加弱势/震荡市压到 60 → 而行动阈值是 60 → **结构性永远不动**。

改法：评级限制的是**幅度、期限、仓位**，不是把置信度压到行动阈值以下再据此归零。分档映射，**任何档位都必须落到一个可执行动作**：

| 置信度 | 动作（必填其一） | 幅度/期限收缩 |
|---|---|---|
| ≥70 | 标准仓（≤5%） | 不收缩 |
| 65–69 | 小仓（≤3%） | 期限压至原窗口 2/3 |
| 60–64 | 试仓（≤2%）**或 触发式条件单** | 期限压至 1/2 |
| 55–59 | **触发式条件单**（价位+止损+目标，不到价不动） | 期限压至 1/3，幅度按 ±1σ 减半 |
| <55 | `不覆盖`，出局 | — |

**`position` 字段禁用纯否定式终稿**：`不动·仅记录` / `观望为主` / `不参与` / `0%新建` 单独出现一律退回重写，必须补上「触发价 + 止损 + 目标 + 仓位档」。
（允许保留否定式**前提**：后面紧跟触发布署方案。NR2701 那条「现价不动，但反弹 17000-17086 抛空≤10%、回落 16285-16400 做多≤8%」是**合规样例**。）

## 铁律 3：禁止三情景概率并列

`scenarios: {bull_prob / base_prob / bear_prob}` 一律删除（本轮残留 52 条）。用户铁律：**不给概率，反三情景并列**。
改为单字段：`主判断`（一句话方向+幅度+期限）＋ `falsification`（证伪位）＋ `flip`（触发反向的价格条件）。

## 铁律 4：同标的同日只允许一张有效卡

同日同标的多卡并存一律降级：保留**最新且置信度最高**的一张，其余 `status=superseded`（不是都留 open）。
本轮实测 3 组重复：FG2701（10-20，两张方向相反：中性偏多 vs 中性偏空）、C2701（10-22，两张完全相同）、NR2701（10-28，三张：中性偏多 62 / 中性偏多 40 / 中性震荡 55）。
**改判走贝叶斯更新追加 trigger，不新建平行卡**（沿用既有规则，此处补上强制执行：新建前必须先查同标的 7 日内是否有 open 卡）。

## 铁律 5：到期必结算，禁止留 open

`expiry` 过了 3 个交易日内必须 `score.py mark`（hit/miss/partial/void）。**未结算的预测等于没做**——无法校准置信度，无法证伪方法。
当前 398 条 open 是系统性失效，不是数据问题。

## 铁律 6：闸门不通过 = 降级，不是改向

风控终审 / 期货团六闸门（时间闸门、流动性闸门、位置口径闸门等）不通过时：
**只降仓位、降期限、加触发条件，不许把方向改成「中性」或把动作改成「不动」**。
本轮工业硅（10-28）因「零合规合约」把整份报告降为「方向参考·0% 新建仓·不出交易计划」——**合约不可执行应写「无合规合约，改用 XX 合约 / 或出局」，而不是把方向抹掉**。

## 铁律 7：每条记录必带五件套，缺一不可进终稿

`方向`（涨/跌）＋ `幅度`（目标价区间）＋ `期限`（具体日期）＋ `证伪位`（价格）＋ `动作`（价位+仓位档+止损）。
报告正文与台账双写，缺项由 append 前检查清单拦截。
