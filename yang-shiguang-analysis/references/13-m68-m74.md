## M68：三大报表三维定位法（存量 / 增量 / 流量）

**核心命题**：一张公司 = 三张表联立。三张表是同一家公司的三个切面，永远均衡。先有"感觉"再深究科目。

| 报表 | 维度 | 杨世光俗名 | 恒等式 / 落点 | 对应估值尺 |
|---|---|---|---|---|
| 资产负债表 | **存量**（从创立到报表日的累积） | 找钱·花钱表 | 资产 = 负债 + 权益；增量利润最终沉淀进权益 | **PB** 市净率（股价 / 净资产） |
| 利润表 | **增量**（当期赚赔） | 赚钱·赔钱表 | 收入 − 成本 = 利润 → 回流权益（未分配利润） | **PE** 市盈率（股价 / EPS） |
| 现金流量表 | **流量**（钱怎么来去） | 钱来·钱去表 | 经营 + 投资 + 筹资 = 现金净变动 → 沉淀为资产科目 | **PS** 市销率（市值 / 营收） |

**微积分比喻（记忆锚）**：利润表是**微分**（瞬时增量），资产负债表是**积分**（增量累积的总和）。流量（现金）沉淀为存量（资产科目）。

**资产负债表恒等式拆解**：
- 资产 − 负债 = **净资产（股东权益）**
- 资产 − 权益 = 负债
- 负债 / 权益 = **杠杆率**（权益 1 块 + 负债 2 块 = 杠杆 200%）

**实践口诀**：买股票是买企业（分割股权让小散做大生意）；二级市场比一级更成熟、安全边际更高，但爆发性/成长性不如一级。看报表先抓"钱怎么来（负债还是权益）、钱花去哪（变成什么资产）"。

## M69：流动性梯度判读法（科目上→下 = 变现性↓ = 时间敏感度↑）

**核心命题**：无论并列还是直列，报表**自上而下的科目排序 = 时间变现性的逆序**。越上面越能马上变真金白银（跟时间无关），越下面越难变现、越需要时间证明价值。

| 位置 | 资产侧 | 负债侧 | 判读 |
|---|---|---|---|
| **最上** | 货币资金、交易性金融资产（股票/理财） | 短期借款、应付票据/账款、预收款 | 资产：随时提现，**最安全**；负债：马上要还，**压力最大** |
| **中间** | 应收款项、存货 | 一年内到期非流动 | 存货"价低就卖得掉、价高卖不掉" |
| **最下** | 固定资产、无形资产、**专利权/商誉** | 长期借款 | 资产：难卖、需时间证明价值，**越下越有猫腻/风险**；负债：越久利率越高但短期无压力 |

**判据**：
- 资产越上面越安全，越下面越有"估值难、变现难"的猫腻。
- 负债越上面压力越大（明天就要还），越下面压力越小（可拖）。
- 但**不能全要流动资产/全现金**：钱都躺现金就没必要开公司融资；全砸设备也有风险——要均衡。
- 注意行业营业周期：房地产一个周期 4 年、造船 3 年+，"一年以内"的流动/非流动划分要按产业营业循环看，不是死卡日历。

**常见误读**：把"都是现金"当绝对好——现金过多说明钱没花到有意义的地方；把"非流动资产多"当绝对坏——重资产公司的设备本就是生产资料。

## M70：应收应付·预收预付定价权透镜（产业链地位 + 同业优劣势）

**核心命题**：从"谁欠谁钱"一眼看出公司在**产业链的谈判地位**和**同业竞争的定价权**。这是杨世光最锋利的微观洞察之一。

| 科目 | 性质 | 高余额意味着 |
|---|---|---|
| **预收款**（先收定金，欠货/欠服务） | 负债（交房/交货时转收入→利润） | **客户求我** = 强势、有定价权（茅台/五粮液/万科/碧桂园预收数千亿、硅片厂收客户定金） |
| **预付款** | 资产 | 我求别人 = 弱势 |
| **应收款项**（货卖了追债） | 资产 | 我求客户 = 弱势；东西再好也不该有高应收 |
| **应付款/票据**（欠供应商） | 负债 | 对上游极强议价能力（苹果应付多≠坏，是想接它单的厂求它） |

**判据**：
- **预收 > 预付** → 公司在产业链/同业中是"定价权大哥"，不是"价格跟随小弟"。
- 横向比同业：五粮液 vs 茅台，**先不看毛利率、不看单价，先看预收款**，差距直接暴露地位差。
- 房地产负债的 1/3～1/2 来自**预收款**，不是真负债——交房即转收入。
- 纵向看产业链角色：应收高 = 下游弱、被人欠；应付高 = 上游强、欠别人。

**常见误读**：① 把预收款当"负债风险"——它本质是未来收入，交房即消失；② 把高应收款当"生意好"——恰恰是被客户占用资金、弱势信号。

## M71：股东权益结构质量透镜（资本实力 + 老板决心）

**核心命题**：光看资产负债不够，**股东权益怎么成型**直接暴露公司质量。股本、资本公积、盈余公积、未分配利润的比例，比单看总资产更说明问题。

| 科目 | 来源 | 质量判读 |
|---|---|---|
| 实收股本 | 发行股本（本金） | 基准 |
| **资本公积** | ① 高价发股超面值部分 ② 资产重估增值 | **中性偏负**：过大 = 老公司 / 过去高位圈钱 / 套牢人多；靠融资或重估充实，**对股价未来影响小** |
| **盈余公积** | 盈余按法定 10–15% 提拨，**进去不能分红/回购** | **好项目**：越多 = 老板做实资本、不急于分掉的决心越强 |
| **未分配利润** | 历年留存 | 回购 / 提高分红率的**弹药源**；越多 = 资本越充足 |

**判据（倍数越大越好）**：
- 盈余公积、未分配利润相对股本的倍数越大 → 资本实力越强，**不靠不断圈钱/资产重估充门面**。
- 例：股本 10 亿 + 盈余公积 2 亿 + 未分配利润 50 亿 → 通常不是差公司。
- 反例：资本公积畸高 + 盈余公积/未分配利润薄 → 靠融资和重估堆出来的"虚胖"。

**常见误读**：以为股东权益高就稳——要拆"怎么来的"。资本公积高的"股东权益"含金量远低于盈余公积/未分配利润高的。

## M72：两桶金估值框架（价格 vs 内涵价值）

**核心命题**：投资人赚两桶钱，都来自"外部价格"与"内部价值"的落差。

- **第一桶金 = 市场失灵 / 定价失误**：价格变化快（每天 9:30–15:30 浮动），价值变化慢（一家公司三天暴涨不代表业务三天打七折）。当价格 < 内涵价值 = 低估 = 黄金坑。**来源是市场定价的错误，不是公司变好**。
- **第二桶金 = 产业未来成长性**：公司持续创造现金/利润的能力，从报表及衍生工具预测"可持续性"。

**操作衔接**：
- 价值用三大报表算（M68），价格黑板天天有 → 落差即机会。
- 与 **M10 巴菲特指标**、**F5 戈登模型** 衔接：都用"内涵价值 vs 市场价格"的框架。
- 巴菲特逻辑三件套：安全边际、能力圈、市场波动——买股票=买生意。

**常见误读**：把"股价三天涨 32%"当公司价值涨 32%——价值不会三天变，变的是价格（可能是失灵）。

## M73：资产报酬率–资金成本剪刀差法（ROA vs WACC）

**核心命题**：资产负债表是恒等号（量相等），赚不赚钱看**率的差**。

```
资产报酬率 ROA   −   加权资金成本 WACC   =   杠杆放大后的获利空间
   （资产能赚多少）      （找钱的成本）
```

**判据**：
- ROA(8%) > WACC(3%) → 每 1 元资产净赚 5%，且因"资产=负债+权益"恒等，**杠杆会放大**这 5%（用 5% 成本的负债去赚 8% 的资产收益）。
- 反过来 ROA < WACC → 借得越多亏越多，杠杆是毒药。
- 目标：**资产报酬率越高越好，负债资金成本越低越好**；中间的结构调节（加多大杠杆）是核心学问。

**实践**：上市公司普遍用负债扩张（8% 资产收益 vs 5% 负债成本 → 股东倾向多借）。但债权人/投资人/银行都要有安全边际才成立。

**衔接**：ROA 是 M68 资产负债表侧、ROE 是利润表侧（股东视角）；ROE 的系统拆解见 **F6 杜邦分析法**（净利率×周转率×权益乘数）。

## M74：商誉 / 专利权并购后遗症诊断法

**核心命题**：最底层的非流动资产（商誉、专利权）通常由**并购**产生，难变现、需时间证明价值，且摊销/减值规则会反噬未来利润表。

**判据**：
- 商誉、专利权高 → 过去有并购"诟病行为"（只有并购才会凭空产生这两科目）。
- 并购溢价形成的商誉，一旦减值测试不达标 → 一次性大额减值直接砸利润表（A 股"商誉雷"经典路径）。
- 专利权摊销政策变化 → 未来每年的摊销成本影响利润表可持续性。
- 这两项是"感觉很有价值、卖钱很难、要时间证明"的典型，读表时单独拎出来看风险。

**衔接**：与 **M25 第一性原理估值批判**、**M41 债务可持续性** 互补——看"纸面资产"是否经得起时间。

## 3 分钟快速读表 Checklist（M68–M74 实战串联）

> 杨世光目标：30 秒～3 分钟看完报表"有感觉"，快速断好坏。

1. **平衡感**（M68）：资产 = 负债 + 权益？杠杆率多少？（权益 1 + 负债 2 = 200%）
2. **流动性梯度**（M69）：资产上端是不是一堆现金/理财？下端是不是商誉/专利/重设备堆着？负债上端短期压力多大？
3. **定价权**（M70）：预收 > 预付？应收高不高？同业预收一比，地位立判。
4. **股东质量**（M71）：盈余公积、未分配利润相对股本倍数大不大？资本公积是不是虚胖？
5. **两桶金**（M72）：当前价格相对报表内涵价值，是失灵低估（第一桶金）还是看未来成长（第二桶金）？
6. **剪刀差**（M73）：ROA 是否 > WACC？杠杆在放大利润还是放大亏损？
7. **并购雷**（M74）：商誉/专利权高不高？过去并购会不会在未来减值炸利润？
