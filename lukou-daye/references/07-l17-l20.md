# E 组｜产业周期与资产定价深层框架

## L17：重资产产业周期供给弹性分析框架

**专门用于解释长产能周期、重资产行业的景气波动与盈亏规律，也是解读半导体、航运等超级周期的底层逻辑。**

### 核心定义

**供给价格弹性**：价格每变动 1%，对应市场供给量的变动幅度。数值越低，代表产能调整越滞后、越难跟上价格变化。

**需求价格弹性**：价格每变动 1%，对应市场需求量的变动幅度。数值越低，代表需求刚性越强、替代成本越高。

### 底层逻辑

**超级牛市成因：供需弹性双低**
- 需求端刚性强、非买不可
- 供给端受建厂、造船等长周期约束，即便价格翻倍，产能也无法快速释放
- 供需缺口会推动价格暴涨，企业边际收益呈指数级扩张

**周期下行反噬：低弹性的风险对称**
- 供给弹性低是双刃剑。景气反转时，前期投入的产能会集中交付
- 固定成本极高且无法快速收缩摊销，极易引发全行业亏损，甚至头部企业批量破产

### 标准分析维度

1. **产能建设 / 交付的周期时长**（决定供给弹性高低）
2. **下游需求的替代成本**（决定需求弹性高低）
3. **当前行业资本支出规模与未来产能释放节奏**
4. **历史周期中的行业出清与破产案例**

### 应用场景

- **上行验证**：2022-2023 年货柜航运牛市、2025-2026 年半导体牛市
- **下行验证**：韩国头部船商破产、存储厂商尔必达 / 力晶 / 茂德倒闭、AMD 分拆格罗方德
- **当前预判**：AI 算力稀缺信仰松动，半导体大额资本支出已落地，未来产能过剩风险持续放大

## L18：科技巨头战略转型与格局重构分析框架

**用于分析互联网 / 科技巨头主业见顶后的战略转向，及其对产业链竞争格局的连锁影响。**

### 底层逻辑

科技巨头的战略转向通常不是主动扩张，而是核心主业增长触顶后，对存量资产的变现与再利用，本质是寻找第二成长曲线。

### 标准分析维度

**动因层：主业天花板验证**
- 核心营收赛道的市场存量是否见顶
- 核心业务的投入产出比是否持续下降（如军备竞赛性价比走低）

**资源层：存量资产复用能力**
- 现有资产（算力、用户、技术、数据）能否直接转化为新业务的核心竞争力
- 新业务是否能复用原有生态优势

**格局层：角色转换的行业冲击**
- 企业从产业链的 "需求方 / 买家" 转变为 "供给方 / 卖家"
- 对原有市场头部玩家的份额、定价、增速的冲击程度
- 是否会触发行业价格战

**信号层：市场风险偏好转向**
- 市场对战略转向的定价反馈，反映资本对行业底层逻辑的共识变化
- 如市场奖励 "减少投资、加速变现"，意味着无节制资本支出的时代结束

### 应用场景

- Meta 从广告 + 大模型自研，转向算力出租 + 云服务的战略转型分析
- 判断科技巨头转型对上下游产业链的冲击路径

## L19：货币政策前瞻指引与预期管理分析框架

**用于分析央行货币政策框架的演变，及其对资本市场的长期系统性影响。**

### 核心定义

**前瞻指引（即预期管理）**：央行通过发布未来短期利率的政策路径，引导市场形成长期利率预期，进而调控全社会投资、消费与物价的政策工具。

### 运作传导机制

```
央行调控短期政策利率
  → 通过前瞻指引给出未来短期利率路径
  → 市场将短期利率累加形成长期利率预期
  → 影响居民 / 企业的中长期消费与投资决策
  → 最终作用于物价、就业与总供需
```

### 政策失效分析维度

**公信力维度**：政策制定者任期与指引周期不匹配，市场对远期承诺的信任度持续下降

**机制异化维度**：预期管理异化为 "央行托底" 的刚性信仰，导致市场出清机制失效，资产价格长期扭曲

### 政策转向影响分析维度

| 维度 | 影响 |
|------|------|
| **市场波动率** | 失去明确预期锚后，资产价格波动幅度的系统性抬升 |
| **期限溢价** | 长期利率中隐含的时间风险补偿，将进入长期上行通道 |
| **政策传导** | 基于即时数据的相机决策，其传导效率与政策不确定性的变化 |
| **风险出清** | 失去托底预期后，极端黑天鹅、灰犀牛事件的兑现概率 |

### 应用场景

- 美联储、欧央行、英央行、加央行集体放弃沿用 30 年的前瞻指引框架的影响分析
- 判断央行政策框架重构对市场波动率和期限溢价的长期影响

## L20：资产价格泡沫账面财富真实性分析框架

**用于识别股市、房市等资产的 "纸面富贵" 幻觉，判断泡沫风险与财富兑现能力。**

### 核心底层认知

财富的本质不是账面货币数字，而是对真实资源的掌控与实际兑现能力。

### 标准分析维度

**兑现悖论**
- 资产上涨时仅极少数人可成功高位变现
- 若市场形成集体卖出共识，价格会直接崩盘，绝大多数账面财富永远无法兑现

**交易占比验证**
- 真实成交的资产仅占总存量的极小比例（如房产仅千分之一交易）
- 少量交易的价格决定了全部存量的账面估值，不代表整体可按该价格兑现

**一致预期反身性**
- 当市场普遍形成 "涨到某点位再卖出" 的一致预期时，该点位必然无法到达，价格会提前反转

### 应用场景

- 台湾股市上涨带来的账面财富幻觉分析
- 散户 "等 5 万点再调仓" 的集体预期风险识别
- 房地产价格的纸面增值逻辑与真实兑现能力评估

## L19-补：利率中枢三分法与前瞻指引删除的不确定性溢价（2026-09-17 追加 · 置于文末以保持既有编号不动）

> **来源**：公众号「燧木数农」2026-09-17 文，完整核验见 `references/10-fed-rate-ag-cost-transmission-20260917.md`
> **与 L19 的关系**：**并行使用、互不替代**。L19 原文回答「前瞻指引框架为什么会失效、失效后影响什么维度」；本补充回答「**一次具体的加息/降息该给多少分量**」——L19 缺的是这个操作层。

### L19-补-1 利率中枢三分法（判一次政策动作的分量）

| 层 | 看什么 | 改变的是什么 | 时间尺度 | 数据源 |
|---|---|---|---|---|
| **第 1 层：单次幅度** | 本次 ±25bp | 当期现金成本 | 天–周 | FOMC 声明 |
| **第 2 层：SEP 路径中值** ★ | 年末及未来 2–3 年利率中值 vs 上一版 | **所有人对未来三年资金价格的假设**（库存持几天、远期给多少升水、年度预算按什么成本做） | **季度–年** | FOMC SEP（3/6/9/12 月） |
| **第 3 层：名义–实际分离** ★ | 10Y **TIPS 实际收益率**（非名义） | 全球资本对安全资产的回报要求 | **年** | 美财政部 TIPS 序列 / 美联储 H.15，日频 |

**硬规则**：
- **判分量只看第 2、3 层。** 单看 25bp 会把一次「中枢上移」错读成「一次性微调」。
- **第 3 层最难被一次会议改回去**——它是三条里最慢的变量。只要实际利率不显著回落，融资成本中枢就一直在高位。
- **实际利率与名义利率必须分开报**：名义 = 实际 + 通胀预期；只说名义无法判断是「政策收紧」还是「通胀预期上移」。

**2026-09-16 实例（已逐项核验）**：25bp 加息至 3.75–4.00%（12 票委全票）；SEP 年末中值 2026 年 3.8%→**4.1%**、2027 年 3.6%→**4.1%**、2028 年 3.4%→**3.9%**；10Y TIPS 实际收益率 **2.62%**（两年最高）、10Y 名义 **5.00%**。

### L19-补-2 「前瞻指引被删」的检测器与价格含义

**检测器（可机器化）**：声明中是否包含「在考虑目标区间进一步调整的幅度与时机时，委员会将仔细评估后续数据与风险平衡」这一整段。

```
有前瞻指引 → 央行主动压缩未来的可能性空间 → 远期定价可少含一块风险补偿
删掉前瞻指引 → 路径分布变宽 → 远期定价必须含进「不确定性溢价」
```

**接 L19 既有表**：直接对上「期限溢价」行（长期利率中隐含的时间风险补偿进入长期上行通道）。本次美联储删指引、且主席明确表示「不会提供前瞻指引，而是根据经济数据与市场信息评估」「单个数据充满噪音，趋势才最重要」——是 L19 判据的**实例化验证**，而非新框架。

**注意时点特征**：删除指引的影响**不体现在决议当天报价上**，而是慢慢进入**远月合约与长单报价**。因此不能用「决议日价格没动」来否定这条变化。

### L19-补-3 「慢变量 vs 事件驱动」分离器（判压力性质）

```
决议日各资产涨跌幅全部 < 1%（日常波动量级）
  → 该政策事件未触发一次性重估 → 压力若存在，必是慢变量（中枢 / 融资成本 / 库存意愿）
反过来：
  → 不能因决议日价格没动，就判定「政策无效」
```

**使用方法**：先用本分离器定性「这是事件冲击还是慢变量」，再决定用 L19-补-1 的第 2、3 层还是用短期事件传导工具（L4 地缘冲突穿透）。

### L19-补-4 使用限制

- 「前瞻指引删除 = 不确定性溢价」是**方向性推断，不是可观测价格**。只能用「后续声明是否重现该表述」来证伪，不能直接量化。
- 本补充的实例数据来自 2026-09-16 一次会议，**会议级别的事实会过期**；三分法结构不过期，具体数值必查当期 SEP。
- 与本框架「不给概率、给条件式判断」的偏好一致：本补充的输出应是「若 X 连续 N 期成立 → 则 Y」，不得写成情景概率。
