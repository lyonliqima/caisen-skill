# 杨世光宏观·负债端与双谱系三工具（M79–M81）

> **来源**：杨世光《金简报》2026-10-08 期录音整理稿（ASR 二次转写）。原文核验见 `base-logic/负债端崩溃与产能过剩双谱系-核验观点.md`。
> **性质**：这是**研究方法**，不是观点集合。节目里的方向性判断（10 月股灾、黄金跌破 4000、产能过剩左右都不利）是历史时点的例子，**不可**当当前结论复用。
> **定位**：本模块补齐 yang-shiguang-analysis 的**信用端读数件**与**叙事判别件**——M78 管「企业新发债首日」，本组补「**主权债一级拍卖结构**」「**债务滚动成本**」「**同一现象的双谱系解读**」。
> **与 M75–M78 的分工**：M75–M78 解决「**实物与信用端在发生什么**」；M79–M81 解决「**主权融资端的结构与成本读数**」与「**叙事 vs 方向的分离**」。
> **顺序**：先跑 M63 定利率归因，再跑 M79/M80 定主权融资端状态；M81 是**任何「现象 → 结论」表述的通用前置过滤器**。

## M79：主权债拍卖结构温度计

> **国债拍卖不是「一场招标」，是「无风险利率的定锚事件」。**
> 读拍卖**不能只看得标利率**——得标利率高只说明「要求补偿高」，不说明「有没有人买」。
> 真正的信息在**得标结构**：谁买了、谁没买、需不需要华尔街兜底。同一组数据有**两种相反读法**，必须裁决。

### 核心原理

```
国债拍卖的三个「得标结构」口径（必须分列，不可合并）：

① 一级交易商（Primary Dealer，托市 / 造市者）
   市场没有买盘时，他们必须跳出来承接剩余
   → 得标比例【高】= 市场买盘不足、需要兜底（需求弱）
   → 得标比例【低】= 市场自发性买盘充足、无需兜底（需求强）
   ⚠️ 反面读法：得标比例【极低】也可读作「最后防线撤离 / 华尔街被挤出」
      —— 须用②裁决

② 间接投标人（Indirect Bidder ≈ 海外央行 + 政府货币当局 + 经经纪行下单的非美私人 + 长线机构）
   → 比例【高】= 海外需求强（但须警惕：含大量短期博弈资金）
   → 判据：这类资金「来得快、走得也快」——高比例既可能是真需求，也可能是
     「收益率够诱人 → 抢票 → 数据一转坏就撤」的套利盘（参 M78 的「需求幻觉」）

③ 直接投标人（Direct Bidder，本土机构自投）

辅助口径：
  · 投标倍数（bid-to-cover）→ 相对【近 6 次同期限均值】比较，不看绝对值
  · 得标利率 vs 投标截止前 when-issued 收益率 → 负偏离（得标低）= 需求强
```

### 四条判据（决定结论怎么写）

```
① 结构判据（第一顺位）：必须报出 ①一级交易商 / ②间接 / ③直接 三档得标比例
   → 只报「得标利率」= 未完成读数

② 分位判据：用【双基准】定位——该期限「近 6–10 次均值」+「该期限历史极值」

③ 偏离判据：得标利率相对 when-issued 的偏离方向与幅度

④ 双读裁决判据（本模块的核心纪律）：
   一级交易商比例创新低，有两种读法且结论相反——
   读法 A（需求真实）  ：市场买盘充足，不需要华尔街兜底
   读法 B（防线失效）  ：隐性稳定机制退出，最后防线撤离
   → 裁决器：看②间接投标人是否具备「快速撤离」属性
     若间接投标以大额、短期博弈资金为主 → 倾向读法 B（M78「需求幻觉」同源）
     若为央行 / 长线配置的机械再平衡   → 倾向读法 A
   → 无法裁决时，禁止单取任何一种读法
```

### 标准分析步骤

```
□ 第一步：记录发行规模、期限、得标利率、投标倍数（写明相对何均值）
□ 第二步：分列三档得标比例（一级交易商 / 直接 / 间接）——不可只看得标利率
□ 第三步：双基准定位一级交易商比例的历史分位
□ 第四步：裁决②间接投标的性质（央行/长线 vs 短期博弈资金）→ 走判据④
□ 第五步：输出——「需求真实」或「防线失效」，二选一或并列标注分歧；禁止含糊合并
```

### 与 M78 的分工（合起来才是完整融资端读数）

| 模块 | 看什么 | 口径 |
|---|---|---|
| **M78** 新发债首日温度计 | **二级市场承接力**（企业 / 大额新发债首日相对面值偏离） | 二级 |
| **M79** 主权债拍卖结构温度计 | **一级市场拍卖结构**（主权债得标结构三档 + 投标倍数） | 一级 |
| 二者联读 | 「融资端对边际新增供给的容忍度」——**一级结构 + 二级承接** | 一级 + 二级 |

**引用纪律**：凡写「拍卖成功 / 需求旺盛」，**必须同时报出三档得标结构并完成判据④**；只取得标利率即下结论的，判为未完成读数。

## M80：债务滚动成本重估法（借新还旧利率差）

> 判断「利率上行对债务人的真实压力」，**不看总发行量，看同一笔债务滚动时的利率差**。
> 把抽象的「利率上行」翻译成**可数的利息账单**——这是把宏观变量落到财政约束上的唯一硬办法。
> ⚠️ 同时是本技能的**反面教材**：它天然是一个**慢变量**，最容易被误用来推**快结论**。

### 核心原理

```
四步：
① 锁定「借新还旧」规模 —— 本次发行中用于【偿还旧债】的部分，不是总发行额
   （例：发行 390 亿 ≠ 新增债务 390 亿；其中 N 亿是对旧债的滚动再融资）
② 找旧债的原始得标利率与发行日
③ 算利率差 ΔR = 新得标利率 − 旧得标利率
④ 额外利息 = 借新还旧规模 × ΔR × 剩余期限

2026-10-08 实例（节目口径，算术自洽）：
  发行 390 亿（10 年期），其中 200 亿为借新还旧
  旧债 2016-10 得标 ≈ 1.79%（⚠️ 未经财政部一手源确认）
  新得标 5.300%  →  ΔR ≈ 3.51%
  额外面息成本 = 200 亿 × 3.51% × 10 年 ≈ 70.2 亿
```

### 三条判据

```
① 口径判据：必须区分【总发行额】与【借新还旧额】——两者不可混用
② 期限判据：额外利息必须绑定【剩余期限】（10 年 vs 1 年差异巨大）
③ 时间尺度匹配判据（本模块的核心纪律）：
   该指标是【多年累积】的慢变量
   → 只能用来判断「债务的长期结构压力」，不能用来推「某月/某周崩盘」
   → 凡把「十年累计利息」当作「近期市场崩盘依据」的表述
     → 判为【时间尺度不匹配】，禁止作为择时依据
```

### 标准分析步骤

```
□ 第一步：拆出「借新还旧额」与「净新增额」（口径分列）
□ 第二步：查旧债原始得标利率与发行日（须一手源，查不到标 ⚠️）
□ 第三步：算 ΔR 与额外利息（绑定剩余期限）
□ 第四步：写明该数字的【时间跨度】——是 10 年摊还是 1 年
□ 第五步：输出——「长期结构压力」判定 + 明确【不作】短期择时依据的声明
□ 第六步：与 M41（r vs g）、M42（资金供需反推）联读
```

### 应用纪律

- **本模块最容易犯的错，是节目自己犯的那个错**：拿「十年 70 亿额外利息」去论证「10 月股灾」。**结构压力 ≠ 时点**。
- 正确表述：**「同一笔债务的滚动成本从 X 抬到 Y，未来 T 年额外利息 Z」——只描述财政约束的斜率，不给崩盘日期。**
- 与 **M41**（债务可持续性二分，r vs g）互补：M41 判「会不会走向不可持续」，M80 量化「每一步滚动要付多少」。

## M81：双谱系对照解读法（同一现象，左右两读）

> 对同一个经济现象，用**左（马克思）与右（海耶克）**两套思想谱系分别解读，
> 目的**不是选出谁对**，而是把「叙事」与「方向」分离——**看这套解读能不能给出可验证的方向与证伪位**。
> 若两套解读**殊途同归**（结论都指向同一侧），只说明「该现象被普遍承认为风险」，**不等于给出方向**。

### 核心原理

```
同一现象（典型：产能过剩）的两种谱系读法：

【马克思读法】产能过剩 = 资本主义崩溃的宿命
  生产资料私有化 → 厂商竞争扩产、抢市占 → 利润率下滑
  → 面对银行利息 / 地主地租无能为力 → 只能剥削工资
  → 有效需求不足 → 相对供给过剩 → 结构性危机（宿命论）

【海耶克读法】产能过剩 = 错误利率信号 → 清算式自我疗愈
  错误的利率 / 货币信号 → 厂商误判资金充裕 → 过度投资、资源错配
  → 市场通过危机「自我疗愈、最终清算」（"就死光吧"）

两套读法的【共同落点】：都对【资产端】不利。
```

### 三条判据（判别器，不预设结论）

```
① 可证伪判据：这套解读能否给出【可观测的方向 + 幅度 + 时点 + 证伪位】？
   → 不能给出 → 只作【背景 / 氛围】理解，禁止作交易依据

② 殊途同归判据：若左右两套解读【结论一致】（都指向同一侧）
   → 只说明「该现象被普遍承认为风险」
   → 【不等于】给出方向、幅度、时点
   → 此类段落属于【叙事】，不是【分析】

③ 来源判据：这套叙事【从哪来】？＝政策 / 思潮氛围的指纹
   → 用途：判断当前顶层政治经济路线的偏向（参 M26 / M65）
   → 但「思潮回归」本身不是价格信号
```

### 标准分析步骤

```
□ 第一步：抽出被解读的现象（如「产能过剩」）
□ 第二步：并列写出左（马克思）与右（海耶克）两套读法
□ 第三步：走判据①——两套读法各自能不能给出可验证的方向与证伪位？
□ 第四步：走判据②——若结论殊途同归，明确标注「这是叙事，不是方向」
□ 第五步：走判据③——把叙事当作「思潮氛围指纹」归档，不当作交易信号
□ 第六步：输出——「可作背景」或「可作依据」二分类；后者必须附方向 + 证伪位
```

### 与既有模块的分工

| 模块 | 视角 | 本模块的关系 |
|---|---|---|
| **M26** 央行主席意识形态拆解 | **个人**意识形态 → 政策倾向 | 本模块是**流派谱系**层面的对照，颗粒度更粗 |
| **M65** 政策范式转移的定价映射 | 范式转移 → **定价映射**（看跌期权 / 波动率 / ERP） | 本模块不映射定价，只做**叙事 vs 方向的分离** |
| **M36** 物价倒推供需 | 用价格反推**真实供需** | 本模块处理「同一现象被叙事包裹」时的**剥离动作** |

**引用纪律**：凡「某现象被 X 学派解读为 Y」的表述，**必须先走判据①**——不能给出可验证方向与证伪位的，一律归入「背景」，**不得写入结论**。

## M79–M81 联动配方

```
判「这场国债拍卖是不是真的强」     → M79（三档得标结构 + 判据④双读裁决）
判「利率上行对债务人的真实压力」   → M80（借新还旧利率差 × 期限；只给斜率不给时点）
判「同一现象左右两派怎么看」       → M81（先走可证伪判据，不能证伪则只作背景）
判「主权融资端整体状态」           → M79（一级结构）+ M78（二级承接）联读
判「一个宏观结论有没有可证伪位」   → M81 判据①（通用前置过滤器）
```

**共用一条铁律**：**凡「某现象 = 某宏观含义」的表述，一律先跑 M81 判据①；凡「拍卖成功 / 债务压力」的表述，一律先跑 M79 / M80 补齐结构口径与时间尺度。**

> **与 M63–M67 / M75–M78 的关系**：M63–M67 管**利率本体**；M75–M78 管**实物与信用端状态**；M79–M81 管**主权融资端读数**与**叙事判别**。**先 M63 → 后 M75–M78 → 再 M79–M81。**

> **未采纳项**（本期节目提出但本模块不收）：节气（寒露 / 霜降）作转折点；「马斯克 → 台积电」因果链（方向错）；「中国不扩赤字 → 地产股必涨」（前提错）；「保时捷裁员＝有效需求不足」（归因错）。
