# 笨鸟宏观数据拆解方法论

> **核心定位**：这是一套**研究方法**，不是观点集合。每次分析时，按方法论独立推导结论。笨鸟本人的观点只是方法论的实战示例。

## 工作流程 / 使用步骤
1. 明确分析对象：宏观数据、政策表态，还是跨资产（金/银/铜/油/股/债/汇）传导。
2. 在下方参考索引中选取对应方法论（如 M1 数据拆解法、M9 美债危机三层拆解法、M19 石油-美联储协同逼债法）。
3. 严格按该方法的「第一步…第N步」逐步推导，并用 M23 前后表态交叉验证 / M24 政策文本模块化拆解等校验工具交叉验证。
4. 参照 `references/cases.md` 实战案例对照校验结论，用 `references/meta.md` 的方法论组合使用指南做多方法联动。
5. 输出：独立推导的结论 + 不确定性说明，区分「方法论推导」与「观点示例」。
6. **归因纪律（强制）**：凡涉及「某因素驱动了某价格/利率」的结论，必须写明时间窗口，并跑满三窗口对照（YTD / 近 12 个月 / 最近 1-3 个月）；输出必须收敛到方向 + 期限 + 幅度 + 证伪位，做不到四项的一律视为**叙事**，不作决策依据。详见 M47。
7. **通胀数据判读纪律（强制）**：凡涉及 CPI/PCE 等通胀数据的预判或解读，四个动作不可省——① 分项拆解（M50：列政策刀口 → 定时滞与效力 → 找「够不到的分项」= 超预期风险点）；② 政策两难结构（M51：先确认政策目标函数是否已从「救股市」切到「稳债市」，再跑加息/不加息两条路径看是否收敛）；③ **价格反应预判（M50 第五步 政策门槛法：先找政策决策的离散阈值 → 只给预期差定价 → 同比看方向、环比定反应 → 判断超预期分项落在「刀口之内还是之外」以定其可否被「暂时性」豁免 → 预判曲线形态是熊平还是熊陡）**；④ 窗口声明与性质区分（M47：短端预期驱动=可逆 / 期限溢价或信用驱动=不可逆）。**禁止只给「整体 CPI 高还是低」的单一结论**，必须落到分项与价格反应函数。详见 M50-M52。
8. **跨市场约束判读纪律（强制）**：凡涉及「美国政策是否受外部约束 / 某国是否被迫不动 / 风险会从哪传导」的结论，四个动作不可省——① **先看日元**（M53：日元是美国利率市场的约束读数器，出现「加息预期升+长端降」「加息预期升+股票涨」这类矛盾时，先查日元是否重新进入贬值风险区）；② 判定薄弱环节（M54：找「持有量足够大 + 自身货币有压力 + 被迫抛售」三者同时成立的一方，美债体系首先是日本）；③ **画央行日历**（M55：多国窗口博弈必须先列各央行议息日程与先后，判定属「约束方先动」还是「被约束方先动」，再看施压方是否掌握对方底牌）；④ 结构定位（M56：美元体系四支柱的中期状态，仅为背景不为时点）。**禁止在未画央行日历前下「某国被迫不能动」的结论**——时序一旦颠倒，结论会完全反向。详见 M53-M56。
