🔵 杨世光宏观六步法分析

第一步：经济周期定位（M1）

中国当前处于复苏初期阶段。2026年GDP目标约5%，央行维持适度宽松，PMI在荣枯线附近波动。核电/能源基建作为政府投资的重要抓手，属于典型的"复苏期→过热期"过渡阶段受益板块。

第二步：货币政策与利率环境（M2）

中国央行2026年明确"灵活高效运用降准降息"，市场利率处于历史低位。对核电/能源基建类重资产企业显著利好： ①融资成本低→大型工程项目财务费用压力减轻；②政府专项债发行加速→基建资金来源充裕。

第三步：美元周期与人民币（M3）

美元指数偏强但人民币受资本管控新规支撑（杨世光M21：中国"强出口+人民币走强"=资本外流管道被管控）。人民币相对稳定有利于国内基建投资环境，不会出现资本外流冲击。

第四步：流动性分析（M4）

中国处于"流动性陷阱"边缘（M2高增但实体响应有限）。在此背景下，政府通过核电审批加速、能源基建投资来主动创造有效需求——这正是凯恩斯主义的典型操作。

第五步：大类资产轮动（M5）

A股整体处于"政策底→市场底"确认阶段。两融余额1.47万亿（活跃但未过热）。核电/能源基建属于政策驱动型价值股，在"熊陡"环境下（杨世光M17）相对受益于价值风格偏好。

第六步：地缘政治传导（M6）

中东冲突→油价高企→全球通胀压力→中国输入性通胀可控（能源结构多元化）。核电作为替代能源的战略意义进一步凸显。能源安全=国家安全，核电审批加速的地缘逻辑坚实。

🟣 卢麒元制度结构分析

M1：广义财政三色分析

核电/能源基建投资主要属于白色财政（国家预算内重大工程投资）和部分灰色财政（地方融资平台配套）。核电审批加速意味着白色财政在战略性基础设施领域的扩张力度加大。这对中国核建和中国能建是直接利好——订单来源高度依赖政府核准。

M2：资本三流分析

流量：全球美元流动性偏紧（美联储不降息），但中国国内流动性充裕（央行降准降息）。核电作为"内循环"资产，不受外部美元流动性紧缩影响。

流向：国内资本从房地产→战略性产业转移。核电/新能源基建成为资本新去向。中国核建定增40亿正是"弃房转核"的微观缩影。

流速：核电工程周期长（5-8年），资本流速慢但确定性极高，属于"慢钱"配置。

M5：卡莱斯基利润恒等式

总利润 = 投资 + 政府赤字 + 净出口

对核建企业而言：政府核电投资是利润的核心来源。核电审批加速→投资规模扩大→企业利润有保障。中国能建2025年新签合同1.45万亿，其中能源电力工程占65.6%，本质上依赖政府基建投资。

M6：明斯基融资阶段判断

中国核建：定增40亿 = 从债务融资转向股权融资（杨世光"弃债转股"信号），说明公司负债率已接近天花板。这是投机性融资→对冲性融资的积极转变。

中国能建：2026年3月已定增25.49亿股（发行价2.55元，募资约65亿），同样在降杠杆。两家公司都在主动优化资本结构。

M3：向心坍缩阶段检查（中国市场适用性）

中国因资本管控和独立货币政策，不在向心坍缩的冲击范围内。相反，中国是"资本安全港"——当全球美元流动性紧缩时，中国内部的战略性基建投资提供了确定性回报。

稀缺层判断

工程建设层（中国核建/中国能建所在层）：稀缺度中等（⭐⭐⭐）。原因是：

  • 中国核建在核岛工程领域具有准垄断地位（核岛土建+安装市场份额>90%），这是该层内的核心卡点
  • 中国能建在常规岛和配套BOP工程领域份额较大，但竞争激烈（中国建筑、中国中铁等也参与）
  • 核岛工程需要特殊资质和数十年经验积累，进入壁垒极高，但已入场者之间的竞争不算激烈

Serenity五步法评估

核电工程建设的核心卡点不在施工本身，而在核安全级设备供应（反应堆压力容器、蒸汽发生器、主泵等）。这些设备制造周期长（2-3年）、供应商极少（全球仅少数几家）、扩产困难。中国核建/中国能建作为施工方，受制于设备到货节奏。

📐 底层逻辑关联

国民经济恒等式 S-I = X-M

中国巨额贸易盈余（1-5月顺差4,517亿美元）= 超额储蓄无法转化为有效投资。政府通过核电/能源基建投资来主动缩小S-I缺口，这是将超额储蓄转化为有效投资的战略路径。

传导链：核电审批加速 → 固定资产投资↑ → I增加 → S-I缩小 → 总需求↑ → 通缩缓解

美联储流动性框架

美联储维持不降息，全球美元流动性偏紧。但中国央行独立降准降息，国内流动性充裕。核电/能源基建股作为纯内需资产，不受外部美元紧缩影响，是"流动性避风港"。

卡莱斯基利润恒等式

利润 = 投资 + 政府赤字 + 净出口

对核建企业：政府核电投资↑ + 能源基建赤字↑ = 企业利润有保障。即使净出口因人民币升值而下降，政府投资的对冲效果足以弥补。
