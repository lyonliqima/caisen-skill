## 石油库存临界点追踪法

> 石油是地缘政治的血液。库存降到临界点时，任何风吹草动都会引发剧烈波动。

### 三重库存警戒线

| 库存指标 | 危险阈值 | 当前状态（2026.6） | 含义 |
|----------|----------|-------------------|------|
| 美国战备储油 | 消耗过快 | 释放1.72亿桶，已消耗6600万桶 | 战备储油见底=地缘溢价飙升 |
| 全球安全库存 | <90天 | 已跌破100天 | 国际能源署规定90天为安全线 |
| 期货商业储油（Cushing） | <2000万桶 | 2100万桶（逼近） | 跌破2000万桶=见底，无法解决的技术问题 |

### 分析框架

```
石油关键转折判断流程：
Step 1：检查三重库存——哪一项逼近或突破临界点？
Step 2：检查地缘因素——战争/制裁/禁运是否在加剧供给冲击？
Step 3：检查恢复时间——即使和平，恢复生产需要时间（不能马上补库存）
Step 4：检查保险/运费——海峡通行+保险费+运费 = 隐性成本壁垒
Step 5：结论——库存临界点 + 地缘未解 = 第二波涨势可能性高
```

### 蔡森观点（2026.6）

- "大底很难一下子完成，头部就算和平了，恢复生产也要一段时间"
- "原有关键转折，处理不好第二波涨势就会来"
- 以色列扩张领土（60%→70%）+ 黎巴嫩侵略 = 战争持续

## 缺口存亡确认法

> 跳空缺口是多空力量的即时验证。缺口补不补 = 利多利空的最快确认。

### 核心规则

```
跳空缺口判断法：
┌────────────┬──────────────┬────────────────────┐
│ 情景         │ 缺口表现       │ 含义                      │
├────────────┼──────────────┼────────────────────┤
│ 利多有效     │ 缺口不补       │ 市场认可利多，趋势延续      │
│ 利多出尽     │ 缺口回补       │ 利多已被消化，可能反转      │
│ 利空有效     │ 向下缺口不补   │ 市场认可利空，跌势延续      │
│ 利空出尽     │ 向下缺口回补   │ 利空已被消化，可能反弹      │
└────────────┴──────────────┴────────────────────┘
```

### ⚠️ 利多缺口铁律（重点强化）

> **由利多消息（业绩、政策、并购、题材等）跳空形成的向上缺口，绝对不能被补上；一旦被补掉，就是大问题。**

- **逻辑**：利多造成的缺口 = 市场对利多的"即时认可价"。缺口不补 = 多头守住阵地、趋势延续；缺口被补 = 利多立刻被市场否决，原本的利好变成"假突破 / 利多出尽"，多翻空往往很凶。
- **严重性**：这不是普通回踩，而是**方向性否定**。蔡森原话精神："今天大涨跳空缺口 → 不补没事，补了就有事"，而**利多消息缺口被补 = 特别严重的事**（比单纯技术性缺口回补危险得多）。
- **操作含义**：
  - 利多跳空当日/次日若还守住缺口 → 可顺势持有或加码；
  - 若**回补缺口**（收盘价或实体跌破缺口下沿）→ 视为利多失效信号，应减仓/离场，杠杆者尤其要立刻处理；
  - 缺口下沿即为止损参考线，破线即走，不犹豫。
- 适用于台股、美股、A股、期货等所有市场。

### 实战应用（通用缺口观察）

- **杠杆操作者必看**："你有在做杠杆的，一定要特别注意缺口"
- 今天大涨跳空缺口 → 缺口不补 = 没事 → 缺口补了 = 有事
- 其中**因利多消息形成的缺口被补，信号最危险**，优先处理。
- 适用于台股、美股、期货等所有市场

## 起涨点支撑法

> **股价跌回「上一波的起涨点」附近，就是很大的支撑。起涨点 = 那一段时间的最低点（一波上涨行情的起点）。**

### 核心定义

- **起涨点**：某一段上涨行情的启动位置，即该段时间区间内的最低点 / 局部最低。它是这波多头行情的"根基价"。
- 回到起涨点 = 价格把这一波涨幅几乎全部吐回，重新回到多头最初发力、大量筹码换手的起点。

### 为什么是强支撑

- 起涨点是前一波多头的**成本集中区与心理锚点**：涨上去之后，回到起点意味着"回到大家都还想买的价格"。
- 该位置往往叠加：前低支撑、平台密集成交区、以及"多头颈线起点"（见 reference.md「颈线时间延伸性」——贯穿整波上涨的上升趋势线正是从起涨点拉出）。
- 所以起涨点既是**支撑位**，也是**多头结构是否有效**的试金石。

### 操作含义

```
回跌到上一波起涨点附近：
┌──────────────────┬───────────────────────────────────┐
│ 表现               │ 含义 / 动作                        │
├──────────────────┼───────────────────────────────────┤
│ 到起涨点止跌企稳   │ 量缩 / 长下影 / 翻红 → 强支撑有效    │
│ （量缩不破、下影线 │ 可轻仓试多或作为加仓参考             │
│  探后收回）        │                                     │
├──────────────────┼───────────────────────────────────┤
│ 有效跌破起涨点     │ 该波上涨结构被破坏，支撑转压力        │
│ （收盘确认跌破）   │ 减仓 / 离场，不恋战                  │
└──────────────────┴───────────────────────────────────┘
```

- **企稳确认信号**：在起涨点附近出现缩量、长下影线、或翻红 K 线，且未有效跌破 → 支撑有效，可视为低吸/加码参考区。
- **失效信号**：收盘价有效跌破起涨点 → 整波多头结构被否定，原支撑变为新压力，应减仓或离场。
- 与「破底翻」配合：若跌破起涨点后**快速翻回**站上，则是假跌破洗盘（破底翻），反而是买点；但翻不回 = 真破，走人。
- 适用于台股、美股、A股、期货等所有市场。

## AI盈亏平衡测算法

> AI不是软件——软件边际成本趋近于零，AI每一次使用都要电、要算力、要建置。边际效应相对小。

### 测算框架

```
AI产业盈亏平衡计算：
Step 1：估算总投资额（当前 ≈ 7000亿美元）
Step 2：5年盈利门槛 = 投资额 × 2 ≈ 1.4兆美元
Step 3：对比当前营收（2026年 ≈ 1000亿美元，爆发性成长）
Step 4：评估差距——从1000亿到1.4兆需要14倍增长
Step 5：可见的两年内 → 极难达到盈利门槛

关键公司盈利状态（2026年估算）：
┌───────────┬────────────┬─────────────┐
│ 公司        │ 营收（估）   │ 盈利状态      │
├───────────┼────────────┼─────────────┤
│ Google     │ 100亿+     │ 盈利（带动一篮子商品）│
│ 微软       │ 100亿+     │ 盈利（Copilot订阅）  │
│ Anthropic  │ 较小        │ 盈利（AI宪法优势）   │
│ OpenAI     │ 200亿（最大）│ 亏损（投资太大）    │
└───────────┴────────────┴─────────────┘
```

### 投资启示

- AI泡沫 ≠ AI消失（故事绵延50年）
- 泡沫破裂后才是真正买入时机
- "宁可套AI也不要套在一般的股票"（2022年蔡森观点）
- 管制是必须的：AI无序发展风险越来越高

## 战争反市场操作法则

> 战争开打股市不跌，战争结束股市不见得会涨。这叫反市场操作。

### 核心规律

```
战争与市场反应的非线性关系：
┌────────────────┬──────────────┬────────────────────┐
│ 事件             │ 市场预期        │ 实际表现                  │
├────────────────┼──────────────┼────────────────────┤
│ 战争开打         │ 应该大跌        │ 不一定跌（已price in）   │
│ 战争结束/和谈    │ 应该大涨        │ 不一定涨（利多出尽）       │
│ 战争升级超预期   │ —              │ 真正大跌（超出price in范围）│
│ 和平协议破裂     │ —              │ 真正大跌（预期反转）        │
└────────────────┴──────────────┴────────────────────┘
```

### 与M9的联动

- 战争领袖（如内塔尼亚胡）以战争延续政治生命 → 停战困难
- 川普急于和谈（储油见底+通膨4%）→ 但对方不一定配合
- 战争 + 石油库存临界 + 通膨 = M9十大罪状中的多项触发

## 选择权分层抄底法

> 抄底不是赌一次，是按风险梯度分批进场。期货风险最高，选择权居中，ETF风险最小。

### 风险三级梯度

```
抄底工具选择（风险由低到高）：
┌──────────┬──────────────┬───────────────────┐
│ 工具       │ 风险等级        │ 适用场景                     │
├──────────┼──────────────┼───────────────────┤
│ ETF        │ ★☆☆ 最低      │ 不想盯盘、长线持有           │
│ 选择权买权 │ ★★☆ 中等      │ 有底型雏形、风险可控         │
│ 期货       │ ★★★ 最高      │ 完整底型打出、停损点明确     │
└──────────┴──────────────┴───────────────────┘
```

### 操作节奏

```
Step 1：第一次进场（买权为主）
  - 用买权（Call），不要卖权
  - 日期长的贵但成功率高（有时间等待）
  - 日期短的便宜但要准备两次损失
  - 控制第一次损失金额

Step 2：观察底型
  - 可能需要二次打底（单脚不成底）
  - 除非突发V型反转（如以色列局势升级）
  - 打出两个底 → 风险可控 → 再决定做期货

Step 3：期货进场（等底型确认）
  - 必须看到完整底型（如双底、破底翻）
  - 停损点设在底型低点下方
  - 5分钟线找破底翻作为精确进场点
```

### 核心原则

- 赚到后，下一次用买权买扣（控制风险）
- 等底型出来再决定要不要做期货
- 日期长的选择权贵但让成功率提高
- 两次选择权的预算准备（不要只赌一次）
- 基本面一旦出现问题，技术面就会立刻反应 → 但要有二次打底准备

## 龙头带动板块轮动法

> 同一产业里，龙头先涨，后面拖着上去。识别龙头 = 抓到整条产业链的入场信号。

### 龙头识别规则

```
龙头判定标准：
├── 先涨原则：同产业里第一个放量突破的就是龙头
├── 带量原则：龙头必须带量，不带量的不算
├── 涨幅原则：龙头涨幅通常最大或最先涨停
└── 确认原则：龙头涨后其他同产业跟上 = 确认
```

### 实战轮动链

| 产业 | 龙头（先涨） | 跟随（后涨） | 落后补涨 | 时间差 |
|------|-------------|-------------|---------|--------|
| A股面板 | 京东方A | TCL → 深天马A | 利亚德 | 1-3天 |
| 台股记忆体 | 美光（美股先行） | 华邦电、南亚科 | 旺宏 | 1-4周 |
| A股存储 | 兆易创新（12月） | 其他存储 | 佰维存储（9月26才代量） | 数月 |
| A股核建 | 中国核建 | 中国能建 | — | 同天 |

### 操作流程

```
Step 1：锁定产业板块
Step 2：找出龙头（谁第一个带量突破）
Step 3：龙头涨后观察同产业是否跟上
  - 跟上 → 板块轮动确认 → 跟随股进场
  - 不跟 → 可能只是龙头个股行情
Step 4：跟随股进场后，支撑看「今天低点」
  - 带量转折的当天低点 = 支撑
  - 不追价（前面有带量压力就等回测）
```

### 跨市场先行指标

- **台股先行，A股落后反应**：台股记忆体先涨 → A股存储后面才突破
- **美股先行，台股跟随**：美光先涨 → 台股华邦电/南亚科跟上
- **龙头先行，落后补涨**：产业关系带动，落后的最终也会跟上
