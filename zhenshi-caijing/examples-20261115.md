## 三、解剖发现（≥3 条 · 每条点名 Z 模块）

1. **Z31 口径层级**（本期最干净的一处）：原推演把「全行净利息收益率 2.57%」当成「单笔 10 万无抵押贷的利差」，乘出「年赚 2600」。净息差 =（利息收入−利息支出）÷ 平均生息资产，是**合并报表比率**；2600 是已扣资金成本、**未扣信用成本 / 运营成本 / 资本成本的净利息收入，不是利润**。与 11/14「毛/净利息两口径混用」「2.1 倍说成一倍」、11/10「涨幅回落念成下跌」同型 → **读法防错族第四次复现**，故立 Z31。
2. **Z30 已发生反例检验**：原推演的核心因果是「降息 → 零售活不下去」。但**自变量已经实打实变动了 8 年**（2.57%→1.83%，累计 −74bp），**因变量却没死**（ROE 13.44%、AUM +9.52%、大财富管理 +16.91%）。用当期一手数据回测推演前提，比争论未来可靠得多。同型：11/14「退伍金夸大」、11/04「库销比方向读反」。
3. **Z32 政策约束内生性（自我刹车）**：推演一边论证「降息让银行活不下去」，一边假设「会一路降到零」——**逻辑不自洽**。央行 2026-01-15 明确把「稳定净息差」列为「为降息创造空间」的前提，即银行息差是政策利率的硬约束。极端政策的副作用本身构成政策制定者的约束 → 线性外推到极端不成立，应给「约束位」而非「终点位」。Z24（归因分离）与 Z26（类比边界）的政策版。
4. **Z26 类比迁移边界（跨国版）**：日本经验可迁移的是「坏账必须及时出清 + 财政货币协同 + 降息差依赖」；不可迁移的是「企业部门转净储蓄、通缩持续、改革滞后、僵尸企业续命」这一组前提。中国走的是**化债 + 财政货币协同 + 债务重组**（接用户三次化债研究线），不是日本式「银行独自扛坏账拖着不出清」。**只抄「必然零利率 + QE」这个结论、不核前提差异 → 类比降级为软证据**。
5. **Z21 两端定位 + Z2 量价分离**：原推演全程只讲资产端（贷款 / 抵押物 / 房价），完全没提**负债端**（招行活期占比约 50%、低成本存款护城河、存款零下限刚性）。缺了负债端这一半，才把「零售 = 靠房子兜底的放贷生意」讲成完整模型。而「理财收摊」是把**单品费率变薄**等同于**业务规模消失**，漏掉量价关系（+10.08%）与商业模式差异（财富管理赚手续费、不承担息差风险）。
6. **Z13 双叙事**：官方/机构叙事「中期趋势未改、结构性资产荒、央行流动性工具充足」↔ 本方读数「信用利差压到历史 3% 以内极低分位、拥挤交易、无缓冲」。两条都对，但**外部机构观点仅作背景，不作本方结论支点**。

**本文的遗漏项（必须补，Z13 要求）**：① 未回理财规模 / 社融原始表（3000 亿赎回、35.37 万亿均为权威二手 T2）；② 未核中国住房自有率 80% 的统计口径（城镇 / 含农村 / 是否含共有产权），但因法律层已证伪，该数不影响结论；③ 未核免税收入税规模与财政增收测算（研报估算首年税负约 1023 亿，未回财政部原件）；④ 未核招行零售贷款分品类的**拨备与信用成本**明细（仅用不良率代理）；⑤ 159397 净值序列未逐日回基金公司官网原件（多源横向一致代替）。
