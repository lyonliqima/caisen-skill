## 一、多流派交叉验证矩阵

### 验证维度说明

对任何一个期货品种的行情预测，都应从以下 5 个维度进行交叉验证：

| 维度 | 对应流派 | 核心问题 | 代表大师 |
|------|---------|---------|---------|
| 宏观面 | 宏观对冲派 | 大方向是否支持？ | 索罗斯、葛卫东、保罗·都铎·琼斯 |
| 产业面 | 产业基本面派 | 供需矛盾是否成立？ | 傅海棠、叶庆均、林军、刘福厚、林广袤、冯成毅 |
| 技术面 | 趋势跟踪派 | 趋势是否确认？ | 利弗莫尔、克罗、青泽 |
| 情绪面 | 行为金融派 | 市场是否极端？ | 索罗斯、林军 |
| 系统面 | 系统化派 | 信号是否一致？ | 徐长波 |

### 评分矩阵模板

对每个维度打分（-2 到 +2）：

| 维度 | 评分 | 依据 | 权重 | 加权分 |
|------|------|------|------|--------|
| 宏观面 | -2/-1/0/+1/+2 | 政策/利率/周期 | 25% | |
| 产业面 | -2/-1/0/+1/+2 | 供需/库存/利润 | 30% | |
| 技术面 | -2/-1/0/+1/+2 | 趋势/突破/均线 | 20% | |
| 情绪面 | -2/-1/0/+1/+2 | 持仓/成交/舆论 | 15% | |
| 系统面 | -2/-1/0/+1/+2 | 多周期信号一致性 | 10% | |
| **总分** | | | **100%** | |

**评分标准：**
- +2：强烈看多（有明确且有力的证据）
- +1：偏多（有一定支持但不够强）
- 0：中性/不确定/矛盾
- -1：偏空（有一定压力但不够强）
- -2：强烈看空（有明确且有力的证据）

**决策规则：**
- 总分 ≥ +1.0 且至少 3 个维度同向 → **高确定性机会**，可重仓（30%-50%仓位）
- 总分 +0.3 ~ +1.0 且至少 2 个维度同向 → **中等确定性**，轻仓试错（10%-20%仓位）
- 总分 -0.3 ~ +0.3 或维度矛盾 → **放弃**，继续等待
- 总分 ≤ -0.3 → 反向机会，按上述规则评估做空

## 二、品种筛选清单

### 第一步：宏观筛选（自上而下）

**问题清单：**
- [ ] 当前宏观经济周期处于什么阶段？（复苏/扩张/滞胀/收缩）
- [ ] 货币政策方向？（宽松/收紧/中性）
- [ ] 财政政策力度？（扩张/收缩/中性）
- [ ] 美元指数趋势？（影响大宗商品整体）
- [ ] 地缘政治风险？（影响特定品种）
- [ ] 大类资产轮动信号？（股/债/商/汇）

**对应大师方法：**
- 索罗斯反身性：识别认知与现实的偏差
- 葛卫东混沌理论：判断阻力最小方向
- 保罗·都铎·琼斯：寻找不对称机会

### 第二步：产业筛选（供需锚定）

**傅海棠五维拐点判定法（核心筛选工具）：**

当五个条件同时满足时，商品价格必然迎来大级别单边行情。这是基本面派最系统的大行情识别工具。

**做多（牛市拐点）五条件：**
| 维度 | 判定标准 | 检查 |
|------|---------|------|
| 低价格 | 价格远低于行业平均生产成本，历史低位 | [ ] |
| 低库存 | 社会总库存、工厂库存、贸易库存均历史低位 | [ ] |
| 负利润 | 全行业普遍性亏损，中小产能开始退出 | [ ] |
| 需求稳 | 下游终端需求稳定或边际改善 | [ ] |
| 高贴水 | 期货价格大幅低于现货价格，安全边际充足 | [ ] |

**做空（熊市拐点）五条件：**
| 维度 | 判定标准 | 检查 |
|------|---------|------|
| 高价格 | 价格远高于生产成本，历史高位 | [ ] |
| 高库存 | 社会库存持续累积，历史高位 | [ ] |
| 超高利润 | 全行业超额暴利，资本大量扩产 | [ ] |
| 需求弱 | 下游需求转弱或下滑 | [ ] |
| 高升水 | 期货价格大幅高于现货价格 | [ ] |

**补充问题清单：**
- [ ] 全球/国内产量趋势？（增加/减少/持平）
- [ ] 库存周期位置？（累库/去库/低位/高位）
- [ ] 期现价差？（升水/贴水，幅度）
- [ ] 产业链利润分布？（上游/中游/下游谁赚钱）
- [ ] 开工率/产能利用率？
- [ ] 进口/出口情况？
- [ ] 替代品价格走势？
- [ ] 政策影响？（收储/限产/环保/贸易）

**对应大师方法：**
- 傅海棠五维拐点法：价格+库存+利润+需求+基差五维度
- 刘福厚供需分析法：产量+需求+政策三维度
- 林军三维分析：供需+逻辑+情绪
- 冯成毅产业逻辑：现货升贴水+库存定方向
- 林广袤单品深耕：全产业链深度调研

### 第三步：技术筛选（趋势确认）

**问题清单：**
- [ ] 周线/月线主趋势方向？
- [ ] 价格与均线关系？（50日/60日均线）
- [ ] 是否处于盘整区间？
- [ ] 是否有关键突破信号？
- [ ] 成交量是否配合？
- [ ] 持仓量变化？
- [ ] 多周期是否共振？（日线/周线/月线）

**对应大师方法：**
- 利弗莫尔关键点：突破确认趋势
- 克罗趋势策略：周月线+50均线定方向
- 青泽临界点：60均线+结构突破
- 徐长波系统化：多指标多周期验证

### 第四步：情绪筛选（极端识别）

**问题清单：**
- [ ] 市场一致性预期是否极端？
- [ ] 媒体/舆论是否一边倒？
- [ ] 散户参与度是否异常？
- [ ] 持仓结构是否极端？（多空持仓比）
- [ ] 波动率是否处于历史极端位置？

**对应大师方法：**
- 索罗斯反身性：识别泡沫与崩盘
- 林军情绪维度：市场情绪与想象
- 保罗·都铎·琼斯：极端后的反转机会

## 三、预测决策流程

### 完整预测流程图

```
宏观定方向
    ↓
产业选品种
    ↓
技术定时机
    ↓
情绪找极端
    ↓
交叉验证打分
    ↓
┌─────────────┐
│  ≥3维度共振？ │
└──────┬──────┘
   是 ↓   ↓ 否
  重仓   等待/放弃
    ↓
制定交易计划
    ↓
执行与监控
    ↓
动态调整/离场
```

### 各步骤操作要点

**步骤1：宏观定方向（1-2天）**
- 阅读最新宏观经济数据（GDP、CPI、PMI、利率）
- 判断当前周期位置
- 确定大宗商品整体方向
- 输出：宏观方向（多/空/中性）+ 置信度

**步骤2：产业选品种（3-5天）**
- 筛选3-5个供需矛盾最突出的品种
- 深入研究每个品种的产业链
- 对比各品种的供需缺口大小
- 输出：重点关注品种列表 + 排序

**步骤3：技术定时机（持续跟踪）**
- 对重点品种进行技术面分析
- 标记关键支撑/阻力位
- 设置预警条件（突破某价位、均线拐头等）
- 输出：入场条件清单

**步骤4：交叉验证（入场前）**
- 填写交叉验证矩阵
- 计算加权总分
- 判断确定性等级
- 输出：交易决策（入场/等待/放弃）

**步骤5：制定计划（入场前）**
- 确定入场价位区间
- 确定止损位
- 计算仓位大小
- 规划加码策略
- 设定止盈条件
- 输出：完整交易计划书

| 冯成毅 | 单日最大承受额超限停手 | 清仓起步，浮盈加码 |
| 青泽 | 止损提升到信仰高度 | 赢冲输缩 |
| 徐长波 | 多品种多周期对冲 | 不止损，用对冲替代 |
| 利弗莫尔 | 单次亏损不超10%本金 | 绝不摊平亏损 |
| 克罗 | 关键位止损 | 跌破止损位立即出局 |
| 保罗·都铎·琼斯 | 每笔风险≤1%总资产 | 5:1盈亏比铁律 |
| 索罗斯 | 敢于认错快速调整 | 不追求精确，理解反馈循环 |

### 仓位管理模板

**金字塔加仓法（适用于趋势行情）：**
- 底仓：总计划仓位的 40%（首次入场）
- 第一次加仓：30%（趋势确认后，回调企稳时）
- 第二次加仓：20%（突破前高/前低后）
- 第三次加仓：10%（趋势加速时，最后加）

**注意：**
- 只在盈利头寸上加仓
- 每次加仓后，整体止损上移到保本位置
- 加仓次数不超过3-4次

## 五、不同行情下的方法论选择

### 趋势行情

**特征：** 方向明确，持续时间长，波动较大
**最适用方法：**
- 傅海棠天道供需——供需失衡驱动的大级别单边行情
- 利弗莫尔关键点交易法——捕捉趋势启动
- 克罗趋势策略——持仓不动摇
- 叶庆均趋势跟踪——吃足利润
- 青泽临界点交易——60均线定方向

**操作要点：**
- 顺势而为，不猜顶底
- 金字塔加仓，让利润奔跑
- 止损设在逻辑破位处，不轻易移动
- 用周线/月线判断主趋势，忽略日线杂波
- 核心逻辑未反转就坚定持有

### 震荡行情

**特征：** 区间波动，方向不明，反复打脸
**最适用方法：**
- 徐长波系统化交易——多周期对冲
- 刘福厚期现套利——赚基差修复的钱
- 冯成毅短线精度——在区间内高抛低吸

**操作要点：**
- 减少交易频率，降低仓位
- 考虑套利/对冲策略
- 不追涨杀跌
- 等待突破信号再转为趋势策略

### 拐点行情

**特征：** 趋势末期，情绪极端，即将反转
**最适用方法：**
- 傅海棠五维拐点判定法——基本面极端状态识别牛熊拐点
- 索罗斯反身性理论——识别泡沫与崩盘
- 保罗·都铎·琼斯不对称交易——极端后反转
- 林军情绪维度——市场情绪极端度

**操作要点：**
- 用小仓位试探，严格止损
- 寻找不对称机会（小风险博大收益）
- 关注成交量、持仓量的异常变化
- 不急于抄底/逃顶，等待确认信号
- 五维条件全部满足时可重仓左侧布局

### 黑天鹅行情

**特征：** 突发事件，极端波动，流动性枯竭
**最适用方法：**
- 保罗·都铎·琼斯防守至上——活下来最重要
- 叶庆均敬畏市场——永远假设自己错了
- 林军黑天鹅三击——认知差+情绪差+杠杆差

**操作要点：**
- 第一时间减仓/止损
- 不抄底，不接飞刀
- 等待市场稳定后再评估
- 保留足够现金应对极端情况

## 六、个人交易体系构建指南

### 第一步：找到自己的"主场"

每位大师都有自己的核心优势领域，你也需要找到你的：

| 你的特质 | 适合流派 | 参考大师 |
|---------|---------|---------|
| 有产业背景/现货资源 | 产业基本面派 | 傅海棠、刘福厚、冯成毅、林广袤 |
| 宏观敏感度高/喜欢研究经济 | 宏观对冲派 | 葛卫东、索罗斯、保罗·都铎·琼斯 |
| 纪律性强/擅长编程 | 系统化交易派 | 徐长波 |
| 耐心好/能拿住单 | 趋势跟踪派 | 克罗、利弗莫尔、叶庆均 |
| 善于思考/哲学思辨 | 趋势哲学派 | 青泽、索罗斯 |
| 综合能力强/资源多 | 三维分析派 | 林军、叶庆均 |

### 第二步：构建核心框架

建议以一个流派为主，1-2个流派为辅：

**示例1：傅海棠纯基本面体系**
- 主：傅海棠五维拐点判定法（选品种、定方向、找拐点）
- 辅：林广袤单品深耕（深度调研+浮盈加仓）
- 特点：完全不看技术指标，纯基本面驱动，一年只抓1-2次大机会

**示例2：产业派为主 + 趋势派为辅**
- 主：刘福厚供需分析法（选品种、定方向）
- 辅：克罗趋势策略（定时机、控仓位）

**示例3：趋势派为主 + 宏观派为辅**
- 主：利弗莫尔关键点交易法（入场、加仓）
- 辅：葛卫东混沌理论（大方向判断）

**示例4：系统化为主 + 产业派为辅**
- 主：徐长波三多趋势跟踪（系统化执行）
- 辅：林军三维分析（人工筛选品种、排除风险）

### 第三步：制定交易规则

你的体系必须包含以下规则：
1. **入场规则**：什么条件下开仓？
2. **止损规则**：什么条件下止损？
3. **加仓规则**：什么条件下加仓？加多少？
4. **止盈规则**：什么条件下止盈？分几批？
5. **仓位规则**：单笔最大仓位？总仓位上限？
6. **品种规则**：做哪些品种？不做哪些品种？
7. **时间规则**：什么时间交易？什么时间不交易？

### 第四步：回测与验证

- 用历史数据回测你的规则
- 至少回测 4 年以上的数据（徐长波原则）
- 记录每笔交易的盈亏和原因
- 持续优化，但不要过度拟合

### 第五步：实盘与迭代

- 小资金实盘验证
- 写交易日志，记录每笔交易的思考
- 定期复盘，找出体系的漏洞
- 持续迭代进化

### A. 饲料蛋白原料（粕类）定价与替代

来源：公众号「燧木数农」2026-09-17（原文见上述归档附录）。适用范围：豆粕 / 菜粕 / 花生粕 / DDGS / 鱼粉等饲料蛋白原料，以及与油籽压榨相关的任何品种。

| # | 公式 | 用途 | 接入状态 |
|---|---|---|---|
| A1 | `单位蛋白成本 = 价格(元/吨) ÷ (蛋白% × 10)` → 元/kg蛋白 | 跨品种比价的唯一正确口径。绝对价差与单位蛋白价差方向不一致时，**以单位蛋白为准** | ⬜ |
| A2 | `粕价底部 ≈ 油籽原料到港成本 ÷ 出粕率 + 压榨费分摊` | 同源成本锚，判断成本支撑位 | ⬜ |
| A3 | `油粕比 = 油期货价 ÷ 粕期货价`（同月合约） | 压榨收益分配阀；比值走低 = 粕强 | ⬜ |
| A4 | `油贡献 = (油价 × 0.185) ÷ (油价×0.185 + 粕价×0.785)` | **量化修正 A3 的定性规则**：比值为 2.60 时粕仍贡献 62% 压榨收入 → 「油强则油厂不在乎粕价」不成立 | ⬜ |
| A5 | `库存三级：油厂库存 / 港口库存 / 交易所仓单` | 任何"库存紧"结论必须标层级。实例：菜粕油厂库存 1.0 万吨 vs 交易所仓单约 18.18 万吨（差 18 倍） | ⬜ |
| A6 | `持仓结构闸门：增仓上涨 = 多头主动（方向可信）／减仓上涨 = 空头回补（视为脉冲）` | **判断涨势可持续性的一级信号**，本框架新增 | ⬜ |
| A7 | `价差三态：窄 → 替代发生／宽 → 替代受阻／反向 → 失去廉价替代资格` | 替代关系定性判定 | ⬜ |
| A8 | `双口径涨幅：同时给"较前结算价"与"较前收盘价"两个涨幅` | 数据纪律，建议推广到所有外部数据引用 | ⬜ |

### B. 已实测的反面案例（写入本框架作警示）

| 案例 | 表面结论 | 单位蛋白复核后 | 教训 |
|---|---|---|---|
| 豆粕 − DDGS 价差 1112 元/吨 | "DDGS 具备替代价值" | DDGS 单位蛋白成本 **8.20** vs 豆粕 **7.87** → DDGS 反而贵 4.2% | 绝对价差宽 ≠ 有替代性价比 |
| 豆粕 − 花生粕价差 | "花生粕已失去价格优势" | 花生粕单位蛋白 **7.02** vs 豆粕 **7.87** → 始终便宜，且优势在扩大 | 蛋白含量不同的品种，绝对价格比较必然出错 |
| 菜粕油厂库存 1.0 万吨 | "供给几乎无缓冲，弹性最大" | 交易所仓单约 18.18 万吨（9/15 单日 +6,645 张） | 库存不标层级 = 无效表述 |
