# 蔡森形态学量化检测算法

> 来源：炒股 app pattern-recognizer.ts 实现，提炼为可参考的量化检测标准。
> 用途：辅助人工判断形态是否成立，提供客观的数值参考。

---

## 通用工具函数

### 局部极值检测

```
寻找局部最小值（底部）：
- 对比前后 N 根 K 线（lookback=5）
- 若当前 K 线 low ≤ 前后所有 K 线 low → 标记为局部底部

寻找局部最大值（顶部）：
- 对比前后 N 根 K 线（lookback=5）
- 若当前 K 线 high ≥ 前后所有 K 线 high → 标记为局部顶部
```

### 均量计算

```
均量(start, end) = sum(volume[start..end]) / count
用于判断突破时是否放量（> 均量 × 1.3 = 放量确认）
```

### 价格容忍度合并

```
两个底部"接近"的判定：|close1 - close2| / min(close1, close2) ≤ 3%
两个顶部"接近"的判定：|close1 - close2| / max(close1, close2) ≤ 5%
```

## 形态1：W底（双底）检测

**量化条件**：
1. 最近 120 根 K 线中找到至少 2 个局部底部
2. 两底之间价格差 ≤ 5%（容忍度）
3. 两底之间间隔 ≥ 8 根 K 线
4. 两底之间存在一个明显的高点（颈线位）
5. 第二个底之后收盘价突破颈线 → 确认突破

**突破放量验证**：
```
突破时 volume > 前5根均量 × 1.3 → 放量确认（confidence=80）
未放量但收盘价突破 → 突破可疑（confidence=65）
```

**目标价计算（底部至颈线的距离 = 突破颈线后的等幅距离）**：
```
depth = neckline - min(底1, 底2)  // 蔡森公式：底部至颈线的距离

第一满足点 = neckline + depth      // 等幅距离投射
第二满足点 = neckline + 2 × depth  // 两波涨幅满足
止损价 = min(底1, 底2) × 0.97

教学数值：底1=15, 底2=13, 颈线=19
depth = 19-13 = 6
第一满足 = 19+6 = 25
第二满足 = 19+12 = 31
```

**划线规范**：
- 颈线：橙色虚线（#FF6B00），标注"W底颈线"
- 双底支撑：绿色虚线（#2ecc71），连接两个底
- 标注：左底（绿）、右底（绿）、颈线（橙）

## 形态2：M头（双顶）检测

**量化条件**：
1. 最近 120 根 K 线中找到至少 2 个局部顶部
2. 两顶之间价格差 ≤ 5%（容忍度）
3. 两顶之间间隔 ≥ 8 根 K 线
4. 两顶之间存在一个明显的低点（颈线位）
5. 第二个顶之后收盘价跌破颈线 → 确认跌破

**两波跌幅满足目标价计算**：
```
height = max(顶1, 顶2) - neckline

第一满足点（基本测幅）：
  target1 = neckline - height
  蓝色竖线距离 = height

第二满足点（延伸测幅）：
  target2 = neckline - 2 × height
  蓝色竖线距离 = 2 × height

止损价 = max(顶1, 顶2) × 1.03（+3%缓冲）
```

**两波跌幅满足判定**：
```
跌破颈线后：
  □ 第一波跌幅 = H（顶→谷的跌幅）
  □ 第二波跌幅 = H（破颈线后的等距投射）
  □ 两波等距即“满足” → 到达 target1 减仓，到达 target2 跌势尾声
```

**划线规范**：
- 颈线：红色虚线（#e74c3c），标注“M头颈线”
- 双顶压力：红色虚线，连接两个顶
- 第一满足点：绿色水平线（#2ed573）
- 第二满足点：绿色虚线水平线（#2ed573，较淡）
- 形态高度：蓝色竖线（#4a9eff）从顶部到颈线
- 标注：左顶（红）、右顶（红）、颈线（红）

## 形态3：头肩底检测

**量化条件**：
1. 最近 150 根 K 线中找到至少 3 个局部底部
2. 中间底部（头部）必须是最低点
3. 左肩与右肩价格差 ≤ 8%（对称性检查）
4. 左肩→头→右肩间距各 ≥ 5 根 K 线
5. 颈线斜率角度 ≤ 15°（颈线不能太陡）

**颈线计算**：
```
左峰 = 左肩与头之间的最高收盘价
右峰 = 头与右肩之间的最高收盘价
slope = (右峰 - 左峰) / (右峰index - 左峰index)
angle = atan(slope / 左峰) × 180 / π
若 angle > 15° → 颈线过陡，形态不成立
```

**目标价计算**：
```
neckline_avg = (左峰 + 右峰) / 2
depth = neckline_avg - head_close
目标价 = neckline_avg + depth
止损价 = head_close × 0.97
```

**confidence = 75**

## 形态4：头肩顶检测

**量化条件**：
1. 最近 150 根 K 线中找到至少 3 个局部顶部
2. 中间顶部（头部）必须是最高点
3. 左肩与右肩价格差 ≤ 8%
4. 间距各 ≥ 5 根 K 线
5. 颈线斜率角度 ≤ 15°

**颈线计算（"点多的为主"原则）**：
```
左谷 = 左肩与头部之间的最低收盘价
右谷 = 头部与右肩之间的最低收盘价

多点检测（核心）：
  扫描左谷±3%范围内的所有K线低点，统计触碰次数(touchLeft)
  扫描右谷±3%范围内的所有K线低点，统计触碰次数(touchRight)
  若 |左谷 - 右谷| / min(左谷,右谷) ≤ 3% → 两个谷在同一价位附近
    → 合并统计总触碰次数 = touchLeft + touchRight
    → 若总触碰 ≥ 4次 → 极强水平颈线
    → 若总触碰 ≥ 3次 → 强效水平颈线
    → 若总触碰 ≥ 2次 → 有效水平颈线
    → neckline = (左谷 + 右谷) / 2
  否则 → 两谷差距较大
    → 画倾斜颈线，斜率 = (右谷 - 左谷) / (右谷index - 左谷index)
    → 角度 = |atan(斜率 / 左谷) × 180/π|
    → 若 angle > 15° → 颈线过陡，形态不成立

水平线优先原则：
  若多个低点都集中在同一价位±3%内 → 必须画水平线（不是斜线）
  蔡森原话："横的平的，零角度的平的横线""最漂亮""最正确"
```

**两波跌幅满足目标价计算**：
```
height = head_close - neckline_avg

第一满足点（基本测幅）：
  target1 = neckline_avg - height
  蓝色竖线距离 = height

第二满足点（延伸测幅）：
  target2 = neckline_avg - 2 × height
  蓝色竖线距离 = 2 × height

止损价 = max(左肩, 右肩) × 1.03（+3%缓冲）
```

**两波跌幅满足判定**：
```
当价格跌破颈线后：
  □ 跌到 target1 附近 → 第一波跌幅满足 → 减仓/不追空
  □ 继续跌破 target1 → 看 target2 → 第二波跌幅满足
  □ 两波跌幅等距（都是 height）→ "两波跌幅满足"
  □ 到达 target2 后跌势大概率进入尾声
```

**划线规范**：
- 颈线：红色虚线（#e74c3c），标注"头肩顶颈线"
- 左肩/头部/右肩：分别用 pin 标注
- 形态高度：蓝色竖线（#4a9eff）从头部到颈线
- 第一满足点：绿色水平线（#2ed573）
- 第二满足点：绿色虚线水平线（#2ed573，较淡）
- 逃命波：反弹到颈线处标注"逃命/右侧逃命"

**confidence = 75**（放量跌破颈线可达 85）

## 形态4.5：假突破检测（头肩顶/M头假突破）

> **实战案例图**：见 `images/false-breakout-example.png` — 经典颈线假突破诱多陷阱

### 图形视觉特征（基于实战案例）

```
假突破经典K线形态（从截图提炼）：

  价格
  150 │
      │         ╭──╮  ← 假突破K线，冲到142.350高点
  140 │    ─────│──│──── 紫色水平颈线（阻力位 ~130-132）
      │         │  │
  130 │─────────┤  ├────────────
      │         │  │   ╮
  120 │         │  │   │  ← 大阴线直接跌回颈线下方！
      │         │  │   │
  110 │         │  │   ╱          （甚至更低到~118）
      │         │  │  ╱
  100 │    ╭────┤  ├─╯
      │    ╱    │  │
   90 │   ╱     │  │
      │  ╱      │  │
      └────────────────────────→ 时间

  关键特征：
  ① 趋势背景：明确的上升趋势（从100以下涨到130+）
  ② 颈线位置：紫色水平阻力线（多次测试过的关键价位）
  ③ 假突破动作：一根K线突破颈线冲高至142.350（超出颈线约8-9%）
  ④ 立即反转：紧接着大阴线/长阴线跌回颈线下方
  ⑤ 跌幅惨烈：从142.350高点回落到118左右，跌幅约17%
```

**量化条件**：
1. 先检测头肩顶或M头形态是否成立
2. 价格突破前高阻力位（突破 > 前高 × 1.01）
3. 突破后 ≤ 5根K线内跌回阻力位下方（假突破确认）
4. 随后跌破颈线（假突破确立 = 卖出/做空信号）

**假突破判定流程**：
```
Step 1：识别头部形态 / 关键阻力位
  头肩顶：左肩~90，头部~95，右肩~85
  M头：两顶接近，第二个顶略高于第一个
  ★ 本案例类型：上升趋势中的水平颈线假突破（非完整头肩/M头结构）
    - 趋势背景：从100以下持续上涨到130+
    - 颈线：紫色水平阻力线（约130-132）
    - 不需要完整的头部形态，颈线本身即是关键阻力

Step 2：检测假突破
  突破确认：收盘价 > 前高阻力位（如95）
  假突破确认：突破后 ≤ 5根K线内跌回阻力下方

  ★ 本案例具体数据：
  - 颈线位置：~131-132（紫色水平线）
  - 假突破高点：142.350（超出颈线约8.3%）
  - 突破后回落速度：1-2根K线内即大幅回落
  - 回落低点：~118（跌破颈线约10%，距高点跌幅约17%）
  - 这是"突破幅度越大、跌得越狠"的典型案例

Step 3：颈线计算
  左谷：~68 | 右谷：~72
  若 |68 - 72| / 68 ≈ 5.9% > 3% → 画倾斜颈线
  斜率 = (72 - 68) / (右谷index - 左谷index)

Step 4：假突破确立信号
  "跌落頸線下假突破確立賣出訊號"
  股价跌破颈线下方 = 假突破成立 = 做空信号

  ★ 本案例确立信号：
  - 大阴线实体完全回到颈线下方 → 假突破立即确认
  - 无需等待跌破另一条颈线（本例中颈线即阻力位本身）
  - 收盘价远离颈线（不是刚好在颈线上方晃）= 极强假突破信号

Step 5：跌破颈线加码信号
  "跌破頸線空單加碼訊號"
  价格继续下跌到颈线以下（如72位置）
  → 第二个加码做空点
```

**目标价计算**：
```
height = 假突破高点(95) - 颈线均价(70) = 25
目标价 = 颈线均价 - height = 70 - 25 = 45
止损价 = 假突破高点(95) × 1.03

★ 本案例测幅估算（基于截图数据）：
  假突破高点 = 142.350
  颈线位置 ≈ 131
  height = 142.350 - 131 = 11.35
  第一满足点 = 131 - 11.35 = 119.65  ← 当前已接近或到达！
  第二满足点 = 131 - 22.7 = 108.3
  止损价 = 142.350 × 1.03 = 146.6

  ⚠️ 从图中看价格已回落到~118附近，
     已接近第一满足点119.65！
```

**假突破 vs 真突破的量化区分**：
```
假突破特征（confidence = 70~85）：
  □ 突破时成交量 < 前5日均量 × 1.0（缩量或量价背离）
  □ 突破K线长上影线（上影 > 实体 × 1.5）
  □ 突破后 ≤ 5根K线跌回阻力下方

  ★ 本案例符合度分析：
  - 突破K线：冲高但可能带有上影线（从截图可见高点142.350但收盘较低）
  - 回落速度：极快（1-2根K线内）→ 强烈假突破信号
  - 回落力度：直接大阴线贯穿颈线 → 不是温和回调而是出货
  - 综合判断：confidence ≥ 80（高度确信假突破）

真突破特征（confidence = 75~90）：
  □ 突破时成交量 > 前5日均量 × 1.3（明显放量）
  □ 突破K线实体收盘（收盘 > 阻力位）
  □ 突破后站稳阻力上方，不回踩
```

**划线规范**：
- 前高阻力线：红色水平线（#e74c3c）
- 颈线：黑色/红色水平线
- 假突破高点：红色圆圈标注 + 标注具体数字（如"142.350"）
- 跌破颈线点：红色圆圈 + 红色向下箭头
- 止损：X标记在假突破高点上方
- 满足目标：绿色水平线（#2ed573）

**confidence = 70**（量价配合 + 头部形态确认可达 85）

## 形态5：破底翻检测

**量化条件**：
1. 先确定前低支撑位（破底发生前的局部最低价 = 前低；**注意不是含破底K线在内的最近30根最低价**，否则会把破底新低误当支撑）
2. 出现一根 K 线收盘价跌破前低 × 0.97（破底确认，跌破幅度通常 2-3%）
3. 之后出现一根 K 线收盘价重新站上前低（翻回确认）
4. 两个事件之间间隔不超过 30 根 K 线

**核心升级：两条颈线体系**

蔡森强调破底翻必须有**两条颈线**，不是一条：

```
第一条颈线（底部支撑线 / 前低）：
  = 破底发生前的局部最低价（前低支撑位）
  = 股价跌破此线 = "破底"（主力洗盘信号）
  = 股价翻回站上此线 = "翻"（破底翻初步确认，买点1）

第二条颈线（整理区上缘 / 前高突破线）：
  = 破底前一波反弹的高点（前高阻力位）
  = 股价突破此线 = 主升浪启动（买点2 / 加码点）
  = 突破必须配合成交量放大（> 前5日均量 × 1.3）
  = 突破后绝对不能再跌破此线，否则形态失败
```

**第二条颈线的确认标准（关键升级）**：
```
破底前反弹高点 = 破底发生前，最近一段下跌趋势中
                 最后一次明显反弹的最高价
                 
例（对应教学图）：
  前一波高点 = 11.00（图中约11元位置）
  前低支撑位 = ~10.36（绿线位置，破底前的局部最低）
  破底低点 = ~10.20（跌破前低）
  
  第二条颈线 = 11.00（前高）
  突破确认：收盘价 > 11.00 × 1.01 且 成交量 > 前5日均量 × 1.3
```

**两条颈线的目标价计算**：

```
# 第一层目标（基于第一条颈线）
support = 前低（破底前的支撑位）
neckLine1 = 第一条颈线 = 前低（翻回确认的支撑线）
目标价1 = neckLine1 + (neckLine1 - support)
        = 前低 + (前低 - 破底前支撑)  
        
# 注意：由于 neckLine1 ≈ support（翻回后站上的就是前低），
# 第一层目标的深度 = 破底幅度（前低 - 破底低点）
# 教学值：support=10.36, 破底低点=10.20, 破底幅度=0.16
# 目标价1 = 10.36 + 0.16 = 10.52（短期反弹目标）

# 第二层目标（基于第二条颈线）—— 核心目标
neckLine2 = 第二条颈线 = 前高（整理区上缘）
# H = 第二条颈线 - 第一条颈线 = 整理区高度
H = neckLine2 - neckLine1

目标价2-1 = neckLine2 + H      # 第一满足点（等幅距离）
目标价2-2 = neckLine2 + 2×H    # 第二满足点（两波涨幅满足）

教学数值（对应用户图案例）：
  第一条颈线（前低/支撑）= 10.36
  第二条颈线（前高/突破）= 11.00
  H = 11.00 - 10.36 = 0.64
  
  目标价2-1 = 11.00 + 0.64 = 11.64（第一满足点）
  目标价2-2 = 11.00 + 1.28 = 12.28（第二满足点）
  
  止损价 = 第一条颈线 × 0.97 = 10.36 × 0.97 ≈ 10.05
```

**进场与加码的完整策略**：
```
买点1（翻回确认）：
  条件：收盘价站回第一条颈线（前低）上方
  仓位：轻仓试探
  止损：第一条颈线下方 3%（或破底最低点下方）
  风险：翻回可能只是短暂反弹，尚未确认趋势反转

买点2（突破加码）：
  条件：收盘价突破第二条颈线（前高）+ 放量确认
  仓位：加重仓位
  止损：第二条颈线下方 3%（即跌破前高 = 形态失败）
  风险：假突破后回落（需观察3日站稳）
```

**止损铁律（蔡森）**：
1. 跌破"前低"后快速翻回 = 假跌破洗盘。进场后若再次跌破"前低" = 翻底失败，立即止损。
2. 止损锚定**前低**（第一条颈线/破底前的支撑位），**绝不锚定破底最低点**——后者会让风险敞口多出"前低 → 破底低点"这段无效亏损，认错太晚。
3. 突破第二条颈线后，止损上移至第二条颈线下方3%。若再次跌破第二条颈线 = 假突破，形态失败，止损出场。

**翻回确认与3日站稳规则**：
```
单日翻回：收盘价 > 第一条颈线 → 初步信号，但不可靠
3日站稳：连续3日收盘价 ≥ 第一条颈线 → 翻回确认，可靠性大幅提升
  
若翻回后第2日或第3日又跌破第一条颈线 → 破底翻失败
若翻回后快速上攻突破第二条颈线 → 强势信号，不必等3日
```

**confidence 分级**：
- 单日翻回站上第一条颈线：confidence = 55（初步信号）
- 3日站稳第一条颈线：confidence = 65（翻回确认）
- 放量突破第二条颈线：confidence = 75（主升浪启动）
- 突破第二条颈线后3日站稳：confidence = 85（形态完全确认）

**划线规范**：
- 第一条颈线（前低/支撑）：绿色虚线（#2ecc71），标注"破底翻-支撑线"
- 第二条颈线（前高/突破）：橙色虚线（#FF6B00），标注"破底翻-突破线"
- 破底点：红色向下箭头，标注"破底"
- 翻回点：红色向上箭头，标注"翻回"
- 突破点：红色圆圈 + 向上箭头，标注"突破"
- 目标价：绿色水平线（#2ed573）

**破底翻与W底的区分**：
```
破底翻：第二只脚跌破第一只脚（创新低后翻回）→ 更强势洗盘
W底：第二只脚 ≈ 第一只脚（不创新低）→ 标准双底

两者可以同时存在：
  W底的第二只脚 = 破底翻结构（跌破前低后翻回）
  → 这是最强的底部形态组合
```

## 形态6：收敛三角形检测

**量化条件**：
1. 至少 2 个递降的局部高点（descendingHighs）
2. 至少 2 个递升的局部低点（ascendingLows）
3. 高低点交替出现，波动收窄

**方向判断**：
```
若 最近低点 > 起始低点 → isRising=true → 底部三角形（bullish）
否则 → 顶部三角形（bearish）
```

**目标价计算**：
```
maxWidth = |lastMax.high - lastMin.low|  // 三角形最宽处
上涨目标 = lastMax.high + maxWidth
下跌目标 = lastMin.low - maxWidth
```

**三角形头部跌幅满足算法（蔡森教学）**：
```
三角形头部高度 H = 头部高点 - 三角形底部（颈线）

有效跌破条件：
  跌破位置必须在三角形的 1/2 到 3/4 处
  有效区间 = [底部 + H×1/2, 底部 + H×3/4]
  教学值：H=20, 底部=60 → 有效区间 = [70, 75]
  → 太早跌破（靠近头部）= 不算三角形
  → 太晚跌破（靠近尖端）= 力度太弱

跌幅满足：
  第一满足 = 底部 - H
  第二满足 = 底部 - 2H
  教学值：60-20=40, 60-40=20
  实战：80→65(破线)→45(第一波)→25(第二波)
```

**confidence**：
- 接近三角形尖端（高点间距 < 15根）→ 70
- 远离尖端 → 55

**划线规范**：
- 上轨：红色实线（#e74c3c），连接递降高点
- 下轨：绿色实线（#2ecc71），连接递升低点

## 形态7：旗形整理检测

**量化条件**：
1. 找到至少 2 个递降/递升的高点和低点
2. 高点和低点同方向移动（平行通道）

**分类**：
```
下飘旗形（Bull Flag）：
- 高点和低点都递降
- 且之前是上涨趋势（旗杆）
- → 上涨中继，突破上沿继续涨

上飘旗形（Bear Pennant）：
- 高点和低点都递升
- 且之前是下跌趋势
- → 下跌中继，跌破下沿继续跌

上飘旗形 + 波段跌幅满足算法：
```
前提：急跌后形成向上旗形整理
  波段高点 = wave_high
  旗形下沿 = flag_low（= 前低）
  旗形上沿 = flag_high

确认条件：
  必须跌破 flag_low（前低）才能确认 wave_high 是有效高点
  蔡森原话："跌破前低才能确定前高，是高點才能计算跌幅满足"

跌幅满足计算：
  H = wave_high - flag_low
  第一满足 = flag_low - H
  第二满足 = flag_low - 2H

教学数值：
  wave_high=90, flag_low=70, flag_high=75
  H = 90-70 = 20
  第一满足 = 70-20 = 50
```

**confidence = 65**（跌破旗形下沿后可达75）

## 形态7.5：斜颈线头部检测（上升楔形头部）

**量化条件**：
1. 最近 120 根 K 线中找到至少 3 个局部底部（形成递升低点序列）
2. 存在至少 1 个明显的局部顶部作为头部
3. 低点序列满足：底2 > 底1，底3 > 底2（递升）
4. 高点序列满足：顶2 ≈ 顶1 或 顶2 略低于 顶1（高点无力）
5. 斜颈线角度在 15°~45° 之间（过陡不可靠）

**斜颈线计算（"穿过最多点的就是颈线"核心原则 + 时间延伸性）**：
```
关键升级：扫描范围不限于"头部区域"，而是回溯到整个上涨结构的起点

步骤1：确定上涨结构
  上涨起点 = 找到头部之前的最明显局部底部（起涨点）
  头部 = 上涨过程中的最高局部顶部
  扫描区间 = [上涨起点index, 头部index]

步骤2：扫描所有回调低点
  在扫描区间内找出所有局部低点（回调低点）
  包含：起涨点、上涨过程中的所有回调低点、头部区域回调低点

步骤3：寻找最优颈线斜线
  对每对低点 (i,j) 计算斜率：slope = (low[j] - low[i]) / (j - i)
  角度 = atan(slope / low[i]) × 180 / π

  若 15° < 角度 < 45°：
    统计该斜线上±2%范围内触碰的K线低点数量(touchCount)
    记录 touchCount 最多的斜线 → 最优颈线

步骤4：判定颈线强度
  若最优颈线穿过 ≥4 个低点（含起涨点） → 极强颈线（跌破后跌幅巨大）
  若最优颈线穿过 ≥3 个低点 → 有效斜颈线
  若 touchCount = 2 → 需配合其他头部信号确认
```

**头部确认**：
```
头部 = 斜颈线上方的最高局部顶部
头部到斜颈线的垂直距离 = 头部最高价 - 颈线在头部index处的价格

颈线在头部index处价格 = 颈线起点价格 + slope × (头部index - 颈线起点index)
```

**两波跌幅满足目标价计算**：
```
 neckline_at_break = 跌破K线对应在颈线延长线上的价格
 height = 头部最高价 - neckline_at_head  // 形态高度（垂直距离）

第一满足点（基本测幅）：
  target1 = neckline_at_break - height
  含义：跌破颈线后第一波下跌 = 形态高度

第二满足点（延伸测幅）：
  target2 = neckline_at_break - 2 × height
  含义：两波跌幅等距（都是 height），即"两波跌幅满足"

止损价 = 头部最高价 × 1.03（+3%缓冲）
```

**跌破确认**：
```
收盘价 < 颈线价格（按当日index计算颈线延长线价格）→ 跌破确认
跌破时成交量 > 前5日均量 × 1.1 → 放量确认（confidence=80）
跌破时成交量正常 → 突破可疑但有效（confidence=70）
```

**划线规范**：
- 斜颈线：红色实线（#e74c3c），标注"斜颈线头部颈线"
- 头部：红色 pin 标注最高顶部
- 形态高度：蓝色竖线（#4a9eff）从头部垂直量到颈线
- 第一满足点：绿色水平线（#2ed573）
- 第二满足点：绿色虚线水平线（#2ed573，较淡）
- 跌破点：红色向下箭头标注"破线"
- 逃命波：反弹到斜颈线处标注"逃命/右侧逃命"

**confidence = 70**（放量跌破斜颈线可达 85）

**注意事项**：
- 斜颈线头部容易与上升楔形中继混淆：前者出现在顶部、高点无力，后者出现在上涨中途
- 跌破后反弹测试斜颈线 = 典型逃命波，难以站回
- 斜颈线角度 > 45° → 形态不成立，视为急涨后的正常回调
- 若同时存在水平颈线 → 以触碰次数多的为准（水平优先原则）

## 形态8：趋势线检测

> **实战案例图**：`images/trendline-breakdown-example.png`
> **核心原则**：「点多的为主」画线 + 渲染实体K线 + 效率操作点

**量化条件**：
1. 找到至少 2 个局部底部/顶部
2. 上升趋势线：后一个底部 > 前一个底部
3. 下降趋势线：后一个顶部 < 前一个顶部
4. 斜率角度在 0.5° ~ 45° 之间（太陡不可靠）

**★ 实体K线渲染前置要求（2026-07-07新增）**：
```
画趋势线之前必须先渲染实体K线图（非折线图）：

原因：
□ 折线图丢失高低点信息 → 画的线不准
□ 影线触及 ≠ 实体触及 → 意义不同
□ 蔡森原话："要把图渲染出来再画比较准"
□ 蔡森原话："根据图形来画，画实体K线"

具体做法：
Step 1: 获取OHLCV完整数据
Step 2: 渲染蜡烛图（每根K线有开高低收+影线）
Step 3: 基于K线实体低点(或收盘价)识别局部极值
Step 4: 用"点多的为主"连线
Step 5: 验证每根K线与线的位置关系

本案例验证（截图数据）：
  - 绿色支撑线基于实体K线低点绘制
  - 至少穿过4个回调低点（86251、87054等）
  - 若用折线图绘制可能遗漏关键触碰点
  - 实体K线图确保每个低点都被正确识别
```

**「点多的为主」趋势线绘制算法增强**：
```
基础版（旧）：找2个点连线
增强版（新）：扫描所有极值点，选触点最多的线

详细步骤：
Step 1：在渲染后的K线图上扫描局部极值
  - 上升趋势：用lookback=5找所有局部最低点(low)
  - 下降趋势：用lookback=5找所有局部最高点(high)

Step 2：记录每个极值点的 (index, price)

Step 3：枚举所有两点组合 (i, j)，计算斜线参数
  slope = (price[j] - price[i]) / (j - i)
  angle = atan(slope / price[i]) × 180 / π

Step 4：筛选有效斜线（0.5° < angle < 45°）

Step 5：对每条有效斜线统计touchCount
  扫描所有极值点，若 |point_price - line_price_at_index| / line_price ≤ 2%
  则该点"触碰"此线，touchCount++

Step 6：选择 touchCount 最大的线 = 最优趋势线

Step 7：强度判定
  touchCount ≥ 4 → 极强趋势线（跌破/突破后力度巨大）
  touchCount = 3 → 有效趋势线
  touchCount = 2 → 弱趋势线（需配合其他信号）
```

**角度计算**：
```
slope = (val2 - val1) / (idx2 - idx1)
angle = atan(slope / val1) × 180 / π
有效范围：0.5° < angle < 45°
```

**效率操作点检测（★新增）**：
```
什么是效率操作点？
= 趋势线被确认突破/跌破的精确K线位置
= 风险最小、确定性最高的执行时机

上升趋势线跌破（做空）的效率操作点判定：
  □ 收盘价 < 趋势线在该日的价格（不是盘中最低价）
  □ 跌破K线为阴线（绿色/蓝色，视颜色惯例）
  □ 跌破后价格远离趋势线（不是贴着线震荡）
  □ 此处标记绿色圆圈 = 做空执行位置

下降趋势线突破（做多）的效率操作点判定：
  □ 收盘价 > 趋势线在该日的价格
  □ 突破K线为阳线
  □ 突破后价格站稳趋势线上方
  □ 此处标记红色圆圈 = 做多执行位置

止损设置：
  上升趋势线跌破做空：止损设在趋势线上方或前高上方
  下降趋势线突破做多：止损设在趋势线下方或前低下方
```

**confidence 分级（增强）**：
| 触碰次数 | 趋势线强度 | confidence | 跌破/突破后的含义 |
|----------|-----------|------------|------------------|
| ≥ 4 点 | 极强 | **70→85** | 趋势反转确认，大行情启动 |
| 3 点 | 有效 | **55→70** | 趋势转折信号，需配合确认 |
| 2 点 | 弱 | **40→55** | 参考性质，不单独作为依据 |

> 注：原 confidence=55 为未考虑触碰次数的基础值。加入「点多的为主」触点统计后，confidence 可显著提升。本案例绿线≥4触点 → confidence可达85。

## 多头支撑线有效性判定算法（收盘价确认规则）

**量化条件**：
1. 确认当前处于多头趋势（价格位于支撑线上方，近期低点递升）
2. 在多头整理区找到多个低点，用"点多的为主"原则画出支撑线
3. 每日用收盘价判定支撑有效性

**支撑线绘制算法**：
```
扫描多头整理区（最近 60 根K线）的所有低点
统计各低点价位的触碰次数（±3%范围内合并）
触碰次数最多的价位 = 支撑线价格（support_line）

支撑线颜色 = 绿色 #2ecc71
支撑线类型 = 水平线（多点价位一致时）
```

**每日收盘价判定算法**：
```
每日收盘后执行：
  close_price = 当日收盘价
  support_line = 支撑线价格

  if close_price > support_line:
    status = "支撑有效" → 多头继续，持股不动
  elif close_price < support_line:
    status = "支撑失效" → 多头结构破坏，等待新信号
  else:
    status = "临界状态" → 观望，下一日再确认

特殊规则：
  盘中最低价 < support_line 但 close_price > support_line
    → 不算跌破（主力洗盘），支撑仍有效

加码信号判定：
  回踩支撑线不破 + 当日为阳线 + 成交量 > 前5日均量 × 1.3
    → 加码买入信号
```

**多层级支撑线算法**：
```
第一层支撑（主支撑）：
  = 整理区低点连线，触碰次数最多
  = 多头生命线，收盘跌破 = 趋势结束

第二层支撑（次级参考）：
  = 反弹高点/突破后回踩位（黑色水平线）
  = 可作为第二层支撑或目标位参考

第三层参考（前压力位）：
  = 历史阻力/目标位（紫色水平线）
  = 突破后角色转换为支撑
```

## 平台跌破判定算法（向下跌破·头部形态）

**量化条件**：
1. 识别高位整理平台（价格在某区间内反复震荡 ≥ 20 根K线）
2. 平台顶部：至少 2 个局部高点，价格差 ≤ 8%
3. 平台底部：多个低点触碰同一价位（"点多的为主"），差值 ≤ 3%
4. 价格有效跌破平台底部颈线（收盘价跌破）

**平台颈线绘制算法**：
```
扫描平台整理区（最近 60 根K线）的所有低点
统计各低点价位的触碰次数（±3%范围内合并）
触碰次数最多的价位 = 平台底部颈线（support_line）
平台顶部 = max(平台内局部高点)
平台高度 H = 平台顶部 - support_line

颈线颜色 = 黑色水平线
触碰 ≥ 2次 = 有效，≥ 3次 = 强效，≥ 4次 = 极强
```

**跌破判定算法**：
```
每日收盘后执行：
  close_price = 当日收盘价
  support_line = 平台底部颈线

  if close_price < support_line:
    status = "平台跌破确认" → 做空进场
    target1 = support_line - H（第一满足点）
    target2 = support_line - 2H（第二满足点）
    stop_loss = max(平台内局部高点) × 1.03

特殊规则：
  跌破不需要放量确认（下跌不需要量——蔡森铁律）
  跌破后不能再站回颈线（站回 = 形态失败，空头止损）
  跌破后反弹到颈线 = 逃命波（右侧逃命信号）
```

**confidence = 70**（平台整理时间越长、触碰次数越多，可达 85）

## 形态9：波段等幅测量检测

**量化条件**：
1. 在最近 120 根 K 线中找到至少 1 个完整波段（明显的绝对低点→绝对高点，或绝对高点→绝对低点）
2. 波段必须清晰可辨：低点到高点的K线数 ≥ 5 根，且涨幅/跌幅 ≥ 10%
3. 找到回调/反弹后的新起点（明显低点/高点），新起点与前一波段之间必须有回调/反弹（不能连续）
4. 新起点确认后，价格已向波段同方向运行至少 3 根 K 线

**波段识别算法**：
```
寻找完整上涨波段：
  低点 = 局部最小值（前后 lookback=5）
  高点 = 低点之后的局部最大值（前后 lookback=5）
  波段涨幅 H = 高点 - 低点
  有效条件：H / 低点 ≥ 10%，且 高点index - 低点index ≥ 5

寻找完整下跌波段：
  高点 = 局部最大值（前后 lookback=5）
  低点 = 高点之后的局部最小值（前后 lookback=5）
  波段跌幅 H = 高点 - 低点
  有效条件：H / 高点 ≥ 10%，且 低点index - 高点index ≥ 5
```

**涨幅满足计算（做多场景）**：
```
前波段：低点1 → 高点1，H = 高点1 - 低点1
新起点 = 回调后的明显低点2（低点2 > 低点1，即回调不创新低）

涨幅满足点 = 低点2 + H
延伸满足点 = 低点2 + 2H

教学图数值：
  低点1 = 29.97, 高点1 = 54.40
  H = 54.40 - 29.97 = 24.43
  低点2 = 43.17
  涨幅满足 = 43.17 + 24.43 = 67.60
  
  当前价格（黄线位置）≈ 64.40
  距离满足 = 67.60 - 64.40 = 3.20（还有约 5% 空间）
  → 结论：尚未到达涨幅满足，可继续持有
```

**跌幅满足计算（做空场景）**：
```
前波段：高点1 → 低点1，H = 高点1 - 低点1
新起点 = 反弹后的明显高点2（高点2 < 高点1，即反弹不创新高）

跌幅满足点 = 高点2 - H
延伸满足点 = 高点2 - 2H
```

**满足度判定（关键升级）**：
```
满足度 = (当前价格 - 新起点) / H × 100%

满足度 < 50%  → 上涨/下跌初期，力度健康
满足度 50%~80% → 中段运行，继续观察
满足度 80%~100% → 接近满足，警惕反转信号
满足度 ≥ 100%  → 到达满足，考虑减仓/止盈

教学图：
  当前价 = 64.40, 新起点 = 43.17, H = 24.43
  满足度 = (64.40 - 43.17) / 24.43 = 21.23 / 24.43 ≈ 87%
  → 接近满足（87%），但尚未到达，可继续持有
```

**波段等幅 vs 颈线测幅的联合使用**：
```
当同时存在形态（如W底）和波段等幅时：
  颈线测幅目标 = 颈线 + H_form
  波段等幅目标 = 低点2 + H_wave
  
  若两个目标接近 → 共振确认，可靠性极高
  若两个目标差距大 → 以颈线测幅为主（形态优先），波段等幅作参考
  
  例：W底 + 波段等幅
    W底：底1=30, 底2=32, 颈线=40, H_form=10
    颈线目标 = 40+10=50
    
    波段：低点1=25→高点1=45, H_wave=20
    新起点=35
    波段目标 = 35+20=55
    
    两个目标 50/55 接近 → 50~55 区间 = 强阻力/目标区
```

**confidence 分级**：
- 单一波段等幅，无形态配合：confidence = 55（参考性）
- 波段等幅 + 趋势线支撑/压力：confidence = 60
- 波段等幅 + 颈线测幅共振：confidence = 70
- 大周期（周线）波段等幅 + 小周期形态确认：confidence = 75

**划线规范**：
- 前波段：紫色虚线框（#9b59b6），标注"波段H"
- 等幅投射线：紫色虚线（#9b59b6），从"新起点"向上/向下量取H
- 涨幅满足点：绿色水平线（#2ed573），标注"涨幅满足"
- 延伸满足点：绿色虚线水平线（#2ed573，较淡），标注"延伸满足"
- 当前满足度：在图表旁标注百分比

**注意事项**：
- 波段等幅是**概率性预测**，不是确定性目标，可能提前结束或超预期
- 必须结合量价：第二波量缩 → 不满足概率高；量增 → 满足概率高
- 大周期优先：周线波段等幅 > 日线波段等幅 > 60分钟波段等幅
- 避免"刻舟求剑"：市场不是机械运动，满足点是参考区间而非精确价位

## 与蔡森人工判断的结合

量化检测是辅助工具，最终判断仍需蔡森体系的人工确认：

1. **量化先筛选**：自动扫描所有形态，给出候选列表
2. **人工再验证**：检查量价关系、多周期共振、基本面配合
3. **蔡森操作纪律**：形态不明确不操作，严格止损
4. **大周期优先**：量化检测在日线级别以上更可靠

**重要提醒**：60分钟以下周期的量化检测结果仅供参考，不建议作为操作依据。
