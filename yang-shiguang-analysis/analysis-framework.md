# 杨世光宏观经济分析框架详解

## 一、经济周期分析框架

### 美林投资时钟（杨世光改良版）

杨世光在分析中经常使用改良版的投资时钟模型：

```
             通胀上行
                ↑
    过热期      |      滞胀期
   (商品为王)   |    (现金为王)
                |
经济下行 ←──────┼──────→ 经济上行
                |
    衰退期      |      复苏期
   (债券为王)   |    (股票为王)
                ↓
             通胀下行
```

### 周期判断指标体系

**领先指标（预测未来3-6个月）**：
- PMI新订单指数
- 建筑许可
- 首次申请失业救济人数
- 消费者信心指数
- 收益率曲线斜率
- 货币供应量M2增速

**同步指标（确认当前状态）**：
- GDP实际增长率
- 工业生产指数
- 非农就业人数
- 个人收入
- 零售销售

**滞后指标（确认趋势）**：
- CPI/PPI
- 失业率
- 银行贷款余额
- 库存销售比

## 二、美联储政策分析框架

### 美联储双重使命

1. **物价稳定**：通胀目标2%
2. **最大就业**：失业率降至自然失业率

### 政策工具分析

**联邦基金利率（FFR）**：
- 加息 → 提高借贷成本 → 抑制需求 → 降通胀
- 降息 → 降低借贷成本 → 刺激需求 → 促增长

**量化宽松/紧缩（QE/QT）**：
- QE：购买国债/MBS → 释放流动性 → 压低长端利率
- QT：缩表 → 回收流动性 → 推升长端利率

**前瞻指引（Forward Guidance）**：
- 鹰派措辞 → 市场预期加息 → 美元走强
- 鸽派措辞 → 市场预期降息 → 美元走弱

### 利率曲线分析

```
正常曲线（牛市信号）：
短端利率 < 长端利率
2年 < 5年 < 10年 < 30年

平坦曲线（转折信号）：
短端利率 ≈ 长端利率

倒挂曲线（衰退预警）：
短端利率 > 长端利率
2年 > 10年（最经典的衰退预警信号）
```

### 期限溢价（Term Premium）

杨世光特别关注期限溢价：
- 期限溢价 = 长端利率 - 预期短期利率均值
- 期限溢价上升 → 市场对长期通胀/财政风险担忧加剧
- 期限溢价飙升 → 可能引发债券市场动荡

## 三、美元周期分析框架

### 美元指数的构成

美元指数（DXY）主要权重：
- 欧元 57.6%
- 日元 13.6%
- 英镑 11.9%
- 加元 9.1%
- 瑞典克朗 4.2%
- 瑞士法郎 3.6%

### 美元强弱的影响因素

| 因素 | 美元走强 | 美元走弱 |
|------|----------|----------|
| 利差 | 美国利率高于其他经济体 | 美国利率低于其他经济体 |
| 经济增长 | 美国增长快于其他经济体 | 美国增长慢于其他经济体 |
| 通胀 | 美国通胀低于其他经济体 | 美国通胀高于其他经济体 |
| 风险偏好 | 全球风险厌恶（避险） | 全球风险偏好（逐险） |
| 财政政策 | 美国财政紧缩 | 美国财政扩张 |
| 去美元化 | 去美元化减缓 | 去美元化加速 |

### 美元周期与资产轮动

**美元走强周期**：
- 美股：大型科技股相对抗跌
- 新兴市场：承压（资本外流、货币贬值）
- 大宗商品：走弱（以美元计价）
- 黄金：承压
- 美债：外资买入（美元需求）

**美元走弱周期**：
- 美股：全面受益
- 新兴市场：受益（资本流入）
- 大宗商品：走强
- 黄金：走强
- 非美货币：升值

## 四、流动性分析框架

### 宏观流动性来源

```
美联储资产负债表
    ↓
银行系统准备金
    ↓
信贷创造（乘数效应）
    ↓
实体经济流动性
    ↓
资产价格
```

### 流动性收紧的传导路径

1. 美联储加息/缩表
2. 银行准备金减少
3. 信贷标准收紧
4. 企业融资成本上升
5. 消费者借贷减少
6. 经济增速放缓
7. 资产价格承压

### 流动性陷阱

杨世光分析日本案例：
- 央行释放大量流动性
- 但银行不愿放贷
- 企业不愿投资
- 消费者不愿消费
- 流动性无法传导到实体经济
- 资产价格不涨反跌

### 关键流动性指标

- **美联储资产负债表**：总资产规模变化趋势
- **逆回购（ON RRP）**：货币基金存放美联储的资金
- **TGA余额**：财政部在美联储的存款
- **银行准备金**：商业银行在美联储的超额准备金
- **净流动性** = 美联储资产负债表 - TGA - ON RRP

## 五、通胀分析框架

### 通胀的驱动因素

1. **需求拉动型**：总需求 > 总供给 → 物价上涨
2. **成本推动型**：原材料/能源/工资上涨 → 生产成本传导
3. **货币型**：货币供应量过度增长 → 货币贬值
4. **预期型**：通胀预期自我实现 → 工资-物价螺旋

### 关键通胀指标

- **CPI（消费者价格指数）**：消费端通胀
- **核心CPI**：剔除食品和能源
- **PPI（生产者价格指数）**：生产端通胀（领先指标）
- **PCE（个人消费支出价格指数）**：美联储最关注的通胀指标
- **通胀预期**：市场对未来通胀的预期（TIPS利差）

### 通胀与资产价格的关系

| 通胀状态 | 股票 | 债券 | 商品 | 黄金 |
|----------|------|------|------|------|
| 温和通胀(1-3%) | ★★★★ | ★★★ | ★★★ | ★★★ |
| 加速通胀(3-5%) | ★★★ | ★★ | ★★★★★ | ★★★★ |
| 高通胀(>5%) | ★★ | ★ | ★★★★★ | ★★★★★ |
| 通缩(<0%) | ★ | ★★★★★ | ★ | ★★★ |

## 六、黄金分析框架

### 黄金定价的五大因子

1. **实际利率（最核心）**：
   - 实际利率↓ → 持有黄金的机会成本↓ → 金价↑
   - 实际利率↑ → 持有黄金的机会成本↑ → 金价↓

2. **美元走势**：
   - 美元↓ → 以美元计价的黄金↑
   - 美元↑ → 黄金↓

3. **地缘风险**：
   - 战争/冲突/制裁 → 避险需求↑ → 金价↑

4. **央行购金**：
   - 各国央行增加黄金储备 → 需求↑ → 金价↑
   - 去美元化趋势推动央行购金

5. **通胀预期**：
   - 通胀预期↑ → 黄金作为保值工具需求↑ → 金价↑

### 金油比分析

杨世光常用金油比（Gold/Oil Ratio）判断：
- 金油比高 → 避险情绪浓 / 经济衰退担忧
- 金油比低 → 经济乐观 / 风险偏好高
- 历史均值约15-25倍

**供给端**：
- OPEC+产量决议

- 伊朗/委内瑞拉/俄罗斯供给变化

- 航空/运输/工业需求

### 原油作为通胀领先指标

- 原油价格↑ → 运输成本↑ → 生产成本↑ → CPI↑
- 原油是PPI的领先指标
- 原油飙升往往预示通胀加速

## 八、股市分析框架

### 杨世光的股市分析维度

1. **宏观环境**：经济周期、利率、流动性
2. **估值水平**：P/E、P/B、P/S、EV/EBITDA
3. **盈利增长**：EPS增速、营收增速、利润率
4. **资金流向**：外资、机构、散户的买卖方向
5. **筹码结构**：大股东持仓、融资融券余额
6. **行业轮动**：不同周期阶段的最优行业

### 估值与利率的关系

```
合理P/E ≈ 1 / (无风险利率 + 风险溢价)
```

- 利率2% → 合理P/E约25-30倍
- 利率4% → 合理P/E约15-20倍
- 利率6% → 合理P/E约10-15倍

**杨世光的警示**：高利率环境下，高估值股票面临"杀估值"风险。

### 行业轮动与经济周期

| 周期 | 最优行业 |
|------|----------|
| 复苏期 | 科技、可选消费、金融 |
| 过热期 | 能源、材料、工业 |
| 滞胀期 | 必选消费、医药、公用事业 |
| 衰退期 | 公用事业、医药、国防 |

## 十、风险分析框架

### 杨世光的风险识别方法

1. **资产端风险**：
   - 资产价格泡沫（估值过高）
   - 流动性枯竭（卖不出去）
   - 信用违约（债券违约潮）

2. **负债端风险**：
   - 债务规模膨胀
   - 利息负担加重（利率上升）
   - 再融资困难（借新还旧断裂）

3. **系统性风险信号**：
   - 信用利差急剧扩大
   - VIX恐慌指数飙升
   - 银行间拆借利率飙升
   - 主要金融机构出现流动性问题
   - 主权债务评级下调

### 黑天鹅与灰犀牛

- **灰犀牛**：明显可见但被忽视的风险（如债务泡沫、人口老龄化）
- **黑天鹅**：不可预测的极端事件（如疫情、战争）
- 杨世光强调：防范灰犀牛比预测黑天鹅更重要

## 十二、公司资本结构分析方法（从金錢爆0604期提炼）

### 12.1 融资方式拆解框架

当科技巨头进行巨额融资时，拆解其融资结构：

| 融资方式 | 特点 | 市场信号 |
|----------|------|----------|
| ATM（市价销售） | 在公开市场按市价渐次卖出 | 对股价压力最直接的 |
| 定向增发 | 向特定机构发行 | 波克夏参与=价值背书 |
| 承销公开发行 | 投行承销的公开发行 | 规模最大，市场影响最广 |
| 强制可转换优先股 | 兼具债与股特性 | 企业希望降低债务杠杆 |

### 12.2 債轉股信号分析

“棄債轉股”的三层含义：
1. **利率环境信号**：企业认为继续发债不划算，利率已过拐点
2. **AI资本开支信号**：“入场券变贵”，需要更多股权资本而非杠杆
3. **周期信号**：对比历史净发行量数据判断周期位置

**美国净股权发行量历史对照表**：

| 时期 | 净发行量 | 背景 | 含义 |
|------|---------|------|------|
| 2000年 | 正值 | 科技股疯狂上市 | 泡沫末期 |
| 2009年 | 大幅正值 | 金融股破产式现增 | 危机求生 |
| 2020年 | 正值 | 疫情企业稀释股权换现金 | 生存压力 |
| 2025Q4 | -$44B | 回购力道萎缩 | 周期转向初期 |

## 十三、美联储政策框架分析（从金錢爆0604期提炼）

### 13.1 准备金供需三阶段

| 阶段 | 时期 | 需求曲线形状 | 政策传导效率 |
|------|------|----------|----------|
| 稀缺准备金 | 2008金融海嘯前 | 陡峭 | 高：微调供给即影响利率 |
| 充足准备金 | 当前 | 走平 | 低：利率不敏感 |
| 超额准备金 | 有效利率底限以下 | 完全水平 | 极低：政策失效 |

### 13.2 美联储资产负债表演变

| 时间 | 规模 | 政策动作 |
|------|------|----------|

### 13.3 RMP（准备金管理购买）渐进缩减路径

```
2025年1-3月：启动RMP购债（$400亿/月）
↓ 银行准备金不足（低于GDP的0.9%）
2025年4月：缩减至$250亿/月
↓ O/N RRP降至$33B，流动性压力
2025年5月：缩减至$100亿/月
↓ 渐进式退出
目标：完全停止RMP，回归纯市场化流动性供应
```

### 13.4 r*（自然实质利率）上升的三大驱动力

1. **国债定价权转移**：央行减速购买→私人资本接盘→要求更高收益率
2. **AI资本需求**：AI驱动生产率增长→企业投资需求上升→资本竞争推高利率
3. **财政扩张压力**：人口老龄化+军费扩张+减税→债务/GDP上升→借贷需求增加

## 十四、历史资金规模类比法（M23，从端午节前会议提炼）

### 14.1 分析流程

| 步骤 | 动作 | 美伊MOU实例 |
|------|------|----------|
| 1 | 计算当代协议资金规模（增量+存量） | 3000亿重建基金 + 1100亿资产解冻 = 4100亿 |
| 2 | 计算接受方年度财政基准 | 伊朗年财政收入~1000亿，国防预算92亿 |
| 3 | 折算为“X年财政收入” | 3000亿 ≈ 4年财政收入、数十年国防预算 |
| 4 | 寻找历史类似倍数事件 | 马关条约1895：2.3亿两白银 ≈ 日本4年财政收入 |

### 14.2 关键原则

- **量级对标比绝对数字更重要**：3000亿只是数字，“4年财政收入”才揭示颠覆性
- **增量+存量并计**：不能只看新资金，还要算解冻的存量资产
- **历史类比要匹配倍数关系**：找“资金量/财政收入”倍数相近的案例

## 十六、第一性原理估值批判法（M25，从端午节前会议提炼）

### 16.1 分析流程

```
宣称市值叙事
    ↓
拆解行业容量天花板
    ↓
检验公司实际竞争地位
    ↓
对比同行业龙头的市值/营收/EPS
    ↓
用“要干掉多少家竞争对手”还原估值荒谬性
```

### 16.2 估值泡沫诊断信号

| 信号 | 含义 | 实例 |
|------|------|------|
| 市值逼近行业龙头，但地位远低于龙头 | 估值脱离竞争格局 | 国巨700亿道追村田1200亿（但仅全球第四） |
| 宣称市场规模超过多个行业总和 | 叙事脱离现实 | SpaceX要拿7000亿广告+1万亿网络服务 |
| 市值增长远快于营收/EPS增长 | 估值压缩未反映基本面 | 市值膨胀远超行业市场规模 |
| “这次不一样”的叙事 | 泡沫经典特征 | GPU社会价值有限但估值被AI叙事推高 |

### 16.3 与M10的协作

- M10巴菲特指标：宏观层面，“总市值/GDP”判断整体市场泡沫
- M25第一性原理：微观层面，“行业容量天花板 vs 宣称市值”判断个股泡沫
- 两者并用：宏观发现泡沫→微观定位泡沫集中在哪里

## 十八、实体经济三线验证法（M27，从端午节前会议提炼）

### 18.1 三线检查模板

| 线路 | 核心指标 | 健康信号 | 危险信号 |
|------|----------|----------|----------|
| 消费线 | 零售销售实际增速（扣除通胀） | 名义和实际均正增长 | 名义增长但实际停滞 |
| 库存线 | 制造业/批发/零售库销比 | 库销比稳定或温和上升 | 库销比创新低→不愿补库存 |
| 固投线 | 新屋开工+商业营业投资 | 持续正增长 | 持续下滑→实体投资萎缩 |

### 18.2 GDP增长质量诊断

```
三线均强劲 + GDP增长 → 高质量增长，可持续
两线强劲 + 一线疲软 → 结构性问题，需关注疲软线
三线均疲软 + GDP增长 → 虚假繁荣，仅靠特定行业账面数据支撑
三线均疲软 + GDP下滑 → 实质性衰退
```

### 18.3 实战案例（美国 2026年5月）

| 线路 | 数据 | 诊断 |
|------|------|------|
| 消费线 | 零售销售名义+6.88%，实际≈0% | ⚠️ 虚假繁荣 |
| 库存线 | 三线库销比全线创新低 | 🚨 企业极度悲观 |
| 固投线 | 新屋开工+商业投资持续下滑 | 🚨 实体萎缩 |
| **GDP** | **仅靠AI投资账面数据支撑** | **☠️ 虚假繁荣，类1929** |

### 18.4 与M12的协作

- M12菲利普曲线：定位“失业率×CPI”在哪个象限
- M27三线验证：拆解GDP增长的真实质量
- 联合使用：M12判断“经济表面看起来如何” → M27判断“经济实际上如何”

## 十九、经济学公式工具箱（从《金钱爆》基本面课程提炼）

> 杨世光在《金钱爆》基本面系列课程中系统讲授经典经济学与金融公式。他强调「理论是工具，不是教条」，所有公式都必须结合实际市场数据和政策环境灵活运用。以下公式与 M 系列方法论配合使用，提供定量推导的基础。

### 19.1 宏观经济学公式

#### F1：GDP支出法核算公式

```
Y = C + I + G + (X - M)
```

| 变量 | 含义 |
|------|------|
| Y | 国内生产总值（总产出） |
| C | 居民消费支出 |
| I | 国内投资支出 |
| G | 政府购买支出 |
| X - M | 净出口（出口减进口） |

**杨世光的应用**：
1. **中国贸易顺差与超额储蓄分析**：2026/6/15 专期视频从此公式出发，分析中国经常帐顺差（X-M）、超额储蓄（C占比偏低）与人民币升值的关系
2. **经济周期拐点预判**：拆解各组成部分的变化趋势（如 G 占比上升=疫情依赖财政），预判不同国家的经济周期拐点
3. **疫情后财政依赖度**：解释新冠疫情后各国经济对政府支出（G）的依赖程度，G 占比过高的经济可持续性存疑

**与现有框架的协作**：
- **与 M21（贸易盈余-汇率背离）**：用净出口（X-M）持续扩大诊断「强出口+弱货币=资本外流」
- **与 M27（实体经济三线验证）**：用消费线（C）和投资线（I）交叉验证 GDP 增长质量——若 GDP 增长但 C、I 实际停滞，则为虚假繁荣
- **与 M1（经济周期定位）**：通过 C/I/G 的结构变化判断经济处于复苏/过热/滞胀/衰退

#### F2：费雪方程式（货币数量论）

```
MV = PY
```

| 变量 | 含义 |
|------|------|
| M | 货币供应量 |
| V | 货币流通速度 |
| P | 一般物价水平 |
| Y | 实际国民收入 |

**杨世光的应用**：
1. **通胀与货币政策的核心工具**：M2 增速超过 GDP 增速的部分（MV−PY 缺口）是通胀与资产价格泡沫的根源
2. **「货币超发≠立即通胀」**：当货币流通速度 V 下降时，即使央行大量扩表（M↑），MV 增量可能被 V 下降抵消，通胀不出现
3. **资产价格走势判断**：结合 M2 增速与 GDP 增速的差异判断资产价格走势——缺口越大，资产泡沫压力越大

**与现有框架的协作**：
- **与 M4（流动性分析）**：用 M2 增速与 V 的变化判断流动性是否真正传导到实体经济。V 持续低迷=流动性陷阱
- **与 M2（货币政策分析）**：当 V 持续低迷时，央行即使持续扩表也难以推升通胀（日本式流动性陷阱）
- **与 M19（通胀内外申分层）**：费雪方程式解释了「内生通胀」与「货币超发」的差异

#### F3：投资乘数公式

```
k = 1 / (1 - MPC)
```

| 变量 | 含义 |
|------|------|
| k | 投资乘数 |
| MPC | 边际消费倾向 |

**杨世光的应用**：
1. **财政政策放大效应**：MPC 越高，乘数 k 越大，政府投资/财政刺激的 GDP 拉动效果越强
2. **跨国财政有效性对比**：分析不同国家财政刺激政策的有效性差异——消费文化强的国家（美国）MPC 高，财政刺激效果大；储蓄文化强的国家（中国/德国）MPC 低，效果弱
3. **中国超额储蓄困境**：低 MPC 环境下，财政刺激的乘数效应被削弱，投资难以有效转化为消费拉动

**与现有框架的协作**：
- **与 M21（贸易盈余-汇率背离）**：低 MPC 导致储蓄堆积→贸易顺差（X-M）扩大→汇率背离
- **与 M1（经济周期定位）**：乘数效应决定复苏期财政刺激的实际力度

#### F4：购买力平价理论（PPP）

```
S = P₁ / P₂
```

| 变量 | 含义 |
|------|------|
| S | 直接标价法下的汇率 |
| P₁ | 本国一篮子商品价格 |
| P₂ | 外国一篮子商品价格 |

**杨世光的应用**：
1. **汇率高估/低估判断**：用 PPP 计算的「公允汇率」与市场汇率对比，判断货币是否被高估或低估
2. **人民币国际化分析**：讨论人民币国际化进程时，结合购买力平价与实际汇率的差异进行分析——人民币实际汇率远低于 PPP 汇率意味着长期升值空间
3. **「巨无霸指数」式类比**：用具体商品价格对比直观判断汇率偏离程度

**与现有框架的协作**：
- **与 M3（美元周期分析）**：PPP 为美元强弱的长期均值提供基准，当前汇率偏离 PPP 越远，回归压力越大
- **与 M21（贸易盈余-汇率背离）**：PPP 差异是贸易失衡的根本驱动力之一

### 19.2 金融估值公式

#### F5：戈登股利增长模型

```
P = D₁ / (r - g)
```

| 变量 | 含义 |
|------|------|
| P | 股票内在价值 |
| D₁ | 下一期预期股利 |
| r | 投资者要求的必要收益率（贴现率） |
| g | 股利固定年增长率 |

**杨世光的应用**：
1. **「价值投资的基石」**：基本面课程第七集重点讲解，称其为价值投资估值的核心工具
2. **成熟行业估值**：评估公用事业、消费等成熟行业的合理估值（股利稳定、增长率可预测）
3. **利率×估值的核心洞察**：股票价格与市场利率（r）成反向关系——这是理解央行政策对股市影响的关键

**与现有框架的协作**：
- **与 M2（货币政策分析）**：利率上升→贴现率 r 上升→合理估值 P 下降→高估值股票面临「杀估值」。这是高利率环境下科技股承压的理论基础
- **与 M10（巴菲特指标）**：戈登模型从微观（个股）层面解释为何整体市场估值与利率负相关
- **与 M17（风格因子轮动）**：r 上升时，低增长高股息股（D₁大但 g 小）的估值下降幅度更大

#### F6：杜邦分析法

```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
```

| 分解维度 | 公式 | 反映 |
|----------|------|------|
| 盈利能力 | 净利润 / 营收 | 产品定价权和成本控制 |
| 运营效率 | 营收 / 总资产 | 资产使用效率 |
| 财务杠杆 | 总资产 / 股东权益 | 债务杠杆水平 |

**杨世光的应用**：
1. **系统拆解课程**：基本面课程第四至第六堂系统讲解杜邦分析法
2. **识别 ROE 真正来源**：通过将 ROE 分解为三个维度，帮助投资者识别企业盈利能力的真正来源——是靠产品力、运营效率还是财务杠杆
3. **行业 ROE 驱动差异**：
   - 奢侈品/高端品牌：靠高净利率（定价权强）
   - 零售/快消：靠高周转率（薄利多销）
   - 银行/金融：靠高权益乘数（高杠杆）
   - 科技/平台：三者均衡或净利率突出

**与现有框架的协作**：
- **与 M25（第一性原理估值批判）**：用杜邦分析拆解 ROE 来源，判断估值由真实盈利驱动还是杠杆驱动。若 ROE 主要靠权益乘数撑起，则高估值风险更大
- **与 M20（賣鏟人 vs 賣慘人）**：賣鏟人（上游半导体）的高 ROE 来自高净利率+高周转，賣慘人（下游应用）的 ROE 可能依赖杠杆

#### F7：资本资产定价模型（CAPM）

```
Rᵢ = Rբ + βᵢ(Rₘ - Rբ)
```

| 变量 | 含义 |
|------|------|
| Rᵢ | 资产 i 的预期收益率 |
| Rբ | 无风险收益率 |
| βᵢ | 资产 i 的系统性风险系数 |
| Rₘ - Rբ | 市场风险溢价 |

**杨世光的应用**：
1. **证券市场线（SML）讲解**：在课程中结合 SML 讲解不同风险资产的合理定价位置
2. **风格切换分析**：分析市场风格切换时，β 值高低的股票在不同市场环境下的表现差异
   - 牛市/风险偏好高：高 β 股票跑赢大盘（放大收益）
   - 熊市/风险偏好低：低 β 股票抗跌（缩小亏损）
3. **「不同风险的资产应有不同预期收益」**：用 CAPM 解释为什么不能简单比较绝对收益率，必须考虑风险调整后收益

**与现有框架的协作**：
- **与 M2（货币政策分析）**：利率变化改变无风险收益率 Rբ→改变所有资产的必要回报率→估值重估
- **与 M17（风格因子轮动）**：利率上升时 Rբ 上升，高 β 资产的必要回报率上升更快→高 β 成长股承压，低 β 价值股相对抗跌
- **与 M10（巴菲特指标）**：CAPM 提供个股层面的风险定价基准，巴菲特指标提供宏观层面的估值标尺

### 19.3 公式工具箱使用原则

杨世光在使用这些公式时的核心原则：

1. **理论是工具，不是教条**：根据不同的市场环境调整公式的应用条件。例如戈登模型在高增长科技公司上不适用（g 不稳定），CAPM 在非有效市场中可能失效
2. **结合实际数据**：公式中的变量必须用真实市场数据填充，而非假设值
3. **跨公式交叉验证**：例如同时用费雪方程式（MV=PY）和菲利普曲线（M12）判断通胀来源——若 M↑但通胀不涨→V 在下降（流动性陷阱）；若通胀+低失业→菲利普曲线内生压力
4. **与 M 系列方法论联动**：公式提供定量计算基础，M 系列提供定性分析框架，两者配合形成完整分析链

## 二十、周期股估值法（M28，从6/23全球资本市场会议提炼）

### 20.1 PB vs PE 的核心逻辑

```
周期股盈利随行业景气度大幅波动：

景气底部：
  盈利大幅下滑 → PE被动拉高（甚至亏损导致PE失效）
  但此时PB接近历史低位 → 资产价值被低估 → 买入时机

景气顶峰：
  盈利爆发增长 → PE被压至极低
  但PB远超历史均值 → 资产价值被高估 → 卖出时机

核心原则：
  周期股看PB不看PE
  「买在高PE（景气底部），卖在低PE（景气顶峰）」
  市场用低PE给周期股定价 = 周期股泡沫化的典型特征
```

### 20.2 分析模板

| 步骤 | 动作 | 诊断标准 |
|------|------|----------|
| 1 | 确认标的属于强景气周期股 | 存储/钢铁/化工/航运/能源 |
| 2 | 查看当前PE历史分位 | 底部=高PE，顶峰=低PE |
| 3 | 查看当前PB历史分位 | 底部=低PB，顶峰=高PB |
| 4 | 交叉诊断 | 低PE+高PB→卖出；高PE+低PB→买入 |
| 5 | 验证行业指标 | 产能利用率、库存周期、产品价格 |

### 20.3 实战案例（SK海力士 2026/6/23）

| 指标 | 数据 | 诊断 |
|------|------|------|
| 营业利润率 | ~70%（极端高位） | 景气顶峰特征 |
| 2025e盈利 | ~1800亿美金 | 盈利爆发增长 |
| 四年累计盈利预测 | ~7000亿美金 | 市场以此推高估值 |
| 市值 | 超过三星电子 | 市值/盈利不匹配 |
| 估值误区 | 市场用低PE追高 | 泡沫化情绪表现 |
| 正确做法 | 用PB估值 | 检验PB是否已远超历史均值 |

### 20.4 与现有框架的协作

- **与 M20（賣鏟人vs賣慘人）**：周期股估值法用于评估賣鏟人（半导体上游）估值是否已透支景气顶峰盈利
- **与 M25（第一性原理估值批判）**：M25批判市值叙事，M28批判盈利定价方式，两者配合全面诊断估值泡沫
- **与 M10（巴菲特指标）**：M10判断整体市场泡沫，M28判断个股是否处于周期顶峰
- **与 F6（杜邦分析）**：杜邦分析拆解ROE来源，周期股估值法判断ROE处于周期哪个位置

## 二十一、页岩油产能见顶分析法（M29，从6/23全球资本市场会议提炼）

### 21.1 核心逻辑：气为主油伴生

```
传统油气：油为主，气伴生
  → 油价决定产能

页岩油气（美国技术）：气为主，油伴生
  → 天然气价格决定产能（占7成影响权重）
  → 油价仅占3成影响权重

传导链：
  气价高 → 大规模开采页岩气 → 副产品页岩油供给增加
  → 天然气过剩 → 气价崩盘
  → 气价低 + 油价回落 → 毛利率收窄
  → 企业再投资意愿下降 → 产能见顶
  → 页岩油/气产出零增长

结论：页岩油产能见顶 = 全球原油长期供给增量大幅收窄
```

### 21.2 分析模板

| 步骤 | 指标 | 见顶信号 |
|------|------|----------|
| 1 | 天然气价格趋势 | 持续低迷 |
| 2 | 页岩油气企业Capex | 持续下降 |
| 3 | 页岩油产出增速 | 接近零增长 |
| 4 | 页岩气产出增速 | 接近零增长 |
| 5 | 综合判断 | 气价低迷+Capex下降+产出零增长=已见顶 |

### 21.3 实战案例（2026/6/23）

| 指标 | 状态 | 含义 |
|------|------|------|
| 天然气价格 | 全球气价崩盘后持续低迷 | 页岩气开采动力不足 |
| 油价 | 回落至80美元附近 | 叠加气价低迷，毛利率收窄 |
| 再投资意愿 | 显著下降 | 企业不愿扩产 |
| 产出增速 | 基本零增长 | 产能已接近峰值 |
| 欧佩克判断 | 美国页岩油2024-2026见顶 | 长期供给增量不足 |

### 21.4 与现有框架的协作

- **与 M30（美元-油价相关性模型）**：页岩油见顶是美元-油价正相关关系瓦解的根本原因
- **与 M3（美元周期分析）**：页岩油见顶后，美元的能源实体属性支撑消退，转为金融属性主导
- **与 M5（大类资产轮动）**：页岩油见顶 → 全球能源供给收缩 → 大宗商品大周期信号

## 二十二、美元-油价相关性三阶段模型（M30，从6/23全球资本市场会议提炼）

### 22.1 三阶段演变

| 阶段 | 时期 | 相关性 | 驱动因素 |
|------|------|--------|----------|
| 第一阶段 | 2017年之前 | 负相关 | 美国能源净进口+购买力平价 |
| 第二阶段 | 2017年之后 | 正相关 | 页岩革命→美国走向能源净出口 |
| 第三阶段 | 当前 | 回归负相关 | 页岩油见顶→能源红利消退 |

### 22.2 各阶段详细逻辑

**第一阶段：传统负相关（2017年之前）**
```
逻辑1：美国是全球最大能源逆差国
  油价↑ → 贸易收支恶化 → 利空美元
  油价↓ → 贸易收支改善 → 利好美元

逻辑2：购买力平价机制
  原油以美元计价，供需不变时
  美元↑ → 油价名义价格↓（维持实际购买力稳定）
  美元↓ → 油价名义价格↑
```

**第二阶段：正相关形成（2017年之后）**
```
驱动：美国页岩油革命
  → 美国从能源净进口国走向能源净出口国
  → 油价↑ → 改善美国贸易收支 + 带动能源出口的美元需求
  → 油价与美元同步上涨
本质：市场对美国能源贸易结构变化的定价
```

**第三阶段：回归负相关（当前正在发生）**
```
驱动：页岩油产能见顶
  → 美国能源贸易结构优化红利结束
  → 无法再通过能源出口增量支撑美元
  → 油价对美元的正向驱动消失
含义：
  短期：美元走强压制油价（计价效应）
  长期：全球能源供给增量收缩 → 能源品长期定价中枢抬升
```

### 22.3 与M18（黄金-利率相关性周期法）的对称性

- M18：黄金与实质利率的相关性符号翻转 = 黄金超级周期信号
- M30：美元与油价的相关性符号翻转 = 大宗商品超级周期信号
- 两者都是「相关性符号翻转」方法论，用于判断资产是否进入超级周期

### 22.4 与现有框架的协作

- **与 M29（页岩油产能见顶）**：M29提供因果解释，M30提供价格信号验证
- **与 M3（美元周期分析）**：M30解释美元强弱与油价的联动关系，M3分析美元本身的驱动因素
- **与 M5（大类资产轮动）**：相关性状态决定美元和商品的轮动关系

## 二十三、轧空风险评估法（M31，从6/23全球资本市场会议提炼）

### 23.1 分析框架

```
□ 现货库存诊断：
  □ 商业库存（不含战略储备）处于历史什么分位？
  □ 关键交割点库存（如库欣）是否逼近"死亡线"？
  □ 库存趋势：持续下滑 or 正在回补？

□ 空头持仓诊断：
  □ 期权空头持仓量：是否接近或创历史新高？
  □ 期货空头持仓量：投机空单 vs 套保空单的比例
  □ 空头集中度：是否集中在少数机构？

□ 综合诊断：
  低库存 + 高空单 → 轧空风险极高
  低库存 + 低空单 → 供给偏紧但无逼空压力
  高库存 + 高空单 → 供给宽松，空头有底气
  高库存 + 低空单 → 中性偏空

□ 轧空触发信号：
  突发供给中断（地缘/天气）
  需求端意外利好（旺季/政策刺激）
  空头龙头率先平仓 → 连锁反应
```

### 23.2 实战案例（原油 2026/6/23）

| 指标 | 数据 | 轧空风险评估 |
|------|------|------------|
| 商业原油库存（不含SPR） | 过去5年低位 | 现货端供给不宽松 |
| 库欣交割点库存 | 过去5年低位 | 接近逼空条件 |
| 全球原油期权空头持仓 | 即将创历史新高 | 空头极度拥挤 |
| 综合判断 | 低库存+高空单 | **轧空风险极高** |
| 亚洲盘弱/欧美盘强 | 亚洲交易和谈乐观，欧美交易供给风险 | 日内节奏分化 |

### 23.3 与6/18会议的呼应

- 6/18会议已提出"库欣库存逼近2000万桶死亡线"和"有轧空潜力但不是100%发生"
- 6/23会议升级为"期权空单即将创历史新高"，轧空风险从"有潜力"升级为"隐含巨大"
- 追踪逻辑：库存低位持续 + 空单持续增加 → 轧空风险逐步升级

### 23.4 与现有框架的协作

- **与 M27（实体经济三线验证）**：库存线（M27）提供现货库存趋势，M31将其升级为轧空风险评估
- **与 M5（大类资产轮动）**：轧空风险是原油等大宗商品短期暴涨的触发机制
- **与 M15（地缘事件计数法）**：地缘事件可作为轧空的触发信号
