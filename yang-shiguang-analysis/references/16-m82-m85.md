# 杨世光投资理论基础与风险认知四工具（M82–M85）

> **来源**：杨世光《投资八堂课》（《金钱爆》基本面/投资学系列口播稿，约 2018 年底–2019 年初录制，案例用 2018-10-29 印尼狮航波音 737 MAX 坠机）。
> **性质**：这是**研究方法与风险认知框架**，不是观点集合。节目里的方向性表述（"选股=猴子""财富自由不在选股"）是他在特定语境下的**论断**，须**条件化**使用，不可当绝对结论复用。
> **定位**：补齐 yang-shiguang-analysis 的**微观理论基础层**——前 81 个方法全在宏观/债市/报表维度，本组补「**单个持仓/策略怎么量风险**」「**一个市场该用哪类分析**」「**怎么靠了解深度压风险**」「**长期超额到底来自哪**」。
> **顺序**：本组是**前置的世界观校准器**。做任何标的分析前，可先用 M83 定位市场效率段位、用 M82 建立风险调整后收益的口径。
> **关系**：与 F7（CAPM）配套——CAPM 给"预期收益该是多少"，夏普比率给"这收益划不划算"。

## M82：夏普比率风险调整法（评估任何标的第一刀）

> **单个标的 / 组合好不好，不看"赚了多少"，看"为这份收益承担了多少风险"。**
> 夏普比率 = **超额回报 ÷ 风险的代价（标准差）**——即"每承担一单位风险，换来多少超额回报"。

### 核心公式

```
夏普比率 = [ E(Rp) − Rf ] ÷ σp

  E(Rp)  ：投资组合 / 标的的预期（通常年化）报酬率
  Rf     ：无风险利率（一般取国债殖利率，参 M79 / M80 的主权债定价）
  σp     ：报酬率的标准差（= 波动率 = 总风险的量化）
  分子    ：超额回报（比躺平多赚的部分）
  分母    ：承担了多少风险
```

**定位**：这是把"风险与报酬的权衡"从口号变成数字的**唯一简便工具**。夏普越高，同等风险下收益越高（或同等收益下风险越低）。

### 三条判据（决定读数怎么写）

```
① 口径判据：必须同时报出【期间】（年化？）与【Rf 取自何处】——缺一即未完成读数
② 同类判据：只能**同类比同类**（股票基金↔股票基金、期货↔期货）；跨资产直接比无效
③ 分布判据：夏普隐含【报酬服从正态分布】假设
   → 现实有厚尾 / 偏态（黑天鹅、暴涨暴跌），夏普会**低估极端风险**
   → 判"高夏普策略安全"前，须叠看最大回撤 / 索提诺比率（只看下行风险）
```

### 标准分析步骤

```
□ 第一步：取标的年化报酬 E(Rp)
□ 第二步：取同期无风险利率 Rf（写明来源，如美债 10Y / 1 年期定存）
□ 第三步：取报酬率标准差 σp（写明频率：日/周/月）
□ 第四步：算夏普 + 标注上述口径
□ 第五步：参考分位（普通理解：<1 收益不足抵风险；≈1 平衡；1–2 优良；>2 极佳且罕见；
           为负 = 跑不过无风险利率）——⚠️ 分位是经验刻度，非绝对标准
□ 第六步：叠看厚尾风险（最大回撤 / 索提诺）后再下"性价比"结论
```

### 与既有模块协作

- **F7（CAPM）**：CAPM 算"预期收益该是多少"，M82 算"这收益划不划算"，一前一后。
- **M2（利率）**：Rf 随央行政策变动 → 同一标的的夏普会**因 Rf 变化而改变**（Rf↑ → 夏普↓）。
- **M80（债务滚动成本）**：都是"把风险翻译成可数的代价"的思路，M80 落在财政、M82 落在持仓。
- **M49（流动性优先与折价补偿）**：低流动性资产的 σ 被低估 → 夏普被高估，须打折。

## M83：有效市场光谱定位法（先定位市场，再选分析工具）

> **没有"分析有没有用"的普适答案——先判断这个市场在「无效 ↔ 有效」光谱的哪一段，再裁决哪类分析有效。**
> 越成熟 / 机构化 / 高流动性的市场，**技术分析（量价形态）效率递减**，基本面与第一手观察权重上升。

### 核心原理：把"市场"当连续光谱，不是二元

```
光谱左端（无效市场）                 →            光谱右端（强式有效）
  · 信息不对称严重                                    · 信息瞬间反映
  · 内幕 / 事件分析有效                                · 内幕无用（已被定价，参 M38）
  · 基本面分析部分有效                                 · 基本面分析无用
  · 技术分析（量价形态、线性外推）有效                 · 技术分析无用
  · 定价靠人为的量价博弈                              · 定价靠广泛流动性的买卖撮合
```

**判据（四把尺，判断市场在哪一段）：**
```
① 信息效率：重大事件发生的价格反应速度（秒级 → 高效；滞后数日 → 低效）
② 流动性与成交量：广泛流动性 = 撮合充分 = 高效
③ 机构化程度：外资占比、MSCI / 富时纳入、QFII / QDII 开放度（越开放越有效）
④ 价格发现方式：靠"打听消息"还是靠"流动性撮合"定价
```

**方法映射（定位后才知道该用哪类分析）：**
| 市场段位 | 内幕消息 | 基本面 | 技术分析 |
|---|---|---|---|
| 弱式 / 无效 | 有效 | 部分有效 | **有效** |
| 半强式 | 无用 | 部分有效 | 无用 |
| 强式有效 | 无用 | 无用 | 无用 |

### ⚠️ 核心纪律：首次定价 ≠ 终局真相

- 单次事件的价格反应，**不能**直接当"市场已给出真相"（波音案例：当天跌 7% → 回升创历史新高 → 第二炸才停飞）。
- 正确用法：把价格反应当作**假设**，用后续事实**证伪**；未证伪前，不把"市场已知道"写进结论。
- 与 **M38（市场价格隐含信息解读法）** 配对：M38 读"价格已定价什么"，M83 追加约束"这次定价**可能是错的**"。

### 标准分析步骤

```
□ 第一步：选定目标市场（某品种 / 某板块 / 某国股指）
□ 第二步：走四条尺（信息效率 / 流动性 / 机构化 / 价格发现方式）→ 定段位
□ 第三步：按段位表裁决——内幕 / 基本面 / 技术分析各自的有效性
□ 第四步：凡引用"某事件的价格反应"，先过"首次定价 ≠ 终局真相"纪律
□ 第五步：输出——"该市场当前该以哪类分析为主"，并标注段位判断依据
```

### 与既有模块协作

- **M9（A 股特化）**：M9 给"政策→资金→技术"三层传导，M83 补"这三层各占多少权重取决于市场效率段位"。
- **M38**：M38 读价格内容，M83 判价格可信度，配合使用。
- **M43（机构行为变迁）**：机构化程度（判据③）与 M43 同源，M43 看"谁在定价"，M83 看"定价效率高不高"。

> ⚠️ 杨世光的**观点**（"中国市场从无效走向有效，技术分析将越来越失效"）**属判断**，须用最新机构化数据独立复核，**不可直接引用为结论**。

## M84：信息不对称折价法（了解深度 = 降低标准差）

> **风险不是玄学——"期望与真实的落差"就是标准差。你对标的了解越深（第一手、知根知底），落差越小 = σ 越小 = 夏普越高。**
> 选择的"数量"（认识 30 人还是 3000 人）不决定好坏；**对风险的掌握程度**才决定好坏。

### 核心原理（源：办公室恋爱 / 网恋 P 图类比）

```
网恋对象（美图 P 过）  ：期望报酬高，但期望与真实落差【大】→ 标准差【大】→ 风险高
办公室同事（日常素颜） ：期望报酬一般，但知根知底、落差【小】→ 标准差【小】→ 风险低

→ 不是"漂不漂亮"（收益率）的问题，是"期望与真实落差"（标准差）的问题
→ 同样的目标回报下，选【你了解更深】的那个，夏普更高
→ 映射：投资中，信息不对称 = 主动放大的标准差
```

### 三条判据

```
① 一手判据：信息是【第一手调研】还是【二手转述 / 传闻】（源头越远，落差越大）
② 偏差判据：该标的 / 该说法历史上"预期 vs 实际"的偏差记录（偏差大 = 该标的"美图度高"）
③ 选择集判据：扩大选择集（认识更多人 / 看更多标的）**本身不提高质量**，只在"了解深度"跟进时才有用
```

### 标准分析步骤

```
□ 第一步：标出你对目标标的的信息来源层级（一手 / 二手 / 传闻）
□ 第二步：评估该标的"预期 vs 实际"的历史偏差（是否常"P 图"）
□ 第三步：把信息掌握度当作降低 σ 的因子（而非提高收益率的因子）
□ 第四步：在夏普口径（M82）里体现——了解越深，σ 越可信、越小
□ 第五步：输出——"这个标的的信息折价 / 风险溢价是否被低估"
```

### 与既有模块协作

- **M43（机构行为）/ M36（物价倒推供需）**：都是"从一手事实反推"的思路，M84 是把它收到**单个标的的风险判断**上。
- **M38**：一手观察是对抗"价格隐含偏见"的办法。

## M85：风险认知优先法（长期超额从哪来）

> **长期看，超额收益的主要来源是"对风险的认知与掌握"，而非"选股"。**
> ⚠️ 这是杨世光的**论断**，须**条件化**——它成立的前提是"市场偏有效"（M83 光谱右端）；在无效市场，选股（量价形态）仍有效。

### 核心原理

```
世光逻辑链：
  市场越有效 → 单个标的的风险占长期报酬的比重越来越低
             → 需分散化 / 规模化（降低非系统性风险）
             → "选股"对长期报酬的贡献被稀释
             → 长期赢家 = 把【风险认知与掌握】做到位的人
             → 结论：财富自由的关键不在选股，在风险管理

关键提醒：市场是光谱（M83），此结论【只在偏有效市场成立】
         在弱式 / 无效市场，"选股 + 量价形态"仍是有效工具
```

### 三条纪律（防止把论断绝对化）

```
① 前提纪律：用 M85 前先跑 M83 定位市场段位；段位偏左（无效）时，禁止套用"选股无用"
② 分散纪律：分散化降低的是【非系统性风险】；系统性风险（β）靠资产配置 / 对冲管理
③ 反例纪律：凡见"选股完全无用 / 和抛硬币一样"的表述，一律先判【市场段位】再表态——
            不可跨市场、跨段位直接引用
```

### 标准分析步骤

```
□ 第一步：跑 M83 定目标市场段位（左 / 右）
□ 第二步：若偏有效 → 侧重风险认知（M82 + M84），淡化个股择时
□ 第三步：若偏无效 → 保留选股 / 量价工具（参 caisen-kline / caisen-technical-analysis）
□ 第四步：无论哪种，都先做风险画像（σ / β / 最大回撤 / 相关性）
□ 第五步：输出——"该市场下，长期超额应优先取自【风险管控】还是【选股】"
```

### 定位与协作

- **与 caisen-kline / caisen-technical-analysis（蔡森系）的关系**：蔡森体系 = **无效市场段位的选股/择时工具**；M85 = 偏有效市场段位的风控世界观。**二者按 M83 的段位判断分工，不互斥**。
- **与 M47（确定性溢价）/ M49（流动性折价）**：都是"定价里含风险补偿"的思路，M85 是它在"长期收益来源"上的总纲。

## M82–M85 联动配方

```
判「这个标的值不值得承担」         → M82（夏普口径：超额回报 ÷ 标准差）
判「这个市场该用哪类分析」         → M83（四把尺定段位 → 方法映射表）
判「某事件的价格反应能不能当真相」 → M83 纪律（首次定价 ≠ 终局真相，配 M38）
判「怎么把风险压下来」             → M84（信息掌握度 ↑ → σ ↓）
判「长期超额该取自选股还是风控」   → M85（先跑 M83 定段位，再分工）
```

**共用铁律**：**凡"市场已经知道 / 分析完全无用 / 选股就是抛硬币"的表述，一律先跑 M83 定市场段位，再表态。**

> **与 M1–M81 的关系**：M1–M81 是**宏观与资产负债表层面的读数件**；M82–M85 是**投资理论基础与风险认知的世界观层**。做任何标的分析前，可先用 M83 校准"该用什么工具"。
