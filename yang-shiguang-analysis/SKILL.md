# 杨世光宏观六步法方法论
> **核心定位**：这是一套**研究方法**，不是观点集合。每次分析时，按方法论独立推导结论。杨世光本人的观点只是方法论的实战示例。

## 工作流程 / 使用步骤

## 分析工作流

当用户要求分析某个经济现象、市场走势或资产方向时，按以下步骤进行：

### 第一步：判断经济周期位置

用以下框架判断当前经济处于哪个阶段：

| 周期阶段 | 经济特征 | 通胀特征 | 最优资产 |
|----------|----------|----------|----------|
| 复苏期（Recovery） | GDP加速增长 | 通胀低迷 | 股票（成长股） |
| 过热期（Overheating） | GDP高增长 | 通胀上升 | 商品/大宗商品 |
| 滞胀期（Stagflation） | GDP减速 | 通胀仍高 | 现金/短期债券 |
| 衰退期（Recession） | GDP负增长 | 通胀下降 | 债券（长久期） |

**关键指标**：
- PMI（采购经理人指数）：>50扩张，<50收缩
- GDP增速：环比/同比趋势
- CPI/PPI：通胀压力
- 失业率：劳动力市场松紧
- 消费者信心指数

### 第二步：分析货币政策与利率环境

美联储（FED）政策是杨世光分析的核心锚点：

**利率周期判断**：
- 加息周期 → 资金成本上升 → 压制风险资产（股票、加密货币）→ 美元走强
- 降息周期 → 资金成本下降 → 利好风险资产 → 美元走弱
- 利率持平 → 观望市场如何重新定价

**关键观察指标**：
- 联邦基金利率（FFR）及其前瞻指引
- 美联储资产负债表规模（QE/QT）
- 美债收益率曲线（2年vs10年利差）
- 期限溢价（Term Premium）
- 实际利率 = 名义利率 - 通胀预期

**杨世光特别关注**：
- 美联储措辞变化（鹰/鸽转向信号）
- 点阵图与降息/加息预期
- 缩表进度对流动性的影响

### 第三步：分析美元周期

美元是全球资产定价的锚：

**美元强势周期**：
- 资金回流美国
- 新兴市场承压
- 大宗商品走弱
- 黄金承压

**美元弱势周期**：
- 资金流出美国
- 新兴市场受益
- 大宗商品走强
- 黄金走强

**美元周期驱动因素**：
1. 利差（美国vs其他经济体）
2. 通胀差异
3. 经济增长差异
4. 去美元化趋势
5. 地缘政治/制裁影响

### 第四步：流动性分析

杨世光频繁分析流动性问题：

**宏观流动性指标**：
- 美联储资产负债表变化
- 银行系统准备金余额
- 逆回购（RRP）规模
- TGA（财政部一般账户）余额
- M2货币供应量增速
- 信用利差（投资级vs高收益）

**流动性判断**：
- 流动性充裕 → 资产价格上涨
- 流动性收紧 → 资产价格承压
- 流动性陷阱 → 央行释放流动性但经济不响应（类似日本）

### 第五步：大类资产分析

基于以上宏观判断，分析各类资产方向：

**股票市场**：
- 关注估值（P/E、P/B）与盈利增长的匹配度
- 利率环境对估值的影响
- 行业轮动（科技、金融、能源、消费等）
- 筹码结构（外资、主力、散户持仓变化）

**债券市场**：
- 收益率曲线形态（正常/平坦/倒挂）
- 信用利差变化
- 期限溢价走势
- 央行政策对债券市场的影响

**黄金**：
- 实际利率是核心定价因子（实际利率↓→金价↑）
- 美元走势
- 地缘风险溢价
- 央行购金需求
- 去美元化趋势

**原油/大宗商品**：
- 供需基本面（OPEC+产量、库存数据）
- 美元走势
- 全球经济增长预期
- 地缘政治（中东局势等）
- 原油是通胀的领先指标

**汇率**：
- 利差驱动
- 经济基本面差异
- 资本流动
- 央行干预

### 第六步：地缘政治与政策影响

杨世光重视地缘政治对市场的传导：

- 中美贸易/科技博弈
- 关税政策对供应链和通胀的影响
- 制裁与反制裁（去美元化）
- 区域冲突（俄乌、中东）
- 各国央行政策分化

### 第七步：输出分析报告

```
【宏观经济形势判断】
- 当前经济周期位置：XXX
- 货币政策环境：XXX
- 流动性状况：XXX

【关键变量分析】
- 美元/利率：XXX
- 通胀趋势：XXX
- 地缘风险：XXX

【大类资产方向判断】
- 股市：XXX（理由）
- 债市：XXX（理由）
- 黄金：XXX（理由）
- 原油/商品：XXX（理由）
- 汇率：XXX（理由）

【风险提示】
- 主要风险因素
- 需要关注的数据/事件

【投资策略建议】
- 配置方向
- 需要回避的风险
```
