# 波段跌幅满足（Band Drop Target）

> 来源：蔡森视频课逐字稿《波段跌幅满足》（用户 2026-10-29 提供全文）
> 归档日期：2026-10-29
> 校验状态：**8 个讲义算例全部复算一致 + 东财真实日线交叉验证通过**（见 §4、§8）
> 定位：这是「涨幅满足」的镜像工具，用于**左侧抄底定位价值区**，不用于判断止跌时点

---

## 0. 一句话定义

**一段下跌（A→B）之后反弹到 C、再跌破 B，则第二波的跌幅与第一波等长，目标价 = C − (A − B)。**

```
A ─╮                    ╭ C  ← 反弹高点（跌破B之后才追认为高点）
    ╰╮      ╭──────────╮│
     ╰╮    ╱  上飘旗/中继  ╰╮
      ╰╮  ╱                ╰╮   ← 破线（跌破B）
       ╰B╯                  ╰╮
                                ╰╮  第二波跌幅 = D = A−B
                                 ╰→ 满足点 = C − D
```

---

## 1. 为什么必须是「两波」——不是几何规律，是主力叠空间的习性

讲义反复强调这是**习性**，不是数学必然。逻辑链：

1. 主力在高位出完货，价格自然往下掉一段（第一波，A→B）
2. 跌出来的空间不够，主力不愿意进——**必须"叠出一个空间"才肯做价**
3. 于是做一个短弹（C 点），弹幅通常 15%~20%，因为"这是做短，做一下就跑了"
4. 再砸第二波（第二波跌幅 = 第一波），把空间叠到主力满意的位置，才开始布局

**推论（这是本课最有用的一条）：**
- **第一波不测，第二波才测。** 第一波你不知道主力要打到哪，只能抱着看；第二波才有"等幅"这个锚
- 与「涨幅满足」完全对称：第一波不知道涨多少，第二波才算得出
- 所以这个工具天然是**第二次下跌时用的**，第一波下跌途中用它算目标，属于误用

## 2. 五步操作法

| 步骤 | 动作 | 判定标准 | 常见错误 |
|---|---|---|---|
| **0 前置** | 确认下跌途中出现过「上飘旗 / 中继整理」 | 反弹段有收敛结构、不是V型直上 | 反弹没整理就硬算 |
| **1 量第一波** | 找 A（第一波顶）→ B（第一波底），算 D = A − B | 用同一复权口径的收盘/极值 | 跨除权日计算 |
| **2 等破线** | 反弹到 C 后，**必须跌破 B（前低）** | 跌破 B 才追认 C 是高点 | ⚠️ 没破前低就算，C 到处都是 |
| **3 投影** | **满足点 = C − D** | 见 §3 算法分歧 | 误用「颈线 − D」 |
| **4 到价处理** | 到满足点不猜底，等底部信号 | 见 §5 三种例外 | 到价就满仓 |

**Step 2 是全课的技术核心**，讲义原话：

> "涨要涨过前高，跌要跌破前低。因为跌破前低才能确定这个 75 是高点啊，要不然的话每个地方都是高点。"

**可以算 / 不可以算：**

| 可以算 | 不可以算 |
|---|---|
| 有明确 A→B 下跌段 | 还在第一波下跌途中（未见反弹 C） |
| 反弹 C 有整理结构 | 反弹直接 V 型尖顶后又破底（C 不清晰） |
| 已跌破 B（前低） | 只是盘中假摔破 B、当日收回（等实体确认） |
| 同一复权口径的价格 | 跨除权/跨拆股拼接的价格 |

## 3. ⚠️ 算法分歧：`C − D` 还是 `颈线 − H`（本课最重要的一条修正）

现有 `SKILL.md` 第四步的 M 头算法是 **满足点 = 颈线 − H**。本课讲的是 **满足点 = C − D**。两者差一个量：**反弹高度（C − B）**。

### 实测裁决（江丰电子 2017-11 ~ 2018-02，真实日线）

- A = 88.13，B = 53.96 → D = 34.17
- C = 73.44（破线后确认的反弹高点）
- **本课法**：73.44 − 34.17 = **39.27** → 实际最低 39.01 ✅（偏差 0.66%）
- **颈线法**：53.96 − 34.17 = **19.79** → 与 39.01 相差 **50%** ❌

三例全测：

| 标的 | C − D（本课法） | B − D（颈线法） | 实际最低 | 颈线法偏离 |
|---|---|---|---|---|
| 比亚迪 | 36.73 | 29.52 | 36.73 | −20% |
| 江丰电子 I | 39.27 | 19.79 | 39.01 | −50% |
| 江丰电子 II | 30.98 | 22.77 | 30.36 | −27% |

### 结论（写进方法论）

1. **两波等幅投影的基准是「破线确认后的反弹高点 C」，不是颈线。**
2. **M 头场景下**，若反弹高点 ≈ 颈线（标准 M 头右肩回抽到颈线），两法自然收敛，`颈线 − H` 可用。
3. **凡是 C 明显高于颈线**（反弹超出颈线再回落），**必须用 C − D**，否则目标价被系统性低估 20%~50% —— 这是最危险的错误方向：目标算太低会**错过整个底部**，抄底单永远等不到价。
4. 两种测幅的分工：
   - `颈线 − H`：**形态测幅**（M头、头肩顶，靠形态高度投射）
   - `C − D`：**波段等幅测幅**（任何下跌—反弹—破底结构，靠前一波自身幅度投射）
   - 后者适用面更宽，因为是自参照（self-referential），不需要先认定形态

### 三条从数据里挖出来的规律（讲义没讲，但决定怎么用）

**规律一：价位越低，偏差越大 —— 满足点必须给区间，不能给点**

| 目标价位 | 样本 | 平均绝对偏差 |
|---|---|---|
| ≥ 25 元 | 比亚迪、江丰 I、江丰 II | **1.01%** |
| < 12 元 | 平安银行、世创、苏宁、伊利 | **5.60%** |

差 5.5 倍。原因很直白：**跌的绝对金额相同，但低价股的跌幅占比天然更大**（平安银行跌 0.60 元 = 7.6%，比亚迪跌 0.14 元 = 0.38%）。低价股本身波动率高。

→ **落地容差：**

| 目标价位 | 满足区带宽 |
|---|---|
| ≥ 20 元 | ±2% |
| 10 ~ 20 元 | ±4% |
| < 10 元 | ±8% |

**规律二：满足点是「引力区」，不是「支撑位」——7 例中 5 例跌过头**

| 方向 | 数量 | 案例 |
|---|---|---|
| 跌破满足点（超跌） | **5/7** | 比亚迪 −0.38%、江丰I −0.66%、江丰II −2.00%、平安 −7.57%、世创 −13.01% |
| 未到满足点即止跌 | 2/7 | 伊利 +0.09%、苏宁 +1.74% |

讲义说"跌的时候也会多跌一点，很正常"，实测确实偏向下穿，但**不是必然**——苏宁和伊利就是没到就止跌了。

→ **操作含义：不能挂单死等满足点。** 满足区入场应当是**分批**的：满足区上沿先建一半，跌到区间下沿补另一半。死等精确点会踏空 2/7 的票。

**规律三：满足点很少一次到位，会"穿一下再回来"**

讲义原话："常常超跌，他很快也会回来啊，都会很快回来的。" 唯一的反例是基本面差的票（见 §5.3）。

## 5. 三种必须临场改规则的情形

### 5.1 未到满足点，先出破底翻 → **破底翻优先，别再等满足**

> "有时候还没到，他就先把一个做出一个破底翻了，还没到之前就做破底翻了啊，那就不要等满足了。"

判定顺序：**底部结构信号 > 满足点价格**。破底翻（跌破后快速收回、3 日站稳）出现时，即使离满足点还有距离，也是有效入场信号。反之，**只要没出现底部结构，就一直等到满足点**。

### 5.2 满足点后继续杀 → 指数/期货**不许裸接**，改买权

> "做期货的或做股指期货，万一不幸到满足又往下杀呢，那种机会很少，但是遇到一次就被杀断了怎么办，那就做选择权的买权。"

这是全课唯一一条**风控硬约束**，且直接关系到杠杆工具：

| 工具 | 到满足点后继续杀 | 后果 |
|---|---|---|
| 现货股票 | 浮亏，可扛 | 可接受 |
| 股指/商品期货裸多 | 追缴保证金、强平 | **一次归零** |
| **买权（Call）** | 最多损失权利金 | 可控 |

讲义的理由："那种机会很少，但是遇到一次就被杀断了"。**低频高损 = 必须用非线性工具对冲**。这正好对应「越跌越买」策略在期货端的最大死穴：满足点再破位时，左侧补仓会加速爆仓。

### 5.3 基本面差的票 → 满足点无效，会在线下弱势整理

> "很少有的有的股票比较差的，基本面比较差……就算差一点，他也是跌破会回来，弱势整理一下……比较少的他会在什么线的下面整理。"

满足点是**价值型标的**的工具。基本面恶化（业绩塌方、退市风险、行业逆转）的票，跌到满足点后不会回来，而是在均线下方长期磨。**用之前先确认这票"有成长性或者有投资价值"** —— 这是讲义的原话前置条件，不是可选项。

## 7. 落地清单 / 禁止清单

**算之前必须确认的 5 件事：**
1. 复权口径统一（跨除权日必须重算，否则 D 失真）
2. A→B 是完整下跌段，不是下跌中的一根阴线
3. 反弹 C 有整理结构（上飘旗/中继），不是 V 型尖顶
4. **已经跌破 B（前低）** —— 未破不算
5. 标的有基本面支撑（否则满足点无效）

**算完之后必须做的 3 件事：**
1. 目标价改成区间（按 §4 价位分档给带宽）
2. 拆两批进（区间上沿 + 下沿），不挂单死等点
3. 标注底部信号观察位：破底翻 / 带量长红 / 大底盘出 → 出现即提前动手

**绝对禁止：**
- ❌ 第一波下跌途中就用它算目标（那是"猜底"）
- ❌ 未破前低就认定 C 是高点（"每个地方都是高点"）
- ❌ 用颈线代替 C 投影（目标低估 20%~50%，会错过整个底部）
- ❌ 用满足点裸接期货/股指（见 §5.2）
- ❌ 拿它给基本面崩坏的票定价值（见 §5.3）
