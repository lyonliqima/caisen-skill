## M36：物价倒推供需分析法

> 总供需不可直接观测，物价是其均衡结果；用「物价方向 → 供需格局 → 排除不符现实的一侧」倒推核心矛盾，是判断周期与定位矛盾的第一性工具。

### 核心原理

```
总供给/总需求不可直接观测（数十亿消费者 + 数千万企业 + 上千产业）
  → 物价 = 供需博弈后的均衡价格 = 最直接、实时可见的结果指标

物价持续走高 → 整体供不应求
物价持续走低 → 整体供过于求

验证闭环：
  先由物价方向给初步供需格局
  → 分别排查供给端（产能 / 进口 / 原料 / 供应链）
  → 与需求端（消费 / 投资 / 出口）现实
  → 排除不符合现实的一侧
  → 锁定「供给主导」 or 「需求主导」
```

### 标准分析步骤

```
□ 选定核心物价指标（CPI / PPI / 核心PCE），确认趋势性方向
□ 由物价方向给出供需格局初步判断
□ 排查供给端现实：产能、进口、原材料、供应链
□ 排查需求端现实：消费、投资、出口
□ 排除不符现实的一侧 → 锁定核心矛盾（供给 or 需求主导）
```

### 实战案例（2026 本次会议）

| 观察 | 判断 | 含义 |
|------|------|------|
| 消费者物价指数走弱 | 先排除「供给不足」（消费品产能充足，无大面积短缺） | 核心矛盾指向需求侧 |
| 经济逐步走弱 | 锁定「需求不足」为凸显矛盾 | 政策应刺激需求 |
| 油价上涨 | 先判为供给端成本冲击，再验证其对需求的反噬 | 高油价对需求的破坏 > 对成本的推升 |

### 与现有框架的协作

- **与 M1（经济周期定位）**：物价倒推是周期定位的先行输入
- **与 M2（货币政策与利率）**：需求不足 → 宽松必要性上升
- **与 M4（流动性分析）**：需求侧矛盾对应信用扩张意愿
- **与 M19（通胀内外申变量分层）**：物价方向区分内生/外生冲击的起点

## M37：名义利率二元拆解法（费雪拆解法）

> 名义利率 = 实质利率 + 通胀预期；拆分后可避免把利率变动笼统归因于「通胀」或「加息」，精准定位真实驱动因子。

### 核心原理

```
费雪方程式：名义利率 r = 实质利率 r* + 通胀预期 π^e

实质利率 r*：资本真实报酬率，反映资金稀缺性、经济体真实回报、主权信用风险，亦含期限溢价
通胀预期 π^e：对未来物价上涨的预期，给投资者的通胀补偿

两者驱动逻辑完全不同：
  通胀预期 ← 物价、大宗商品、供需
  实质利率 ← 资金供需、主权信用、经济潜在增速

拆分意义：避免把名义利率变动笼统归因为「通胀」或「加息」
```

### 标准分析步骤

```
□ 获取目标期限国债名义利率变动（以 BP 计，1BP = 0.01%）
□ 通过 TIPS 收益率 / 盈亏平衡通胀率，算同期通胀预期变动
□ 实质利率变动 = 名义利率变动 − 通胀预期变动
□ 对比两者贡献占比 → 判断本轮利率变动的核心驱动因子
```

### 实战案例（美 10Y 2026/1–7 上行 61BP）

| 月份 | 名义利率 | 通胀预期贡献 | 实质利率贡献 | 主导 |
|------|----------|--------------|--------------|------|
| 3月 | +33BP | +5BP | +28BP | 实质利率（>80%） |
| 4月 | +10BP | +16BP | −6BP | 通胀预期 |
| 5–7月 | 通胀预期持续回落，实质利率持续走高 | — | — | 实质利率 |
| 整轮（美伊摩擦以来） | +61BP | ≈0 | +61BP | 100% 实质利率 |

**结论**：整轮利率上行通胀贡献为 0，100% 由实质利率推动，推翻「油价上涨推高美债利率」的表层认知。

### 与现有框架的协作

- **与 M2（货币政策与利率）**：费雪拆解是 M2 分析利率的底层工具
- **与 M11（黄金-实质利率回归）**：实质利率项是黄金定价核心
- **与 M13（利率定价消化）**：区分定价中通胀 vs 信用部分

## M38：市场价格隐含信息解读法

> 高流动性资产价格是全体参与者真金白银投票的结果，比任何单一观点更客观；分析的核心是「价格已经定价了什么」，而非「我认为会怎样」。

### 核心原理

```
高流动性交易资产价格 = 全部公开信息 + 预期 + 情绪 的加权共识
  → 比单一机构/个人观点更客观，更接近真实共识

原则：不是「我认为会怎样」，而是「价格已经定价了什么」
```

### 标准分析步骤

```
□ 选定流动性充足、定价有效的核心资产（大国国债、主流大宗商品、大盘指数）
□ 剥离市场普遍认知的表层驱动（新闻 / 政策 / 事件）
□ 通过价格结构、跨资产联动、不同时段表现，反推价格隐含的真实逻辑
□ 用价格证据验证或证伪主流观点
```

### 实战案例（美伊冲突 2026）

| 主流观点 | 价格证据 | 结论 |
|----------|----------|------|
| 美伊冲突推高通胀 → 推高美债利率 | 利率拆解：冲突对通胀影响极小，实质利率主导 | 证伪 |
| 美国主权信用无忧 | 亚洲时段美债持续抛售 | 最大海外债权人正在减持 |
| — | 债券价格揭示主权信用损伤 / 评级潜在问题 | 「这是价格告诉我们的真相」 |

### 与现有框架的协作

- **与 M7（ETF资金流）**：价格行为背后是机构资金流
- **与 M13（利率定价消化）**：价格已消化 vs 未消化的拆解
- **与 M34（汇率比领先指标）**：用价格结构判断风险偏好

## M39：事件冲击分阶段传导分析法

> 任何外部冲击沿「金融市场 → 产业链 → 实体经济 → 居民需求」逐步扩散，阶段主导逻辑不同，拒绝线性外推。

### 核心原理

```
传导链：金融资产 → 上游成本 → 中下游价格 → 终端需求
每个阶段主导逻辑不同
初期影响 ≠ 长期结果（线性外推必偏）
```

### 标准分析步骤

```
□ 以事件爆发为起点，按月度/季度切分多阶段
□ 每阶段观测核心变量变动，识别该阶段主导驱动
□ 梳理传导链条：金融资产 → 上游成本 → 中下游价格 → 终端需求
□ 总结逻辑切换点，预判下一阶段主导逻辑
```

### 实战案例（美伊摩擦 三阶段）

| 阶段 | 时间 | 主导逻辑 | 表现 |
|------|------|----------|------|
| 第一阶段 | 冲击当月（3月） | 冲击金融市场与主权信心 | 实质利率大幅上行，通胀未体现 |
| 第二阶段 | 冲击后 2 月（4月） | 油价成本向下游转嫁 | 通胀预期抬升，成利率上行主力 |
| 第三阶段 | 冲击后 3 月起（5月） | 高油价反噬终端需求 | 消费/进口走弱，通胀预期转向下拖，实质利率重新主导 |

**类比验证**：DRAM 涨价 vs 手机销量 → 「上游涨最终压制下游需求」的传导规律。

### 与现有框架的协作

- **与 M6（地缘政治传导）**：M39 是 M6 的「分阶段细化版」
- **与 M15（地缘事件计数）**：事件计数为阶段划分提供时间锚
- **与 M32（AI债务传导链）**：产业链传导的另一种形态

## M40：资产相关性异动分析法

> 每种宏观环境对应一套稳定资产相关性；当长期稳定的相关性持续偏离或回归，往往意味着宏观底层逻辑切换，是左侧识别拐点的信号。

### 核心原理

```
宏观环境 ↔ 稳定资产相关性（如加息周期：利率涨→黄金跌；美元涨→商品跌）
相关性持续偏离 或 偏离后回归 = 宏观底层逻辑根本性变化
```

### 标准分析步骤

```
□ 确立两组资产的历史常态相关性与逻辑支撑
□ 跟踪当前相关性变动方向与偏离程度
□ 结合其他宏观变量，验证相关性变化背后的逻辑
□ 判断短期扰动 vs 长期逻辑切换 → 调整宏观判断
```

### 实战案例（2026 均值回归）

| 相关性对 | 历史常态 | 当前变化 | 判断 |
|----------|----------|----------|------|
| 美元 vs 原油 | 过去三年正相关（美成油气出口国） | 转向负相关 | 回归传统规律 |
| 黄金 vs 实际利率 | 过去一年多脱钩 | 重新回归负相关 | 回归传统规律 |
| 两组同时回归 | — | — | 全球宏观定价均值回归，环境生变 |

### 与现有框架的协作

- **与 M30（美元-油价相关性）**：M40 的特例（M30 是相关性翻转信号）
- **与 M18（黄金-利率相关性周期）**：同属「相关性符号翻转」方法论
- **与 M5（大类资产轮动）**：相关性异动是轮动切换的领先信号

## M41：债务可持续性二分判断框架

> 主权债务是否可持续，核心不在绝对规模，而在「政府融资成本 vs 名义GDP增速」的相对关系，这是所有主权债务分析的底层公理。

### 核心原理

```
融资成本 r < 名义GDP增速 g → 债务/GDP 自发下降 → 良性、可滚续
融资成本 r > 名义GDP增速 g → 债务/GDP 螺旋上升 → 恶性、终现偿付压力

即：r<g 良性；r>g 恶性（底层公理）
```

### 标准分析步骤

```
□ 计算政府债务加权平均融资成本（通常用长端国债收益率代表）
□ 计算名义GDP增速（实际GDP增速 + 通胀率）
□ 对比 r 与 g，判断良性/恶性区间
□ 基于目标（让 r<g），推导政策两方向：要么拉高 g，要么压低 r
```

### 实战案例（美国债务 2026）

| 判断 | 依据 | 推导 |
|------|------|------|
| 长端利率持续走高逼近/超名义GDP增速 | r↗ → 逼近 g | 债务向恶性转化压力 |
| 化解「三部曲」 | ①稳通胀预期稳国债需求 ②重建长期买家群体 ③压低长端利率 | 政策统一目标 |
| SLR调整 / IORB下调 / 稳定币立法 | 服务于「找买家、压利率」核心目标 | 政策被统一解释 |

### 与现有框架的协作

- **与 M2（货币政策与利率）**：r 的取值由利率环境决定
- **与 M33（行业债务排挤）**：主权债务与行业债务的竞争性
- **与 M35（资本财进口）**：债务融资去向与实体掏空
- **与 M42（资金供需反推）**：长端利率 = 资金需求（黑洞）的价格信号

## M42：资金供需-价格反推法

> 利率是资金的价格，由供需决定；当利率趋势性变动而供给端无对应变化，必是需求端结构性变化（「资金黑洞」），可从总量数据发现隐性流向。

### 核心原理

```
利率 = 资金的价格
资金供给↑ → 利率↓
资金需求↑ → 利率↑

若利率趋势变动，供给端无对应变化 → 需求端结构性变化
由已知供给 + 价格 → 反推需求端变动（寻找「资金黑洞」）
```

### 标准分析步骤

```
□ 明确「利率是资金的价格」
□ 观测资金供给端变化（央行资产负债表、M2、基础货币投放）
□ 对照利率实际变动，判断供给端能否解释价格变动
□ 供给端无法解释 → 反推需求端变化，定位资金需求主体（资金黑洞）
```

### 实战案例（美国实质利率 2026）

| 事实 | 数据 | 推导 |
|------|------|------|
| 资金供给 | 美联储资产负债表过去三月扩张 | 供给未减 |
| 资金价格 | 10Y 实质利率创三年新高 | 价格在涨 |
| 供需对比 | 供给没减、价格却涨 | 资金需求大幅增加 |
| 需求主体 | 全球 AI 基建形成巨大资本需求黑洞 | 持续吸收全球流动性，推高实际利率 |

### 与现有框架的协作

- **与 M4（流动性分析）**：从总量流动性看分项的供需
- **与 M33（行业债务排挤）**：AI 债务黑洞是 M33 的「需求侧解释」
- **与 M37（费雪拆解）**：实质利率上行 = M42 定位的资金需求冲击
- **与 M43（机构行为变迁）**：谁在提供/抽离资金

## M43：机构投资者行为变迁分析法

> 任何资产的长期价格趋势由其核心买方群体的配置行为决定；传统核心买家系统性迁移而新买家承接不足，则供需格局逆转、定价中枢长期移动。

### 核心原理

```
长期买家决定长期价格
传统核心买家系统性迁移 + 新买家承接不足
  → 资产供需格局根本性逆转 → 定价中枢长期移动
```

### 标准分析步骤

```
□ 识别资产传统核心买方群体（长期最大持有者）
□ 跟踪核心买方持仓规模 / 配置比例 / 偏好变化
□ 分析买方迁移底层原因（收益差、监管、负债端压力）
□ 排查潜在新买方，评估承接能力能否弥补流失
□ 综合判断长期供需格局与定价趋势
```

### 实战案例（美债 2026）

| 维度 | 状态 | 判断 |
|------|------|------|
| 传统买家 | 养老金/退休金/主权基金/保险是数十年核心长期买家 | 基准 |
| 行为变迁 | 系统性转向私募信贷/另类/高收益权益（AI回报远高于国债，负债端倒逼提风险偏好） | 流失 |
| 潜在新买家 | 美联储经 SLR 调整 / IORB 下调引导商行回归长债；稳定币立法创短债需求 | 承接有限 |
| 综合 | 传统流失大，新买家承接不足 | 美债长期需求承压，融资成本易升难降 |

### 与现有框架的协作

- **与 M7（ETF资金流）**：机构行为是资金流的底层
- **与 M42（资金供需）**：机构迁移是资金需求/供给的结构性来源
- **与 M33（行业债务排挤）**：机构撤离国债 → 资金流向 AI 等排挤方
- **与 M41（债务可持续）**：买家流失 → 长端利率难降 → r 逼近 g
