## 输出物

- **高清 K 线标注图 PNG**（约 4100×3900 px，4K 级）：颈线带 / 等幅目标①② / 失败信号 / 套牢区 / 大周期定位
- **结构化文字**：结构判定 / 关键价位 / 风险报酬 / 量价论据 / **C1–C4 强制风险约束**
- **返回字段**：`{png, report, sig, meta}`；⚠️ `sig.ok=False` 时带 `reason`（数据不足**不抛异常**）——**不要把 `ok=False` 当作出图成功**。

## 支持范围（2026-09-20 实机复核）

- ✅ **可用**：沪市 / 深市 / 创业板 A股、港股、中证系列指数、沪深 ETF（含跨境 QDII）、商品期货（上期所 / 大商所 / 郑商所 / **广期所 SI·LC·PS，setcode=66**）

## 四条使用纪律（强制）

1. **引擎给几何，专家给解读** —— 引擎输出的目标位是几何外推结果，须由蔡森专家席位结合量价、大周期（S12 已内嵌逆势自动降级）、基本面交叉验证后才能进结论。**禁止把引擎目标位直接写成操作建议**。
2. **形态识别错会连锁错** —— 颈线选错 → H 错 → 目标错。复杂 / 长期整理结构**必须人工复核颈线触点是否落在同一水平带**。
3. **S14 未实现（已知缺口）** —— 形态仍在进行、价格**已达目标①但未破位**时，引擎**不会主动提示「分批止盈 / 止损移至成本」**。实盘参考时须自行补上这一步。
4. **无回测、无胜率** —— 引擎为几何外推演示工具。**禁止引用为「胜率 XX%」类表述**（与主 SKILL.md「诚实度协议」一致）。

## 出图配色规范：四色K线 + 量价（2026-09-20 作者定稿，默认开启）

> 作者原话：「蔡森每次画图，用这个 <Pine 四色K线指标>，要看量价」。
> 实现落在 `caisen-kline/caisen_trend.py`，**所有蔡森出图默认套用，不要再画红绿二色 K 线**。

| 颜色 | 语义（= Pine 原义） | 色号 |
|------|--------------------|------|
| 红 | `close ≥ EMA12 且 ≥ EMA50` 多头强势区 | `#d81e06` |
| 黄 | `close < EMA12 但 ≥ EMA50` 多头回调 | `#e8a33d` |
| 蓝 | `close ≥ EMA12 但 < EMA50` 空头反弹 | `#1565c0` |
| 绿 | `close < EMA12 且 < EMA50` 空头弱势区 | `#12a13f` |

- **K 线实体：实心 = 收阴，空心 = 收阳**（颜色专管「阵营」，涨跌维度不被四色吞掉）。
- **量价层**：量柱与 K 线**同色**；叠加量 MA5（灰虚线，放量/缩量基准）+ 区间均量（灰点线）；文字副图【六】块给出现量比、近 5 根量价配合判断。
- **暖机区**：EMA 无真值，前 **116 根**（EMA50 种子影响 >1%）颜色低置信 → 轻淡化 0.72 + 虚线分隔 + 图例说明；**数据 <116 根时全图重淡化 + 红字【警讯】要求加大取数**。→ 取数 `wantNum` 建议 ≥240（实务 300~400）。
- **侧切换三角**：多空阵营（R/Y ↔ B/G）翻转且**连续 ≥3 根确认**才标记（滤噪），▲ 在下方空白带、▼ 在上方空白带，不压 K 线。
- ⚠️ **展示层纪律**：四色与量价读数是**展示/校验层，不参与 A/B/K 招判定**（颈线/等幅/失败识别仍走纯形态几何）。它只做一件事：与形态方向做**一致性交叉校验**——背离时提示「视为反弹 / 破位需带量」，不自动改判。
- 兼容：`render(..., four_color=False)` 退回原红绿路径；`trend=` 可传入外部（更长历史）算出的 EMA，避免暖机失真。
