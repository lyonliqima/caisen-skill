# 期货团 · 已知错因归因与拦截清单

> **立档：2026-10-21**｜触发事件：工业硅 SI 六周内 4 次偏多判断全部失败 + 台账 98.3% 从未结算
> **性质**：这不是一份「反思文章」，是**可执行的拦截规则**。每一条都必须能在出结论前被机械检查，做不到"是/否"判断的条款一律不写进来。
> **维护纪律**：第三节案例库**只增不删**；第二节闸门可修但每次修改必须写明修改理由与实锤来源。

## 零、这份文件怎么用（三句话）

1. **圆桌开会前**先过第一节（元错误自检）——不通过就别开圆桌，先补数据。
2. **出任何方向结论前**必须过第二节六道闸门——任何一道 ✗ 即降级为「观望·不出方向」。
3. **每次复盘**把新错因按第七节模板追加进第三节——不许只写"下次注意"，必须写成闸门条款。

## 一、元错误：框架在不停出判断，但从不算账

### 1.1 实测数据（2026-10-21，`predictions-ledger/ledger.jsonl`）

| 指标 | 数值 | 含义 |
|---|---|---|
| 台账总条数 | **362** | 框架累计给出的研判 |
| `actual_return` 非空 | **6** | 真正被检验过的只有 6 条 |
| 检验覆盖率 | **1.7%** | **98.3% 的预测从未被验证** |
| `status=open` | 355 | 挂着不动的 |
| 其中已过 `expiry` 仍未结算 | **84** | 逾期率 24%，最早一条 2026-07-31 到期，逾期近 3 个月 |
| 最近 10 条置信度 | 全在 55–75 | 系统自动告警：`该字段可能已退化为噪音，Brier 将失去区分度` |

**校准回路实测**（`predictions-ledger/score.py --calibration`，2026-10-21）：

| 置信度桶 | n | 原命中率 | 说明 |
|---|---|---|---|
| 50–60 | 0 | — | 样本 0 |
| **60–70** | **6** | **17%** | **写了 6 成把握，实际只对 1/6** |
| 70–80 / 80–90 / 90–100 | 0 | — | 样本 0 |

```
Brier = 0.2163   reliab = 0.0913（差→校准有问题）
                 resol  = 0.0139（差→判断本身没区分度，加校准也没用）
                 unc    = 0.1389
```

**两个结论**：
1. **系统性过度自信**：60–70 桶实测命中 17%，是标称值的 1/4。宁可写 60 也不肯写 40，等于把不确定性藏起来。
2. **分辨率 0.0139 = 判断本身缺乏区分度**——这是比过度自信更严重的问题。哪怕把校准做好，一个"对什么品种都写 60"的系统也提供不了信息量。反映在工业硅上就是：4 次偏多，4 次同一套理由。

### 1.2 后果链条（这是所有具体错误的母体）

```
不结算 → 不知道自己准不准
       → 置信度无法校准（写 60 和写 75 没有任何实测差别）
       → 错因无法继承（没人回头看）
       → 同一品种、同一类理由、重复犯同一个错
       → 工业硅 6 周内 4 次偏多全错（2026-09-03 至 10-14）
```

**⚠️ 这条比下面任何一条具体错因都严重。** 具体错因是可以拦的，元错误会让拦截机制本身失效——因为拦截规则也是靠复盘喂出来的。

### 1.3 落地要求（硬性 · 已有现成工具，禁再造轮子）

```bash
# ① 每个交易日开工第一件事：列到期待结算（expiry<=today 且 status=open）
python3 predictions-ledger/score.py --due

# ② 逐条结算（--exit-price 会自动算 actual_return，免手填；miss 必须给错因分类）
python3 predictions-ledger/score.py mark <rec_id> --status miss \
        --exit-price <到期日收盘> --miss-type {direction_wrong|timing_wrong|magnitude_wrong}

# ③ 每月一次校准（PRED 9）+ 专家分项矩阵（PRED 12）
python3 predictions-ledger/score.py --calibration
python3 predictions-ledger/score.py --expert-matrix
```

1. **每日开工先跑 `--due`**，把已过 `expiry` 的记录补算 `actual_return` 与 `status`。当前积压 84 条（最早 2026-07-31 到期）。
2. **同一品种存在逾期未结算记录时，不得给出该品种的新方向判断**——先把上一笔算清楚。
3. **`--miss-type` 必须如实填**：`direction_wrong`（方向判断反了）/ `timing_wrong`（方向对但时点错）/ `magnitude_wrong`（幅度估错）。工业硅 4 连错若如实归因，前 3 条是 `timing_wrong`、P-20260903-002 是 `direction_wrong`——**归因错了，拦截规则就会修错地方**。
4. **每月校准一次**：样本达 30 条后校准回路自动启用；在此之前，把置信度按实测命中率自行下调（60–70 桶实测 17% → 写 65 最多只值 45）。

## 二、六道拦截闸门（工业硅实锤版）

> 用法：每条闸门都必须给出**是/否**判定。不能给判定 = 证据不足 = 视为 ✗。
> 「✗」的处理只有一种：结论降级为「观望·不出方向」，不许"降低置信度后照发"。

### 闸门 1｜破成本 ≠ 买点（A10 成本底四问未过，禁止引用成本支撑）

**工业硅实锤**：新疆完全成本 8626 元/吨（百川盈孚第 40 周），SI2611 收 8415，破线 211 元 → 当时判断"贴近成本可多"。结果：2025 年至今大部分时间价格就在成本线下方运行，**破线不是新信息**。

**四问（全过才可用作多头理由）**：

| 问 | 判据 | 工业硅实况 | 结论 |
|---|---|---|---|
| ① 口径问 | 现金成本还是完全成本？几个源？ | 只有百川一源（完全成本） | ⚠️ 单源 |
| ② 时间问 | 破线已持续多久？期间止跌了吗？ | 2025 年起长期破线，期间未止跌 | ✗ |
| ③ 方向问 | 成本线自己在抬升还是下沉？ | 电价上（枯水期）＋硅煤下（焦煤石油焦回落） | ✗ 双向 |
| ④ 行为问 | 破线后资金增仓加空还是移仓？ | 总持仓减 26%（移仓），非增仓 | ✗ 无主力表态 |

**⛔ 硬规则**：四问里 ②③④ 任一 ✗ → 成本的"托底"功能不予采信，**不得作为建仓理由**，最多写进"下方空间有限"的描述性文字。

---

### 闸门 2｜政策表态 ≠ 需求改善（3 日回吐 70% 判失败）

**工业硅实锤**：2026-10-11 硅料厂闭门会议约定"硅料完全成本不低于 4.3 万元/吨"，10-16 工业硅涨 2.3%（SI2611 收 8720）。随后 10-19 → 8595、10-20 → 8460、10-21 → 8415，**三个交易日跌 3.5%，跌破上涨起点**。

**判据（三条同时满足才算政策有效）**：

1. **可验证的产能动作**：不是"开会约定""协会报送名单"，而是具体的停炉台数/减产量。工业硅侧确实有（合盛东部停炉 6 万吨/月），但**多晶硅减产已执行、库存仍在增加** → 供给收缩跑不过需求收缩。
2. **3 日价格留痕**：消息日涨幅在 3 个交易日内回吐 **>70%** → 判定该消息**已被市场否证**，此后不得再以此为多头理由。
3. **下游接受度**：涨价后下游是否补库？工业硅 10-20 现货"弱稳、不及上周强势、绝对价格下移后下游有点价补货"= 下游只接受低价，不接受涨价。

**⛔ 硬规则**：政策类消息驱动的单日涨幅，**3 个交易日内回吐 >70% → 该理由永久作废（在本轮周期内）**，禁止换一个说法重新包装后再次使用（"反内卷""供给侧改革""收储""行业自律"视为同一类）。

---

### 闸门 3｜先查标的可用性，再谈方向（★本团最大盲区，2026-10-21 新增）

**工业硅实锤**：4 次偏多判断（P-20260903-002 / P-20260911-009 / P-20260929-031 / P-20260929-034）**没有一次检查过合约能不能做**。实况：

| 合约 | 10-20 收盘 | 距自然人最后平仓日 | 流动性 | 可建多？ |
|---|---|---|---|---|
| SI2611 | 8460 | **7 个交易日**（10-30） | 主力级 | ✗ 时间闸门 |
| SI2612 | 8710 | **27 个交易日**（11-30） | 主力级 | ✗ <60 天禁建仓 |
| SI2701 | 8640 | 约 70 天（12-31） | 成交 2.97 万手 | ⚠️ 只减不加 |
| SI2703 | 8595 | 约 120 天 | **成交 23 手** | ✗ 流动性 |
| SI2705 | 8600 | 约 180 天 | **成交 638 手**（主力的 0.6%） | ✗ 流动性 |

→ **同时满足「死线≥90 天」与「流动性够」的合约一个都没有**。也就是说，那 4 次偏多判断在**标的层面就是不可能执行的**，方向对不对根本不重要。

**三问（全过才允许写方向）**：

| 问 | 阈值 | 说明 |
|---|---|---|
| ① 时间闸门 | 距自然人/法人最后平仓日 **≥90 天** | 60–90 天只减不加；<60 天禁止建仓 |
| ② 流动性闸门 | 该合约单日成交 **≥ 主力合约的 5%**，且持仓 ≥2 万手 | 低于此无法进出 |
| ③ 换月成本闸门 | 到下一个可接续合约的年化租 **≤5%** | 工业硅 2611→2612 升水 250 元/月 = **年化 35.5%**（多头年亏 1/3），做多等于逆水行舟 |

**⛔ 硬规则**：**任何期货方向结论必须先写"标的可用性三问"，全过才写方向。** 三问只要有一条 ✗，输出格式改为「方向偏多，但当前无合规可执行合约，不建仓」，**不许跳过标的直接给"可以做多"**。

> 配套正面案例：工业硅结构里唯一的低租段是 2701→2705，换月仅 +15 元/吨（0.17%）——**做多唯一合理的标的是 SI2701 起、滚月至 2705**，不是近月。

### 闸门 4｜同品种 60 天内第 2 次同向，必须先写「上次错在哪」

**工业硅实锤**：2026-09-03 至 10-14，6 周内 4 次偏多，每次理由高度雷同（跌破成本 / 政策反内卷 / 贴底 / 枯水期电费），**从未有一次回写"上一笔为什么错"**。

| 台账ID | 日期 | 方向 | 目标 | 现价(10-21) | 结果 |
|---|---|---|---|---|---|
| P-20260903-002 | 09-03 | 多 | 9000–9300 | 8415 | 差 -6.5% ✗ |
| P-20260911-009 | 09-11 | 中性偏多 | 8500–8800 | 8415 | **证伪位 8500 已被打穿** ✗ |
| P-20260929-031 | 09-29 | 中性偏多 | 8900–9500 | 8585 | 差 -3.5% ✗ |
| P-20260929-034 | 09-29 | 多 | 9200–9600 | 8580 | 差 -6.7% ✗ |
| P-20261014-003 | 10-14 | 中性震荡 | 回踩 8820–8875 | 8635 | **交易层「日收<8800 离场」已触发** ✗ |

**统一错因**：每次都拿「跌破成本 / 政策底线 / 枯水期电费」当买入理由，**没有一次先检查位置与时间闸门**。这是方法层错误，不是运气问题。

**⛔ 硬规则**：同一品种 60 天内第 2 次及以上同向判断，报告必须含「上次错因段落」，至少回答三问：
1. 上次的证伪位是什么？有没有被打穿？
2. 上次错在**方法**（理由本身不成立）、**时点**（理由对但进场太早/太晚）还是**纪律**（没执行止损）？
3. 这次的理由和上次有实质区别吗？如果只是换个说法 → **禁止出同向结论**。

### 闸门 5｜主连换月升水 >2% 时，位置必须用单合约重算（gap≥25pp 判失效）

**工业硅实锤**：同一时点三个口径算出完全相反的"位置"

| 口径 | pos60（近 60 日区间位置） | 读数 |
|---|---|---|
| SI0 主力连续 | **71.7%** | 偏高，最差买点 |
| SI2611 单合约 | 35.4% | 偏低 |
| SI2612 单合约 | **13.5%** | 低位，好买点 |

**gap = 58.2pct >> 25pct → 判位置因子失效。**

**根因**：主力连续在换月时把 SI2611（8 月约 8400–8865）换成 SI2612（8710，升水 250 元 = 2.96%），换月抬升被计入连续序列，制造了虚假的"价格上涨"。且因为升水幅度 2.96% < 3.5% 的常规跳空阈值，**跳空修正算法抓不到**。

**⛔ 硬规则**：
1. 相邻主力合约升水 **>2%** 的品种（工业硅、部分化工品常见），`pos60 / 分位 / 距高点 / 均线偏离` **一律用单合约重算**，连续合约读数只作走势示意。
2. 三口径（连续原始 / 跳空修正 / 单合约）gap **≥25pct → 判位置因子失效**，**不得用"便宜/贵"回答买卖问题**，改用成本线、期限结构、时间闸门、持仓量补位。
3. 报告必须**三列并排**，不许只报一个口径。

### 闸门 6｜席位净多必须除以双边总量（占比<2% 视为无方向性押注）

**工业硅实锤**（2026-10-20，曲合网前 8 名）：

| 指标 | 数值 |
|---|---|
| 前 8 席多单 | 201,906 手 |
| 前 8 席空单 | 195,675 手 |
| 净多 | 6,231 手 |
| **占前 8 双边总量比** | **1.6%** |
| 席位净多市值占总市值比 | **0.58%**（对比 PVC 12.16%、沪金 4.8%） |

**读法**：光看"净多 6231 手"会误判为"多头占优"。除以总量后只有 1.6% / 0.58% —— **大户多空几乎完全对冲，没有任何人愿意下注**。

**⛔ 硬规则**：
1. 席位数据一律**双报**：净持仓手数 + **占双边总量占比**。只报手数的视为无效表述。
2. 占比 **<2% → 判"无方向性押注"，不得作为任何方向的多空证据**（既不能当利好，也不能当利空）。
3. 席位范围（前 8 / 前 20）、品种汇总 / 单合约、手数 / 保证金口径——**三项必须声明**（M-FD 三声明）。广期所、大商所无官方席位通道，WebSearch 转述**证据等级降一级**。

## 四、圆桌发言模板（新增必填字段）

13 位大师每次发言，除「方向 + 置信 + 证据 + 证伪」外，**必须追加一行闸门自检**：

```
闸门自检：1☑/✗ 2☑/✗ 3☑/✗ 4☑/✗ 5☑/✗ 6☑/✗
```

**主理人汇编规则**：
- 任一大师的结论若建立在某个 ✗ 的闸门上 → **该票作废，不计入 13 人计票**，并在「分歧」段落写明作废理由。
- 全体 13 位都用了同一个被否证的理由（如政策利好）→ **不是 13 票共振，是 1 票被复制 13 次**，按 1 票计。
- 闸门 3（标的可用性）为**前置硬闸**：✗ 则整个圆桌输出改为「方向参考·无合规合约」，**不出交易计划**。

## 五、自检口诀（出结论前默念）

> **一算账、二破成本、三看政策留痕、四查合约能不能做、五问上次错在哪、六除席位总量、七单合约重算位置。**

顺序不能乱：**先算账**（不知道上次错哪，这次必错）；**再查合约**（不能做的话方向毫无意义）；**最后才谈方向**。
