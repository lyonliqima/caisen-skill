# 第三方指数核验与官方口径对齐（2026-09-17）

> 触发：遇到第三方自建指数（Domestic Demand Tracker / Activity Proxy / Nowcast 等）与官方序列（GDP / 内需 / 工业）大幅背离、且被用于"官方数据失真"指控时，按本文件五步法独立核验。不直采信、不直否定第三方图。
>
> 本案源：2026-09-17 第三方「China: Real GDP vs Domestic Demand Tracker」图（Shanghai Macro Strategist）以"内需<−5% vs GDP 4–5%"指控官方 GDP 造假。判决：**方向对、推论错、量级不可核**。置信度 70/100。

## 适用范围与证据等级

- 第三方自建指数若未公开**样本框 / 权重 / 加权方式 / 基期 / 季调方式**中任意一项 → 按框架证据制度降为「外部参照（自述 / 未验证）」，**不得作为方向性结论支点、不得用于证伪官方数据**。
- 官方序列（统计局 / 海关总署 / 央行）为 T0，优先采信。

## M-X1 第三方指数独立性核验协议（先问方法论，再判量级）

1. 取数前先索取：样本框、权重、加权方式、发布频率、基期、是否已季调。
2. 四项缺失任意一项 → 该指数只能作方向参照，量级不可核。
3. 本案：Shanghai Macro Strategist「Domestic Demand Tracker」口径 / 权重 / 加权方式均未公开 → −5% 量级不可核，仅作方向参照。图注混入叙事（"Surprise Politburo meeting"）属观点注入而非纯数据标注。

## M-X2 GDP（生产法 / 不变价）vs 内需（支出法）口径对齐换算

- GDP 实际增长 = 不变价增加值同比（生产法为主，含净出口与存货变动）。
- "内需" = 支出法最终消费 + 资本形成（不含净出口）。
- 名义↔实际换算：实际 ≈ 名义 − 平减指数（或逐项用 CPI / PPI 平减）。例：社零名义 +0.4% − CPI +0.8% ≈ 实际 −0.4%。
- 背离的"合法"来源：① 口径不同（生产法 vs 支出法）；② 净出口拉动（外需不计入内需）；③ 存货变动计入增加值但不计入最终需求。

## M-X3 存货机制对 GDP-内需背离的解释

- 机制：供强需弱时，未售出产出以存货增加计入资本形成 / 增加值，使生产法 GDP 高于当期最终需求。
- 触发条件：工业营收正、产销率下行、产成品存货上行。
- 本案：未取到存货分项 → 标注「未验证」，但机制成立，列为四解释之一。

## M-X4 PPI 成本推动 vs 需求拉动判别（框架 M-D3 关联）

- 判据：生产资料强 + 生活资料弱 + 购进价 > 出厂价 → 成本推动（输入型 / 上游供给冲击），**非需求拉动**。
- 本案：PPI +3.8%（生产资料 +5.0%、采掘 +17.8%；生活资料 −0.5%、食品 −2.3%）；购进 +5.8% > 出厂 +3.8%（剪刀差 −2.0pp）→ 成本推动坐实。
- 反用禁令：不得将成本推动型 PPI 上行当作「内需改善 / 再通胀」证据（见陷阱库 ㉘）。

## M-X5 红队镜像自抽检查（用危机基准评估非危机指数）

- 规则：主分析若用 A 基准否定 B 指数量级，而主分析前文正批评"用 A 口径评 B 是混标"，则该否定无效且须自查镜像错误。
- 本案：主分析用"低于 2022 上海封城、接近 2020 首波"贬低 −5% = 用 GDP 危机基准评估需求指数 = 口径混标镜像自抽，红队 −10 采纳。

## 核验结论锚（本案，置信度 70 / 100）

- **方向对**：内需确实弱（官方亦承认"供强需弱矛盾突出"），且居民端 / 民间投资实际收缩。
- **推论错**：GDP 与内需背离可由四机制（口径 / 外需托底 / AI 算力增量 / 存货）解释，无需造假假设。
- **量级不可核**：第三方指数口径未公开，−5% 只能作方向参照。
- **修正判断（三速结构）**：上游通胀（采掘 +17.8%） + 出口 / AI 算力独强（出口 +18.6%、机电 +21.9%、集成电路利润 +18.5 倍、高技术制造 +50.1%） + 居民端与民间投资实际收缩（社零实际 −0.4%、限额以上 −3.7%、民间投资 −10.1%、地产 −19.9%）。
- 关联陷阱库：㉗（GDP 与内需背离 ≠ 造假）、㉘（成本推动冒充需求改善 + 危机基准评估非危机指数）。
