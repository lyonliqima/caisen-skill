# 杨世光宏观·增长质量与情绪反指双工具（M91–M92）

> **来源**：杨世光《今年报》2026-10-13 期录音整理稿（ASR 文本）。逐字稿解读与事实核查见 `examples-1013.md`。
> **性质**：这是**研究方法**，不是观点集合。节目里的方向性判断（「记忆体价格不涨=EPS增速断」「散户与法人对赌」等）是历史时点的例子，**不可**当当前结论复用。
> **定位**：M91 补「增长质量」读数件——与既有 M-增量拐点识别（二阶导）衔接：二阶导管「增量还在不在」，M91 管「增量由什么构成、还能活多久」；M92 补「情绪计分板」反指件——与 M34/M53 等情绪类工具互补，专管**期权极端读数的反向用法**。
> **顺序**：判定一个行业/指数的 EPS 增速可持续性，先跑 M91（拆增量）再谈 G 因子；判读期权情绪，先跑 M92 三件套再谈反指。

## M91：增量量价拆账法

> **高增长不等于好增长——增量由「价」驱动的部分，自带天花板和断点。**
> 节目核心句：「只要记忆体价格明年涨不动，明年 EPS 的增速就会急剧放缓——不是不赚钱，是非常赚，重点是没有增速。」

### 核心原理

```
行业营收增量 = Σ(各品类增量)
品类增量     = 量贡献（Δ量 × 基期价） + 价贡献（Δ价 × 本期量）

价贡献占比 → 决定增速的「性质」：
  量驱动   = 需求扩张型，可持续性看需求曲线
  价驱动   = 稀缺涨价型，可持续性看供给周期；价格见顶 = G 因子断点
  价驱动且占比 > 70% = 「涨价市」，必须给增速标「保质期」
```

**为什么价驱动致命**：单价暴涨直接转化为毛利（几乎零边际成本传导），但当期价格数据永远滞后于市场定价——市场定价的是**明年的价格增速**。所以价驱动型行情的估值顶出现在价格顶之前，股价领先现货/合约价下跌是常态而非背离。

### 拆解步骤（五步）

1. **总量增量**：本期营收 − 上期同期（如 2026 年 1-8 月全球半导体 1.043 兆 vs 去年同期 4770 亿，+119%，增量 5661 亿）。
2. **分品类归因**：增量中谁贡献几成（记忆体 4330 亿 ≈ 八成、逻辑晶片约 1080 亿、其余忽略）。
3. **主品类再拆量价**：记忆体增量中量贡献 640 亿、价贡献 3790 亿（**价占 85%**）；逻辑晶片量 370 亿、价 710 亿。
4. **判定性质**：价贡献 >70% = 涨价市 → 写明「价格见顶 = 增速断点」，并回答「价格需要涨到多少才能维持当前增速」（节目口径：HBM4 合约价 30 美元/GB 以上才撑得住）。
5. **压力测试**：假设价格持平，重算增速剩余 → 这个「剩余增速」才是估值该给的锚。

### 实战联动（三件套）

| 件 | 管 | 工具 |
|---|---|---|
| M91 拆增量 | 增速的质量与保质期 | 本工具 |
| 二阶导 | 增量还在不在（拐点） | M-增量拐点识别 |
| M86 价差裁决 | 当期价格的真实性（现货 vs 纸货） | 期现货价差裁决法 |

### ⚠️ 使用纪律

- 节目引用的拆账原始报告未独立核实到出处（⚠️），**方法论可用，具体数字引用前必须重查**。
- 「现货还在涨」**不得**用来反驳股价下跌——那是 M91 第 4 步就该写明的领先定价，不是市场错。
- 与 M86 分工：M86 鉴别当期价格真假（短缺 vs 事件溢价），M91 判定价格增速还能撑多久。先 M86 后 M91。

## M92：卖权买权比反指判读法

> **P/C ratio 的极端值是情绪计分板，实务反着用。**
> 节目核心句：「当 P/C ratio 低于 90% 甚至 80%，是市场上极度看空……但怕反弹怎么办？也不会买现货、也不会补期货，买一点 put 聊胜于无——这个买 put 的动作，把底牌亮出来了。」

### 核心原理

```
P/C ratio = 卖权成交(或持仓) ÷ 买权成交

> 100–110%（卖权 > 买权）：法人期现货做多 + 买 put 避险（buy-side 逻辑）
  → 怕的是拉回不是崩盘 → 多数时候反而是涨的
< 90%，尤其 < 80%：现货卖超 + 期货空单 + 买 put 防回马枪
  → 极度看空，但「怕反弹」的结构性对冲暴露了空方软肋
```

### 判读三件套（缺一不可）

| 件 | 本期读数（2026-10-13 台股） | 历史分位 |
|---|---|---|
| 现货单日卖超 | 1653 亿 | 史上第三大 |
| 期货净空单 | 87,329 口 | 史上第七大，距纪录（8/3 的 90,038 口）仅 2800 口 |
| P/C ratio | 68.95% | 两年半新低 |

三者**同向极端** = 情绪计分板顶格，反指意义最强；只有 P/C 单项极端 = 信号，不构成判定。

### ⚠️ 使用纪律

1. **反指管的是「不追空」，不是「立即抄底」**。极端可以更极端（净空单距纪录只差 2800 口，再跌就可能破纪录）——左侧入场仍须等价格企稳或其他证据确认，M92 只否决「顺势加空」的性价比。
2. 区分对冲性 put 与投机性 put：法人买 put 是暴露软肋，散户追 put 才是同向信号。有条件时看大额 OTM put 的买家结构。
3. 与 M53（K 型分化）、M89（政治传导）分工：M92 是**日内/周度情绪刻度**，不承载中期方向判断。
