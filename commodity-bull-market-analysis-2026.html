🔵 第2步-①：杨世光宏观六步法分析

M1 经济周期定位：过热期→滞胀过渡期

当前美国经济呈现典型的过热→滞胀过渡特征：

  • GDP增速仍为正值但放缓
  • 通胀因油价冲击（霍尔木兹海峡关闭）重新升温
  • Fed维持高利率3.50-3.75%，信号可能加息
  • 美林时钟定位：过热期末段/滞胀期入口 → 大宗商品理论上是过热期的最优资产

商品利好 过热期利好商品，但若进入滞胀则转为现金为王

M2 货币政策：鹰派维持，加息风险上升

Fed在Warsh时代维持3.50-3.75%，但6月会议9位官员预期年内加息：

  • 实际利率 = 名义利率3.625% - 通胀预期~3.1% ≈ +0.5%（正值，对黄金不利但黄金仍在$4000+）
  • 黄金-实质利率相关性已回归正常（R²=0.56） → 实际利率上升确实压制金价
  • 但若Fed被迫加息应对油价通胀 → 经济衰退风险上升 → 最终转向降息 → 商品受益

短空长多 短期加息预期压制商品，但加息引发衰退后反而利好商品

M3 美元周期：短期强势，中期转弱临界点

DXY 99.7，已跌破100关口。但美元近期反弹的三条支撑线均依附于短期叙事：

  • 定向避险需求（中东紧张 → 美元避险）→ 一旦和谈突破，美元回落
  • 利差预期（Fed可能加息）→ "嘴炮加息"极脆弱，数据一松即崩
  • 石油结算需求（霍尔木兹关闭 → 买美油用美元）→ 通航恢复即消失

中期利好商品 三条支撑线均为叙事驱动，一旦叙事破裂 → 美元转弱 → 商品全面受益

M6 地缘政治传导：霍尔木兹海峡是核心变量

伊朗冲突已持续115天（2/28→6/21），霍尔木兹海峡6/18部分重开但通行仍缓慢：

  • 若和谈破裂 → 海峡再次关闭 → 油价暴涨 → 通胀飙升 → 滞胀 → 商品分化
  • 若和谈成功 → 油价暴跌 → 通胀降温 → Fed转鸽 → 美元走弱 → 贵金属+工业金属受益
  • 以色列为最大变数（独立于美伊协议之外）

🟢 核心结论一：大宗商品正在经历"分化型牛市"，而非全面超级周期

当前商品市场不是2000年代那种所有品种同涨的全面超级周期，而是三条独立牛市线并行：

  1. 贵金属结构性牛市（黄金、白银）— 驱动力：去美元化+央行购金+财政危机对冲。黄金已从$2000涨至$5602 ATH，回调26%至$4153属于健康整理。牛市确认
  2. 能源转型金属牛市（铜、铀、铝）— 驱动力：AI数据中心+电动车+电网升级的结构性需求爆发 + 矿山10-15年开发周期的供给刚性。牛市确认
  3. 能源商品地缘博弈（原油、天然气）— 驱动力：霍尔木兹海峡开关效应。这不是趋势性牛市，而是事件驱动型高波动。非牛市

时间节点判断：

  • 贵金属牛市：2024年启动，预计持续至2027-2028年（类似2000s贵金属10年牛市的前半段）
  • 铜/能源金属牛市：2025年启动，可能持续至2030年+（供应缺口在2029年扩大至110万吨）
  • 原油：无趋势性牛市，2026年$65-95区间震荡
  • 农产品：无牛市，库存充裕压制价格

🔴 什么情况下牛市不会出现（风险因素）

  1. Fed激进加息至4.5%+：实际利率飙升 → 黄金跌破$3500 → 商品全面承压（概率20%）
  2. 全球经济深度衰退：需求崩塌 → 铜/油暴跌（但黄金反因避险上涨）（概率15%）
  3. 美伊全面和平协议+伊朗产能恢复：油价跌至$55 → 拉低整体商品指数（概率10%）
  4. 中国经济硬着陆：铜/铁矿石需求崩塌（概率5%）
  5. AI泡沫破裂：数据中心投资骤降 → 铜/铝需求预期逆转（概率10%）
