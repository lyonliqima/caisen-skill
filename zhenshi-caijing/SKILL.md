# 真实财经 · 中国金融数据解剖分析法（蔡森框架第 16 席）

> **核心定位**：这是一套**解剖法**（怎么把央行报表拆开、怎么读出官方通稿没写的那一层），
> 配套一份**带时间衰减的观点档案**（原文那些锋利判断，会过期，按档案里的参考度表用）。
>
> **一句话边界**：别人告诉你「钱松不松」，真实财经告诉你「**钱从哪出、经过谁、卡在哪一段**」。

---

## 🔺 双模块调用律（最重要的一条 · 分析时必须同时调用）

> **调用本席 = `references/`（研究方法）+ `examples-*.md`（观点档案）两份同读。**
> **只读其一 = 未完成调用。** 这条是硬性要求，理由：

| 只读研究方法 | 只读观点档案 |
|---|---|
| 得到一堆「该怎么看」的步骤，却没有该专家**实际敢下的判断**，退化为通用读数模板 | 拿到一堆过期数值和情绪化判断，不知道是怎么推出来的 → **违反「学步骤不抄结论」**，且会被 🕵️检查者当外部结论剔除 |

**正确姿势**：`ref_weight.py` 定参考度 → 读 `references/` 拿解剖工具 → 读 `examples-*.md` 拿该专家的判断作为**待验证假说** → **用当期一手数据把 Z1–Z13 重新跑一遍**，跑出来的才是本框架的结论。

## 🚀 调用流程（三步，不能跳步）

### 第 1 步：先定参考度（强制 · 开始前必跑）

**任何引用本库之前**，先问一句「这份资料现在还能不能用」：

```bash

$P "$CAI/ref_weight.py" check --require-fresh                  # 阻断级闸机（落后太久 exit 2）
```

**三层参考度模型**（这是用户 2026-10-17 定的规则，机器化版）：

| 层 | 装什么 | 衰减 | 地板 |
|---|---|---|---|
| **method 方法论层** | Z1–Z13 解剖步骤、判据、检查清单 | **不衰减** | 100% |
| **structure 结构读数层** | 份额迁移、传导断点、主体分化 | 走主表 | **60%** |
| **event 事件数值层** | 具体数字（M2 多少万亿）、方向性判断 | 走主表 | 0（可判 EXPIRED） |

主衰减刻度与框架第 4 步严格对齐：`≤7天 100 · ≤30天 80 · ≤90天 60 · ≤180天 40 · ≤365天 20 · >730天 10（仅留痕）`

**红线**：**事件层参考度 < 60%，该条里的具体数值禁止作为当期判断的数值支点**，只能入历史留痕；< 40% 一律标 ❌。同一条规矩适用于**分析时搜到的任何一条新闻**——拿捏不准就 `--eval --date <它的发布日>`。

### 第 2 步：读研究方法（references/）

先看 **`references/01-z1-z13-financial-data-anatomy-20261017.md`**，13 个模块按组外卖：

| 组 | 模块 | 干什么 |
|---|---|---|
| **A 读数骨架** | Z1 需求→供给→落点三段式 / Z2 存量 vs 增量双镜（含份额镜像） / **Z3 默契数识别（同一笔钱换马甲）** | 拿到报表先看哪、顺序是什么 |
| **B 科目解剖** | **Z4 放款主体定性（小科目金丝雀）** / Z5 未披露项残差倒减法 / **Z6 财政传导四段水道追踪** | 把科目拆到有钱有主体的层面 |
| **C 时间轴手术** | **Z7 半年报差分法** / Z8 单季拆伙 / Z9 三年纵列 + 拐点年 | 累计值掩盖的东西全在这里显形 |
| **D 结构判定** | Z10 M1/M2/M0 三元勾稽 / Z11 期限结构与票据冲量 / Z12 季节性利好失效检验 | 读出「钱到底在干什么」 |
| **E 反叙事** | **Z13 同源数据双叙事拆解** | 防止把官方通稿的表述当成自己的结论 |

> 🔴 **Z5 高危提醒**：残差法得出的数（如机关团体存款）是**推算值不是官方数**，一律标 T3，禁止作结论支点。这是本库最容易被误用的一处。

### 第 3 步：读观点档案（examples-*.md）

档案里每条观点都带 **权重衰减表 + 推导链条 + 原话 + 后续追踪**。**一律按「外部观点·待验证」引用**，不得写成框架自己的结论。

## 🎯 触发条件（命中任一则调度第 16 席）

- 用户问到**中国宏观金融数据**：社融、信贷、M0/M1/M2、剪刀差、存款、贷款结构、票据融资
- 涉及**财政政策传导效果**：专项债、化债、基建资金到位率、「钱有没有变成实物工作量」
- 涉及**居民/企业部门行为**：提前还款、存款定期化、消费贷、储蓄率、现金流
- 涉及**政府债务/城投/企业债**的中国国内数据解读
- 涉及**物价数据的传导解剖**：CPI/PPI 结构劈叉（生产资料 vs 生活资料）、产业链价格传导断点、核心 CPI 成色检验（2026-10-17 起扩入，见 examples 第二篇观点十一至十六）
- 需要**判定官方金融数据与实际情况的差距**时
- 明确说「用真实财经 / 真实财经怎么看 / 按第16席」

**不触发**：美股 / 加密货币 / 纯商品期货技术面 / 公司个体财报（那些留给笨鸟 M68–M74、蔡森、Mi姐）。

## 📋 输出规范（复杂输出 · 六段式，缺一不可）

> 用户要求本席走**复杂输出**——不能只给一句「信贷需求弱」。

1. **参考度声明**（机读一行，固定格式，不许改写成散文）
   ```
   真实财经参考度：归档日=2026-10-17 · 距数据发布=3天 · 方法层=100% · 结构层=100% · 事件层=100% → 事件数值可作当期读数
   ```
2. **解剖读数表**：科目 × 存量 × 增量 × 同比变化 × **口径**（月度/累计/推算必标）
3. **至少 3 条解剖发现**，每条必须**点名用的是哪个 Z 模块**（不点名 = 没用方法）
4. **财政四段水道图**（文本版）：政府债 → 财政存款 → 机关团体 → 企业存款，逐段标 ✅/❌ 与断点归因
5. **双叙事对照表**（Z13）：官方/专家原话 ↔ 本文读数，并列出**本文的遗漏项**（必须补！）
6. **反共识标记 + 证伪位**：本席哪些判断与市场共识相反、什么信号出现则失效

- **数据是别人的没关系，结论必须是自己的。** 本席提供的数据来自央行公开报表（T0），**引用其剖析动作，不继承其语气与结论**。

- **强制**:引用本席方向性判断前，必须先补上 `references/01-*.md` 第十三节列的 **4 项遗漏读数**（贷款利率历史低位、结构性贷款高增、外币贷款多增、单月社融环比回升）。**只引本席会系统性把经济读得比实际更差。**
