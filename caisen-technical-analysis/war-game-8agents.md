# 八兵棋推演体系（多Agent交叉验证）

> 来源：炒股 app PRD "全维度多 Agent 兵棋推演"模块
> 定位：与四专家整合分析互补的实战推演框架，侧重个股决策

---

## 核心理念

将多位专家视角拆解为 8 个独立 Agent，按固定顺序发言，交叉验证后由总指挥汇总决策。

与四专家整合分析的区别：
- **四专家**：宏观→制度→技术→数据，偏宏观/大类资产
- **八兵棋**：政治→经济→军事→周期→舆论→资金→技术→指挥，偏个股实战

---

## 8 大 Agent 职责

### 1️⃣ 政治与地缘 Agent

**核心职责**：分析政策、地缘冲突、贸易摩擦对该股票的影响

**输出格式**：
```
利多/利空判断：利多/利空/中性
影响等级：低/中/高
具体影响逻辑：
  - 政策面：XXX
  - 地缘风险：XXX
  - 贸易摩擦：XXX
```

### 2️⃣ 宏观经济 Agent

**核心职责**：分析利率、通胀、GDP、货币政策对行业和个股的影响

**输出格式**：
```
大盘环境判断：牛市/震荡/熊市
经济周期位置：复苏/过热/滞胀/衰退
对行业影响：
  - 利率敏感度：高/中/低
  - 通胀敏感度：高/中/低
  - 政策受益/受损：XXX
```

### 3️⃣ 军事与安全 Agent

**核心职责**：分析地区冲突、能源供应风险对相关板块的影响

**输出格式**：
```
相关板块影响：
  - 军工板块：利好/利空/无关
  - 能源板块：利好/利空/无关
  - 科技供应链：影响程度
风险传导路径：XXX → XXX → XXX
```

### 4️⃣ 大周期研判 Agent

**核心职责**：分析康波周期、美林时钟、牛熊级别大趋势

**输出格式**：
```
当前周期阶段：XXX
康波位置：复苏/繁荣/衰退/萧条
美林时钟：股票/债券/商品/现金
操作策略建议：追涨/低吸/空仓/防守
```

### 5️⃣ 舆论与市场情绪 Agent

**核心职责**：分析舆情、恐慌贪婪指数、散户/主力行为

**输出格式**：
```
情绪状态：过热/恐慌/中性/乐观
恐慌贪婪指数：0-100
散户行为判断：追高/抄底/观望/恐慌卖出
主力行为判断：吸筹/出货/拉升/洗盘
```

### 6️⃣ 资金与机构行为 Agent

**核心职责**：分析北向资金、龙虎榜、筹码分布、机构持仓

**输出格式**：
```
资金流向：流入/流出/平衡
  - 北向资金：XXX亿（方向）
  - 龙虎榜：机构买入/卖出 XXX
  - 融资融券：增加/减少
机构持仓变化：增持/减持/不变
筹码集中程度：集中/分散/正在集中
```

### 7️⃣ 技术形态 Agent

**核心职责**：验证蔡森形态、买点可靠性、技术面评分

**输出格式**：
```
当前形态：XXX（底部/头部/中继）
形态匹配度：0-100分
颈线位置：XXX
买点成立与否：成立/不成立/待确认
技术面评分：0-100
  - 量价配合：X/25
  - 多周期共振：X/25
  - 形态清晰度：X/25
  - 突破/跌破确认：X/25
```

### 8️⃣ 兵棋总指挥 Agent

**核心职责**：汇总前 7 位 Agent 观点，量化加权评分，交叉验证分歧，给出最终决策

**输出格式**：
```
【综合评分】0-100分（加权计算，见下方公式）
【置信区间】评分 ± 5（基于专家分歧度调整）
【仓位建议】0%-100%（评分→仓位映射表）
【操作方向】做多/做空/观望
【进场价】XXX
【止盈价】XXX（基于测幅满足）
【止损价】XXX（基于形态失败点）
【推演结论】
  - 宏观环境：利多 X 票 / 利空 X 票 / 中性 X 票
  - 专家分歧度：高/中/低（分歧越大置信区间越宽）
  - 最大风险点：XXX
  - 最大机会点：XXX
  - 建议持有周期：XXX
【风险提示】XXX
【历史对标】XXX（相似形态/相似宏观环境的历史案例命中率）
```

#### 综合评分公式（加权打分法）

每个分析 Agent 输出 0-100 分的子分 + 方向（利多/利空/中性），总指挥按权重加权汇总：

```
综合评分 = Σ（Agent子分 × Agent权重 × 方向系数）

方向系数：
  利多 = +1
  中性 =  0（该 Agent 不计入方向分，仅作为环境背景）
  利空 = -1

各 Agent 权重表（个股实战导向，可按标的类型微调）：
┌─────────────────────┬────────┬──────────────────────────────────┐
│ Agent                 │ 权重     │ 说明                                 │
├─────────────────────┼────────┼──────────────────────────────────┤
│ 7-技术形态            │ 30%    │ 蔡森体系核心，形态决定买卖点             │
│ 6-资金与机构行为      │ 20%    │ 主力资金是直接推动力                   │
│ 2-宏观经济            │ 15%    │ 决定行业β                            │
│ 5-舆论与市场情绪      │ 10%    │ 情绪是短线催化                        │
│ 4-大周期研判          │ 10%    │ 决定持仓周期与仓位上限                 │
│ 1-政治与地缘          │  8%    │ 个股层面影响有限（军工/资源股除外）       │
│ 3-军事与安全          │  7%    │ 仅特定板块（军工/能源/供应链）相关       │
└─────────────────────┴────────┴──────────────────────────────────┘

权重调整规则：
  - 军工/能源股：1号政治地缘 +3号军事安全 权重上调至 15%+12%，7号技术下调至 25%
  - 周期股（有色/煤炭/化工）：4号大周期上调至 18%，2号宏观上调至 18%
  - 题材股（AI/机器人/低空）：5号舆论情绪上调至 18%，6号资金上调至 22%
  - 蓝筹白马：2号宏观上调至 20%，6号资金上调至 22%

综合评分计算示例：
  技术形态Agent：85分 利多 → 85 × 30% × (+1) = +25.5
  资金Agent    ：70分 利多 → 70 × 20% × (+1) = +14.0
  宏观Agent    ：40分 利空 → 40 × 15% × (-1) =  -6.0
  舆论Agent    ：60分 中性 → 60 × 10% × ( 0) =  0.0
  周期Agent    ：55分 中性 → 55 × 10% × ( 0) =  0.0
  政治Agent    ：50分 中性 → 50 ×  8% × ( 0) =  0.0
  军事Agent    ：50分 中性 → 50 ×  7% × ( 0) =  0.0
  ─────────────────────────────────────────────
  综合评分 = 25.5 + 14.0 - 6.0 = +33.5

  # 归一化到 0-100（50为中性）：
  归一化评分 = 50 + (综合评分 × 50 / 最大可能分)
  最大可能分 = Σ(100 × 权重) = 100（当所有非中性Agent都满分利多时）
  归一化评分 = 50 + (33.5 × 0.5) = 66.75 ≈ 67分
```

#### 评分→仓位映射表

```
┌──────────────┬─────────────┬──────────────────────┐
│ 归一化评分      │ 操作方向       │ 建议仓位                  │
├──────────────┼─────────────┼──────────────────────┤
│ ≥ 80          │ 坚定做多      │ 80%-100%（满仓）        │
│ 70-79         │ 偏多          │ 50%-70%                 │
│ 60-69         │ 谨慎做多      │ 30%-50%                 │
│ 50-59         │ 观望          │ 0%-20%（轻仓试探）       │
│ 40-49         │ 谨慎做空      │ 30%-50%空头            │
│ 30-39         │ 偏空          │ 50%-70%空头            │
│ ≤ 29          │ 坚定做空      │ 80%-100%空头           │
└──────────────┴─────────────┴──────────────────────┘

仓位上限修正（结合 M11 停损纪律）：
  - 单笔最大风险 = 总资金的 2%-5%（止损幅度 × 仓位 ≤ 5%）
  - 实际仓位 = min(评分映射仓位, 5% / 止损幅度)
  - 示例：止损幅度 8%，则 5% / 8% = 62.5% → 即使评分≥80，仓位上限 62.5%
```

#### 置信区间（基于分歧度）

```
分歧度 = 方向为利多的Agent数 与 方向为利空的Agent数 之差的绝对值占非中性Agent数的比例

  分歧度 = |利多票数 - 利空票数| / max(利多票数 + 利空票数, 1)

置信区间调整：
  - 分歧度 < 0.3（高度分歧）→ 评分 ± 8（不确定性高，区间加宽）
  - 分歧度 0.3-0.6（中度分歧）→ 评分 ± 5
  - 分歧度 > 0.6（方向一致）→ 评分 ± 3（确定性高，区间收窄）

决策门槛：
  - 评分 ≥ 65 且置信下限 ≥ 60 → 执行做多
  - 评分 ≤ 35 且置信上限 ≤ 40 → 执行做空
  - 否则 → 观望（分歧过大或评分中性）
```

## 推演流程

```
第1步：输入目标股票 + 推演周期（1-7天）
第2步：技术形态Agent 先行（调用量化工具输出客观数据，见"工具联动"章节）
第3步：政治Agent → 宏观Agent → 军事Agent → 大周期Agent → 舆论Agent → 资金Agent 依次发言
       （每位Agent发言时必须对前序Agent的观点标注"认同/分歧/中立"）
第4步：交叉质询环节（见"交叉验证机制"章节）
       - 总指挥列出所有分歧点
       - 相关Agent二次发言澄清
       - 标记"不可调和分歧"vs"可调和分歧"
第5步：总指挥量化汇总（加权评分 + 分歧度置信区间，见总指挥Agent章节）
第6步：输出推演报告（含评分、置信区间、仓位、历史对标）
第7步：生成操作计划（关联自选股 + 停损纪律）
第8步：归档到历史推演库（用于后续回测命中率，见"预测准确度机制"章节）
```

## 使用建议

**适用场景**：
- 个股深度分析（不是宏观/大类资产）
- 需要综合多维度信息做买卖决策
- 验证蔡森技术形态与基本面是否共振

**不适用场景**：
- 宏观市场判断（用四专家整合分析）
- 大类资产配置（用四专家整合分析）
- 纯技术面交易（直接用蔡森体系）

## 交叉验证机制

> 单专家可能盲人摸象，多专家交叉验证才能逼近真相。核心是让分歧显性化、可追溯。

### 三层交叉验证

```
Layer 1：发言时标注（自动）
  每位Agent发言末尾必须输出"对前序观点的态度"：
  ┌──────────────────────────────────────────┐
  │ 认同：XXX（引用前序Agent的某观点）          │
  │ 分歧：XXX（指出与前序Agent哪里矛盾）         │
  │ 中立：无直接关联                            │
  └──────────────────────────────────────────┘

Layer 2：交叉质询环节（第4步）
  总指挥汇总所有"分歧"标记，逐条要求相关Agent二次发言：
  - 分歧点1：技术Agent说破底翻成立，但资金Agent说主力在出货
    → 技术Agent二次发言：放量情况如何？是否主力假出货真吸筹？
    → 资金Agent二次发言：龙虎榜机构净买入还是净卖出？
    → 总指挥裁决：标记为"可调和分歧"（技术看形态，资金看短期，可能主力洗盘末段）

  - 分歧点2：宏观Agent说利率上行利空，但周期Agent说康波复苏期利多
    → 标记为"不可调和分歧"（时间尺度不同：短期利空vs长期利多）
    → 总指挥处理：短期权重给宏观，长期权重给周期，分别标注

Layer 3：一致性矩阵（可视化）
  ┌─────────────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
  │             │ 政治  │ 宏观  │ 军事  │ 周期  │ 舆论  │ 资金  │ 技术  │
  ├─────────────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
  │ 政治         │  -   │ 认同  │ 分歧  │ 中立  │ 中立  │ 中立  │ 中立  │
  │ 宏观         │ 认同  │  -   │ 认同  │ 分歧  │ 中立  │ 认同  │ 中立  │
  │ ...         │      │      │      │      │      │      │      │
  └─────────────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
  分歧数 > 5 → 高分歧 → 置信区间 ±8
  分歧数 3-5 → 中分歧 → 置信区间 ±5
  分歧数 < 3 → 低分歧 → 置信区间 ±3
```

### 分歧处理规则

```
可调和分歧：
  - 本质是同一事实的不同视角（如技术看多+资金短期看空）
  - 处理：以权重更高的Agent为准，但下调置信度
  - 示例：技术(30%)看多 vs 资金(20%)看空 → 偏多，但置信区间+5

不可调和分歧：
  - 时间尺度或逻辑框架根本不同（如短期利空vs长期利多）
  - 处理：分场景输出两套结论
  - 示例：
    · 短线（1-3天）：偏空，仓位≤30%
    · 中线（1-4周）：偏多，仓位50-70%
  - 总指挥明确标注"时间尺度分歧"，让用户自选

致命分歧：
  - 技术形态看多但基本面（财务造假/退市风险）看空
  - 处理：一票否决，直接观望
  - 任何"致命风险"标记 → 综合评分强制 ≤ 40（不可做多）
```

### 共振加分机制

```
当多个Agent独立得出同方向结论（非跟风式认同）时，加分：

3个以上Agent独立利多 → 综合评分 +5（共振奖励）
5个以上Agent独立利多 → 综合评分 +10（强共振）
全部7个Agent利多      → 综合评分 +15（满共振，罕见）

"独立"判定标准：
  - 该Agent的工具数据支持该方向
  - 且该Agent的推理逻辑与前序Agent不同
  - 跟风式认同（"我同意上一位"）不算独立
```

## 预测准确度机制

> 没有回测的预测都是空谈。通过历史对标 + 归档回测 + 置信度校准，持续提升准确度。

### 历史对标（单次推演时）

总指挥在输出结论前，查找相似历史案例的命中率：

```
历史对标维度（找最近10个相似案例）：
  1. 形态相似：相同形态（如破底翻）+ 相近信心度（±5）
  2. 宏观相似：相同经济周期位置（复苏/过热/滞胀/衰退）
  3. 资金相似：相同资金流向（流入/流出）

输出：
  【历史对标】
  - 相似案例数：X 个
  - 历史命中率：X%（X/X 达到第一目标价）
  - 平均涨幅：+X.X%（达到目标价案例）/ -X.X%（失败案例）
  - 典型失败原因：XXX（如"宏观利空覆盖技术形态"）
  - 本次与历史的差异点：XXX
```

### 推演归档库（持续积累）

```
每次推演完成后归档：
  output/wargame_archive/
  └── YYYYMMDD_股票代码/
      ├── 推演报告.md（含7位Agent发言+总指挥结论）
      ├── 评分快照.json（综合评分/子分/分歧度/置信区间）
      ├── 操作计划.json（进场价/止损/目标/仓位）
      └── 后续跟踪.md（T+1/T+3/T+7/T+30 实际走势回填）

后续跟踪字段：
  - T+1 收盘价 / 是否触发止损 / 是否达到第一目标
  - T+3 收盘价 / 形态是否破坏
  - T+7 收盘价 / 是否达到测幅满足
  - T+30 收盘价 / 最终盈亏
  - 结论：✅成功 / ❌失败 / ⏳待定
  - 失败原因归类：技术形态误判 / 宏观突变 / 资金反转 / 黑天鹅
```

### 季度回测与权重校准

```
每季度执行一次回测：
  1. 统计过去3个月所有归档推演的命中率
  2. 按Agent拆分：哪个Agent的子分与最终结果相关性最高？
  3. 权重校准：
     - 命中率高的Agent → 权重上调 2-3%
     - 命中率低的Agent → 权重下调 2-3%
     - 总权重保持 100%
  4. 信心度校准：
     - 统计各信心度区间的实际命中率
     - 若 信心度70-75 的实际命中率只有 50% → 信心度算法高估，下调加分
     - 若 信心度80-85 的实际命中率有 90% → 算法合理
  5. 输出《季度回测报告》更新权重表

回测门槛：
  - 样本量 ≥ 20 次才有统计意义
  - 低于 20 次时权重保持默认，仅记录
```

### 预测准确度提升路径

```
准确度 = 命中次数 / 总推演次数（达到第一目标价 = 命中）

短期提升（立即可做）：
  ✅ 技术形态Agent强制调用工具（消除主观偏差）
  ✅ 交叉验证机制（减少单一专家盲点）
  ✅ 致命分歧一票否决（规避致命风险）

中期提升（1-3个月）：
  📈 积累20+次归档推演
  📈 建立历史对标数据库
  📈 校准信心度算法参数

长期提升（季度迭代）：
  🎯 权重动态校准（让历史表现好的Agent话语权更大）
  🎯 形态识别算法优化（结合命中/失败案例修正阈值）
  🎯 分歧度→置信区间映射校准
```
