## Z29 外部推演逐条裁决三分法

**一句话**：**不许对一整段推演整体判「对 / 错」**。先拆成主张清单，每条分「事实层 / 归因层 / 外推层」分别核验，再按三分法裁决；**现象对 ≠ 机制对，机制对 ≠ 结论对**。

### 操作步骤（缺一步不准下总判定）

1. **抄原话**：把对方表述逐条抄进表，保留原意、不改写、不替对方补逻辑。这一步防止把自己的推论写成对方的结论（Z13）。
2. **拆主张**：一段话常含 5–8 条独立主张，逐条编号。复合句拆开（「A 导致 B，所以该做 C」= 三条）。
3. **分三层核验**：
   - **事实层**：数字、时点、主体、法条是否成立（回一手：年报 / 官网 / 法条 / 官方发布会）。
   - **归因层**：因果方向是否成立（有没有更直接的一手归因被跳过 → Z24）。
   - **外推层**：从已发生推到未发生的那一步，是否越过了约束或类比边界（→ Z26 / Z32）。
4. **三分法裁决**：✅ 事实与逻辑均成立 / ⚠️ 事实成立但归因或外推有误 / ❌ 方向性错误。**⚠️ 与 ❌ 必须分开**——「半对」是最常见的形态，也是最容易含糊过去的形态。
5. **留有利证据**：主动列出「对原观点有利但我没提 / 对方没提」的项。只列打脸项的辨析不可信。
6. **给总判定 + 置信度 + 证伪位**（Z22 / 用户收敛铁律：明确方向，反三情景并列）。

### 2026-11-15 实锤
- 原推演 7 条主张 → 2 条半对、3 条方向正好相反、2 条对；**总判定「不会这样」**，置信度 82。
- 关键：它把「零售缩量」「息差收窄」「房价跌」三个**现象全看对了**（事实层 ✅），却在归因层（「收房卖不掉」）和结论层（「砍零售转对公」）连续装反。若整体判「错」，会丢掉那四条真有含金量的观察；若整体判「对」，会把三条硬伤一起吞下。
- **自相矛盾检查**（三分法附赠）：原推演第 7 条「银保业底层都是地产」与第 5 条「砍零售去做对公」冲突——对公地产不良 4.47% 远高于零售按揭 0.48%。**内部一致性核验必须做**，一整段推演常在两条主张之间自打脸。

### 接口
- 与 **Z13** 连用：抄原话 + 双叙事对照。
- 与 **Z24** 连用：归因层查有没有跳过最直接的因。
- 与 **Z22** 连用：每条主张问「给得出阈值 / 证伪位吗」，不给的降级为仅背景。

## Z30 已发生反例检验法（用当期一手数据回测推演前提）

**一句话**：**推演说「A 会导致 B」时，先看 A 是不是已经部分发生了、B 有没有跟着发生**。已发生的现实比关于未来的争辩更硬；A 变而 B 未变，因果链即被削弱甚至证伪。

### 操作步骤

1. **提取自变量 A 与因变量 B**：写成「若 A，则 B」的干净形式，去除修辞。
2. **查 A 的当期实际值**：A 在过去一段时间是否已经变动？变动幅度多大？给数据日与口径。
3. **查 B 的当期实际值**：同一时间窗内 B 的实际读数（用多个代理指标，避免单一指标巧合）。
4. **三态判据**：
   - A 已变、B 同向变 → **支持**（但仍非证明，须查有无共因）。
   - A 已变、B 未变或反向 → **削弱 / 证伪**，推演的因果链要么不成立、要么漏了抵消机制。
   - A 尚未变 → **无法检验**，明确写「待验」，不许用逻辑推演代替数据。
5. **找抵消机制**：B 没跟着变，一定有东西顶住了（本例是非息收入 / AUM / 低成本负债）。**把这个抵消机制写进结论**，它往往才是真正的结构读数。
6. **给证伪位**：什么信号出现说明「抵消机制失效」、原推演重新成立。

### 2026-11-15 实锤
- 原推演：降息（A）→ 零售贷款无法覆盖风险成本、零售业务活不下去（B）。
- A 已实打实变动 8 年：招行净利息收益率 2.57%(2018) → 1.98%(2024) → 1.87%(2025) → 1.83%(2026Q1)，累计 **−74bp**。
- B 未发生：2025 ROE **13.44%**、不良 0.94%、拨备覆盖 391.79%；零售 AUM **18.71 万亿(+9.52%)**；2025 大财富管理收入 440.13 亿(**+16.91%**)、非息占比 36.13%；2026 前三季营收 / 净利仍正增长。
- 抵消机制 = **财富管理 / AUM 的非息收入 + 低成本活期负债**。这才是该写进结论的结构项，而不是「零售靠房子兜底」。
- 证伪位：AUM 或大财富管理收入**同比转负** → 抵消机制失效，重推。
- 同型复现：11/04 库销比 1.39→1.34→1.33 下行却称「主动加库存第 5 个月」（用已发生数据反证口播）；11/10 六处「涨幅回落」念成「下跌」。

### 硬约束
- **不许只用一个代理指标**：ROE 可能被拨备释放美化，须配不良率、拨备覆盖、AUM、非息占比至少四个。
- **不许把「尚未发生」写成「永远不会发生」**：结论是「当前因果链不成立 / 被削弱」，不是「该风险不存在」。配证伪位。
- **口径必须同期**：A 与 B 的时间窗要重叠，不许拿 2018 的 A 配 2026 的 B 却不说窗口（Z17）。

### 接口
- 与 **Z2**（存量 / 增量双镜）、**Z9**（三年纵列 + 拐点年）同骨架。
- 与 **Z17**（估值口径与窗口标注）连用：所有数值标数据日。
- 与 **Z28** 连用：本方法检验的是**方向与机制**（L1），不承诺择时精度。

## Z31 口径层级核验（比率 ≠ 单笔、存量 ≠ 增量、价 ≠ 量）

**一句话**：引用任何比率之前，**先写清分子、分母、主体、窗口**；并确认它没有被从「合并报表层」偷运到「单笔交易层」，或从「价格 / 费率层」偷运到「业务规模层」。

### 操作步骤

1. **写四要素**：比率的分子 / 分母 / 主体（全行？集团？单笔？行业？）/ 窗口（哪一期、日均还是期末）。
2. **标层级**：① 合并报表层 ② 业务条线层 ③ 单笔交易层 ④ 行业均值层。**跨层套用一律判错**，除非显式给出桥接假设。
3. **区分净额口径**：净利息收入（已扣资金成本、未扣信用成本 / 运营成本 / 资本成本）≠ 净利润 ≠ 风险调整后收益（RAROC）。银行口径尤其易混。
4. **量价分离**：费率 / 收益率 / 利差变薄是「价」，规模 / AUM / 保有量是「量」。**价跌 ≠ 业务消失**，须同时查量的同比（Z2 份额镜像）。
5. **毛 / 净、同比 / 环比、存量 / 增量三组切换各核一次**（Z18 一阶导前置）。
6. **法条 / 制度类口径**：涉及「可追索 / 可执行 / 可抵押」时，回法条原文核**权利性质**（优先受偿权 vs 普通债权）与**例外条款**，不许用日常语义替代法律定义。

### 2026-11-15 实锤（三处同型）
| 项 | 外部表述 | 一手 | 层级错在哪 |
|---|---|---|---|
| 招行 2018 净息差 | 「2.6%，×10 万 = 单笔年赚 2600，其实并不赚钱」 | 实为 **2.57%**（净利差 2.44%）；净息差 =（利息收入−利息支出）÷ 平均生息资产 | **合并报表层 → 单笔交易层**；且 2600 是净利息收入不是利润 |
| 唯一住房 | 「有房，坏账可追索，不良回收率可观」 | 最高法《执行异议和复议规定》**第 20 条** +《查封扣押冻结规定》4/5 条：生活必需住房**可查封、不得拍卖变卖抵债**；无抵押贷对房产**无优先受偿权** | 把「普通债权可执行」当成「抵押权优先受偿」，且忽略三项例外 |
| 理财业务 | 「利差薄 → 大部分收摊」 | 2026Q3 理财 **35.37 万亿 / +10.08% 创新高**；降息→存款搬家 | **价 → 量**偷运；财富管理赚手续费、不承担息差风险 |

- **反证设计（本方法的精华）**：口径错不乱吵，找**该口径自身的内部结构**自证。原推演说「房子兜底让银行不怕坏账」，但招行 2026H1 分品类不良率是**有抵押的按揭 0.48%（最低）、无抵押的信用卡 1.90%（最高）**——若机制成立，无抵押贷不良应当更低，事实完全相反。**用对方选定的口径去反证对方的结论，是最省力的拆法。**
- 同型：11/14「1154 亿 ÷ 38 兆 = 3.58%」（月息年化÷总债务 ≠ 加权平均票面利率，分母应为有息国债）、「支出是收入的一倍」实为 2.10 倍；11/10 六处涨幅回落念成下跌。→ **读法防错族第四次复现**。

## Z32 政策约束内生性检验（自我刹车识别）

**一句话**：当推演假设「政策会一路走到极端」（降到零 / QE / 大水漫灌 / 无限宽松），**先查这个极端路径会不会先摧毁政策自身的约束条件**。若副作用本身构成决策者的硬约束，线性外推不成立——该给「约束位」，不该给「终点位」。

### 操作步骤

1. **写出极端终点**：对方说的终点是什么（零利率、QE、全面国有化……），以及推演路径是线性还是阶梯。
2. **列政策的约束集**：逐条写决策者公开承认的约束。中国语境至少四项：**银行净息差 / 汇率与资本流动 / 财政纪律与地方债务 / 通胀与资产价格**。每项找官方原话（国新办发布会、货币政策执行报告、央行工作会议）。
3. **查「约束是否被列为前提」**：官方若把「稳定 X」写成「为降息创造空间」的前提，则 X 是**内生刹车**，不是外生噪声。
4. **做自洽性检查**：推演内部是否一边论证「政策会伤害 X」、一边假设「政策会无视 X 一路走到底」？**这是最常见的逻辑不自洽**。
5. **给约束位而非终点位**：把结论写成「在约束 X 触发前，路径最可能停在什么区间 / 什么节奏」，并标出 X 的可观测阈值。
6. **区分工具同名**：「国债买卖」≠ QE、「结构性工具降息」≠ 全面降息、「换锚」≠ 降息。工具同名不同义时，回官方对该工具的**定位表述**（基础货币投放 / 债市供求 / 收益率曲线 vs 压低长端 / 资产负债表扩张）。

### 2026-11-15 实锤
- 原推演：中国「大规模降息 → 最后降到零利率 → 然后开始 QE」；同时论证「降息让银行活不下去」。→ **自洽性检查不过**。
- 官方一手：2026-01-15 国新办邹澜——2025 年以来**银行净息差连续两个季度 1.42%**、2026 年长存款到期重定价 + 下调再贷款利率 0.25pct「有助于降低银行付息成本、**稳定净息差，为降息创造一定空间**」；措辞是「**一定空间**」，且「**不搞大水漫灌，防范高通胀、高债务等潜在风险**」。机构解读「可排除 2026 年大幅降息及实施大规模数量型宽松的可能」。
- 工具定名：国债买卖被官方定位为「综合考虑**基础货币投放需要、债券市场供求情况、收益率曲线形态变化**」的流动性工具，配合政府债发行——**不是**以压低长端 / 对抗通缩为目标的 QE。
- 换锚定名：政策利率 7 天 1.40% → 隔夜 1.25%（2026-11-02 落地），光大张旭 / 中信明明均明确「**不能解读为降息 15bp**」，因 DR007 长期高于 DR001 约 18bp，属期限结构。
- 学术定位：人大重阳《现代金融导刊》2025(9)——中国潜在增速仍中高、核心 CPI 仍正、常规工具仍有空间，仍属**常规区间**；零利率「应被视为**最后的非常规政策选项**」。
- **约束位写法（本方法的输出形态）**：「政策利率小幅阶梯下行（非归零）+ 国债买卖常态化 + 息差缓慢筑底」，配可观测阈值「政策利率 <0.5% 或明确 QE」「CPI 连续两季为负」。
- **类比边界补记（Z26 中国版）**：日本走到零利率 + QE 的前提组是「持续通缩 + 企业部门转净储蓄 + 泡沫遗留坏账 + 僵尸企业续命 + 改革滞后」；中国走的是**化债 + 财政货币协同 + 债务重组**。可迁移的是「坏账须及时出清、财政货币须协同」这些**步骤**；不可迁移的是那组前提。**学步骤不抄结论**——抄「必然零利率 + QE」而不核前提差异，类比降级为软证据。

### 硬约束
- **不许把「尚未走到极端」写成「永远不会走到极端」**：输出必须是「约束位 + 触发阈值」，不是「不可能」。
- **不许用机构观点代替官方原话**：券商 / 基金研判只作背景，约束集必须以央行 / 政府发布会原文为准。
- **不许拿他国路径当本国终点**：须过 Z26 迁移边界表（列可迁移 / 不可迁移项）。
