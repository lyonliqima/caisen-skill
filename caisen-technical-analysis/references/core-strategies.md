## 两大核心策略

### 破底翻（做多绝招）

蔡森最推崇的做多策略。主力在底部洗盘，刻意跌破支撑清洗浮筹后迅速收回。

**识别步骤**：
1. 股价在底部区域形成支撑（画出底部颈线/支撑线）
2. 某日带量跌破支撑线（散户恐慌抛售）
3. 随后快速收回到支撑线之上（主力吸筹完毕的信号）
4. 回调不破底部低点 → 确认破底翻成立

**进场时机**：
- 第一个买点：股价翻回支撑线上方时
- 第二个买点（加码）：突破颈线时
- 胜率约70%，适合波段持有

**止损**：若再次跌破底部低点，则破底翻失败，止损出局。

> **⚠️ 2026-10-29 展开版**：`references/破底翻-20261029.md`（机制推导 + 三个价格层次 + 仓位规则 + 案例核查）。四条必须按展开版执行：
> 1. **支撑在成本区下沿，不在破底低点**。主力只用少量筹码灌破，绝大部分持仓成本仍在箱体里（"支撑在 20，不是 18.5"）。等回踩 18.5 永远等不到。
> 2. **破底翻是"发现主力"的工具，不是"预测涨幅"的工具**。它能确定"这里有人"，不能确定"何时拉、拉多高"——后者来自催化剂。三六零 18 个涨停是借壳重组，不能当破底翻胜率样本。
> 3. **仓位规则**：大盘非多头只 20%；多头确立可 50%~70%；单票不超两三成；第一买点建仓、带量突破颈线加码 10%~30%。
> 4. **破底幅度 3%~10% 为宜**，超过 15% 大概率是真跌不是洗盘；翻回必须带量。

### 假突破（做空绝招）

与破底翻对称的做空策略。股价突破前高后迅速回落，表明突破失败。

> **经典实战案例图**：`images/false-breakout-example.png`
> 图中展示：上升趋势中价格突破紫色颈线冲至142.350后，立即大阴线跌回颈线下方（~118），跌幅约17%，是教科书级假突破诱多陷阱。

**图形视觉特征**：
```
  价格
  150 │              ╭──╮ 假突破高点（142.350）
  140 │    ──────────│──│──── 紫色水平颈线（阻力位 ~131）
      │              │  │
  130 │──────────────┤  ├───────
      │              │  │   ╲
  120 │              │  │    ╲ 大阴线贯穿颈线！
      │              │  │     ╱
  110 │              │  │    ╱
      │    ╭─────────┤  ├──╯
   90 │   ╱          │  │
      └────────────────────────→ 时间

  核心要素：
  ① 趋势背景：明确上升（从100→130+）
  ② 颈线：多次测试的水平阻力位
  ③ 假突破：1根K线超出颈线（8-9%幅度）
  ④ 反转：紧接着1-2根K线大阴线跌回
  ⑤ 结果：跌破颈线后继续下跌
```

**识别步骤**：
1. 股价在头部区域形成阻力（画出颈线）——可以是水平颈线、头肩顶/M头颈线、或上升趋势中的关键阻力位
2. 某日突破前高/阻力线（散户追高买入）
3. 随后快速回落到阻力线下方（主力出货完毕）——**关键：回落速度越快、跌幅越大，假突破越确定**
4. 反弹无法再站上阻力线 → 确认假突破成立

**假突破的量化判定增强**：
| 判定维度 | 假突破信号 | 本案例表现 |
|----------|-----------|-----------|
| 突破幅度 | 超出颈线 > 3% 即可疑 | 超出约 **8.3%**（131→142.35），大幅突破更危险 |
| 回落速度 | ≤5根K线内跌回 | **1-2根K线**即大幅回落 |
| 回落力度 | 跌破颈线 > 3% | 跌破约 **10%**（到118），极强确认 |
| K线形态 | 大阴线/长上影线 | **大阴线**直接贯穿颈线 |

**进场时机**：
- 股价回落跌破颈线时做空（第一卖点/空点）
- 反弹无法站回颈线时加码做空（第二空点）
- **最佳时机**：大阴线跌破颈线的收盘时刻或次日开盘

**止损**：若再次突破并站稳前高上方（如146.6 = 142.35×1.03），则假突破失败，止损出局。

> **⚠️ 2026-10-29 展开版**：`references/假突破-20261029.md`（出货机制 + 13 例实测 + 非死即伤 + 检查清单）。上面基于单张案例图的量化表保留，但以下六条必须按展开版执行：
> 1. **前置硬筛选：该轮涨幅 ≥100%**。13 例实测突破前涨幅中位 **+137%**、12 例中 10 例已翻倍。低位"突破又跌破"多半是洗盘（见 `washout-techniques.md`），不是出货 —— 这是两套东西的唯一分水岭。
> 2. **必须有确立动作：跌回颈线以下才算。** "不能说突破就说它是假突破"。实测跌 10% 中位只需 **1 周**（12/13 例 ≤2 周），因为主力已在颈线附近反复派发，**不敢在突破位停留**（停留会激活解套卖压）。→ 若突破后 2 周以上仍在颈线上方，基本不是假突破。
> 3. **量价不对称**：拉上去要用力（需主动吃单）、往下撑不用筹码。所以突破那周必须放量（实测中位 **1.45 倍**，10/11 例），**不放量的突破反而不像出货**。华邦电那种"爆量又收在颈线之下"是最强信号。
> 4. **非死即伤，不必后悔**：洛阳钼业实测 —— 假突破后套牢 **25 周（5.8 个月）** 才解套，解套后仅多给 **+10.1%**，随后二次头部 **−64.9%**。所谓"受伤"是赔半年时间换 10%，不是可以继续持有的理由。累计跌幅实测中位 **约 −50%**（区间 −34.8%~−68.9%）。
> 5. **高档涨停突破是高危不是强势**（中信证券案例："吸引打板的，涨停板有时候隔天就没高点"）；**"之前很会涨"正是主力要利用的心理**（华邦电案例：横盘 5 个月训练价格错觉）。
> 6. **假突破是卖出触发器，不是目标计算器**。目标由 `波段涨幅满足` / `收敛三角边长法` 给。若还在满足点以下就出现"假突破"，先怀疑形态画错。跨市场（汇率等）镜像应用时**必须先确认报价方向**（USD/CNY 向下假突破 = 人民币升值）。

**测幅满足**（基于本案例估算）：
```
height = 假突破高点 - 颈线 = 142.350 - 131 ≈ 11.35
第一满足点 = 131 - 11.35 ≈ 119.65  ← 已接近！
第二满足点 = 131 - 22.7 ≈ 108.3
```

## 期权操作纪律

蔡森反复强调的期权操作铁律：

| 原则 | 说明 | 原因 |
|------|------|------|
| **绝不做卖方** | 不卖Call也不卖Put | 卖方收益有限但风险无限（可能被断头） |
| **只做买方** | 看多买Call，看空买Put | 买方风险有限（最多赔权利金），收益空间大 |
| **选择权卖方=被杀对象** | 盘中一口拉到涨停板就是卖方被断头 | 一次极端行情就能让卖方全部亏损 |

**实战案例**：台股大跌时，卖权（Put卖方）一口被拉到涨停板，成交仅两口就V型反转——这两口就是卖方被强制平仓（断头）。
