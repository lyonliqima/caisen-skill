# B 组｜地缘与政策拆解

## L4：地缘冲突"能源+金融战"穿透法

**任何一场军事冲突，都要穿透表象，追问：谁出钱？谁赚钱？以什么货币计价？定价权归谁？**

### 四问穿透法

```
问题1：资金谁出？谁赚？
     → 排出各方收益矩阵（谁掏钱、谁收费、谁主导）
问题2：收费基数是什么？算出金额
     → 按不同基数（全部GDP / 全部石油收入 / 石油收入的X%）算出不同方案金额
问题3：以什么货币计价？
     → 美元计价 = 强化美元体系；本币/多元货币 = 去美元化
问题4：定价权归谁？
     → 谁掌握资金最终调配权 = 谁掌握定价权
```

### 各方收益矩阵模板

| 参与方 | 出资 | 收益 | 真实目的 |
|--------|------|------|---------|
| 主导国 | ? | ? | ? |
| 出资方 | ? | ? | ? |
| 被重建方 | ? | ? | ? |

### 关键原则

1. **看谁不出钱却拿主导权**：如果某方一分钱不掏却当"总包商"、掌握资金调配权、制定所有标准——这是一场金融主导战
2. **货币计价是核心**：所有资金往来以美元计价 = 强化美元霸权；这是"包装成战争的能源战和金融战的融合"
3. **协议法律效力要看清**：谅解备忘录往往无强制约束力，要看未达成共识的关键问题（如自卫权、资产解冻、核承诺）
4. **压油价的真实目的**：主导国压低油价 → 降国内通胀 → 为央行会议/选举铺路，同时掌控能源命脉
5. **连带金融效应**：压油价→抑制通胀；释放信息压金价；各国增持美元储备买油；安抚华尔街推高股市

### 适用场景
- 透视中东/俄乌等地缘冲突背后的能源与金融博弈
- 评估"重建基金/援助计划"的真实利益分配
- 判断地缘事件对油价/金价/美元的传导

### L4 补充框架：中东战争·通胀阀门·全球资本回流（提炼自会议观点；框架可复用，具体数值待验证）

**中东战争的底层定义（跳出宗教/领土/民族叙事）**
- 二战后中东围绕石油定价权爆发的六次大规模战争，本质是资本殖民秩序的工具：奠定全球资本殖民新型国际秩序，并数次调整全球资本大规模流转方向。
- 双重枢纽属性：①能源枢纽（核心石油产能与运输通道，决定能源松紧与价格）；②交通枢纽（欧亚非交界、全球贸易航道核心节点，决定运输成本与供给效率）。
- 通胀阀门机制：中东战争是全球通胀"总开关"——开战推高能源与航运成本、打开通胀上行通道；停战供给恢复、通胀回落；开关主动权长期在美国手中。

**通胀四级分类标准（量化基础框架）**
| 等级 | 月度通胀 | 特征 |
|------|---------|------|
| 温和通胀 | ≤2% | 对经济最友好 |
| 高水平通胀 | 2%-10% | 经济明显压力 |
| 狂奔通胀 | 10%-50% | 秩序紊乱、本币快速贬值 |
| 恶性通胀 | >50% | 货币体系近崩溃、秩序失灵 |

**石油-通胀阈值测算（量化指标；成本基线：美国SPR建仓约55-65美元/桶，中国约低5美元）**
- 油价 90 美元/桶 维持 6个月以上 → 全球进入高水平通胀
- 油价 150 美元/桶 → 全球接近狂奔通胀
- 油价 200 美元/桶 → 全球进入恶性通胀边缘
- 传导：油价→交通能源→物流/化工原料→下游消费品，周期 3-6 个月，边际效应递减。

**通胀驱动资本回流完整链条（"制造动荡→强美元回流"逻辑）**
1. 中东战争推高全球能源与商品价格 → 输入型通胀扩散
2. 70%+ 非美国家压力剧增，多数新兴市场进入狂奔通胀、部分小国恶性通胀，本币贬值/崩溃
3. 高通胀国"股债汇三杀"，本土与外资避险，抛售本币资产、兑换美元撤离
4. 全球美元资本大规模回流美国，完成财富转移，为美债与资产市场接盘
5. 回流美元主要涌入美债市场，承接美大规模发债，为财政与"大漂亮"计划提供资金

**强美元"哲学悖论"（物理定义 vs 哲学定义）**
- 物理定义（常识）：美元购买力越强 → 美元越强
- 哲学定义（历史现实）：通胀高企、美元购买力下降时 → 反而"真强美元"，因全球动荡下美元是终极避险资产，非美货币贬值越严重，美元指数相对越强

**"向心坍缩"资本流转模型（cross-ref：卢麒元 M3 向心坍缩阶段判断清单）**
1. 全球通胀点燃 → 各地资本向美国"核心"收缩（引力类比）
2. 收缩至一定程度进入"速冻" → 非美地区资本外流、资产崩塌、经济萧条
3. 完成美元信用重置 → 美国再向外释放美元，抄底全球优质资产，完成一轮资本循环
- 边界与对冲（避免机械套用）：①美国自身债务脆弱性（高通胀推高美债收益率、利息支出破万亿，或先冲击美元信用）；②全球去美元化（金砖扩容/本币结算/人民币跨境支付/央行增持黄金分流避险资本）；③非美政策应对（资本管制/汇率干预/能源保供，中国为典型案例）降低坍缩烈度。

**重质油 vs 轻质油（微观机制）**
- 美本土页岩油多为轻质低硫（汽油等轻质油品）；伊朗/委内瑞拉重质高硫（柴油/沥青/化工原料），是美工业体系与战略储备必需 → 美执着控制伊朗石油的技术原因。
- SPR真实作用：应对短期供给中断、平抑短期波动，无法长期压油价；美SPR处近40年低位，补库迫切但仅靠伊朗油无法完全填补。

**适用场景（补充）**：透视中东地缘冲突的能源/金融/资本维度；判断油价-通胀-资本回流链条；评估"制造动荡→强美元回流"收割逻辑及失控风险；配合 L11（美元信用支柱）、卢麒元 M3（向心坍缩）交叉验证。

## L5：政策工具四维拆解法

**任何一项金融/财政政策工具，都按「内容→目的→解决问题→使用限制」四维拆解，才能判断其真实影响。**

### 四维拆解模板

```
政策工具：[名称]
├── 内容：具体操作是什么？谁执行？对谁？
├── 目的：核心目标是什么？（定价权/流动性/稳定性/国际化）
├── 解决问题：堵住了哪个漏洞？防范了什么风险？
└── 使用限制：什么条件下才能用？有什么约束？
```

### 常见央行工具分类

| 工具类型 | 典型工具 | 核心目的 |
|---------|---------|---------|
| 定价权类 | 离岸市场交易试点 | 拿回定价话语权，防止投机做空 |
| 流动性支持类 | 境外回购工具（FIMA） | 给外资吃定心丸，防止恐慌抛售 |
| 应急救援类 | 非银流动性支持工具 | 防止"抛售-下跌-更多抛售"负向螺旋 |
| 利率调控类 | 收窄利率走廊/增加隔夜操作 | 精准调温，稳定短期资金价格预期 |

### 关键原则

1. **区分常态化工具与应急工具**：应急工具（如"金融救护车"）仅在极端情况使用，抵押品必须是高等级资产
2. **利率走廊收窄的信号**：从"看量"（货币供应量）转向"看价"（基准利率），意味着直接融资开始主导，需要稳定的短端利率做定价基石
3. **政策工具组合拳的逻辑**：拿回定价权（离岸交易）+ 给外资定心丸（FIMA）+ 防系统性风险（非银支持）+ 精准调控（利率走廊）= 构建现代化金融框架
4. **利率上升 ≠ 紧缩**：有时只是央行把过低的利率拉回正常走廊区间，要区分"正常化"和"紧缩"

### 适用场景
- 解读央行新政策工具的真实意图
- 判断政策是常态化还是应急性
- 评估货币政策框架转型
