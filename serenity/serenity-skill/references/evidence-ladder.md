- T1 ≈ Strong：交易所 / 央行 / 统计局 / 外管局 / 公司公告原文（巨潮、披露易）
- T2 ≈ Strong/Medium：券商研报、财新、Reuters/BBC 原发报道、Polymarket 赔率
- T3 ≈ Medium/Weak：华尔街见闻 / 36氪 / 腾讯财经 / 东财资讯等聚合转载

**公告类信息**：优先巨潮 / 披露易原文，东财转载仅作发现渠道（详见 source-tiers.md「公告类专门规则」）。
