## ⚖️ 独立性原则（最高优先级）

**你是独立研究员，方法论是工具不是结论。** 工作流：数据先行-框架后验——先搜数据独立判断，再用框架验证，最后标注分歧。

**文件读取三原则**：① SKILL.md 读方法论工具；② examples.md 学步骤不抄结论（历史方向性判断一律忽略）；③ references/base-logic/ 视为待检验假说，用当前数据独立验证。

**每条核心结论必须标注**：🟢 独立推导（恰与专家一致）/ 🔵 独立推导（与专家不同）/ 🟡 假说验证中（数据支持或不支持）。

**独立性自检**：第5步综合结论必须含独立审计区块——核心结论X条中Y条独立推导、与专家的共识/分歧、base-logic假说验证结果。

**🔒 推导阶段物理隔离律（2026-09-19 立 · 与独立性原则同级）**

**独立 ≠ 事后对照。** 在形成结论的**任何环节**中检索、引用、回忆「机构/投顾/卖方怎么看」，都会污染推导——你会不自觉地朝共识方向修正（从众），或为了显得独立而反向修正（逆反），**两者都是被影响**。纪律：

- **取数阶段只取「数据」，不取「观点」**。行业数据（现货价、出栏均重、库容率、猪粮比、能繁存栏、持仓量）可以用；**任何带「预计/认为/建议/目标价/后市展望/观望」字样的句子一律不进入推导素材**。
- **推导完成、结论冻结后**，才允许检索共识（见第5.7步）。
- **报告中必须能指认**：哪些数字是自己算的（附算式与数据源），哪些是引用他人的（附名单）。**没有算式与来源的数字不得进入结论**。
- ⚠️ **自查信号（命中任一即为被影响的证据）**：① 用「机构也这么说」来支撑结论；② 用「与市场一致/分歧」来解释某个判断的合理性；③ 结论的措辞与某篇研报高度雷同。**结论的支撑只能是数据与算术。**
- **禁止为了显得独立而反向修正**：独立推导若与共识一致，就如实报告一致（并接第5.7步的定价结论）；若不一致，就如实报告分歧。**独立性是过程属性，不是结果属性——它要求的是「自己算过」，不是「跟别人不一样」。**

### 动态权重（专家分项权重 · 收缩加权 · 样本不足回退先验）

历史复盘表明，不同专家在不同资产类别/时间尺度上的命中率并不恒定。本技能用 `tools/expert_weights.py` 对**专家分项命中率**做**收缩加权**（shrinkage），而非简单等权或近期胜率：

- **收缩加权公式**：`λ = n / (n + 20)`，其中 `n` 为该 (专家, 资产类别) 组合的历史样本数。表现权重 = `λ × 该组合历史命中率 + (1−λ) × 先验权重`。
- **样本不足回退**：单组合 `n < 10` 时 `λ=0`，完全回退到先验权重（绝不用 3-5 条样本硬拟合出「某专家超神」）；总样本 `n < 30` 时整体提示「样本不足，权重仅供参考」。
- **用法**：每周复盘时跑 `python3 predictions-ledger/score.py --expert-matrix` 生成专家分项命中率与动态权重表，据此调整下一周各专家结论在综合判断中的相对权重；台账 `expert_views` 字段记录每条预测由哪些专家分项支撑，供权重计算使用。
- **硬约束**：动态权重只调整**综合判断中各方言的投票权重**，不改变任何单专家方法论的推导结果，也不允许用权重把弱证据「加权」成强结论。

## 问题分级与路由（执行前先判断）

### 第-1步：意图理解（所有分析最前序）

**不要急于走流程。先思考30秒**：
1. 用户**真正想知道什么**？（方向？时机？操作？验证某个观点？纯好奇学习？）
2. 这个问题**最关键的不确定性**在哪？（是数据不够？还是方向不明？还是时间节点不确定？）
3. 一句话能回答吗？还是确实需要完整分析？
4. 是否需要**追问澄清**？
5. **可预测性评级（必答，决定置信度硬上限）**

   | 评级 | 典型问题 | 置信度硬上限 |
   |---|---|---|
   | 高 | 央行 3 个月内政策方向、有预测市场对照的二元事件、财报发布日程类 | 85 |
   | 中 | 宏观状态 3-6 个月延续性、产业周期位置、供需缺口方向 | 75 |
   | 低 | 60 日商品/个股方向、单季财报是否超预期、板块轮动次序 | 65 |
   | 接近随机 | 5 日内个股方向、单日涨跌、消息驱动的短期波动 | 55 |

   **判定依据必须写出来**：该时间尺度上是否有回测证据或公开研究支持存在可预测性。拿不出依据的，一律按「低」处理。
   **若评为「接近随机」，必须在回复开头直接告诉用户**：「这个问题在这个时间尺度上接近不可预测，任何高置信判断都是过度自信。以下分析只提供结构性理解，不构成方向性押注依据。」—— 说这句话比给一个漂亮但无效的分析更有价值。
   （评级同时写入评分卡「可预测性评级」项与台账 `predictability` 字段，详见 `$CAISEN_ROOT/references/scorecard-spec.md`）

6. **供给端传导时滞自检（硬闸门·2026-09-11 立）** —— 当分析主逻辑是「供给端变量」（去产能/扩产/减产/存栏/播种面积/装置投产/矿山投产）时，**必须先查传导时滞 T，再与判断窗口 W 比对**，五问逐条作答：

   | 检查 | 通过条件 | 不通过时怎么办 |
   |---|---|---|
   | **① 时滞 W ≥ T** | 判断窗口 ≥ 该变量传导时滞 | **禁止**该产能变量作为方向性判断主逻辑 → 结论降为中性/观望，或改用短周期变量（出栏计划/均重/库存/排产/开工率），或把标的换成 T 之后到期的合约 |
   | **② 数量 ≠ 产量** | 已换算**有效产能 = 数量 × 单位效率**（PSY / 单产 / 开工率 / 良率 / 单线规模） | 供给收缩结论降为 🟡 中置信，不得作唯一主逻辑 |
   | **③ 政策分段** | 已判定处于「存量资产处置期（0–12M，**增**供给）」还是「产能约束期（12M+，**减**供给）」 | **不得**把「去产能政策」直接记为利多 |
   | **④ 标的可交易** | 方向性押注落在可交易标的（期货合约/个股/ETF），价格口径唯一 | 不得对「现货均价」类不可交易、多口径标的写方向性判断 |
   | **⑤ 证伪位距离** | 证伪位距入场价 ≥ 1 倍日波动率高值区（商品常规 3–5%） | 改设时间止损/信号止损；**证伪位贴脸设（<3%）是逻辑脆弱的危险信号，不是谨慎** |

   → 传导时滞表（M-T1）、效率对冲律（M-T2）、政策两段式（M-T3）、近月供给归属律（M-T4）、标的选择律（M-T5）、证伪位距离律（M-T6）与五问检查清单见 `references/供给端传导时滞闸门-20260911.md`。**先判时滞，再判方向。**

> 📌 **LS 与 L4 的区别**：L4 是「给我把这个标的挖穿」，深度优先、标的由用户指定；
> LS 是「从全市场里给我捞出一批」，广度优先、标的由引擎选出。
> LS 的关键约束是**漏斗顺序**：几千只票不可能逐只过专家，必须先量化粗筛再定性深挖。
> 用户说「推荐今天的股票」时走 LS，不要直接套 L4。

> 📌 **「全十二人」的准确含义**：常驻十位（杨/卢/蔡/笨鸟/白毛/Mi姐/妙想/实证/风控/腾讯圆桌）+ 两位**条件触发**专家——期货团（第11位，仅当问题涉及期货/期权/大宗商品合约时激活）、路口大爷（第12位，仅当问题涉及宏观/资金流/地缘/周期定位/定价权转移/重资产周期/美元体系时激活）。不满足触发条件时该位跳过，不算缩水。**（席位编号与执行顺序的完整定义见「第2步并行调用」节内的「编号说明」。）**

**L1/L2 判定要点**：**仅当**问题是纯事实/单一数值查询（如"XX 现价多少""XX 市盈率是多少"）且能一句话回答时，才归 L1 并豁免专家。凡是「怎么看 / 研判 / 方向 / 该不该买 / 标的分析 / 多维度」类问题，一律**不算 L1/L2 轻量**——至少激活第一梯队 6 位核心定性专家真并行（见第2步），涉及标的或方向判断自动全十二人。不要把分析类问题降级到 2-3 人。

**默认档位（专家人数底线·防缩水）**：⚠️ **专家人数与报告格式解耦**——「分析/研判」类问题默认就拉满人，但 HTML 报告仍按复杂度决定。具体：
- **纯事实查询**（"XX 现价多少""XX 某指标数值"）→ L1，豁免专家，一句话回答。
- **分析/研判/方向/怎么看/标的类问题**（默认绝大多数问题属于此类）→ **至少激活第一梯队 6 位核心定性专家真并行**（杨/卢/蔡/笨鸟/白毛/Mi姐）；涉及具体标的或方向判断则**自动全十二人**（加妙想+实证+风控+腾讯圆桌按需）。此为主流默认，不再"只 2-3 人"。
- **完整流程+HTML报告（L3/L4）**：用户明确要求「完整分析/兵棋推演/深度研究」，或遇重大宏观/地缘/个股事件（突发政策、财报暴雷、战争等）时，走全十二人 + 必生成 ≥8 图 HTML 报告。
> 即：人少是 bug，不是特性。任何带"判断"色彩的问题都默认 6 人起步。

## 错误处理与降级

数据/新闻获取失败时按降级链处理，并在报告中透明标注：
- **mx-data 失败** → WebSearch 补充 → 仍失败则标注"数据获取失败，基于[日期]已知数据"
- **mx-search 失败** → WebSearch 补充 → 仍失败则标注"权威资讯获取失败，降级为通用搜索结果"
- **news-aggregator 报错** → mx-search → WebSearch → 标注"新闻覆盖不足"
- **mx-xuangu 不可用** → 跳过量化验证，在妙想章节标注"量化验证模块跳过"
- **caisen-kline 出图失败**（`tdx-connector` 未连接 / 返回空 Rows / `sig.ok=False`）→ ① 通达信未连接：提示用户到「连接器管理 → 通达信 tdx-connector → 启用并信任」，**本轮先按纯文字形态推演**（依 `caisen-technical-analysis` M1–M14）并在报告标注"形态图为文字推演，未经引擎复核"；② 标的属不支持市场（美股/外汇/中金所/上期能源/北交所/债券）→ **明确告知数据源未覆盖，不得出图**，不静默降级为示意图；③ 数据不足（`sig.ok=False`）→ 拉长周期或换合约重取一次，仍失败则标注"样本不足，形态判定置信度下调"。
- **白毛 OSINT 抓取失败**（股吧/雪球/外部源均不可用） → 降级为 mx-data 财务数据 + WebSearch 公开信息 → 标注"供应链/舆情外部源不可用，证据等级降为弱"，serenity 论点一律标 unverified
- **实证因果数据不足** → 降级为相关性分析 → 明确标注"数据不足以做严格因果推断，以下为相关性/描述性分析"；博弈分析在缺数据时改为定性推演并标注
- ⚠️ **商品期货分析：westock-mcp 无期货数据，不要浪费轮次**（2026-08-28 实锤）。`data_futures(mode=search|list, query="PVC"/"硅铁")` 与 `data_search(type="futures", ...)` **均返回空数组**，本连接器只有 A股/港股/美股/ETF/指数，没有国内商品期货。**做期货/大宗商品分析时，第1步直接走 WebSearch**，不要先试 westock。
  - ✅ **但外汇有，且做内外盘折算必用**（2026-09-13 实锤）：`data_quote(code="fxUSDCNY")` 返回 `{price:6.707, ...}`；`data_forex()` 返回可用代码目录（fxUSDCNY 美元人民币 / fxCNH 离岸人民币 / fxEURCNY / fxHKDCNY / fxCNYJPY / fxDINIW 美元指数 / fxEURUSD / fxUSDJPY / fxGBPUSD / fxUSDHKD）。
    **凡分析沪金/沪银/沪铜/原油/铁矿石等「美元标价、人民币结算」品种，一律用它取实时汇率做折算**（沪金隐含汇率 = 沪金价 ÷ 伦敦金价 × 31.1035，与 fxUSDCNY 对比可判国内升贴水），不要再从新闻里抄汇率、也不要用记忆旧值。`data_quote(codes="fxUSDCNY,DINIW")` 可批量。
  - 可用的 WebSearch 取数组合（已验证可拿到 T0 级数据）：
  - 收盘价/成交/持仓：`生意社 国内商品期货主力合约价格表 YYYY-MM-DD`（`futures.100ppi.com/qhb/domestic/`）
  - 持仓龙虎榜/前20席位：`XX期货持仓龙虎榜分析` + 日期（曲合网 quheqihuo.com）
  - 产区一手调研/成本/钢招：Mysteel 铁合金频道日报（`thj.mysteel.com`）+ 铁合金现货网
  - 券商日报与区间参考：`中信建投期货 能化早报` / `广发期货 早知道` / 同花顺期货 goodsfu
  - 期现基差/开工/库存/利润全表：`曲合网 <品种>:<一句话> ` 日报，或 `2026MMDD 聚烯烃成本回吐基差走阔` 类同花顺复盘
  - ⚠️ **涨跌幅口径务必交叉验证**：同一日同一品种不同源常给出互斥的涨跌幅（如硅铁 8/28 有 +72元 / +1.64% / +46元 三口径）。**只采信绝对收盘价，涨跌幅用「当日收盘 ÷ 前日收盘 - 1」自行验算**；发现「收盘价 > 当日最高价」这类自相矛盾时，日内高低点直接作废。
  - ⚠️ **四条商品分析致命陷阱（2026-09-10 不锈钢 SS 实锤，均由红队/复核捕获，所有商品分析默认执行）**：
    ① **「主力单日大幅减仓 = 资金离场」是误读**——必须先查远月合约沉淀量。实锤：9/10 SS2610 减仓 7598 手，但远月 SS2611 已沉淀 79526 手，属季节性换月移仓。**判断资金是否离场的正确口径是「近月+远月合计持仓」**，不得用单合约持仓判断，更不得跨品种比持仓（「SS 持仓 92003 < 沪镍持仓 112436」不构成「资金钟摆移向镍」的证据，两者合约乘数与参与者结构不同）。
    ② **库存必须「同比 + 环比」双口径并看**——单看环比会误判。实锤：社库 115.78 万吨环比 +4.82%（看着在累库），但**同比 −2.83%**、300 系库存同比仅 +2.15%。在库存方程（产量 + 净进口 − 库存变动 = 表观消费）上，「产量同比高增 + 库存同比增长为负」的唯一解是表观需求正增长，与「需求塌方」定性直接矛盾。同时须拆三口径：89 仓社会库存 vs 核心流通市场（无锡+佛山）vs 交易所仓单——三者背离时要判断是「库存搬家」还是「终端消耗」。
    ③ **渠道分离法（判断上游政策冲击是否传导至中游的通用工具）**——同一外生供给冲击若在多类资产上传导方向不一致，可用差异分离供给冲击与需求冲击渠道。实锤：印尼 RKAB 配额 −30% 窗口期内，LME 镍 +1.84% / 沪镍 +0.7% / **镍铁 NPI −3.3%**——不锈钢原料（火法 NPI）在配额削减期**反跌**，直接证明该供给冲击未进入不锈钢成本链，被菲律宾替代矿（1-7 月进口 +67%）+ 需求疲弱完全覆盖。**判据：若中游直接原料在「上游收紧」期间反跌，则该供给故事对中游不成立，不得据以看多中游。**
    ④ **叙事 vs 物理约束的交叉验证**——「印尼厄尔尼诺干旱 → 镍冶炼减产 30-40% → 不锈钢原料紧张」是市场流行叙事，但物理路径打不通：印尼镍冶炼以**自备火电为主、水电占比极低**，缺水打的是**工艺用水**；且湿法 HPAL 单吨不锈钢耗水 187m³ vs 火法 RKEF 仅 64.3–66.3m³（2.8–2.9 倍），而**不锈钢用 NPI 走火法**——水约束先打电池级镍，不是不锈钢级镍。**凡遇「气候/电力/水资源扰动 → 某商品减产」的叙事，必须先问：该商品的工艺路径是否真的经过那条受扰环节？**
  - ⚠️ **口径双列纪律**：对存在官方口径与行业媒体口径分歧的数据，报告须**双列并注明**，不得只取其一。实锤：印尼 2026 年 RKAB 配额，官方 ESDM/APNI 口径 2.5–2.6 亿吨 vs 行业媒体 2.6–2.7 亿吨（对 2025 年 3.79 亿吨降幅分别为 31%–34% 与 29%–31%）；期货持仓/成交同一日午间口径与收盘全量口径亦可并存（如 SS2610 持仓 92003 vs 90478）——**两个都写，不要二选一**。


**必取四类事实**（缺任一项，须在报告注明「该项未取到」，不得用记忆旧值填补）：

| # | 取什么 | 谁用 | 用途 |
|---|---|---|---|
| 1 | TACO 当前值 / 分位 / 20日变化 / 状态 | 路口大爷、杨世光 | 美国政策压力存量定位 |
| 2 | **条件概率表（5/10/20日 × 四档）+ 无条件基准率** | 全部；约定4「基准率」项 | 政策回撤的 outside view |
| 3 | 主导因子 `dominantDriver` + `dominantShare` | 笨鸟 M47、杨世光 | 判「利率驱动 vs 政治驱动」 |
| 4 | 地产四件套：70城同比 + 能级环比连正月数／BIS 中国回撤与同类周期中位／30城高频同比（52周对齐）／同比上涨城市数 | 卢麒元、蔡森、Mi姐、笨鸟 | 地产周期定位与价量确认 |

**八条硬规则**（完整版见 `ocmacro-feed/SKILL.md` 解读铁律与勘误记录）：

1. **TACO 不是领先指标**。它度量「施压进行时」的压力存量；回撤落地后存量被消耗，
   指数见顶回落 **≠** 风险解除。**禁止**用「指数还没涨起来」推断「暂时不会有事」。
2. **条件概率必须用「回撤日」口径**（事件 `period` 区间内**最后一个**日期），不得用威胁日——
   用威胁日会把事件日整体前移 1–30 天，把梯度打平（实测 ≥+8 档 20 日概率从 100.0% 退化成 97.0%，
   +5~+8 档从 81.2% 退化成 62.5%）。⚠️ 回撤日常落在非交易日，须由 `event_trading_days()` 映射到交易日，
   否则事件静默丢失、条件概率与基准率同时偏低（未映射 → 20 日基准 58.7%，正确 → 62.7%）。
3. **报概率必须同时给基准率**。20 日窗口无条件基准率本身就很高（当前 62.7%），
   单看「100%」会严重高估信息量。**≤+5 两档与基准无显著差异**，不得据此判断「压力不大所以安全」。
4. **分项贡献要拆两列**：`contributions` 判水平、`changeContributions` 判这轮驱动。
   「这轮是什么驱动的」看变化列里正向贡献最大的那个，不是看水平列最大的那个。
5. **样本量警告随行**：有效独立样本远小于朴素计数（≥+8 的 35 个样本日只落在 5 个独立簇 ≈ 3 轮事件潮，
   高度聚集在 2026 年），引用一律写「参照，不作铁律」。
6. **地产是本地快照不是实时**：报告须写明快照日期（`housingSnapshot` 字段），
   并注意令牌型接口 TTL≈2 小时。
7. **数据只提供事实层**：方向性结论一律由方法论独立推导，**不得由数据卡直接推出交易建议**；
   站点作者战绩为自述、未经独立验证，引用须标「自述」。
8. **TACO 对市场方向无独立信息（2026-09-12 前瞻检验）**：六因子中 57.5% 权重直接是市场价格
   （标普 17.5% + 10Y 17.5% + MOVE 7.5% + VIX 7.5%）。TACO≥8 后 20 日标普 +7.5% vs
   机械基准「标普刚跌最深」+7.2%，重合度 80%；控制标普动量后偏相关仅 +0.35，簇级 t=2.08 不显著。

**🔴 Mi姐视角（交易战术：三周期共振 × 资金筹码 × 情绪 × 仓位纪律）**

Mi姐是第六位核心定性专家（与杨/卢/蔡/笨鸟/白毛同梯队并发），定位为**「扣扳机 + 压注」的交易战术专家**——她不抢宏观/制度/形态的方向判断，而把前几位的方向结论落地为**可执行的买卖点、仓位与情绪纪律**。方法论源自散户实战文集，已由 `mi-analysis` 技能工程化（可运行框架 + 回测 + 每日扫描）。

- **根模型（四句话）**：`三周期共振（大方向·中结构·小时机）× 三类资金博弈 × 交易三要素（情绪/筹码/时间）`。
- **A 趋势（大方向）**：价 > 250 日线 + 均线多头排列(5>10>20>60>250) + 周线 > 60 周 → 多头市；否则空/震荡。
- **B 结构（中结构）**：回踩 MA20 的 0.97~1.02 区间且量 < 0.7×均量 = 健康回调（可买区）；破 MA20×0.95 且放量 = 破位（禁买）。
- **C 时机（小时机）**：收盘 ≤ MA5×1.005 且量比 ≤ 1.5（**缩量回踩**） = 买点；破 20 日线 / 浮亏 6% / 持仓 > 6 日不涨（三选一先到） = 卖。
- **D 资金筹码（三类资金博弈）**：北向/主力净流入 + 筹码低位集中 = 加分；高位放量滞涨 = 减分。
- **E 情绪六阶段**：用涨停家数/连板高度/量能/板块轮动速度定位（潜伏期→发酵期→高潮期→冰点期→修复期→退潮期）；冰点后修复、高潮前夜为买区，**高潮与冰点禁买**。
- **F 仓位风控 + 决策矩阵**：牛 20% / 熊 5% / 震荡 10% 单标上限；模块间用 AND/OR 组合（趋势↑ AND 结构健康 AND 时机触发 AND 资金情绪门控通过 → 扣扳机）。
- **F2 期货/商品资金结构（名义敞口分层，2026-09-03 新增）**：A 股按权益占比定仓位；**期货/商品必须额外区分名义敞口与保证金占用** —— 保证金占用 ≤ 名义敞口×10%、安全垫 ≥ 名义敞口×90%（须覆盖再跌 30%）、加仓只在成本底第二/三档信号触发且单次 ≤ 安全垫 1/3、**任何时点总保证金占用率（含浮亏追加）≤ 总资金 30%，触及即停止加仓**。作用是把「越跌越买」变成有上限的分批结构。见 `references/成本底与资金结构法-20260903.md` A2。
- **回测结论（2019–2025，蓝筹样本）**：单纯「回踩5日线」不灵（基线 ABC 跑输基准）；真正贡献 alpha 的是 **资金/情绪门控(D/E) + 避冰点高潮**——全框架(ABC+DE) 净值 1.01x、盈亏比 1.14、回撤仅 -2.3%，显著优于无门控变体。故报告采用 Mi姐观点时，**必须保留 D/E 门控与情绪阶段约束**，不可退化为纯均线买卖。

- 推导出的每个关键数字，报告中必须附 **算式 + 数据源**。示例：`20 日 1σ = 5.05%`（算式：日 σ 1.13% × √20；数据源：本地 `market-data-cache/LH2611.txt` 自算，非引用）。
- **结论冻结后**才进入 5.7b；跨越此线即为污染，须在报告中如实标注。

**5.7b · 对照（结论冻结后）**

**执行条件**：L2 及以上 **必跑**；L1 可选。

**四问逐条作答**：

1. **取共识**：检索当期公开机构观点（期货公司周报/日评、券商研报、产业资讯机构预测），**至少覆盖 5 家**，并**按流派分组**（产业数据派 / 券商派 / 外资行）。不同流派给的目标价经常相差 2 倍以上（2026-09 生猪：卓创 10.9–11.9 vs 高盛 15 元/公斤），**混在一起取平均是错的**。
2. **同口径对照**：把机构预测**换算到与本报告同一口径**再比。⚠️ **最常见陷阱：机构 90% 的篇幅在讲现货（元/公斤），而报告结论往往是盘面（元/吨）。** 现货与盘面在升水未收敛完时**方向相反**——「现货横着不动，盘面照样跌」。**口径未对齐就对比，会得出「我们和机构一样」或「完全相反」两种都是错的结论。**
3. **分三栏归位**：逐条把结论分为 ① **与共识一致**（＝已被定价，**无交易价值**，须显式标注）、② **与共识分歧**（＝潜在 alpha，须给出可检验的数字与证伪位）、③ **共识未覆盖**（＝报告独有的观察维度）。
4. **落到动作**：若核心方向与共识一致，**禁止据此给出方向性建仓建议**——一致预期已在价格中，此时建仓赚的是已被定价的钱，赔率极差。报告须显式写出这条推理链：**「方向一致 → 已被定价 → 无 alpha → 建议不动」**。

**输出物**：报告附录一节「与市场共识的对照」，至少含两张图——① 价格路径对照（本报告 vs 各流派预测）；② 关键位对照（本报告目标带 vs 各家给出的支撑/压力位）。

**禁止**：
- 禁止只写「与市场观点基本一致」而不列名单与数字——**没有名单的「一致」无法核查**。
- 禁止用「机构普遍认为」代替具体机构名与具体数字。
- 禁止因与共识一致而**提高**置信度（一致 ≠ 更可能正确，只意味着更可能已被定价）。
- ⚠️ 机构预测本身可能有错，**引用前须做常识校验**（2026-09-19 实测：某券商给出的四季度 16–19 元/公斤与当期现货 10.8 元/公斤严重背离，疑为旧年份或口径错配数据）。

**实测收益（2026-09-19 生猪 LH2611，P-20260919-001）**：该方法把「中性偏空」从「一个方向判断」降级为「一个**已被定价**的判断」，从而把仓位建议锁定为「不动·仅记录」，并识别出唯一真正的反共识点（远月四季度乐观出口：机构主流 12–13.5 元/公斤 vs 本报告 10.5–11.5 元/公斤）。**没有这一步，五类证据一致看空极易被误读为「应该做空」。**
