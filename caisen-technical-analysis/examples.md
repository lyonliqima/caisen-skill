# 蔡森形态学实战案例

> **⚠️ 独立性声明**：本文件仅用于演示如何识别和应用12种技术形态。其中的具体市场方向判断（做多/做空、目标价位等）是历史时点的观点，不是当前分析的答案模板。读取时只学习「形态识别步骤」，忽略所有方向性结论。

## 案例一：W底破底翻做多

### 走势描述

某股票从100元下跌至60元后反弹至80元，再跌至58元（略低于第一底60元），随后快速反弹至82元突破颈线80元。

### 分析过程

**第一步：识别形态**
- 第一次探底：60元
- 反弹高点（颈线）：80元
- 第二次探底：58元（破底翻变体W底）
- 第二底略低于第一底 → 形成**破底翻**

**第二步：画颈线**
- 颈线位置：80元（两底之间的反弹高点）

**第三步：量价验证**
- 第二底58元破底时带量（恐慌抛售）
- 翻回80元上方时量能温和（抛压已轻）
- 突破80元颈线时放量 → 有效突破

**第四步：测幅满足**
```
形态高度 = 80 - 58 = 22元
目标价 = 80 + 22 = 102元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：W底 + 破底翻
颈线位置：80元

【交易方向】做多

【进场条件】
- 第一买点：股价翻回80元上方时（82元进场）
- 第二买点（加码）：放量站稳80元上方3日确认

【止损设置】
- 跌破58元（底部最低点）止损
- 风险幅度：82 - 58 = 24元

【目标价位】
- 测幅满足：102元
- 预期获利：102 - 82 = 20元

【风险提示】
- 若翻回后再次跌破60元，破底翻失败
- 若突破颈线后缩量，可能是假突破

【盈亏比】20 / 24 ≈ 0.83（偏低，但胜率约70%可接受）
```

## 案例二：头肩顶假突破做空

### 走势描述

某股票从50元上涨至120元（左肩）回落至90元，再涨至150元（头部）回落至95元，第三次上涨至125元（右肩，低于头部），尝试突破前高150元失败，最高148元后快速回落跌破颈线。

### 分析过程

**第一步：识别形态**
- 左肩：120元
- 头部：150元（最高）
- 右肩：125元（低于头部）
- 右肩尝试突破150元但仅到148元 → **假突破**信号

**第二步：画颈线**
- 左肩回调低点：90元
- 头部回调低点：95元
- 颈线：从90元到95元的向上倾斜线

**第三步：量价验证**
- 左肩成交量大，头部更大，右肩明显缩量 → 上涨动能衰竭
- 假突破时量能虽大但价格未能有效创新高 → 出货信号
- 跌破颈线时放量 → 恐慌性抛售

**第四步：测幅满足**
```
形态高度 = 150 - 92.5（颈线中点） = 57.5元
目标价 = 92.5 - 57.5 = 35元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：头肩顶 + 假突破
颈线位置：90-95元（向上倾斜）

【交易方向】做空

【进场条件】
- 跌破颈线（约93元处）做空
- 反弹无法站回颈线上方时加码

【止损设置】
- 站回148元（假突破高点）上方止损
- 风险较大，需控制仓位

【目标价位】
- 第一目标：60元（颈线 - 形态高度的部分满足）
- 第二目标：35元（完全满足）

【风险提示】
- 若再次突破150元，头肩顶失败
- 跌破颈线后可能出现逃命波反弹
```

## 案例二点五：上升趋势颈线假突破（★实战截图案例）

> **对应截图**：`images/false-breakout-example.png`
> **类型**：非头肩/M头的**独立颈线假突破**——上升趋势中突破水平阻力位后立即反转

### 走势描述

某标的处于明确上升趋势，从100元以下一路上涨至130元附近遭遇紫色水平颈线（阻力位）压制。某日放量突破颈线，冲高至**142.350元**（超出颈线约8.3%），但紧接着出现大阴线大幅回落，价格直接跌回颈线下方至118元左右，从高点跌幅约17%。

### 分析过程

**第一步：识别形态**
```
这不是头肩顶或M头！
这是"上升趋势 + 水平阻力颈线 + 假突破"结构：

趋势背景：100 → 110 → 120 → 130（阶梯式上升）
关键颈线：紫色水平线 ~131-132元（多次测试的阻力位）
假突破动作：单根K线冲到142.350
反转信号：1-2根K线大阴线跌回118
```

**第二步：画颈线**
- 颈线位置：~131-132元（图中紫色水平线）
- 颈线性质：**水平阻力位**（非倾斜颈线）
- 触碰次数：至少2-3次测试（从K线排列可判断）

**第三步：量价验证**
- 突破时可能有量（诱多需要成交量配合）
- **但回落时更是大阴线带量** = 主力出货不是小出货
- 跌穿颈线的K线实体长、力度大 = 假突破确认

**第四步：测幅满足**
```
height = 假突破高点 - 颈线 = 142.350 - 131 ≈ 11.35

第一满足点 = 131 - 11.35 ≈ 119.65  ← 图中已接近此位置！
第二满足点 = 131 - 22.7 ≈ 108.3
止损点 = 142.350 × 1.03 ≈ 146.6

⚠️ 从图中可见价格已回落到~118，
   已接近或到达第一满足点119.65
```

**第五步：交易计划**
```
【形态分析结论】
标的：某标的（来自实战截图）
当前形态：上升趋势 + 水平颈线假突破
假突破高点：142.350
颈线位置：~131

【交易方向】做空（假突破确认后）

【进场条件】
- 第一空点：大阴线跌破颈线131时进场做空
- 第二空点：反弹无法站回131时加码做空

【止损设置】
- 止损价：146.6（142.350×1.03）
- 若价格再次站上142.350并站稳 → 假突破失败，止损

【目标价位】
- 第一目标（满足）：119.65（已接近）
- 第二目标（延伸）：108.3

【风险提示】
- 这是"突破幅度越大、跌得越狠"的典型案例
- 8.3%的突破幅度+17%的高点回落 = 极强假突破信号
- 若假突破失败（再创新高），必须严格止损

【盈亏比估算】
做空价≈130 / 止损146.6 / 目标119.65
风险=16.6点 / 获利=10.35点
盈亏比 ≈ 0.62（偏低但胜率80%+可接受）
若加码到第二空点132附近：
风险=14.6点 / 获利=12.35点 → 改善
```

### 关键学习要点

| 要点 | 本案例教训 |
|------|-----------|
| 不需要完整头部形态 | 有明确的水平阻力颈线即可判定假突破 |
| 突破幅度越大越危险 | 超出8%的突破后跌17%=主力蓄谋已久 |
| 回落速度是关键 | 1-2根K线内跌回 ≠ 正常回调 = 出货 |
| 大阴线贯穿颈线 | 不是温和回踩而是恐慌性下跌 |
| 接近第一满足点 | 图中价格~118 vs 第一满足~119.65 = 已基本到达 |

## 案例二点七五：上升趋势支撑线跌破（★实战截图·效率操作点）

> **对应截图**：`images/trendline-breakdown-example.png`
> **核心教学**：「点多的为主」画颈线 + 实体K线渲染 + 效率操作点

### 走势描述

某标的处于明确上升趋势，价格从低位一路上涨。在上涨过程中，每次回调的低点都落在一条**向上倾斜的绿色支撑线**上（"点多的为主"原则——这条线穿过了至少4个回调低点）。顶部区域有一条**黑色水平压力线**（87547/87500附近），价格多次测试未有效突破。最终在图表右侧，价格以大阴线方式**跌破绿色支撑线**，图中用**绿色圆圈**精确标记了跌破位置 = **效率操作点**。

### 关键价位

| 价位 | 含义 |
|------|------|
| **87547.00** | 前高压力区（黑色水平阻力线下沿） |
| **87500.00** | 另一个前高（接近87547） |
| **87054.00** | 回调低点之一，触碰绿色斜颈线 |
| **86251.00** | 更低的回调低点，触碰绿色斜颈线 |

### 分析过程

**第一步：渲染实体K线图**
```
必须先有完整的OHLCV蜡烛图：
- 蓝色K线 = 阴线（下跌）
- 绿色K线 = 阳线（上涨）
- 红色K线 = 强势下跌（可能）
- 每根K线的实体和影线都清晰可见

不能基于折线图或模糊印象画线！
```

**第二步：识别趋势结构**
```
趋势类型：上升趋势（ higher highs + higher lows ）
├── 低点递升：每个回调低点比前一个更高 → 上升趋势确认
├── 高点也在抬升：虽然未突破87547压力区
└── 支撑线：绿色斜线连接所有递升的低点

这不是头肩顶、不是M头、不是假突破
这是纯粹的「上升趋势支撑线跌破」
= 多头趋势的终结信号
```

**第三步：画颈线（"点多的为主"）**
```
画法核心：
1. 扫描所有K线的最低价(low)
2. 标记局部极值低点
3. 尝试不同的两点连线
4. 统计每条线±2%范围内的触碰次数
5. 选触碰最多的那条 = 绿色支撑线

本案例绿线特征：
- 穿过 ≥4 个明显低点（含86251、87054等标注位）
- 向上倾斜，角度约15-30°（健康趋势角度）
- 每次价格回落到绿线都反弹 → 支撑反复被验证
- 触碰越多 → 支撑越强 → 一旦跌破破坏力越大
```

**第四步：识别效率操作点（绿圈）**
```
效率操作点的判定：
□ 价格实体收盘跌破绿色支撑线（不是影线假刺穿）
□ 跌破时伴随较大力度（长阴线/连续阴线）
□ 跌破后价格远离支撑线（不是贴着线晃）
□ 这就是做空的最佳执行时机

为什么叫"效率操作"？
- 不提前预判（等真正跌破了才动）
- 不犹豫拖延（跌破瞬间就进场）
- 止损清晰（设在支撑线上方或前高处）
- 目标可算（测幅满足公式适用）

vs 散户常见错误：
- 提前猜测"快要跌了" → 可能过早进场被洗
- 跌破后犹豫"再看看" → 错过最佳进场价
- 没有止损计划 → 跌了就扛
```

**第五步：交易计划**
```
【形态分析结论】
标的：某标的（来自实战截图）
当前形态：上升趋势 + 斜向支撑线跌破
支撑线类型：绿色上升斜线（≥4个触点，极强支撑）
顶部压力：87547/87500（黑色水平线）

【交易方向】做空（多头趋势终结信号）

【效率操作点（进场条件）】
- K线实体收盘价跌破绿色支撑线
- 绿圈标注的位置就是进场点
- 不需等待二次确认（强支撑线首次跌破即可行动）

【止损设置】
- 方法A：止损设在绿色支撑线上方（如站回支撑则失败）
- 方法B：止损设在前一个高点87547上方
- 推荐方法A（更贴近实际跌破价，风险更小）

【目标价位】
- 测幅计算（参考）：
  height = 最高点(87547) - 跌破处颈线价格(估算)
  第一满足 = 跌破处颈线 - height
- 具体数值需根据完整数据计算

【关键学习要点】
1. 「点多的为主」→ 绿线穿过4+低点 = 极强支撑
2. 渲染实体K线后再画 → 不能凭感觉
3. 绿圈 = 效率操作点 → 跌破即执行
4. 上升趋势支撑线跌破 = 多头趋势终结的最明确信号之一
```

### 与其他案例的对比

| 维度 | 本案例（支撑线跌破） | 案例二点五（水平颈线假突破） |
|------|---------------------|---------------------------|
| 趋势背景 | 上升趋势中 | 上升趋势中 |
| 颈线类型 | **斜向支撑线**（绿色） | **水平阻力线**（紫色） |
| 触发事件 | 跌破支撑线 | 突破阻力后回落 |
| 操作方向 | 做空 | 做空 |
| 信号强度 | 极强（多次验证的支撑被破） | 强（诱多后反转） |
| 止损参考 | 支撑线上方 | 假突破高点上方 |

## 案例三：矩形底突破做多

### 走势描述

某股票在30-40元之间横盘震荡18个月，多次触及40元回落，多次触及30元反弹。最终某日放量突破40元。

### 分析过程

**第一步：识别形态**
- 下沿：30元（多次触及）
- 上沿：40元（多次触及）
- 横盘时间：18个月
- 形态：**矩形底**

**第二步：画颈线**
- 颈线 = 矩形上沿 = 40元

**第三步：量价验证**
- 横盘期间成交量逐渐萎缩（底部筑底）
- 突破40元当日成交量为近期2倍以上 → 有效突破
- 突破后连续3日站稳40元上方 → 确认突破

**第四步：测幅满足**
```
矩形高度 = 40 - 30 = 10元
目标价 = 40 + 10 = 50元
```
18个月的大级别矩形底，实际涨幅可能远超满足点。

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：矩形底（18个月大级别）
颈线位置：40元

【交易方向】做多

【进场条件】
- 突破40元站稳3日确认后进场
- 或回踩40元不破时进场

【止损设置】
- 跌回矩形内部（跌破38元）止损

【目标价位】
- 第一目标：50元（测幅满足）
- 第二目标：55-60元（大级别形态超额满足）

【风险提示】
- 若突破后快速跌回矩形内部，为假突破
- 横盘18个月的大底，突破后趋势通常较强
```

## 案例四：三角收敛后突破

### 走势描述

某股票从100元上涨至160元后开始整理：
- 第一个高点160元，低点120元
- 第二个高点150元，低点125元
- 第三个高点142元，低点130元
- 最终向上突破142元

### 分析过程

**第一步：识别形态**
- 高点递降：160 → 150 → 142
- 低点递升：120 → 125 → 130
- 形态：**三角收敛**（上升三角偏向）

**第二步：画颈线**
- 上轨：160 → 150 → 142（向下倾斜）
- 下轨：120 → 125 → 130（向上倾斜）

**第三步：量价验证**
- 整理期间成交量逐渐萎缩（正常）
- 突破上轨142元时放量 → 有效突破

**第四步：测幅满足**
```
三角形最宽处 = 160 - 120 = 40元
目标价 = 142 + 40 = 182元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：三角收敛（向上突破）
颈线位置：上轨142元

【交易方向】做多

【进场条件】
- 放量突破142元时进场
- 或突破后回测142元不破时进场

【止损设置】
- 跌回三角内部（跌破135元）止损

【目标价位】
- 测幅满足：182元

【风险提示】
- 三角收敛可能向任一方向突破
- 若突破后迅速回落至三角内部，为假突破
```

## 案例五：M头做空

### 走势描述

某股票从30元上涨至80元（第一顶）回落至60元，再涨至78元（第二顶，略低于第一顶）后开始回落。

### 分析过程

**第一步：识别形态**
- 第一顶：80元
- 回调低点（颈线）：60元
- 第二顶：78元（未能创新高）
- 形态：**M头**

**第二步：画颈线**
- 颈线 = 两顶之间的回调低点 = 60元

**第三步：量价验证**
- 第一顶成交量大，第二顶缩量 → 上涨动能不足
- 第二顶低于第一顶 → 多头力量衰减
- 跌破60元颈线时确认M头成立

**第四步：测幅满足**
```
形态高度 = 80 - 60 = 20元
目标价 = 60 - 20 = 40元
```

**第五步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：M头
颈线位置：60元

【交易方向】做空

【进场条件】
- 跌破60元颈线时做空
- 反弹60元附近无法站回时加码

【止损设置】
- 站回65元（颈线上方5元）止损

【目标价位】
- 测幅满足：40元

【风险提示】
```

## 案例六：大级别斜颈线头部做空（贯穿整个上涨结构）

### 走势描述

某股票从15.42元起涨，经历多波上涨：
- 起涨点：15.42元（上涨结构起点）
- 第一波上涨后回调低点：22.23元
- 第二波上涨后回调低点：22.78元
- 第三波上涨后回调低点（头部区域）：22.78元
- 头部高点：33.94元（最高局部顶部）

从起涨点到头部，所有回调低点（含起涨点本身）都在同一条向上倾斜的上升趋势线上。

### 分析过程

**第一步：识别形态**
- 起涨点：15.42元
- 回调低点A：22.23元
- 回调低点B：22.78元
- 回调低点C（头部区域）：22.78元
- 头部：33.94元（最高局部顶部）
- 所有低点在同一条斜线上 → **大级别斜颈线头部（贯穿整个上涨结构）**

**第二步：画颈线（关键：回溯到起涨点）**
- 不要只找"头部附近"的低点！
- 从起涨点15.42开始，连接22.23 → 22.78 → 22.78
- 画出贯穿整个上涨结构的上升趋势线（黑色斜线）= 颈线
- 总共4个触点（含起涨点），极强颈线

**第三步：测量形态高度**
```
头部最高价：33.94元
颈线在头部正下方价格：≈22.78元
形态高度 H = 33.94 - 22.78 = 11.16元（垂直距离）

注意：形态高度是垂直距离，不是沿斜线的距离
```

**第四步：跌破确认**
- 价格跌破颈线22.78元 → 头部确认
- 跌破时伴随放量 → 恐慌性抛售
- 跌破后反弹测试颈线（逃命波），但无法站回

**第五步：测幅满足（两波跌幅）**
```
第一满足点 = 颈线跌破点 - H = 22.78 - 11.16 = 11.62元
第二满足点 = 颈线跌破点 - 2H = 22.78 - 22.32 = 0.46元

实战验证：
  实际低点到达 ~11.62元（第一满足点精准触及）
  → 形态高度H = 头部到颈线距离 = 跌破后跌幅（精确验证）
  → 两波跌幅满足：第一波从22.78跌到11.62，跌幅=11.16=H
```

**第六步：交易计划**
```
【形态分析结论】
标的：某股票
当前形态：大级别斜颈线头部（贯穿整个上涨结构）
颈线位置：22.78元（上升趋势线）
触点数量：4个（含起涨点）→ 极强颈线

【交易方向】做空

【进场条件】
- 跌破颈线22.78元时做空（第一进场点）
- 反弹测试颈线无法站回时加码（第二进场点）

【止损设置】
- 站回33.94元（头部高点）上方止损
- 或站回颈线22.78元上方3日确认时止损

【目标价位】
- 第一满足点：11.62元（基本测幅，到达后可能反弹整理）
- 第二满足点：0.46元（延伸测幅，跌势尾声）

【量价观察要点】
- 跌破颈线时是否放量（放量=恐慌抛售，确认度高）
- 反弹测试颈线时是否缩量（缩量=无力回弹，空头延续）
- 到达第一满足点后是否出现止跌信号

【风险提示】
- 极强颈线（4个触点），跌破后跌幅力度大
- 到达第一满足点11.62后可能出现反弹，不宜追空
- 大级别头部，下跌时间可能较长
```

### 核心教训

1. **颈线不只画在头部附近**：要从起涨点开始扫描所有回调低点，找到"穿过最多点"的斜线
2. **贯穿整个上涨结构的颈线 = 极强颈线**：4个触点 > 3个触点 > 2个触点，触点越多跌破后力度越大
3. **形态高度 = 垂直距离**：从头部垂直量到颈线，不是沿斜线量
4. **测幅满足精确验证**：头部到颈线的距离 = 跌破后的跌幅，这是蔡森形态学最核心的公理

## 常见错误与注意事项

### 错误一：形态未确认就提前进场
- **错误做法**：W底还在形成中就买入
- **正确做法**：等突破颈线确认后再进场

### 错误二：忽略量价配合
- **错误做法**：缩量突破颈线就追进
- **正确做法**：突破颈线需放量确认

### 错误三：不设止损
- **错误做法**：破底翻失败后死扛
- **正确做法**：跌破底部低点立即止损

### 错误四：过度交易
- **错误做法**：每天都找形态操作
- **正确做法**：只在形态明确时操作，宁可错过不可做错

### 错误五：忽视大周期
- **错误做法**：只看日线形态
- **正确做法**：先看月线/周线大趋势，再看日线找买点

### 错误六：做期权卖方
- **错误做法**：卖Call或卖Put收取权利金
- **正确做法**：只做买方（买Call或买Put），风险有限收益无限
- **案例**：台股大跌时卖权一口拉到涨停板，成交仅两口就是卖方被断头

### 错误七：用本益比判断贵便宜
- **错误做法**：看到AI股本益比20-30倍就认为便宜
- **正确做法**：底部出现在本益比最高（亏损时），高点出现在本益比最低（获利最好时）
- **案例**：南亚科底部时EPS亏损本益比无法算，涨到高位时本益比才10倍

## 案例十七：台股60分钟线假突破 + 去感情化实战（百度网盘直播）

### 走势描述

台股台指期60分钟线，出现小波段高点破线。盘中破了颈线，但收盘没收破。

### 分析过程

```
Step 1：60分钟线破线观察
  - 小波段高点胜率法 → 60分钟线破线
  - 盘中破了颈线 → 看起来要跌2000点

Step 2：收盘确认（关键！）
  - 盘中破了 → 追空
  - 但收盘没收破 → 假突破
  - 「深哥已经跟你讲过看收盘，你盘中破了你又没看收盘」

Step 3：假突破 = 反向信号
  - 假突破向上破线 → 其实是做多信号
  - 追空者被弹起来洗掉
  - 停损点设在颈线 → 严格执行
```

### 核心要点

- **看收盘，不看盘中** —— 这是小波段高胜率法的核心纪律
- 感情用事（盘中追空）= 被假突破洗掉
- 「失败不要找理由，不是深哥的工具无懈可击」
- 50%觉得好用，30%用得上但无法完全掌握，20%完全无法使用
- 免费的最贵（小波段高胜率法是免费送的，但很多人用不好）
