## 颜色系统

- 黑色水平线: 颈线(最重要的支撑/阻力线)
- 红色水平线: 跌破确认线/危险位
- 绿色水平线: 目标满足线(测幅满足目标价)
- 紫色水平线: 辅助参考线(前高/前低/次要支撑阻力)
- 紫色虚线矩形: 整理区域框选(矩形底/箱体整理区间)
- 红色箭头: 突破方向/关键转折点指示
- 红色圆圈: 重要价格转折点标记
- "+" 标记: 建议进场位置
- "X" 标记: 形态失败/止损位置
- 蓝色竖线: 测量形态高度(用于计算满足点)
- 数字标注: 所有关键位置的具体价格

## 各形态的划线示范

### 一、W底(双底)划线

划线顺序:
1. 黑色水平线画在两底之间的反弹高点(颈线)
2. 标注"第一底"和"第二底"的价格
3. 蓝色竖线从底部量到颈线,标注高度数值
4. 绿色水平线画在颈线上方等距处(满足点)
5. 红色箭头指向突破颈线的K线
6. "+"标记在突破点或回踩确认点

### 二、头肩底划线

划线顺序:
1. 连接左肩反弹高点和头部反弹高点,画出倾斜颈线(黑色)
2. 标注"左肩""头部""右肩"
3. 蓝色竖线测量头部到颈线的垂直距离
4. 绿色水平线标注满足点
5. 红色箭头指向突破颈线处
6. "+"标记进场点

### 三、M头(双顶)划线（详细版·含两波跌幅满足）

划线顺序（蔡森实战教学完整流程）:

**第1步：标注两个顶部结构点**
- 在K线图上识别并标注两个局部顶部：
  - "第一顶"（左顶）：第一波上涨的高点
  - "第二顶"（右顶）：第二波上涨的高点（与第一顶接近或略低，差值≤5%）
- 第二顶可以略高于第一顶（形成假突破变体）
- 每个点旁标注具体价格数字

**第2步：画颈线（核心）**
- 找到两顶之间的回调最低点（谷底）= 颈线位置
- 在谷底价位画水平线（红色水平线 #e74c3c）
- 蔡森原则：颈线触碰低点次数越多越有效（≥2次有效，≥3次强效）
- 若谷底附近有多个接近的低点，选择触碰次数最多的价位
- 在颈线旁标注价格数字

**第3步：测量形态高度（蓝色竖线）**
- 从较高的顶部向下画蓝色竖线（#4a9eff）到颈线
- 标注高度数值 H = max(顶1, 顶2) - 颈线价格
- 这条竖线就是"形态高度"，用于后续投射

**第4步：标注"破线"位置**
- 在价格跌破颈线的K线处，画红色向下箭头
- 标注"破线"文字
- 蔡森铁律：跌破颈线不需要放量确认（下跌不需要量）
- 跌破后不能再站回颈线上方，否则形态失败

**第5步：投射两波跌幅满足目标（绿色水平线）**
- **第一目标（基本测幅满足）**：
  - 从颈线向下投射 H（形态高度）
  - 第一满足点 = 颈线价格 - H
  - 画绿色水平线（#2ed573），标注"满足点1 XXX"
- **第二目标（延伸测幅满足）**：
  - 从颈线向下投射 2H（两倍形态高度）
  - 第二满足点 = 颈线价格 - 2H
  - 画绿色虚线水平线，标注"满足点2 XXX"
- 用蓝色竖线标注投射距离

**第6步：标注进出场位置**
- "+" 标记在跌破颈线处（做空进场点）
- "X" 标记在第二顶高点上方（止损点）
- 止损价 = max(顶1, 顶2) × 1.03（+3%缓冲）

**M头画线教学数值示范**（蔡森手绘教学图）:
```
       第一顶(110)          第二顶(105)
        /\                   /\
       /  \                 /  \
      /    \               /    \
     /      \             /      \
    /        \___80______/        \
    第一波跌幅=30  (谷底/颈线)      \ ← 破线
                                   \
                                    55 ←─ 第一波下跌途中
                                     \
                                      50 ←── 第一满足点（绿色水平线）
                                       \
                                        20 ←── 第二满足点（绿色虚线）
```

数值:
- 第一顶: 110
- 第二顶: 105（略低于第一顶）
- 谷底/颈线: 80（红色水平线）
- 第一波跌幅 = 110 - 80 = 30

计算（两波跌幅满足）:
```
形态高度 H = 110 - 80 = 30

第一波跌幅满足（基本测幅）:
  第一满足点 = 颈线 - H = 80 - 30 = 50
  蓝色竖线距离 = 30

第二波跌幅满足（延伸测幅）:
  第二满足点 = 颈线 - 2H = 80 - 60 = 20
  蓝色竖线距离 = 60
```

两波跌幅满足原则:
- 第一波：从破线到第一满足点（50），跌幅 = H = 30
- 第二波：从第一满足点继续延伸到第二满足点（20），再跌 H = 30
- 两波跌幅等距（都是30），即"两波跌幅满足"
- 到达第一满足点后，可能出现反弹整理 → 不宜追空
- 到达第二满足点后，跌势大概率进入尾声

**实战K线图示范要点**（蔡森实际标的分析·微软MSFT）:
```
第一顶高点标注具体价格（如 ~351.836）
谷底/颈线标注价格（如 ~340.400）
绿色垂直箭头 = 形态高度测量（顶→颈线）
黑色水平线 = 颈线（连接谷底低点）
绿色水平线 = 满足目标位（颈线下方等距投射）
绿色双向箭头 = 总下跌空间（颈线→满足点）

注意：
  跌破颈线后反弹到颈线 = 逃命波（右侧逃命信号）
  颈线反弹量慢慢出来 = 法人出货陷阱，不是买盘
```

### 四、头肩顶划线（详细版·含两波跌幅满足）

划线顺序（蔡森实战教学完整流程）:

**第1步：标注三个顶部结构点**
- 在K线图上识别并标注三个局部顶部：
  - "左肩"：第一波上涨的高点
  - "头部"：中间最高点（必须是三者最高）
  - "右肩"：第三波上涨的高点（低于头部，与左肩大致对称，差值≤8%）
- 每个点旁标注具体价格数字

**第2步：画颈线（核心·点多的为主）**
- 找到左肩→头部之间的回调低点（左谷）
- 找到头部→右肩之间的回调低点（右谷）
- **蔡森核心原则："点多的为主"——触碰次数最多的价位连线就是正确颈线**
- 若左谷附近有多个K线低点触及同一价位（如多次回踩同一水平）→ 该价位为强效颈线
- 若右谷附近同样有K线低点触及相同价位 → 多点共振，颈线极强
- 连接所有触碰点，画出颈线（黑色水平线/微倾斜线）
- 颈线倾斜角度 ≤ 15° 才有效；超过15°形态失效
- 若多个触碰点价格接近（差值≤3%），画水平线
- 在颈线旁标注价格数字 + 触碰次数

**多点颈线实战示范**（蔡森实战K线图）:
```
头肩顶多点颈线画线实例：

左肩区域：多个K线低点回踩价位 A（如 3 根K线触及）
头部区域：回调时低点再次触及价位 A（如 2 根K线触及）
右肩区域：回调时低点又触及价位 A（如 2 根K线触及）

总共 7 个触点都在价位 A 附近
→ "点多的为主" → 价位 A 就是颈线（水平线）
→ 极强颈线（≥4次触碰），跌破后力度更大

蔡森标注法：
  绿色水平线 = 顶部阻力线（头部高点向右延伸）
  黑色水平线 = 颈线（多点触碰的支撑位）
  绿色垂直箭头 = 形态高度测量（头→颈线）
  绿色水平线（下方） = 满足目标位
```

**水平线 vs 斜线的选择**：
- 若多个低点都在同一价位附近 → 水平线（"最漂亮""最正确"——蔡森原话）
- 若只有两个低点且差距较大 → 斜线（但角度必须≤15°）
- 若有斜线趋势线+水平颈线同时存在 → 以触碰次数多的水平线为颈线
- 斜线可作为辅助参考线（趋势线），但不是颈线

**第3步：测量形态高度（蓝色竖线）**
- 从头部最高点向下画蓝色竖线（#4a9eff）到颈线
- 标注高度数值 H = 头部价格 - 颈线价格
- 这条竖线就是"形态高度"，用于后续投射

**第4步：标注"破线"位置**
- 在价格跌破颈线的K线处，画红色向下箭头
- 标注"破线"文字
- 蔡森铁律：跌破颈线不需要放量确认（下跌不需要量）
- 跌破后不能再站回颈线上方，否则形态失败

**第5步：投射两波跌幅满足目标（绿色水平线）**
- **第一目标（基本测幅满足）**：
  - 从颈线向下投射 H（形态高度）
  - 第一满足点 = 颈线价格 - H
  - 画绿色水平线（#2ed573），标注"满足点1 XXX"
- **第二目标（延伸测幅满足）**：
  - 从颈线向下投射 2H（两倍形态高度）
  - 第二满足点 = 颈线价格 - 2H
  - 画绿色虚线水平线，标注"满足点2 XXX"
- 用蓝色竖线标注投射距离

**第6步：标注进出场位置**
- "+" 标记在跌破颈线处（做空进场点）
- "X" 标记在右肩高点上方（止损点）
- 止损价 = 右肩高点 × 1.03（+3%缓冲）

### 五、破底翻划线（详细版·含小型破底翻实战）

划线顺序（蔡森实战教学完整流程）:

**第1步：识别整理区并画两条颈线**
- **第一条颈线（底部支撑线）**：整理区下缘支撑位
  - 黑色水平线画在底部支撑位
  - 蔡森强调：破底翻必须画出两条颈线
- **第二条颈线（整理区上缘突破线）**：整理区上缘压力位
  - 紫色水平线/黑色水平线标注
  - 突破此线 = 主力发起猛攻 = 加码点
  - 突破时必须配合放量（量 > 前5日均量 × 1.3）
- 用紫色虚线矩形框选整个整理区间

**第2步：标注"破线跌破"位置**
- 红色向下箭头指向破底K线
- 标注"破線跌破"文字
- 蔡森铁律：跌破不需要放量确认（下跌不需要量）
- 跌破后必须快速翻回，否则形态失败

**第3步：标注"翻回"位置**
- 红色向上箭头指向翻回K线
- 标注"翻回"文字
- 翻回 = 股价重新站上支撑线
- 翻回时成交量应放大确认

**第4步：标注进出场位置**
- "+" 标记在翻回支撑线上方（进场点1）
- "X" 标记在前低下方（止损点，破前低即认错）
- 第二个加码点：突破整理区上缘时（进场点2）

**第5步：标注满足目标**
- 绿色水平线标注测幅满足目标
- 蓝色竖线测量形态高度

**破底翻(W底)经典教学示范**（蔡森教学图）：
```
形态结构：
  第一个底（左谷）：~30
  第二个底（右谷/破底）：~28.5（标注"破底"，比第一底更低）
  W底中间的反弹高点
  颈线：~45（红色水平线，标注"頸線"）
  反弹小高点：32, 32.1

破底翻过程（5步）：
  Step 1：价格下跌到30（第一个底）
  Step 2：反弹后再跌到28.5（第二底破底，比第一底低）
  Step 3：反弹到32/32.1附近，标注"破底翻止穩確立買點"
           （蓝色圆圈 = 确认买入点1）
  Step 4：继续上涨突破颈线45，标注"突破頸線加碼訊號"
           （空心圆圈 = 加码买入点2）
  Step 5：黑色箭头指向右上方 = 持续上涨趋势

画线标注：
  红色水平线 = 颈线45
  红色水平线 = 破底低点区域
  蓝色圆圈 = 破底翻止穩確立買點(~32)
  空心圆圈 = 突破頸線加碼訊號(45上方)
  黑色箭头 = 持续上涨方向

两个买点（蔡森核心）：
  买点1："破底翻止穩確立買點"（轻仓）
    位置：破底(28.5)后反弹到~32
    信号：蓝色圆圈标注
    含义：第二只脚破底后不再创新低 + 反弹确认 = 止穩
  买点2："突破頸線加碼訊號"（加码）
    位置：突破颈线45
    信号：空心圆圈标注
    含义：突破颈线 = W底形态确认 = 主升浪启动

测幅满足计算：
  H = 颈线 - 破底低点 = 45 - 28.5 = 16.5
  满足目标 = 颈线 + H = 45 + 16.5 = 61.5
  止损 = 前低 30 下方（破前低即认错，不锼定破底最低点28.5）

操作策略：
  进场点1：破底翻止穩確立買點(~32)（轻仓）
  加码点2：突破颈线45（放量确认）
  止损：跌破 30（前低，破前低即认错）
  目标价：~61.5
```

**小型破底翻实战示范**（蔡森教学K线图）：
```
形态结构：
  前期高点：~17.15
  整理区间：紫色虚线框选（约 14.80 ~ 17.15）
  破底低点：~14.80（跌破整理区下缘）
  黑色水平线 = 破底翻第一条颈线（支撑线）

破底翻过程：
  Step 1：价格跌破支撑线 14.80（红色向下箭头，"破線跌破"）
  Step 2：快速翻回站上支撑线（红色向上箭头，"翻回"）
  Step 3：继续上涨突破前高 17.15 → 新高点 17.30
  Step 4：突破整理区上缘（紫色箭头，"突破"）

画线标注：
  黑色水平线 = 14.80（第一条颈线/支撑线）
  紫色虚线框 = 整理区间
  红色向下箭头 = 破线跌破
  红色向上箭头 = 翻回
  紫色箭头 = 突破整理区上缘
  绿色箭头 = 全程循环（17.15 → 14.80 → 17.30）

两条颈线：
  第一条：14.80（底部支撑线）→ 跌破 = 洗盘，翻回 = 确认
  第二条：~17.15（整理区上缘）→ 突破 = 主升浪启动

操作策略：
  进场点1：翻回支撑线时（轻仓）
  加码点2：突破整理区上缘时（放量确认）
  止损：跌破 14.80（破底最低点）
```

**大型 vs 小型破底翻的区别**：
```
大型破底翻：                小型破底翻：
  整理时间 ≥ 3个月            整理时间 1~3个月
  破底幅度较深                 破底幅度较浅
  突破后涨幅更大               突破后涨幅适中
  更适合大资金布局             更适合短线操作

共同特征：
  □ 都有两条颈线（支撑线 + 整理区上缘）
  □ 都需要破底后翻回确认
  □ 翻回时都需要放量
  □ 突破整理区上缘 = 加码信号
```

### 六、假突破划线（详细版·含头肩顶假突破教学）

划线顺序（蔡森教学完整流程）:

**第1步：识别头部形态并画颈线**
- 识别头肩顶/M头结构
- 红色水平线画在前高位置（阻力线）
- 黑色水平线画在两顶之间的回调低点（颈线）
- 蔡森强调：颈线连接左右两个谷底（可以是水平线或微倾斜线）

**第2步：标注假突破位置**
- 红色圆圈标注假突破的高点（突破前高后无法维持）
- 标注"假突破"文字
- 假突破 = 价格突破前高但快速回落
- 蔡森原话："假突破是主力刻意拉高吸引追高散户的陷阱"

**第3步：标注假突破确立位置**
- 股价跌回颈线下方 = 假突破确立
- 标注"跌落頸線下假突破確立賣出訊號"
- 这是第一个做空进场点

**第4步：标注跌破颈线加码点**
- 红色箭头指向回落跌破方向
- "+"标记在跌破颈线处（做空进场点）
- 标注"跌破頸線空單加碼訊號"
- 这是第二个加码做空点

**第5步：标注止损位置**
- "X"标记在假突破高点上方（止损点）

**第6步：标注满足目标**
- 绿色水平线标注测幅满足目标
- 蓝色竖线测量形态高度

**假突破（头肩顶）教学示范**（蔡森教学图）：
```
形态结构：
  左肩高点：~90（标注"突破"，价格短暂突破后回落）
  头部高点：~95（标注"假突破(頭肩頂)"）
  颈线：~70（红色水平线，标注"頸線"）
  左谷：~68
  右谷：~72

颈线画法：
  连接左谷(68)和右谷(72)的连线 → 微倾斜的颈线
  颈线从68向右上延伸到72（因为右谷略高于左谷）

假突破过程：
  Step 1：价格上涨突破前高到95（红色圆圈，"假突破"）
  Step 2：价格快速回落到颈线下方
  Step 3："跌落頸線下假突破確立賣出訊號" = 确认卖出
  Step 4：继续下跌跌破颈线到72（红色圆圈，"跌破頸線空單加碼訊號"）
  Step 5：大黑箭头向下 = 确认空头趋势

画线标注：
  红色水平线 = 前高阻力位（~90）
  红色水平线 = 颈线（~70）
  红色圆圈 = 假突破点(95)和跌破确认点(72)
  大黑箭头 = 空头确认方向

操作策略：
  进场点1：假突破后跌回颈线下方（轻仓做空）
  加码点2：跌破颈线到72时（加码做空）
  止损：假突破高点95上方
  目标价：形态高度 H = 95 - 70 = 25，目标 = 70 - 25 = 45
```

**假突破 vs 真突破的识别**：
```
假突破特征：                    真突破特征：
  突破时缩量或量价背离            突破时明显放量
  突破后迅速回落到阻力下方       突破后站稳阻力上方
  突破K线长上影线              突破K线实体收盘
  头部形态（M头/头肩顶）         底部形态（W底/头肩底）
  不需要放量确认                需要放量确认
```

**假突破的三种变体**：
```
变体1：M头假突破
  第二个顶略高于第一个顶后回落
  跌破颈线确认

变体2：头肩顶假突破（本次教学）
  头部创新高后无法维持
  右肩反弹无法创新高
  跌破颈线确认

变体3：前高假突破
  突破历史高点后迅速回落
  最经典的假突破场景
```

### 六、波段跌幅满足 + 上飘旗形

蔡森核心规则：**“跌破前低才能确定前高，是高點才能计算跌幅满足”**。

**教学数值示范**：
```
第一波下跌：
  高点 = 90
  下跌至 = 70（第一波低点）
  反弹至 = 75（形成上飘旗形上沿）

上飘旗形：
  旗形上沿 = 75
  旗形下沿/颈线 = 70
  旗形高度 = 75 - 70 = 5
  ⚠️ 必须跌破70（前低）才能确认75是高點
  ⚠️ 确认75是高點后才能计算跌幅满足

第二波下跌（跌破旗形后）：
  跌幅满足目标 = 70 - (90 - 70) = 70 - 20 = 50
  蓝色竖线标注：从70向下量 20 = 50

第三波延伸：
  若继续下跌，从 50 再投射旗形高度或波段高度
  可至 50 - 5 = 45 或更低
```

**画线步骤**：
1. 标注波段高点（90）→ 第一波低点（70）
2. 标注上飘旗形：用红色斜线画出旗形上下沿（75→70）
3. 标注“跌破颈线”位置（跌破70）
4. 蓝色竖线从70向下量出波段高度（20）→ 目标50
5. 绿色水平线标注跌幅满足目标位
6. 标注关键蔡森原话：“跌破前低70才能確定75是高點”

**核心逻辑**：
```
上飘旗形 = 下跌中继形态
  ↓
旗形下沿被跌破 = 确认下跌继续
  ↓
跌幅满足 = 前一波段高度 等距投射
  ↓
满足点 = 旗形下沿 - (前高 - 旗形下沿)
```

### 七、三角形头部跌幅满足

蔡森规则：**“三角形需在1/2至3/4处跌破才算有效跌破”**。

**教学数值示范**：
```
三角形结构：
  头部高点 = 80
  三角形底部（颈线） = 60
  三角形高度 H = 80 - 60 = 20

有效跌破条件：
  跌破位置必须在三角形的 1/2 到 3/4 处
  1/2处 = 60 + 20×1/2 = 70
  3/4处 = 60 + 20×3/4 = 75
  → 即在 70~75 区间跌破才算有效
  → 太早跌破（靠近头部）= 不算三角形
  → 太晚跌破（靠近尖端）= 力度太弱

破线位置：~65（在有效区间内）

跌幅满足计算：
  第一满足点 = 60 - 20 = 40
  第二满足点 = 60 - 40 = 20
  实战：65→45（第一波跌20）→25（第二波再跌20）
```

**画线步骤**：

6. 从颈线60向下投射H=20 → 满足点40

### 八、W底涨幅满足计算

蔡森核心公式：**底部至颈线的距离 = 突破颈线后的等幅距离**。

**教学数值示范**：
```
W底结构：
  第一底 = 15
  双底（第二底）= 13（稍低于第一底）
  颈线（两底之间的反弹高点）= 19

涨幅计算：
  H = 颈线 - 底部 = 19 - 13 = 6
  第一满足点 = 颈线 + H = 19 + 6 = 25
  第二满足点 = 颈线 + 2H = 19 + 12 = 31

实战示范值：
  突破点 ≈ 18~19
  第一波上涨至 23
  继续上涨至 28（接近第二满足点附近）
```

**画线步骤**：
1. 标注“第一底”（15）和“第二底/双底”（13）
2. 红色水平线画在颈线位置（19）
3. 蓝色竖线从底部（13）量到颈线（19），标注 H=6
4. 标注“突破”位置（价格站上颈线）
5. 绿色水平线标注第一满足点（19+6=25）
6. 绿色虚线标注第二满足点（19+12=31）
7. 标注蔡森公式：“底部至颈线的距离 = 突破后的等幅距离”

**与头部形态的对称关系**：
```
W底（做多）                 M头（做空）
───────────────────────────────────
底部至颈线 = H              顶部至颈线 = H
突破颈线 +H = 第一满足      跌破颈线 -H = 第一满足
突破颈线 +2H = 第二满足     跌破颈线 -2H = 第二满足
```

```
  H = 颈线 - 底部 = 19 - 13 = 6
  第一满足点 = 颈线 + H = 19 + 6 = 25
  第二满足点 = 颈线 + 2H = 19 + 12 = 31

实战示范值：
  突破点 ≈ 18~19
  第一波上涨至 23
  继续上涨至 28（接近第二满足点附近）
```

**画线步骤**：
1. 标注"第一底"（15）和"第二底/双底"（13）
2. 红色水平线画在颈线位置（19）
3. 蓝色竖线从底部（13）量到颈线（19），标注 H=6
4. 标注"突破"位置（价格站上颈线）
5. 绿色水平线标注第一满足点（19+6=25）
6. 绿色虚线标注第二满足点（19+12=31）
7. 标注蔡森公式："底部至颈线的距离 = 突破后的等幅距离"

**与头部形态的对称关系**：
```
W底（做多）                 M头（做空）
───────────────────────────────────
底部至颈线 = H              顶部至颈线 = H
突破颈线 +H = 第一满足      跌破颈线 -H = 第一满足
突破颈线 +2H = 第二满足     跌破颈线 -2H = 第二满足
突破需放量                  跌破不需量
```

## 实战划线注意事项

### 颈线画法（核心·网上补充强化）

#### 颈线的本质定义（蔡森原话）
蔡森: "从我踏进市场到现在，都依赖颈线为主。" 颈线 = 某段区间内的压力或支撑线。

**区间选取**：
- 标准区间 = 3个月到半年（约60~120个交易日）
- 做空看支撑颈线: 区间内**最低的2个或以上价位**连线
- 做多看压力颈线: 区间内**最高的2个或以上价位**连线

#### 颈线触点效力原则（最重要·"点多的为主"）
**颈线碰触到的低点/高点价位次数越多，支撑/阻力效果越强。**
- 触碰2次 = 有效颈线（最低要求）
- 触碰3次 = 强效颈线
- 触碰4次以上 = 极强颈线，突破/跌破后力度更大
- **画线时必须选择触碰次数最多的点位连线，而非随意取两个点**

**头肩顶多点颈线实战要点**：
- 左肩、头部、右肩之间的回调低点如果都触及同一价位 → 该价位就是颈线
- 多个K线的影线低点反复触碰同一水平 → 极强颈线
- 此时必须画水平线（不是斜线），因为多点价位一致
- 蔡森原话："横的平的，零角度的平的横线""最漂亮""最正确"
- 若同时存在斜线趋势线+水平颈线 → 以触碰次数多的水平线为颈线，斜线仅作辅助参考

#### 线条类型选择
- 水平颈线: 两个（或多个）点位价格接近时画水平线
- 倾斜颈线: 两个点位差距较大时画倾斜线（头肩底/顶的颈线通常微倾斜）
- 倾斜颈线角度 ≤ 15° 才有效；超过 15° 形态失效
- 颈线应使用较粗线条，表示这是最重要的参考线

#### 颈线突破/跌破的铁律
**突破后不能再跌破，跌破后不能再站回。**
- 突破颈线后跌回 = 形态失败，立即止损
- 跌破颈线后站回 = 形态失败，空头止损
- 角色转换: 突破后的原压力颈线 → 新支撑；跌破后的原支撑颈线 → 新压力

#### 破底翻的"两条颈线"画法（蔡森强调）
破底翻必须画出**两条颈线**：
1. **第一条颈线（底部支撑线）**: 整理区下缘支撑位
   - 灰色虚线标注破底前支撑，橙色虚线标注破底翻确认
2. **第二条颈线（整理区上缘突破线）**: 整理区上缘压力位
   - 突破此线 = 主力发起猛攻 = 加码点
   - 突破时必须配合放量（量 > 前5日均量 × 1.3）
   - 突破后绝对不能再跌破此线

#### 颈线突破实战示范（向上突破·底部形态）

**实战案例：京东方A（日线）**
```
形态结构：
  长期盘整 → 价格反复在颈线下方运行
  颈线 = 黑色水平线（连接多个高点/压力位）
  颈线下方：多根K线在颈线下方反复测试（多次回踩）
  颈线下方低点：~3.53
  突破点：价格放量突破颈线，站稳颈线上方
  突破后：连续阳线大幅拉升
  突破后高点：~7.18

画线要点：
  1. 识别底部整理区域的多个高点
  2. 连接这些高点画出压力颈线（黑色水平线）
  3. 用"点多的为主"原则：触碰次数最多的高点价位就是颈线
  4. 突破颈线时标注红色向上箭头
  5. 突破后标注"突破"文字
  6. 标注突破后涨幅空间

向上突破的铁律：
  □ 突破颈线必须放量确认（量 > 前5日均量 × 1.3）
  □ 突破后不能再跌破颈线（跌破 = 形态失败，立即止损）
  □ 角色转换：突破后的原压力颈线 → 新支撑
  □ 回踩颈线不破 = 确认突破有效 = 加码点
  □ 蔡森原话："最有效率的操作是找到突破点和跌破点"

与头部形态的区别：
  头部形态（M头/头肩顶）→ 跌破颈线（向下）→ 不需要放量
  底部形态（W底/头肩底）→ 突破颈线（向上）→ 必须放量确认
```

**实战案例：韩国KOSPI指数（周线）**
```
形态结构：
  长期盘整 → 价格在颈线下方反复运行
  颈线 = 黑色水平线（连接整理区多个低点）
  红色圆圈 = 突破点（价格放量站上颈线）
  突破后：连续阳线大幅拉升
  突破后高点：~9385.59
  紫色水平线 4042.77 = 前期压力位/目标位
  涨幅：~177.91%

蔡森画线要点：
  1. 周线级别的颈线同样适用"点多的为主"原则
  2. 颈线触碰次数越多 → 突破后力度越大（KOSPI涨幅惊人）
  3. 周线突破比日线更可靠（时间周期越大，信号越强）
  4. 标注突破点（红色圆圈）+ 前压力位（紫色水平线）+ 涨幅百分比
  5. 蔡森方法论通用性：个股、指数、不同时间周期都适用相同的画线原则

多周期应用总结：
  日线突破颈线 → 短期做多信号
  周线突破颈线 → 中期做多信号（更可靠，涨幅更大）
  月线突破颈线 → 长期做多信号（最可靠，超级行情）
```

#### 平台跌破实战示范（向下跌破·头部形态）

**实战案例（蔡森教学K线图）**：
```
形态结构：
  价格先在高位整理形成平台
  平台顶部：~75.82（第一峰）→ ~75.08（第二峰）
  平台底部 = 黑色水平线（连接多个低点，"点多的为主"）
  平台内回调低点：~58.15、~53.57、~52.07
  黑色水平线 ≈ 52~58 区域（多个低点触碰，强效颈线）

跌破过程：
  价格从平台 ~52.07 处有效跌破黑色水平线
  红色向上箭头标注跌破位置（“破线”）
  跌破后第一波目标：~39.50（标注“1”）
  跌破后继续下跌：~25.63（最低点）
  绿色虚线框 = 标记跌破后的主跌段

画线要点：
  1. 识别头部整理平台的多个低点
  2. 用"点多的为主"原则画出平台底部支撑线（黑色水平线）
  3. 平台内多次触碰同一价位 → 极强颈线（≥4次触碰）
  4. 跌破时标注红色箭头 + "破线"文字
  5. 绿色虚线框标注跌破后的主跌段范围
  6. 标注跌破后各波目标位（39.50、25.63）

平台跌破的铁律：
  □ 跌破颈线不需要放量确认（下跌不需要量——蔡森铁律）
  □ 跌破后不能再站回颈线上方（站回 = 形态失败，空头止损）
  □ 角色转换：跌破后的原支撑颈线 → 新压力（反弹到颈线 = 逃命波）
  □ 触碰次数越多的颈线 → 跌破后跌幅越大
  □ 平台整理时间越长 → 跌破后下跌空间越大

测幅满足计算：
  平台高度 H = 平台顶部 - 平台底部（颈线）
  H = 75.08 - 52.07 ≈ 23
  第一满足点 = 52.07 - 23 = ~29（接近实际低点 25.63）
  第二满足点 = 52.07 - 46 = ~6（若继续下跌）
```

**平台跌破 vs 颈线突破对照**：
```
平台跌破（向下）              颈线突破（向上）
───────────────────────────────────────
头部形态（M头/头肩顶）          底部形态（W底/头肩底）
跌破颈线不需要放量              突破颈线必须放量
跌破后不能再站回              突破后不能再跌破
支撑颈线 → 新压力              压力颈线 → 新支撑
做空进场点                    做多进场点
逃命波=反弹到颈线               回踩颈线不破=确认有效
```

### 价格标注
- 所有关键转折点都要标注具体价格
- 颈线位置标注在水平线右侧
- 满足点标注"满足"文字

### 箭头使用
- 红色向上箭头: 突破颈线、翻回支撑等做多信号
- 红色向下箭头: 跌破颈线、假突破回落等做空信号
- 关键信号用大箭头，放在信号K线旁边

### 成交量标注
- 突破日的成交量柱标注"放量突破"
- 缩量回调区域标注"缩量健康"
- 天量/地量位置特别标注
- **量价是所有指标的最先行指标**（蔡森原话）: 任何技术指标都是滞后的，只有量价是第一手的；形态再好，没有量价配合就是假的

### 量价对应识别压力区（绿色框标注法）

蔡森核心规则：**量价对应可以分析出大压力区**。

**实战案例**（蔡森教学K线图）：
```
压力区识别：
  绿色框 = 大压力区
  压力区范围：~42.72 ~ 53.86
  压力区顶部：53.86（前高大阴线高点）
  压力区底部：42.72（前期支撑位）

量价对应逻辑：
  1. 绿色框内有多根K线反复交易 → 大量筹码集中在此价位区间
  2. 底部成交量柱显示：该区域有大量红色柱子（卖压）
  3. 大量买盘在此区域被套 → 价格回升到此区域时，解套卖压巨大
  4. 因此该区域形成"大压力区"

画线方法：
  □ 用绿色矩形框标注压力区（蔡森使用绿色框而非红色，因为这是"需要突破的区域"）
  □ 框的上沿 = 压力区最高点（如 53.86）
  □ 框的下沿 = 压力区最低点（如 42.72）
  □ 框的宽度 = 覆盖压力区的时间范围

压力区的操作意义：
  □ 价格从下方接近压力区 → 警惕回调，不宜追涨
  □ 价格突破压力区上沿 + 放量 → 压力区角色转换为支撑
  □ 价格跌回压力区内 → 确认压力有效，观望
  □ 价格有效突破压力区 = 主力解套所有套牢盘 = 大行情启动
```

**压力区 vs 支撑区的识别**：
```
压力区（绿色框在上方）：        支撑区（绿色框在下方）：
  大量筹码在此区域被套            大量筹码在此区域建仓
  价格接近时 → 解套卖压         价格接近时 → 买盘支撑
  红色成交量柱为主                绿色成交量柱为主
  跌破后变成新压力              突破后变成新支撑
```

### 效率操作点与盈亏比标注

蔡森核心理念: "最有效率的操作是找到突破点和跌破点。"

画线时必须在图表上标注：
1. **进场点（+）**: 突破/跌破瞬间，敢于一次性建仓
2. **止损点（X）**: 进场前就确定止损位（如跌破颈线、破底翻最低点等）
3. **目标价（绿色测幅满足线）**: 按形态公式计算
4. **盈亏比**: 目标涨幅 / 止损幅度
   - 盈亏比 > 3:1 = 值得操作（在图表旁标注盈亏比数值）
   - 盈亏比 < 2:1 = 放弃操作

### 涨跌幅百分比标注（新发现）

蔡森在通达信/东方财富的K线图上，会直接在图表空白区域标注关键区间的涨跌幅百分比：

```
标注工具：通达信/东方财富内置标注工具
标注位置：K线图上方或下方的空白区域
标注颜色：绿色=涨幅百分比、红色/蓝色=跌幅百分比
标注格式："+17.42%"、"-21.3%"、"+31.1%"、"+6.72%"、"+0.51%"
```

**标注时机**：
- 一段明显上涨行情结束后，标注总涨幅（如"+31.1%"）
- 一段明显下跌行情结束后，标注总跌幅（如"-21.3%"）
- 当前行情与前段行情对比时，同时标注两段涨跌幅

**与测幅满足的结合**：
- 前段涨幅"+31.1%" + 当前回调"-21.3%" → 再次上涨可参考前段涨幅
- 若两段涨幅接近（如"+31.1%"和"+31.8%"）→ 可能已经涨幅满足

## 量化形态识别算法（从炒股app移植）

> 本章节从《炒股app》项目的 `pattern-recognizer.ts` + `kline-colors.ts` 移植而来，将蔡森的形态学经验量化为可编程算法。生成HTML报告画线时，必须参照以下算法参数执行。

### 分析窗口：60日标准（默认）

| 形态 | 回看K线数 | 局部极值lookback | 说明 |
|------|----------|-----------------|------|
| W底（双底） | **最近120根**（约60个交易日×2周期） | 3 | 在窗口内找最近一对双底 |
| M头（双顶） | **最近120根** | 3 | 在窗口内找最近一对双顶 |
| 头肩底/顶 | **最近150根** | 3 | 需3个极值点，窗口更大 |
| 破底翻 | **最近100根**，细查最近30根 | 2 | 跌破+收回确认 |
| 收敛三角形 | **最近80根** | 2 | 高点递降+低点递升 |
| 旗形 | **最近80根** | 3 | 高低点同向移动 |
| 趋势线 | **最近100根** | 3 | 最后2个极值点连线 |

> **HTML报告画线时，日线默认分析窗口为60个交易日**（约3个月），对应算法中的120根K线回看范围（含前后缓冲）。

### 核心算法函数

#### 1. 局部极值检测（findLocalMins / findLocalMaxs）
```
查找第i根K线是否为局部最低/最高点：
  对于 lookback 范围内的所有 j（1到lookback）：
    若 candles[i].low > candles[i-j].low 或 candles[i].low > candles[i+j].low → 不是极小值
  全部通过 → 是局部极小值

lookback参数：
  ├── 默认 5（标准窗口）
  ├── W底/M头/头肩 用 3（更敏感）
  ├── 收敛三角/旗形 用 2（最敏感）
  └── 破底翻 用 2
```

#### 2. 近似极值合并（mergeClose）
```
将价格接近的相邻极值点合并为一组：
  阈值 = 3%（|curVal - prevVal| / prevVal <= 0.03）
  合并后的组视为同一个支撑/阻力位
  → 用于W底/三重底中识别"双底接近"的情况
```

### 各形态的量化识别参数

#### W底（双底）
```
识别条件：
  ① 两个局部最低点间距 >= 8根K线
  ② 两底收盘价差值 / min(底1,底2) <= 5%（tolerance）
  ③ 两底之间存在一个反弹高点（颈线点），且颈线点≠底1

颈线画法：
  颈线值 = 两底之间的反弹最高点的收盘价
  颈线 = 橙色虚线 #FF6B00（突破确认）
  双底支撑 = 绿色虚线 #2ecc71

量价确认：
  突破颈线时，当日成交量 > 前5日均量×1.3 → 有效突破

测幅满足：
  形态深度 = 颈线值 - min(底1,底2)
  目标价 = 颈线值 + 形态深度
  止损价 = min(底1,底2) × 0.97（-3%）
```

#### M头（双顶）
```
识别条件：
  ① 两个局部最高点间距 >= 8根K线
  ② 两顶收盘价差值 / max(顶1,顶2) <= 5%
  ③ 两顶之间存在一个回调低点（颈线点）

颈线画法：
  颈线值 = 两顶之间的回调最低点的收盘价
  颈线 = 红色虚线 #e74c3c（跌破确认）
  双顶压力 = 红色虚线

测幅满足：
  形态高度 = max(顶1,顶2) - 颈线值
  目标价 = 颈线值 - 形态高度
  止损价 = max(顶1,顶2) × 1.03（+3%）
```

#### 头肩底/顶（倾斜颈线）
```
识别条件（以头肩底为例）：
  ① 3个局部最低点：左肩→头→右肩
  ② 头部收盘价 < 左肩 且 < 右肩
  ③ 右肩 - 头 >= 5根 且 头 - 左肩 >= 5根
  ④ 左肩与右肩收盘价差 / min(左肩,右肩) <= 8%

颈线画法（关键：倾斜颈线）：
  左颈线点 = 左肩→头之间的反弹最高收盘价
  右颈线点 = 头→右肩之间的反弹最高收盘价
  颈线斜率 = (右颈线值 - 左颈线值) / (右颈线索引 - 左颈线索引)
  颈线角度 = |atan(斜率 / 左颈线值) × 180/π|
  □ 角度 <= 15° → 有效颈线（近水平或微倾）
  □ 角度 > 15° → 颈线过陡，形态无效
  颈线 = 橙色虚线 #FF6B00（头肩底）/ 红色虚线（头肩顶）
  direction = up(斜率>0) / down(斜率<0)

测幅满足：
  颈线均值 = (左颈线值 + 右颈线值) / 2
  形态深度 = 颈线均值 - 头部收盘价
  目标价 = 颈线均值 + 形态深度
  止损价 = 头部收盘价 × 0.97
```

#### 破底翻
```
识别条件：
  ① 在最近30根K线中找到支撑位（区间最低价的low）
  ② 存在某根K线收盘价 < 支撑位 × 0.97（跌破3%以下）→ brokeDown=true
  ③ 随后某根K线收盘价 > 支撑位 → recoverIdx=收回点

画线：
  破底前支撑 = 灰色虚线 #999（标记原支撑位）
  破底翻颈线 = 橙色虚线 #FF6B00
  □ 颈线值 = 跌破前5根K线的最高价（盘整高点）

测幅满足：
  目标价 = 颈线值 + (颈线值 - 支撑位)
  止损价 = 支撑位 × 0.97
  confidence = 60（需3日站稳确认才提升）
```

#### 收敛三角形（边长等长测幅法）
```
识别条件：
  ① 取最近3个局部最高点 + 3个局部最低点
  ② 高点逐步递降（descendingHighs）
  ③ 低点逐步抬高（ascendingLows）
  ④ 两组趋势线收敛

画线：
  上轨 = 红色实线 #e74c3c（连接递降高点）
  下轨 = 绿色实线 #2ecc71（连接递升低点）

测幅满足（M12边长等长原则）：
  最宽处高度 = |最后高点的high - 最后低点的low|
  底部突破目标 = 最后高点high + 最宽处高度
  顶部突破目标 = 最后低点low - 最宽处高度
  → "边长边长等于突破后的等长"
```

#### 旗形
```
识别条件：
  下降旗形（下飘旗形=上涨中继）：
    ① 最近3个高点递降 + 3个低点递降
    ② 前期趋势为上涨（区间起点close < 第一个低点close）
    → 突破上沿延续上涨
  上升旗形：
    ① 最近3个高点递升 + 3个低点递升
    → 跌破下沿延续下跌

画线：
  旗形上沿/下沿 = 实线，颜色视多空而定
```

#### 趋势线（自动检测）
```
上升趋势线：
  ① 取最后2个局部最低点
  ② 第二低点 > 第一低点（低点抬高）
  ③ 斜率角度 in (0.5°, 45°]
  ④ 从第一低点向右延伸20根K线
  画线 = 绿色实线 #2ecc71，标记"起涨点"+"回调低点"

下降趋势线：
  ① 取最后2个局部最高点
  ② 第二高点 < 第一高点（高点降低）
  ③ 斜率角度 in (0.5°, 45°]
  ④ 从第一高点向右延伸20根K线
  画线 = 红色实线 #e74c3c，标记"滞涨点"+"反弹高点"
```

## K线四种颜色系统详解

蔡森在不同看盘平台上使用的K线图会出现四种颜色。这不是随机配色，而是遵循华人金融市场的标准颜色编码系统。

### 四种颜色及其含义

| 颜色 | 代表含义 | 画在哪里 | 出现条件 |
|------|----------|----------|----------|
| **红色（Red）** | 上涨/阳线 | K线实体（填充） | 收盘价 > 开盘价 |
| **绿色（Green）** | 下跌/阴线 | K线实体（填充） | 收盘价 < 开盘价 |
| **黑色（Black）** | 影线/实体轮廓 | 上影线、下影线、十字线 | 每根K线都有 |
| **白色（White）** | 平盘/十字星 | K线实体（空心/白色填充） | 收盘价 = 开盘价 |

### 每种颜色的画法规则

**红色实体（阳线）：**
- 当收盘价高于开盘价时，K线实体用红色填充
- 表示当天（或该周期）价格上涨
- 华人市场惯例"红涨"（与西方"绿涨红跌"相反）
- 实体范围 = 开盘价到收盘价之间的区域

**绿色实体（阴线）：**
- 当收盘价低于开盘价时，K线实体用绿色填充
- 表示当天（或该周期）价格下跌
- 华人市场惯例"绿跌"
- 部分平台用蓝色代替绿色（如通达信金融终端）

**黑色影线：**
- 每根K线都有上影线和下影线，用黑色（或深灰色）细线绘制
- 上影线：从实体顶部延伸到最高价
- 下影线：从实体底部延伸到最低价
- 如果最高价 = 收盘价（阳线），则没有上影线
- 如果最低价 = 收盘价（阳线），则没有下影线
- 黑色也可能用于十字星/十字线的横线部分

**白色实体（平盘/十字星）：**
- 当收盘价等于（或非常接近）开盘价时，K线实体为白色或空心
- 这种K线叫"十字星"或"T字线"
- 表示多空力量均衡，可能是转折信号
- 在蔡森的形态学分析中，十字星出现在头部或底部区域时特别有意义

### 蔡森使用的不同平台及其颜色差异

| 平台 | 使用场景 | 阳线颜色 | 阴线颜色 | 影线颜色 |
|------|----------|----------|----------|----------|
| XQ全球赢家（保哥财经分析系统） | 台股个股/期货 | 红色 | 绿色 | 黑色 |
| 通达信金融终端 | 美股/港股/A股 | 红色 | 蓝色 | 黑色 |
| 东方财富/同花顺 | A股 | 红色 | 绿色 | 黑色 |
| TradingView | BTC/加密货币 | 绿色(涨) | 红色(跌) | 深灰 |

**重要提示**：虽然不同平台的颜色略有差异，但蔡森的分析方法不变。关键是识别K线的涨跌方向，而非纠结于具体颜色。在分析用户提供的K线图时，需要先确认该图的颜色编码惯例。

### 成交量柱的颜色

K线图下方的成交量柱也使用相同的四色系统：
- **红色柱**：当天收阳线时的成交量
- **绿色/蓝色柱**：当天收阴线时的成交量
- **白色柱**：当天收十字星时的成交量
- 成交量柱的颜色跟随K线实体的颜色，不是跟随价格涨跌

### 在形态分析中的颜色关注点

蔡森在分析形态时特别关注：
1. **红色大阳线突破颈线** → 放量突破，确认有效
2. **绿色大阴线跌破颈线** → 跌破有效，不需量确认
3. **白色十字星出现在关键位置** → 可能转折信号
4. **红色阳线伴随放量 + 绿色阴线缩量** → 健康的上涨趋势
5. **连续红色大阳线（天量）** → 可能是头部信号
6. **连续绿色阴线后出现白色十字星** → 可能是底部信号

## 6-18视频新学画线技巧（蔡森原话+图表实战）

### 一、水平线 vs 倾斜线的选择原则

蔡森在罗素2000分析时明确讨论了画线选择：

```
蔡森原话：
"一般是畫這樣"（指斜线趋势线）
"所以有時候要怎麼畫線，我們是沒有跟各位講"
"比如說你要結合當時的情況"
"通常正確的是這樣畫，直線，那個橫線，橫的平的，零角度的平的橫線"
"這個最漂亮"

但当时有下影线（和平消息导致）：
"因為這裡有拉一個下影，也就是說那個和平來了"
→ 此时从下影线低点画水平线
```

**画线决策树**：
```
画线选择：
├── 默认情况 → 水平线（零角度平的横线）= "最漂亮""最正确"
├── 有事件下影线 → 从下影线低点画水平线
├── 趋势线连接多点 → 斜线（连接不同时间的低点-低点/高点-高点）
└── 回拉低点支撑 → 从创新高后回拉低点画水平线（向右延伸）
```

### 十、多头支撑线画线法（收盘价确认规则）

蔡森核心原则：**多头时画出支撑线，如果当日收盘没有跌破，则支撑依然有效。**

**实战案例（K线图）**：
```
多头趋势中的支撑线画线法：

第1步：画出主支撑线
  找到多头整理区的多个低点，连接成一条水平线（绿色 #2ecc71）
  用"点多的为主"原则：触碰次数最多的低点价位就是支撑线
  例：多个低点都在 ~42006.39 附近 → 绿色水平线 = 主支撑

第2步：画出次级阻力/支撑线
  找到多头突破后的高点/反弹高点，连接成一条水平线（黑色）
  例：反弹高点在 ~47871.19 → 黑色水平线 = 次级参考线
  该线可充当第二层支撑，但不作为主支撑

第3步：确认支撑有效性（收盘价规则）
  每日观察收盘价（不是盘中最低价）：
  □ 当日收盘价 > 支撑线 → 支撑依然有效
  □ 当日收盘价 < 支撑线 → 支撑被有效跌破 → 多头结构破坏
  □ 盘中最低价跌破支撑但收盘站回 → 不算跌破，支撑仍有效

第4步：支撑有效时的操作策略
  □ 支撑未跌破 → 多头趋势继续，持股不动
  □ 回踩支撑不破 + 放量阳线 → 加码买入机会
  □ 跌破支撑 → 多头结构破坏，等待新信号
```

**收盘价确认规则的核心意义**：
```
蔡森的判断标准：
  支撑有效 = 收盘价没有跌破支撑线（不是盘中最低价）
  支撑失效 = 收盘价跌破支撑线（确认跌破）

为什么用收盘价而不是盘中价？
  □ 盘中最低价可能只是瞬时恐慌/洗盘
  □ 收盘价代表当日市场最终共识
  □ 主力可以制造盘中假跌破，但收盘价更能反映真实意图
  □ 蔡森原话：当日收盘没有跌破，支撑还是有效
```

**多层级支撑画线法**（实战K线图示范）：
```
多头趋势中常见的多层级画线：

第一层：绿色水平线（主支撑）
  = 整理区低点连线，触碰次数最多
  = 多头生命线，跌破 = 趋势结束

第二层：黑色水平线（次级参考线）
  = 反弹高点/突破后回踩位
  = 可作为第二层支撑或目标位参考

紫色水平线（前期压力位）
  = 历史阻力/目标位，突破后角色转换为支撑

实战案例数值：
  绿色支撑线 ~42006.39（多个低点触碰，主支撑）
  黑色参考线 ~47871.19（反弹高点，次级参考）
  收盘价始终在绿色支撑线上方 → 多头有效，支撑成立
```

**与头部形态的对照**：
```
多头支撑线：收盘价未跌破 → 支撑有效 → 继续持有
空头颈线：  收盘价跌破颈线 → 形态确认 → 做空进场

两者共同原则：
  □ 都用收盘价判断，不用盘中价
  □ 都用"点多的为主"画线
  □ 突破/跌破都需确认（不是假信号）
```
