## M9：多头十大罪状检测法

> 当市场处于多头末期时，用此清单系统性检测是否出现空头信号。每一条"罪状"都是独立的危险信号，出现越多越危险。

### 十大罪状清单

| # | 罪状 | 检测方法 | 危险级别 |
|---|------|----------|----------|
| 1 | 融资破历史记录 | 融资余额创历史新高，量价背离（价格新高但融资增速放缓） | 极高 |
| 2 | 外资操纵三步曲 | 外资拉现货→空期货→杀现货（养套杀循环） | 极高 |
| 3 | ETF疯抢全民运动 | ETF规模暴增，散户疯狂涌入，炒股成全民运动 | 高 |
| 4 | 全球杠杆爆表 | 世代同堂式借贷（信贷+房贷+车贷+融资全面膨胀） | 极高 |
| 5 | 长期通胀+油价>$85 | 石油85美元以上对全球经济杀伤力极强，带动通胀万物皆涨 | 高 |
| 6 | 利率长升趋势+美债危机 | 10年期殖利率破底翻进入长期上升周期 | 高 |
| 7 | 巴菲特指标>230% | 股市总市值/GDP超过230%属严重极度高估 | 高 |
| 8 | 席勒本益比历史第二高 | S&P 500 CAPE约41，155年来第二高位 | 高 |
| 9 | 市场广度崩塌 | 大盘创新高但40%+个股从52周高点跌>20%，极端背离 | 极高 |
| 10 | 比特币腰斩/投机结束 | 加密市场崩盘作为投机情绪消退的先行指标 | 中 |

### 使用方法

```
Step 1：逐条检查十大罪状的当前状态
Step 2：统计触发条数
  □ 1-3条触发 → 警觉期，开始减仓
  □ 4-6条触发 → 危险期，大幅减仓+考虑做空指数
  □ 7-10条触发 → 极危险，多头末期信号明确
Step 3：配合M8市场宽度确认（涨跌比、新高新低比）
Step 4：配合M6假突破策略（指数假突破→做空）
```

### 关键原则

- **招招致命**：每一条单独出现都足以引发大跌
- **历史规律**：过去每次触发多条后都发生崩盘（1990、2000、2008）
- **庞氏骗局逻辑**：融资/杠杆到最后没人跟时就是崩盘时点
- **不是不來，只是遲到**：空头不是不来，只是迟到

## M10：月线翻黑周期分析法

> 月线指标翻黑是中长期走空的重要信号，上次翻黑后的盘整周期可作为本次的参考。

### 分析框架

```
月线翻黑检测流程：
□ 月线技术指标是否翻黑？（MACD/均线等由多翻空）
□ 上次翻黑是什么时候？
□ 上次翻黑后盘了多久才开始跌/涨？
□ 当前翻黑的股票/指数列表（哪些已翻黑，哪些还没）
□ 翻黑顺序 = 先行指标：龙头先翻黑 → 二线股跟跌
```

### 翻黑顺序的先行意义

| 翻黑顺序 | 含义 | 操作含义 |
|----------|------|----------|
| 龙头先翻黑 | 大户已开始撤退 | 警惕但还不做空（等确认） |
| 多数科技股翻黑 | 板块性走空 | 做空信号明确 |
| 指数翻黑 | 全面性走空 | 坚定做空 |
| 唯一未翻黑的龙头 | 最后的堡垒 | 画好颈线等破线 |

### 实战案例（苹果AAPL月线翻黑）

- 上次月线翻黑后：盘了半年到一年才重新开涨
- 当前又翻黑：上次没事但这次可能不一样
- 含义：月线翻黑不代马上崩，但代表至少半年内偏弱

## M11：停损纪律操作系统

> 纪律操作不带任何感情，赚两次赔一次就是成功的节奏。

### 核心原则

```
纪律操作 = 七七勤展六億，不带有任何感情

节奏管理：
□ 看空时坚定做空，设好停损点
□ 赚两次 → 准备5-8万来赔一次
□ 赚10万 → 准备3-5万来赔
□ 一次错不代表全部错，前面赚的要算
□ 长空中：反弹还要空，直到空单被停损
```

### 假突破做空的纪律

```
假突破出现 → 做空（这是铁律）
  ├── 点到停损 → 出场（赔3-5万）
  ├── 未点停损 → 继续持有
  └── 反弹出现 → 继续做空（不是等解套，而是重新布局）

成功率评估：
  做空成功率 ≈ 85%（失败率15%）
  每次赚4000-5000点（台指期）
  每次赔300-500点
  赚两次赔一次 = 长期必赚
```

### 纪律vs感情

- **不能断章取义**：不能只算错的次数，要把前面赚的也算进去
- **前面对的也要算**：赚三次错一次又赚一次 = 总体还是赚
- **不带感情**：看到假突破就做空，看到停损就出场，不加个人判断

## M12：收敛三角满足操作法

> 收敛三角支撐不破看滿足，满足了就不追价。

### 分析框架

```
收敛三角操作流程：
Step 1：识别收敛三角（上压线+下支线的夹角越来越小）
Step 2：画颈线（上下两条趋势线）
Step 3：突破确认（实体突破，不只是影线）
Step 4：压回不破颈线 → 确认有效
Step 5：测幅满足计算
  □ 三角最宽处的垂直距离 = 测幅目标
  □ 突破点 + 测幅 = 目标价
Step 6：满足后不追价！
  □ 设短线支撑 = 停利点
  □ 逆势走强的看逆势低点作为强弱分界
```

### 边长等长原则（6-17视频补充）

```
收敛三角测幅精确表述：
├── 三角最宽处的"边长"（垂直距离）= 突破后的"等长"（等距延伸）
├── 画法：用蓝色竖线量出三角最宽处的垂直距离
├── 从突破点向右等距延伸 = 满足点
└── "边长边长等于突破后的等长"——蔡森原话
```

### 与其他方法论的协作

- **M5分钟线抄底**：日线出现收敛三角时，用5分钟线/小时线找精确进场点
- **M6破底翻**：三角内部可能出现破底翻，新上市/下跌中的第一次破底翻都有反弹
- **M2颈线**：三角突破后的压回颈线是关键支撐
