# 《今年报》2026-10-15 期：AI 信用端断裂与债市「利空不跌」

> **案例说明**：本期是全球杀盘日的完整示范——把「CPI 超预期」与「AI 高杠杆公司债券被当准违约定价」两条线并起来，得出「加息故事被信用事件抢跑」的判断；同时记下美债长端第一次「利空不跌」。方法论沉淀见 `references/19-m93-m97.md`（M93 通胀门槛倒推法、M94 CPI 分项主导权交接判读法、M95 油价—选票政治反馈闭环法、M96 长端「利空不跌/利多不涨」转折判读法、M97 资源错配型通胀验证法）。

## 一、核心逻辑链（节目主线）


## 二、模块首秀（M93–M97）

### M93 通胀门槛倒推法
节目给出「要维持 3.74% 的年增率，明年 9 月油价至少 130–135 美元」。按四步法复核：
能源 CPI 篮子约 汽油 49% / 电力 36% / 燃气 11% / 燃油 3%，当期电力同比仅 +2~3% 几乎不涨；
要复现能源同比 +20.4%，汽油需同比 ≈ +36.5%；汽油对原油弹性 k ≈ 34.2% ÷ 44.7% ≈ 0.77 →
原油需同比 ≈ +47.7% → **门槛 ≈ 90.34 × 1.477 ≈ 133 美元**。
反向门槛：**WTI ≤ 约 108 美元 → CPI 同比跌破 3%**。
→ 节目「130–135」站得住（详见 `examples-1015.md` 第四节与 `references/19-m93-m97.md` M93 反面教材）。

### M94 CPI 分项主导权交接判读法
能源贡献 1.50pp / 40.5% = 单一分项主导（可逆、地缘驱动）；核心商品环比 +0.3%（前值 +0.1%）、二手车连三月 +0.7%、电脑/外围 +1.4% = **接棒候选**；核心服务 +0.4%（前值 +0.3%）、外出住宿连两月 +2.3%、机票同比 +22.4% = 黏性底盘。
→ 判定：**当前仍是「能源主导、可逆」，但接棒动作已开始**。节目「是接棒」方向对，但用环比口径说「13 个月新高」会夸大（同期核心商品同比持平于 0.7%）。

### M95 油价—选票政治反馈闭环法
伊朗高级官员**自述**新战术目的是「维持油价高位并影响美国中期选举」→ A 标志（对手自述）成立，武器化无需推断。
价格端：WTI 90.86、布伦特 103.02、全美汽油 4.33 美元/加仑（战前 2.98）。
体感端：实际时薪同比 −0.7%（连续第六个月）；益普索约 78% 美国人归咎关税与美伊战争。
→ 闭环四段全通。**关键推论：11/3 选举日 = 油价地缘溢价的到期日**，不是风险持续期。

### M96 长端「利空不跌」转折判读法
10/14 CPI 后：5Y 盘中一度 +15BP 至 5.153%（2007 年来最高）→ 收盘 2Y +0.84BP、3Y −0.57、5Y −1.44、7Y −2.16、10Y −2.30（5.1854%）、20Y −3.00、30Y −3.38（5.5231%）。
→ **中长端全线收在反向、越长越强；只有短端收涨** = 第一信号成立，且属「久期偏好」而非「政策路径」变化。
→ 纪律：**单次背离不建仓，等第二次同向背离**（节目亦自述「等第二个讯号」）。

### M97 资源错配型通胀验证法
① 需求端对照为负：实际时薪同比 −0.7%（连续 6 个月负）、周薪环比 −0.5%、必需消费类股价走弱 → 需求端解释被否决。
② 价格端为正：核心商品环比 +0.3%、服装 +0.3%、二手车 +0.7% 连三月 → 价格确实在涨。
③ 占用方可指认：AI 资本开支（台积电 2026 资本支出 600–640 亿美元、2026–2028 显著高于过去三年；CoreWeave 负债+租赁 520 亿美元）。
→ **「资源错配型通胀」三验成立**。节目「资本被占用、资源被浪费」的口头总纲，本次首次被做成可证伪判据。

## 六、短期推演（10-15 给出，含证伪位）
