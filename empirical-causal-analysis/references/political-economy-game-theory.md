## 一、博弈论核心模型

### 1.1 博弈分析标准流程

**五步法**：
1. **识别参与者（Players）**：谁有决策权？各方的偏好排序是什么？
2. **识别策略集（Strategy Sets）**：各方有哪些可选行动？是离散还是连续策略？
3. **构建收益矩阵/博弈树**：每种策略组合下各方的收益
4. **求解均衡**：剔除劣策略 → 求纳什均衡 → 检验精炼条件
5. **比较静态分析**：参数变化时均衡如何移动？政策如何改变博弈结构？

### 1.2 完全信息静态博弈

**纳什均衡求解**：
$$s^* = (s_1^*, ..., s_n^*) \text{ s.t. } \forall i: u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*)$$

**求解步骤**：
1. 逐行/逐列找每个参与者的最优反应
2. 画最优反应曲线
3. 交点 = 纳什均衡
4. 检查是否存在帕累托改进空间（囚徒困境）

**经典应用：关税博弈（贸易战）**

|  | B国：低关税 | B国：高关税 |
|--|----------|----------|
| **A国：低关税** | (3, 3) | (1, 4) |
| **A国：高关税** | (4, 1) | (2, 2)* |

- *标注 = 纳什均衡（高关税, 高关税）
- (低关税, 低关税) 是帕累托最优但不是均衡 → 典型囚徒困境
- WTO 的作用：改变博弈结构，使合作成为可持续均衡

### 1.3 完全信息动态博弈

**子博弈精炼纳什均衡（SPNE）**：
- 用**逆向归纳法**（Backward Induction）求解
- 从最后一步开始，逐层向前推导最优策略
- 排除不可信威胁

**经典应用：多轮贸易谈判**

```
A国: 提议 →  B国: 接受/拒绝
                ├── 接受 → (协议达成, 各方收益)
                └── 拒绝 → A国: 报复/退让
                              ├── 报复 → (贸易战升级, 双输)
                              └── 退让 → (A国受损, B国获益)
```

- 求解：从叶子节点逆向推导
- 关键：A国的"报复"威胁是否可信？→ 如果报复成本高于退让成本，则不可信
- 贴现因子 δ：未来收益的折现，δ 越大越倾向于长期合作

### 1.4 不完全信息博弈

**贝叶斯纳什均衡**：
- 参与者不知道对手的"类型"（偏好/能力/意图）
- 用先验概率分布描述不确定性
- 均衡策略依赖于对对手类型的信念

**信号博弈（Signaling Game）**：
- 发送者知道自己的类型，接收者不知道
- 发送者选择一个行动（信号），接收者观察信号后行动
- **分离均衡**：不同类型发送不同信号 → 接收者能推断类型
- **混同均衡**：不同类型发送相同信号 → 接收者无法区分

**经典应用：央行政策信号博弈**

```
央行类型: 鹰派/鸽派 (市场不知道)
    ↓
央行行动: 加息/不变 (信号)
    ↓
市场反应: 根据信号推断央行类型 → 调整预期
```

- **分离均衡**：鹰派必加息、鸽派必不变 → 市场完美推断
- **混同均衡**：两类央行都加息 → 市场无法区分
- **半分离均衡**：鸽派以一定概率"伪装"鹰派 → 部分信息传递
- **关键变量**：信号成本——鹰派加息成本低（本来就想加），鸽派加息成本高（违背偏好）

### 1.5 重复博弈

**无限重复博弈中的合作**：
- 触发策略（Trigger Strategy）：一旦对手背叛，永久回到不合作
- 合作均衡条件：$\frac{3}{1-\delta} \geq 4 + \frac{2\delta}{1-\delta}$
- 化简：$\delta \geq \frac{1}{3}$ → 贴现因子足够大时合作可维持
- **含义**：δ 越大（越重视未来），越容易维持合作

**在市场分析中的应用**：
- 中美贸易关系的持续性：是单次博弈还是重复博弈？
- OPEC+ 减产协议：重复博弈中的 cartel 可持续性
- 核威慑：冷战"相互确保毁灭"作为永久触发策略

### 1.6 演化博弈

**演化稳定策略（ESS）**：
- 策略 $s^*$ 是 ESS，如果当大多数人都采用 $s^*$ 时，任何变异策略 $s'$ 都无法入侵
- 复制动态：$\dot{x}_i = x_i[\pi(s_i) - \bar{\pi}]$

**在市场分析中的应用**：
- 去美元化的演化：从单国尝试到多国跟进，需要跨越"临界质量"
- 制度变迁：旧制度 vs 新制度的适应度竞争
- 加密货币 vs 法定货币：演化博弈中的策略扩散

## 二、政治风险评估框架

### 2.1 政治风险量化矩阵

| 风险维度 | 指标 | 数据源 | 量化方式 |
|---------|------|--------|---------|
| 选举风险 | 选举日期/民调/赔率 | RealClearPolitics / PredictIt | 胜选概率 → 政策变化概率 |
| 地缘冲突风险 | 军事部署/外交声明/情报评估 | OSINT / think tank reports | 事件概率树 |
| 制裁风险 | 制裁清单/立法提案/行政命令 | OFAC / EU sanctions tracker | 受影响实体/行业清单 |
| 政策逆转风险 | 新政府/立法变动/法院裁决 | 法案追踪 / 最高法院日历 | 逆转概率 × 影响幅度 |
| 主权违约风险 | CDS 利差/债务/GDP/评级 | CDS市场 / IMF / S&P | 违约概率 + 恢复率 |
| 资本管制风险 | 外储/经常账户/政治压力 | IMF / 央行数据 | 外储/月进口 < 3 → 高风险 |

### 2.2 政治事件情景树

**情景树构建方法**：
```
事件: 美国大选
├── 情景A: 候选人X当选 (概率 p₁)
│   ├── 政策1: 关税升级 → 市场影响 (概率/幅度)
│   ├── 政策2: 减税 → 市场影响
│   └── 政策3: 放松监管 → 市场影响
├── 情景B: 候选人Y当选 (概率 p₂)
│   ├── 政策1: 加税 → 市场影响
│   ├── 政策2: 加强反垄断 → 市场影响
│   └── 政策3: 气候政策 → 市场影响
└── 争议/延迟 (概率 p₃)
    └── 不确定性溢价上升 → 避险资产受益
```

**期望影响**：
$$E[\text{Impact}] = \sum_{s} P(s) \times \text{Impact}(s)$$

**与蔡森兵棋推演的联动**：本框架提供概率量化与收益矩阵，蔡森8Agent提供多路径情景发散，两者互补。

### 2.3 地缘政治传导链

**五层传导模型**（与笨鸟 M16 联动）：

| 层级 | 事件 | 传导机制 | 市场影响 |
|------|------|---------|---------|
| 第1层 | 地缘事件发生 | 直接影响 | 避险情绪飙升 |
| 第2层 | 能源/商品供应 | 供给侧冲击 | 油价/金价跳涨 |
| 第3层 | 贸易/制裁措施 | 供应链断裂 | 相关产业重估 |
| 第4层 | 央行/财政政策 | 流动性/利率 | 股债重新定价 |
| 第5层 | 长期格局变化 | 制度重构 | 资本流再配置 |

**量化方法**：
- 每一层用事件研究法估计 CAR
- 用 VAR 脉冲响应量化传导速度和幅度
- 用 DiD 比较受影响 vs 未受影响的差异化效应

## 三、政策评估因果框架

### 3.1 政策类型与识别策略匹配

| 政策特征 | 推荐识别策略 | 关键假设 | 典型应用 |
|---------|------------|---------|---------|
| 全国统一政策（无空间对照组） | 中断时间序列（ITS）+ SCM | 前期趋势可外推 | 全国性房产税 |
| 部分地区先实施 | DiD + 交错估计量 | 平行趋势 | 自贸区试点 |
| 阈值触发 | RDD | 断点附近局部随机 | 被动指数纳入 |
| 自主申请 | PSM + DiD | 条件独立 + 平行趋势 | 补贴申请 |
| 分阶段实施 | 交错 DiD | 无预期效应 | 注册制改革 |
| 多重政策叠加 | DML | 可分离性 | 多项产业政策 |

### 3.2 中断时间序列（ITS）

**模型**：
$$Y_t = \beta_0 + \beta_1 Time_t + \beta_2 Policy_t + \beta_3 Time_t \times Policy_t + \epsilon_t$$

- $\beta_2$：政策导致的**水平变化**（截距跳变）
- $\beta_3$：政策导致的**斜率变化**（趋势改变）
- 前期 $Policy_t = 0$，后期 $Policy_t = 1$

**自相关处理**：ARIMA 误差或 Newey-West 标准误

### 3.3 政策评估中的常见陷阱

| 陷阱 | 描述 | 解决方案 |
|------|------|---------|
| Ashenfelter 沉降 | 处理组在处理前本身就在下降 | 用更长的前期窗口检验 |
| 预期效应 | 市场在政策正式生效前已反应 | 事件研究法检验前期系数 |
| 溢出效应 | 对照组受处理组间接影响 | 检验 SUTVA 假设；空间 RDD |
| 混淆政策 | 同期其他政策也变了 | DML 分离各政策效应 |
| 组成变化 | 处理前后样本组成变了 | 固定面板 + 平衡样本 |

## 四、制度分析的实证桥梁

### 4.1 与卢麒元制度分析的互补

卢麒元的制度分析是**定性框架**（广义财政论、资本三流、向心坍缩），本专家提供**定量化桥梁**：

| 卢麒元定性概念 | 实证操作化方法 | 可用数据 |
|-------------|-------------|---------|
| 广义财政 | 财政收支/GDP趋势 + 断点检验 | 财政部数据 / IMF |
| 资本三流（产业→金融→投机） | 资金流向分解 + VAR 脉冲响应 | 央行资金流量表 |
| 向心坍缩 | 系统性风险指标时序 + 预警模型 | CDS / TED spread / LIBOR-OIS |
| 费雪债务通缩 | 债务/GDP + 通胀的 VAR / 门槛回归 | BIS 债务数据 |
| 明斯基三阶段 | 信用利差 + 波动率的 Markov 区制转移 | 信用债利差 / VIX |
| 卡莱斯基利润 | 利润份额回归 + 结构断点检验 | 国民收入账户 |

### 4.2 制度断裂的自然实验

**制度断裂作为外生冲击**：
- 寻找制度变革时点的**准随机变异**
- 在制度阈值处用 RDD
- 在制度先行地区用 DiD
- 用 SCM 构建"如果没有制度变革"的反事实

**经典应用**：
- 中国加入 WTO 的产业层面因果效应（DiD：受关税影响大 vs 小的行业）
- 注册制改革对 IPO 定价效率的影响（RDD + DiD）
- 土地财政转型对地方财政的影响（ITS + SCM）

### 4.3 政治经济周期

**机会主义政治经济周期模型**：
- 选举前操纵经济（财政/货币扩张）以增加连任概率
- 检验方法：选举虚拟变量的回归
$$Y_t = \alpha + \beta \cdot Election_t + \gamma X_t + \epsilon_t$$
- 用 RDD 在选举日期附近检验政策变化

**党派周期模型**：
- 不同政党有不同的通胀-失业偏好
- 检验：执政党更替前后通胀/利率的变化
- 方法：DiD（执政党变化 vs 不变）

## 五、博弈论在市场分析中的应用实例

### 5.1 OPEC+ vs 美国页岩油的 Stackelberg 博弈

**模型**：
- OPEC+ 作为先动者（领导者），选择产量 $q_O$
- 美国页岩油作为后动者（追随者），观察 $q_O$ 后选择 $q_S$
- 反需求函数：$P = a - b(q_O + q_S)$

**求解**：
1. 追随者最优反应：$q_S^*(q_O) = \frac{a - c_S - bq_O}{2b}$（$c_S$ = 页岩油边际成本）
2. 领导者最大化利润：$q_O^* = \frac{a - c_O}{2b} - \frac{q_S^*(q_O)}{2}$
3. 均衡产量、价格、利润

**关键洞察**：
- 页岩油的短周期特性（钻井→产油只需 3-6 个月）改变了博弈结构
- OPEC+ 的"先动优势"被页岩油的"快速响应"削弱
- 博弈从 Stackelberg 向更接近古诺竞争演化

### 5.2 央行博弈：时间一致性问题

**Kydland-Prescott (1977) 时间不一致性**：
- 央行宣布零通胀政策
- 私人部门形成低通胀预期
- 央行有激励"意外"制造通胀以降低失业（菲利普斯曲线）
- 私人部门预判后 → 结果是高通胀 + 无就业改善

**解决方案**：
- 规则 vs 相机抉择（Taylor Rule）
- 央行独立性
- 通胀目标制 + 前瞻指引
- 信誉机制（重复博弈）

**Barro-Gordon 信誉模型**：
- 强央行（鹰派）：始终坚守零通胀
- 弱央行（鸽派）：有制造意外通胀的激励，但伪装成强央行以维持信誉
- 均衡：弱央行在前期伪装，后期可能暴露
- 市场通过数据（实际通胀 vs 预期）更新对央行类型的信念

### 5.3 贸易战的多阶段博弈

**无限重复关税博弈**：
- 每期双方选择：合作（低关税）或背叛（高关税）
- 触发策略：一旦对方背叛，永久回到高关税
- 合作均衡条件：$\delta \geq \frac{C_{deviate} - C_{cooperate}}{C_{deviate} - C_{punishment}}$
- **δ 的现实决定因素**：
  - 政治周期长度（选举频率越低，δ 越大）
  - 经济相互依赖度（贸易/GDP越高，背叛成本越大）
  - 国际制度约束（WTO 仲裁 → 增加背叛成本）

**分析输出**：
```
博弈类型: 无限重复关税博弈
参与者: [国家A, 国家B]
策略集: {低关税, 高关税}
支付矩阵: [具体数值]
触发策略: 背叛后永久回到高关税
合作维持条件: δ ≥ [阈值]
当前 δ 估计: [基于贸易依赖度/政治周期]
均衡预测: [合作/背叛/混合]
政策含义: [如何提高 δ 以维持合作]
```

### 5.4 去美元化的协调博弈

**网络效应模型**：
- 货币的国际使用具有强网络效应（越多国家用，越有价值）
- 去美元化是一个**协调博弈**：单国去美元化成本高，多国同时行动才能成功
- **临界质量（Critical Mass）**：当使用替代货币的国家比例超过阈值后，去美元化成为自我强化趋势

**博弈结构**：
```
状态: 每个国家选择美元/替代货币
收益: 使用某种货币的收益 ∝ 使用该货币的国家数量（网络效应）

均衡:
- 均衡1: 所有人用美元 (现有均衡, 网络效应锁定)
- 均衡2: 所有人用替代货币 (需要协调)
- 协调失败风险: 单国转向的成本 > 收益, 除非有足够多国家同时转向
```

**分析价值**：解释为什么去美元化"说得多做得少"——协调失败 + 美元的网络效应锁定。与卢麒元制度分析联动：制度层面的推演需要博弈论验证协调可行性。
