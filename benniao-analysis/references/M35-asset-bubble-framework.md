## M35：全球流动性收缩周期下的资产泡沫研判框架

**核心洞察**：资产泡沫不是单一指标能判定的，必须沿「宏观水源 → 微观情绪」的全链条逐层交叉验证。本框架以**央行资产负债表周期**为底层驱动源，自下而上经过五层（底层驱动→跨境传导→市场结构→风险边界→情绪尾部）交叉验证，最终完成**泡沫顶部识别、下跌路径推演、系统性风险测算**。它本质是一套从"宏观水源"到"微观情绪"的全链条验证体系，专门解决单一指标误判问题，适合研判**区域性股市泡沫**、**全球流动性拐点下的大类资产走向**。

> 使用原则：本框架是方法论（工具），结论必须独立推导。文中"本次对应案例"均为**实战示例/观点示例**，会随时间过期，不构成永久结论。

---

### 框架核心逻辑（总链路）

```
央行资产负债表周期（水源）
        │  缩表 = 总水源主动收紧 = 泡沫终结根本前提
        ▼
跨境资金传导（套息交易 + 汇率联动）─── 杠杆增减的跨境风向标
        │
        ▼
市场结构验证（筹码 + 基差双重验证）─── 机构派发 / 散户接盘
        │
        ▼
债务极限约束（债务可持续临界点模型）─── 资产端风险 → 主权信用端
        │
        ▼
情绪尾部确认（社会行为学信号）─────── 全民炒股 = 购买力耗尽 = 见顶在即
        │
        ▼
输出：顶部识别 + 下跌路径推演 + 系统性风险测算 + 目标点位
```

**关键判定哲学**：单一层到达信号仅为线索；**多层同步确认**才判定泡沫进入加速破裂阶段。任何一层被证伪，都应下调破裂概率。

---

### 第一层：底层驱动层 —— 央行资产负债表周期研判

**核心逻辑**：所有资产价格的长期支撑都是流动性。央行缩表意味着"总水源"主动收紧，是泡沫终结的**根本前提**。没有这一层确认，后面所有顶部信号都只是波动而非趋势终结。

**核心观测指标**：
- 主要央行**总资产规模变动**、**累计缩表幅度**
- 央行**公开市场工具**的投放/回收状态（如日本商业票据、台湾央行定存单流标）
- **银行间市场基准利率**（隔夜拆款利率等）

**判断标准**：
```
缩表幅度 > 10%
  + 货币市场工具主动回收（定存单流标 / 逆回购持续净回笼）
  + 银行间利率上行
= 流动性正式进入收缩周期 ✅
```

**本次对应案例（示例）**：日本央行缩表 15.6%、台湾央行定存单流标 + 隔夜拆息走高，共同确认全球流动性"收酒杯"进程。

---

### 第二层：跨境传导层 —— 套息交易与汇率联动分析

**核心逻辑**：全球流动性通过**套息交易（Carry Trade）**实现跨境传导；融资货币（日元）的汇率趋势是全球杠杆增减的**核心风向标**。汇率贬到哪，决定了全球杠杆加/减的节奏。

**核心观测指标**：
- 核心融资货币兑美元汇率，及**技术测幅测算的趋势目标位**
- 主要经济体**利差变化**（美日利差为核心）
- **跨境资本流动方向**（外资买卖股债数据）
- 政策端对资本回流的引导（如养老基金本土回流政策）

**判断标准**：
```
融资货币持续贬值 + 利差扩大
  = 套息交易扩张、流动性外溢（风险资产上涨水源）

贬值到位 + 利差收窄
  = 套息交易平仓、流动性回流（风险资产失去水源）
```

**本次对应案例（示例）**：日元贬破 163、测幅目标 172-173，叠加日本养老基金回流，预示全球套息交易反转窗口临近。

---

### 第三层：市场结构层 —— 筹码与基差双重验证

**核心逻辑**：价格可以被情绪拉动，但**机构行为和资金成本不会说谎**。行情顶部必然伴随"机构派发、散户接盘"的筹码转移过程。这一层是**价格信号（情绪）与行为信号（筹码）的交叉验证**。

**核心观测指标**：
- 股指期货**基差方向**（正价差 / 逆价差）及拐点
- **分投资者买卖结构**：外资、机构、散户的净买卖方向
- **融资余额**、**ETF 申购规模**（散户参与度资金指标）

**判断标准**：
```
现货创新高
  + 期货由正价差转逆价差（期现背离）
  + 外资持续卖超
  + 散户融资 / ETF 接盘
= 确认顶部筹码交换完成 ✅
```

**本次对应案例（示例）**：台股现货大涨但期指由正转逆，外资卖超、散户融资接盘，构成典型顶部结构信号。

---

### 第四层：风险边界层 —— 债务可持续性临界点模型

**核心逻辑**：泡沫破裂的最终约束是**政府财政承载力**。当债务付息成本持续超过经济增长能力时，危机将从**资产端**传导至**主权信用端**。

**核心公式**：
```
债务雪球触发条件 = 债务平均付息利率 > 名义 GDP 增速
```

**核心观测指标**：
- 主权政府**债务总规模**
- 债务**平均加权付息利率**
- **长端国债收益率**（30 年期为代表）
- **名义 GDP 增速**（实际增速 + 通胀率）

**判断标准**：
```
平均利率拐头向上
  + 名义增速下行预期（如 AI 泡沫破裂拖累）
= 财政风险临界窗口临近 ✅
```

**本次对应案例（示例）**：美国债务 39.6 万亿、平均利率 3.409% 拐头向上，若 AI 泡沫破裂带动名义增速下滑，将触发债务不可逆膨胀。

---

### 第五层：情绪确认层 —— 社会行为学尾部信号

**核心逻辑**：泡沫最后一程由**散户情绪**推动。当非专业群体全面入场时，意味着市场潜在购买力基本耗尽，下跌一触即发。这是**最滞后但最确定的见顶信号**。

**核心观测指标**：
- 非金融 / 非投资圈层人群**普遍参与炒股**
- 社会话题中"炒股致富"占比大幅提升
- 低价题材股普涨，**估值与基本面严重脱钩**

**判断标准**：
```
跨圈层全民炒股现象出现
= 泡沫进入最后冲刺阶段，见顶在即 ✅
```

**本次对应案例（示例）**：服务业非专业从业者大规模参与题材股交易，对应历次科技泡沫见顶的典型特征。

### 完整推演路径（从信号到结论）

```
Step 1 定大方向：先确认全球主要央行进入缩表周期
        → 流动性大方向收紧，泡沫失去长期支撑（第一层）

Step 2 看传导节奏：跟踪融资货币贬值进度
        → 判断套息交易反转时点，锁定全球资金回流节奏（第二层）

Step 3 验顶部结构：观察股市期现背离 + 筹码转移
        → 确认机构派发是否完成，锁定顶部时间窗口（第三层）

Step 4 算风险空间：用债务可持续模型
        → 测算泡沫破裂后的系统性风险深度（第四层）

Step 5 做尾部确认：结合全民炒股等社会情绪信号
        → 确认泡沫见顶的最终时点（第五层）

Step 6 输出结论：结合历史泡沫周期的时间 / 跌幅规律
        → 给出下跌周期长度与目标点位
```

> 逐层确认原则：第 1 层是"是否可能"，第 2-3 层是"何时"，第 4-5 层是"跌多深、是否主权信用共振"。任一层被证伪，下调破裂概率而非硬判。

| 维度 | 说明 |
|------|------|
| **适用场景** | 全球流动性拐点下的区域性股市泡沫研判、大类资产配置方向判断、中期趋势性行情顶底识别 |
| **核心假设** | 全球金融市场由美元/日元主导的套息流动性驱动，资产泡沫遵循"机构拉抬 — 散户接盘 — 流动性收紧 — 崩盘"的经典路径 |

### 反误判清单

遇到以下说法时，用 M35 框架逐层校验：

| 常见判断 | M35 校验 | 真实结论 |
|----------|---------|----------|
| "XX 股市创新高 = 牛市" | 第三层：期现是否背离？外资是否卖超？ | 创新高+派发 = 顶部结构而非牛市 |
| "央行还没加息 = 流动性宽松" | 第一层：缩表幅度是否>10%？ | 缩表=被动收紧，加息非唯一标志 |
| "日元贬值 = 利好风险资产" | 第二层：贬值是否到位+利差收窄？ | 贬值到位+利差收窄 = 套息反转前兆 |
| "散户接盘无所谓" | 第三层+第五层：机构派发+全民炒股 | 双信号叠加 = 购买力耗尽，见顶在即 |
| "债务高但能借新还旧" | 第四层：平均利率是否>名义增速？ | 利率拐头向上+增速下行 = 雪球触发 |
