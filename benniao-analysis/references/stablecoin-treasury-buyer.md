## 一、稳定币基本情况

### 运行规则

| 维度 | 详情 |
|------|------|
| **日常使用** | 跨境电商、外贸、跨境结算（到账快、手续费低） |
| **运行原理** | 与美元1:1兑换，发行公司收美元后购买美国短期国债 |
| **典型代表** | USDT（泰达币） |

### 市场规模

| 指标 | 数据 |
|------|------|
| **稳定币总规模** | 3000多亿美元 |
| **最大发行商持美债** | ~1350亿美元 |
| **全球排名** | 第17位（超过许多主权国家） |
| **增长预期** | 财长贝森特认为20年代末可能增长10倍 |

### 关键认知

```
每一个USDT的背后：
  用户存入1美元
  → 发行商收到1美元
  → 购买美国短期国债
  = 稳定币发行商 = 美国短债的被动买家
  = 3000亿美元稳定币 = 3000亿美元美债需求
```

## 二、美联储与美债政策转变

### 时间线

| 时间 | 政策变化 | 影响 |
|------|---------|------|
| 2025.12.1 | 缩表结束 | 美联储不再主动卖出美债 |
| 2026.1 | 转入准备金管理模式 | 靠买入短期国债补充银行体系流动性 |
| 未来 | 沃什任美联储主席 | 是否重启缩表待定 |

### 关键人物

| 人物 | 角色 | 立场 |
|------|------|------|
| **鲍威尔** | 结束缩表 | 为稳定币接盘创造条件 |
| **沃什** | 新任美联储主席 | 政策方向待定 |
| **贝森特** | 财政部长 | 重视稳定币作为短债买家 |

### 政策含义

```
美联储从卖方变成买方
+ 稳定币发行商持续买入
= 短债需求端巨量增加
= 短债价格上行压力 / 收益率下行压力
```

## 三、稳定币接盘的实质：赤字融资工程

### 表面 vs 实质

| 层次 | 说明 |
|------|------|
| **表面** | 稳定币是加密市场的便捷支付工具 |
| **实质** | 稳定币发行商 = 美国财政部的新债主 |
| **操作** | 贝森特与发行商商量发债节奏，主动配合财政需求 |

### 赤字融资的逻辑

```
美国美债总额高企
→ 传统长债需求疲软（主权国家减持）
→ 需要新买家
→ 稳定币行业 = 天然短债买家
→ 财长主动推动稳定币行业增长
→ 靠多发短债 + 稳定币接盘 = 填补财政窟窿
```

## 五、债主替换战略

### 旧债主 vs 新债主

| 维度 | 旧债主（中/日等主权国家） | 新债主（稳定币加密用户） |
|------|------------------------|----------------------|
| **集中度** | 大型主权国家集中持有 | 全球分散的加密用户 |
| **抛债威胁** | **高**（集中持有=集中抛售能力） | **低**（分散持有=难以集体抛售） |
| **政治杠杆** | **高**（主权国家可用美债做政治筹码） | **低**（加密用户无政治意图） |
| **可控性** | **低**（主权国家有独立意志） | **高**（发行商受美国监管） |
| **稳定性** | 受地缘政治影响大 | 受市场情绪影响，但无集体行动能力 |

### 战略效果链

```
稳定币制造短债需求
    ↓
财政部敢调整发行结构（多发短债）
    ↓
用分散的新债主替换大型主权债主
    ↓
解除主权国家的抛债威胁
    ↓
美国财政安全度提升
```

## 六、M18框架下的综合判断

### 对美债市场的影响

| 维度 | 判断 |
|------|------|
| 短债收益率 | 被压低（需求远大于供给） |
| 长债收益率 | 可能走高（长债需求仍然疲软） |
| 美债信用 | 短期改善（新买家涌入），长期存疑（债务本质未变） |

### 对美元霸权的影响

```
稳定币 = 美元的数字延伸
→ 全球加密用户实际上在持有美元
→ 美元使用场景进一步扩展
→ 美元霸权获得新支撑
```

### 对加密市场的影响

| 维度 | 影响 |
|------|------|
| 稳定币行业 | 政策利好（美国政府主动推动增长） |
| 加密市场整体 | 与美元体系深度绑定 |
| 监管方向 | 友好化（稳定币是财政工具，不会被打压） |

### 风险提示

- 稳定币增长能否如预期达到10倍存在不确定性
- 沃什是否重启缩表可能改变供需格局
- 长期风险从主权国家转移到了分散的加密用户身上
