## 0. 输入

- 标的 OHLCV 序列（日线，按时间升序，至少 60 根）
- 可选：用户指定形态类型（W底/头肩底/M头/头肩顶/三角/旗形/破底翻/假突破）；不指定则引擎自动扫描
- 前置依赖：量价数据（量先价行、爆量、背离判定需成交量列）

## 1. A. 颈线识别与画线规则

### A1 整理区定义
- 价格在区间 [L, H] 内来回 ≥ `min_bars`（默认 15，可调）根 K 线，无明显趋势
- 判定法（择一/并用）：
  - 区间内高低点标准差 < 区间高度 × `choppy_th`（默认 0.4）
  - 或收盘价对区间中值的线性回归斜率 ≈ 0（|slope| < 阈值）

### A2 颈线画法（点多为主原则）
- **多头颈线** = 整理区上缘：取区间内所有「反弹高点」（局部极高点），按「点多为主」连直线（≥2 点，点越多越准）
- **空头颈线** = 整理区下缘：取区间内所有「回档低点」（局部极低点），连直线
- **影线取舍**：实体高低点或含影线均可，按「连线穿过的点密集度」自动择——哪种取法连出的线穿过更多拐点，用哪种
- **头肩形态**：
  - 头肩顶颈线 = 连接 左肩低点、头部后回档低点、右肩低点（水平或微斜，点多为主）
  - 头肩底颈线 = 连接 左肩高点、头部后反弹高点、右肩高点
- **收敛三角形**：上缘 = 依次降低的高点连线（下倾）；下缘 = 依次抬高的低点连线（上倾）；两线向右收敛
- **旗形（平行通道）**：
  - 下飘旗形（多头中继）：下倾平行通道
  - 上飘旗形（空头中继）：上倾平行通道

### A3 颈线交易含义
- 突破（收盘/实体重心站上颈线）→ 颈线由压变撑
- 跌破 → 由撑变压
- 同时是 **进场触发器 + 停损线**

## 2. B. 等幅满足计算器

### B1 形态满足（招 1/6/8/10/11/12）
- 高度 `h = |形态极点 − 颈线|`
  - 底形态（W底/头肩底/三角底）：极点 = 形态最低点；颈线 = 上缘
  - 顶形态（M头/头肩顶/三角顶）：极点 = 形态最高点；颈线 = 下缘
- 一波目标 = 颈线 + h（多） / 颈线 − h（空）
- 两波目标 = 颈线 + 2h（多） / 颈线 − 2h（空）
- 书中：达两波满足「大多获利了结」

### B2 波段满足（招 4/5，下飘旗形/上飘旗形）
- 前段幅度 `d = |前高 − 回档低点|`（多） / `|前低 − 反弹高点|`（空）
- **前置条件（最易误用）**：必须先突破前高（多）或跌破前低（空），才能确认回档低点/反弹高点成立，才起算
- 目标 = 突破点 + d（多） / 跌破点 − d（空）

### B3 波数判定（算一波还是两波）
- **规模规则**：头部/底部形态酝酿时长、跌破后运行时长 → 决定波数
- **背离规则**：若算出目标严重背离基本面（负数、或跌破合理估值）→ 只做一波
- 默认：一波为基，两波需满足规模条件

```yaml
signal:
  pattern: W底/头肩底/M头/...
  direction: long/short
  neckline: <价格>          # 颈线水平
  neckline_points: [...]    # 画线点坐标（供绘图）
  entry: <价格>             # 进场 = 颈线突破/跌破
  stop: <价格>              # 停损 = 颈线（或 ±2~7% 动态）
  target1: <价格>           # 一波等幅满足
  target2: <价格>           # 两波等幅满足（若有）
  basis: 形态满足 / 波段满足
  basis_detail: <算法依据文字>
  evidence:                 # 论据字段，供图上标注
    touch_count: <颈线经过点数>
    volume_confirm: <量先价行? bool>
    precond_met: <波段满足前置是否满足? bool>
```
