## M54：债券组合会计分类透视法（HTM / AFS / FVTPL）

> 报表上没有浮亏，不等于没有浮亏。「不违约就没有损失」这句话只在**不被强制卖出**的前提下成立——而强制卖出恰恰是危机时刻必然发生的事。

### 核心原理

```
同一笔债券、同一个市价，记进哪张表，决定利润表是否难看：

  HTM（持有至到期）      → 市价波动**不进损益**，只在附注披露，按摊余成本挂账
  AFS（可供出售）        → 浮亏进 OCI（其他综合收益），不进当期利润，但进净资产
  FVTPL（交易类）        → 市价每日进当期损益，浮亏立刻打利润

二级市场下跌的性质（必须分清）：
  机会损失：旧券票息固定，新券利率更高 → 旧券只能降价才卖得掉
  本金损失：只有在**被迫卖出**时才发生（美国国债本身不违约）

浮亏「实体化」的触发条件（这是全部风险所在）：
  ① 负债端有随时可赎回/可支取的压力（基金、银行活期、保险退保）
  ② 流动性挤兑或资本充足率考核 → 被迫抛售
  ③ 一旦抛售，OCI/附注里的浮亏**当场变成已实现亏损**
```

### 标准分析步骤

```
□ 第一步：查会计分类 —— 该机构的债券资产记在 HTM / AFS / FVTPL 哪一档？（看年报附注）
□ 第二步：查负债端刚性 —— 负债是否可随时赎回？久期是否与资产错配？（银行活期 vs 保险长期保单）
□ 第三步：评估被迫抛售的触发概率 —— 赎回压力、资本充足率、评级触发条款、质押融资折价率
□ 第四步：算「浮亏实体化」的规模 —— 若被迫卖出 X% 持仓，损失 = X% × 未实现浮亏
□ 第五步：定性 —— 「报表干净」是**真安全**（负债长期锁定）还是**假安全**（负债随时可跑）
□ 输出：账面浮亏 + 实体化触发条件 + 该机构是「真稳」还是「纸面稳」
```

### 实战案例（2026-09 美债熊市中的两类机构）

| 主体类型 | 会计/负债特征 | 判断 |
|---|---|---|
| 台湾险企 / 部分保险资管 | HTM 为主 + 长期保单负债 | 报表**不体现**巨额浮亏；负债长期锁定 → 短期无实体化压力，但净资产与偿付能力受挤压 |
| 美国地区银行（2023 SVB） | AFS/HTM 混合 + 活期存款负债 | 存款挤兑 → 被迫抛售 → **浮亏当场变真亏，直接破产** |
| 共同基金 / 交易盘 | FVTPL | 每日计价，浮亏**当天**进利润 |

**纪律**：看到「某机构持有大量美债但报表无亏损」时，**不要读成安全**，要读成「风险被会计规则移出了利润表」。判断它的安全性，看**负债端会不会跑**，而不是看资产端账面价。

### 与现有框架的协作

- **与 M41（债务可持续性）**：主权不违约是「HTM 无损失」的前提；r→g 恶化会动摇该前提
- **与 M43（机构行为变迁）**：会计分类决定了机构「能忍多久」，直接影响边际买家行为
- **与 M21/M22（历史类比）**：1994 橙县、2023 SVB 都是「浮亏实体化」样本
- **与 M45（极值反向）**：极值抄底前，须先确认标的持有人里**有没有会被迫抛售的强制卖家**——他们才是最后一跌的执行者

## M55：利率变动 BP 归因分解法（费雪拆解的定量执行版）

> M37 告诉你「名义 = 实际 + 通胀预期」；本模块把这句话变成**可以逐 BP 对账的算式**，并给出定性阈值——因为实际贡献 80% 和通胀贡献 80%，是两种完全不同的世界。

### 核心原理

```
名义利率变动（BP） = 实际利率变动（BP） + 通胀补偿（breakeven）变动（BP）

实际贡献占比 = 实际利率变动 ÷ 名义利率变动
通胀贡献占比 = 盈亏平衡通胀率变动 ÷ 名义利率变动

定性阈值（本框架纪律）：
  实际贡献 > 70%  → 定价的是「资金机会成本 / 资金竞争」→ 周期性、可缓解、可定价
  通胀贡献 > 50%  → 定价的是「通胀失控」→ 需要央行真收紧，性质不同
  两者相当        → 处于「短端预期 + 实际利率」双主导区 → 政策收紧定价

必须分期限各算：  5Y / 10Y / 30Y 的实际贡献占比**不相同**，
                  长端受期限溢价与买家结构影响，实际端主导通常更强

配套弹性系数（把叙事换成可复算的数）：
  油价 → 长端弹性：布伦特从当期价回落至历史中枢，对 30Y 的贡献
  （实测：104 → 78 美元，对 30Y 贡献 **不足 10BP** → 传导极弱）
```

### 标准分析步骤

```
□ 取「名义利率变动」的**明确窗口**（起点日/终点日必须写出来）
□ 取同窗口的 breakeven 变动 → 得通胀预期贡献
□ 实际利率变动 = 名义 − 通胀预期 → 得实际贡献
□ 算占比 → 对照阈值定性（>70% = 资金竞争 / >50% 通胀 = 通胀定价）
□ 分期限复算 5Y / 10Y / 30Y，看占比是否一致（不一致说明定价逻辑分层）
□ 交叉验证：用 TIPS 实际收益率直接观测，与拆解结果对账
□ 算弹性系数：把「油价涨→利率涨」这类叙事换成 BP 数
□ 输出：性质定性（资金竞争 / 通胀 / 政策预期）+ 贡献占比 + 窗口说明
```

### 实战案例（2026-09 美债长端上行）

| 口径 | 名义变动 | 实际贡献 | 通胀贡献 | 实际占比 |
|---|---|---|---|---|
| 10Y（年初→9/9，工银国际程实） | **+65BP** | +53BP | +12BP | **82%** |
| 30Y（年初→9/9，同上） | **+44BP** | +36BP | +8BP | **82%** |
| 10Y（8/25→9/11，第三方日度） | +30BP | +25BP | +5BP | **83%** |
| 5Y（8/25→9/11） | +38BP | +34BP | +9BP | **89%** |
| TIPS 实际收益率（直接观测） | 10Y = **2.60%→2.62%**（2008-10 以来最高）；30Y ≈ **3.07%→3.12%** | | | |

**结论**：本轮长端上行，**实际端贡献稳定落在 82–89%**，通胀补偿贡献仅一成上下 → 定性为「资金机会成本变贵（资金竞争）」，不是「通胀失控」。这也解释了最反常的一处：**布伦特破 100 美元的同时，10Y breakeven 纹丝不动（2.377%）**——若市场真在定价油通胀，breakeven 必先动。

### 与现有框架的协作

- **与 M37（费雪拆解）**：M37 是概念工具，M55 是它的**定量执行细则**（分期限 + 阈值 + 弹性），并行使用、互不替代
- **与 M44（三元拆解）**：M55 算出「实际端主导」后，用 M44 再往下拆（期限溢价 / 自然利率 / 买家结构）
- **与 M19（通胀内外生分层）**：油价属外生冲击，须单独算弹性，不能混进通胀预期里
- **与 M13（利率定价消化）**：本模块用于事后归因，M13 用于事前定价概率

## M56：同源共振与因果链判别法

> 两条曲线同向，多数人的第一反应是编因果链。正确的第一反应是问：**它们是不是被同一个上游变量推着走？** 编错因果链，会得出方向相反的操作结论。

### 核心原理

```
观测：序列 A 与序列 B 同期同向

两种解释（必须区分）：
  ① 因果链：A → 中间变量 → B（有传导机制，有弹性）
  ② 同源共振：共同上游因子 F → A 且 F → B（无直接传导，弹性极弱）

判别三步：
  第一步｜列共同候选因：总需求？全球流动性？美元周期？风险偏好？
  第二步｜算传导弹性：让 A 变动一个单位，B 应该动多少 BP？
          弹性极小 → 因果链不成立，走 ③
  第三步｜找「共同因」的独立证据：能否找到只受 F 影响、与 A 无关的第三方指标
          若该指标同样异常，则 ② 成立

⚠️ 内部一致性检查：解析出的「共同因」必须能解释**双方**的全部事实。
   若某个事实与共同因矛盾，说明分层没做够（常见：把不同经济体的需求当成一个「总需求」）
```

### 标准分析步骤

```
□ 画出被怀疑的因果链（A → ? → B），写出每一环的传导机制
□ 逐环找弹性证据：该环的传导系数是多大？有没有量化研究支持？
□ 若弹性显著 → 保留因果链；若弹性可忽略 → 转同源共振假设
□ 为同源共振找共同上游因，并用第三方独立指标验证该因
□ 做内部一致性检查：共同因能否解释双方全部事实？矛盾处是否来自分层不足？
□ 输出：真因果 / 同源共振 + 对应的操作含义（这一步决定「A 跌了该不该做 B」）
```

### 实战案例（2026-09 油价 vs 美债收益率）

| 环节 | 检验 | 结果 |
|---|---|---|
| 表面因果链 | 油价涨 → 通胀预期涨 → 美联储加息 → 美债收益率上行 | 直觉成立，但属**编出来的链** |
| 弹性检验 | 布伦特从 104 美元回落至 78 美元（历史中枢），对 30Y 的贡献 | **不足 10BP** → 传导极弱 |
| 直接观测 | 布伦特破 100 美元期间，10Y breakeven | **纹丝不动（2.377%）** → 通胀预期未被油价推动 |
| 共同上游因 | 经济韧性 / 总需求偏强 → 同时推高利率与油价 | 成立 |
| **内部一致性警示** | 纪要同时声称「经济韧性太强」与「中国原油需求同比减少 60 万桶/日、库存充裕」 | ⚠️ **张力**：若需求真的强，中国油需为何下滑？→ 须按 M53 分层（美国需求强 vs 中国需求弱），不可用一个「总需求」混说 |
| 定性 | **同源共振**，非因果 | 操作含义：油价回落**不会**自动带来美债上涨；美债买点仍取决于长端自身的见顶信号 |

### 与现有框架的协作

- **与 M30（美元-油价相关性三阶段）**、**M40（资产相关性异动）**：同属「相关性不可直接读成因果」的方法族，M56 提供通用判别流程
- **与 M19（通胀内外生分层）**：外生冲击（油价）的传导弹性必须单独测，不能默认它进核心通胀
- **与 M53（K 型分化）**：内部一致性检查失败的典型补救手段就是分层
- **与 M37/M55**：弹性算完再用 BP 拆解，两者构成「归因双检」

## M57：增量拐点识别法（二阶导拐点）

> 压垮利率的不是「AI 存在」，而是「AI 资本开支还在加速」。**存量决定现状，增量决定边际**——判断宏观压力何时缓解，必须看二阶导，不看规模。

### 核心原理

```
对利率形成压迫的 = 融资需求的「增量」，不是「存量规模」

  「AI 产业消失」≠「AI 资本开支增速见顶」
  前者是存量坍塌（会带来衰退式利好）
  后者是增量回落（这才是利率的边际缓释）

拐点识别的硬指标（必须用可核查的数据，不能用叙事）：
  ① 发债规模（同比/环比）——最直接，反映融资需求
  ② 资本开支指引（公司公开 guidance）
  ③ 单位价格曲线（如每百万 token 价格、算力单位成本）——反映边际收益
  ④ 债务融资占资本开支的比例——比例还在升 = 融资需求仍在扩张

证伪纪律：
  「增速见顶」是本框架**最容易被证伪**的一类判断 → 必须绑定硬指标 + 写明证伪位
  若次年指引/发债额仍在增长，则该判断被证伪，不能靠「长期看会顶」自我辩护
```

### 标准分析步骤

```
□ 锁定「引擎」（谁在消耗增量资金：AI 算力？能源？财政？）
□ 取**增量指标**（增速、同比发债额、capex 指引变动），而非存量规模
□ 交叉验证四条硬指标（发债 / 指引 / 单位价格 / 债务融资占比）
□ 判断：增量是「仍在加速」「增速见顶」还是「绝对量回落」——三档含义完全不同
□ 只有当增量回落，才传导为「全社会融资需求下降 → 利好债券」
□ 写明证伪位（次年指引若 ≥ 当年，判断作废）
□ 输出：增量所处档位 + 证伪位 + 对利率的传导方向
```

### 实战案例（2026-09 AI 资本开支，**本模块的证伪样本**）

| 硬指标 | 实测 | 指向 |
|---|---|---|
| 四大云厂 capex 指引（2026） | 约 **7000–7450 亿美元** | 仍在上行 |
| 2027 云厂 capex（高盛预测） | 约 **9300 亿美元** | **继续增长** |
| 2027 云厂+芯片厂发债规模（高盛） | 较 2026 年**再增约 40%**，约 3400 亿美元 | **增速未见顶** |
| 债务融资占 capex 比例 | 30%（2026）→ **37.5%（2027E）** | 比例仍在升 = 融资需求扩张 |
| 2026 年 AI 相关发债 | 约 3200 亿美元（含 SPV）＝同期财政部新增长久期借款的 **68%** | 与主权争夺资本（接 M33/M42） |
| 政策/政治层面 | 9/14 特朗普与黄仁勋通话，确认「不因融资成本上升放缓」 | 利率敏感度反而下降 |

**判定**：外部纪要称「AI 资本开支增速**即将见顶**」→ **目前无证据支持，反向证据占优**。硬指标显示占比与绝对额双升，且产业对利率的敏感度在下降。**该判断尚未成立，需等 2027 年指引与发债数据检验。**

### 与现有框架的协作

- **与 M32（AI 债务传导链）**：M32 判「链会不会断」，M57 判「增量会不会缓」——同一链条的两个方向
- **与 M33（行业债务排挤）**：AI 发债规模 vs 主权融资需求 = 部门间资本争夺
- **与 M42（资金供需反推）**：增量是 M42 里「资金需求」这一侧的边际量
- **与 M50（库存耗竭拐点）**：同为拐点识别，M50 看库存耗尽（一阶），M57 看增速拐点（二阶）

## M58：单一锚点触发器法（拐点指标二元化 + 曲线形态四象限）

> 当三种叙事同时存在、谁也辩不赢谁时，别再辩了——**选一个最难被操纵、最贴近定价的指标，把「要不要动手」变成一个是/否的问题。**

### 核心原理

```
多叙事并存的困境：
  「财政拖累」「资金竞争」「通胀黏性」「信用重估」都能解释长端上行
  → 靠宏观辩论永远得不出操作结论

解法：把判断压缩到一个「锚点指标」的二元问题上
  ① 选锚：选**最难被操纵、最贴近真实定价**的价格量（本框架常用长端收益率/长债价格）
  ② 定判据：不是「应该会怎样」，而是「有没有发生 X」——二元、可观察、无歧义
  ③ 映射动作：锚点破位 → 维持等待；锚点不再破位 → 允许左侧分批
  ④ 单日不算数：至少需要连续 N 次「拒绝创新高」才构成确认

配套：曲线形态四象限（判断周期位置）
              长端快           短端快
  收益率上行  熊市陡峭化       熊市平坦化
  收益率下行  牛市陡峭化       牛市平坦化
  · 熊平 = 加息预期主导（短端政策定价）
  · 熊陡 = 长端风险定价（财政/供给/信用）
  · 由熊平转熊陡 = 政策定价让位给结构定价（本期争论焦点）
```

### 标准分析步骤

```
□ 列出当前并存的互相矛盾的叙事（不得只选一个）
□ 选定锚点指标（原则：价格量 > 统计估计量；单一市场 > 综合指数）
□ 定义二元判据（「是否创新高 / 是否跌破某位」），禁止用「预计」「大概率」
□ 定义动作映射（未触发做什么、触发做什么），在执行前写死
□ 同步记录曲线形态（熊平/熊陡/牛平/牛陡）→ 判断哪一端在主导
□ 每次新数据入账，只回答二元问题，不重新辩论叙事
□ 输出：锚点 + 判据 + 动作 + 当前状态（触发/未触发/争议）
```

### 实战案例（2026-09 美债：锚点首测记录）

| 项目 | 内容 |
|---|---|
| 锚点 | 30 年期美债收益率 / 长债价格是否继续创新高 |
| 破位侧状态 | 9/10 收 5.368%、9/14 最高 5.388%、9/15 盘中 **5.40%**（2007-06 以来最高，19 年新高） |
| **首测（9/16 美联储加息落地日）** | 加息 25BP 至 3.75–4.00%（12-0 全票）当日：**30Y 收 5.357%，反降 0.5BP**；10Y 收 5.012%，**升 2BP** → 长端**未跟随短端创新高** |
| 判定 | **单日构成「锚点未破」的第一个候选信号，但不足确认**；需连续观察长端是否继续「拒绝创新高」 |
| 曲线形态 | 年内实测为**熊市平坦化**（2s10s 由年初约 71BP 收窄至约 32–34BP）；9/15 单日 30Y +1.8BP > 2Y +0.1BP 为单日熊陡 → 处于「熊平转熊陡」的**转换争议区，单日可翻转** |
| 争议提示 | 同期机构观点对立：一方判「2026H2 由熊平转熊陡」，另一方实测数据显示年内仍是熊平。**形态判断须写窗口，不写窗口的形态结论无效** |
| 动作映射 | 30Y 继续创新高 → 不配置（浮亏继续扩大）；连续 3 次以上拒绝创新高 + 长端走平回落 → 允许左侧分批（M45 纪律） |

### 与现有框架的协作

- **与 M45（极值反向辩证）**：M45 说「极值解决赔率、不解决时机」，M58 就是那个「时机触发器」的具体实现
- **与 M44（三元拆解）**：锚点触发后，用 M44 判断上行性质（可逆否），再决定是否动手
- **与 M47（确定性门槛）**：无风险利率高位时，等待本身有收益（票息/短端），「不动作」不是零成本
- **与 M2（货币政策与利率）**：曲线四象限是 M2 里收益率曲线分析的形态化补充
