# 四方法论整合市场分析框架

> **核心定位**：这是**四套研究方法论的整合运用**，不是四位专家观点的拼凑。每次分析时，用方法论独立推导结论。专家本人的观点只是方法论的实战演示，仅作参考，不直接作为结论。

## 核心原则

```
方法论（可复用工具）→ 独立推导 → 结论
专家观点（历史示例）→ 仅参考 → 不直接引用为结论
```

1. **方法论优先**：每个分析维度的结论必须由方法论工具推导，不能直接引用专家观点
2. **多维交叉验证**：四套方法论从不同角度分析同一标的，结论互相验证或暴露分歧
3. **数据驱动**：所有结论必须有数据支撑，不接受纯主观判断
4. **强制推演**：必须输出兵棋推演情景树，展示二阶/三阶/四阶传导效应
5. **反馈闭环**：每次分析后回顾上次预测准确率，持续校准方法论

## 时间衰减权重机制

**方法论不过期，观点会过期**：

| 时间范围 | 观点权重 | 方法论权重 |
|----------|----------|------------|
| 7天内 | 100% | 100%（始终适用） |
| 1个月内 | 80% | 100% |
| 3个月内 | 60% | 100% |
| 6个月内 | 40% | 100% |
| 1年以上 | 20% | 100% |

**冲突处理**：
- 观点冲突 → 以最新观点为准
- 方法论冲突 → 以数据验证结果为准
- 方法论结论 vs 专家观点 → **方法论结论优先**

## 兵棋推演情景树（必须输出）

每次分析报告**必须**包含一个「兵棋推演情景树」，采用**「如果…就…」**的条件分支结构，像多米诺骨牌一样推演长链条传导。

### 核心思想

这不是结果分类表，而是**事件推演沙盘**。从一个真实事件出发，一步步推演它引发的连锁反应，每个节点都可以继续传导、分支或反转。要有创意，要发散，要看到别人看不到的二阶、三阶、四阶效应。

### 树状图结构规范

- **根节点**：当前局势（所有事件发生的起点）
- **每个节点格式**：
  ```
  🔀 如果 [具体事件]
  → [第一步后果：资产变化]
    → [第二步传导：引发什么新事件]
      → [第三步后果：最终资产影响]
  ```
- **节点可以有两种展开方式**：
  - **① 横向分支**：一个事件分裂成多个可能子路径（如：伊朗停战 → OPEC反应A / 以色列反应B / 俄罗斯反应C）
  - **② 纵向传导链**：一个事件一步步往下传，像多米诺（如：Fed降息 → 美元走弱 → 新兴市场资金流入 → 大宗商品反弹 → 通胀回升 → Fed被迫转鹰）
- **层级要求**：
  - 至少15个节点（不是分支，是节点总数）
  - 至少3条长链（传导≥4步）
  - 至少5个分支点（一个节点分出2-3个子节点）
  - 同一节点的兄弟分支标注概率，概率之和=100%
- **每个节点标注**：
  - 📊 **概率分数**（如果是分支节点）
  - 🎯 **资产后果**（列出受影响的资产方向和幅度）
  - 🏷️ **方法论标签**（这个传导逻辑来自哪套方法论工具箱）

### 创意发散要求（这是重点！）

**必须做到**：
1. **跨市场传导**：事件A影响市场B，再传到市场C（如：伊朗停战 → 油价崩 → 中东主权基金抽资 → 美股承压）
2. **时间差传导**：短期利多 → 中期利空（如：Fed降息 → 短期股市涨 → 中期通胀反弹 → 长期被迫加息）
3. **反身性传导**：市场预期反过来影响事件本身（如：美股暴跌 → 消费者信心崩 → 经济真衰退 → 股市更跌）
4. **意外传导**：看似无关的事件被串联（如：俄乌停战 → 欧洲重建 → 欧洲财政扩张 → 欧元走强 → 美元走弱 → 大宗商品涨）
5. **包含至少1个“脑洞级”长链**（≥6步传导，有创意、有逻辑、意想不到）
6. **包含「如果多事件同时发生」的组合分支**（如：停战+降息+AI商业化 = 全面牛市）

### 分类维度

按以下维度组织分支（每个维度至少2-3个分支节点）：
- 🌍 地缘政治（停战、冲突、制裁、联盟变化）
- 💰 货币政策（Fed决策、其他央行、流动性）
- 🤖 AI/科技（商业化、泡沫、技术突破、监管）
- 🇨🇳 中国因素（刺激、报复、改革、汇率）
- ⚡ 黑天鹅（爆雷、战争、疫情、政治动荡）
- 🎉 正向惊喜（多利好同时兑现、意外突破）

### 树状图位置与附件

- 放在报告的第10节（四方法论交叉验证之后、先行指标之前）
- 树状图后附「事件×资产」影响矩阵总览表
- 至少6个Chart.js图表辅助可视化

### HTML实现

- 使用纯 HTML/CSS/JS 实现（不依赖额外库）
- 每个节点用卡片形式，左列=条件，箭头，右列=后果
- 长链用缩进+连接线表示传导步骤
- 分支用同层并列表示
- 颜色编码：绿色=看多，红色=看空，金色=黄金，蓝色=中性

## 分析工作流（方法论驱动）

```
第0步：背景了解与新闻搜索（发散阶段）
  - 搜索最新新闻、政策动态、市场情绪
  - 发散搜索关联市场（不只看单一品种）
  - 按需读取 alphaear/last30days 参考skill
第1步：搜索具体市场数据（价格、供需、技术指标、资金流）
第2步：用杨世光方法论推导（宏观定位 + 跨市场传导）
  → 输出：经济周期/利率/美元/流动性/资产方向
第3步：用卢麒元方法论推导（制度结构 + 恒等式 + 阶段判断）
  → 输出：财政健康度/坍缩阶段/融资阶段/利润来源
第4步：用蔡森方法论推导（技术形态 + 量价 + 交易计划）
  → 输出：形态类型/颈线位/测幅满足/多空判断
第5步：用笨鸟方法论推导（数据拆解 + 因果链 + 反常信号）
  → 输出：数据双拆/降息预期/传导链/反常标记
第6步：四方法论交叉验证
  → 共识 = 高信心结论
  → 分歧 = 需进一步数据验证
  → 标注哪个方法论的推导链条更完整
第7步：兵棋推演情景树（多路径分支 + 条件 + 概率）
第8步：回顾上次预测（反馈闭环）
第9步：生成 HTML 报告（含丰富图表 + 树状图）
```

### 交叉验证规则

```
四个方法论对同一标的的判断：
├── 4/4一致 → 极强信号（confidence 85-95%）
├── 3/4一致 → 强信号（confidence 70-85%）
├── 2/4一致 → 弱信号（confidence 50-70%），以宏观+数据维度为准
├── 4/4分歧 → 无信号（confidence <50%），建议观望
└── 特殊情况：蔡森形态明确 + 宏观面矛盾 → 形态服从宏观（大周期>小周期）
```

## 权重体系

- **核心推导**（决定分析结论）：四套方法论 + 底层逻辑
- **辅助参考**（提供背景与发散）：alphaear 系列 + last30days + 专家个人观点
- **核心规则**：
  - 结论必须从方法论推导，不能直接引用专家观点
  - 专家观点只作为"方法论推导的参考示例"
  - 辅助参考不能推翻方法论推导结论
  - 如果方法论推导结论与专家观点矛盾 → 优先信方法论

> 每次分析前，先回顾上次分析的预测准确率，持续校准方法论。

### 反馈模板

```
【上次预测回顾】（如果有的话）
分析日期：YYYY-MM-DD
分析标的：XXX

上次预测 vs 实际结果：
□ 杨世光方法论推导：预测___ → 实际___ → 准确/偏差/错误
□ 卢麒元方法论推导：预测___ → 实际___ → 准确/偏差/错误
□ 蔡森方法论推导：预测___ → 实际___ → 准确/偏差/错误
□ 笨鸟方法论推导：预测___ → 实际___ → 准确/偏差/错误

方法论校准：
□ 哪个方法论的推导链最准确？为什么？
□ 哪个方法论出现了偏差？偏差在哪个环节？
□ 是否需要调整方法论的某个工具参数？
□ 本次分析应特别关注哪些修正后的环节？
```

### 反馈数据积累

每次分析后在报告中记录：
- 预测准确率统计（累计N次分析中，各方法论的命中率）
- 常见偏差模式（如：蔡森形态识别准确率高但时间节奏常偏慢）
- 方法论调优建议（如：当前环境下M3美元周期权重需上调）
