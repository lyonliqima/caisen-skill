## 经济学公式工具箱

> 经典经济学与金融公式是杨世光分析的底层工具。他在《金钱爆》基本面课程中系统讲授这些公式，并强调「理论是工具，不是教条」——必须结合实际市场数据和政策环境灵活运用，而非生搬硬套。这些公式与 M 系列方法论配合使用，提供定量推导的基础。

### 宏观经济学公式

#### F1：GDP 支出法核算公式

```
Y = C + I + G + (X - M)
```

| 变量 | 含义 |
|------|------|
| Y | 国内生产总值（总产出） |
| C | 居民消费支出 |
| I | 国内投资支出 |
| G | 政府购买支出 |
| X - M | 净出口（出口减进口） |

**杨世光的应用**：
- 从此公式出发分析中国经常帐顺差、超额储蓄与人民币升值的关系（2026/6/15 专期视频）
- 拆解各组成部分的变化，预判不同国家的经济周期拐点
- 解释新冠疫情后各国经济对政府支出（G）的依赖程度
- **与 M21 协作**：用净出口（X-M）持续扩大诊断「贸易盈余-汇率背离」
- **与 M27 协作**：用消费线（C）和投资线（I）交叉验证 GDP 增长质量

#### F2：费雪方程式（货币数量论）

```
MV = PY
```

| 变量 | 含义 |
|------|------|
| M | 货币供应量 |
| V | 货币流通速度 |
| P | 一般物价水平 |
| Y | 实际国民收入 |

**杨世光的应用**：
- 分析通货膨胀与货币政策的核心工具
- 解释为什么货币超发不一定立即导致通胀（当货币流通速度 V 下降时，MV 增量被 V 下降抵消）
- 结合 M2 增速与 GDP 增速的差异（即 MV−PY 的缺口）判断资产价格走势
- **与 M4 协作**：用 M2 增速与 V 的变化判断流动性是否真正传导到实体经济
- **与 M2 协作**：当 V 持续低迷时，央行即使持续扩表也难以推升通胀（日本式流动性陷阱）

#### F3：投资乘数公式

```
k = 1 / (1 - MPC)
```

| 变量 | 含义 |
|------|------|
| k | 投资乘数 |
| MPC | 边际消费倾向 |

**杨世光的应用**：
- 解释政府财政政策的放大效应：MPC 越高，财政刺激效果越大
- 分析不同国家财政刺激政策的有效性差异（取决于居民边际消费倾向）
- 中国超额储蓄（低 MPC）环境下，财政刺激的乘数效应被削弱
- **与 M21 协作**：低 MPC 导致储蓄堆积→贸易顺差扩大→汇率背离

#### F4：购买力平价理论（PPP）

```
S = P₁ / P₂
```

| 变量 | 含义 |
|------|------|
| S | 直接标价法下的汇率 |
| P₁ | 本国一篮子商品价格 |
| P₂ | 外国一篮子商品价格 |

**杨世光的应用**：
- 判断各国货币汇率是否被高估或低估
- 讨论人民币国际化进程时，结合购买力平价与实际汇率的差异进行分析
- **与 M3 协作**：PPP 为美元强弱的长期均值提供基准

### 金融估值公式

#### F5：戈登股利增长模型

```
P = D₁ / (r - g)
```

| 变量 | 含义 |
|------|------|
| P | 股票内在价值 |
| D₁ | 下一期预期股利 |
| r | 投资者要求的必要收益率（贴现率） |
| g | 股利固定年增长率 |

**杨世光的应用**：
- 基本面课程第七集称其为「价值投资的基石」
- 评估成熟行业（公用事业、消费）股票的合理估值
- **关键洞察**：股票价格与市场利率（r）成反向关系——这是理解央行政策对股市影响的核心
- **与 M2 协作**：利率上升→贴现率 r 上升→合理估值 P 下降→高估值股票面临「杀估值」

#### F6：杜邦分析法

```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
```

| 分解维度 | 公式 | 反映 |
|----------|------|------|
| 盈利能力 | 净利润 / 营收 | 产品定价权和成本控制 |
| 运营效率 | 营收 / 总资产 | 资产使用效率 |
| 财务杠杆 | 总资产 / 股东权益 | 债务杠杆水平 |

**杨世光的应用**：
- 基本面课程第四至第六堂系统拆解杜邦分析
- 通过将 ROE 分解为三个维度，识别企业盈利能力的真正来源
- **行业差异**：奢侈品靠高净利率、零售业靠高周转率、银行业靠高权益乘数
- **与 M25 协作**：用杜邦分析拆解 ROE 来源，判断估值由真实盈利还是杠杆驱动

#### F7：资本资产定价模型（CAPM）

```
Rᵢ = Rբ + βᵢ(Rₘ - Rբ)
```

| 变量 | 含义 |
|------|------|
| Rᵢ | 资产 i 的预期收益率 |
| Rբ | 无风险收益率 |
| βᵢ | 资产 i 的系统性风险系数 |
| Rₘ - Rբ | 市场风险溢价 |

**杨世光的应用**：
- 结合证券市场线（SML）讲解
- 分析市场风格切换时，β 值高低的股票在不同市场环境下的表现差异
- **牛市**：高 β 股票跑赢大盘；**熊市**：低 β 股票抗跌
- **与 M2/M17 协作**：利率变化改变无风险收益率 Rբ→改变所有资产的必要回报率→风格因子轮动
