# 笨鸟 M63：宏观观察数据清单（里克岛六节点死循环监测法）

> 来源：2026-10-18 对用户"里克岛"推演的蒸馏。用户用一个虚构小岛讲清了当下宏观的底层结构——老板不赚钱、打工人降薪、餐饮卷九块九、消费谨慎，但出口创新高、顺差大到被海外抵制。这不是段子，是一套**可观测的因果链**。本文件把它变成笨鸟的"宏观体检表"：观察宏观到底该拿什么数据，每张数据对应死循环的哪一环。
> 定位：这是一套**观察工具**，不是观点。它回答"现在死循环转到第几格了"，不替你下"该不该抄底/该不该空"的结论。
> 与笨鸟其他模块的关系：M1（数据拆解法）教"数量+质量双维看一个数"；M63 教"沿死循环六节点挑哪些数、怎么串起来看结构"。M63 是 M1 的**选数清单 + 串联框架**，二者配套（见文末组合使用）。

---

## 核心洞察

总量指标（GDP、社融、M2）会**掩盖**死循环，因为出口猛增和内需萎缩会互相抵消在总量里。要看见真相，必须沿里克岛的六节点逐一找数据，把"链条转到哪一环"标记出来。

```
里克岛六节点死循环（结构因果链，非观点）：

  ① 技术创新正循环          ② 产能过剩                ③ 价格战 · 降薪
  健康企业提效→超额利润→  ──> 供给>需求(140万vs100万) ──> PPI被打/工资停滞
  高工资→消费繁荣                                              │
        ▲                                                      │
        │                                                      ▼
  ⑥ 出口猛增 · 内需萎缩  <── ⑤ 健康企业被迫出海  <── ④ 僵尸企业信贷续命
  顺差巨大但钱包没鼓          内销不行转外销低价倾销      低效产能靠银行借新还旧吊着
```

**诊断逻辑**：六节点不是孤立的，是一根链条。单独一个节点异常（比如出口高增）可能是好事，也可能是死循环的节点⑤。只有当 **①↓ → ②↑ → ③↓ → ④↑ → ⑤↑ → ⑥↑** 的方向同时成立，死循环才被确认。任一节点方向相反，链条就断，结论要改。

## 第零步（前置铁律）：锁口径

> 所有数据在读数前，**先锁统计口径与基期**。口径错配是宏观误判第一来源。

本次核查中真实撞到的两个"同名异值"陷阱（直接做教材）：
- **产能利用率 74.6% vs 75.6%**：同名"工业产能利用率"，但一个是某年三季度、一个是另一年三季度；分"全国工业 / 制造业 / 分行业"口径也不同。错配一年或一类，结论直接反。
- **规上工业企业利润 +0.9% vs +15.7%**：同名"1-8月工业企业利润"，但一个是累计同比、一个是当月同比、或行业结构不同。不锁口径直接比，会得出完全相反的利润判断。

**操作**：每张表先写清——指标名 / 口径（全国工业还是制造业、累计还是当月、名义还是实际）/ 数据期（哪年哪季哪月）/ 来源（国家统计局月报原文还是二手综述）。先锁后读。

## 六节点观察清单（核心交付）

| 节点 | 数据指标 | 官方来源 | 频率 | 判读方向 | 里克岛对应 |
|------|----------|----------|------|----------|-----------|
| **① 正循环健康度** | 工业企业营业收入利润率 | 国家统计局（工业企业效益月度） | 月度 | 上行=健康扩张；下行=利润被挤压 | 马尔服装厂的"超额利润→高工资→消费繁荣" |

| **② 产能过剩** | 产能利用率（同①，重点看低值） | 国家统计局 | 季度 | 持续低于 75–78%=过剩；回升=边际改善 | 140万件产量 vs 100万件需求 |

| | 制造业固定资产投资累计同比 | 国家统计局 | 月度 | 还在冲=产能继续堆，恶化节点② | 扩产冲动未停 |
| | PPI 生产资料 vs 生活资料 分化 | 国家统计局（PPI 分项） | 月度 | 生产资料涨、生活资料不涨=上游扩产下游不接 | 上游扩产能、下游接不动 |

| | 核心CPI / CPI-PPI 剪刀差 | 国家统计局 | 月度 | 终端弱、剪刀差走阔=需求不足 | 工资难涨→消费谨慎→终端弱 |

| | M1 增速 vs M2 增速（剪刀差） | 中国人民银行 | 月度 | M1 低、剪刀差走阔=企业活化不足、钱空转 | 低效产能吊着不退出 |

| | 工业企业出口交货值（占营收比） | 国家统计局 | 月度 | 占比升=越来越依赖外需 | 内销不行转外销 |
| | 贸易顺差（海关口径） | 海关总署 | 月度 | 顺差持续扩大+进口相对慢=内需弱外需强 | 全世界被打趴、顺差巨大 |

| | 住户存款增量 / 储蓄率 | 中国人民银行 | 月度/季 | 存款猛增=不敢花、预防性储蓄 | 消费越来越谨慎 |

## 诊断流程（一步一步串）

```
第1步：锁口径（第零步）—— 每张表先写 指标/口径/数据期/来源，先锁后读。
第2步：拉六个节点的当期数据（上表左列），逐项填"升/降/分化"。
第3步：按 ①→②→③→④→⑤→⑥ 标记方向，画成链。
第4步：判定链条是否闭合——
        ①↓ ②↑ ③↓ ④↑ ⑤↑ ⑥↑ 同时成立 → 死循环确认（全面恶化阶段）
        部分成立 → 处于链条中段（如仅⑤⑥强、①④中性=外需强内需弱早期）
        方向相反（如①↑②↓）= 正循环健康，推翻死循环叙事
第5步：处方推演（仅框架，非投资建议）——
        维持节点④（继续借新还旧打点滴） vs 砍节点④+补节点①工资端（出清+补贴居民）
        两种路径对 ②产能过剩 与 ⑥内需 的含义相反，须分开讲。
```

## 实战校准（截至 2026-10 可获取的最新官方数据 · 仅作示例 · 落地须重跑）

> 下列数字用于演示"怎么填表"，**不是观点、会过期**。每项都标了来源与口径，复用时以国家统计局/海关最新月报原文为准。

- **产能利用率**：2026Q3 全国工业 ≈ **75.6%**（国家统计局，环比 Q2 的 73.0% 回升）。⚠️ 口径陷阱：NBS 部分综述文章出现 **74.6%** 为不同期间，须对当年官方季度发布，勿混。
- **CPI / PPI**：2026年9月 **CPI 同比 +0.9%**（环比 +0.2%，核心CPI +1.0%）；**PPI 同比 +5.0%**（环比 +1.2%，创近四年新高）。⚠️ 结构分化：PPI 上游强（煤炭+35.3%、油气开采+24.5%），终端 CPI 弱——典型"上游成本推、下游接不动"。
- **进出口**：2026前三季度 货物贸易 **39.94万亿元 +18.8%**；**出口 23.2万亿 +16.4%**、**进口 16.74万亿 +22.3%**、顺差约 **6.46万亿**；9月单月出口 **+29.6%**、进出口首破 5万亿。进口增速快于出口 5.9 个百分点（内需边际回暖信号，但顺差仍巨）。
- **工业企业利润**：2026年1-8月 规上利润同比**由降转升**（⚠️ 口径：不同发布显示 **+0.9%** 或 **+15.7%**，须核对"累计/当月"及行业结构）；8月当月 **+20.4%**、营收利润率 **5.83%**。
- **居民收入**：须从 NBS 住户调查拉"居民人均可支配收入及工资性收入增速"（本次未取到干净的 2026前三季度值，列为**待补**——这正是 M63 第零步要补的口径）。
- **社零 / 储蓄率**：须拉最新月度（本次未取干净值，列为**待补**）。

**示例性读取（非观点，仅演示判读）**：从已核实数据看，呈现"出口猛增（节点⑤/⑥强）+ PPI 上游强但终端 CPI 弱（节点③分化）+ 产能利用率偏低但环比回升（节点②边际改善）+ 工业企业利润修复（节点①边际改善）"的组合——与里克岛"外需强、内需弱、价格战但未全面恶化"的**中段**吻合。是否进入全面死循环，取决于**节点④（信贷续命/僵尸）**与**节点⑥（内需萎缩）**是否继续恶化，这两项本期数据缺口最大，需补。

## 常见误用

1. **只看 GDP 总量与社融** —— 总量掩盖死循环（出口增与内需弱互相抵消）。必须拆结构。
2. **把出口高增当"经济好"** —— 出口高增可能是节点⑤（被迫出海），是死循环的表现而非健康。
3. **不锁口径直接比同比** —— 本次 74.6%vs75.6%、+0.9%vs+15.7% 即是教训，错配一年或一口径结论直接反。
4. **把 PPI 上游强误读为全面通胀** —— 实为上游成本推动、终端 CPI 弱，是"上游强下游弱"的分化，不是需求拉动型通胀。
5. **单节点异常就下诊断** —— 六节点须同时标方向，单点异常（如仅出口强）不构成死循环确认。
6. **用示例数字当现在** —— 本文件示例数据会过期，落地必须用最新官方月报重跑。

## 铁律（宏观观察数据清单）

1. **先看结构不看总量** —— GDP/社融掩盖死循环，必须沿六节点拆。
2. **每个节点先锁口径再读数** —— 本次 74.6%vs75.6%、+0.9%vs+15.7% 即教训；先写清 指标/口径/数据期/来源。
3. **出口高增 ≠ 经济健康** —— 可能是节点⑤（被迫出海），须结合节点⑥（内需）一起看。
4. **六节点须同时标方向** —— 单节点异常不构成诊断，链条闭合才确认死循环。
5. **数据用最新官方源重跑** —— 本文件示例数字会过期，落地以国家统计局/海关月报原文为准。
6. **本文件是工具不是观点** —— 它告诉你"死循环转到第几格"，不替你下交易结论；处方推演须过 M48 资产负债表检验。
