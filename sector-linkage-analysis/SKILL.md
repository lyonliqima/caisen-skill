# 板块间联动关系实证分析法（状态依赖型虹吸）

## 何时用

用户问一类问题：**「X 板块起来，Y 板块会怎样？」**
典型形态：跷跷板？还是同涨同跌？能不能从 X 推导 Y？

## 铁律（先记住这四条，否则分析必错）

1. **板块间不存在固定关系，只存在「状态依赖关系」。** 一个板块大涨，另一个板块的命运由**大盘水位**决定，不由该板块自身涨幅决定。凡是给出「单一方向固定结论」的分析，都是错的。
2. **不许输出概率百分比，只给准确判断。** 用户硬性要求。用「胜率 n/N」这种**可核查的频次**表述替代概率；结论必须收敛为 方向 + 期限 + 幅度 + 证伪位。
3. **相关性 ≠ 因果，且共跌会制造伪负相关。** 剥离 beta 之前的相关性不可用作结论，必须先看原始相关与超额相关的**符号是否反转**。
4. **口径必须显式声明。** ETF 份额拆分/复权、板块口径 vs 单只标的口径，混用即结论作废。

---

## 执行步骤（七步）

### 第 0 步：先把问题问对

用户原话「X 起来，Y 会怎样」隐含一个未验证前提：**X 现在真的起来了？**
→ 必做：先验证 X 当前状态。**这个前提经常不成立**，一旦不成立，整个问题的答案就变成「条件不成立，不做」。

### 第 1 步：数据准备

取三组周线（或日线后合成周线），**必须含基准（沪深300 / 000300）**：
- X（发起板块）、Y1、Y2（目标板块）、**基准**（这是本方法的灵魂，不能省）

统一为**周度收盘序列**，计算 **4 周滚动收益率**（`close[t]/close[t-4]-1`，报率 %）。

### 第 2 步：事件筛选

筛出 X 的 4 周滚动收益 ≥ 阈值的所有月份/周。
- 阈值定法：优先用 X 自身波动率定标（≥2σ）；无 σ 时用固定值（如 12%）。
- 记录每组事件的**月份标签**，后文分组要用。

### 第 3 步：关键分组（本方法的核心动作）

把事件组按**同期基准是否同步上涨**二分：

| 组 | 定义 | 含义 |
|---|---|---|
| **增量普涨型** | 同期沪深300 4周涨 > 3% | 有增量资金，全场水位上抬 |
| **存量独立型** | 同期沪深300 4周涨 ≤ 3% | 无增量，场内零和博弈 |

对每组分别算：X / Y1 / Y2 / 基准 的**均值收益 + 中位数 + 胜率(n/N)**。

**判读规则**：
- 两组的 Y 收益**符号相反** → 确认「状态依赖型虹吸」，开关 = 大盘水位。
- 两组的 Y 收益基本同向 → 不存在状态依赖，走常规 beta 解释。

### 第 4 步：反证检验（能不能被否掉）

再筛 **X 的 4 周滚动收益 ≤ −阈值** 的事件组，看 Y 的表现。
- Y 同向下跌 → **双向跷跷板被否证**，只存在单向虹吸（X 涨时抽血，X 跌时一起跌）。
- Y 反向上涨 → 跷跷板成立。

**不做这一步的分析不成立。** 这是把「讲故事」变成「有证据」的分界线。

### 第 5 步：相关结构三件套（找符号反转）

用 4 周滚动序列做**全样本**相关（n = 滚动窗口总数）：

1. **原始收益相关**（含 beta 层）：共用一个大盘，应**全为正**。
2. **剥离 beta 的超额收益相关**（`个股收益 − 基准收益`）：alpha 层零和，应**出现负值**。
3. **同组内 Y1 − Y2 的超额相关**：若为**显著正值** → Y1 与 Y2 是**同一因子**。

**判读**：原始相关为正、超额相关为负 = **符号反转** = 最硬的因子重叠证据。
→ 同一因子的板块**必须合并计算仓位**，不能各给一份仓位。

### 第 6 步：波动率定标

**⚠️ 口径铁律：σ 必须用「单周收益率」的 σ_1w，再按 √horizon 缩放到持有期。**

```
σ_H（持有期） = σ_1w × √持有周数
目标区间宽度   = 1 × σ_H        （即 1σ 区间）
证伪位最小距离 = 1.5 × σ_H
```

**错误示范**：拿 W 周滚动收益的 σ_W 再乘 √horizon —— σ_W 本身已含 √W 因子，会**重复放大**。
（实战验证：半导体 σ_1w = 5.90% → σ_H = 5.90 × √12 = 20.4% → 证伪距离 30.6pct，与报告吻合；若误用 σ_W = 13.47% 会算出 70pct 的荒谬值。）

→ **证伪位距离小于 1.5σ_H 的研判是无效研判**，会被日常噪声打掉。

### 第 7 步：当前状态定位 → 收敛

代入当前价格，算三个数：
- 距**触发价**还差多少 %（正 = 还没到）
- 距**止损价**多少 %（负 = 更近）
- **风险回报比** = 上行空间 ÷ 下行空间

**纪律判定**：
- 风险回报比 < 1:2 → **0% 仓位**，写明「不是看空，是条件不成立」。
- 二选一时，选**与大盘 beta 更一致、波动率更低、估值位置更低**的那个。
- 同因子板块**合计仓位上限**（如 ≤10%），不叠加。

## 输出规范

1. **结论先行**：开门见山给准确判断，不铺垫。
2. **不给概率**：用「胜率 11/11」「0/5」这类频次，不用「约 70% 概率」。
3. **提示前提是否成立**：若 X 当前没「起来」，第一句就说，并给出 0% 仓位结论。
4. **数字给算式**：每个关键数字带上怎么算出来的。
5. **图表**：用 `analysis-report-template/render.py` 出 Chart.js HTML 报告（9 图以上）。
6. **显式纠偏**：把发现的口径问题、用户前提错误，单列一节声明。

## 陷阱清单（踩过的坑）

| 坑 | 症状 | 处理 |
|---|---|---|
| **ETF 份额拆分** | 月线值与给定值恰差整数倍（如 2.0 倍） | `data_kline` 传 `fq:""` 复核有无跳空缺口；若接口返回的 qfq 已自动拆分调整，则数据可用。查交易所公告核实登记日/除权日 |
| **口径混用** | 「某板块主力净流入 43 亿」与「单只 ETF +2.83 亿」相加 | 全市场行业板块口径 ≠ 单只标的口径，**不可混用或相加** |
| **共跌伪负相关** | 超额相关为负就下「虹吸」结论 | 先看原始相关是否为正（符号反转才成立）；并检查负相关是否只是「一起跌」的产物 |
| **只做上涨组** | 得出「半导体涨 → 地产养殖跌」的单向结论 | 必做第 4 步反证检验 |
| **verify_charts.js 不查数值** | 结构 PASS 但数组数值是凭记忆拼的 | 定稿前**逐日重算**图表数组，别信记忆 |
| **render.py 删 body** | 渲染后找不到 body 片段 | 渲染前先用 `cp` 另存一份备份，文件名加下划线前缀 |
| **body 手写 Markdown 加粗** | 页面出现 `**文字**` | 定稿前 `grep -o '\*\*' <输出.html> \| wc -l` 必须为 0 |

## 配套脚本

`linkage.py` —— 输入规范化 JSON，一次算出第 2–6 步全部数字。

```bash
python3 linkage.py --data series.json --x 半导体 --bench 沪深300 \
  --y 房地产 养殖 --threshold 12 --bench-threshold 3 --sigma-years 2
```

输入 JSON 契约（长表，最省事）：

```json
{
  "半导体": [["2024-01-05", 0.812], ["2024-01-12", 0.845]],
  "房地产": [["2024-01-05", 0.612], ["2024-01-12", 0.629]],
  "养殖":   [["2024-01-05", 0.498], ["2024-01-12", 0.501]],
  "沪深300":[["2024-01-05", 3.412], ["2024-01-12", 3.455]]
}
```

输出：事件清单 + 二分组统计（均值/中位/胜率）+ 反证组 + 三对相关系数 + 各标的周 σ 与证伪位距离。

## 实战结论存档（2026-09-16）

标的：半导体（512480）× 房地产（512200）× 养殖（159865）× 沪深300

| 组 | n | 半导体 | 房地产 | 养殖 | 沪深300 |
|---|---|---|---|---|---|
| 增量普涨型 | 11 | +18.9% | **+8.5%（中位 +3.2%，胜率 91%）** | **+4.0%（中位 +1.7%，胜率 82%）** | +7.2% |
| 存量独立型 | 5 | +19.0% | **-5.5%（胜率 20%）** | **-6.4%（胜率 0%，0/5）** | -1.0% |

同为半导体涨约 19%，房地产差 14pp、养殖差 10.4pp。

- 反证（半导体跌 ≥12%，n=11）：房地产 -2.3%（胜率 27%）、养殖 -1.3%（胜率 36%）→ **同向跌，跷跷板否证**。
- 超额相关：半导体−房地产 **-0.182**、半导体−养殖 **-0.307**、**房地产−养殖 +0.356**；原始相关全正（+0.270 / +0.164 / +0.545）→ **符号反转**。
- 周 σ：半导体 5.89% / 房地产 4.29% / 养殖 3.20% / 沪深300 2.45%。
- 长期（2019-06-14→2026-09-16）：半导体 +316.5% / 房地产 -50.5% / 养殖 -43.4% / 沪深300 +22.6%。
- 结论：房地产与养殖是**同一因子**（超额相关 +0.356），须合并仓位；均给 0% 仓位（条件不成立）；二选一选房地产。
