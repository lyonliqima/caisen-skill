## 二、该文的算法拆解（"怎么算的"）

该文与本地 skill 最大的结构差异：**它用「实质负利率」当总纲，用「仓位结构变化」代理流向，用「波动率+估值分位」代理流速**。

### 0）前置总纲 —— 实质负利率

```
实质负利率 = 名义利率 − 名义CPI − (M2增速 − GDP增速)
                              └──── 货币超发率 / 货币化缺口 ────┘
```

- **名义利率**：该文取 **Shibor 1Y**。理由（原文）："央行已取消统一基准存款利率，LPR 1年期为 3.0% 但主要影响贷款端，Shibor 更能反映银行间资金成本及理财替代效应"。→ **这个口径选择是对的**，事后核验 2026-09-11 Shibor 1Y = 1.4800%（见第四节）。
- **第二项 `M2增速 − GDP增速`** 是"货币超发"对持有现金购买力的侵蚀，这是该文相对本 skill 最有价值的独立贡献。
- 该文实测：`1.48% − 0.5% − (7.7% − 4.7%) = −2.02%`

### 1）资本流向 —— 用「持股比例变化」替代「净买入额」

- **外资**：以**季度末北向持股比例变化（pct）**取加仓/减仓 Top3 对照。
  - 方法学上绕开了"2024-08 起交易所停止披露每日净买入额"这一数据缺口 —— 与本 skill 用「外汇储备变动」代理是**两条不同路**，可互补。
  - 代价：**季度频率、滞后约一个季度**，不能当高频信号用。
- **内资**：近 5 交易日**南向资金净流入合计**（亿港元）+ 重点标的（阿里-W、腾讯、南方恒生科技）。

### 2）资本流量 —— 三层递进（货币总量 → 实体需求 → 产业扩产）

| 层 | 该文用的指标 |
|----|--------------|
| 货币总量 | M2 余额 355.5 万亿、同比 7.7% |
| 实体需求 | 制造业 PMI 49.8；**新订单 49.4**（收缩）；**新出口订单 47.9**（外需承压）；PPI 同比 3.5%；**生产资料 +4.8% vs 生活资料 −0.8%**（上游有支撑、终端疲软） |
| **产业扩产强度** | **扩张−需求差 = 在建工程增速 − 营收增速**（分行业） |

**"扩张−需求差"是该文最有价值的原创落地指标**（本 skill 目前没有）：

- 正值大 → 在建工程增速远超营收增速 → 产能未消化即在扩产 → **过剩/价格战风险**
  - 该文读数：综合行业 **+33.21pct**、建筑装饰 **+13.51pct**、公用事业 **+10.60pct**
- 负值 → 资本开支收缩 → **行业已进入出清**
  - 该文读数：通信 **−5.91pct**、美容护理 **−6.92pct**
- 数据来源：上市公司财报（在建工程科目 vs 营业收入科目），属**季频**，不是日频。

### 3）资本流速 —— 用「市场风险分 + 波动率 + 估值分位」代理

| 指标 | 该文口径 | 该文读数 |
|------|----------|----------|
| 市场风险分 | 综合打分，按**历史分位**分档（🔴高危 = 历史最高 25% 分位） | 73.39（高危档） |
| 年化波动率 | 阈值 ≥24% 判高波动 | 25.97% |
| 历史回测含义 | 同档位下未来 3 个月回撤幅度历史发生比例 | ≥10% 为 64%、≥15% 为 33% |
| 估值水位 | 沪深300 PE/PB 近5年分位 + **动量赢家估值分位** | PE 73.99%、PB 58.97%、动量赢家 87.38% |

→ 这是"**情绪—波动口径**"，与本 skill 现有的"DR007 / 换手率 / 信用利差 "**货币—交易口径**"互补，本 skill 目前缺"波动率 + 估值分位"这一层。

### 4）输出结构（可直接借用）

```
五节分维（实质利率 / 资金活化 / 外资流向 / 产业周期 / 市场波动）
  → 现状-信号含义对照表
  → 情景推演（附概率 ← 本框架不采用）
  → 关键观察指标（带"下次验证窗口"+ 具体日期）
```

**"关键观察指标 + 明确验证日期"这一条值得抄**。该文给的四条与验证窗口：
1. M2−M1 剪刀差是否连续 3 周（约 15 个交易日）收窄 → 资金活化
2. 制造业新订单是否连续 2 个月站上 50% → 内需回暖
3. 北向持股季度变化 → **2026-09-30 季报披露**验证三季度是否继续加仓高端制造
4. "综合""建筑装饰"在建工程增速是否放缓 → 产能过剩风险缓解

## 五、该文未说但重要的三点（本框架补充，属推论非事实层）

1. **PPI 的"上游有支撑"应改为"输入性涨价 + 已开始退潮"**。
   该文只引同比（+3.5%，生产资料 +4.8%），但官方同期数据显示：**环比 −0.7%（降幅比上月扩大 0.4pp）、同比涨幅比上月回落 0.6pp**；且涨价集中在输入性品类——有色金属材料及电线 **+19.0%**、燃料动力 **+9.3%**、化工原料 **+9.3%**，而建筑材料及非金属 **−4.1%**、农副产品 **−0.8%**。
   → 上游价格是**外部输入推动且动能正在衰减**，不是内需拉动。这削弱了该文"流量层面上游有支撑"的强度。

2. **"微观紧信用"有比 PMI 更直接的数据支撑，同时还揭示了流量的真实来源**。
   央行 7 月数据：社融存量 +7.4%，但**1–7 月社融增量 22.25 万亿、同比少增 1.74 万亿**；对实体经济人民币贷款 +5.2%（低于社融增速）；而**政府债券余额 +14.1%**（社融中唯一高增项）。
   → 说明当前**社融扩张主要靠财政加杠杆，不是信贷需求回暖**。"宽货币紧信用"的更准确表述是"**宽货币 + 财政强 + 信贷弱**"。

3. **该文的自报风险分（73.39 高危）与 2026-09-11 当日行情是一致的，不是矛盾**。
   当日上证综指 **−1.18% 至 3888.11**、深证成指 −1.08%、创业板指 −0.49%，10 年期国债收益率上行至 1.684%，人民币中间价 6.7743（较年初升值）。
   → 该文标题"高危波动"与正文"高位震荡"措辞不统一；**风险分高危 + 当日已在下跌 → 应读作"脆弱已开始兑现"，而非"高位震荡待变"**。

## 七、原文全文归档

> 以下为该文正文全文（用于日后核对原始表述，不排版美化）。标题《2026年9月中国资本三流深度研判：实质负利率下的流量淤积与高危波动》，公众号「资本三流分析助手」，2026-09-12 11:59 发布，数据基准"2026 年 09 月 11 日收盘"。原文以代码块完整保存，避免二次概括失真。

```text
今日非交易日，以下为2026年09月11日收盘数据。

基于「资本三流」框架（流向、流量、流速），结合宏观实数与财报数据，当前中国资本市场呈现出
「流量充裕但活化不足、流向剧烈分化、流速进入高危区间」的复杂特征。以下是详细拆解：

一、核心指标测算：实质负利率已达 -2.0%

根据您的定义公式：实质负利率 = 名义利率 - 名义CPI - (M2增速 - GDP增速)

- 名义利率：参考Shibor 1年期利率 1.48%（注：央行已取消统一基准存款利率，LPR 1年期为
  3.0%但主要影响贷款端，Shibor更能反映银行间资金成本及理财替代效应）。
- 名义CPI：2026年7月同比 0.5%。
- M2增速：2026年7月同比 7.7%。
- GDP增速：2026年Q2同比 4.7%。

计算结果：1.48% - 0.5% - (7.7% - 4.7%) = 0.98% - 3.0% = -2.02%

解读：实质负利率处于-2.0%的深度区间。这意味着持有现金或低息存款的实际购买力在以每年2%的
速度缩水。理论上，这会驱动资本逃离储蓄，寻求更高收益资产。然而，M2-M1剪刀差在7月仍达3.7
个百分点（M1同比4.0%，M2同比7.7%），说明大量货币依然淤积在定期存款与企业活期账户中，并未
有效转化为实体投资或消费动力，出现了典型的「流动性陷阱」特征。

二、资本流向（Direction）：外资结构性调仓，内资偏好红利与出海

由于港交所自2024年8月起停止披露每日净买入额，我们通过2026年二季度末北向持股比例变化来观察
真实流向：

- 大幅加仓方向：天承科技（+7.85pct）、潍柴动力（+7.51pct）、艾罗能源（+6.01pct）。这些标的
  集中在高端制造、出口链及新能源细分龙头。
- 大幅减仓方向：中信金属（-8.92pct）、华明装备（-6.69pct）、星网锐捷（-5.33pct）。外资正在
  从部分资源类及传统设备股中撤出。
- 结论：外资并非全面撤离，而是在进行剧烈的结构性换仓，从周期性资源股转向具备全球竞争力的
  制造业龙头。

近5个交易日（9月7日-11日），南向资金合计净流入27.46亿港元，日均约5.5亿港元，保持稳步流入态势。

- 重点标的：阿里巴巴-W、腾讯控股、南方恒生科技。内资正在通过港股通配置低估值的互联网科技
  巨头，反映出对国内核心资产估值修复的预期。

三、资本流量（Volume）：宏观宽货币与微观紧信用的背离

- 货币总量：M2余额达 355.5万亿元，同比增速 7.7%，绝对流量巨大。
- 实体需求：
  - PMI：8月制造业PMI为 49.8，虽接近荣枯线，但新订单指数 49.4 仍处于收缩区间，新出口订单
    47.9 显示外需承压。
  - PPI：7月PPI同比 3.5%，生产资料同比 4.8%，显示上游价格仍有支撑，但生活资料同比 -0.8%，
```
