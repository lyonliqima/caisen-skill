## Z24 短端利率三因分离法

**一句话**：短端利率异动，必须拆成**三个可独立证伪的因**，用利率期货定价交叉验证；**不许跳过一手证据最直接的因，去选一个不可观测的因**。

### 操作步骤（缺一步不准下归因结论）

1. **列三因**：① 通胀预期（当期 CPI/PPI 一阶导）② 政策路径（FOMC 点阵、官员表态、CME FedWatch 定价）③ 资本供需 / 期限溢价（拍卖得标利率与当时二级市场收益率之差、准备金、回购利率）。
2. **逐因找一手证据**：每一因至少一条可复现数据，写清发布日与口径；查不到就写「无证据」，不许用叙事填。
3. **看政策利率期货定价**：短端收益率与政策利率的价差是否扩大、市场对下次会议的加息概率是否重定价。**这一步能直接分辨「央行态度」是不是主因**。
4. **看拍卖尾部**：得标利率高于当时市场收益率（tail）→ 供给/需求压力；低于 → 需求良好。「得标率越来越高」这类转录表述必须回原始表核对是**得标利率**还是**投标倍数**。
5. **才下归因**：只写「哪一因在当期贡献最大 + 证据」；三因都无证据时，结论是「**归因未定**」，不是「所以是资本稀缺」。

### 硬约束

| 约束 | 说明 | 2026-11-13 实锤 |
|---|---|---|
| **不许排除已有一手证据的因** | 口播说「不是通胀、不是央行态度、甚至不是第一原因，因为脱钩了」 | 当期一手链完整：10 月 CPI 环比 +0.4%（预期 0.3）、核心 +0.3%（连续三月）→ 沃勒 11/10 伦敦支持 12 月加息 → CME 加息概率 84.2%→约 99% → 2Y 单日 +18.46bp。**政策路径重定价就是主因** |
| **「脱钩」要先证明** | 说 2Y 与官方利率脱钩，须给两段序列的滚动相关与错峰检验，不能凭一次观察 | 口播未给任何序列 |
| **不可观测量降级** | 「资本被占用 / 资源被浪费」若无法落到可观测指标，只能作**提问清单**，不得作结论 | 与 11/12 王安「上帝视角」、11/04「EPS 减速归因库存周期」同型，第三次复现 → **永久前置** |

### 接口
- 与 **Z1**（需求→供给→落点三段式）同骨架，对象换成利率。
- 与 **Z13** 连用：官方/口播叙事 ↔ 一手定价数据，做双叙事对照。

## Z25 曲线形态符号核验（熊平 ≠ 倒挂）

**一句话**：**在写下「倒挂」两个字之前，先回一手数据算 10Y−2Y 的符号**。利差收窄（熊平）与利差转负（倒挂）是两件事；机构对未来的预测不是既成事实。

### 操作步骤

1. 取同一时点的 2Y、10Y（必要时 + 30Y）收盘，逐日算 **10Y−2Y**，单位 bp，**带符号**。
2. 判形态：利差 > 0 且收窄 = **熊平**；利差 < 0 = **倒挂**；利差 > 0 且走阔 = 熊陡。写清是哪一种，不许混用。
3. **逐日核「短端涨得比长端快」**：拿 2Y 与 30Y 的当日 bp 变动直接比，不许用 CPI 冲击当天的形态外推整段。
4. **区分「已发生」与「预测」**：机构原话若含「若 / 可能 / 不会意外」，一律标预测，不得写成状态。
5. 历史类比若涉及不同利率水平（如「上次倒挂时 2Y 不到 2%」），**先核该数值属于哪个主体、哪个国家**，禁止跨主体借数。

### 硬约束（2026-11-13 实锤）

| 项 | 口播 | 一手 | 裁决 |
|---|---|---|---|
| 形态 | 「可能要倒挂」「这一次的倒挂」 | 11/10 2Y 4.742 / 10Y 4.996 → **+25.4bp**；11/12 4.881 / 5.133 → **+25.2bp**，均为正 | ❌ **本期最硬错误**：熊平被讲成倒挂 |
| 机构原话 | 未区分 | 普信 Husain：「如果曲线在相对不久的将来出现倒挂，也不会感到意外」＝**预测** | 预测 ≠ 状态 |
| 短端 > 长端 | 「连续三个节目都这样」 | 11/10 2Y +18.46bp vs 30Y +7.74bp ✅；**11/12 2Y +9.95bp vs 30Y +10.73bp、10Y +13.51bp → 长端涨更多** | ⚠️ 单日形态外推整段，**第四次同型复现** |
| 历史起点 | 「2000 年不到 2%、2006 年 1.0%」 | 2000 年美联邦基金利率约 6.5%、2006 年 5.25% | ❌ 跨主体借数，标 T3 |

### 接口
- 与 **Z18** 同源：Z18 防把「涨幅回落」念成「下跌」，Z25 防把「利差收窄」念成「利差为负」，以及把「将来可能」念成「已经」。
- 与 **Z23** 同源：都是「读法防错」族，一个防念反符号，一个防念反时间箭头。

## Z26 微观→宏观类比的迁移边界表

**一句话**：把企业/银行的行为放大成国家之前，**先列一张两栏表：哪些机制可迁移、哪些约束不可迁移**；不可迁移项多于可迁移项时，类比只能当提问，不能当结论。

### 操作步骤

1. **写清两个主体**：微观主体是谁、宏观主体是谁（Z21 第 1 步，缺这步直接停）。
2. **列可迁移项**：机制层面共有的（如「短期融资压力上升时，先抢短钱、不锁长钱」）。
3. **列不可迁移项**：**逐条写约束差异**——本币铸币权、央行最后贷款人、存款保险、违约定义、预算约束、期限错配的清算方式。
4. **找可观测的宏观对应物**：微观机制若在宏观成立，应有对应指标（回购利率、准备金、拍卖尾部、互换基差）。找不到 → 类比降级为软证据。
5. **给证伪位**：什么数据出现说明类比不成立。

### 2026-11-13 实锤
- 口播：「即将破产的银行会大幅拉高短期存款利率救急、不拉长期 → 放大 1000 倍、1 万倍就变成国家」。
- 可迁移：流动性紧张时短端资金价格先反应 ✅（机制层面对）。
- 不可迁移：**主权发行人有本币铸币权与央行最后贷款人、无存款保险兑付约束、国债以本币计价**；商业银行会真正违约、主权在其本币债务上不会以同样方式「破产」。
- 裁决：类比可作**提问清单**（「短端急升是不是流动性事件？」），不可作**结论**（「所以国家在救急、所以景气要转折」）。
- 与 11/12「一美元资产 cover 三块人民币负债」同型：**把微观恒等式直接搬去宏观，未计约束差异**。

## Z27 「这次不一样」的证伪要求（历史剔除的准入条件）

**一句话**：**要抹掉 30 年历史，先交三样东西**——断点位置、断点前后样本量、双口径结果；交不出，就老老实实承认历史规律仍对自己不利。

### 操作步骤

1. **指认制度断点**：具体到年月与事件（如 1980 后央行常态化干预、2008 后 QE、2020 后零利率与前瞻指引、2022 后高通胀回归），不许只说「回归古典 / 回归课本」。
2. **给断点前后样本量**：前后各多少个观测、多少轮完整周期。**样本量不足以支撑统计结论时，明说「无法检验」**。
3. **双口径平行跑**（Z15）：含 / 不含被剔段、线性 / 对数，四格都给；**只含一种口径的结论不作数**。
4. **换标的重跑**（Z16）：换个市场（德债 / 英债 / 日债 2s10s）看规律是否同样失效。
5. **给替代判据**：剔掉历史后，用什么新判据判多空？没有替代判据 → 这次剔除只是**为了让自己的结论不被证伪**，判 Z22 万能解释，直接剔除。

### 2026-11-13 实锤
- 口播：「1976 年以来的这张图没有分析意义哦」「要把过去 30 年甚至 40 年经验给抹掉」「回归传统、回归古典、回归价值、回归课本」。
- 制度断点确实存在（沃尔克后的央行托底 / 格林斯潘 put / QE），但口播**未给断点日期、未给样本量、未跑双口径、未换标的、未给替代判据**。
- 裁决：**「这次不一样」未证伪**，仅作背景叙事，不得进入交易清单。这条与 11/04「周期长度外推」、11/12「3 年对 3 年锚点挑选」同源，是 **Z14 锚点挑选的宏观版第三次复现**。

## Z28 预测精度分级与择时成本报价（卡西欧原则）

**一句话**：**方向对 ≠ 择时对**；精度每提高一级，代价非线性上升；**做不到的精度就不承诺、不收费、不假装**。任何信号发布前，先声明自己属于哪一级。

### 操作步骤

1. **把信号拆成两笔账**：**方向/择股判断** 与 **入场时点/择时精度** 分开记录、分开评分。事后复盘不许用「后来解套了」抹掉择时误差，也不许用「那天跌停」否定方向。
2. **给精度分级**（按可承受的时间误差，用标准差语言）：
   | 级 | 能承诺什么 | 不能承诺什么 | 代价（口播原话的量化版） |
   |---|---|---|---|
   | L1 | 方向 + 大致区间 | 具体哪天、哪个价位 | 一杯咖啡级 |
   | L2 | 方向 + 周内窗口 | 日内转折点 | 加两个零 |
   | L3 | 精确到日 / 开盘价 | — | 再加两个零 |
   | L4 | 精确到分钟 / 跌停板 | — | 原子钟级，无人可持续做到 |
3. **声明自己停在哪一级**：口播自述「我是卖卡西欧的，不是百达翡丽」，并**主动拒绝**了月费 12 万 / 120 万的「更准」产品。**这个动作本身是方法**：能力边界声明 = 信息源可信度加分项。
4. **给每个信号配「晚买一天 / 早买一天」的后果表**：不同杠杆（现货 / 个股 / 期货）对同一时点误差的承受度不同，必须分开写。
5. **配证伪位**（Z22）：方向判断也必须有失效信号，不能因为「长期看对」就永远不认错。

### 2026-11-13 实锤
- 口播自曝：上礼拜三给买进讯号 → 礼拜四买、礼拜五跌停 → 这礼拜上半周才解套。**他明确把「择股逻辑对（方向看对）」与「择时早了一天」分开记账**，这是本期最干净的示范。
- 「礼拜四做节目、礼拜五开盘买跌停」是**事后假设**，口播自己否认做得到（「做不到做不到」）——**不许把事后假设写成能力**。
- 「要用钻石的代价」「没有 1200 变 6000，是 1200 直接加两个零」＝精度—代价非线性，与 L1–L4 分级一致。
- 对用户的直接接口：**「越跌越买」左侧策略本质就是主动放弃 L3/L4 精度、换取 L1 的价格优势**——所以该策略的证伪位必须挂在**方向与资金分层**上，不能挂在「买在最低点」上。

### 硬约束
- **不许用「我常常讲不准的」替代校准记录**：口头自谦不等于台账。要落表。
- **不许把「精度不够」当免责牌**：声明 L1 后，仍须给方向、期限、幅度、证伪位四件套（Z22 / 用户收敛铁律）。
- **「什么时候涨不知道、会涨才重要」判不可证伪**（Z22），降级为软证据，不得触发买卖。

## 🧩 待升级观察项（本期先记录，第二次同型复现再立模块）

### ① 计价单位切换法（numéraire）
口播「投资是购买力的**交换过程**」「用黄金计价还是涨的」「拿台积电计价」「一张中租 + 一张统一超换一张台积电」——把同一资产换不同分母重算相对价值，是买方思维里最可复用的一步。
**待补**：换分母后须标口径（P/B 还是 P/E、TTM 还是最新季）、标窗口（Z17）、并说明「便宜」是相对哪个分母。本期口播自己说「明天我就变了，我这个人很善变」＝**分母未固定**，故暂不立模块。

### ② 期权双腿拆解法（主方向 + 卖权收波动率）
口播：做多期货 → 卖目标价 Call（4 万 4200 → 卖 4 万 5300 C）；做空期货 → 卖回撤价 Put（3 万 9 P）。把「目标价」和「证伪位」直接转成期权执行价，用主方向之外的波动率创造额外报酬/保护。
**待补**：须写清卖权是**收波动率、承担尾部风险**，与「保护」不是一回事；须给到期周次、隐含波动率口径、被行权后的处理。缺证伪位，暂不立模块。
