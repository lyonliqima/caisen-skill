# 检查者 · 外部结论溯源稽查法（2026-09-21 立，2026-09-21 修订为「剔除制」）

> **定位**：🕵️ 检查者是「蔡森十二专家」框架的**第十五席 · 溯源稽查席**（与红队第十三席同属"事后校验席"，**不入并行分析梯队**，不产出观点）。
> 它只干一件事：**扫描分析全过程的推理链，揪出任何来自外部机构 / 网站 / 媒体 / 卖方研报 / 专家言论的「结论」，并把它从分析里剔除出去**——不是自己推导出来的结论，不留在框架里。
> 一句话：**它不判断对错，只判断"这句话到底是你自己推出来的，还是抄别人的"；是抄的，就删。**
>
> ⚠️ **核心纪律（本席铁律）**：**外部结论一律"去掉"，不进入推理链、不进入综合结论、不进入报告正文论据。** 不是"标注来源后保留"，是**直接剔除**；确需留痕的只能进附录"外部观点参考（非本框架结论·不作为判断依据）"。若剔除后某个核心判断失去全部支撑 → 该判断**作废**，不得进入综合结论。

---

## 0. 为什么需要（与「⚖️ 独立性原则」的关系）

框架的最高原则之一是 **⚖️ 独立性原则**：核心结论必须由本框架方法论独立推导，并标注 🟢独立推导 / 🔵独立推导（与专家不同）/ 🟡假说验证中。

但"要求独立"不等于"真的独立"——分析者（尤其是 LLM）极易把**读到的他人结论**悄悄混进推理链，冒充成自己的推导。**检查者就是独立性原则的事后守门人**：独立性原则负责"要求"，检查者负责"清理有没有偷用"。

**处理原则的升级（2026-09-21 用户定）**：
- ❌ 旧做法（已废）：揪出来 → 标注来源 → 降权保留。
- ✅ 新做法（现行）：揪出来 → **直接剔除**。外部结论不是"打折的论据"，而是**不能用的论据**。保留它 = 让别人的脑子替本框架下结论。真要留痕，只能放附录并明确"非依据"。

**触发**：所有 L2+ 分析，在**综合结论形成后、写入报告前**执行（与红队并列）。

## 1. 稽查对象（五类"外部结论"——一律剔除）

| 类别 | 例子 | 处理 |
|---|---|---|
| ① **机构结论** | 券商研报、投行、基金、评级机构的方向 / 目标价 / 评级（"中信证券看多""高盛上调目标价至 X""某机构建议增持"） | ❌ 剔除 |
| ② **网站 / 媒体结论** | 财经网站的分析性判断（东方财富 / 同花顺 / 雪球大V / 华尔街见闻等的**观点**，非其转述的事实） | ❌ 剔除 |
| ③ **专家 / 名人言论** | 分析师、KOL、大V 的方向性观点（"某首席说见底了"） | ❌ 剔除 |
| ④ **AI / 他人报告结论** | 其他 AI 生成的分析、他人研报的结论段 | ❌ 剔除 |
| ⑤ **隐性借用** | 未署名、但实质等同某机构判断框架/口径的结论（直接套用某券商"周期定位"结论、照搬某机构的叙事结构） | ❌ 剔除（**最隐蔽，必查**） |

> 剔除 ≠ 禁止阅读。外部资料可以看（提供线索、启发查证方向），但**一旦要拿它当论据、当判断依据，就必须先剔掉**——除非本框架用自己的方法论、用自己的数据**重新独立推一遍**，推出来才算自己的。

---

## 2. 关键判据：事实数据 vs 结论/观点（剔除的分界线）

稽查第一步是**分清这句话的性质**。**一句话自查**：这句话是「可被观测的事实」，还是「某方的判断」？

| 类型 | 处理 | 例子 |
|---|---|---|
| **事实数据** | ✅ **允许直接使用**（标数据源即可，不属"外部结论"，不剔除） | 价格 / 涨跌幅 / 财报数字 / 产量 / 库存 / 持仓 / 官方统计 / 已发生的事件 |
| **结论 / 观点** | ❌ **不是本框架推的 → 一律剔除**；是本框架推的 → 保留 | "会涨""低估""周期见底""建议买入""目标价 X""估值合理" |

**铁律**：判断 = 外部结论，须剔除；事实 = 数据，不误伤。

**唯一例外（本框架自推）**：若外部某结论与**本框架方法论独立推出的结论**结论一致，则保留**本框架的推导**，外部那句仍**不引用、不署名、不作为论据**（它的存在不构成支持）。也就是说：一致时留"自己的话"，不留"别人的话"。

## 3. 稽查流程（四步）

1. **逐句过推理链**：从核心结论倒推每条论据，逐条标记来源类型——`自有推导（本框架方法论+自有数据）` / `事实数据` / `外部结论`。
2. **揪出外部结论**：凡属"结论/观点"类、且来源非本框架推导的，全部列出（含隐性借用）。
3. **判定"是否被用作论据"**（命中任一即须剔除）：
   - 出现在推理链任一支撑节点上；或
   - 被用于支撑**核心方向**；或
   - 出现在**综合结论**里而未标明仅为外部参考；或
   - 虽未署名，但实质等同某机构判断且拿不出独立推导过程（隐性借用）。
4. **直接剔除 + 回填测试（必做）**：
   - **删除**该外部结论，从推理链与综合结论中移除；报告正文不再出现（如需留痕，移入附录"外部观点参考（非本框架结论·不作为判断依据）"）。
   - **回填测试**：删掉这条外部结论后，重看它原本支撑的那个判断——
     - 仍有本框架自有推导支撑 → 该判断**保留**（但不得再引用外部结论为其背书）；
     - 失去全部支撑 → 该判断**作废**，从综合结论中移除，标为"⚠️ 无独立推导支撑，不作判断依据"；若这是用户要的核心方向，则**如实告知"本框架推不出来"**，禁止用外部结论临时补位。
   - 无法确定来源的疑似结论 → 视同外部结论，**一并剔除**（标 `来源不明·已剔除`）。

## 4. 输出格式（强制）

```
① 外部结论清单：逐条 [原句] → [来源：机构/网站/专家名] → [位置：哪一步/哪一节点]
② 剔除项：N 条，逐条列出原句 + 剔除理由（被用作论据 / 支撑核心方向 / 隐性借用）
③ 回填测试结果：
   - 保留的判断（删后仍有自有推导支撑）：…
   - 作废的判断（删后无支撑）：… → 已从综合结论移除 / 核心方向推不出如实告知
④ 独立性结论：本报告核心结论中，X 条本框架独立推导、Y 条外部结论已剔除、Z 条因剔除而作废
⑤ 补推导建议：被剔除后作废的方向，若确需结论，须用哪个专家方法论 + 哪些自有数据重新独立推（列出补做路径）
```

> 输出中**不再有"已标注来源后保留"的选项**——外部结论要么被剔除、要么由本框架重新独立推出（推出后以本框架推导形式呈现）。

---

## 5. 硬约束

- 检查者**只稽查来源、不评价对错**（对错归红队 / 各专家）；它只关心"这个结论是不是自己推的"。
- **外部结论零留存**：不是自己推导出的结论，**不得**出现在推理链、综合结论、报告正文论据中。唯一去处是附录"外部观点参考（非本框架结论·不作为判断依据）"，且不得被任何判断引用。
- **不放过隐性借用**：即使没抄原句，只要结论实质等同某机构判断、且报告里拿不出独立推导过程，一律剔除。
- **事实数据不误伤**：财报数字、价格、官方统计、已发生事件是事实，允许使用并标数据源，不列为"外部结论"、不剔除。
- **剔除后必须回填测试**：删掉外部结论，看原判断是否还站得住；站不住就作废，禁止用外部结论顶包。
- **推不出就说推不出**：若某核心方向只能靠外部结论支撑，**如实告知用户"本框架无独立推导，不给该方向判断"**，不得借用外部口径蒙混。
- 检查者必须**见过全部分析素材与成稿**（给全量输入，**不做切片**），否则无法溯源。
- 稽查结论**必须可核查**：每条剔除项都要给出原句与来源，禁止"总体感觉独立性不足"式模糊判断。

## 6. 与既有机制的分工（不重叠）

| 机制 | 查什么 | 方向 |
|---|---|---|
| ⚖️ 独立性原则 | **要求**结论独立推导 + 标注（事前规范） | — |
| 🕵️ **检查者（本席）** | **溯源内部推理链，剔除被冒充成自有推导的外部结论** | 内部 → 来源核查 |
| 🔍 第5.7步市场共识对照 | **对照外部共识**看本报告有无增量 alpha（仅作对照，不作论据） | 外部 → 内部方向对照 |
| 🟥 红队（第十三席） | 查**论点有没有洞**（逻辑证伪） | 逻辑层 |
| 🛡️ 风控终审 | 查**标的有没有雷**（退市/质押/立案等硬风险） | 风险层 |

**一句话记忆**：红队查"说得对不对"，风控查"标的干不干净"，**检查者查"结论是不是自己推的，不是就删掉"**。

## 7. 报告章节对应（第6步 HTML）

在「全专家综合结论」之后、「先行指标」之前，加一个 **🕵️ 检查者·独立性溯源稽查** 区块（用表格呈现）：
- **外部结论剔除清单**（原句 / 来源 / 位置 / 剔除理由）
- **回填测试结果**（保留的判断 / 作废的判断）
- **独立性结论**（本框架独立推导 X / 外部已剔除 Y / 因剔除作废 Z）
- **补推导路径**（若核心方向被剔空，写明需补做的方法论与数据）
- 报告正文与综合结论中**不再保留任何外部结论作为论据**；确需留痕的，仅置于本章节或附录并标"非本框架结论·不作为判断依据"。
