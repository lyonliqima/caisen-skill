# 四方法论整合市场分析框架

> **核心定位**：这是**四套研究方法论的整合运用**，不是四位专家观点的拼凑。每次分析时，用方法论独立推导结论。专家本人的观点只是方法论的实战演示，仅作参考，不直接作为结论。

## 核心原则

```
方法论（可复用工具）→ 独立推导 → 结论
专家观点（历史示例）→ 仅参考 → 不直接引用为结论
```

1. **方法论优先**：每个分析维度的结论必须由方法论工具推导，不能直接引用专家观点
2. **多维交叉验证**：四套方法论从不同角度分析同一标的，结论互相验证或暴露分歧
3. **数据驱动**：所有结论必须有数据支撑，不接受纯主观判断
4. **强制推演**：必须输出兵棋推演情景树，展示二阶/三阶/四阶传导效应
5. **反馈闭环**：每次分析后回顾上次预测准确率，持续校准方法论

## 问题分级与路由（执行前先判断）

分析前先判定问题属于哪一档，**默认走 L1/L2 轻量路径，L3/L4 需用户明确要求或遇重大事件才触发**。不要把所有问题都跑重流程。

| 档位 | 典型问题 | 流程要求 | HTML | 激活范围 |
|------|---------|---------|------|---------|
| L1 快评 | 「黄金今天怎么看」「茅台技术面」 | 单方法论、纯文字、几分钟 | 不生成 | 1 位最相关方法论 |
| L2 标准分析 | 「半导体板块中期逻辑」 | 2-3 方法论 + 简图 | 可选（用户要求才生成） | 2-3 位方法论 |
| L3 多维度 | 「大宗商品牛市何时来」 | 四方法论全跑（并行子代理）+ 兵棋推演 | 必须（≥6 图） | 四方法论全激活 |
| L4 深度研究 | 「帮我研究宁德时代」 | L3 全流程 + 个股财报/舆情/估值 | 必须（≥8 图） | 四方法论 + 个股 skill |

**默认与触发**：
- L1/L2 是默认档；能一句话/几段话回答的归 L1/L2，不要默认走 L3/L4。
- L3/L4 仅在：(a) 用户明确要求「完整分析/兵棋推演/深度研究」；(b) 重大宏观/地缘/个股事件（突发政策、财报暴雷、战争等）时自动升级。
- L3/L4 才生成完整 HTML 报告并套用 `analysis-report-template`；L1/L2 纯文字或按需简图即可。

## 时间衰减权重机制

**方法论不过期，观点会过期**：

| 时间范围 | 观点权重 | 方法论权重 |
|----------|----------|------------|
| 7天内 | 100% | 100%（始终适用） |
| 1个月内 | 80% | 100% |
| 3个月内 | 60% | 100% |
| 6个月内 | 40% | 100% |
| 1年以上 | 20% | 100% |

**冲突处理**：
- 观点冲突 → 以最新观点为准
- 方法论冲突 → 以数据验证结果为准
- 方法论结论 vs 专家观点 → **方法论结论优先**

## 兵棋推演情景树（必须输出）

每次分析报告**必须**包含一个「兵棋推演情景树」，采用**「如果…就…」**的条件分支结构，像多米诺骨牌一样推演长链条传导。

### 核心思想

这不是结果分类表，而是**事件推演沙盘**。从一个真实事件出发，一步步推演它引发的连锁反应，每个节点都可以继续传导、分支或反转。要有创意，要发散，要看到别人看不到的二阶、三阶、四阶效应。

### 树状图结构规范

- **根节点**：当前局势（所有事件发生的起点）
- **每个节点格式**：
  ```
  🔀 如果 [具体事件]
  → [第一步后果：资产变化]
    → [第二步传导：引发什么新事件]
      → [第三步后果：最终资产影响]
  ```
- **节点可以有两种展开方式**：
  - **① 横向分支**：一个事件分裂成多个可能子路径（如：伊朗停战 → OPEC反应A / 以色列反应B / 俄罗斯反应C）
  - **② 纵向传导链**：一个事件一步步往下传，像多米诺（如：Fed降息 → 美元走弱 → 新兴市场资金流入 → 大宗商品反弹 → 通胀回升 → Fed被迫转鹰）
- **层级要求**：
  - 至少15个节点（不是分支，是节点总数）
  - 至少3条长链（传导≥4步）
  - 至少5个分支点（一个节点分出2-3个子节点）
  - 同一节点的兄弟分支标注概率，概率之和=100%
- **每个节点标注**：
  - 📊 **概率分数**（如果是分支节点）
  - 🎯 **资产后果**（列出受影响的资产方向和幅度）
  - 🏷️ **方法论标签**（这个传导逻辑来自哪套方法论工具箱）

### 末端路径概率（聚合三情景 · 必做）
- 每个分支节点的**兄弟分支概率之和必须 = 100%**（容差 0.01），否则推演不自洽。
- 从根到每个**末端叶子**的联合概率 = 路径上各节点条件概率之积；所有末端叶子概率之和必须 = 1。
- **三情景（牛 / 基准 / 熊）概率必须由末端路径聚合得出**，不得脱离情景树独立拍定：将每条末端路径按其「方向」归入牛/基准/熊，分别求和即三情景概率（置信度 = 主情景概率）。
- 用 `python3 tools/scenario_tree.py tree.json` 校验兄弟概率和、聚合三情景、输出末端路径表；输出附在报告「兵棋推演」章节。

### 创意发散要求（这是重点！）

**必须做到**：
1. **跨市场传导**：事件A影响市场B，再传到市场C（如：伊朗停战 → 油价崩 → 中东主权基金抽资 → 美股承压）
2. **时间差传导**：短期利多 → 中期利空（如：Fed降息 → 短期股市涨 → 中期通胀反弹 → 长期被迫加息）
3. **反身性传导**：市场预期反过来影响事件本身（如：美股暴跌 → 消费者信心崩 → 经济真衰退 → 股市更跌）
4. **意外传导**：看似无关的事件被串联（如：俄乌停战 → 欧洲重建 → 欧洲财政扩张 → 欧元走强 → 美元走弱 → 大宗商品涨）
5. **包含至少1个“脑洞级”长链**（≥6步传导，有创意、有逻辑、意想不到）
6. **包含「如果多事件同时发生」的组合分支**（如：停战+降息+AI商业化 = 全面牛市）

### 分类维度

按以下维度组织分支（每个维度至少2-3个分支节点）：
- 🌍 地缘政治（停战、冲突、制裁、联盟变化）
- 💰 货币政策（Fed决策、其他央行、流动性）
- 🤖 AI/科技（商业化、泡沫、技术突破、监管）
- 🇨🇳 中国因素（刺激、报复、改革、汇率）
- ⚡ 黑天鹅（爆雷、战争、疫情、政治动荡）
- 🎉 正向惊喜（多利好同时兑现、意外突破）

### 树状图位置与附件

- 放在报告的第10节（四方法论交叉验证之后、先行指标之前）
- 树状图后附「事件×资产」影响矩阵总览表
- 至少6个Chart.js图表辅助可视化

### HTML实现

- 使用纯 HTML/CSS/JS 实现（不依赖额外库）
- 每个节点用卡片形式，左列=条件，箭头，右列=后果
- 长链用缩进+连接线表示传导步骤
- 分支用同层并列表示
- 颜色编码：绿色=看多，红色=看空，金色=黄金，蓝色=中性

## 分析工作流（方法论驱动）

```
第0步：背景了解与新闻搜索（发散阶段）
  - 搜索最新新闻、政策动态、市场情绪
  - 发散搜索关联市场（不只看单一品种）
  - 按需读取 alphaear/last30days 参考skill
  - 🚀 **先读数据缓存**：跑 `python3 market-data-cache/latest.py` 读取已落盘的大盘指数/板块/资金流作背景；缓存缺失或需最新时再实时补拉。仅对目标个股做实时数据获取（详见 market-data-cache/README.md）
  - ⚠️ 信息源时效性强制要求（见下方"信息源时效性规范"）
第1步：按专家方法论需求搜索具体市场数据（价格、供需、技术指标、资金流）
  - 必须覆盖四套方法论各自所需的数据类型（见下方"按专家需求搜索清单"）
第2-5步：并行调用四方法论子智能体（杨/卢/蔡/笨鸟，**同一消息发 4 个 Agent 调用**）
  → 每个子智能体只跑自己的方法论工具，返回固定格式结构化摘要（见下方「并行执行机制」）
  → 编排者（主 agent）**不重推**，只收集 4 份摘要进入第6步交叉验证
第6步：四方法论交叉验证
  → 共识 ≠ 高信心：专家内部共识只是「共识矩阵」的一个轴（共识 × 市场定价），落左上角（共识+已定价）即零 alpha，仓位强制「不动·仅记录」
  → 分歧 = 需进一步数据验证，且须区分「我们错 / 市场错」（落入共识矩阵左下/右上格）
  → 标注哪个方法论的推导链条更完整；最终落格记入 `consensus_cell` 字段（详见 `references/scorecard-spec.md` §12）
第7步：兵棋推演情景树（多路径分支 + 条件 + 概率）
第8步：回顾上次预测（反馈闭环）
第9步：生成 HTML 报告（含丰富图表 + 树状图）
```

### 🚀 并行执行机制（四方法论子智能体 · 默认开启）

四方法论推导**必须真并行**——在第1步数据收集后，**同一消息发 4 个 `Agent` 工具调用**（杨/卢/蔡/笨鸟各 1 个），让 4 个子智能体同时工作；**编排者（主 agent）只做综合，不重推每个方法论**。机制要点：

1. **并发启动**：4 个子智能体各自只加载自己对应的 skill（杨→`yang-shiguang-analysis`、卢→`lu-qiyuan-analysis`、蔡→`caisen-technical-analysis`、笨鸟→`benniao-analysis`），不共享草稿，避免观点回声室。
2. **子智能体任务书（统一模板）**：
   ```
   你是四方法论整合分析中的【XX方法论】。基于主 agent 已收集的背景资料，仅用你的方法论工具独立推导结论，忽略 skill 里带日期的方向性观点（视为待验证假说）。
   返回「一页以内」固定格式结构化摘要：
   ① 核心结论 3-5 条（每条标🟢共识/🔵独立推导/🟡分歧）
   ② 置信度（0-100 整数）
   ③ 关键证据（数据/图表来源，2-3 条）
   ④ 证伪条件（什么情形出现则本结论失效，1-2 条）
   ```
3. **结构化回收**：主 agent 收集 4 份摘要后直接进第6步交叉验证；子智能体输出须可直接填入报告对应章节。
4. **失败降级**：任一子智能体失败/超时，主 agent 标注「XX方法论视图缺失」并照常合成其余 3 份，不整体重试（失败≥2 才补跑）。

> ⚡ 性能：并行把墙钟时间从「4 段顺序」压到「1 段并发」，主要提速来源是四方法论同时跑。

### 信息源时效性规范（强制）

> 分析结论的质量取决于输入数据的新鲜度。用旧消息做分析 = 刻舟求剑。搜索时必须遵守以下时效性要求。

**时效性分级**：

| 数据类型 | 最高时效要求 | 可接受下限 | 超期处理 |
|----------|-------------|-----------|----------|
| 价格/行情/汇率 | 当日 | 3个交易日内 | 超期必须重新搜索，不得使用 |
| 资金流/持仓/ETF流 | 最近1周 | 2周内 | 超期标注"数据滞后"，结论降级 |
| 宏观经济数据（CPI/PMI/非农等） | 最新一期 | 最近1期 | 必须用最新公布值，注明发布日期 |
| 央行政策/会议纪要 | 最新会议 | 上一次会议 | 对比前后变化，不得只引用旧的 |
| 新闻/事件/地缘动态 | 最近7天 | 30天内 | 超过30天的新闻仅作历史背景，不作为主分析依据 |
| 专家视频/观点 | 最近一期 | 1个月内 | 严格遵循各skill的时间衰减权重机制 |

**搜索执行规则**：

```
□ 每次分析必须先搜索最新信息，不能直接套用 skill 中嵌入的历史案例数据
□ skill 中的数据（如"2026/6/5巴菲特指标243.7%"）是撰写时的快照，分析时必须搜索最新值替换
□ 搜索时在 query 中带上当前日期或"latest/最新/2026年7月"等时间限定词
□ 引用数据时必须标注来源和发布日期
□ 同一指标如有多个来源，优先取最新发布的数据
□ 如果搜索不到最新数据（如节假日、数据未发布），明确标注"截至X月X日数据"
□ 严禁用3个月前的新闻作为"当前局势"分析依据
```

### 交叉验证规则

```
四个方法论对同一标的的判断：
├── 4/4一致 → 极强信号（confidence 85-95%）
├── 3/4一致 → 强信号（confidence 70-85%）
├── 2/4一致 → 弱信号（confidence 50-70%），以宏观+数据维度为准
├── 4/4分歧 → 无信号（confidence <50%），建议观望
└── 特殊情况：蔡森形态明确 + 宏观面矛盾 → 形态服从宏观（大周期>小周期）
```
