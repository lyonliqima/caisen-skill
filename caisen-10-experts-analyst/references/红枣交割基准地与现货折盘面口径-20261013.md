## 一、结论摘要（一句话）

**这篇文章修的不是"数字"，是"标签"：郑商所红枣期货的基准交割地在新疆，而全市场现货报价的锚在河北崔尔庄（销区），两者相差 600 元/吨的地区升水。同一时点的"基差"因此存在两个都成立的版本（河北直比口径 / 新疆基准地口径），二者恒差 600 —— 引用时必须带口径标签，且在同一个算式里只能用一个。**

**性质提示（★本文最有迁移价值的一条）**：这个偏差是「**固定常数**」而非比例误差——分子恒为 600、分母是盘面价。2026-09-04 盘面 7,780 时相差 7.7%，2026-10-12 盘面 6,750 时相差 **8.9%**。**红枣跌得越深，两个口径的结论分歧越大、越不能混用。**

## 二、算法拆解（把「说法」翻成「事实 + 公式」）

### 2.1 交割基准地与基准价（规则事实，原文核心 —— 已逐条核验 ✅）

| 项 | 内容 | 性质 |
|---|---|---|
| **基准交割仓库** | **新疆**交割仓库，无升贴水 | 规则事实 |
| **非基准交割仓库** | 沧州、郑州交割仓库，**升水 600 元/吨** | 规则事实（**"郑州"表述见 §5.3-3**） |
| **交割基准价定义** | = 基准交割品在**基准交割仓库出库时汽车板交货的含税价格（含包装）** | 规则事实 |
| **现货定价中心** | **河北沧州崔尔庄**（产区在新疆、销区/加工集散地在河北） | 行业惯例 |
| **为什么软件/机构用河北价** | 新疆各地只有**原料统货收购价**（品质参差、以质论价、无高频标准报价）；崔尔庄有标准化、高频的每日批发报价 → 全市场（软件 / 资讯 / 研究机构）默认引用崔尔庄价 | 行业惯例 |

### 2.2 两个口径的定义（★本文的真增量不是「公式」，是「给口径命名」）

```
【口径 A｜河北直比口径】  行业惯例 · 华泰/卓创/同花顺 · A8 采用
      basis_河北 = S_河北 − F
      用途：卖方买的就是河北现货 → 回答「河北现货的可交货套利空间」「旧作天花板」

【口径 B｜新疆基准地口径】 规则口径 · 本文主张
      basis_新疆 = (S_河北 − 600) − F = basis_河北 − 600
      用途：郑商所基准价锚在新疆库出库价 → 回答「期货相对基准地现货升水/贴水多少」

【恒等关系（算术事实，与谁对谁错无关）】
      basis_新疆 − basis_河北 = −600 元/吨（恒定，不随价格变）
      失真占比 = 600 / F   （F 越小占比越大：7780 → 7.7%、6750 → 8.9%）
```

**同一把尺子的双向使用**：成本侧（A4/A6）是「新疆 → 河北要**加** 600」，基差侧是「河北 → 新疆要**减** 600」。两边方向相反、绝对值同源，**不得各用一套**。

## 三、★ 正面冲突裁断（skill 铁律：两份来源在同一事实上冲突，必须裁断并写清窗口）

### 3.1 冲突双方

| | 主张 | 出处 |
|---|---|---|
| **甲（本文）** | 现货（河北）价必须**先扣 600 还原到新疆基准地**再与盘面比；不还原 = 误导 | 本文件 §2.2 口径 B |
| **乙（A8-6）** | **「期货与现货的对比不额外叠加地区升贴水」**——业内（华泰、卓创）一律直接以河北一级现货与盘面比基差；出疆运费约 600 元/吨**已体现在基差里**；统一采用「现货−期货」直比口径，**不重复调整**（否则同一时点会算出两套相反结论） | `成本底与资金结构法-20260903.md` A8-6（2026-09-18 立） |

### 3.2 裁断

**① 甲、乙都是对的，但不是同一件事——差的是「问句」。**

| 你要回答的问题 | 用哪套口径 | 理由 |
|---|---|---|
| 期货相对**基准交割地（新疆）现货**升水/贴水多少（判 M-H4「交割月水位」、判「期货是否已平水」） | **口径 B（新疆）** | 郑商所交割基准价 = 新疆基准库出库价，这是期货报价的定义域 |
| **河北现货的可交货套利空间** / 旧作可交割天花板（A8） | **口径 A（河北）**，且**不得再减 600** | 卖方买入的就是河北现货；A8 的门槛 `S+C+D` 里 S 必须与 F 同域 → 与河北现货同域 |
| 与期货公司日报（华泰/卓创）**对表** | **口径 A** | 对方报的就是 A 口径（实测：华泰 10-12「现货基差 CJ01 −150」= 6600 − 6750 ✅） |
| 跨品种 / 跨期比较「基差率有多深」 | **必须统一口径**，不统一即不可比（M-FD5） | — |

**② 乙的禁令继续有效，且是最重要的一条：同一个算式 / 同一结论句内只许用一套口径。** 尤其 **A8 的门槛公式里不得再减 600**（那会与「S 用河北现货」重复调整，正是 A8-6 要防的错误）。

**③ 甲真正成立的硬结论只有一条，且与口径之争无关**：**同花顺类软件把「基准地」字段标成「河北」是与交易所规则直接冲突的事实错误**（郑商所基准地为新疆）。该字段**不可作为基准地判据**。
> 「现货折盘面 = 现货价」这一步本身**与行业惯例一致**（华泰/卓创也是这么比的），**不是算术错误**；错的是它与「基准地：河北」这个标签**合在一起展示**，把「期货基准交割价（新疆口径）」与「现货参考价（河北口径）」两个不同层面的概念**混为一谈**——这正是原文标题所说「混淆了两个不同层面的概念」。

**④ 新增强制要求（本裁断产出）**：**报告里任何"基差"数字必须带地区口径标签**（`河北口径` / `新疆基准地口径`），并注明两者**恒差 600**。**未标口径的"基差 −150 / 升水 750"都属无效表述。**

**⑤ 对闸门判据的实际影响（★可执行）**：**M-H7 见底要件 R3「期货转贴水」与 A8 的"期现升水"读数，都必须在口径声明后才有意义** —— 两个口径相差 600，**足以在临界点翻转 R3 的判定**。A8 已在 2026-09-17 用**河北口径**判 R3 由 ❌ 转 ⚠️临界（期货对现货升水 340）；若换新疆口径，同日升水为 940，**R3 的临界性会被推翻**。→ **今后报 R3 必须写明口径。**

### 5.2 两口径复算（★本文核心产出：不是「对错」，是「标签」）

### 5.3 ✅/⚠️/❌ 勘误与小结论

### 5.4 本框架补充（推论，非事实层 —— 原文未提，由核验数据反推）

1. **误差方向恒为「口径 B 的基差更负」**：河北是**升水地**，剪掉升水后现货更低 → 基差更负 → 期货相对**基准地**现货**更贵**。所以口径 A **系统性把"期货贵"读轻**。对 **左侧抄底** 的含义：`M-H4 远月含升水` 的逆风被隐藏，容易把"期货已近平水"当成"下跌空间有限"。
2. **失真占比随价格下跌而放大**（600 / F）：2026-09-04 为 7.7%、2026-10-12 为 **8.9%**。**这是"固定常数偏差"的特征签名**——若某口径的偏差**量级恒定、不随价格按比例变动**，应先怀疑是不是**漏了/多算了一个固定升贴水或固定费用项**，而不是怀疑数据源。
3. **【2026-10-12 实测】红枣注册仓单已归零（全部 12 库数量 = 0）**：红枣仓单有效期为「N 年 11 月 1 日起注册 → N+1 年 9 月最后一个工作日」→ **2025 产季仓单 9 月底已全部到期清退**，新产季仓单 **2026-11-01 起**才可注册。→ **这不是"无货可交"，也不是需求好转，而是制度性的产季空窗**（A5-4「仓单下降 ≠ 利多」的第三层：**制度性清退**，本次为"归零"级实证）。**当下"可交割压力比"分母为 0 → 仓单类信号暂时失效**，不得用"仓单大幅下降"叙述供给收缩。
