# 附录｜美元体系四支柱健康度监测框架

> **定位**：L11/L12/L13 之上的**总览监测层**。L11 诊断"信用支柱崩塌-重建"、L12 追踪"双管道施工"、L13 检测"政策独立性是否放弃"——本框架给出**四维度交叉验证**的完整体检表，先于 L11/L12 跑一遍，定位到底哪个维度在亮红灯，再下钻深挖。
>
> **核心判断**：四大维度从"日常需求"到"底层权力"逐层递进，共同构成美元体系的完整闭环。**单一维度的变化不足以判定"美元崩溃"，必须四维度交叉验证。**

---

## 四支柱总览模型

```
美元体系闭环（从日常需求 → 底层权力，逐层递进）
├── 支柱一：底层交易盘（计价结算需求基本盘）
│   └── 角色：流量基本盘，决定市场对美元的日常刚需
│   └── 体量：原油/黄金现货期货 + Swift跨境 + 虚拟资产 ≈ 350~400万亿美元/年
│   └── 特征：绝大多数以美元计价结算
├── 支柱二：资产蓄水池（价值存储信用锚点）
│   └── 角色：存量压舱石，决定全球对美元的价值信任
│   └── 体量：海外央行9.37万亿美债 + 全球储备57%美元 + 80万亿美股 + 离岸1.2~1.5万亿美钞
├── 支柱三：机制骨架（清算网络 + 流动性修复机制）
│   └── 角色：运行骨架 + 安全阀（常被忽略的自我修复机制）
│   └── 组成：Swift(指令)+CHIPS(清算) 双系统 + 美联储与5家央行无上限常备货币互换
└── 支柱四：实体硬支撑（能源定价权 + 军事辅助）
    └── 角色：实体权力保障，能源定价权是核心抓手，军事是兜底辅助
    └── 组成：美国原油产量新高/净出口 + 分化OPEC + 控制产油国渠道 + 美军强制力
```

**闭环逻辑**：交易盘产生日常刚需 → 资产蓄水池承接存量价值 → 机制骨架保障清算与流动性不中断 → 实体硬支撑（能源+军事）兜底规则落地。四者相互加固，任一单点松动都会被其余维度缓冲，只有系统性、规模化替代才触及体系层面风险。

---

## 支柱一：底层交易盘（计价结算需求基本盘）

**对应内容**：原油现货/期货、黄金现货/期货、Swift 跨境交易、虚拟资产等每年合计 350~400 万亿美元交易体量，绝大多数以美元计价结算。

**预测核心逻辑**：这是美元体系的"流量基本盘"，决定市场对美元的日常刚需。只有当**非美元计价的交易实现系统性、规模化替代**，才会动摇底层基础；单一品类、单笔贸易的结算切换，不会改变整体格局。

**可跟踪预测指标**：
- 全球大宗（原油、黄金、粮食）的美元计价交易占比
- Swift 系统中的美元结算份额
- 跨境贸易本币结算（如人民币跨境支付）的年度增速与绝对规模
- 非美元计价的原油、黄金期货合约的交易量占比

---

## 支柱二：资产蓄水池（价值存储信用锚点）

**对应内容**：海外央行持有 9.37 万亿美债、全球外汇储备中 57% 为美元资产、80 万亿美元市值的美股、海外流通的 1.2~1.5 万亿美钞。

**预测核心逻辑**：这是美元体系的"存量压舱石"，决定全球对美元的价值信任。美元体系的**系统性风险往往先从"资产蓄水池漏水"开始**——各国持续减持美债、美元储备占比长期下行、美股长期失去财富效应，都会逐步削弱美元的信用锚。

**可跟踪预测指标**：
- 海外央行美债持有量的月度变化趋势
- IMF 全球外汇储备中的美元资产占比（季度更新）
- 美股市值占全球股市总市值的比重
- 离岸美元市场的流动性松紧程度

---

## 支柱三：机制骨架（清算网络与流动性修复机制）

**对应内容**：Swift（指令）+ CHIPS（资金清算）的双系统、美联储与五家央行的无上限常备货币互换协议。

**预测核心逻辑**：这是美元体系的"运行骨架与安全阀"，也是很多人容易忽略的**自我修复机制**。当全球出现美元荒、金融恐慌时，美联储可以通过货币互换直接向盟友体系注入美元流动性，避免集中抛售美债引发的连锁崩溃。只有当**替代清算系统形成全球规模化网络，且脱离美元中介完成闭环**，才会逐步瓦解这一层。

**可跟踪预测指标**：
- CIPS、Mbridge 等替代清算系统的日均交易规模与覆盖国家数
- 美联储货币互换网络的扩容 / 收缩情况
- 全球美元流动性危机时，互换机制的启用规模与响应效率

---

## 支柱四：实体硬支撑（能源定价权与军事辅助）

**对应内容**：美国原油产量创 2025 年新高、成为石油净出口国、分化 OPEC、控制产油国渠道、美军作为体系辅助力量。

**预测核心逻辑**：这是美元体系的"实体权力保障"，其中**能源定价权是核心抓手，军事是兜底辅助**。美国通过自身产能、分化产油国、控制运输通道，牢牢绑定"石油-美元"循环；美军并非美元信用的唯一来源，而是保障这套体系规则落地的强制力。

**可跟踪预测指标**：
- 美国原油 / 成品油的日产量与净出口量
- OPEC 组织的内部一致性与减产执行率
- 中东产油国与美国的能源合作 / 背离动向
- 霍尔木兹海峡等关键能源通道的控制权变化

## 三类传导路径与情景推演

四大维度不是孤立的，预测的关键是判断**变化从哪个维度发起、如何向其他维度传导**，对应三种典型演化路径：

### 1. 渐进式弱化路径（基准情景）
```
传导顺序：底层交易盘缓慢替代 → 资产蓄水池占比缓步下行 → 替代清算机制并行发展 → 实体权力逐步分化
```
- **对应现实**：全球货币多元化推进，部分贸易用本币结算、各国缓慢分散外汇储备，但美元仍占据主导地位，不会出现"崩盘"。
- **会议观点对应**：官方提出的"货币体系多元化、人民币国际化稳慎有序"，正是对这一路径的应对。

### 2. 剧烈动荡路径（风险情景）
```
传导顺序：资产蓄水池率先爆雷（如美债违约风险、美股崩盘）→ 引发离岸美元流动性危机 → 若货币互换机制兜不住范围 → 传导至清算层与交易层 → 大宗计价剧烈波动、全球金融市场共振
```
- **核心判断**：美元体系的风险从来不是"慢慢崩"，而是**流动性危机引发的连锁踩踏**；但只要美联储的互换网络与清算权还在，就有很强的托底能力。

### 3. 阶段性强化路径（反弹情景）
```
传导顺序：实体权力强化（如拿下更多能源定价权、科技革命推升美股）→ 交易盘与资产盘吸引力回升 → 全球资本回流美元资产 → 体系地位阶段性巩固
```
- **典型案例**：美国提升页岩油产量、分化 OPEC、深入中东油田运营，本质就是通过强化实体支撑，反向巩固美元体系。

## 使用框架的关键注意事项

1. **拒绝单指标判断**：不能仅凭"美债发得多""某国用人民币结算原油"就判定美元崩溃，**必须四大维度交叉验证**。
2. **区分波动与体系性崩塌**：美元贬值、美债下跌都是正常周期波动，只有当**清算、计价、储备三大功能同时出现系统性替代**，才会触及体系层面的风险。
3. **重视修复机制**：这套体系运行了几十年，有成熟的补漏能力，预测时不能只算"削弱项"，也要算美国的反制与修复动作。

## 与 L11 / L12 / L13 的协同关系

- **L11 美元信用支柱崩塌-重建诊断**：本框架"资产蓄水池（支柱二）"对应 L11 旧支柱诊断；"机制骨架（支柱三）"对应货币互换兜底；"实体硬支撑（支柱四）"对应 L11 支柱3石油美元。
- **L12 结构性需求锁定双管道**：本框架"底层交易盘（支柱一）"对应 L12 自上而下（石油美元）+ 自下而上（稳定币）双管道。
- **L4 地缘冲突能源+金融战穿透**：本框架"实体硬支撑（支柱四）"是 L4 在美元体系维度的具体展开。

**标准用法顺序**：
1. 先跑本框架四维度体检，定位哪个维度在亮红灯；
2. 若**资产蓄水池 / 机制骨架**出现预警 → 回到 **L11** 诊断旧支柱崩塌进度；
3. 若需评估新支柱施工状态 → 用 **L12** 追踪双管道进度；
4. 若怀疑政策独立性被动摇 → 用 **L13** 检测财政-货币协同信号。

## 补充：美元利率中枢 → 商品成本传导三道换算（2026-09-17 追加 · 置于文末以保持既有编号不动）

> **来源**：公众号「燧木数农」2026-09-17 文，完整核验见 `references/10-fed-rate-ag-cost-transmission-20260917.md`
> **定位**：本框架讲美元体系的**结构性权力**（四支柱），缺一条**「美元利率变化如何落到具体商品成本」的微观通道**。本补充补这一条。
> **与四支柱的关系**：**并行使用、互不替代**。四支柱判「美元体系稳不稳」，本补充判「美元利率变了，某品种的成本要动多少」。

### 补-1 判定顺序（先证伪「美元冲高」这个归因）

```
看到「美元走强 → 商品承压」的说法时，先做两步核验：
① 看美元「水平」而非单日涨跌幅 —— 对比年内高点 / 历史高点
   工具：ICE 美元指数（DXY，日）+ 美联储广义美元指数（H.10，周，覆盖含 EM 的贸易对手国）
② 看决议日各资产涨跌幅是否 > 1%
   全部 < 1% → 属日常波动，未发生事件驱动重估
→ 结论形态：「压力来自 X 中枢的抬升预期」，而不是「来自美元某一天冲高」
```

**为什么必须这么做**：把压力归给「美元冲高」，最大的风险是**当美元指数回落时，你会误以为压力已经解除**——而中枢抬升的慢变量还在。

**⚠️ 实锤陷阱（2026-09-17 核验）**：该案例原文称「决议当日美元指数只涨 0.03%」，实际为 **+0.63~0.70%**（东财 100.2860/+0.67%、腾讯 100.31/+0.63%、搜狐 100.33/+0.7%、Edge 100.249/+0.64%）。**判「某资产没动」是极强主张**（它要否定一整条传导链），证据等级必须 ≥2 个独立 origin；单一源或单一接口字段（尤其 `changePct = 0` 的**字段缺失型零值**）不足以支撑。同族实锤另见《数据时效与准确性闸门》陷阱⑲。

### 补-2 传导三道换算（微观通道）

```
第 1 道｜进口完税成本 = CNF报价 × 汇率 × (1+关税) × (1+增值税) + 港杂费
        汇率与 CNF 在「乘数」位置 → 两者合计每变动 1%，本币成本≈同向 1%
        速算：4,000 元/吨 货值，汇率每贬值 1% → 每吨 +40 元
        缓冲项：本币升值会反向对冲（本案例：2024 初 7.1426 → 2026-09-11 6.7080）

第 2 道｜内外价差 = 到港完税成本 − 国内港口分销价        ★领先指标
        价差为正 → 进口商加快买船；压到零或转负 → 买船节奏放缓
        ——「价差先动，价格后动」，这是三道里唯一有交易价值的领先信号

第 3 道｜压榨 / 加工利润
        利润侵蚀倍数 = 原料涨幅 ÷ 利润率
        例：利润 200 元/吨，原料涨 1%（40 元）→ 吃掉 20% 利润
        棕榈油精炼、食糖加工、棉花纺织，结构同理
```

### 补-3 资金端量级三算式（**慢变量的主战场**）

```
① 库存搬运成本 = 每吨货值 × 利率变动 × 持有期(年)
   4,000 元/吨 + 25bp 持 3 个月 → 2.5 元/吨
   中枢上修 60bp → 3 个月 6 元/吨；6 个月 12 元/吨

② 贸易融资成本 = 船货值 × 融资利率变动 × (天数/360) ÷ 总吨数
   6 万吨、2.4 亿元货值、+25bp、90 天 → 15 万元 ≈ 2.5 元/吨

③ 库存意愿（不可直接量化，须定性）：中枢上移 → 贸易商主动缩短持有期、
   压低远期升水、提高报价里的风险缓冲；加工厂下调年度采购的库存天数假设
```

**关键理解**：单笔幅度都很小（元/吨级），但**它们同时出现在每一个环节、每一笔库存、每一份远期合同上**，并与中枢抬升的预期叠加。
→ **库存搬运成本的系统上移不制造某一天的暴跌，它改变一年内的库存意愿。**

### 补-4 用法与限制

- **先做四支柱体检**定体系状态，**再用本补充**定某品种的成本传导量级；两者不可互相替代。
- 本补充只覆盖**常态供需下的慢变量传导**，**不覆盖**极端天气、突发贸易措施、政策大幅调整三类外生冲击。
- 三道换算中第 1 道的关税/增值税率必须取**当期实际**（配额、反倾销、加征部分单独计），不得用记忆值。
- 快速筛子：先按「进口依赖度 = 进口量 ÷ 国内消费量」（USDA FAS PSD，须标市场年度 + 版本）分层——**高敏感 ≥60% / 中敏感 15–60% / 低敏感 <5%**——再决定要不要展开三道换算。
