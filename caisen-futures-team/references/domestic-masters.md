## 一、宏观产业综合派

### 叶庆均（南帝·叶大户）

**人物定位**：敦和资管创始人，国内期货界"南帝"，百亿级体量，业内称"东方索罗斯"。10万本金起家，经历3次爆仓后建立完整交易体系。

#### 核心理念

1. **期货是投机市场，不投入过度情感**——行情结束及时离场，不执着于单一品种，不贪恋不适合自己的行情
2. **K线是果，供需才是因**——从图表派转向基本面派，价格背后是供需、是周期
3. **敬畏市场，永远假设自己错了**——市场是老板你是打工的，老板永远是对的
4. **交易不是赌博，是寻找确定性**——成功不是因为天赋或运气，是重复做正确的事

#### 交易体系

**三步法：等待 → 入场 → 管理与离场**

**第一步：等待（最重要环节）**
- 看不懂或没机会就坚决空仓
- 一年只出手 5 次左右，机会是等出来的
- 从宏观经济、产业供需、资金情绪三个维度筛选机会

**第二步：入场**
- 趋势确认后再入场，不提前抄底逃顶
- 首次开仓资金不超过总资金的 10%
- 宏观政策转向 + 供需核心逻辑反转 = 趋势确认信号

**第三步：管理与离场**
- **金字塔加仓**：只在盈利头寸上加仓，后加仓量小于前一次
- **止损设置**：止损设在趋势逻辑破位的位置（宏观政策转向或供需核心逻辑反转）
- **止盈节奏**：
  - 第一次见顶信号 → 平掉 30% 仓位
  - 周线级别破位 → 再平 50%
  - 剩下 20% 吃到鱼尾行情，最后全部离场

#### 风控原则

- 盈利后将利润的 40% 提取出来，作为风险储备金
- 绝对不跟趋势对抗，哪怕判断错了也立刻砍
- 接受趋势中的正常回调，不被小波动洗出局

#### 可借鉴要点

- 大资金的仓位管理与金字塔加仓法
- 基于逻辑破位的止损，而非固定点数
- 分批止盈的节奏控制
- 耐心等待高确定性机会

### 葛卫东（东邪·混沌投资）

**人物定位**：混沌投资董事长，国内宏观趋势交易第一人，首个在全球大宗商品市场与华尔街投行正面抗衡的中国交易者。经历两次爆仓后顿悟。

#### 核心理念

1. **混沌理论**：结果的不可预见性 + 过程的可推导性
   - 市场永远按照阻力最小的路径来运行
   - 各种因素导入市场的方式和时间不同，起的作用不同，产生的结果千变万化
   - 蝴蝶效应：很小的因素可能在系统内和其他因素相互作用后形成巨大的不可预料的结果
2. **倾听市场、跟随市场**——与其盲目预测，不如"倾听市场、跟随市场"
3. **市场永远是对的，错的只有我们的执念**——贪婪和恐惧是交易最大的敌人
4. **追求稳定复利，而非短期暴利**

#### 交易体系

**三大核心准则：**

**准则一：只顺大势，不做逆势单**
- 永远顺着宏观与产业确定的大趋势走
- 真正能实现财富量级跨越的，永远是几年一遇的大级别趋势行情
- 短线交易只能赚小钱，甚至必然亏损

**准则二：三原则筛选交易**
1. 盈亏比原则：冒 1 元风险能否赚 3 元钱（盈亏比不足 2:1 直接放弃）
2. 基本面原则：宏观政策、行业供需、企业中长期业绩三者必须同步向好
3. 技术面原则：基本面与技术面形成共振才出手

**准则三：集中重仓、长期持有**
- 听市场、跟趋势、反人性、重风控
- 大机会敢于重仓持有

#### 风控原则

- 爆仓两次换来的教训：市场永远是对的，执念是最大敌人
- 盈亏比铁律：不足 2:1 的交易直接放弃
- 风控为盾，混沌前行

#### 可借鉴要点

- 混沌理论的思维方式：不追求精确预测，追求过程推导
- 三原则筛选法（盈亏比 + 基本面 + 技术面共振）
- 宏观与产业双轮驱动的分析框架
- 反人性交易心理建设

### 林军（鸿凯投资）

**人物定位**：鸿凯投资董事长，香然会创始人，中国第一代期货传奇。3000元起步，30年交易生涯，横跨股票、期货、贸易、实业、艺术品投资。

#### 核心理念

1. **三维分析法**：供需 + 逻辑 + 情绪与想象
2. **看得透、砍得快、输得起、放得下**
3. **先大后小，逻辑闭环**：宏观 → 产业 → 技术，顺序不可颠倒
4. **人性就是金融属性，造就大涨大跌行情**

#### 交易体系

**三维分析框架：**

**第一维：供需（基本面）**
- 库存、产能、终端需求变化
- 期现价差与套利空间
- 产业链利润分布

**第二维：逻辑（宏观+产业）**
- 宏观经济周期位置
- 政策导向与资金面
- 产业逻辑的自洽性与可持续性

**第三维：情绪与想象（市场心理）**
- 市场情绪极端度
- 资金持仓结构
- 市场预期与现实的差距

**交易决策流程：**
1. 先定大周期（周线级上涨趋势），再找小周期入场
2. 宏观面、产业面、技术面三者至少有两面共振才出手
3. 盈亏比优先：开仓前确认潜在盈利空间至少是潜在亏损的 3 倍
4. 大部分时间是等待，抓矛盾最高的品种，一年只做两波

**黑天鹅三击理论：**
- 认知差：你比市场更懂基本面
- 情绪差：市场情绪极端时逆向布局
- 杠杆差：用合理杠杆放大收益

#### 风控原则

- 止损永远前置，单笔亏损严格控制总资金比例
- 错了果断离场，不跟行情赌气扛单
- 本金安全始终放在第一位
- 多元化投资组合分散风险（期货 + 固定资产 + 实业股权）

#### 可借鉴要点

- 三维分析法的完整框架
- 先大后小的决策顺序
- 多维度共振才出手的纪律
- 黑天鹅三击理论

## 二、产业基本面派

### 傅海棠（北丐·天道供需）

**人物定位**：农民出身的期货传奇，期货界"北丐"，"天道供需"体系创始人。从5万起步做到数十亿，以纯基本面、不看任何技术指标、重仓抓大行情著称。公开演讲体系完整，是国内基本面派最具系统性的方法论之一。

#### 核心理念

**1. 天道思想——市场的终极规律**
- 市场运行遵循"天道"即自然经济规律，不以任何人的意志为转移
- 人为力量只能影响短期，无法改变长期趋势
- 物极必反：价格跌到极致必然上涨，涨到极致必然下跌，如同四季更替、钟摆回归
- 核心准则：**贵出如粪土，贱取如珠玉**；低位不做空，高位不做多

**2. 供需二元定律**
- 价格涨跌的唯一根本驱动力是供求关系，这是万古不变的真理
- **供求决定价格**：供不应求价格必涨，供过于求价格必跌，趋势大小由供需失衡程度决定
- **价格反过来重塑供需**：
  - 价格跌破成本 → 全行业亏损 → 产能退出 → 供给收缩 → 牛市开启
  - 价格暴利 → 资本扩产 → 供给过剩 → 熊市来临

**3. 确定性交易原则**
- 投资不是概率游戏，而是**确定性博弈**
- 只做逻辑 100% 闭环、结果必然发生的行情
- 看不懂、不确定就坚决不做
- 一年只抓 1-2 次大机会即可

#### 交易体系

**核心模型：五维拐点判定法**

这是傅海棠体系最核心的行情识别工具，五个条件同时满足时，商品价格必然迎来大级别单边行情。

**做多（牛市拐点）五条件：**

| 维度 | 判定标准 | 本质 |
|------|---------|------|
| 低价格 | 价格远低于行业平均生产成本，处于历史价格区间低位 | 安全边际 |
| 低库存 | 社会总库存、工厂库存、贸易库存均处于历史低位，去化彻底 | 供需紧张 |
| 负利润 | 全行业普遍性亏损，生产者持续亏钱，中小产能开始退出 | 供给收缩动力 |
| 需求稳 | 下游终端需求稳定或边际改善，无持续性崩塌风险 | 需求支撑 |
| 高贴水 | 期货价格大幅低于现货价格，安全边际充足 | 期货安全垫 |

**做空（熊市拐点）五条件：**

| 维度 | 判定标准 | 本质 |
|------|---------|------|
| 高价格 | 价格远高于生产成本，处于历史价格区间高位 | 泡沫化 |
| 高库存 | 社会库存持续累积，处于历史高位 | 供给过剩 |
| 超高利润 | 全行业赚取超额暴利，资本大量涌入扩产 | 供给扩张动力 |
| 需求弱 | 下游需求转弱或出现下滑，终端承接无力 | 需求坍塌 |
| 高升水 | 期货价格大幅高于现货价格，泡沫化明显 | 期货泡沫 |

**信息验证：实地调研与真相甄别**

傅海棠体系的核心壁垒是一手调研信息，拒绝二手消息和盘面情绪干扰。

**调研核心路径：**
- **供给端**：主产区田间地头、工厂生产车间、矿山油田，核实种植面积/开工率/产能变化
- **流通端**：贸易商、批发市场、港口仓库，核实库存水平、走货速度、贸易情绪
- **需求端**：下游加工厂、终端消费场景，核实真实消耗量，区分投机囤货的虚假需求

**信息真伪判断：**
- **交叉验证**：同一数据至少从 3 个不同产业链环节获取，互相印证
- **区分边际**：重点看供需的边际变化，而非绝对总量——平衡被打破的瞬间才是行情起点
- **反人性验证**：全行业一致看空、所有人都劝你不要做时，往往是底部信号；全市场一致看多、全民涌入时，往往是顶部信号

**完整执行流程（六步法）：**

**第一步：初选标的——盯住"有问题的品种"**
- 优先筛选出现极端状态的品种：
  - 要么全行业深度亏损、生产端怨声载道
  - 要么全行业暴利、扩产消息铺天盖地
- 无明显矛盾的平稳品种直接排除，不浪费精力

**第二步：五维数据量化核验**
- 收集公开产业数据，对照五维模型打分
- 成本线：计算行业完全生产成本（含原料、人工、折旧、财务成本）
- 库存周期：计算库存消费比，判断库存历史分位
- 利润水平：核算行业平均利润率
- 需求增速：跟踪下游开工率、终端消费量变化
- 基差水平：计算期货与现货的价差比例

**第三步：实地调研闭环验证**
- 针对初选品种奔赴产业一线，验证数据真实性
- 发现公开数据未体现的边际变化
- 农产品：走访主产区，核实种植面积、苗情、天气影响、农民种植意愿
- 工业品：走访工厂、矿山，核实开工率、检修计划、新增产能进度
- 核心目标：确认"供需失衡是否真实存在、拐点是否已经到来"

**第四步：市场情绪极端度确认**
- 底部信号：论坛/社群全面看空、利空消息满天飞、多头彻底绝望、成交量低迷
- 顶部信号：全民看多、利好消息铺天盖地、空头被爆仓、成交量天量
- 情绪极端度越高，行情级别越大

**第五步：价格空间与节奏预判**
- 上涨目标位：至少回归行业平均成本线，若供需缺口大则看至正常利润甚至超额利润区间
- 下跌目标位：至少回归行业平均成本线，若过剩严重则看至行业亏损区间
- 节奏：大趋势不会一蹴而就，中间必然伴随反复震荡洗盘，核心逻辑不变则趋势不改

**第六步：持仓跟踪与动态校验**
- 持仓过程中持续跟踪供需数据
- 只要核心逻辑（供给收缩/需求增长）未发生反转，就坚定持有
- 不因短期波动离场

#### 交易执行与仓位原则

**入场时机：**
- 左侧布局，不追求买在最低点、卖在最高点
- 只要确认大方向正确、安全边际足够，就分批建仓

**仓位策略：**
- 确定性越高，仓位越重
- 完全符合五维条件的极致机会，可重仓甚至满仓
- 趋势确认后，用浮盈加仓，放大收益，不轻易动用本金加仓
- 核心逻辑：用安全边际对冲回撤风险，用大仓位赚大行情的钱

**出场信号（满足任意一条即可逐步离场）：**
1. 价格到达预判的目标区间，进入另一个极端状态
2. 核心供需逻辑发生反转（如供给开始恢复、需求开始下滑）
3. 市场情绪极度疯狂，全市场一边倒看好/看空

#### 核心禁忌与铁律

- **绝对不用技术指标干扰基本面判断**——K线只是结果，不是原因
- **不做短线、不频繁交易**——拒绝 99% 的无效波动机会
- **不随大流、不听消息**——只相信自己调研验证的事实
- **不对抗趋势，不抄顶摸底**——只在极端拐点出手
- **低位不做空，高位不做多**——天道准则

#### 风险提示

- 本方法仅捕捉大级别行情，过程中回撤幅度可能极大，需要极强的心理承受能力和资金管理能力
- 调研深度不足、信息失真会导致逻辑误判，是最大风险来源
- 极端政策、黑天鹅事件可能短期打破供需节奏，需预留安全边际
- 期货交易自带高杠杆，普通投资者请勿盲目模仿重仓操作

#### 实战预测快速校验清单

每次预测前对照检查，全部打勾再执行：
- [ ] 品种有明确的生产成本线，可量化核算
- [ ] 价格处于历史极端分位（低于成本/远超成本）
- [ ] 库存处于历史极端水平（低位/高位）
- [ ] 行业利润处于极端状态（普遍亏损/普遍暴利）
- [ ] 供需边际已经出现明确变化（供给收缩/需求下滑）
- [ ] 已通过至少 2 个产业链环节交叉验证信息真实性
- [ ] 市场情绪出现一边倒的极端状态
- [ ] 核心逻辑闭环，结果具备必然性

#### 可借鉴要点

- 五维拐点判定法——最系统的基本面大行情识别工具
- 天道思想与物极必反的周期认知
- 实地调研的方法论与信息交叉验证
- 确定性博弈的思维方式（只做必然发生的事）
- 安全边际 + 大仓位的辩证统一
- 反人性验证的情绪判断法

### 林广袤（浓汤野人·棉花大王）

**人物定位**：北京物资学院期货专业毕业，2010年棉花牛市600万做到20亿，"西毒"。最极致的单品趋势交易者，鳄鱼交易哲学。

#### 核心理念

1. **鳄鱼交易哲学**
   - 耐心等待：鳄鱼不会盲目追击，而是潜伏等待最佳时机
   - 一击必中：出击前计算距离、反应时间和速度，确保成功率
   - 等待对手犯错：等待市场犯下足够大的错误，机会出现时果断重仓出击
   - 减少出击次数，降低失败成本
2. **大行情从基本面出发**——大行情一定会符合趋势的各个因素，但符合趋势条件的不一定是大行情，核心是基本面发生了巨大变化
3. **输不起的不是钱，输不起的是机会**——5-10年才一遇的大行情不能错过
4. **交易的终极是反人性的修行**

#### 交易体系

**单品深耕法：**
- 人的精力有限，把一个品种的供需吃透，远胜于在100个品种上画趋势线
- 跑遍全国产区，连棉农的化肥成本都要了解
- 一辈子只做几个自己真正懂的品种

**浮盈加仓策略：**
- 浮盈加仓绝非盲目追涨，必须完全基于基本面判断
- 每一次加仓都要满足最初的开仓条件，等同于新开仓操作
- 过程中出现回调，只要大方向未变，无需过度纠结
- 最后一次加仓往往在行情最疯狂时

**超高盈亏比：**
- 棉花一战：500左右的风险，10000左右的利润
- 提前做好分析、计划并耐心等待机会临近
- 和预期不一致，及时止损，及时保命不死扛

#### 风控原则

- 成功之后最危险的是觉得自己无所不能
- 交易最大的错误不是初学时发生的，而是在老手时发生的
- 只要存在固定的交易程式，市场自然就能找到你的漏洞——需要不断进化
- 顺势而为，不与趋势为敌

#### 可借鉴要点

- 单品深耕的研究方法
- 鳄鱼式等待与出击哲学
- 基于基本面的浮盈加仓法
- 对大机会的识别与把握

### 刘福厚（钢材现货派）

**人物定位**：内蒙古鄂尔多斯兴万福集团董事长，钢材现货贸易起家。2008年亏1680万后转型，靠供需逻辑翻身，15年实盘盈利超2亿。

#### 核心理念

1. **期货就是现货生意的延伸**——低价囤货、高价抛售，赚供需错配的钱
2. **彻底抛弃K线和技术指标**——把期货当成囤货做生意
3. **只做自己懂的品种**——聚焦黑色系（螺纹钢、铁矿石、焦煤焦炭）
4. **算账思维**——做实业出身的人最看重算账，不孤注一掷赌单边

#### 交易体系

**供需分析法三步：**

**第一步：查全球产量和库存**
- 不仅看国内产量，还要看全球（如大豆看美国、巴西种植面积）
- 进口量、出口量
- 库存周期（累库/去库）

**第二步：看国内外需求**
- 终端需求变化（如钢材看基建、房地产）
- 下游产业利润与开工率
- 替代品需求影响

**第三步：紧盯政策与突发事件**
- 收储/抛储政策
- 环保限产
- 自然灾害
- 国际贸易摩擦

**四大分析维度：**
1. 期现价差：现货价低、期货价高 → 做空；反之做多
2. 供需关系：供不应求做多，供过于求做空
3. 仓单数量与外盘指数：观察仓单增减和价格关系
4. 商品内在逻辑关系：如收储政策扭曲价格后的回归

**操作原则：**
- 顺势而为，不逆势而行
- 逢低买入，逢高卖出（在合理价格区间）
- 分批操作，不一次性操作
- 习惯开对冲头寸，进行套利套保交易

#### 风控原则

- 止损建立在产业逻辑上，不是简单跌几个点就割肉
- 只要现货基差没修复、基本面逻辑没被证伪，不仅不止损，甚至敢在极端行情下继续加仓
- 资金规划极其严谨，确保能扛到逻辑兑现
- 不熟悉的品种少碰，不盲目摸底

#### 可借鉴要点

- 用实业思维做期货的朴素方法论
- 供需分析法的四维度框架
- 基于产业逻辑的止损理念
- 套利套保思维降低风险

### 冯成毅（沪铜大王）

**人物定位**：20多年只做铜一个品种，2012年全国期货大赛以1034.42%净利润夺冠。经历三次爆仓后确立"一生只做铜"的铁律。

#### 核心理念

1. **交易品种专一性**——一辈子只做铜，铜是"我最熟悉的孩子"
2. **积小胜为大胜**——不追求暴利，追求稳定复利，每天赚1%一年140倍
3. **现货是期货的锚**——锚稳了船才不会翻
4. **小胜凭智，大胜靠德**——把利润留给市场，把风险留给市场

#### 交易体系

**产业逻辑 + 短线精度 双轮驱动：**

**长线方向（产业逻辑）：**
只看两个数据定方向：
- 现货升贴水：升水扩大 → 看多；贴水扩大 → 看空
- 交易所库存：库存连降 → 看多；库存累积 → 看空

**短线入场（盘口精度）：**
- 关注关键价位与量价验证
- 午后2:30产业资金动向
- 在长线趋势中找最优价位，让每笔头寸都建立在成本优势上

**交易四原则：**
1. 只做铜——单品深耕，打造"神经记忆"
2. 只做单边——双向套利太复杂，做不来
3. 只盯现货——现货是期货的锚
4. 只赚能赚的钱——只赚看得懂的钱

#### 风控原则

- 清仓起步，靠浮盈加码，亏损即砍舍
- 单日最大承受额，超限停手保状态
- 不可太"满"，得饶人处且饶人，不赚最后一枚铜板
- 反思爆仓四大原因：重仓交易、多品种交易、偏执性交易、性格缺陷

#### 可借鉴要点

- 单品专一的深度研究方法
- 现货升贴水 + 库存定方向的极简框架
- 长线方向 + 短线精度的结合
- 积小胜为大胜的复利思维

## 三、趋势哲学派

### 青泽（十年一梦）

**人物定位**：《十年一梦：一个操盘手的自白》作者，哲学硕士，影响几代国内交易者。从短线转型中长线趋势交易，强调交易哲学与心性修炼。

#### 核心理念

1. **人为市场立法**——不是市场本身有什么固有规律等着我们去发现，而是我们用自己的投资理念和交易系统去赋予市场走势一种我们能够理解和应对的秩序
2. **市场无法精准预测，只能顺势应对**
3. **交易的终极真相不是征服市场，而是征服自己**
4. **三分技术，七分心性**
5. **我可以输几个点，但输不起一个趋势**

#### 交易体系

**临界点交易法：**

**第一步：定趋势**
- 用周线图判断市场长期的牛熊方向
- 60周均线作为多空生命线
- 线上只考虑做多或观望，线下只考虑做空或观望
- 价格站稳60日线之上且均线方向拐头向上 → 多头备选池

**第二步：找临界点**
- 只在关键点（结构突破）出手
- 放弃所有似是而非的机会
- 多头突破震荡箱体 → 入场信号
- 止损设在箱体下沿再向下1%的位置

**第三步：金字塔加码**
- 首单盈利后，价格回踩至10日线附近再度企稳 → 加码第二笔
- 仓位为首单的1.5倍
- 趋势强劲运行，突破前一波高点后小幅回调 → 加码第三笔
- 总仓位控制在合理范围

**重仓原则：**
- 优质交易机会具有稀缺性，一旦出现必须竭尽全力把握
- 重大机会出现时，仓位至少达到总资金的30%以上
- 重仓把握市场大趋势，是期货市场获得暴利的唯一路径

#### 风控原则

- 止损提升到信仰高度——不是失败，而是为捕捉大趋势必须支付的保险费
- 赢冲输缩资金管理：轻仓试错、盈利加仓、亏损果断止损
- 交易逻辑的完整性和一致性至关重要
- 系统本身需要根据市场演变微调，但必须在盘后冷静状态下进行

#### 可借鉴要点

- 人为市场立法的哲学思维
- 60均线定趋势 + 临界点入场的简洁体系
- 交易心性修炼的方法论
- 赢冲输缩的资金管理

## 四、系统化交易派

### 徐长波（趋势跟踪系统）

**人物定位**：大连长波集团前任董事长，1996年起从事期货。独创"多品种、多指标、多周期"趋势跟踪交易系统，2008年盈利80多倍，累计盈利近7亿。

#### 核心理念

1. **三多原则**：多品种、多指标、多周期
2. **确定性是交易的前提**——指标越简单越好，最重要的是确定性要强，是唯一的、不可选择的
3. **回避基本面**——避免基本面干扰，技术派和基本派各有各的特点
4. **以年为单位考量**——系统好坏不在于一周一月，而应以一年的战果来考量
5. **先活下去，再赚钱**——千万不能亏大钱，尤其是以年为单位计算的时候

#### 交易体系

**趋势跟踪交易系统：**

**三多原则：**
1. **多品种**：分散投资多个品种，降低单一品种风险
2. **多指标**：均线、MACD、KDJ等（越简单越好，确定性要强）
3. **多周期**：10min、1h、日线等不同周期

**三不做原则：**
1. 上市品种不足四年不做（历史数据量不够）
2. 交易量小、非主力合约不做
3. 回测不过关的策略不做

**不止损的奥秘：**
- 不是不止损，而是用长中短周期的对冲替代传统止损
- 长周期盘整 + 短周期小趋势波段 → 形成多空对冲，减少仓量
- 达到比止损更好的风险控制效果
- 每品种做10条策略（10条线），每条线都要4年以上数据回测

**执行纪律：**
- 年初制定资金分配计划
- 全程手动下单，但严格执行系统信号
- 团队只允许严格执行计划，不允许随意主观调整
- 交易纪律性和策略稳定性极高

#### 风控原则

- 靠系统内的风控参数控制风险
- 多品种分散化降低单一品种暴雷风险
- 多周期对冲降低震荡市损耗
- 以年度为单位评估，不追求短期暴利

#### 可借鉴要点

- 三多原则的系统化思维
- 用周期对冲替代单点止损的思路
- 机械执行、排除主观干扰的纪律
- 以年为单位的长期评估视角
