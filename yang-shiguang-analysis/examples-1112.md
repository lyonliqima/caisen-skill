## 一、节目结构（五段）

1. **台股短线**：四天弹逾 6,600 点后 11/12 拉回；杀 NVIDIA 概念股，广达、技嘉重挫，京元电破底；「挑战极限可能性仍大」，空单谨慎做。给 **P/C ratio 69% → 85%/100%** 作为反弹能否转回升的关键，够不到则 11 月中下旬见右侧起跌。空头留意 **DRAM、货柜航运**。
2. **王安类比**：1984 美国第五大富豪 → 1990 过世 → 1992 破产，「上帝视角」归因于全球货币环境（1981 沃克升息 → 1984 登顶；2022–23 升息 → 2026 黄仁勋登顶）。
3. **美元与储备地位**：DXY 创波段新高；哈马克苏黎世演讲谈美元储备份额 72%→57%；主张「高利率是挽回储备地位的主观手段」；用「1 美元资产 cover 3 块人民币负债」解释各央行有底气抛美债。
4. **负债端收缩 → 资产端崩塌**：钻石 8488→2055「又破底」、中药材创五年低点；黄金「破底翻失败」看 **2980–3200**，跌下去「沉睡 20 年」；油价、贵金属、商品都要当心。
5. **汇率**：欧元 9/21 1.1464 → 11/12 1.1066（约 −3.5%），贬值利德国出口、德股喷出；人民币对欧元创三年新高，「对人民币震荡要有信心」；日元 7/30 高点 163 与干预，163.7 防线若再挑战 → 美债抛压 → 负债端更紧。

### ❌ 方向性错误（本期关键，权重归零）

| 节目论据 | 核验结果 | 对应红线 |
|---|---|---|
| 「美元储备从 **60 年代** 72% 降到 57%」 | 72% 是 **2001 年**峰值（1995 有季度统计以来最高）；1980 年代曾 85%、1991 低点 45%。**起点错约 40 年** | R25 / R18 |
| 哈马克担忧储备地位「一去而不复返」，故靠高利率挽回 | 原话是份额「**可能已经见顶**」＝上不去了、近期横住；2026Q3 **57.02%** 较上季仅 −0.09pct 且今年小幅回升，纽约联储测算季度波动近半来自**汇率折算**。她把地位挂在物价稳定 / 法治 / 央行独立性，并点名稳定币可能带来短债新需求 | **R26** ＋ R25 |
| 「中国 10Y 国债 2% 以上」、负债端 1.7%，故 5.1÷1.7＝3 | 中债 10Y 实为 **1.59%**（11/07 周报；30Y 2.03%、2Y 1.22%），DR001 1.2886%。用真实数 4.86–5.01÷1.59≈3.06 量级巧合接近，但**两个输入都错**；且把**存量恒等式**压成收益率之比，未计久期、汇率折算、冲销成本 | **R24** |
| 钻石「这礼拜又破底」8488→2055 | 指数来源未核到（T3）；**Rapaport 2026-05 四个板块三个回升**（0.30ct **+2.1%**、0.50ct **+0.9%**、1ct −0.3%、3ct −0.5%），业内判断「短期筑底已完成」；Paul Zimnisky 毛坯指数 2026 年内 −7.3%、距 ATH −51.8%。**累计 −75% ≠ 当期还在跌** | **R25** |
