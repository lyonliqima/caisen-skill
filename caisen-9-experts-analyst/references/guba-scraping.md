# 股吧 / 散户舆情采样协议（个股研究必做 · 仅 L4）

> 本细节从主 SKILL.md 抽出，避免编排器膨胀。主文件 step 0 第5项只留指针 + 「限 L4 + 结果当日缓存」规则。
> 本协议**替代原 A-D 翻页叙述**——不再逐页读评论写散文，而是固定采样 + 量化 + 合成 1 张 T4 证据卡。

---

## 一、采样协议（4 步）

1. **抓取**：打开东方财富个股股吧页（`https://guba.eastmoney.com/list,{code}.html`），取**最新 50 条**评论。
   - 平台优先级：东方财富股吧 > 雪球（`https://xueqiu.com/S/{code}`）> 同花顺社区 > 新浪财经评论。
   - 东财不可达 → 降级雪球，仍取最新 50 条。
2. **逐条标注**：每条标 **多 / 空 / 中性 / 无关** 之一。
3. **汇总 4 个数字**：
   - 多头占比 = 多 ÷ (多+空+中性)
   - 空头占比 = 空 ÷ (多+空+中性)
   - 样本数 = 实际有效条数（目标 50）
   - 热度倍数 = 当日发帖量 ÷ 近 5 日均值（当日发帖量取该吧当日总数，近 5 日均值取缓存/历史均值）
4. **极端判定（写死）**：多头占比 **>80%** **且** 热度倍数 **>3** → 标 **🚨 狂热顶部信号**（散户一致性狂热，通常见顶前兆）。

## 二、代表引文

取 **3 条**最能代表多/空两极的原话（逐条带 `origin=股吧/雪球`、`via=股吧`、`tier=T4`、`published_at` 取发帖绝对时间），用于卡内 `quote`。

## 三、合成 1 张 T4 证据卡

按 `evidence-protocol.md` 落 **一张** 卡：

| 字段 | 取值 |
|------|------|
| `id` | 顺延编号 |
| `claim` | 如「散户舆情多头占比 X%，热度 Y 倍」；触发极端判定则写「🚨 狂热顶部信号：多头 X% 且热度 Y 倍」 |
| `quote` | 3 条代表引文（合并或取最强一条） |
| `origin` | 股吧 / 雪球 |
| `via` | 股吧 |
| `tier` | T4 |
| `direction` | 背景（情绪类，不入因果链） |
| `topic` | 情绪 |
| `published_at` / `retrieved_at` | 绝对时间 +0800（取采样时刻） |

## 四、权重与边界

- 舆情只能作**情绪佐证 / 散户行为线索**，不进因果链、不推翻核心框架（仅 T4，见 `source-tiers.md` 规则3）。
- 与笨鸟 M4 反常信号识别交叉验证（极度恐慌=可能见底、极度狂热=可能见顶）。

## 五、缓存

- 结果按 `股票代码 + 日期` 落盘 `references/_cache/guba_{code}_{YYYYMMDD}.md`，**同一自然日内不重复抓取**，次日失效重抓；当日第二次分析直接读缓存，不重抓。
- 缓存仅供本次分析参考，不入台账、不跨日复用。
