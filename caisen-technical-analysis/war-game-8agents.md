# 八兵棋推演体系（多Agent交叉验证）

> 来源：炒股 app PRD "全维度多 Agent 兵棋推演"模块
> 定位：与四专家整合分析互补的实战推演框架，侧重个股决策

---

## 核心理念

将多位专家视角拆解为 8 个独立 Agent，按固定顺序发言，交叉验证后由总指挥汇总决策。

与四专家整合分析的区别：
- **四专家**：宏观→制度→技术→数据，偏宏观/大类资产
- **八兵棋**：政治→经济→军事→周期→舆论→资金→技术→指挥，偏个股实战

---

## 8 大 Agent 职责

### 1️⃣ 政治与地缘 Agent

**核心职责**：分析政策、地缘冲突、贸易摩擦对该股票的影响

**输出格式**：
```
利多/利空判断：利多/利空/中性
影响等级：低/中/高
具体影响逻辑：
  - 政策面：XXX
  - 地缘风险：XXX
  - 贸易摩擦：XXX
```

### 2️⃣ 宏观经济 Agent

**核心职责**：分析利率、通胀、GDP、货币政策对行业和个股的影响

**输出格式**：
```
大盘环境判断：牛市/震荡/熊市
经济周期位置：复苏/过热/滞胀/衰退
对行业影响：
  - 利率敏感度：高/中/低
  - 通胀敏感度：高/中/低
  - 政策受益/受损：XXX
```

### 3️⃣ 军事与安全 Agent

**核心职责**：分析地区冲突、能源供应风险对相关板块的影响

**输出格式**：
```
相关板块影响：
  - 军工板块：利好/利空/无关
  - 能源板块：利好/利空/无关
  - 科技供应链：影响程度
风险传导路径：XXX → XXX → XXX
```

### 4️⃣ 大周期研判 Agent

**核心职责**：分析康波周期、美林时钟、牛熊级别大趋势

**输出格式**：
```
当前周期阶段：XXX
康波位置：复苏/繁荣/衰退/萧条
美林时钟：股票/债券/商品/现金
操作策略建议：追涨/低吸/空仓/防守
```

### 5️⃣ 舆论与市场情绪 Agent

**核心职责**：分析舆情、恐慌贪婪指数、散户/主力行为

**输出格式**：
```
情绪状态：过热/恐慌/中性/乐观
恐慌贪婪指数：0-100
散户行为判断：追高/抄底/观望/恐慌卖出
主力行为判断：吸筹/出货/拉升/洗盘
```

### 6️⃣ 资金与机构行为 Agent

**核心职责**：分析北向资金、龙虎榜、筹码分布、机构持仓

**输出格式**：
```
资金流向：流入/流出/平衡
  - 北向资金：XXX亿（方向）
  - 龙虎榜：机构买入/卖出 XXX
  - 融资融券：增加/减少
机构持仓变化：增持/减持/不变
筹码集中程度：集中/分散/正在集中
```

### 7️⃣ 技术形态 Agent

**核心职责**：验证蔡森形态、买点可靠性、技术面评分

**输出格式**：
```
当前形态：XXX（底部/头部/中继）
形态匹配度：0-100分
颈线位置：XXX
买点成立与否：成立/不成立/待确认
技术面评分：0-100
  - 量价配合：X/25
  - 多周期共振：X/25
  - 形态清晰度：X/25
  - 突破/跌破确认：X/25
```

### 8️⃣ 兵棋总指挥 Agent

**核心职责**：汇总前 7 位 Agent 观点，交叉验证，给出最终决策

**输出格式**：
```
【综合评分】0-100分
【仓位建议】0%-100%
【操作方向】做多/做空/观望
【进场价】XXX
【止盈价】XXX（基于测幅满足）
【止损价】XXX（基于形态失败点）
【推演结论】
  - 宏观环境：利多 X 票 / 利空 X 票 / 中性 X 票
  - 最大风险点：XXX
  - 最大机会点：XXX
  - 建议持有周期：XXX
【风险提示】XXX
```

## 推演流程

```
第1步：输入目标股票 + 推演周期（1-7天）
第2步：政治Agent发言 → 地缘Agent → 军事Agent → 大周期Agent → 舆论Agent → 资金Agent → 技术Agent
第3步：总指挥汇总交叉验证
第4步：输出推演报告
第5步：生成操作计划（关联自选股）
```

## 与四专家整合分析的映射关系

| 八兵棋 Agent | 对应四专家 | 差异 |
|-------------|-----------|------|
| 政治与地缘 | 杨世光(宏观) | 更聚焦地缘，个股层面 |
| 宏观经济 | 杨世光(宏观) | 相同，侧重行业传导 |
| 军事与安全 | 卢麒元(制度) | 偏供应链安全视角 |
| 大周期研判 | 杨世光(宏观) + 卢麒元(制度) | 康波+美林叠加 |
| 舆论与市场情绪 | 笨鸟(数据) | 偏情绪指标 |
| 资金与机构行为 | 笨鸟(数据) | 偏资金流向 |
| 技术形态 | **蔡森(技术)** | 完全一致，蔡森体系 |
| 兵棋总指挥 | 整合汇总 | 量化评分+仓位建议 |

## 使用建议

**适用场景**：
- 个股深度分析（不是宏观/大类资产）
- 需要综合多维度信息做买卖决策
- 验证蔡森技术形态与基本面是否共振

**不适用场景**：
- 宏观市场判断（用四专家整合分析）
- 大类资产配置（用四专家整合分析）
- 纯技术面交易（直接用蔡森体系）

## 与量化检测算法的结合

技术形态 Agent 可调用 `pattern-algorithms.md` 中的量化检测算法：

1. 自动扫描 W底/M头/头肩底/头肩顶/破底翻/收敛三角形/旗形
2. 计算 confidence 分数
3. 计算目标价和止损价
4. 将量化结果作为技术面评分的一部分

```
技术面评分 = 量价配合(25%) + 多周期共振(25%) + 形态清晰度(25%) + 量化检测分数(25%)
```
