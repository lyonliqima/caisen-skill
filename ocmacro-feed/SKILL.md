## digest 证据卡解读铁律（写死，不要即兴发挥）

### ① TACO 是「压力存量」，不是领先指标

- 它度量**施压进行时**的压力存量。重大回撤发生后存量被消耗 → 指数见顶回落 **≠** 风险解除。
- **禁止**用「指数还没涨起来」推断「暂时不会有事」。强级事件发生前的指数分位中位数约在中位附近，没有领先性。
- 30 条复盘里绝大多数是「暂停/延期/口径降档」，明确写着「并非永久撤销」「尾部风险后移」。

### ② 条件概率必须用「回撤日」口径，不是威胁日

事件 `period` 字段格式是 `「威胁日 → 回撤日」`。
做「给定今日压力 → 未来 N 日是否发生回撤」的条件概率，**必须取区间内最后一个日期（回撤日）**。
用威胁日会把事件日整体前移 1–30 天，严重污染检验结果（2026-09-12 实锤：同一批 30 条事件、
回撤日口径下 ≥+8 档 20 日概率 100.0%、+5~+8 档 81.2%；威胁日口径下退化成 97.0% / 62.5%）。
⚠️ 另有一坑：**回撤日常落在非交易日**，必须先映射到「≤ 回撤日的最后一个交易日」再进集合，
否则这些事件会静默丢失、使条件概率与基准率同时偏低（未映射 → 20 日基准 58.7%；正确映射 → 62.7%）。
用 `event_trading_days(events, dates)`，不要自己拼集合。
`rollback_date()` / `threat_date()` 两个函数都在，别用错。

### ③ 规则要看梯度，不要只看极端档

digest 会**现场复算**条件概率表（不硬编码），当前实测形态：

- 5 日 / 10 日 / 20 日三个窗口下，**≥+8 档相对基准约为 1.6~1.9 倍**（5/10/20 日 = 42.4%/63.6%/100.0% vs 基准 22.7%/41.0%/62.7%）；
- **+5~+8 档 20 日档已明显抬升**（81.2% vs 基准 62.7%），但 5/10 日档仅略高于基准；
- **≤+5 两档与无条件基准无显著差异** → 不得据此判断「压力不大所以安全」。

20 日窗口的基准率本身就很高（当前 62.7%），因为事件高度时间聚集。
**报数时必须同时给基准率**，否则单看 100% 会严重高估信息量。

### ④ 样本量警告必须随行

有效独立样本远小于朴素计数（33 个 ≥+8 样本日高度聚集在 2026 年）。
引用时一律写「参照，不作铁律」。

### ⑤ 分项贡献要拆「水平 vs 变化」，主导因子看变化列

- `contributions` = 该因子对**当前指数水平**的贡献；
- `changeContributions` = 该因子对**近 20 日变化**的贡献；
- **判断「这轮是什么驱动的」要看 changeContributions 里正向贡献最大的那个**（digest 已算好 `dominantDriver`）。

实锤（2026-09-12）：TACO +8.3 里 4.84 来自 10 年美债；20 日变化 +4.1 里 **75% 由 10Y UST 单独贡献**。
→ 推论方向：**指数下一轮见顶回落大概率由 10Y 见顶驱动，不会由支持率反弹驱动**（支持率已在低位区，边际增量衰减）。
这是「利率驱动而非政治驱动」的关键判别，不拆分项看不出来。

### ⑥ 支持率别轻易说「任期最低」

digest 会直接标 `任期最低` 或 `距任期最低 X pp`。
（2026-09-12 实锤：最新 −19.90% 曾被误读为「任期最低」，实际最低是 2026-07-30 的 −20.62%。）

### ⑦ 30 城高频成交同比必须 52 周对齐

周度序列（周日发布）做同比，基准点必须取**距最新点 364 天最接近的那一点**，再比**4 周均 vs 4 周均**。
用「≤ 某日截断」会错位 1 周，数字乱跳。
（2026-09-12 实锤：错位 1 周使 30 城同比从 −5.2% 漂到 +7.8%；再换个取法又变成 −22.7%。）
且**只能取 `market=commodity` 的四个汇总序列**（30城/一线/二线/三线）——
城市级序列里同名的「商品房」和「二手房」会重复出现，混入即口径污染。
digest 已按上述规则过滤，`hf[].baseLagDays` 会显示对齐偏差天数（应 ≤3）。

## digest 输出结构（JSON 版）

```
{ fetchedAt, source,
  taco: { asOfDate, valueLabel, status, percentile, change20dLabel,
          range, peak, trough, sampleDays,
          factors[], contributions{}, changeContributions{},
          dominantDriver, dominantDriverLabel, dominantShare,
          conditional: { buckets:[{label,n,p:{5,10,20}}], base:{5,10,20},
                         eventDays, tradingDays },
          events[]: { rollbackDate, threatDate, strength, topic, rollback, implication } },
  approval: { date, net, netLo, netHi, termMin, termMax, n, atTermLow },
  housing: { period, secondHandYoy{}, newHouseYoy{}, secondHandMom{}, newHouseMom{},
             citiesUp, citiesDown, momPositiveStreak{},
             bisChina{}, highFreq[] },
  housingSnapshot }
```

`events[].strength` 枚举：`最强` / `强` / `中强` / `中`（30 条中 13 强 / 6 中强 / 3 最强 / 8 中）。
**重大回撤 = 强 + 最强 + 中强**（22 个事件日，映射到 21 个交易日）。

## TACO 前瞻卡：它能预测什么、预测不了什么（2026-09-12 实证）

`taco_forecast.py` 对 366 个交易日 × 6 项市场数据（FRED + 沪深300，缓存在 `../taco-predictive/data/`）
做了系统检验。结论分三层，**可靠性完全不同，混用就是犯错**：

| 层 | 问题 | 结论 | 可靠度 |
|---|---|---|---|
| [一] 指数自身的未来 | TACO 接下来会怎么走 | **高**。AR(1)=0.96、半衰期约 15 个交易日。同类区间（≥8±1，6 簇）内 20 日后 TACO 均值回落到 +1.2、上行概率 0% | 高 |
| [二] 政策回撤窗口 | 未来 N 日内出现重大回撤 | **中**。≥+8 档 20 日 100%（基准 62.7%，1.6x），前瞻等待中位约 12 个交易日；+8 以下各档无区分度 | 中 |
| [三] 市场方向 | TACO 高 → 股市/债市会怎么走 | **低（≈无独立信息）**。TACO≥8 后 20 日标普 +7.5% vs 机械基准「标普刚跌最深」+7.2%，重合度 80%；控制标普动量后偏相关仅 +0.35；簇级 t=2.08 不显著 | 低 |

三条使用铁律：

1. **第一层当事实用**：「高压读数 3 周内自然回落」是指数构造（成分均值回归）决定的，不是判断，可以写死进报告。
2. **第二层当参考用**：报 100% 必须同时报基准 62.7% 和「仅 3 个独立簇」。基准率高是因为 2026 年事件密集，不是指数厉害。
3. **第三层禁止单独用于方向判断**：TACO 有 57.5% 权重直接来自市场价格（标普 17.5% + 10Y 17.5% + MOVE 7.5% + VIX 7.5%），
   「TACO 高 → 美股反弹」基本是「美股刚跌过 → 反弹」的换皮。要做市场方向判断，**用标普自身动量 + 蔡森形态学**，
   TACO 只作为「政策事件日历」的辅助输入。

⚠️ 前瞻卡的市场层依赖本地缓存 `taco-predictive/data/`（FRED 日频 + 沪深300）；缓存缺失时自动降级为只出前两层，并明确标注。

## 失败与降级

- TACO 抓取失败 → 标注「ocmacro 不可用，政策压力面留空」，**不得用记忆里的旧读数冒充当前值**。
- 地产令牌失败 → digest 会回落到**本地最近快照**（`housingSnapshot` 字段标明文件名与日期），
  报告里必须写「地产为 <日期> 快照，非实时」。
- 站点限流（HTTP 429）→ 脚本内建 3 次退避重试 + 请求间隔 ≥1.2s；仍失败则降级。
- ⚠️ 抓取间隔不要低于 1.2s，连续猛拉会被站点限流（提示「请求过于频繁」）。

## 合规边界

- robots.txt 显式 Allow 这三个路径；**仅 GET 只读，不写远端**。
- 数据版权归 MacroMargin 所有，本地仅作研究缓存，不对外分发原始数据。
- 站点作者的预判战绩为**自述，未经独立验证**；引用时须标注「自述」。
- 抓取的数据**只提供事实层**（压力水平 / 条件概率 / 周期定位），
  方向性结论一律由十二专家方法论独立推导，不得由数据卡直接推出交易建议。
