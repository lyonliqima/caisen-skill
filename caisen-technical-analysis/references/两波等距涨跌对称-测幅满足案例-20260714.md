## 二、核心原理：涨跌等距对称

蔡森规则——**若上升段走出两波等幅度的拉升，见顶后的下跌也倾向于走出两波等幅度的杀跌**。

```
        ╱╮ 9385.59（顶）
       ╱ │
      ╱  │ ← 右绿框（第2波上涨）= H
     ╱   │
    ╱    │ ← 中间整理
   ╱     │
  ╱      │ ← 左绿框（第1波上涨）= H
 ╱       │
╱________│
         4042.77（颈线/平台）

↓ 见顶后对称下跌（两波跌幅各 = H）：

        9385.59
          │
          ╲  第1波跌幅 = H → 满足1
           ╲
            │ ← 反弹/整理（对应两波上涨中间的休息区）
           ╱
          ╱  第2波跌幅 = H → 满足2
         ╱
   目标价区 ─────────（≈4042.77）
```

**要点**：两波上涨的「波浪单元 H」是市场的结构密码，不是随机漫步；它同时决定了下跌时两波跌幅满足的尺寸。

## 四、形态定性

**🟡 高概率假说 —— 抛物线顶 + 双浪等距反转**

1. 右绿框 = blow-off top：蜡烛越来越大、斜率越来越陡、最后几根异常长 → 散户 FOMO 追入，主力高位派发。
2. 两波等距上涨 = 市场结构有明确「波浪单元」。
3. 垂直大阴线破位（鼠标指向处）= 赶顶结束的确认信号，非正常回调。
4. 4042.77 紫线 = 前一波上涨平台起点 + 第二波跌幅满足理论目标区。
