# 实战案例 2026-10-28《金钱报》台北股市季线扣抵 + 美股"同一剧本两种定价"专题

> 本期是**技术面定时 + 宏观数据去伪 + 叙事同一性识别**的样本。价值不在于杨世光的结论（偏空）对不对，而在于：**扣抵定时怎么用、PCR 反指标怎么读、耐久财订单怎么拆穿、库存周期怎么定位相位**——以及他惯用的"资本写剧本"叙事何时越界成非可检验结论。

---

## 一、节目结构（四段，可复用的节目读法）

1. 台北股市盘面：季线扣抵最后一天扣低值 + Put/Call Ratio 持续低迷 → 反弹定性为"假反弹/死猫跳"
2. 10/13 长黑定性：假突破确认，主力中性偏空，PCR 自该日起再未回 80%
3. 美国宏观去伪：耐久财订单年增 10% 表面强 → 拆成汽车/PC/手机/房市/家电全弱，真正拉动是飞机订单
4. 主菜："同一剧本两种定价"——波音（缺料+监管→交不了货→崩）与海力士/三星/台积电（同逻辑→涨）被华尔街资本选择性定价；叠加库存周期相位定位（被动去库存→主动加库存→即将被动加库存=高点）

**读法提示**：杨世光的节目是"技术面定时 + 一个宏观深挖主菜"。技术面（扣抵/PCR）是方法，宏观主菜里混有可检验数据（耐久财拆解）和不可检验叙事（资本写剧本），须切开。

## 四、批判：坏掉的推理链（→ 已提炼为 R9–R12 红线）

1. **选择性举证（R9）**：只引用对方向有利的资产（海力士 +10%、三星 +10%）佐证"AI 叙事被追捧"，却用同逻辑的波音（-10.69%）证明"剧本虚假"——两边都用，等于**用同一证据同时证真与证伪**，构成选择性举证。正确做法：同一剧本两种定价是"资本选择性定价"的证据，不是"AI 叙事错"的证据。
2. **用叙事替代因果（R10）**：把市场分歧归因于"华尔街资本写好莱坞剧本"。这是归因风格，不可证伪、不可定量，只能事后自洽。可作假说，不可当结论。
3. **定性断言不量化（R11）**：广告收入悖论、AI capex 占比"微不足道"均无拆分数据支撑。凡涉及"占比/结构"的判断，必须给拆分，否则等于没说。
4. **相位外推无时间锚（R12）**：库存周期"被动加库存=高点"给了方向无具体触发阈值与时间窗，属事后可修正的软判断。

## 五、收敛判断（我方独立结论，非节目观点）

- **方向**：台北股市**偏空**。当前反弹定性为"假突破后的反抽 / 逃命波"，非新一轮多头起点。
- **逻辑链**：① 季线扣抵拐点（7/31 高值 43,119）即将令季线**走平乃至下弯**，多头时间窗收窄；② PCR 自 10/13 后持续 <80%（且多在 70% 以下）表明法人/主力**未翻多、仅避险买 put**；③ 美股真实经济（汽车/电子/房市/家电）全面走弱，AI 叙事被资本选择性定价，背离在积累。
- **期限**：**5–15 个交易日**（扣抵拐点至均线可见下弯的滞后窗，M98 实测滞后 5–15 日）。
- **幅度**：若季线确认下弯且 PCR 不回升，回测 **10/13 低点 48,341**；有效破位则进入更低价格区。
- **证伪位（偏空失效条件，三选一即翻多）**：加权指数**有效站回并站稳 5 万点**（前高压力区）｜**PCR 回升 >90%**｜**季线重新上弯**。三者任一触发，偏空判断作废。
- **反身性注记**：杨世光"接下来要编鬼故事"本身是叙事判断（R10），仅作风险偏好提示，**不作为方向证据**；方向由上述三项硬条件给。
