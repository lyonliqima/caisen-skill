# 数据时效性与准确性闸门（Q 闸门 · 2026-09-13 立）

> **定位**：本文件是 `caisen-10-experts-analyst` 的**数据质量硬闸门**，对应 SKILL.md **第1.5步**。
> 它和既有两道门槛分工明确，三者不重叠：
> - `references/00-data-collection-v2.md` 的 **D0–D8**：查**采集流程**是否规范（怎么取、怎么落卡）；
> - SKILL.md **第0步**的「数据质量门槛 8 项」：查**覆盖度**（够不够——T0 有几条、origin 有几个、镜子盖了几面）；
> - **本文件（Q 闸门）**：查**单点真伪**（对不对、新不新——这个数是不是这个口径、是不是这一期、是不是这一源）。
>
> **为什么必须单立一道**：第0步的 8 项门槛全过了，仍然可能把「上半年累计 GDP」当「二季度同比」用
> （2026-09-13 实锤，见第三章陷阱①）。覆盖度合格 ≠ 单点正确。

## 一、时效六查（Q-T1 ~ Q-T6）

### Q-T1 数据日确认（最先做，最容易错）

**先回答一个问题：现在最新的"可观测数据日"是哪一个交易日？**

- 今天是**非交易日**（周末/节假日）时，最新行情数据日 = **上一个交易日**，不是今天。
  ⚠️ 实例：2026-09-13 是**周日**，最新交易日为 **2026-09-11（周五）**。
  分析中一旦出现「今日收盘」「今天涨跌」，即为**事实错误**，必须改写为「截至 2026-09-11 收盘」。
- 海外数据（美股/美债/VIX/DXY）有自己的交易日历，**不得默认与 A 股同步**。
- 月频数据有**发布时点**（CPI/PPI 约每月 9–10 日，社融/M2 约每月 10–15 日，PMI 月末/月初），
  发布日前一律只能引用**上一期**，且必须写出**数据期**（如「2026-07」），不能写「最新」。
- 结论：报告开头必须有一行 **`数据日：YYYY-MM-DD（周X）`**，并注明是否交易日。

### Q-T2 频率—保鲜期对照（超期即重抓）

| 数据类别 | 频率 | 保鲜期 | 超期动作 |
|---|---|---|---|
| 指数 / 个股 / 期货收盘行情 | 日 | 1 个交易日 | 重抓，不得沿用昨日 |
| 资金流 / 两融 / 龙虎榜 / 北向南向 | 日 | 1 个交易日 | 重抓 |
| 央行 OMO、Shibor / DR007、国债收益率 | 日 | 1 个交易日（当日 11:00 / 17:00 后取） | 重抓 |
| 实时汇率（USDCNY / CNH / DXY） | 实时 | 当日 | 用 `westock-mcp data_quote` 取，**禁止抄新闻或记忆旧值** |
| TACO 指数 / 净支持率 | 日（随美股交易日） | **3 个交易日** | 重抓 `ocmacro-feed` |
| 30 城高频成交 | 周（周日发布） | 14 天 | 重抓 |
| 库存 / 开工率 / 产量 / 基差（周频） | 周 | 14 天 | 重抓 |
| CPI / PPI / PMI / 进出口 / 社融 / M2 | 月 | 45 天（等下一期） | 标注数据期 |
| GDP / 70 城房价 | 季 / 月 | 一个发布周期 | 标注期次（如 2026Q2 / 2026-07） |
| BIS 实际房价指数 | 季 | 2 个季度 | 说明期次 |
| 政策 / 地缘事件 | 事件驱动 | **历史事件不失效**，但「距今天数」本身是信息 | 写绝对日期 |
| 卖方研报 / 机构观点 | 不定期 | 30 天 | 按 SKILL.md 第4步时间衰减降权 |

### Q-T3 绝对时间戳（禁止相对时间进数据层）

- 数据层一律 `YYYY-MM-DD HH:MM +0800`（或 `YYYY-MM-DD`）。
- **禁止**「昨日 / 上周 / X 小时前 / 最近」等相对表述进入证据卡与数据表。
- 相对时间只允许出现在**最终报告展示层**（且必须能被数据层的绝对时间反查）。

### Q-T4 数据版本（初值 vs 修正值 vintage）

同一指标会在不同时点被修正，**必须写清用的是哪一版**：

| 指标 | 版本链 |
|---|---|
| GDP | 初步核算 → 初步核实 → 最终核实（**可差 0.1–0.3pp**） |
| PMI | 初值 → 终值 |
| 进出口 / 社融 / M2 | 当期初步数 → 后续修订 |
| 上市公司业绩 | 业绩预告 → 快报 → 正式财报（**三者常不一致**） |

规则：引用时写「初步核算」，并意识到后续可能被修正；**做跨期比较时，同一序列的版本必须一致**（不要拿 A 期最终核实数去比 B 期初步数）。

### Q-T5 滞后判定与重抓

满足任一即判「滞后」，必须重抓（不能重抓时按 Q-T6 封顶）：
1. 数据日 ≠ 该类别应有的最新期；
2. 报告主体（如「今天钱往哪流」）所依赖的核心数据超过保鲜期；
3. 同一指标在检查过程中拿到两个不同期次的值（说明至少一个是旧的）。

### Q-T6 时效封顶

| 不合格情形 | 置信度封顶 |
|---|---|
| 数据日误认（把非交易日当交易日、把上一期当「最新」） | **55** |
| 关键数据超保鲜期且未重抓、也无标注 | **60** |
| 使用相对时间表述进入数据层 | **70** |
| 未写数据期 / 版本（月频、季频数据） | **70** |

## 二、准确五校（Q-A1 ~ Q-A5）

### Q-A1 口径校验（错得最隐蔽，代价最大）

**遇下列任一情形，必须显式写出用的是哪个口径，不许含混：**

| 易混口径对 | 必须写明 | 实锤教训 |
|---|---|---|
| **单季同比 vs 累计同比** | 期次 + 单季/累计 | 陷阱①（0.4pp 误差） |
| **同比 vs 环比 vs 累计同比** | 三者不可混用 | 陷阱⑦ |
| **现货价 vs 期货价 vs 结算价** | 标的可交易性 | 陷阱③ |
| **官方口径 vs 行业媒体口径** | 双列并注明 | 陷阱⑤ |
| **名义 vs 实际**（利率/收入/增速） | 是否扣价格因素 | — |
| **含税 vs 不含税、出厂价 vs 含运费** | 黑色/化工必查 | — |
| **中间价 vs 在岸 vs 离岸汇率** | 具体币种对 | 陷阱⑧ |
| **单合约 vs 全期限合计**（持仓/成交） | 合计口径 | 陷阱⑥ |
| **点数 vs 百分比 vs 百分位** | 量纲（PE 分位是 0–100 的百分位，不是收益率） | 陷阱⑫ |
| **产能 vs 产量**（数量 × 单位效率） | 有效产能换算 | SKILL.md 供给端闸门 |
| **盘中 vs 尾盘 vs 收盘**（收益率/汇率/大宗） | 时段 + 源（同日常三源三值） | 陷阱⑭（美债 9/15 单日三源三形态） |
| **分解指标的比较起点**（ACM/DKW/breakeven 拆分） | 比较窗口（vs 年初/vs 上年末/vs 3 年前） | 陷阱⑬（同模型换窗口即结论相反） |

> **判定规则**：只要一处数据的口径没有写明，该数据**不得作为方向性结论的唯一支撑**；
> 若它恰好是主逻辑的支点，则该结论置信度封顶 **60**。

### Q-A2 独立交叉验证（≥2 个独立 origin）

1. **关键数字**（进入结论的每一个数）应 ≥2 个**独立 origin**（同一通稿的转载只算一票）。
2. **涨跌幅一律自算，不抄**：`涨跌幅 = 当日收盘 ÷ 前日收盘 − 1`。
   ⚠️ 陷阱②：硅铁 2026-08-28 同一天出现 +72元 / +1.64% / +46元 三个互斥口径。
3. **三源口径差 >2% 时双列并注明**，不得二选一取顺手的那个（陷阱③：生猪现货三源差 8%）。
4. **不可复算的自制指数**（口径未公开的「市场风险分」等）**只能作外部参照**，不得作为结论支点。

### Q-A3 内部一致性（算式自检，不依赖外部源）

| 检查 | 通过条件 |
|---|---|
| 价格自洽 | 最低 ≤ 收盘 ≤ 最高；出现「收盘 > 当日最高」则**当日高低点直接作废** |
| 分项加总 | Σ 分项 ≈ 合计（容差按量级；不等的要能解释舍入或口径差） |
| 同比环比互算 | 用绝对值和上期值反算同比/环比，与源报值比对 |
| 单位量纲 | 亿元 / 万亿元 / 万吨 / 万手 / bps / % 逐项核对，**跨源换算是错因高发区** |
| 序列连续性 | 时间序列无断点、无跳变（周序号、季序号已对齐，陷阱④） |

### Q-A4 来源分级与可复算性

按 `references/source-tiers.md` 分级，并把可复算性作为独立判据：

- **T0/T1**（官方序列、交易所数据、一手文件）：优先，可直接支撑结论。
- **T2/T3**（主流媒体、卖方研报）：需 ≥2 origin 或与 T0 数据交叉。
- **T4**（自媒体、传闻、未署源转述）：**只能作线索**，不得进结论，不得进评分卡。
- **可复算性**：能由公开数据重算出原值的 → 可信度正常；**不可复算且口径未公开** → 只作参照，且须标注「自述/未验证」。

### Q-A5 量纲与单位复核（最后一关）

- 常见致命错：把「万元」当「亿元」、把「%」当「pct（百分点）」、把「吨」当「万吨」、
  把「指数点位」当「百分比」、把「bps」当「%」（1% = 100bps）。
- 换算后做**量级常识校验**：M2 是百万亿级、日成交额是万亿级、沪深300 点位是四位数——
  数量级不对立即回头查单位，不要往下推。

## 三、已知口径陷阱库（可追加，逐条为实锤）

| # | 陷阱 | 实锤 | 正确做法 |
|---|---|---|---|
| ① | **GDP 把「累计同比」标成「单季同比」** | 2026-09-13：某宏观文写「GDP 增速：2026年Q2同比 4.7%」，官方 **Q2 实为 4.3%**，4.7% 是**上半年累计**。据此算实质负利率得 −2.02%，按 Q2 应为 **−2.42%**，**低估 0.4pp** | 写 GDP 增速必须带「单季/累计 + 期次」 |
| ② | **涨跌幅多源互斥** | 硅铁 2026-08-28：+72元 / +1.64% / +46元 三口径 | 只采信绝对收盘价，涨跌幅自算 |
| ③ | **现货均价多源口径差** | 生猪同期 养猪网 10.96 / 搜猪网 10.70 / 农业农村部 11.59（差 8%） | 不可交易多口径标的不写方向性判断；必须引用则**双列注明源** |
| ④ | **周频数据未对齐周序号** | 30 城高频成交同比未做 52 周对齐、错位 1 周 → 「一线放量 +16.0%」被算成「一线缩量 −22.7%」，结论完全作废 | 同比必须对齐周序号；只取对应汇总序列（`market=commodity`） |
| ⑤ | **官方口径 vs 行业媒体口径** | 印尼 2026 RKAB 配额：官方 ESDM/APNI 2.5–2.6 亿吨 vs 行业媒体 2.6–2.7 亿吨 | **双列并注明**，不二选一 |
| ⑥ | **单合约持仓当全期限** | 2026-09-10：SS2610 减仓 7598 手被读成「资金离场」，但远月 SS2611 沉淀 79526 手，属换月移仓 | 判资金用**近月+远月合计持仓**；不跨品种比持仓 |
| ⑦ | **只看环比不看同比** | 2026-09-10：不锈钢社库环比 +4.82%（像累库），**同比 −2.83%** | 库存必须**同比 + 环比双口径**并拆三口径（社会库存 / 核心流通市场 / 交易所仓单） |
| ⑧ | **汇率口径混用** | 分析沪金/沪银时从新闻抄汇率、或用记忆旧值 | 一律 `westock-mcp data_quote(code="fxUSDCNY")` 现取 |
| ⑨ | **数据日误认** | 2026-09-13（周日）若写「今日收盘」即错，最新交易日为 09-11 | 报告首行写 `数据日` |
| ⑩ | **初值当终值** | GDP 初步核算 vs 最终核实可差 0.1–0.3pp；业绩预告/快报/正式财报常不一致 | 写清版本，跨期比较用同版本 |
| ⑪ | **低基数高同比当景气** | 同比高增可能仅因去年同期塌方 | 查基数（上期绝对值），并做两年 CAGR 或与疫情前同期比 |
| ⑫ | **点数/百分比/百分位混用** | PE「73.99% 分位」是百分位，不是涨幅 | 逐项标量纲（Q-A5） |
| ⑬ | **归因窗口套利（同一分解指标换窗口即得相反结论）** | 2026-09-16：某宏观文用纽联储 ACM 期限溢价论证「长端定价的是财政信用而非加息」。实测同一模型：**vs 2023 年末** → 10Y 拟合 +104bp 中期限溢价 **+110bp**、预期项 −6bp（**期限溢价主导**）；**vs 2025 年末** → +70bp 中预期项 **+69bp**、期限溢价 **仅 +1bp**（**政策预期主导**）。该文取长窗口结论来描述近月行情 | **凡引用利率/收益分解（ACM、DKW、breakeven-TIPS 拆分），必须同时声明比较起点**；**长窗口结论不得用于解释近月行情**（窗口不一不得混用）。另注：ACM 是**统计分解的估计值，不是观测值**，不得据此做"成因识别"（作者本人亦承认）。冲突源须双列（本轮：摩根大通私人银行「财政非近月主因」vs 美联储理事会 7 月研究「几乎全部归因赤字」） |
| ⑭ | **单日形态当趋势 + 盘中/尾盘/收盘口径不明** | 2026-09-15 美债同一日三个源给出**三种曲线形态**：新华财经尾盘口径 30Y +1.8bp 最快（似熊陡）／Reuters 同日 10Y +4.7bp > 30Y +4.5bp（反而偏平）／yieldcurvestoday「little change in its shape」。单日差异 **<2bp**，而同期 2s10s **年内收窄约 38bp**（71bp→32–34.5bp），**量级差 19 倍** | ① 判曲线陡/平必须声明「**盘中 / 尾盘 / 收盘**」与数据源；② **单日幅度 <2bp 视为噪声**，不得外推为趋势，趋势判断须用**利差口径**（如 2s10s）而非单点涨幅；③ **媒体标题不可作为形态证据**——同日 MarketsFN 标题「Curve **Steepens**」与其正文「spread 较上周**收窄** 9bp」自相矛盾 |
| ⑮ | **资金流「累加类字段」单位错位（10 倍级量级错）** | 2026-09-16 北方华创：Mi姐、路口大爷**两位专家同时**报「近 23 个交易日累计主力净额约 **−2.55 亿元**」。主 agent 用原始日序列独立累加，实为 **−2,503,955,398 元 ≈ −25.0 亿元**，**相差 10 倍**。根因：接口返回单位是「元」，子 agent 误按「百万元」累加 | ① 凡**跨期累加类**字段（主力净额 / 北向净买 / 融资净买入 / 成交额），累加前**先打印单日原值并确认单位**，累加后再做**量级常识校验**（大盘股单日主力净额常态在千万–十亿级，23 日累计不可能只有 2 亿）；② 子 agent 报出的累计值，主 agent **必须回算一次**——本条实锤说明**两位专家同错**不构成交叉验证，"多源一致"只在源头独立时成立 |
| ⑯ | **同比「高点比高点」失真（季节性/脉冲型科目）** | 2026-09-16 北方华创：合同负债表面同比 **+6.30%**，实为「2025-06-30（50.045亿）→ 2025-12-31（42.910亿）→ 2026-06-30（53.197亿）」两个**半年高点**相减，中间夹着年末回落。**环比年初实为 +23.97%**，性质从中性偏弱翻转为中性偏强 | 合同负债 / 存货 / 应收 / 预收等**季节性脉冲型科目**，同比之外**必须并列「环比年初」口径**；跨期比较前先看完整 4 期序列确认是否存在中间低点 |
| ⑰ | **国产化率「台数口径 vs 金额口径」** | 2026-09-16 北方华创：同期两个源给出 35% 与 23%，差 12pp。35% = **台数口径**（低单价、高台数环节国产化率已过半）；23% = **金额口径**（EUV/高端量测单价极高压低金额占比） | 两者**可以并存、不矛盾**。引用国产化率/渗透率**必须标口径**（台数 / 金额 / 产能 / 收入）；源未标口径 → 只作定性参照，不进评分卡 |
| ⑱ | **测幅起点取错（二手起点 vs 实拉极值）** | 2026-09-16 北方华创：某统计以 **9/14 的 620.01** 为反弹起点，实拉 250 根日K确认真实最低点是 **9/11 的 613.84**（差 **1.1%**），直接改变测幅点位与止损位设置 | 任何**测幅 / 回撤 / 反弹幅度**计算前，**必须实拉原始价格序列自行确认极值点与发生日**，不采信二手（含子 agent、研报、新闻）给出的起点 |

## 四、输出：机读声明（固定格式，不许改写成散文）

L2 及以上分析，在第1步数据收集完成后、进入第2步专家调度前，**必须输出一行**：

```
数据检查：数据日=2026-09-11（周五，最近交易日）· 时效六查=6/6 · 准确五校=5/5 · 口径修正=1（GDP 累计→单季）· 剔除点=2（涨跌幅多源矛盾）→ 置信度上限 100
```

- 不合格项照实写（如 `时效六查=5/6（TACO 超 3 个交易日未重抓）`），不得粉饰为满分。
- **置信度上限取所有不达标项封顶值的最小值**，并同时受第0步 8 项门槛与本闸门的约束。
- 该行必须进入最终报告（可放在「数据说明」小节），并同步给参与分析的子智能体。

## 五、与既有门槛的协同（三闸门顺序）

```
第-0.4步 ocmacro 取数 ──┐
第0步  新闻/背景/五连想 ──┼─→ 第0步 数据质量门槛 8 项（覆盖度：够不够）
第1步  具体数据搜索    ──┘         ↓ 通过
                       第1.5步 Q 闸门（单点真伪：对不对 / 新不新）★本文件
                                 ↓ 通过（或带封顶）
                       第2步 十二专家并行调度（子智能体只吃已验证数据）
                                 ↓
                       第5步 综合结论 · 第6步 报告 · 第6.6步 台账
```

**为什么闸门放在第2步之前**：专家一旦拿到错口径的数，方法论再正确也只会把错误放大——
而且六位专家会**各自独立地把同一个错数推出六个方向的错误结论**，事后无法归因。
数据先验真，专家后推导，是这套框架成本最低的一道保险。

## 六、失败处理

- **能重抓就重抓**（按 Q-T5）。
- **抓不到就标注**（`⚠️ 数据缺失：X 未取到，最后可得为 YYYY-MM-DD`），**严禁用记忆旧值填补**。
- **口径不明就降级**：该数据不得单独支撑方向性结论，转为「待验证假说」。
- **发现矛盾就双列**：两源冲突且无法判定 → 两个值都写、都注明源，并在报告中标为「口径分歧待解」。
- **不通过就不封顶写 100**：任何一项不达标都必须如实反映到置信度上限，并在台账 `predictability` 与
  置信度字段上体现（附录 `predictions-ledger/append.py` 会机器校验置信度硬上限，人工更须守规矩）。
