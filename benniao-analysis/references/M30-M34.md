## M30：板块属性拆分法（非通杀验证）

**核心逻辑**：面对板块普跌，先按核心属性对标的分类，通过跌幅分化判断行情性质，避免 "板块下跌 = 全行业逻辑破局" 的线性误判。

### 属性分类模板

```
板块：[板块名称]

分类维度：[周期属性/技术壁垒/商业模式/资产结构...]

类别1：[属性A]
  代表标的：___
  理论跌幅：[大/中/小]
  实际跌幅：___
  是否符合理论：___

类别2：[属性B]
  ...

对比分析：
  若各类别跌幅分化明显 → 结构性调整，非通杀
  若各类别跌幅接近 → 板块逻辑可能全面受损
```

### 会议应用示例（AI科技股）

```
板块：AI科技股

分类维度：周期属性 vs 技术壁垒 vs 商业模式

类别1：强周期属性（标准化硬件）
  代表：内存厂商
  理论跌幅：最大（需求波动敏感）
  实际跌幅：最大 ✅

类别2：技术壁垒型（技术墙）
  代表：英伟达
  理论跌幅：中等（有护城河保护）
  实际跌幅：较小 ✅

类别3：运营隔离型（隔离垫）
  代表：谷歌
  理论跌幅：最小（轻资产、租算力替代自建）
  实际跌幅：最小甚至上涨 ✅

结论：
  跌幅分化明显 → 不是通杀，只是部分环节的估值回调
  = 强周期属性从高估值回归，技术壁垒和轻资产模式相对抗跌
```

### 关键原则

1. **跌幅分化 = 结构性调整**：如果分化明显，行情不是板块逻辑全面受损
2. **跌幅趋同 = 全面风险**：如果各类别跌幅接近，需警惕板块整体逻辑变化
3. **分类维度选择**：根据行情性质选择最有解释力的分类维度（周期/壁垒/模式/地域）
4. **验证分类有效性**：理论跌幅与实际跌幅是否吻合，决定分类维度是否正确

## M31：产业链风险传导分析法

**核心逻辑**：沿着产业链上下游，梳理风险从终端需求向上游传导的路径，定位冲击最大的环节和相对安全的环节。

### 传导模型

```
下游（终端需求）
  → 中游（应用/服务）
  → 上游（硬件/设备/材料）

风险传导方向：通常从下游向上游传导
  终端需求萎缩 → 中游订单减少 → 上游产能利用率下降

但也可反向传导：
  上游供给冲击 → 中游成本上升 → 下游价格传导受阻
```

### "铁索连舟"传导模型

```
风险从重到轻依次为：

上游半导体设备/材料 → 内存芯片 → 算力租赁公司 → 下游模型/应用公司

判断标准：
  - 越依赖重资产资本开支的环节，受需求预期下滑的冲击越大
  - 转为运营开支（租算力替代自建）的环节形成风险隔离
  - 越靠近终端用户的环节，需求刚性越强
```

### 分析步骤

```
Step 1：绘制产业链图谱（上下游关系）
Step 2：识别风险触发点（需求端/供给端/政策端）
Step 3：沿产业链追踪传导路径
Step 4：评估每个环节的暴露程度
  - 重资产/轻资产？
  - 可替代性强弱？
  - 定价权归属？
Step 5：定位"重灾区"和"避风港"
```

### 关键原则

1. **重资产环节是重灾区**：资本开支大、折旧高、产能利用率敏感的环节受冲击最大
2. **运营开支模式形成隔离**：从"自建"转向"租用"的环节，风险暴露大幅降低
3. **传导有时间差**：上游通常比下游更晚感受到需求变化，但跌幅可能更大
4. **反向传导不可忽视**：上游垄断者的供给冲击可以反噬整个产业链

## M32：跨市场映射分析法

**核心逻辑**：将海外市场的板块分化逻辑，对应到本土市场的同类标的，预判本土市场的走势与结构分化。

### 映射模板

```
海外市场逻辑：
  板块A：[属性] → [表现]
  板块B：[属性] → [表现]
  ...

本土市场映射：
  对应板块A：[本土标的] → 预期表现 [___]
  对应板块B：[本土标的] → 预期表现 [___]
  ...

节奏判断：
  海外市场已调整 [N] 日
  本土市场已调整 [M] 日
  → 若 M < N，后续仍有传导压力
  → 若 M ≥ N，可能已充分定价
```

### 会议应用示例

```
海外市场（美股）逻辑：
  "隔离垫"类型（轻资产、租算力）：跌幅最小
  "重灾区"类型（重资产设备/材料）：跌幅最大

本土市场映射：
  港股部分模型公司：
    - 已转向租算力模式
    - → 对应"隔离垫"类型 → 冲击相对有限
    
  A股半导体设备、材料、内存：
    - 重资产属性
    - → 对应"重灾区"类型 → 受冲击最明显

节奏判断：
  美股已连续两日调整
  A股仅调整一日
  → 后续仍有传导压力
```

### 关键原则

1. **属性匹配是映射核心**：不是看行业名称是否相同，而是看商业模式和属性是否对应
2. **时间差是布局窗口**：海外市场先反应，本土市场滞后 → 提前预判本土市场走向
3. **本土特殊性不可忽视**：监管环境、资金结构、估值水平可能导致映射偏差
4. **传导强度递减**：从海外到本土，逻辑传导通常会衰减，不能简单照搬跌幅

## M33：行情性质定性法

**核心逻辑**：通过「是否全面通杀、核心龙头是否坚挺、底层产业逻辑是否破坏」三个维度，区分 "阶段性估值回归" 与 "趋势性行情终结"，避免极端化判断。

### 三维度定性模板

```
维度1：是否全面通杀？
  □ 板块内部分化明显 → 非通杀，结构性调整
  □ 板块内部普跌且跌幅接近 → 全面风险，警惕趋势终结

维度2：核心龙头是否坚挺？
  □ 行业龙头相对抗跌甚至上涨 → 产业逻辑未破坏
  □ 行业龙头领跌 → 底层逻辑可能受损

维度3：底层产业逻辑是否破坏？
  □ 需求/技术/政策根基未变 → 估值回归，趋势延续
  □ 需求/技术/政策根基动摇 → 趋势可能终结

综合定性：
  2-3个维度指向"未破坏" → 阶段性估值回归
  2-3个维度指向"破坏" → 趋势性行情终结
```

### 会议应用示例

```
维度1：分化明显（技术壁垒型跌幅小，强周期型跌幅大）
  → 非通杀 ✅

维度2：核心技术龙头（英伟达等）相对坚挺
  → 产业逻辑未破坏 ✅

维度3：AI需求/技术/政策根基未变
  → 只是资本开支预期过热后的冷静期 ✅

综合定性：
  本次回调 = "强周期属性科技股从高估值回归冷静"
  ≠ AI科技牛市的结束
```

### 关键原则

1. **避免二元极端**：不是"牛市继续"就是"牛市结束"，中间有大量灰色地带
2. **龙头是锚**：核心龙头的表现是判断产业逻辑是否破坏的最重要信号
3. **分化是友**：跌幅分化说明资金在重新选择，不是全面撤离
4. **逻辑破坏才是终点**：只要底层需求/技术/政策根基未变，回调就是估值回归

## M34：前置预判验证法

**核心逻辑**：将当前市场走势与前期预判做对标，验证分析框架的有效性，强化后续应对策略的可信度。

### 验证模板

```
前期预判（时间：[日期]）：
  预判内容：___
  预判依据：___（使用了哪些方法论工具）

当前走势：
  实际市场表现：___
  与预判的吻合度：[高度吻合/部分吻合/偏离]

验证结论：
  若吻合 → 分析框架有效，后续策略延续
  若偏离 → 分析框架需要修正，找出遗漏因素

后续应对：
  基于验证结果，调整/延续应对策略
```

### 关键原则

1. **预判必须记录**：没有记录的预判无法验证，分析框架的有效性也无法评估
2. **吻合度量化**：不是"对了"或"错了"，而是评估预判与实际的偏离程度和原因
3. **偏差是改进信号**：预判偏离说明分析框架有盲点，是提升的机会
4. **验证增强可信度**：成功验证的前置预判能大幅提升后续策略的市场说服力
