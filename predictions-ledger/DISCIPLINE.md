# 研判纪律 · 环境过滤器（判市优先于方向）

> 来源：2026-08-25 复盘 6 条预测偏了的归因。本文件是 **append.py 的硬性闸门**，每次方向性分析"给方向之前"必须先过这里。
> 一句话总纲：**先判市，再给方向；弱市不赌方向。**

---

## 第 0 步：先判市（必做，写入 market_regime 字段）

动手给任何方向之前，先回答一个问题——**现在是什么市况？**

| market_regime | 定义（用证据判定，不是拍脑袋） | 给方向的默认规则 |
|---|---|---|
| **趋势市** | 均线多头/空头排列 + 放量突破关键位 + 主线清晰 | 可以给方向；置信度可 >70（需 `trend_confirmed=true`） |
| **震荡市** | 区间上下沿清晰、量能萎缩、无主导方向 | 给方向**必须带条件触发**（"若站上 X 则多"），否则降级为"区间+方向待确认" |
| **弱势市** | 均线压制、量价背离、反弹无量、基本面无改善 | **默认不给单边多/空**，改"区间+方向待确认"；只有放量突破关键位+均线转多才给 |

判定证据来自框架，不要凭感觉：
- 均线系统（蔡森技术形态）→ 多空排列
- 量能（价量一票）→ 突破是否放量确认
- 资本流向（资本三流/路口大爷）→ 钱往哪去

---

## 规则 1：弱势市不赌方向

- 弱势市（market_regime=弱势市）给"多"或"空" → **append.py 会警告**（并强制把置信度压到 60）。
- 正确写法：把单方向改成 **"区间 + 方向待确认"**，例如：
  - ❌ `方向:多 目标:+8%~+20%`
  - ✅ `方向:中性偏多(待确认) 目标:弱反弹看X；放量站上X转多，否则观望；破Y认错`
- 影石创新（`P-20260727-001`）就是这么写的（站稳147转多 / 跌破120转空），所以最后偏空方向判对——**这条写法要推广到所有方向判断**。

## 规则 2：可能加速的品种，不封顶（品位 = 目标上移）

对正在加速/趋势的品种（黄金、股指、强趋势商品），**主判断写"当前区间 A–B；站上 B 看 C"，绝不写"封顶 B"**。

- ❌ `中性 区间3959-4100（封顶4100）` → COMEX黄金后来冲到 4665，封顶被打脸。
- ✅ `偏多；当前3959-4100，站上4100看4300+，破3959转震荡`
- 逻辑：加速品种用"固定上沿"框，尺子一定不够长。把上沿变成"触发位"，破位即上移目标。

## 规则 3：弱势品种不给涨幅，只给"反弹位 + 止损"

弱势/震荡品种，**不写"+8%~+20%"这种涨幅目标**（那是把反弹当趋势，乐观偏差）。

- ❌ `中性震荡偏多 目标:+8%~+20%`（中国铝业，实际只 +1.7%）
- ✅ `弱反弹看 X（约+3%~+5%）；放量站上关键位再看高；破 Y 认错，仓位压低`
- 赌赔率不赌方向，仓位自然压低。

## 规则 4：所有方向性结论改成"条件式"

把"多"改成 **"若放量站上 X 则多，否则观望"**。这样即使看错，也是"条件没触发=没动"，不是"做了反向"。

- 触发条件写进 `falsification` 和 `target_range`（append.py 会检测是否含"若/站上/跌破/放量/转多/转空/待确认"等条件词）。
- 无条件的单边方向在弱势/震荡市会被闸门警告。

## 三道关：方向别脱离框架，先过这三关

给方向之前，按资产类别先过对应的一道（或几道）：

| 资产 / 情景 | 必过关卡 | 作用 |
|---|---|---|
| **股指 / 美股 / 宏观** | **路口大爷**：资本流向 + 美元周期 | 标普偏空错 → 没看流动性/美元周期（宽松下美股不跌）。方向前先确认美元与资本流向。 |
| **商品 / 避险资产** | **资本三流**：流向（钱往哪去） | 黄金破4100 → 资本明显流向黄金（避险/贬值），资金流早指向它，但预测写了中性。资金流必须转化成方向。 |
| **弱势个股"偏多"** | **Mi姐**：D/E 资金情绪门控 | 弱势股给"多/偏多"前，先过资金情绪门控；情绪筹码不配合就不给多。 |

> 这三关是框架的"方向前校验"，不是可选项。判市（第0步）之后、写 direction 之前必须跑。

---

## 置信度纪律

- **弱势市的方向性判断，置信度上限 60**（append.py 自动压）。
- **趋势市置信度 >70，必须 `trend_confirmed=true`**（趋势确认：放量突破+均线排列），否则封 70。
- 震荡市方向性判断，置信度建议 ≤65 且带条件。
- **校准线（每次复盘重点看）**：标 70 分的预测，是否约七成兑现？连续不兑现 → 整体偏高，下一轮统一下调。

- [ ] 加速品种：没写死"封顶"，用了"站上 X 看 Y"
- [ ] 弱势品种：没写涨幅目标，只给了反弹位+止损
- [ ] 方向性结论带条件触发词（若/站上/跌破/放量/转多/转空/待确认）
- [ ] 按资产过了对应关卡（路口大爷 / 资本三流 / Mi姐）
- [ ] 置信度符合纪律（弱势≤60；趋势>70需 trend_confirmed）
