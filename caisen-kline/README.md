## 这是什么

一套基于蔡森《多空轉折一手抓》**方法论**的 K 线自动分析工具。输入任一带 K 线数据的标的（A股 / 港股 / ETF / 指数 / 期货），自动识别：

- **A 招（颈线识别）** + **B 招（等幅满足）** + **K 招（失败识别：量价背离 / 假突破 / 逃命线）**
- 生成**带标注的高清 K 线图**（PNG，约 4100×3900 px，4K 级，全平台通用，放大 10 倍不糊）+ **结构化文字分析**（结构判定 / 关键价位 / 风险报酬 / 量价论据 / C1–C4 强制约束）

支持市场：沪市 / 深市 / 创业板 A股、港股、ETF（沪 / 深，含跨境 QDII）、指数（中证系列）、期货（上期所 / 大商所 / 郑商所）。
不支持：美股、外汇、中金所 / 上期能源 / 广期所（S6 硬编码拒绝，绝不静默出图）。

- **债券不可用（2026-09-11 实测）**：可转债（如 113050）返回空数据，取不到 K 线。请勿按「支持债券」宣传或使用。
