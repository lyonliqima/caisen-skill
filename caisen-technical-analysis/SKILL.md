## 核心理念

- **纯粹技术派**：只看K线形态与成交量，不看基本面。所有信息已反映在价格和成交量中。
- **化繁为简**：去除多余技术指标，专注形态与量价两大核心。
- **波段操作**：抓大趋势波段，不做日内短线差价。
- **形态驱动**：只在形态明确时操作，形态不明确则观望。

## 分析工作流

当用户要求分析某标的走势时，按以下步骤进行：

### 第一步：识别当前所处形态

从K线走势中识别属于哪类形态：

**底部形态（做多信号）**：
| 形态 | 识别特征 | 确认条件 | 量化confidence |
|------|----------|----------|---------------|
| W底（双底） | 两次探底，第二次不低于第一次太多 | 放量突破颈线（两底之间的高点） | 65→80（放量） |
| 头肩底 | 左肩→头（更低）→右肩（高于头） | 放量突破颈线 | 75→85（放量） |
| V底 | 急跌后急涨，无明显底部横盘 | 反转伴随巨量 | 60（难以量化） |
| 圆弧底 | 缓慢弧形筑底，时间较长 | 突破圆弧顶部水平线伴随放量 | 70 |
| 三重底 | 三次探底，底部接近 | 放量突破颈线 | 75→85 |
| 矩形底 | 长时间底部横盘震荡 | 放量突破矩形上沿 | 70 |
| **破底翻** | 跌破支撑后快速收回 | 3日站稳确认 | 60→75（站稳） |

**头部形态（做空信号）**：
| 形态 | 识别特征 | 确认条件 | 量化confidence |
|------|----------|----------|---------------|
| M头（双顶） | 两次冲高，第二次未能有效突破第一次高点 | 跌破颈线（两顶之间的低点） | 65→80（确认跌破） |
| 头肩顶 | 左肩→头（更高）→右肩（低于头） | 跌破颈线 | 75→85 |
| 斜颈线头部（上升楔形头部） | 顶部区域低点递升形成斜颈线，高点无力创新高 | 跌破斜颈线（上升趋势线） | 70→85（放量跌破） |
| 圆弧顶 | 缓慢弧形见顶 | 跌破圆弧底部水平线 | 70 |

**中继形态（趋势延续）**：
| 形态 | 识别特征 | 操作方向 | 量化confidence |
|------|----------|----------|---------------|
| 旗形整理 | 急涨/急跌后小幅反向平行通道整理 | 突破旗形方向延续原趋势 | 65→75 |
| 三角收敛 | 高点递降、低点递升，波动收窄 | 向上突破做多，向下突破做空 | 55→70 |
| 矩形整理 | 水平区间震荡 | 突破方向跟随 | 70 |

### 第二步：画颈线

颈线是形态分析的灵魂：

1. **底部形态颈线**：连接形态中的反弹高点，形成阻力线。突破颈线 = 多头确认。
2. **头部形态颈线**：连接形态中的回踩低点，形成支撑线。跌破颈线 = 空头确认。
3. **颈线可以是水平线或倾斜线**，取决于反弹/回调的具体价位。

### 第三步：验证量价关系

量价配合是确认形态有效性的关键：

| 场景 | 量价要求 | 含义 |
|------|----------|------|
| 突破颈线（多头） | 放量突破 | 突破有效，可进场做多 |
| 突破颈线（多头） | 缩量突破 | 突破可疑，可能假突破 |
| 跌破颈线（空头） | 可放量也可不放量 | 跌破即有效，不需量确认 |
| 回踩颈线 | 缩量回踩 | 健康回调，可加仓 |
| 上涨过程 | 量增价涨 | 趋势健康 |
| 上涨过程 | 量缩价涨 | 上涨乏力，警惕 |

### 第四步：计算测幅满足（目标价位）

测幅满足用于预估行情目标位，制定止盈计划：

**底部形态测幅**（做多目标）：
```
目标价 = 颈线价格 + 形态高度
形态高度 = 颈线价格 - 底部最低点价格
```

**头部形态测幅**（做空目标）：
```
目标价 = 颈线价格 - 形态高度
形态高度 = 顶部最高点价格 - 颈线价格
```

**特殊测幅规则**：
- 三重底/矩形底：可用矩形高度计算
- 头肩底：也可用头部到颈线距离的1.5~2倍估算
- 旗形：旗杆长度 = 突破后预期涨幅
- 月线大级别形态：满足幅度更大，可信度更高
- **M头/头肩顶两波跌幅满足**：第一波跌幅H=形态高度（顶→颈线），第二波跌幅=从颈线再投射H，两波等距即"满足"。第一满足点=颈线-H，第二满足点=颈线-2H。到达第一满足点后可能反弹整理，到达第二满足点后跌势大概率尾声

### 第五步：制定交易计划

基于以上分析，输出交易计划模板：

```
【形态分析结论】
标的：XXX
当前形态：XXX（底部/头部/中继）
颈线位置：XXX

【交易方向】做多/做空/观望

【进场条件】
- 具体触发条件（如：放量突破颈线XXX元）

【止损设置】
- 做多：跌破颈线或形态底部下方2-3%
- 做空：突破颈线或形态顶部上方2-3%

【目标价位】
- 第一目标（测幅满足）：XXX
- 第二目标（如有）：XXX

【量价观察要点】
- 需要关注的量价信号
```

## 两大核心策略

### 破底翻（做多绝招）

蔡森最推崇的做多策略。主力在底部洗盘，刻意跌破支撑清洗浮筹后迅速收回。

**识别步骤**：
1. 股价在底部区域形成支撑（画出底部颈线/支撑线）
2. 某日带量跌破支撑线（散户恐慌抛售）
3. 随后快速收回到支撑线之上（主力吸筹完毕的信号）
4. 回调不破底部低点 → 确认破底翻成立

**进场时机**：
- 第一个买点：股价翻回支撑线上方时
- 第二个买点（加码）：突破颈线时
- 胜率约70%，适合波段持有

**止损**：若再次跌破底部低点，则破底翻失败，止损出局。

### 假突破（做空绝招）

与破底翻对称的做空策略。股价突破前高后迅速回落，表明突破失败。

**识别步骤**：
1. 股价在头部区域形成阻力（画出颈线）
2. 某日突破前高/阻力线（散户追高买入）
3. 随后快速回落到阻力线下方（主力出货完毕）
4. 反弹无法再站上阻力线 → 确认假突破成立

**进场时机**：
- 股价回落跌破颈线时做空
- 反弹无法站回颈线时加码

**止损**：若再次突破并站稳前高上方，则假突破失败，止损出局。

## 操作纪律

1. **只做明确的形态**：形态模糊不清时，宁可错过也不做错
2. **严格止损**：每笔交易必须设定止损，绝不扛单
3. **波段持有**：买入后持有到测幅满足或形态破坏，不做日内差价
4. **大周期优先**：月线、周线形态比日线更可靠，优先操作大级别形态
5. **量价配合**：永远用量价关系验证形态有效性
6. **不预测，只跟随**：等待形态确认后再行动，不提前预判

## K线图表划线方法（蔡森式标注法）

当用户提供股票K线图要求分析时，需要在图表上进行专业标注。以下是蔡森在实战教学中使用的划线规范：

### 划线工具与颜色规范

| 元素 | 颜色 | 用途 |
|------|------|------|
| 颈线（支撑/阻力） | **黑色水平线** | 标注形态的关键颈线位置 |
| 跌破/危险线 | **红色水平线** | 标注跌破即确认空头的关键位 |
| 目标/满足线 | **绿色水平线** | 标注测幅满足目标价位 |
| 辅助参考线 | **紫色水平线** | 标注次要支撑阻力或前高前低 |
| 整理区域 | **紫色虚线矩形** | 框选矩形整理/箱体震荡区间 |
| 突破方向 | **红色箭头** | 指向突破方向或关键转折点 |
| 关键点 | **红色圆圈** | 圈出重要价格转折点 |
| 进场点 | **"+" 标记** | 标注建议进场位置 |
| 失败点 | **"X" 标记** | 标注形态失败/止损位置 |
| 价格标注 | **数字** | 在所有关键位置标注具体价格 |
| 测幅距离 | **蓝色竖线 + 数字** | 标注形态高度（用于计算满足点）|

### 划线步骤（按蔡森实战顺序）

**第1步：画水平颈线**
- 在图表上画出形态的关键颈线（水平线为主）
- 底部形态：连接反弹高点 → 黑色水平线
- 头部形态：连接回调低点 → 黑色水平线
- 在每条线旁标注具体价格数字

**第2步：标注形态结构**
- 用文字或标记标注：左肩、头部、右肩（头肩形态）
- 标注：第一底、第二底（W底）
- 标注：前高、前低
- 用手绘线连接关键点形成形态轮廓

**第3步：画整理区域（如有）**
- 若存在矩形整理/箱体震荡，用紫色虚线矩形框选
- 标注上沿和下沿的价格

**第4步：标注量价信号**
- 在成交量图上标注关键量变化
- 用红色箭头指向关键K线（如破底翻的破底K线、突破K线）

**第5步：计算并标注测幅满足**
- 用蓝色竖线测量形态高度（从底部到颈线，或从顶部到颈线）
- 在竖线旁标注高度数值
- 从颈线位置投射等距高度，用绿色水平线标注目标价位
- 标注文字："满足点 XXX"

**第6步：标注进出场位置**
- 用 "+" 标记进场点
- 用 "X" 标记止损点
- 用红色箭头标注突破/跌破方向

### 多周期分析标注

蔡森习惯同时分析多个时间周期：
1. **先看月线**：确定大方向和大级别形态
2. **再看周线**：确认中级趋势和形态
3. **最后看日线/60分钟线**：找精确进出场点

标注时需说明当前分析的是哪个周期，不同周期的形态可能不同。

### 日线画线分析窗口规范（2026-06-17更新）

**日线形态分析默认窗口 = 60个交易日（约3个月）**，对应算法回看范围120根K线（含缓冲）。

| 分析需求 | K线窗口 | 形态识别优先级 |
|---------|---------|---------------|
| **标准日线画线** | 最近60个交易日 | W底→M头→头肩底→头肩顶→破底翻→收敛三角→旗形→趋势线 |
| 大格局（周线级） | 最近120个交易日 | 同上，但满足幅度更大 |
| 短线（60分钟级） | 最近30根60分钟K线 | 以破底翻/假突破为主 |

**画线必须参照 `drawing-guide.md` 中的量化形态识别算法**：
- 局部极值检测（lookback=3~5）
- 双底/双顶差值阈值（5%）
- 颈线倾斜角度判断（<15°）
- 破底翻量化判定（跌破3%+收回）
- 收敛三角边长等长测幅

## K线图表涨跌幅标注法

蔡森在通达信/东方财富的K线图上，会直接标注关键区间的涨跌幅百分比：

```

**与测幅满足的结合**：

- 标注历史涨跌幅可以帮助识别"涨幅满足"或"跌幅满足"的区间

## M11：停损纪律操作系统

> 纪律操作不带任何感情，赚两次赔一次就是成功的节奏。

### 核心原则

```
纪律操作 = 七七勤展六億，不带有任何感情

节奏管理：
□ 看空时坚定做空，设好停损点
□ 赚两次 → 准备5-8万来赔一次
□ 赚10万 → 准备3-5万来赔
□ 一次错不代表全部错，前面赚的要算
□ 长空中：反弹还要空，直到空单被停损
```

### 假突破做空的纪律

```
假突破出现 → 做空（这是铁律）
  ├── 点到停损 → 出场（赔3-5万）
  ├── 未点停损 → 继续持有
  └── 反弹出现 → 继续做空（不是等解套，而是重新布局）

成功率评估：
  做空成功率 ≈ 85%（失败率15%）
  每次赚4000-5000点（台指期）
  每次赔300-500点
  赚两次赔一次 = 长期必赚
```

### 纪律vs感情

- **不能断章取义**：不能只算错的次数，要把前面赚的也算进去
- **前面对的也要算**：赚三次错一次又赚一次 = 总体还是赚
- **不带感情**：看到假突破就做空，看到停损就出场，不加个人判断

## M12：收敛三角满足操作法

> 收敛三角支撐不破看滿足，满足了就不追价。

### 分析框架

```
收敛三角操作流程：
Step 1：识别收敛三角（上压线+下支线的夹角越来越小）
Step 2：画颈线（上下两条趋势线）
Step 3：突破确认（实体突破，不只是影线）
Step 4：压回不破颈线 → 确认有效
Step 5：测幅满足计算
  □ 三角最宽处的垂直距离 = 测幅目标
  □ 突破点 + 测幅 = 目标价
Step 6：满足后不追价！
  □ 设短线支撑 = 停利点
  □ 逆势走强的看逆势低点作为强弱分界
```

### 边长等长原则（6-17视频补充）

```
收敛三角测幅精确表述：
├── 三角最宽处的"边长"（垂直距离）= 突破后的"等长"（等距延伸）
├── 画法：用蓝色竖线量出三角最宽处的垂直距离
├── 从突破点向右等距延伸 = 满足点
└── "边长边长等于突破后的等长"——蔡森原话
```

### 与其他方法论的协作

- **M5分钟线抄底**：日线出现收敛三角时，用5分钟线/小时线找精确进场点
- **M6破底翻**：三角内部可能出现破底翻，新上市/下跌中的第一次破底翻都有反弹
- **M2颈线**：三角突破后的压回颈线是关键支撐

## 期权操作纪律

蔡森反复强调的期权操作铁律：

| 原则 | 说明 | 原因 |
|------|------|------|
| **绝不做卖方** | 不卖Call也不卖Put | 卖方收益有限但风险无限（可能被断头） |
| **只做买方** | 看多买Call，看空买Put | 买方风险有限（最多赔权利金），收益空间大 |
| **选择权卖方=被杀对象** | 盘中一口拉到涨停板就是卖方被断头 | 一次极端行情就能让卖方全部亏损 |

**实战案例**：台股大跌时，卖权（Put卖方）一口被拉到涨停板，成交仅两口就V型反转——这两口就是卖方被强制平仓（断头）。

## 外资养套杀三步法

蔡森39年操盘经验总结的外资操纵台股经典模式：

```
Step 1（养）：拉现货
  - 外资在台股高档卖出个股（如台积电）
  - 同时大买ETF → ETF基金经理人被迫买入台积电
  - 结果：外资边卖边涨，散户看到赚钱拼命追入

Step 2（套）：空期货
  - 外资在期货市场大举做空（如69000口，契约金额6200亿+）
  - 散户却在期货抢多
  - 结果：外资空单部位庞大，散户多单被套

Step 3（杀）：杀现货
  - 外资集中抛售现货（单日900亿+）
  - 期货同步下跌 → 散户多单被杀到跌停
  - 选择权卖方被断头
  - "半夜行刑"：夜盘台指期货暴跌
```

**蔡森的应对策略**：
- 买个股、空指数
- 只要看到指数假突破，一定做空
- "赚一千点赔三五百点，还是赚"
- 到颈线是否回补看S&P500是否假突破

## 量价背离庞氏信号

蔡森将量价背离与庞氏骗局类比，用于判断多头末期：

### 核心逻辑

```
庞氏骗局：后面进来的人付前面人的利息 → 后面没人跟了就崩盘
股市多头：后面融资/资金进来推高股价 → 融资不再进来就崩盘
```

### 检测方法

1. **融资余额背离**：股价创新高但融资余额增速放缓或不再增加
   - 融资破5000亿以上 → 历史级别危险信号
   - 融资不跟 = 后面没人跟 = 准备崩盘
2. **成交量背离**：最大量不是出现在最高价
   - 最大量的K线之后价格继续涨但幅度变小 → 背离
3. **世代同堂借贷**：信贷+房贷+车贷+融资全部膨胀到极限

### 实战应用

- 蔡森在会员频道提前画出压力区（前大量K线的上下缘）
- 到达压力区时开始减仓："卖到你睡得着为止"
- 睡不着 = 有压力 = 需要继续减仓

## 本益比反向操作法

蔡森用实战经验颠覆传统本益比逻辑：

| 传统认知 | 蔡森实战经验 |
|----------|-------------|
| 本益比低=便宜可买 | 本益比低可能已是股价高点（高点获利最好时本益比最低） |
| 本益比高=贵不宜买 | 本益比高（甚至亏损无法计算）往往是股价底部 |

### 实战案例

- **南亚科**：底部时EPS亏损，本益比无法计算（最高）→ 股价25.6元见底 → 涨到获利大增时本益比反而只有10倍（已是高位）
- **S&P 500**：席勒本益比约41是155年来第二高 → 但股价已在天上 → 这是"double kill"（股价高+本益比也高）

### 使用原则

- 不能用本益比高低作为买卖依据
- 底部都出现在本益比最高（或亏损无法计算）的时候
- 高点都出现在本益比最低（获利最好）的时候
- 当前本益比高+股价也高 = 极度危险

## M7：多资产形态差异指南

> 同样12种形态在不同资产类别上的表现有显著差异。以下指南帮助调整分析参数。

### 各资产形态特异性

| 形态 | 股票 | 指数 | 商品 | 加密货币 |
|------|------|------|------|----------|
| W底 | 标准形态，需放量突破 | 底部更圆，时间更长 | 受供给冲击影响大，可能变形 | 波动极大，颈线易被插针 |
| M头 | 第二顶常低于第一顶 | 双顶间时间可长达数月 | 受地缘冲击可能跳过形态 | 假突破极多，需更强确认 |
| 头肩底/顶 | 标准形态 | 右肩常不对称 | 较少见 | 常见但"右肩"可能极不规则 |
| 破底翻 | 经典做多策略 | 指数破底翻成功率更高 | 商品破底翻后涨幅常超预期 | 插针型破底翻多，需3日确认 |
| 假突破 | 经典做空策略 | 指数假突破后跌幅更大 | 受供给冲击可能反转 | 极多假突破，但反转也快 |
| 三角收敛 | 标准形态 | 大级别三角很可靠 | 受OPEC等地缘冲击可跳过 | 三角常不规整，需更多容忍 |

### 加密货币形态特殊规则

```
□ 波动容忍度上调：两底价格差容忍度从5%上调到10-15%
□ 插针处理：影线突破但实体未突破 → 不算突破
□ 确认时间延长：3日确认改为5-7日确认（7×24交易）
□ 量价关系调整：加密市场量能数据不如股市可靠，更依赖价格行为
□ 周末效应：周末流动性差，突破/跌破常在周末发生但不可靠
```

### 商品形态特殊规则

```
□ 供给冲击优先：地缘事件可能完全跳过形态（如油价突然暴涨）
□ 季节性调整：商品有季节性波动，需区分形态和季节性
□ 库存数据确认：突破时结合库存数据验证（库存降=突破更可靠）
□ 跨品种联动：原油走势传导到化工品、黄金影响白银
```

## M13：V型反转等级鉴定法

> 指数级别的V型反转是几十年才出现一次的极端事件。识别V型反转的等级，是判断当前市场是否处于历史级泡沫尾段的核心工具。

### V型反转鉴定标准

```
V型反转五大必要条件：
1. 涨幅够高：尾段喷出涨幅 ≥ 50%（2-3倍以上为经典级）
2. 速度极快：上去速度快，下来速度也快（直上直下）
3. 跌幅够深：从高点跌幅 ≥ 50%（走长空头半年以上）
4. 全民投机：市场进入全民运动阶段（融资破表、散户疯狂）
5. 尾段加速：头部右侧喷出后才V转（非左侧上涨中途）

V型反转等级评定：
┌─────────┬──────────────┬─────────────────────┐
│ 等级     │ 特征           │ 历史案例                  │
├─────────┼──────────────┼─────────────────────┤
│ 经典级   │ 涨6倍+跌50%+ │ 道琼1929、台股1990      │
│ 标准级   │ 涨1-3倍+跌50%│ 道琼2000/2008、S&P 2008  │
│ 次级     │ 涨50%-1倍+跌 │ S&P 1973、S&P 2022     │
│ 非典型   │ 跌<半年即恢复 │ 1987（一个月就过了）      │
└─────────┴──────────────┴─────────────────────┘
```

### 历史V型反转对照表

| 市场 | 年份 | 涨幅 | 跌幅 | 等级 | 间隔 |
|------|------|------|------|------|------|
| 台股 | 1990 | 8000→12682 (+50%尾段) | -50%+ | 经典 | 36年前 |
| 道琼 | 1929 | 63.9→380 (+500%) | -50%+ | 经典 | 97年前 |
| 道琼 | 2000 | 尾段喷出 | -50%+ | 标准 | — |
| 道琼 | 2008 | 尾段喷出 | -50%+ | 标准 | — |
| S&P500 | 2008 | 尾段喷出 | -50%+ | 标准 | — |
| S&P500 | 1973 | 涨1-2倍 | -50%+ | 次级 | 53年前 |
| S&P500 | 2022 | 涨幅不高 | -40%+ | 次级 | — |
| 道琼 | 1987 | 涨多一次泄完 | 快速恢复 | 非典型 | — |

### 实战应用

```
当怀疑当前处于V型反转前夜时：
Step 1：检查涨幅——当前喷出阶段涨幅是否 ≥ 50%？
Step 2：检查投机度——全民运动？融资破表？ETF狂潮？
Step 3：检查历史间隔——该市场上一次经典V转是多少年前？
Step 4：对标结论——如果三项全中，进入M9空头信号检测
Step 5：不预测，只应对——没出现V转一切都空谈
```

### 蔡森警语

- "指数的V型反转是几十年才会出现一次"
- "你要再赌往上还有多高，那你去赌，森哥祝你成功"
- "没有出现V型反转，一切都空谈"

## M14：康波周期对标法

> 每个时代都有每个时代的故事（工业革命→电脑→AI），故事造成投机泡沫，泡沫结束后故事不会结束，绵延流长50年。

### 康波周期核心规律

```
50年康波周期结构：
Phase 1（30年）：横向筑底期
  → 前一个泡沫破裂后的漫长整理
  → 新技术/新故事开始萌芽
  → 市场遗忘、无人问津

Phase 2（3-5年）：突破喷出期
  → 突破30年横盘区间
  → 新故事（AI/电脑/工业革命）驱动投机
  → 全民运动开始

Phase 3（1-3年）：泡沫高潮→大头部
  → 尾段喷出（涨速极快）
  → 形成大头部结构（V型反转风险最高）
  → M9十大罪状可能逐项触发

Phase 4（1-3年）：空头修正期
  → 泡沫破裂，跌幅 ≥ 50%
  → 但故事本身不会结束
  → 为下一轮50年周期埋下种子
```

### 道琼 vs 台股对标实证

```
道琼（1897-1929）：
  横向筑底 ≈ 30年（1897→1925突破）
  → 喷出至1929年大头部
  → V型反转（63.9→380→暴跌50%+）

台股（1987-2017→现在）：
  横向筑底 ≈ 30年（1987→2017突破）
  → 2020新冠后无限QE喷出
  → 目前在喷出阶段（月线46552）
  → 故事：AI（对应道琼当年的工业革命/电气化）

关键对标：
  道琼30年底 → 台股30年底 ✓
  道琼喷出后V转 → 台股？？（待观察）
  道琼97年前 → 台股36年前（频率不同但结构相似）
```

### 周期应用原则

- **不精确计算**：康波周期准确率极高但过度研究短命，用最粗略的方式套用即可
- **对标而非预测**：用历史结构对比当前阶段，不预测具体时间点
- **故事不灭论**：泡沫破裂 ≠ 技术消失，AI泡沫破裂后AI仍会绵延50年
- **底部才是关键**："什么时候是底才是重要"，错过抄底等下一个周期

### 与其他方法论的联动

```
M14 + M9：喷出阶段用十大罪状检测是否进入泡沫尾段
M14 + M13：对标历史V转判断当前等级
M14 + M10：月线翻黑 = 周期转折的先行信号
M14 + M6：30年底部破底翻 = 超级抄底机会
```

## 战争反市场操作法则

> 战争开打股市不跌，战争结束股市不见得会涨。这叫反市场操作。

### 核心规律

```
战争与市场反应的非线性关系：
┌────────────────┬──────────────┬────────────────────┐
│ 事件             │ 市场预期        │ 实际表现                  │
├────────────────┼──────────────┼────────────────────┤
│ 战争开打         │ 应该大跌        │ 不一定跌（已price in）   │
│ 战争结束/和谈    │ 应该大涨        │ 不一定涨（利多出尽）       │
│ 战争升级超预期   │ —              │ 真正大跌（超出price in范围）│
│ 和平协议破裂     │ —              │ 真正大跌（预期反转）        │
└────────────────┴──────────────┴────────────────────┘
```

## 选择权分层抄底法

> 抄底不是赌一次，是按风险梯度分批进场。期货风险最高，选择权居中，ETF风险最小。

### 风险三级梯度

```
抄底工具选择（风险由低到高）：
┌──────────┬──────────────┬───────────────────┐
│ 工具       │ 风险等级        │ 适用场景                     │
├──────────┼──────────────┼───────────────────┤
│ ETF        │ ★☆☆ 最低      │ 不想盯盘、长线持有           │
│ 选择权买权 │ ★★☆ 中等      │ 有底型雏形、风险可控         │
│ 期货       │ ★★★ 最高      │ 完整底型打出、停损点明确     │
└──────────┴──────────────┴───────────────────┘
```

### 操作节奏

```
Step 1：第一次进场（买权为主）
  - 用买权（Call），不要卖权
  - 日期长的贵但成功率高（有时间等待）
  - 日期短的便宜但要准备两次损失
  - 控制第一次损失金额

Step 2：观察底型
  - 可能需要二次打底（单脚不成底）
  - 除非突发V型反转（如以色列局势升级）
  - 打出两个底 → 风险可控 → 再决定做期货

Step 3：期货进场（等底型确认）
  - 必须看到完整底型（如双底、破底翻）
  - 停损点设在底型低点下方
  - 5分钟线找破底翻作为精确进场点
```

### 核心原则

- 赚到后，下一次用买权买扣（控制风险）
- 等底型出来再决定要不要做期货
- 日期长的选择权贵但让成功率提高
- 两次选择权的预算准备（不要只赌一次）
- 基本面一旦出现问题，技术面就会立刻反应 → 但要有二次打底准备

## 龙头带动板块轮动法

> 同一产业里，龙头先涨，后面拖着上去。识别龙头 = 抓到整条产业链的入场信号。

### 龙头识别规则

```
龙头判定标准：
├── 先涨原则：同产业里第一个放量突破的就是龙头
├── 带量原则：龙头必须带量，不带量的不算
├── 涨幅原则：龙头涨幅通常最大或最先涨停
└── 确认原则：龙头涨后其他同产业跟上 = 确认
```

### 实战轮动链

| 产业 | 龙头（先涨） | 跟随（后涨） | 落后补涨 | 时间差 |
|------|-------------|-------------|---------|--------|
| A股面板 | 京东方A | TCL → 深天马A | 利亚德 | 1-3天 |
| 台股记忆体 | 美光（美股先行） | 华邦电、南亚科 | 旺宏 | 1-4周 |
| A股存储 | 兆易创新（12月） | 其他存储 | 佰维存储（9月26才代量） | 数月 |
| A股核建 | 中国核建 | 中国能建 | — | 同天 |

### 操作流程

```
Step 1：锁定产业板块
Step 2：找出龙头（谁第一个带量突破）
Step 3：龙头涨后观察同产业是否跟上
  - 跟上 → 板块轮动确认 → 跟随股进场
  - 不跟 → 可能只是龙头个股行情
Step 4：跟随股进场后，支撑看「今天低点」
  - 带量转折的当天低点 = 支撑
  - 不追价（前面有带量压力就等回测）
```

### 跨市场先行指标

- **台股先行，A股落后反应**：台股记忆体先涨 → A股存储后面才突破
- **美股先行，台股跟随**：美光先涨 → 台股华邦电/南亚科跟上
- **龙头先行，落后补涨**：产业关系带动，落后的最终也会跟上

## 二度破底翻净化法

> 一次破底翻不够稳，两次破底翻 = 洗盘净化完成。单脚不成底，双脚才是真底。

### 核心逻辑

```
破底翻次数与可靠性：
┌──────────────┬──────────────┬────────────────┐
│ 破底翻次数     │ 可靠性          │ 操作策略               │
├──────────────┼──────────────┼────────────────┤
│ 一次破底翻     │ 中等（可能假底） │ 买权试探，不做期货     │
│ 二度破底翻     │ 较高（净化完成） │ 期货进场，停损明确     │
│ 三度破底翻     │ 极高（彻底洗盘） │ 重仓机会（罕见）       │
└──────────────┴──────────────┴────────────────┘
```

### 操作要点

- 第一次破底翻：用买权试探，控制损失
- 等二次打底：类似「单脚不成底」，需要二次确认
- 二度破底翻确立后：
  - 支撑看「今天低点」（每次破底翻当天的低点）
  - 净化区完成 → 风险可控 → 可用期货
  - 60分钟线也有破底翻（辅助确认）

### 与M6的联动

- M6讲破底翻的基本识别 → 本方法讲**次数与可靠性**
- 一次破底翻可能只是洗盘的开始
- 二度破底翻 = 净化完成 = 真正的底部确认

## 回拉低点支撑线画法（6-17视频新增）

> 创新高后回拉的低点，向右延伸画支撑线。这是颈线之外的另一种动态支撑画法。

### 画法步骤

```
回拉低点支撑线流程：
Step 1：股价创新高后出现回拉（pullback）
Step 2：找到回拉的最低点
Step 3：从此低点向右画水平支撑线
Step 4：后续价格回测此线不破 = 支撑有效

与颈线的区别：
├── 颈线：连接形态中的反弹高点/回踩低点，用于确认形态突破
└── 回拉支撑线：突破后创新高再回拉的低点，用于跟踪动态支撑
```

### 实战应用

- 新股上市后突破、回拉、再创新高 → 从回拉低点画支撑线
- 两低点出来后 → 风险已明确，可以量化停损幅度
- 配合"开高百分比"：如开高6%，风险就是6%，回拉不破低点则继续持有

## 新股主力攻击成本停损法（6-17视频新增）

> 新股突破后的长红K线 = 主力攻击成本，停损设在攻击成本下缘，并随行情推进动态调整。

### 三阶段停损调整

```
新股突破后的停损动态调整：
┌─────────────┬─────────────────────┬──────────────┐
│ 阶段             │ 停损位置                     │ 适用场景              │
├─────────────┼─────────────────────┼──────────────┤
│ 刚突破         │ 主力攻击成本（长红K线）下缘   │ 突破后首次回拉          │
│ 涨一波压回     │ 整理区下缘                   │ 第一波涨幅后回拉          │
│ 涨过一波又回来 │ 只看下缘（不再看攻击成本） │ 趋势已确认，只需跟踪低点  │
└─────────────┴─────────────────────┴──────────────┘
```

### 主力攻击成本识别

- 长红突破K线 = 主力攻击成本
- 如长红涨幅15%，压回一半(7.5%) → 风险剩下不到8%
- 赚一倍后压回不破支撑 = 策略成功
- 压回在支撑线附近 = 确认支撑有效

### 实战案例（SpaceX新股）

```
SpaceX上市分析：
1. 创新高后回拉低点 → 画支撑线
2. 隔天开高6% → 风险就是6%
3. 两低点出来 → 风险已明确
4. 长红突破 = 主力攻击成本 → 停损设在下缘
5. 压回一半(7.5%) → 风险不到8% → 赚一倍
```

## 本益比景气循环法（6-18视频新增）

> 蓝筹股的本益比随景气周期变化：景气不好时10-15倍，景气好时30倍。用EPS×景气倍数=目标价。

```
蓝筹股本益比周期规律：
┌──────────┬─────────────┬─────────────────┐

├──────────┼─────────────┼─────────────────┤

│ 景气好     │ 25-30倍         │ 股价高位，本益比看似低（获利好）  │
└──────────┴─────────────┴─────────────────┘
```

### 实战应用

```

- **本益比景气循环法**：本益比倍数随景气周期变化，用于计算蓝筹股目标价和判断景气位置

### 核心逻辑

```
多点共振检测：
├── 单一品种转弱 = 可能只是个股/品种问题
├── 多品种同时转弱 = 趋势性信号
│   ├── 金融板块转弱
│   ├── 七姐妹多数未创新高
│   ├── 比特币转弱
│   └── 多点发生 → 趋势越容易形成
└── 越多信号同时出现，趋势确认度越高
```

### 与其他方法的联动

- **M8市场宽度确认**：多个品种转弱 = 市场宽度恶化
- **M9十大罪状**：多点触发 = 系统性风险上升
- **M5多周期共振**：不同时间周期+不同品种同时转弱 = 最强信号

## 右侧逃命法（6-18视频新增）

> 一根上去又多，景线出来后长红低点一下就破 = 右侧逃命信号。

### 核心逻辑

```
右侧逃命识别：
Step 1：股价一根上去（大阳线突破）
Step 2：又多（后续继续上涨）
Step 3：颈线/景线出现
Step 4：长红低点一下就破 = 右侧逃命信号
Step 5：执行卖出，不抱幻想

右侧逃命 vs 右侧逃命：
├── 右侧一根上去又多 = 短暂诱多
├── 景线出来后长红低点破 = 确认逃命信号
└── "有一些右侧一根上去又多，右侧就所谓的右多"
```

### 与其他方法的联动

- **M6假突破**：右侧逃命本质上是假突破的反面——假突破后做多失败 = 逃命
- **颈线陷阱出货法**：颈线反弹后长红低点破 = 颈线陷阱的逃命信号

## 量先价行标记法（6-17视频补充）

> "量先价行"——成交量领先于价格变化。标记带量K线的高点/低点作为后续走势的参考。

### 标记规则

```
量先价行标记法：
Step 1：识别带量K线（成交量明显放大的K线）
Step 2：标记此K线的高点（上涨时）或低点（下跌时）
Step 3：后续价格突破/跌破此标记位 = 重要信号

带量K线的含义：
├── 上涨中带量大阳线 → 主力进场成本 → 回调不破此低点=健康
├── 上涨中天量长红 → 可能是头部信号
└── 下跌中带量大阴线 → 恐慌抛售 → 后续缩量翻红=底部
```

> 市场宽度指标是形态确认的"第二双眼睛"。单个股票/指数的形态可能骗人，但整个市场的宽度很难骗人。

### 核心宽度指标

| 指标 | 计算方法 | 形态确认含义 |
|------|----------|--------------|
| 涨跌家数比 | 上涨家数÷下跌家数 | >1.5=多头市场，<0.67=空头市场 |
| 新高新低比 | 创52周新高÷新低 | >2=强势，<0.5=弱势 |
| 上涨成交占比 | 上涨股成交额÷总成交额 | >60%=健康上涨，<40%=假涨 |
| 涨停跌停比 | 涨停家数÷跌停家数 | >3=强势，<0.33=恐慌 |

### 宽度与形态的配合

```
形态确认流程：
Step 1：识别形态（M1）
Step 2：画颈线（M2）
Step 3：量价验证（M3）
Step 4：宽度确认（M8）
  □ 突破时市场宽度是否配合？
    - 指数突破 + 涨跌比>1.5 + 新高比>2 → 强确认
    - 指数突破 + 涨跌比<1 + 新高比<1 → 弱确认（可能假突破）
Step 5：测幅满足（M4）
Step 6：多周期共振（M5）
```

### 宽度背离信号

| 背离类型 | 表现 | 含义 |
|----------|------|------|
| 价格新高+宽度下降 | 指数创新高但上涨家数减少 | 少数权重股拉动，市场实际转弱 |
| 价格新低+宽度上升 | 指数创新低但下跌家数减少 | 恐慌减弱，底部可能临近 |
| 放量突破+宽度不配合 | 指数放量突破但涨跌比不改善 | 资金集中在少数股票，非普涨 |

### 时间衰减权重

方法论不过期，观点会过期：

| 时间范围 | 观点权重 | 方法论权重 |
|----------|----------|------------|
| 7天内 | 100% | 100%（始终适用） |
| 1个月内 | 80% | 100% |
| 3个月内 | 60% | 100% |
| 6个月内 | 40% | 100% |
| 1年以上 | 20% | 100% |
