## 一、卖铲人框架（picks and shovels）

### 定义
淘金热里卖铲子的，即**基础设施 / 资本品供应商**：网络泡沫期的思科（路由器交换机）、AI 潮的 NVIDIA（GPU）、光伏扩产期的工业硅/设备、锂电扩产期的锂盐。

### 核心机制
```
卖铲人的收入 = 下游的资本开支（capex）
下游资本开支的回报 = 应用端的变现能力
```
**这两件事之间有一个 4–6 年的时滞。** 卖铲人先收钱（capex 立刻确认收入），应用端后收钱（要等基础设施变便宜）。

### 时滞的实证（美股互联网周期）
| 事件 | 时间 | 间隔 |
|---|---|---|
| 思科见顶 80.06 | 2000-03-27 | — |
| Google 上市 | 2004-08 | **约 4.4 年** |
| Meta（Facebook）上市 | 2012-05 | **约 12 年** |

**机制解释：** 应用端能起飞的前提是**基础设施变便宜**。思科崩了 → 设备便宜了 → Google 才能低成本建数据中心 → 应用端才起飞。
**所以：卖铲人崩盘是应用端起飞的前置条件，不是同时发生的事。** 两者不是跷跷板，是接力棒。

### 三条铁律
1. **看到"卖铲人赚翻"就去买卖铲人，是最贵的错误。** 赚翻的时候估值已经把红利预支完了。
2. **看到"卖铲人崩了"才该去找应用端**，而且要再等 2–4 年，不是崩完立刻买应用端。
3. **卖铲人内部会先发生一次转移**（从独占者 → 替代者），这次转移比"卖铲人 → 应用端"快得多，是**周级别**的，可以交易；后者是**年级别**的，只能配置。

## 二、思科案例：完整三段时间轴（真实数据，可直接引用）

| 节点 | 价格 | 关键数据 |
|---|---|---|
| 2000-03-27 收盘 | **80.06 美元** | 市值 5,555 亿，超微软（5,416 亿）成全球第一；**PE > 200，EV/Sales = 31** |
| 2002-10-11 收盘 | **8.12 美元** | **-87%**，市值缩到约 600 亿 |
| 2025-12-10 收盘 | **80.25 美元** | **首次收出更高价**，FT 口径 **25 年 8 个月 13 天** |

**同期基本面：** 营收近 5 倍、利润 4 倍、EPS 8 倍、毛利率全程健康。

### 核心公式（这个案例的全部价值在这一句）
```
股东回报 = EPS 增长 − PE 收缩
思科：   +700%   −  90%（200倍 → 20倍）  ≈  0
```
生意一路在增长，股东 25 年零回报。**所以正确表述不是"卖铲人吃不到红利"，是"产业吃到了，股东没吃到"。** 这个区分决定操作：能不能买跟行业景气无关，只跟你付的价格里预支了几年增长有关。

### PE 预支年数速查（用于快速判断"这个价配不配"）
| PE | 预支增长年数 | 隐含要求 |
|---|---|---|
| 20 倍 | 约 3 年 | 增长兑现率 > 15% |
| 40 倍 | 约 8 年 | 增长兑现率 > 25% |
| 100 倍 | 约 15 年 | 必须"这次不一样"且有硬证据 |
| 200 倍 | 约 25 年 | 思科实测，25 年才回本 |

## 三、两种死法：思科 vs 朗讯（这个区分比"泡沫"两个字有用一百倍）

| | 思科 | 朗讯 |
|---|---|---|
| 死因 | **估值** | **放贷** |
| 机制 | PE 200 倍，红利提前预支 | Lucent Credit 给 CLEC 客户提供**设备融资** |
| 传导 | 估值收缩，25 年横盘 | CLEC 倒闭潮 → 坏账 → 炸自己的资产负债表 |
| 结局 | 活着，跌 87%，25 年回本 | **84 美元 → 1 美元以下**，2006 被 Alcatel 收购，2016 归 Nokia |
| 特征 | 慢慢磨 | **快、狠、不可逆** |

### vendor financing 识别判据（新增工具）
盯三个科目的**合计值占营收比**的年度趋势：
```
（对客户的投资 + 应收账款 + 对外担保） / 营收
```
- **持续上升** → 朗讯路径（放贷型，凶险一个量级）
- **收敛** → 思科路径（估值型，慢慢磨）

**为什么 vendor financing 更凶：** 它把"卖设备"变成了"放贷"。设备卖出去时确认收入（账面漂亮），坏账来时是同时打掉应收 + 计提 + 需求消失，三重打击叠加。

### 循环融资的识别
```
A 公司投资 B 公司 → B 公司用这笔钱买 A 公司的产品 → A 公司确认收入
```
这就是循环融资。看到"供应商投资客户、客户反手采购"就该警觉。实证：朗讯（2000）、北电（2001）。

## 四、压低出货陷阱（蔡森原书案例，本文件补齐）

**案例就是思科：** 1997–2001 年，股价从 82 美元跌到 33 美元的"支撑区"，法人仍**持续出货**，最终跌到 11 美元。

### 铁律
**支撑区不是支撑，是出货区。** 尤其当：
- 该支撑是**起涨区**（主力长期成本远低于此）
- 法人/机构在跌到支撑时**仍在卖**
- 支撑位**放量不涨**

### 判据
| 现象 | 含义 |
|---|---|
| 支撑位缩量止跌 | 洗盘，可留 |
| 支撑位**放量不涨** | **出货**，必走 |
| 支撑位放量下跌 | 出货已确认 |
| 反复测试同一支撑不破但也不涨 | 在上方派发，不是筑底 |

**应用：** 任何"前低"被反复测试时，先怀疑出货，再谈支撑。前低不是买点，是**观察点**——带量破了才是空点。

## 五、体系升级：上缘做「否定判据」（本次讲课新增，原文档没有）

### 原用法（已有文档）
上缘 = 第二条颈线 = **突破加码点**：突破整理区上缘 → 主升浪启动 → 加码。

### 新增用法（本次补充，方向相反）
上缘 = **头部成立的否定判据**：
```
破颈线 → 反弹 → 不过整理区上缘  →  头部成立  →  看跌幅满足
                 过得上缘      →  假跌破，回补（原判断作废）
```

### 为什么要这一步
蔡森原话：「过去只看颈线，现在要看**线上面整理区的上缘**。因为内地（A股/商品）常出现**突破颈线一点，但过不了上缘**。」

**机制：** 假突破的常规动作是"穿线一点点"，用颈线做判据会被骗。上缘是**过滤假穿的筛子**——颈线是必要条件，上缘是充分条件。

### 判据优先级（新）
```
第一层：颈线（是不是破/过了）        —— 必要条件
第二层：整理区上缘（反弹能不能上去）  —— 充分条件
第三层：量（上缘处是放量突破还是缩量假穿）—— 确认
```
**三层都过才是信号，只过第一层是陷阱。**

## 六、防守条款：大盘空头时破底翻胜率只有五成（原文档缺，必须补）

| 大盘状态 | 个股破底翻成功率 | 动作 |
|---|---|---|
| 多头 | **70–80%** | 可用，正常仓位 |
| 空头 / 横盘 | **50%** | **等于抛硬币，不该做多** |

**推论（这是本次最重要的推导）：**
> 大盘空头时，破底翻只剩五成胜率，而**假突破做空的胜率不变**。
> 所以在空头市场里，唯一有正期望的动作是**找假突破做空**，不是找破底翻做多。

### 配套的仓位与停损（蔡森原话，讲话里跳过了）
- 停损 **5–7%**，机械执行：「跌破颈线就做空，站上颈线就停损」
- **高位进场最多 1–2 成资金**
- 做空要快狠准，**错过大跌不要追空**
- 只做波段（3 个月到半年），**不做短线**
- 有把握时 50% 以上，单票 ≤ 30%

### 动态止损压缩（1:3 的真实含义）
不是固定停损，是**随反弹上移把分母压小**：
```
进场：风险 3%  → 要求利润 ≥ 9%（1:3）
反弹 5% 后：风险压缩到 1–2% → 同一仓位变成 1:6
```
「部位控制好」= 分子分母都在动，不是仓位大小。

## 七、体系边界：条件 + 动作 ≠ 长期叙事（重要）

**蔡森体系只给"条件-动作"，不给长期预测：**
- ✅ 「跌破 148.80 带量做空，站回 148.80 停损，风险 3%」
- ❌ 「英伟达会像思科跌 20 年」

区别：
| | 条件-动作 | 长期叙事 |
|---|---|---|
| 能否下单 | 能 | 不能 |
| 能否证伪 | 能（价格一到就知道对错） | 不能（20 年后才知道） |
| 错了怎么办 | 停损 5% | 无解 |

### 铁律
**任何不能转成"价位 + 动作 + 停损"的判断，不得进入交易决策，只能作为背景。**

讲课中说"思科撑 15 年、20 年解套""NVIDIA 步入思科后尘"——这是宏观叙事，不是蔡森方法。**听着过瘾，但无法执行。** 学的时候要把它翻译成条件-动作，否则学了个寂寞。

## 八、应用示例：NVDA 2026-11（划线记录）

```
颈线：148.80（2026-11-12 年内最低，区间最低点连线）
现价：162.85（2026-11-13 收）—— 在颈线上方
昨天高点 243.37（2026-10-06）
```

**信号判定：**
- 现价在颈线**上方** → **无信号**，不追空（违反"错过大跌不追空"）
- **带量跌破 148.80** → 空点，停损站回 148.80，风险约 3–5% ✓ 符合 5–7% 规矩
- 反弹到 180–185 后**不过整理区上缘** → 头部成立的第二个确认

**目标测算的边界（必须说清）：**
```
颈线到头部距离 = 243.37 − 148.80 = 94.57
等幅外推第一波满足 = 148.80 − 94.57 ≈ 54
```
**这个数不能用来下单。** 等幅外推只适用于"型态完整、量价规范"的标的；NVIDIA 前瞻 PE 仅 13 倍、净利率 63.7%、营收同比 +100%，用纯技术等幅外推会得到荒谬结果（跌 67%）。**型态给位置，估值给空间**——两套逻辑不能混用。

**参考估值锚（与技术位分离使用）：**
| 位置 | 对应 | 性质 |
|---|---|---|
| 148.80 | 颈线（年内最低） | **技术信号位** |
| 135–145 | 约 11–12 倍前瞻 EPS | 估值接货区 |
| 110 以下 | 约 8–9 倍前瞻 | 需"2028 capex 断崖"被接受 |
| 185 | 11/10 收盘 + 缺口 | 证伪位（+13.6%） |
| 204 | 200 日均线 | 原证伪位，太远，不实用 |

## 十、一句话总结

> **卖铲人赚的是 capex，吃红利的是应用端，中间隔着 4–6 年。**
> **思科死于估值，朗讯死于放贷，两种死法要用两个指标分辨。**
> **上缘是筛子不是加码点——反弹过不了上缘，头就成了。**
> **大盘空头时破底翻只有五成，那时该做的是假突破，不是抄底。**
> **凡是不能写成"价位 + 动作 + 停损"的判断，都不是蔡森的方法。**
