## 一、事件研究法（Event Study）

### 1.1 标准事件研究流程

**步骤**：
1. **定义事件**：公告日、政策日、地缘事件日
2. **选择窗口**：
   - 估计窗口：[-120, -21]（估计正常收益模型）
   - 事件窗口：[-1, +1] / [0, +5] / [0, +10]（计算异常收益）
3. **估计正常收益**：
   - 市场模型：$E[R_{it}] = \alpha_i + \beta_i R_{mt}$
   - CAPM：$E[R_{it}] = R_f + \beta_i(R_m - R_f)$
   - Fama-French 三因子：$E[R_{it}] = \alpha + \beta_1 MktRF + \beta_2 SMB + \beta_3 HML$
   - Fama-French 五因子：+ $RMW$（盈利）+ $CMA$（投资）
4. **计算异常收益**：$AR_{it} = R_{it} - E[R_{it}]$
5. **累积异常收益**：$CAR_i(\tau_1, \tau_2) = \sum_{t=\tau_1}^{\tau_2} AR_{it}$
6. **统计检验**：
   - $t = \frac{\overline{CAR}}{\sigma(\overline{CAR})}$
   - 横截面 AR 的标准化检验（Patell Z / BMP Z / Adj. Patell Z）

### 1.2 异常交易量研究

- 相对成交量：$RVOL_t = V_t / \overline{V}_{estimation}$
- 异常成交量：$AVOL_t = V_t - E[V_t]$
- 用于识别信息泄露/提前反应

### 1.3 预期外事件 vs 预期内事件

| 类型 | 处理方式 | 示例 |
|------|---------|------|
| 完全意外 | 直接用 CAR | 突发地缘冲突 |
| 部分预期 | 用实际 vs 预期差值作为处理变量 | 非农就业 vs 预期中值 |
| 完全预期 | 事件研究可能无效，需用波动率变化 | 预先公告的选举 |

### 1.4 市场分析应用

**"美联储决议对黄金的影响"**：
- 事件日：FOMC 决议发布时刻
- 估计窗口：[-60, -2]
- 事件窗口：[0, +5]
- 正常收益模型：三因子模型（用 GLD 作为市场基准）
- 处理变量：意外降息幅度 = 实际降息 − 联邦基金期货隐含预期
- CAR(0,+5) 及其 t 值 → 量化政策冲击的金价效应

## 二、因子模型与收益归因

### 2.1 Fama-French 模型族

| 模型 | 因子 | 适用 |
|------|------|------|
| CAPM | 市场风险溢价 | 单因子基线 |
| FF3 | 市场 + 规模 (SMB) + 价值 (HML) | 经典三因子 |
| FF5 | FF3 + 盈利 (RMW) + 投资 (CMA) | 全面解释力 |
| Carhart 4 | FF3 + 动量 (MOM) | 短期动量效应 |
| Q-factor | 市场 + 投资 + ROE + 规模 | q理论因子 |

**时序回归（因子载荷）**：
$$R_{it} - R_f = \alpha_i + \sum_k \beta_{ik} f_{kt} + \epsilon_{it}$$

- $\alpha_i$（Jensen's Alpha）：因子无法解释的超额收益
- $\beta_{ik}$：对第 k 个因子的暴露
- $R^2$：因子解释力

### 2.2 收益归因分解

$$R_p = \underbrace{\sum_k \beta_{pk} f_k}_{\text{系统性收益}} + \underbrace{\alpha_p}_{\text{超额收益}} + \epsilon_p$$

- **Beta 收益**：承担系统性风险的回报（被动）
- **Alpha 收益**：选股/择时的能力（主动）
- **残差收益**：未被因子模型解释的部分

**归因维度**：
| 维度 | 分解方法 |
|------|---------|
| 资产配置 | Brinson 模型：行业权重 × 行业收益 vs 基准 |
| 个股选择 | 行业内个股收益 vs 行业基准 |
| 交互效应 | 权重 × 个股双重差异 |
| 因子暴露 | 每个因子的贡献 = $\beta_{ik} \times f_k$ |

### 2.3 市场分析应用

**"妙想选股池的收益来源"**：
- 对选股池构建等权/市值加权组合
- 用 FF5 + 动量回归，分解收益来源
- 如果 Alpha 显著为正 → 选股能力有效
- 如果 Beta（价值因子）贡献最大 → 收益主要来自价值暴露
- 因子拥挤度检验：因子收益率的历史分位

## 三、组合优化

### 3.1 均值-方差优化（MVO）

$$\max_{w} w^T \mu - \frac{\gamma}{2} w^T \Sigma w$$
$$\text{s.t.} \quad \mathbf{1}^T w = 1, \quad w \geq 0$$

- $\mu$：预期收益向量
- $\Sigma$：协方差矩阵
- $\gamma$：风险厌恶系数
- $w$：权重向量

### 3.2 Black-Litterman 模型

**解决 MVO 对输入参数极度敏感的问题**：
1. 从市场组合反推隐含均衡收益 $\Pi = \gamma \Sigma w_{mkt}$
2. 结合投资者观点：$E[R] = [(\tau\Sigma)^{-1} + P^T\Omega^{-1}P]^{-1}[(\tau\Sigma)^{-1}\Pi + P^T\Omega^{-1}Q]$
3. 用后验收益做 MVO

**观点矩阵**：
- $P$：观点矩阵（哪些资产之间的相对表现）
- $Q$：观点向量（预期超额收益）
- $\Omega$：观点不确定性矩阵

### 3.3 风险平价（Risk Parity）

$$w_i \propto \frac{1}{\sigma_i}$$

- 每个资产对组合风险的贡献相等
- 无需估计预期收益，只需波动率和相关性
- 适合作为稳健的基准配置

### 3.4 市场分析应用

**"六专家推荐标的的最优配置"**：
- 输入：各标的的历史收益、波动率、相关性
- 方法：Black-Litterman（结合专家观点）
- 约束：单标的权重上限、行业分散度
- 输出：最优权重 + 有效前沿图

## 四、风险度量

### 4.1 在险价值（VaR）

| 方法 | 公式 | 优势 | 劣势 |
|------|------|------|------|
| 历史模拟 | 经验分布的 5%/1% 分位 | 无分布假设 | 依赖历史样本 |
| 参数法（方差-协方差） | $VaR = \mu + z_\alpha \sigma$ | 简单快速 | 正态假设 |
| 蒙特卡洛 | 模拟 N 条路径取分位 | 灵活 | 模型风险 |

### 4.2 条件在险价值（CVaR / Expected Shortfall）

$$CVaR_\alpha = E[L | L > VaR_\alpha]$$

- 比 VaR 更好衡量尾部风险（ES 是一致性风险度量）
- Basel III 已用 ES 替代 VaR

### 4.3 最大回撤与 Calmar 比

- **最大回撤**：$\text{MaxDD} = \min_t \frac{P_t - \max_{s \leq t} P_s}{\max_{s \leq t} P_s}$
- **Calmar 比**：$\text{Calmar} = \frac{\text{年化收益}}{|\text{MaxDD}|}$

### 4.4 尾部风险指标

| 指标 | 计算 | 含义 |
|------|------|------|
| 偏度 | 三阶矩 | 负偏 = 尾部损失大 |
| 超额峰度 | 四阶矩 − 3 | 厚尾程度 |
| Hill 估计 | 尾部指数 | 极值理论 |
| VIX | 隐含波动率指数 | 市场恐慌定价 |

### 4.5 压力测试框架

**历史情景**：
| 情景 | 时段 | 典型资产表现 |
|------|------|------------|
| 2008 金融危机 | 2008.9-2009.3 | 标普-50%，原油-70%，黄金+10% |
| 2020 疫情 | 2020.2-2020.3 | 标普-34%（V型），美债收益率→0 |
| 2022 加息 | 2022 全年 | 标普-19%，美债-13%，美元+8% |
| 2024 日元carry trade | 2024.8.5 | 日经-12%（单日），全球股市闪崩 |

**假设情景模板**：
- 油价 +50% / -30%
- 美国10年期 +100bp / -100bp
- 美元指数 +5% / -5%
- VIX 跳升至 40+
- 人民币汇率贬值 5% / 升值 3%

**反向压力测试**：
1. 设定不可接受损失（如 -20%）
2. 倒推：什么组合情景会导致这个损失
3. 评估：这些情景发生的概率

### 4.6 市场分析应用

**"当前持仓在极端地缘冲突下的风险"**：
- 历史情景：2022 俄乌冲突期间各资产表现
- 蒙特卡洛：基于 Copula 的多资产联合分布模拟 10,000 条路径
- 输出：95%/99% VaR、CVaR、最大回撤分布
- 反向测试：什么样的冲击会导致 -20%？

## 五、时间序列预测与协整

### 5.1 ARIMA / SARIMA

$$\phi(B)(1-B)^d Y_t = \theta(B)\epsilon_t$$

- $p$：自回归阶数
- $d$：差分阶数
- $q$：移动平均阶数
- 季节性扩展：$(P,D,Q)_s$

### 5.2 向量自回归（VAR）

$$Y_t = c + A_1 Y_{t-1} + A_2 Y_{t-2} + ... + A_p Y_{t-p} + \epsilon_t$$

- 多变量动态系统
- 脉冲响应函数（IRF）：一个变量的冲击如何传导到其他变量
- 方差分解：各变量对预测误差方差的贡献

### 5.3 协整与误差修正模型（ECM）

**协整检验**：
- Engel-Granger 两步法：简单，适合两变量
- Johansen 检验：多变量，报告迹统计量和最大特征值统计量

**误差修正模型**：
$$\Delta Y_t = \alpha + \beta \cdot ECT_{t-1} + \sum \gamma_i \Delta Y_{t-i} + \epsilon_t$$

- $ECT_{t-1} = Y_{t-1} - \hat{\theta} X_{t-1}$：误差修正项
- $\beta$：向长期均衡调整的速度

**市场分析应用**：
- 黄金与美元的长期协整关系
- 油价与通胀的传导
- 美债收益率与A股估值的联动
- 当短期偏离协整关系时 → 均值回归信号

### 5.4 格兰杰因果检验

$$H_0: X \text{ 不 Granger-cause } Y$$

**注意**：Granger 因果**不是**真正的因果，只是"预测改进因果"——$X$ 的历史信息是否能改进 $Y$ 的预测。真正因果需要前述识别策略。

**市场分析应用**：
- 北向资金是否 Granger-cause A股收益
- 美元指数是否 Granger-cause 黄金收益
- PMI 是否 Granger-cause 工业品价格
