## 解剖发现（每条点名 Z 模块）

### 发现 1（Z1 需求→供给→落点三段式）：PPI +5.0% 的落点在"供给冲击"段，不是需求拉动

PPI 同比 +5.0%、购进 +6.9%、煤炭 +35.3%，但核心 CPI 仅 +1.0%、CPI +0.9%。按 Z1 三段式拆解：
- **需求段**：核心 CPI +1.0% 说明终端需求没起来，居民部门未全面加杠杆；
- **供给段**：能源 +32%（中东战争致供应 −5.2%）、硫磺 +210%（进口减少、库存腰斩）、煤炭 +35.3%（迎峰度冬 + 补库）——全是供给端冲击；
- **落点**：涨价停在上游生产资料，**未向下游传递**。

**读数**：这是"成本推动型再通胀"的结构指纹，不是"需求拉动型复苏"。落点与需求段背离，恰恰证明上游热≠经济热。

### 发现 2（Z2 存量 vs 增量双镜 + 份额镜像）：久期高位 + 增量涌入 = 拥挤"火药桶"

- **存量镜**：债基久期中枢 3.97 年（10-23 周），虽较 8/5 峰值 5.10 年回落，但仍处 3.97 的高位；
- **增量镜**：9 月债券托管净增 1.76 万亿，利率债为核心增持 → 边际买盘仍在涌入；
- **份额镜像（存款端）**：4–5 月居民存款连续两月下滑（存款搬家），增量资金从存款流向权益 / 商品，抽离债的边际买盘。

**读数**：存量久期偏高 + 增量涌入 + 负债端搬家，三者叠加构成今日长端大跌的"火药桶"——拥挤度是本质风险，而非单纯基本面。

### 发现 3（Z3 默契数识别 · 同一笔钱换马甲）：存款利率回升 = "负债端保卫战"，不是利率上行周期

工行 3Y 定存 1.25%→1.55%（+30bp），微众 1.60→1.75%，天津金城 1.75→2.1%；5Y 大额存单重启（恒丰 1.75% / 中信 3Y 1.70%）。表面像"加息"，但：
- **同一笔"无风险锚"在负债端被重新定价**——银行对长期资金**不愿付高息**（5Y<3Y 倒挂：1.571% vs 1.682%）；
- 这是"负债端保卫战"（挽留搬家存款），**不是资产端利率上行周期开启**。

**读数**：+30bp 是短期马甲，长期倒挂是真实身体。把存款加息误读为"利率周期反转"会系统性高估长端上行空间。

### 发现 4（Z9 三年纵列 + Z7 差分法）：降息周期"底部确认"，但定性为底部试探而非上行开启

3Y 定存三年纵列：2022 年 2.60% → 2025.5 的 1.25%（降息周期）→ 2026.10 的 1.55%（掉头）。
- 从 1.25% 掉头回升 = **降息周期见底**（存款利率是"无风险锚"，回升即抽走长债替代需求）；
- 但 5Y<3Y 倒挂说明**长期通缩预期未真正消除** → 拐点年定性为"底部试探"，而非"上行周期确认"。

**读数**：这是"负债端保卫战 + 利率底部试探"，与 2022–2025 的单向降息是不同性质。

### 发现 5（Z10 M1/M2/M0 三元勾稽 + Z11 期限结构）：曲线走平 + 倒挂，但关键缺口未补

- **期限结构（Z11）**：10Y−1Y 利差 44.5bp 收窄（曲线走平）；存款 5Y<3Y 倒挂 → 长端谨慎；
- **三元勾稽（Z10）**：M1 / M2、社融 10 月数据**尚未公布**（11 月中旬）→ 本期无法做完整的"钱在干什么"勾稽。

**读数**：宽信用是否真见效，是最大未知项，也是原报告置信度 66（未给 75+）的根本原因。在数据落地前，一切债市方向判断须按**波段而非趋势**处理。

### 发现 6（Z12 季节性利好失效检验）：利率债增持 + 利多钝化 = 利好已 price-in

9 月利率债托管净增 1.76 万亿（核心增持），但 10Y 此前逼近 1.60% 历史大底、降准降息不落地、11 月"宽信用"预期升温 → **传统债牛的利好已被充分交易，边际利多钝化**。

**读数**：当"增持"遇上"利多钝化"，拥挤头寸最脆弱。今日大跌是钝化后的自我了结，属 Z12 失效信号兑现。

### 发现 7（Z13 同源数据双叙事拆解）：同一根大阴线，两个都成立、但时标不同

| 叙事 A（技术） | 叙事 B（基本面） | 本框架裁决 |
|---|---|---|
| "通缩交易平仓"：拥挤多头在边际增量枯竭后自我了结（股债跷跷板 + 资金收敛 + 久期高位 + 利多钝化四线共振） | "再通胀确认"：商品点火 → PPI → 存款利率 → 长债投降，一条成本传导链落地 | **两叙事同源于"长端利率上行"，但时标不同**：A 是短期技术面（平仓），B 是中期基本面（再通胀）。本轮裁决——**叙事切换已发生，但性质偏"温和滞胀"而非健康复苏** |

**读数**：把今日跌简单归为"技术回调"会漏掉 B 叙事；把今日跌当成"再通胀周期开启"会忽略 A 叙事的短期性 + 供给冲击属性。

## 框架遗漏项（引用本档案方向性判断前必须补齐）

**真实财经系统性偏悲观，引用其方向性结论前必须先补 4 项标准遗漏读数**：
1. **贷款利率历史低位**：未言及——若实体融资成本已低，需求未必崩，债市承压有底；
2. **结构性贷款高增**：绿色 / 科创等定向宽信用在发力，部分对冲总量放缓；
3. **外币贷款多增**：外贸 / 外需部门有韧性，不可一概而论"内需塌方"；
4. **单月社融环比回升**：待 11 月中旬公布，若回升则宽信用兑现、债市判断需下修。

**本议题特有遗漏**（原报告已承认，此处显式列出）：
5. **10 月社融 / M1–M2 未公布**——宽信用是否兑现是核心缺口，置信度 66 未给 75+ 即源于此；
6. **存款 5Y<3Y 倒挂**——长期通缩预期未消，不能简单判"利率上行周期"；
7. **中金固收"三股力量仍在"**（供给回落 / 资金宽松 / 避险需求）中期支撑**未被证伪**，与光大"短期压制"不矛盾——中期支撑未破，短期压制占上风；
8. **PPI 是供给冲击驱动**（能源 / 硫磺靠地缘与进口减少），若中东缓和则 PPI 回落、再通胀叙事弱化。

## 反共识标记 + 证伪位

**与市场共识相反（本框架立场）**：
1. 市场把今日跌理解为"技术回调" → 本框架读为**"通缩交易叙事切换"**（更深层，四线共振而非单因）；
2. 市场或预期"存款加息 = 利率上行周期" → 本框架读为**"负债端保卫战 + 底部试探"**（非趋势反转，5Y<3Y 倒挂为证）。

**证伪位（任一触发即重跑 / 反转）**：
- **10Y 有效跌破 1.60%**（创历史新低）→ 主判断失效，转看多债券（通缩交易未被证伪）；
- **11 月中旬社融公布显示宽信用确凿兑现**（社融 / M1 明显回升）→ 债市承压加重，长端目标位上修；
- **存款 5Y 回到 3Y 上方** → 长期通缩预期真正消除，利率上行周期判断升级；
- **核心 CPI 站上 1.5%** → 需求跟上，"滞胀"判读削弱、转向健康复苏。
