## D2 五面镜子（「找不同地方真实反馈」的可执行版）

每次分析强制过 5 个互不相关的反馈面，每面至少取 1 条证据卡，做成表格：

| 镜子 | 问的问题 | 典型源 |
|---|---|---|
| 💰 钱 | 市场自己用真金白银投了什么票？ | 基差 / 期限结构 / 隐波偏斜 / CFTC COT / ETF 流 / 融券 / 预测市场赔率 |
| 📦 货 | 实物有没有真的在动？ | 库存 / 仓单 / 开工率 / BDI·SCFI 运价 / 港口吞吐 / 海关 HS 分项 / 发电量 |
| 👤 人 | 组织在扩张还是收缩？ | 招聘岗位数与薪资 / 裁员公告 / 高管变动 / 增减持 / 员工人数 |
| 📄 单 | 有没有真的签下来的合同？ | 招投标中标 / 上下游上市公司交叉验证 / 互动易问答 / 产能备案 / 验厂认证 |
| 🗣 嘴 | 大家在说什么？ | 股吧 / 雪球 / Reddit / X / 卖方一致预期 / 新基金发行 / 搜索指数 |

**背离警报**：若「💰钱」与「🗣嘴」方向相反，必须在报告里单列一节「钱嘴背离」并优先深挖。这一条接笨鸟 M4 反常信号识别法，是全流程信息密度最高的一格。

**说明现状**：当前框架实际只覆盖第 5 面（股吧，且仅 L4 执行），前 4 面基本空白。

## D4 反向取证

形成主结论前，强制做一次以「我错了」为前提的搜索，query 直接写反方立场。

- 例：主结论看多原油 → 搜「油价见顶 供应过剩 需求破坏 OPEC增产 页岩复产」。
- 至少产出 1 张 `direction=反向` 的证据卡。
- 找不到有力反方也必须落一张「未发现有力反方证据」卡 —— 这本身是强信息：共识高度一致通常意味着已被定价甚至是拥挤交易，应当**下调**而非上调置信度。
