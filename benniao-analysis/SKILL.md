# 笨鸟宏观数据拆解方法论

> **核心定位**：这是一套**研究方法**，不是观点集合。每次分析时，按方法论独立推导结论。笨鸟本人的观点只是方法论的实战示例。

## 工作流程 / 使用步骤
1. 明确分析对象：宏观数据、政策表态，还是跨资产（金/银/铜/油/股/债/汇）传导。
2. 在下方参考索引中选取对应方法论（如 M1 数据拆解法、M9 美债危机三层拆解法、M19 石油-美联储协同逼债法）。
3. 严格按该方法的「第一步…第N步」逐步推导，并用 M23 前后表态交叉验证 / M24 政策文本模块化拆解等校验工具交叉验证。
4. 参照 `references/cases.md` 实战案例对照校验结论，用 `references/meta.md` 的方法论组合使用指南做多方法联动。
5. 输出：独立推导的结论 + 不确定性说明，区分「方法论推导」与「观点示例」。
